This public review bundle presents an AI-generated research hypothesis tree across four life-science domains. Each node is one recorded hypothesis version or starting question. Lines preserve actual derivation; a leaf is a node with no child. The scientific questions are proposals for review, not confirmed findings.

The catalog is organized by domain and dataset. Related questions from separate research paths can appear together, but no relationship is drawn unless it is present in the recorded lineage. Dataset labels describe the source used or the seed study family; they are not a claim that a result has been reproduced.

For expert feedback, see [the review guide](REVIEW.md). Each node links to the **full scientific proposal with internal references redacted**. The short titles help navigate the forest; read the linked proposal before scientific review. Internal file paths, run identifiers, and source checksums have been masked. The public copy contains no raw source datasets, separate model task instructions, native execution traces, or executable research packages.


A private archive retains the exact recorded originals. This public edition preserves their scientific content while masking internal references.
