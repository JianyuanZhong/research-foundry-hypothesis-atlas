## 6. Exact whole-patient deletion estimand and incompatibility resolution

For a full original world `omega=(g,{s_i},{tau_i}) in Omega_book+`, define `omega\D` only as its restriction to retained patients. No post-deletion reinterpretation or source-state reselection is permitted within a before/after witness. Optimization ranges over original full worlds and deletion sets jointly, so every retained projection is covered without creating a new class of worlds.

The exact coordinate-specific breakdown radius is:

`q_e^* = min{|D|: D subset U_T, omega in Omega_book+, N_a(omega\D)>=K, Delta_e(omega\D)<=5}`,

with `q_e^*=+infinity` if no feasible adverse deletion exists. Thus:

- `q_e^*=0` exactly when the undeleted universal margin already fails;
- `q_e^*=1`, after the K+1 gate, is an attained patient/world witness that one whole-patient deletion breaks the strict margin;
- `q_e^*>1` proves every singleton patient deletion retains the strict margin under every remaining source/terminal world and all nine global book pairs;
- a finite `q_e^*=r` is the smallest attained feasible deletion count, while claims about larger deletions must retain the `N_a>=K` qualification;
- `+infinity` requires an exact infeasibility certificate for the adverse constraint over all feasible deletions.

The denominator remains exactly K after deletion: lower-ranked retained patients replace deleted selected patients according to the original locked score order. K is not recomputed from the smaller corpus. For each deletion coordinate and g, use binary `z_i` for whole-patient deletion, with local-state variables satisfying `sum_h x_ih = 1-z_i`, and use the same `z_i,x_ih` in both arms. ## 8. One-hot conclusion logic and falsification

Mandatory source, roster, six-book, nine-pair, terminal regeneration, chronology, event, grid, fit, quotient, K/K+1, replay, and exact-solver gates are evaluated first. Any failure yields `inconclusive` with precedence.

After all gates pass, classify each coordinate exactly once:

1. `stable-supportive` if `delta_e^->5` and `q_e^*>1`;
2. `supportive-but-single-patient-fragile` if `delta_e^->5` and `q_e^*=1`;
3. `heterogeneous` if `delta_e^-<=5<delta_e^+`;
4. `universal-adverse` if `delta_e^+<=5`.

Because `q_e^*=0` whenever `delta_e^-<=5`, these are mutually exclusive and exhaustive after gates. Equality at 5 belongs to heterogeneous or adverse, never supportive.

Emit exactly one global code:

1. `whole-panel-deletion-stable-supportive` iff all four coordinates are stable-supportive;
2. `whole-panel-supportive-but-single-patient-fragile` iff all four undeleted lower endpoints exceed 5 and at least one coordinate is fragile;
3. `universal-adverse-without-positive-coordinate` iff all four coordinates are universal-adverse;
4. `decisive-heterogeneity` for every other complete result, including mixtures of coordinate classes; retain the primary parent's fixed-other radiology-, pathology-, and joint-panel witness rules;
5. `inconclusive` with precedence for any mandatory failure.

The first result supports only: within this frozen eventual-report corpus, both fixed-K documentary-M2 margins exceeded 5 under every declared source/pathology-completion and actual whole-reader-book pair in each test year, and no one whole test-patient deletion reversed either margin. It does not establish population confidence, unseen-reader robustness, correct labels, preoperative visibility, biological M2, utility, or deployment readiness.

Fragility falsifies the successor stability conjunction but not the undeleted parent conjunction; it means one attained deletion can make a coordinate fail, not that the patient is an outlier or error. Heterogeneity falsifies universal robustness and identifies an attained dependency, not a true reader or source state. Universal adverse falsifies the strict margin in all declared worlds but does not prove semantic features useless or rule out smaller documentary gains. Inconclusive is neither supportive nor adverse evidence.
