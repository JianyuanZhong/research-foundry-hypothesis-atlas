## Primary hypothesis and estimand

Let d=(A->B) be low->high or high->low, with A the source stratum and B the opposite target stratum. Let eta^A be the target linear predictor from source-trained frozen R_full and p0=expit(eta^A). Let delta_A be the source-stratum offset below and ptr=expit(eta^A+delta_A).

For score p, define z(p)=1[p>=0.10], including ties. For s in {0,1} denoting F_available and z in {0,1}, define
E_d(p;s,z)=mean(D7-p) over target people in B with F_available=s and z(p)=z.
Define qtr(d)=max_{s,z}|E_d(ptr;s,z)|, q0(d)=max_{s,z}|E_d(p0;s,z)|, and Itr(d)=q0(d)-qtr(d). The bidirectional estimands are qtr*=max_d qtr(d) and Itr*=min_d Itr(d).

H_transport is supportive only if lower95(Itr*)>=0.02 and upper95(qtr*)<=0.05, all eight original transferred-score cells have n>=30, at least 1,900 of 2,000 joint copied-hospital replicates are finite, and neither direction fails the prespecified deletion-stability gate below. Show both directions and all eight component errors; do not average directions or select a favorable side. This tests threshold-cell calibration-in-the-large, not individual calibration or clinical utility.

A valid lower95(qtr*)>0.05 is adverse for the portable-threshold screen. A valid upper95(Itr*)<0.02 is adverse for the material improvement screen. Intervals that straddle a boundary are inconclusive. If q0 already passes 0.05, state that no threshold deficit was demonstrated; failure of Itr remains failure to show a material benefit from transfer, not evidence of clinical harm.

Secondary quantities are q0 and its eight cells; target-hospital-held-out local recalibration qloc and Iloc; source-stratum constant-risk baseline; receiving-stratum prevalence as descriptive oracle only; transfer gap G(d)=qtr(d)-qloc(d); and delta_A-delta_{B,all} descriptively. qloc is fit from target labels excluding each held-out target hospital and is not a label-free deployment method. A local-only pass with transfer failure supports only the need for local labels. A transfer pass with rank failure cannot support a queue.

## Offset procedures

For primary delta_A, perform leave-one-source-hospital-out R_full fits. For each source hospital g, fit preprocessing and model using all other source hospitals and score g, yielding eta^(A,-g). Pool all source held-out pairs and solve by deterministic bisection on [-20,20], tolerance 1e-12:
sum_i[D7_i-expit(eta^(A,-g)_i+delta_A)]-delta_A=0.
The -delta penalty makes the root unique under separation. Then refit R_full on all source hospitals, score target people, and apply the unchanged delta_A. No target label enters p^tr. This nested source cross-fit prevents an optimistic in-sample calibration offset.

For qloc, use the full source-trained eta^A and, for each target hospital h, solve the same penalized equation using all target people in other target hospitals, then score h only. No held-out-hospital label may enter. Empty calibration sets or nonfinite roots are not-computable, not reasons to pool labels.
