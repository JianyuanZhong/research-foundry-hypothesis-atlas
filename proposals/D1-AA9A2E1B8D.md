## 4. Complete pathology-reader envelope

## 6. Falsification and interpretation

After all gates pass, each coordinate is:
- supportive iff `delta_e^->5`;
- heterogeneous iff `delta_e^-<=5<delta_e^+`;
- all-world adverse iff `delta_e^+<=5`.
Equality to 5 is adverse to the strict hypothesis.

The global result is:
1. `universal-supportive` only if all four year-by-contrast lower endpoints exceed 5;
2. `decisive-heterogeneity` if at least one world/coordinate exceeds 5 and at least one fails;
3. `universal-adverse-without-positive-coordinate` if all four upper endpoints are at most 5;
4. `inconclusive` if any source, annotation, event, fit, state-completeness, replay, or solver gate fails.

Support permits only: within this frozen eventual-report corpus, canonical report concepts added more than 5 encounter-documentary M2 captures per 100 fixed positions under every declared source and supplied radiology/pathology interpretation world in both test years. Heterogeneity or adverse results falsify the universal margin, not all semantic value or smaller effects. Inconclusive is not negative evidence. No result establishes confidence-interval coverage, clinical utility, biological M2, real-time deployability, causal effect, treatment benefit, or transportability.
