# Is an in-hospital drop in ICU laboratory draw intensity a monitoring-need signal or a dying-patient anticipation artifact? An informativeness-bounded child of the eICU draw-intensity branch

Lead working proposal — eICU 2.0 island, **episode 28**. Operation: **evolve** of true parent
`[prior hypothesis]` (valid, delivery-complete, mu 32.24, episode-27; itself an
episode-26/27 evolution rooted in expert seed `[starting question]`, "Reduced testing and
subsequent deterioration"). Status: **design owned by the Lead for compilation.** Discovery executed
bounded read-only probes (see §7); no solver/reference estimator was run. **Readiness, not a solved result.**

## 1. Unresolved question and clinical importance

ICU teams control how often laboratory tests are drawn. The decision-facing question is whether a
**within-hospital fall in clinical-panel draw rate, while the patient is still physiologically unstable**,
marks *unmet monitoring need* (fewer draws → missed deterioration → later escalation), or whether it is
mostly a **between-hospital practice fingerprint** and/or **anticipation** (clinicians drawing less because
they already judge the patient will die). The parent branch had one remaining, explicitly recorded
weakness: its falsification of the anticipation rival R5 relied on a **global** documented end-of-life (EOL)
prevalence and, more importantly, **no estimator was ever executed and the informativeness of the R5
stratum was never bounded** — an "attenuation" result in a small stratum could be indistinguishable from
an underpowered null.

**This child closes exactly that gap.** It preserves the parent's frozen population, exposure, outcome,
landmark, severity adjustment, within-vs-between decomposition, E-value rule and leave-one-hospital-out
(LOHO) transport, and adds **one pre-specified, computable output**: a minimum detectable effect (MDE) /
informativeness rule for the zero-documented-EOL stratum, so the R5 test is classified as *informative*,
*underpowered/inconclusive*, or *undecidable* before any causal reading is permitted.

Why it matters clinically: ICU "reduce routine testing" de-implementation is an active policy question
([K2] is a stepped-wedge RCT protocol whose primary outcome is 30-day mortality). If lower draw intensity
is a *patient-state* signal, then de-implementation must be accompanied by escalation safeguards; if it is
a *hospital* fingerprint, de-implementation is safer and monitoring-intensity indices carry no bedside
information. [K1] established that the *presence and timing* of a lab order carries survival signal beyond
the value, so draw intensity is a legitimate physiological-process variable — but it does not settle the
within-patient vs between-hospital question, and it did not test anticipation.

## 2. Evidence: what is established vs what is tested

- Established: test-order presence/timing predicts survival beyond test values in a large two-hospital EHR
  cohort ([K1], abstract). Reducing routine ICU lab testing is being tested with mortality as the primary
  outcome ([K2], protocol/abstract — **no effect estimate exists yet**). The E-value bounds single-confounder
  robustness ([K3], abstract).
- To be tested (this child, falsifiable): **within hospitals, does a 24→48 h fall in panel draw rate
  precede higher 48→72 h escalation, and does that association survive (a) severity adjustment,
  (b) an E-value bound, (c) LOHO transport, and (d) restriction to zero-documented-EOL hospitals?**
- Falsification of R5 requires the zero-EOL stratum to be *informative*, which is what the new output computes.
  Note the scope limit: documented EOL is a *code*, not the clinician's true judgment; absence of an EOL code
  does not prove absence of anticipation.

## 3. Population, temporal boundaries, variables, outcome

- **Source:** eICU 2.0, read-only: `[internal dataset path]`.
- **Population:** adult ICU stays (`patient.csv.gz`) alive at the 24 h landmark, `unitdischargeoffset >= 1440`
  (minutes); analytic unit = `patientunitstayid`; hospital = `patient.hospitalid`. Decedents before 24 h excluded.
- **Exposure:** panel draw-rate change, `R_24_48 − R_0_24`, where rate = distinct `(patientunitstayid,
  labresultoffset)` panel draws per hour from `lab.csv.gz` restricted to the clinical panel `labname`
  strings verified in the probe. Standardized within hospital.
- **Outcome:** binary escalation proxy in the 48–72 h window — initiation of a vasopressor
  (`infusionDrug.csv.gz`) or invasive ventilation (`respiratoryCare.csv.gz`/`treatment.csv.gz`), with an
  explicit `*offset` definition; secondary outcome = in-hospital mortality (`unitdischargestatus`/`hospitaldischargestatus`).
- **Landmark/washout:** exposure measured 0–24 h → 24–48 h; outcome 48–72 h; hour-12 placebo landmark
  and a 48 h washout separate exposure from outcome to respect temporal ordering.
- **Severity adjustment:** APACHE IVa (`apachePatientResult.apachescore`, `apacheversion`) plus 24 h physiology.
- **Rivals:** R1 severity/improvement confounding (removed by 24 h-physiology adjustment); R2 hospital
  fingerprint (hospital fixed effects + LOHO); R3 reverse ordering (placebo landmark); R4 measurement
  (channel-disjoint negative-control chronic-diagnosis outcome); **R5 documented-EOL anticipation**
  (hospital-stratified bound + zero-EOL stratum).

## 4. Analysis and pre-specified outcomes

- **Primary estimand:** β_W, the within-hospital coefficient of standardized exposure on the escalation
  proxy from a hospital-fixed-effects logistic model, adjusted for severity.
- **Decomposition:** β_W (within) vs β_B (between-hospital) reported separately.
- **Robustness:** E-value for β_W and for its CI limit nearest the null ([K3]); LOHO transport (fit
  leaving one hospital out, predict it) as an internal transport test.
- **NEW — informativeness rule (the child's added output):** in the zero-documented-EOL stratum, compute
  the MDE for β_W at 80% power, α = 0.05 (exact test + formula stated in `feasibility.md`), given the
  observed N and event count. Pre-specified reading:
  - **informative** — MDE < the parent's targeted effect ⇒ the R5 test can distinguish H1 from its rival;
  - **underpowered/inconclusive** — MDE ≥ targeted effect ⇒ any null in that stratum is uninformative;
  - **undecidable** — required columns absent ⇒ report honestly, do not infer.
- **Interpretation map:** β_W negative and robust *and* preserved in zero-EOL hospitals with a large E-value
  ⇒ supportive of unmet-monitoring-need (still observational, not causal). β_W attenuates once EOL hospitals
  are removed or is fully absorbed by between-hospital variation ⇒ adverse for H1 / supportive of R5/R2.
  A wide CI spanning null in an underpowered stratum ⇒ **inconclusive**, not refutation.

## 5. Baselines and the substantive alternative (method comparison)

- **Baseline (simple):** hospital-fixed-effects logistic regression, exposure + APACHE severity; interpretable
  coefficient and E-value.
- **Alternative (learned):** gradient-boosted trees over value-only features vs process features (draw counts,
  distinct analytes, never-measured analytes) on the same hospital-held-out split, to test whether
  **non-linear process interactions** carry within-hospital information the linear baseline loses. If the
  GBT does not improve held-out discrimination/calibration over the linear model, the simpler estimator is
  scientifically adequate and is retained (no complexity-for-its-own-sake).
- **Selection/deferral:** CPU is sufficient (tabular fits, ~1.3e5 stays); GBT is the only added compute.
  A sequence/neural model is deferred as unjustified for this question size.
