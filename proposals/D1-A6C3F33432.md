# Does one prior same-assay value improve the repeat-TACE decision-time forecast?

## Clinical decision and exact unresolved claim

At a recorded repeat-TACE encounter, a clinician already has the contemporaneous same-assay value `P` and may be able to retrieve the remote pre-TACE2 value `B`. The practical monitoring question is whether displaying one additional, leakage-safe, latest intermediate value `L` improves the forecast of the next observed albumin or total-bilirubin result enough to justify treating serial history as informative, rather than merely showing that frequently tested patients differ from infrequently tested patients.

The strongest claim supported before outcome analysis is **feasibility only**. The inherited complete-source, outcome-direction-blind audit scanned every row in the five required HCC sources with no sampling. It reproduced 319 systemic-record and 1,491 comparator pathway patients, 159/526 independently selected repeat events, albumin `B/P/Y` triplets in 40/118 patients, bilirubin triplets in 41/119, and a qualifying intermediate value in 37/40 and 108/118 albumin triplets and 38/41 and 108/119 bilirubin triplets. Median intermediate timestamp count was one in each arm and assay; only 18 systemic and 42 comparator patients per assay had at least two intermediate timestamps. It did not summarize `Y`, direction, association, or fitted performance.

The unresolved falsifiable claim is:

> Conditional on the same current value `P`, remote anchor `B`, compact pre-event covariates, and explicit indicators of whether, how often, and how recently intermediate testing occurred, adding the numeric latest intermediate value `L` reduces paired out-of-fold prediction error for the next observed same-assay value `Y`.

This child narrows the parent to that one decision-relevant contrast. It does not ask whether “all history” beats `P`, does not fit a trajectory, and does not interpret measurement frequency as biology. A supportive result could justify external validation of a compact three-value display or decision-support forecast. A precise null would support the simpler conclusion that retrieving the intermediate numeric result is not predictively useful at the prespecified margin once current value, remote anchor, and measurement metadata are known. An adverse result would caution that adding it can worsen transportable forecasts under this model. None of those findings establishes that testing should be ordered, omitted, or timed differently.

## One primary contrast, with a fixed estimator

Fit the following two models on exactly the same assay-specific triplet patients and folds:

`M_meta: Y ~ P + B + arm + age + sex + TACE2_to_repeat_days + P_lead_hours + H_any + logN + R_hours`

`M_value: Y ~ P + B + arm + age + sex + TACE2_to_repeat_days + P_lead_hours + H_any + logN + R_hours + L`

`P_lead_hours=event_time−P_time >0`. The models differ only by `L`. `H_any`, `logN`, and `R_hours` are measurement-process metadata, not trajectory variables. This exact nesting prevents a gain caused merely by adding evidence that a test occurred or by changing the base model between comparisons.

Encode arm as systemic versus comparator. Age is numeric and outer-training median-imputed; include an age-missing indicator only if it varies in that training fold. Literal male is the sex reference; create fixed female and unknown/other/missing indicators, dropping variance-zero indicators by the same deterministic rule in both models. Outer-training median-impute missing `L/R_hours`, variance-filter, center, and scale all continuous predictors; apply those parameters unchanged to held-out patients. The intercept is unpenalized.

Use linear ridge regression with **fixed `alpha=1`**, defined by minimizing `sum_i (Y_i−prediction_i)^2 + alpha * sum_j beta_j^2` over non-intercept standardized coefficients. This removes the parent's nested leave-one-patient-out tuning loop and its implementation ambiguity. As prespecified model-dependence sensitivities only, repeat the complete five-fold analysis at `alpha=0.1` and `alpha=10`; they cannot replace or select the primary result.

The sole primary assay-specific estimand is:

`Delta_L = [RMSE_OOF(M_meta) − RMSE_OOF(M_value)] / SD(Y)`.

Compute both RMSEs from pooled paired held-out predictions, and compute sample `SD(Y)` once in the full assay-specific evaluation cohort. Higher values favor `L`. Also report native RMSE and MAE for both models, standardized paired MAE gain, pooled cross-fitted R-squared, prediction mean/variance, calibration intercept and slope, fold-specific errors, and arm-stratified descriptive errors. Do not infer an arm-specific history effect or fit an interaction.

## Deterministic interpretation branches

Apply in this order, separately by assay:

1. **Negative-feasibility/reconstruction-inconclusive:** source/snapshot/hash mismatch; failure to reproduce frozen pathway, repeat-event, parser, triplet, history, or r00 fold facts; join or clock violation. Do not widen windows or replace `L`.
2. **Computationally inconclusive:** nonfinite or rank-deficient post-drop training matrix, held-out arm below five, `SD(Y)=0`, ridge failure, or fewer than 95% estimable primary bootstraps.
3. **Selection-, linkage-, partition-, model-, or influence-sensitive:** any corresponding prespecified check fails. Report the point estimate but do not call it reliable support.
4. **Adverse degradation:** prior gates pass and the 95% interval for `Delta_L` lies wholly below zero. Conclude only that adding `L` worsened prediction under the locked model.
5. **Supportive numeric-history evidence:** prior gates pass; r00 `Delta_L >=0.05`; its 95% interval excludes zero; Holm-adjusted one-sided tail probability is `<0.05` when making a family statement; standardized paired MAE gain is nonnegative; linkage destruction does not reproduce the gain; all five partition estimates are positive with median `>=0.05`; and both penalty sensitivities remain positive. Conclude only that the numeric latest intermediate result adds reproducible short-horizon prediction beyond current `P`, remote `B`, compact covariates, and measurement presence/count/recency in these selected observed repeat-TACE episodes.
6. **Precise null for the prespecified increment:** prior gates pass and the interval upper bound is `<0.05`. Conclude that this experiment rules out a standardized RMSE gain of 0.05 under the locked model and cohort. This is not equivalence of all possible history summaries and not evidence that intermediate testing is clinically unnecessary.
7. **No demonstrated increment:** prior gates pass but the point estimate is `<0.05`, linkage permutation is comparable, or MAE does not improve, without meeting adverse or precise-null criteria. Conclude that current `P`, remote `B`, and measurement metadata may exhaust the available signal.
8. **Inconclusive:** the interval spans both degradation and `+0.05`, or any remaining prespecified ambiguity exists.

A two-assay statement requires both assays to reach the same branch after Holm correction; otherwise report assay-specific conclusions. The `0.05` standardized-RMSE margin is a prespecified design convention, not an established clinically important difference.

## Meaning for clinical decisions and strict limits

- **Supportive:** warrants external/prospective validation of a compact same-assay history display or forecast before considering workflow use. It does not show that ordering another test improves outcomes or that repeat TACE should be delayed, canceled, or modified.
- **Precise null:** favors a simpler predictive display using `P`, `B`, and metadata in this cohort/model; it does not justify suppressing tests because tests may serve purposes not represented by `Y`.
- **Adverse:** cautions against naively adding `L` to this forecast; it may reflect noise, model misspecification, or setting-specific measurement practice.
- **Selection-sensitive/inconclusive:** indicates that the observed-triplet result does not transport reliably even to the selected repeat-event cohort under the measured observation model.
- **Negative feasibility:** confirms that these records cannot test whether a measurement 1–2 weeks before repeat TACE is uniquely decision-proximal.

HCC lacks laboratory units/reference ranges and analyzer harmonization; adjudicated hepatic decompensation, complications, Child–Pugh/MELD context, tumor burden/radiographic response, technical TACE success or intent, albumin infusion/transfusion/fluid balance, infection/bleeding, verified medication administration/adherence/dose, outside care, reliable death, and clinician action. `Y` is the next *observed* assay value, not hepatic failure or clinical benefit. Conditioning on repeat TACE and complete triplets can induce selection/collider bias. Diagnoses are lexical encounter proxies without native timestamps.
