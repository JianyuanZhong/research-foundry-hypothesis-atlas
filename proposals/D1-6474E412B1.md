## Executable missing-Y audit

The compiler must materialize one row per BP-eligible test episode per assay/origin/block in a private intermediate table with `patient_id`, `arm`, event identifiers, `y` (finite value or null), fixed finite predictions `p0` and `p1`, and no raw text. The source reconstruction must prove that every BP row appears exactly once and that `y` was read only after BP eligibility. The implementation is `[internal dataset path]`; its executed self-test passed and is an arithmetic/status test, not an HCC estimate.

For each assay, origin, future block, and also each arm separately:

1. Define `N` as all BP-eligible rows, or `N_a` for arm `a`; `n_mis` is rows with null Y. Never use complete-triplet count as a bound denominator.
2. Define `L_train=min(Y_train)` and `U_train=max(Y_train)` over the exact finite training parser before looking at future Y. Empty or degenerate range, or any observed future Y outside `[L_train,U_train]`, yields `unsupported` for the temporal bound; do not widen the range with future or full-source values. A no-observed-future block may report the training observed-Y mean only as a training-derived tipping coordinate.
3. For observed rows calculate `d_i=(Y_i-p0_i)^2-(Y_i-p1_i)^2`. For missing rows calculate the affine endpoints `d_i(L_train)` and `d_i(U_train)`. The sharp fixed-prediction contrast bounds are

```
Delta_lower = (sum_observed d_i + sum_missing min(d_i(L),d_i(U))) / N
Delta_upper = (sum_observed d_i + sum_missing max(d_i(L),d_i(U))) / N
```

The identity `d_i(y)=2y(p1_i-p0_i)+p0_i^2-p1_i^2` must be checked, and endpoint values directly evaluated. Report `N`, observed, missing, missing fraction, observed sum, missing endpoint sums, and both arm-specific denominators.
4. Report three deterministic completions, retaining observed Y: every missing Y set to L; every missing Y set to U; and the least-favorable endpoint for the lower M0-minus-M1 contrast, choosing L when `2(p1-p0)>=0`, otherwise U.
5. Separately calculate model-specific SSE/MSE endpoint bounds using `(clip(p_j,L,U)-p_j)^2` and `max((L-p_j)^2,(U-p_j)^2)`. Report the conservative unstandardized RMSE-difference enclosure

```
[sqrt(MSE0_lower)-sqrt(MSE1_upper),
 sqrt(MSE0_upper)-sqrt(MSE1_lower)]
```

and label it non-sharp. Do not standardize this enclosure by an unidentified test SD. If observed test-Y SD is nonfinite or zero, primary `G` and its CI are `nonestimable`, while valid unstandardized bound arithmetic may still be emitted.
6. Compute the common-displacement stress function with shared clipping, `y_i(delta)=clip(m_ref+delta,L,U)` for missing rows and observed Y unchanged, where `m_ref` is observed future-Y mean if available, otherwise training observed-Y mean explicitly marked training-derived. Since `d` is affine, evaluate the continuous piecewise-linear function on `[L-m_ref,U-m_ref]`, solve each interior segment analytically, retain only in-domain roots verified by direct evaluation, and choose smallest absolute root with ties by smallest delta. Report zero if `Delta(0)==0`, otherwise `no_root_sign_robust` when no root exists, and whether the endpoint interval crosses zero. This is a sensitivity coordinate, not an imputation or plausibility claim.

Optional B=2000 paired arm-stratified patient-frequency bootstrap is uncertainty only: freeze predictions and fits, resample patients within arm retaining all selected events, calculate observed complete-triplet RMSE difference, divide by the original point-estimate `SD_test(Y)`, and report seed, failures, and observed patient clusters. Never merge this CI with deterministic identification bounds. If resources fail, report the actual smaller B and reason; zero/undefined SD, no observed triplets, or fewer than two observed patient clusters is `nonestimable`, not zero.

## Verifier and clinical interpretation

The aggregate output must contain source hashes, row counts, duplicate-key checks, frozen cohort/event/triplet assertions, per-assay/per-block funnels, bound statuses, denominators, endpoint components, roots, and any bootstrap bookkeeping. It must fail closed on nonfinite predictions, empty risk sets, invalid ranges, out-of-range observed future Y, prediction-row loss, duplicate episode rows, or disagreement between direct and affine endpoint arithmetic. It must explicitly check that documents without native time never enter Y selection and that ascertainment proxies (exam row, additional encounter, document row) are recording/opportunity proxies rather than completed follow-up.

Interpretation precedence is:

* **Supportive, only locally:** both support gates pass, primary result is estimable, observed-case and bound audit show no material selection warning, and the deterministic `Delta` interval is strictly above zero throughout the declared training-range scenario. This supports selected short-horizon prognostic association in that calendar mixture only.
* **Adverse:** adequately supported nonpositive primary contrast, repeated M1 degradation, or a nonpositive/zero-crossing bound. This challenges incremental prediction; it does not prove B alone sufficient.
* **Selection-sensitive:** favorable complete-case estimate but bound interval crosses zero, tipping displacement is near zero, observation gradient is substantial, or ascertainment categories differ. This means missing-Y observation can explain the direction under the declared range; do not call it supportive.
* **Unsupported/inconclusive:** failed gates, empty/degenerate training range, out-of-range future Y, nonfinite predictions, nonestimable SD/bootstrap, sparse clusters, low transport ESS, or reliance on an unlabeled full-source range. The result is not evidence for or against clinical benefit.

The audit can establish only computation, reconstruction, association, and sensitivity-region arithmetic. It cannot establish assay units or reference ranges, disease severity, tumor burden, imaging response, TACE intent or administration, transfusion/fluid exposure, external-care capture, mortality, hepatic failure, completed follow-up, causal effects, actionability, utility, safety, or patient benefit. Those require clinical adjudication and independent temporal, external, or prospective data.
