## 6. New closed localization estimands

### 6.1 Predeclared panel sets

Freeze these four sets before test unsealing:

- adjudicated core: `H_A={(RA,PA)}`;
- radiology axis around fixed adjudicated pathology: `H_R={(R1,PA),(R2,PA),(RA,PA)}`;
- pathology axis around fixed adjudicated radiology: `H_P={(RA,P1),(RA,P2),(RA,PA)}`; and
- full Cartesian panel: `H_X={R1,R2,RA}×{P1,P2,PA}`.

Thus `H_A` is contained in both `H_R` and `H_P`, each axis is contained in `H_X`, and the four off-axis pairs are `(R1,P1),(R1,P2),(R2,P1),(R2,P2)`. No other subset, leave-reader-out set, consensus set, weighted reader average or data-dependent merge is permitted.

For each frozen set `H`, restrict only the global book-pair index while retaining every admissible source and selected-form terminal state:

`Omega(H)={omega in Omega_book+ : g(omega) in H}`.

The already fitted full-panel minimax model hashes, preprocessing, K and scores are used. There is no axis-specific refitting, retuning, recalibration, thresholding, feature selection, rereading or new adjudication.

For each `e` and `H`, compute

`I^0_{e,H}=[min_{omega in Omega(H)} Delta_e(omega), max_{omega in Omega(H)} Delta_e(omega)]`

and

`I^{-1}_{e,H}=[min_{j in U_T,omega in Omega(H)} Delta_e(omega\{j}), max_{j in U_T,omega in Omega(H)} Delta_e(omega\{j})]`.

Define the undeleted and stable all-coordinate gates

`C_0(H)=1{min_{e in E} L^0_{e,H}>5}`,

`C_S(H)=1{C_0(H)=1 and min_{e in E} L^{-1}_{e,H}>5}`.

All eight inequalities—four undeleted and four singleton-deletion—are required for `C_S(H)=1`. Individual coordinate passes never constitute a supportive localized claim.

For complete reporting, also compute all 36 undeleted and 36 deletion-stress intervals for singleton pairs `H={g}`, `g in H_X`, and classify each interval as `supportive` if `L>5`, `heterogeneous` if `L<=5<U`, or `all-world-adverse` if `U<=5`. These cells are a compulsory failure map, not nine opportunities to select a successful analysis.

### 6.2 Gatekeeping sequence

The order is fixed:

1. **Global prerequisites.** Source-envelope completeness, annotation coverage, fit certificates, `N_ref/K`, all full-panel undeleted and post-deletion adequacy gates, and exact endpoint certificates must pass. If any fails, the result is `inconclusive`; performance localization cannot produce a supportive statement. A gate-failure audit may name the missing book, state, year or deletion only.
2. **Primary full panel.** Evaluate `C_0(H_X)` and `C_S(H_X)`. If `C_S(H_X)=1`, report `stable-whole-panel-universal-supportive`. The localization matrix is still emitted for audit but cannot strengthen that conclusion.
3. **Adjudicated core after primary failure.** If `C_S(H_X)=0`, evaluate `C_0(H_A)` and `C_S(H_A)`. If `C_0(H_A)=0`, classify `adjudicated-core-undeleted-margin-failure`. If `C_0(H_A)=1` but `C_S(H_A)=0`, classify `adjudicated-core-singleton-fragility`. Stop supportive localization in either case; axis-cell results remain descriptive.
4. **Both axes, only after stable core.** If `C_S(H_A)=1`, evaluate `C_S(H_R)` and `C_S(H_P)` in parallel and always report both. The joint two-bit result gives exactly one label:
   - `radiology-axis-fragility` when `C_S(H_R)=0, C_S(H_P)=1`;
   - `pathology-axis-fragility` when `C_S(H_R)=1, C_S(H_P)=0`;
   - `dual-axis-fragility` when both are zero; or
   - `off-axis-cross-reader-fragility` when both are one but `C_S(H_X)=0`.

Within each nonpassing set, append `undeleted` if `C_0(H)=0` and `singleton-only` if `C_0(H)=1` but `C_S(H)=0`. This suffix cannot change the primary conclusion.

Because these are exact finite-corpus set relations rather than sampling tests, no alpha level or p value is attached. Multiplicity and post-hoc rescue are prevented operationally: the only escalation claim is the eight-inequality full-panel conjunction; every localization set, order, margin and label is frozen; both axes and the complete 3-by-3 matrix must be emitted; no isolated coordinate or pair can be called supportive; and no result-dependent reader exclusion, weighting, subgroup, year pooling, contrast demotion or threshold relaxation is allowed. Any later population-inferential analysis requires a separate protocol with simultaneous error control.

### 6.3 Attained failure witnesses

For every nonpassing `H/e/d`, emit every tied minimizing witness, not just the first. A witness contains protected patient hash when deletion applies; global book pair; coherent procedure/clock/episode/year/imaging-window/prior-treatment states; pathology terminal; before/after top-K patient hashes for both arms; score, rank, tie, membership and outcome arithmetic; whether the deleted patient or replacement occupied either top K; and raw/form/object backpointers.

The verifier may state that a failure is attained under a supplied reader-book pair or coherent source completion. It may not state that a reader is wrong, that a source state is true, that the reader axis caused failure, or that a minimizing patient is erroneous or influential in a population.

- `decisive-heterogeneity` otherwise.

The new localization label is nested beneath, never substituted for, that one-hot global state.

Decision implications are predeclared:

- A stable whole-panel result supports prioritizing acquisition of accession-linked report version/final/release/view times. It supports drafting a prospective silent-mode protocol, but actual silent-mode initiation remains conditional on a successful timing/identity audit, locked operational feature production, a prospective candidate-stream and capacity ledger, and clinical/governance review.
- A full-panel singleton-fragile result preserves the undeleted finite-corpus claim but does not clear prospective escalation. The next target is later-period or external finite-corpus replication; timing acquisition may have institutional reuse value, but this experiment does not establish that it should be funded for this model.
- A stable adjudicated core with radiology-, pathology-, dual-axis- or off-axis fragility does not rescue the primary failure. It redirects work to the named complete-reader reliability/rubric study before timing acquisition or silent-mode evaluation. Pathology-axis work additionally requires specimen/time/sampling linkage before any biological-M2 interpretation.
- Adjudicated-core undeleted-margin failure argues against funding timing acquisition or silent mode for this locked model on the basis of this corpus; it does not show that semantics are useless, and redevelopment may still be reasonable. Adjudicated-core singleton fragility calls for replication, not reader exclusion.
- All-world adverse means the strict >5 margin fails in every declared undeleted world for all four coordinates only when its stated condition is met. It does not prove semantics useless or exclude smaller gains. Heterogeneity identifies dependency, not truth. Inconclusive is not adverse evidence.

Actual funding remains a human decision requiring acquisition cost, privacy/governance, service capacity, and expected value not present in HCC. The automatic output is an evidence tier and permitted interpretation, not a procurement authorization.
