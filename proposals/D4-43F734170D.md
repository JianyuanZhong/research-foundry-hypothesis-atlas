## Frozen certificate and exact equation protocol

The compiler must accept one immutable JSON certificate input, supplied as a declared input artifact and never generated from participant values. The certificate is a signed-off input artifact, not a computed report. Its contract is executable as follows. The compiler reads UTF-8 bytes, parses one JSON object, rejects duplicate keys, rejects non-finite numbers, rejects unknown top-level members, and canonicalizes with RFC-8785-style deterministic JSON (sorted object keys, shortest JSON number representation, UTF-8, no insignificant whitespace). It removes only `canonical_digest`, canonicalizes the remaining object, hashes those bytes with SHA-256, and compares the result to the supplied digest. The digest is therefore not self-referential. Every field/equation claim has a separate evidence record containing `claim_id`, exact source URL or artifact path, frozen source SHA-256, retrieval timestamp, locator (field ID, page/section or JSON pointer), verbatim extracted assertion, and issuer/steward identity; an absent locator, hash, or assertion is a failed claim, not an inferred value. The certificate must also contain an ordered claim-to-evidence map, contradiction list (which must be empty), signer identity, signer checksum, and an independent verifier record whose input is the certificate bytes and evidence hashes only. The verifier must reproduce the digest independently and must not have received participant rows, eids, derived counts, or model outputs. Certificate creation, verification, and participant computation are separate steps and artifacts; a verifier cannot certify an assertion merely because it is plausible or reproduces an anchor count.

Use paired outcome-stratified round-robin five-fold cross-fitting, ten fixed repeats, fold-local preprocessing, fixed L2 logistic regression with no tuning and no class weighting:

- `M0`: sex plus the inherited fixed natural-cubic-spline bases for baseline age and `eGFRcr_0`.
- `M1`: M0 plus one training-fold-standardized linear Z column.

For each outcome, output paired out-of-fold risks, log loss, Brier score, calibration-in-the-large and calibration slope. The primary contrast is paired Brier difference `Brier(M1)-Brier(M0)` with a predeclared direction (negative favors M1), evaluated over the entire S_A schedule-marginal cohort. A fixed-capacity secondary contrast uses the complete grid `q=0.01,0.02,...,0.20` (including inherited q=0.10), deterministic participant-independent tie order, `ceil(q*n)` selected by OOF risk, event capture, event fraction captured, PPV, and `DeltaC(q)=C_M1(q)-C_M0(q)`. ## Falsification, timing, and fail-closed gates

1. **Source/schema integrity:** exact current paths, source hashes, schema hashes, columns, one-to-one joins, and overlap agreement pass before cohort construction.
2. **Certificate integrity:** canonical digest, field identity/unit/assay/missing-code/date evidence, equation constants, instance comparability, and independent certificate reproduction pass. Missing, stale, contradictory, or unverifiable evidence produces a neutral technical stop; it is never called an adverse biological result.
3. **Leakage sentinel:** static feature audit rejects repeat dates, ages, biomarkers, interval, completeness, attendance, and any future variable. A deliberately leaked model may run only as a private debugging sentinel and can never contribute a result.
4. **Fold-aware label null:** 200 within-baseline-stratum outcome permutations (seed 520242), reconstructing outcome-stratified folds under each label, refitting both models, and recomputing all statistics. Compare the observed statistic to the statistic-specific empirical null using randomized-plus-one tail fractions; a nominal p-value against zero is invalid. If the observed primary curve is not more favorable than the prespecified 98% favorable-tail null envelope, incremental evidence is not certified.
5. **Predictor null:** permute Z within baseline eGFRcr deciles and sex with identical folds/preprocessing; gains must collapse toward the empirical null. Persistent gains imply leakage or implementation error.
6. **Reversed-label negative control:** rerun for `1-Ycr`; a discordance claim cannot depend on an equally large gain for the artificial reversed target.
7. **Timing sensitivity:** report `[2,3)`, `[3,5)`, `[5,8]` bands and each secondary equation outcome without changing the primary schedule-marginal estimand. Improvement only in one band or equation is not a general kidney-status finding.
8. **Selection sensitivity:** compare complete-case and predeclared weighted descriptive risks. Selection dependence is uncertainty, not a causal correction.
9. **Repeat stability:** retain all ten repeat-level estimates and require the supportive gate to hold in a predeclared majority of repeats, with no materially adverse repeat; do not cherry-pick the best split.

A technical gate failure permits only aggregate structural audit and the explicit terminal state. It does not permit participant counts named as biomarker cohorts, equation outputs, models, curves, or null statistics. No participant-level artifacts, eids, rows, or notes may be published.

## Decision and interpretation gates

- **Supportive for conditional prioritization only:** all source, certificate, equation, comparability, leakage, and null gates pass; M1's paired Brier and capacity contrasts show prespecified favorable direction with simultaneous 98% uncertainty supporting the contrast over the contiguous 5–15% capacity region; results are repeat-stable and not contradicted by required sensitivity gates. This supports only baseline conditional ranking in the selected complete-repeat cohort.
- **Adverse:** after all technical gates pass, M1 reproducibly worsens calibration or capacity capture, or the observed increment is reproducibly unfavorable. This argues against incremental prioritization in this selected schedule boundary, not against cystatin C in other uses.
- **Inconclusive:** technical gates pass but uncertainty crosses the null over the capacity region, repeat or interval heterogeneity is material, or only isolated q points or one unadjudicated equation improves. No threshold recommendation follows.
- **Neutral technical stop:** certificate absent/contradictory, source/schema mismatch, unresolved units or missing codes, unresolved assay/platform comparability, unresolved date semantics, failed equation unit tests, or incomplete null refits. This state is not evidence for any biological hypothesis.

Even supportive findings cannot establish benefit from testing, acceptable false-positive burden, cost-effectiveness, treatment benefit, measured-GFR accuracy, CKD, chronicity, causal utility, or transportability. Those require authoritative steward metadata and clinical review for semantics, repeated clinical records and/or adjudication for CKD and outcomes, measured GFR for accuracy, and prospective observation of testing decisions plus harms, costs, preferences, and downstream outcomes for utility.
