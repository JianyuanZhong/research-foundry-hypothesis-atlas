# Remote pre-TACE2 hepatic state and a jointly adverse next repeat-TACE panel

## Purpose, clinical question, and substantive synthesis

This is a substantive child of `[prior hypothesis]` and `[prior hypothesis]`. It combines the former's exact repeat-TACE trajectory construction and complete-source feasibility audit with the latter's clinically sharper reverse-nested question: once the contemporaneous pre-repeat laboratory panel is known, does a remote pre-TACE2 hepatic-state panel add reproducible information about the next observed panel?

The intended monitoring question is narrow and falsifiable. Among adults in the frozen HCC recorded-pathway cohort who have a first eligible repeat TACE and a complete, event-anchored albumin/total-bilirubin panel, does adding the remote pre-TACE2 state to the contemporaneous pre-repeat state improve prediction of the next observed panel, particularly the prespecified numerical pattern of albumin decreasing while total bilirubin increases? This is a prognostic/monitoring experiment for a selected observed laboratory endpoint. It is not a test of TACE toxicity, treatment benefit, hepatic failure, treatment response, medication effect, or a policy for changing repeat TACE.

The clinically attractive wording “jointly adverse” is deliberately not treated as established clinical meaning. The source has no laboratory-unit column or reference ranges, and the audit cannot establish that values with the same lexical assay label are harmonized across specimen types or collection systems. Therefore the binary endpoint is called **joint numerical direction** in computation and can be called “albumin-down/bilirubin-up” only as an assay-defined pattern. It may not be called hepatic decompensation, toxicity, or clinically adverse without unit/specimen validation and expert adjudication.

### Strongest evidence-supported claim

The direction-blinded, complete-source audit supports only construction and availability: the frozen pathway contains 319 systemic-record and 1,491 comparator patients; the first strict repeat-TACE event occurs in 159 and 526 patients, respectively; and the assay-specific complete triplets are 40/118 for albumin and 41/119 for total bilirubin (systemic/comparator). The strict common-timestamp joint triplet count is 40/118. Assay-specific timing thus adds no albumin triplets and only one bilirubin triplet per arm. The audit did not inspect endpoint directions, predictor-outcome associations, or model performance.

### Unresolved claim and hypothesis

The unresolved claim is that remote pre-TACE2 hepatic-state information adds reproducible, out-of-sample predictive information beyond the contemporaneous pre-repeat panel for a next-panel outcome. The primary binary hypothesis is conditional and gated:

> In the complete common-timestamp joint triplet cohort, after the contemporaneous pre-repeat albumin/bilirubin panel and prespecified event-time covariates are known, adding the remote pre-TACE2 albumin/bilirubin panel improves cross-fitted prediction of the assay-defined pattern `Y_albumin < P_albumin` and `Y_bilirubin > P_bilirubin`, if and only if the locked support, class-balance, unit/specimen, and model-stability gates establish that this binary endpoint is estimable.

If those gates fail, the binary pattern is a negative feasibility result, not a null biological result. The strongest defensible fallback is a continuous two-assay or assay-specific prediction experiment: whether remote B improves prediction of the next observed numeric albumin and/or bilirubin levels beyond P. This fallback preserves the clinical monitoring question while avoiding an unsupported threshold/clinical interpretation.

## Assay parser, remote/current/next panels, and joint timestamp rule

Parse a trimmed `定量结果` only if it is a signed decimal or scientific number with optional leading `<`, `>`, `≤`, or `≥`. The primary analysis uses exact numeric, uncensored rows only; inequality-marked rows are excluded from primary selectors but counted in parser/availability audit. Do not strip commas, accept trailing text, or infer values from `定性结果`. Preserve inequality marker, `标本类型`, source row order, and timestamp in an audit table. There is no lab-unit column. `标本类型` is not a unit and cannot repair this limitation.

For each selected repeat event and assay `a`, define the exact primary selectors before reading outcome directions:

- `B_a` (remote pre-TACE2 state): latest valid, uncensored, concordant numeric result on TACE2 calendar days −30 through −1; TACE2 day 0 is excluded. This is the only primary remote-history feature.
- `P_a` (contemporaneous pre-repeat state): latest valid, uncensored, concordant numeric result in the selected repeat-event encounter in `[event_time −72 hours, event_time)`. The event timestamp is excluded.
- `Y_a` (next panel): valid, uncensored, concordant numeric result in the same selected repeat-event encounter in `(event_time, event_time +72 hours]`, selected nearest nominal event time +24 hours; an exact distance tie chooses the earlier timestamp. Event calendar day 0 is excluded in the locked calendar-day sensitivity.

For an assay-specific selector, each assay is selected independently. For the **joint numerical-direction endpoint**, use the inherited strict common-timestamp construction: albumin and total bilirubin must have the corresponding common timestamp at B, P, and Y stages, with one selected event per patient and the same event clock. The direction-blinded audit target is 40 systemic/118 comparator joint common-timestamp triplets. Do not silently replace this with the 40/118 albumin and 41/119 bilirubin assay-specific triplets. The assay-specific rows remain the predeclared continuous fallback and sensitivity evidence.

At each stage, report exact event-to-panel hours, duplicate groups, concordant/discordant handling, invalid times, unmatched encounter keys, inequality counts, specimen types, and any timestamp ties. Use the final source-order row only for concordant duplicate values; exclude discordant duplicate groups from primary analysis and repeat a concordant-only sensitivity. Never select a timestamp from outcome direction or model performance.

## Primary binary endpoint and its feasibility gates

Within a complete common-timestamp joint triplet, define the computational endpoint

`J = 1{Y_albumin < P_albumin AND Y_total_bilirubin > P_total_bilirubin}`.

Strict inequalities define the pattern. Exact equality is not jointly adverse and is retained in the complement; a missing, censored, discordant, or nonnumeric value is not a negative outcome because it is excluded from the complete-triplet endpoint cohort. This is a numerical direction pattern relative to the contemporaneous panel, not a unit-based threshold and not a diagnosis.

Before any predictor-outcome association is inspected, report only the locked feasibility quantities: joint triplet count by arm, number and proportion of J=1 and J=0 by arm, ties/indeterminate exclusions, specimen-type distribution, and whether the exact assay labels have a single validated unit/specimen interpretation. Do not use those counts to choose a favorable predictor, window, model, or subgroup. The binary endpoint is estimable only if all gates below pass:

1. Reconstruction matches the snapshot, full-scan flow, 319/1,491 arms, 159/526 events, parser, duplicate policy, and 40/118 common-timestamp target.
2. The joint endpoint has at least 20 J=1 observations overall, at least 5 J=1 observations in each arm, at least 10 J=0 observations in each arm, and every fixed outer fold has both classes in its training and held-out data. These are feasibility conventions, not power claims.
3. Five fixed patient-level outer folds, assigned by SHA-256 of patient key plus assay/panel string and fixed seed before outcome inspection, have at least five held-out patients per arm and nonzero outcome variance. No fold may be merged, rebalanced after looking at performance, or replaced because the binary endpoint is sparse.
4. There is no unresolved evidence that the two exact assay labels combine incompatible units or clinically noncomparable specimen types. If units/specimen comparability cannot be established, the binary pattern may be reported only as exploratory numerical direction and cannot receive a clinical “adverse” interpretation; the continuous assay-specific fallback becomes the strongest defensible analysis.
5. The primary logistic pipeline is estimable in every training fold without separation or rank failure. If it is not, do not add flexible models or change the endpoint; mark the binary analysis infeasible.

The audit must not claim that 40/118 joint triplets are 40/118 adverse events. If the event-count or harmonization gates fail, this is an explicit negative feasibility result. It is not evidence that albumin-down/bilirubin-up is absent, safe, or unrelated to remote hepatic state.

## Nested incremental prediction estimand

Use the same patients, common-timestamp selectors, folds, preprocessing, and covariate core for both nested models. The compact core is fixed before outcome inspection and is limited to information available by the pre-repeat decision time:

- contemporaneous panel `P_albumin`, `P_total_bilirubin`;
- pathway arm `A` (systemic-record versus comparator);
- age and sex;
- TACE2-to-repeat interval in calendar days;
- event-minus-P lead time in hours.

No post-repeat value, post-event medication, outcome-derived availability variable, specimen label selected for outcome performance, or broad longitudinal history may be added. If age/sex is missing, impute within training folds with a predeclared training-only rule and retain missingness indicators only if fixed before outcome inspection; otherwise report non-estimability rather than silently changing the core.

For the binary endpoint, fit:

```text
M0-J: logit Pr(J=1) = P_albumin + P_total_bilirubin + A
      + age + sex + TACE2_to_repeat_days + P_lead_hours
M1-J: M0-J + B_albumin + B_total_bilirubin
```

Use a fixed, predeclared ridge/logistic penalty grid `{0, 0.01, 0.1, 1, 10}`, unpenalized intercept, and training-only imputation/scaling. Select penalty by inner leave-one-out log loss within the outer training fold, never using held-out outcomes. Report paired held-out log loss, Brier score, AUROC only as a descriptive rank metric, calibration intercept/slope, calibration plots without exact identifiers, and arm-stratified performance. The primary incremental estimand is the paired cross-fitted change in standardized log loss and Brier score, `loss(M0-J) − loss(M1-J)`, with fixed patient-level bootstrap intervals. No model coefficient is a clinical risk ratio or treatment effect.

The endpoint uses P as the comparator threshold and as a predictor. This is intentional and must be disclosed as a threshold-coupling limitation: the experiment tests incremental prediction conditional on the current panel, not an independent causal effect of P or B. Do not analyze `Y−P` as a primary continuous outcome or call a fitted coefficient a biochemical response.

## Continuous fallback and assay-specific alternative

If the binary endpoint fails any feasibility or harmonization gate, do not discard the scientific question and do not manufacture a binary event. Fit the strongest defensible fallback on the predeclared complete panels:

```text
M0-C: Y_albumin, Y_total_bilirubin ~ P_albumin + P_total_bilirubin + A
      + age + sex + TACE2_to_repeat_days + P_lead_hours
M1-C: M0-C + B_albumin + B_total_bilirubin
```

Fit separate ridge linear regressions for albumin and bilirubin with the same fixed folds and training-only preprocessing. Report assay-specific native-scale RMSE/MAE only as mathematical error summaries, because units are unavailable; primary comparison is within-assay standardized RMSE and MAE using training-fold scaling. A composite two-assay standardized loss may be reported only as a transparent descriptive summary, never as a clinical utility score or pooled laboratory scale. If common-timestamp joint support is insufficient, run the assay-specific fallback on the exact audited assay-specific triplets (albumin 40/118; bilirubin 41/119), retaining separate denominators and no cross-assay pooling. Do not claim that remote state predicts a “jointly adverse” pattern when the binary gate fails.

The predeclared continuous estimand is the paired out-of-fold incremental prediction change, `RMSE_std(M0-C) − RMSE_std(M1-C)`, separately for albumin and bilirubin. Report fold-level performance, calibration intercept/slope, prediction variance, penalty, arm support, and fixed-seed 2,000-replicate paired bootstrap intervals. If fewer than 95% of bootstrap replicates are estimable, the continuous result is inconclusive. Continuous fallback is not a claim that numeric differences are clinically meaningful.

## Selection, observation, regression-to-mean, and timing controls

Repeat TACE selection is post-TACE2 and may reflect disease severity, clinician choice, access, survival/observation, and treatment pathway. Complete laboratory panels are also selected by observation. The analysis is therefore conditional on a selected repeat event and observed labs.

1. First report the complete-triplet analysis unweighted. Separately model selection into the repeat event and availability of B, P, and Y using only pre-event or event-independent information. Use fixed five-fold cross-fitting, overlap/inverse-probability weights, arm-specific positivity, normalized-weight diagnostics, effective sample size (ESS), balance, and maximum/concentration checks. Never use Y or J to model its own availability.
2. Repeat the nested comparison with the resulting weights only as a sensitivity. Predeclare that failed overlap/ESS or material weighted/unweighted conflict yields `selection-sensitive/inconclusive`, regardless of a favorable unweighted result. Weighting cannot recover unobserved outcomes or remove unmeasured collider bias.
3. Retain B and P in all models to distinguish remote state from contemporaneous state and reduce regression-to-the-mean overinterpretation. Report baseline/remote and current distributions, assay timing, and influence diagnostics. No change score is primary.
4. Re-run only the inherited locked timing variants: pre-P latest 24/48/72/168 hours, first pre-P 72 hours, post nearest +24/+48/first eligible, calendar-day +1–3, and strict common-timestamp pairing. Identical selected rows count as one variant. A favorable selector may not replace the primary.
5. Audit temporal leakage: no B row may be in the P encounter, at/after P time, at/after repeat event, or duplicated by a many-to-many join; no Y row may be at/before the event. Report all violations as reconstruction failure.
6. Report leave-one-out/influence diagnostics, leverage/Cook-type measures and DFBETA for transparent linear/logistic fits, partition repetitions, and concordant-only reruns. A small number of patients cannot establish a monitoring signal.
7. A pseudo-current pre-event placebo is retained only if its direction-blind support meets the same fixed minimum. The completed audit found only 2 systemic and 4 comparator candidates per assay for that event-linked pseudo-current check; therefore it is non-estimable and cannot be used to create a favorable negative control or to support event specificity.

## Locked analysis branches and falsification criteria

Apply the following precedence separately to the binary joint endpoint and each continuous assay fallback.

1. **Reconstruction failure.** Any mismatch in source snapshot, full scan, frozen arms/events, exact parser, composite joins, duplicate policy, or primary triplet/common-timestamp target produces `inconclusive` and stops inference.
2. **Binary/continuous feasibility failure.** Failed class support, unit/specimen harmonization, fold support, rank/separation, nonzero variance, training-only processing, or bootstrap estimability makes the binary endpoint `not estimable`. If continuous assay-specific gates pass, publish that fallback; do not call it evidence for the binary pattern.
3. **Selection-sensitive/inconclusive.** Failed overlap/ESS or material weighted/unweighted conflict downgrades the result, even if the unweighted increment is favorable.
4. **Adverse degradation.** If adding B worsens the primary held-out loss beyond its two-sided uncertainty interval, report degradation of prediction, not clinical harm.
5. **Supportive incremental prediction.** Only if all previous gates pass, the binary incremental loss reduction exceeds a prespecified design margin (0.05 standardized log loss or Brier-scale margin defined in the execution specification), the interval excludes zero, calibration does not materially worsen, linkage-destroyed B permutations do not reproduce the gain, timing/concordant-only variants do not reverse it, and influence/partition diagnostics are stable. This supports only reproducible incremental prediction of a numerical pattern in the selected observed cohort.
6. **Precise null.** If all gates pass and the upper interval is below the design margin, report no detectable remote-panel improvement of that size under this cohort/model. This is not equivalence, no biology, no safety, and no clinical utility.
7. **Inconclusive.** Broad intervals, fold or class instability, timing reversal, linkage-placebo comparability, unit/specimen ambiguity, or insufficient continuous precision yield `inconclusive`.

For the continuous fallback, require assay-specific, same-direction incremental gains with uncertainty if making a two-assay summary; disagreement between albumin and bilirubin is an explicit inconclusive/assay-specific result, not a reason to average away discordance. No pathway-arm interaction is a primary claim. With approximately 40/41 systemic triplets, any arm-specific result is descriptive and cannot establish treatment-pathway modification.

## Linkage and negative controls

Within each outer fold, permute paired `(B_albumin, B_bilirubin, B_time)` assignments among analysis patients under 500 fixed-seed permutations, leaving P, Y, arm, and covariates fixed; refit/evaluate M1 with the identical pipeline. If observed incremental performance is not distinguishable from the linkage-destroyed distribution, report no demonstrated patient-specific remote-history increment.

Timing stability, concordant-only duplicates, and the unavailable pseudo-current placebo are falsification diagnostics, not opportunities for endpoint selection. If an exact non-target laboratory label with adequate pre-event support is documented before outcome analysis, it may be used as a negative-control assay; otherwise explicitly report that no validated negative-control assay is available.

## Interpretation and evidence boundary

A supportive result would mean only that a remote pre-TACE2 panel carries reproducible incremental information about the next observed numerical panel or the assay-defined albumin-down/bilirubin-up pattern, conditional on a selected repeat event and observed laboratories. It would motivate validation with harmonized units and an adjudicated clinical endpoint. It would not justify altering TACE timing, adding or withholding systemic therapy, or calling the pattern toxicity, hepatic decompensation, benefit, response, or treatment effect.

An adverse result includes degradation after adding B, a null or opposite continuous association, loss under linkage destruction/weighting/timing sensitivity, influence domination, or failed class/overlap support. A negative feasibility result for the binary endpoint is scientifically useful: it establishes that the attractive joint clinical pattern cannot be reliably resolved in this snapshot, rather than converting sparse data into a false negative or positive.

A null result with adequate precision and passed gates weakens the claim of a practically important remote-history increment for this selected observed endpoint. A null result with sparse support, missing units, failed harmonization, or broad uncertainty is inconclusive. No result can establish that albumin-down/bilirubin-up is clinically adverse without expert adjudication.

The automatic verifier can check source hashes, complete scans, exact cohort/event/triplet counts, parser and duplicate rules, common-timestamp construction, leakage exclusions, fixed folds, training-only preprocessing, nested predictions, loss/interval arithmetic, permutation consistency, and branch precedence. It cannot establish clinical importance, units/reference ranges, medication administration, procedure intent or technical success, radiographic response, decompensation, mortality, outside care, mechanism, causality, or decision utility.

## Unavailable evidence and required next study

The HCC sources lack laboratory units and reference ranges, validated specimen harmonization, cirrhosis severity/complete Child–Pugh context, tumor burden and imaging response, transfusion/albumin infusion/fluid balance, infection or bleeding adjudication, renal/hepatic decompensation outcomes, procedure intent/dose/technical success, verified medication administration/adherence, reliable outside-care capture, and complete vital-status information. Diagnoses have no native time and lexical HCC matching is not expert adjudication. Conditioning on repeat TACE and complete observed panels can induce selection/collider bias.

A stronger clinical claim requires unit- and specimen-validated repeated labs, expert-adjudicated acute and hepatic outcomes, treatment rationale and verified exposure, repeated untreated/comparator observations, and prospective or external validation of calibration and net benefit. The present experiment is valuable precisely because it can conclude that the joint binary monitoring endpoint is not interpretable or sufficiently supported, while preserving a computable continuous alternative and all provenance.
