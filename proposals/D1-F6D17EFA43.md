# Executable persistent respiratory-state experiment with a repaired frozen-cohort dependency

## Purpose and bounded advance

This targeted successor combines the assessed-valid persistent-trajectory designs in `[prior hypothesis]` and `[prior hypothesis]`. It does not reopen the already settled care-plan vocabulary or transportability audits. The unresolved question remains:

> Among the frozen eligible person-landmarks that receive one of the two exact ventilation care-plan labels, does the label add reproducible information about a subsequent persistent, safety-preserving respiratory-support trajectory beyond the pre-label respiratory state and documentation opportunity?

This is a descriptive conditional association/incremental-prediction question, not a treatment-effect question. A positive result would support only information in an exported structured-chart construct. It would not establish that an SBT or daily extubation evaluation occurred, that a setting was delivered, that extubation was ready or appropriate, or that a patient benefited. The strongest inherited evidence is that the exact labels are sparse and hospital-concentrated, prior setting associations were peak-pressure dominated, and durable liberation is not ascertainable from the available independent markers. The untested claim is narrower and falsifiable: after strict temporal separation and pre-D state/opportunity adjustment, the evaluation label has a reproducible held-out association with a persistent independently measured trajectory rather than merely with documentation opportunity.

## Frozen population and the repaired artifact contract

The denominator is exactly 540 person-landmarks from 443 unique first qualifying ICU stays/persons and 74 hospitals, with landmarks `L ∈ {1440, 2880, 4320, 5760, 7200}` minutes after ICU admission. Required identity columns are `sid` (an alias if present, otherwise exactly `patientunitstayid`), `patientunitstayid`, `uniquepid`, `hospitalid`, and `landmark`. Keep all eligible landmarks within the retained first qualifying stay; repeated landmarks are clustered by `patientunitstayid`/`sid`.

The primary exposure is the first exact `carePlanGeneral.cplitemvalue` in the inclusive interval `[L,L+360]` equal to either:

* `evaluation`: `Ventilated - with daily extubation evaluation`
* `no_trial`: `Ventilated - with no daily extubation trial`

`D` is that row's `cplitemoffset`, never `L`. Same-time contradictory target labels are excluded exactly as in the frozen parent. Eligibility is determined before target-label classification and cannot use any post-D row.

The prior blocker was that the proposal named two hashes but did not make their acquisition a compilable dependency. This version defines a two-path, fail-closed artifact contract.

1. **Preferred frozen-artifact path.** The compiler must resolve candidate-support files by content hash, not by a hard-coded path. It searches the assigned parent support objects, the episode workspace, and the candidate support cache for a file with [source checksum] (cohort) and a file with [source checksum] (action rows). Copy, never edit, the matching bytes into the job workspace and record the original support object, destination, byte count, and hash. Validate 540 rows, 443 unique stays/persons, 74 hospitals, five landmark values, one row per `patientunitstayid,landmark`, and exact required columns. Validate action-row `label`, `decision_offset`, `D`, `patientunitstayid`, `hospitalid`, `landmark`, and `D == decision_offset`; cross-join identity must be one-to-one.

2. **Deterministic-rebuild path.** If either hash cannot be resolved, the compiler does not silently substitute a newly outcome-selected cohort. It must execute `rebuild_frozen_population.py` from the read-only sources listed below using a versioned `frozen_recipe.json` copied from the assigned parent support if available. The recipe must contain the exact inherited filter predicates, source columns, null/string normalization, tie-break order, and exclusion counts; it is applied in this order: patient identity/adult and first `unitvisitnumber` per `uniquepid`; landmark ICU-continuation; all parent pre-L invasive-evidence and physiologic-screen predicates; prior carePlanEOL exclusion; prior 24-hour `Spontaneous - adequate` exclusion; then landmark eligibility. Only after that target-independent table is frozen are exact target labels classified from `carePlanGeneral`. Emit `frozen_population_rebuilt.csv`, `exposure_rebuilt.csv`, `rebuild_filter_counts.json`, and `rebuild_recipe_sha256.txt`. The rebuild is accepted only if it reproduces the frozen cardinalities, key uniqueness, landmark set, hospital/stay/person identities, exact labels, and D values, and if a canonical row-level identity digest matches the digest recorded in the parent recipe. If the parent recipe or its filter-level provenance is unavailable, the correct result is `inconclusive/feasibility failure` before outcome scans; do not claim replication and do not estimate. If the rebuild produces any mismatch, stop and report the first mismatch and all attrition counts. This makes missing support an explicit, machine-checkable dependency rather than an implicit inaccessible path.

The deterministic rebuild is therefore not permission to change the cohort: it is an executable recovery of the frozen cohort, accepted only by identity and recipe checks. The compiler must publish both the source-artifact route taken and the reason the other route was not used.

## Time windows, parsing, and primary endpoint

For each frozen row, define baseline `B=(D-720,D]`, pre-D placebo interval `P=(D-1440,D-720]`, primary observation window `O=(D+360,D+1800]`, and horizon sensitivity `O12=(D+360,D+1080]`. All intervals are half-open/open exactly as written. Use clinical offsets only; equality at an endpoint is resolved by these definitions. A six-hour washout separates label classification from the outcome.

Parse only finite numeric `respchartvalue` values after trimming. Before any arm-specific analysis, freeze field-specific physiologic bounds and an outcome-blind, case-insensitive/whitespace-normalized label map for FiO2, PEEP/PEEP-CPAP, pressure support, set respiratory rate, and peak inspiratory pressure. Enumerate all distinct `respchartvaluelabel` values in a full source scan and emit matched/unmatched mapping files. Unknown, ambiguous, empty, nonnumeric, and out-of-bound values are missing, not converted or imputed from another field. Do not infer units beyond the eICU convention.

For every component and window, require at least two valid observations at distinct clinical offsets with separation of at least 30 minutes; take the median of all valid observations. Store counts, unique-time counts, first/last offsets, median, maximum gap, parser status, and missingness reason. The primary support domain excludes peak inspiratory pressure and is positive when at least one of FiO2 decreases by >=0.05, PEEP/PEEP-CPAP by >=2 cm H2O, pressure support by >=2 cm H2O, or set rate by >=2 breaths/min between B and O. A component can contribute only when it is eligible in both B and O.

The safety domain uses `sao2` and `respiration` from `vitalPeriodic`, with the same two-observation/separation and median rules. Each signal that is eligible in both B and O must satisfy `sao2` decline <=2 percentage points and respiration increase <=4 breaths/min. At least one safety signal must be eligible in both windows; if neither is eligible, safety is missing. A violation by any eligible signal fails safety. Report a sensitivity requiring both signals and another allowing at least one, frozen before outcomes.

Airway corroboration is present if O contains at least one `respiratoryCare` row with nonmissing `airwaytype` or at least one nonmissing interval among `ventstartoffset`, `ventendoffset`, `priorventstartoffset`, `priorventendoffset`. This is source corroboration, not device truth.

For the primary horizon, `unitdischargeoffset <= D+1800` is a competing exit, with status/location retained; discharge/death/truncation before the complete O cannot be recoded as improvement. `unitdischargeoffset <= D+360` is additionally flagged as no post-washout opportunity. For O12, apply the analogous `<=D+1080` rule. A complete endpoint row requires at least one support component eligible in both windows, at least one safety signal eligible in both windows, and airway corroboration; otherwise it is endpoint-missing unless a competing exit applies. Among complete non-competing rows, persistent improvement requires support reduction and safety preservation. The mutually exclusive row state is `persistent_improvement`, `observed_nonimprovement`, `endpoint_missing`, or `competing_exit`, with exit subtype separately retained. Setting-only and support-only outcomes are secondary and cannot replace the primary.

The airway-transition sensitivity uses a pre-frozen exact normalized `respiratoryCare.airwaytype` transition to `No Artificial Airway`, or a pre-frozen exact normalized ETT-removal treatment candidate followed by no invasive-airway respiratoryCare row for 48 hours. If observed in fewer than 10% of rows in either arm, it is unavailable/inconclusive and no association is estimated.

## Baseline, opportunity, and leakage prevention

Baseline features use only rows with clinical time `<=D`: latest and median valid pre-D component values, pre-D P-versus-B trends, component eligibility, source presence, count, distinct clinical times, median inter-record gap, and `respchartentryoffset-respchartoffset` lag summaries. Opportunity-only variables include counts/times/label diversity and source presence but never respiratory values, care-plan values, target labels, treatment semantics, or post-D fields. Post-D opportunity is reported descriptively and as a selection-sensitive secondary analysis; it is never a primary adjustment.

The state-only model and state-plus-label model use identical pre-D state/opportunity columns, preprocessing, imputation, standardization, and regularization. Only the latter adds the binary exact label. A separate opportunity-only model excludes all values and label semantics. All fitting, imputation, scaling, observation weights, and calibration are trained inside each training-hospital fold. No held-out outcome, label prevalence, or target-derived calibration is used during training. A complete-case binary analysis is always accompanied by the four-state model and observation/competing-exit denominators; no complete-case estimate is reported alone.

## Hospital-held-out estimand and uncertainty

The primary transport analysis is leave-one-hospital-out. Before fitting, emit per-hospital/per-landmark support counts for each label, complete endpoint rows, four outcome states, and exits. The arm-contrast gate requires at least five hospitals with >=10 complete endpoint-observed rows under each label and >=50% of complete rows from those hospitals. No within-hospital label contrast is claimed if a test or training fold contains only one arm; no artificial relabeling is allowed. Broad prediction metrics may include eligible one-arm folds only when the metric is defined for the observed test distribution, and arm contrasts are marked unavailable.

Report row-weighted micro and equal-hospital macro log loss and Brier score, calibration slope/intercept, AUROC only when both classes occur, observed and predicted evaluation-minus-no-trial risks, and hospital-specific directions. Compare state-plus-label with state-plus-opportunity as primary and opportunity-only as secondary; report four-state observation-process performance separately so a missingness gain is not mistaken for a value-based gain.

Use stay-cluster bootstrap, not row bootstrap: resample `patientunitstayid`/`sid` clusters within hospital strata, preserve every landmark of a sampled stay, and refit the full fold pipeline. Fixed seed is `61061`; target 1,000 replicates, minimum 500 if feasible, with the actual count and failures recorded before inspecting results. A label permutation sensitivity permutes labels within hospital-by-landmark strata only where both arms are present, preserving cluster rows and arm counts; run 1,000 permutations only if >=20 valid strata, otherwise mark unavailable with the exact count.

## Falsification and interpretation gates

Prespecified falsifications are: (1) apply the same endpoint to P versus B as a pre-D placebo; (2) shift the nominal exposure time to D-720 while retaining O relative to D; (3) ablate each support and safety component and airway corroboration; (4) predict post-window source density and entry lag as opportunity-only negative controls; (5) compare the observed increment with valid within-hospital-by-landmark permutations; (6) repeat the frozen recipe's 24-, 12-, and 6-hour pre-L invasive-evidence variants without silently changing the denominator; (7) use pre-D-only inverse-observation weights with fixed 1st/99th percentile truncation; (8) audit all window boundaries and ensure no post-D baseline field; (9) repeat two-observation persistence with 60-minute separation and first/last summaries.

Call the result **computationally supportive** only if the primary unbounded endpoint and at least two invasive-evidence sensitivities pass all of: five-hospital support gate; positive evaluation-minus-no-trial risk difference with at least 4/5 estimable hospital directions positive; state-plus-label improves both micro and macro held-out log loss by >=0.01 over state-plus-opportunity with a favorable stay-cluster 95% interval excluding zero; no comparable pre-D/lead-time placebo, valid permutation, component/source or leave-one-hospital-out reversal; missingness/exit differences do not explain the gain; and airway corroboration is present in >=10% of both arms. Even then, the claim is incremental information in this eICU chart construct only.

Call it **adverse** only when endpoint support is adequate and a prespecified failure reproduces in a bounded sensitivity: no label increment beyond state/opportunity; hospital reversal; placebo-sized or permutation-compatible gain; component/source dependence; or opportunity-density association without value-based gain. This does not prove absence of bedside evaluation or a local documentation convention.

Call it **inconclusive** when artifact/recipe/source verification fails; fewer than five hospitals meet support; no estimable held-out arm contrast exists; endpoint or airway corroboration is too sparse; positivity/weights fail; definitions disagree; or uncertainty spans meaningful gain and no gain. No relaxed threshold, post-hoc relabeling, pooled row bootstrap, or outcome-selected denominator is permitted.
