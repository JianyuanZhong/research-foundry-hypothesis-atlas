# Bundle- and clock-valid report-availability frontier for documentary M2

## Decision question and substantive repair

The clinical question remains bounded: among adults at their first eligible liver resection, can routine preoperative CT/MRI report semantics improve a laboratory-independent flag for pathology-documented high-grade microvascular invasion (M2) enough to justify multidisciplinary review? The output is a historical classification/review flag. It is not a recommendation for resection extent, transplant, neoadjuvant/adjuvant therapy, surveillance, or any treatment.

The parent’s same-fit semantic ablation is retained. The repair is necessary because the source stores report components as rows, report visibility is not observed, and the source has no report-version clock. The primary estimand must therefore distinguish three claims:

1. Stored-content potential (P_store): what value would the fixed semantic pipeline have if all selected, nonempty eventual CT/MRI report bundles were exposed? This is computable, but is not a decision-time or deployment claim.
2. Partial-visibility frontier (P_frontier): for an unknown joint pattern of bundle visibility, what is the worst-case and best-case value when at least a specified fraction of the whole target frame has at least one visible selected report? This is a deterministic partial-identification set; it assumes neither independence nor a visibility distribution.
3. Decision-time value (P_dec): what value would be obtained from the exact report version available at t_dec? The HCC snapshot cannot identify this: it has acquisition time and eventual report text, but no authored, finalized, released, viewed, or version timestamp. A positive P_store or P_frontier result cannot be described as P_dec without a separate source-system audit.

The strongest evidence currently supports only that the HCC files contain operation starts, examination acquisition starts, eventual CT/MRI report text, and pathology text. The schema does not provide report finalization/view times, raw images/slides, specimen IDs, sampling adequacy, recurrence, survival, treatment benefit, or clinician response. The documentary endpoint is consequently not latent biological M2.

## Source audit and what it changes

The frozen HCC snapshot is [source checksum]. Its examination source has 419,996 rows and 932 distinct values of Examination. Direct inspection shows that one Examination Number and Start Time can occur in multiple rows with different anatomical/report-component labels; these rows are one examination-level report bundle, not independent reports.

A read-only broad audit (not a prevalence estimate and not the final clinical dictionary) found 46,618 examination rows in the 90-day pre-index windows of an adult, same-encounter-HCC, broad first-liver-resection audit frame for 2015–2021. Grouping before modality filtering produced 43,827 source bundles and 3 exact duplicate rows. Classified candidate bundles had row multiplicities from 1 through 10. The latest-bundle selection in this audit yielded 6,569 patient-modality bundles; 5,038 patients had no nonempty selected bundle, 5,369 had one, and 600 had two. This diagnostic count used a broad label/machine heuristic and must not replace the frozen reviewed dictionary or final execution counts. It does establish that row-wise modality filtering can discard companion rows and that report-level aggregation is required.

The primary construction is therefore:

- First deduplicate exact source rows on all eight examination columns.
- Form a candidate bundle from all rows sharing (Patient Master Index, Visit Number, Examination Number, Start Time) when Examination Number is nonempty. Determine CT/MRI eligibility at bundle level using the frozen exact reviewed dictionary over the bundle’s Examination values and machine provenance; retain all component rows in an eligible bundle before any text extraction.
- Rows with blank examination numbers are retained in the audit log but are not primary semantic bundles because the report-level join is unidentifiable. A prespecified sensitivity may treat a blank-ID row as a singleton bundle, but it cannot be used to claim report-level availability.
- Select at most the latest eligible CT bundle and latest eligible MRI bundle before t_dec, using start time, then nonempty examination number, then normalized bundle label as deterministic tie-breakers. Do not select rows independently. Record every discarded bundle, tie, component-row count, machine, and text-empty status.
- Concatenate/normalize all retained component rows within a selected bundle before extracting size, count, thrombus, formatting, and semantic fields. A state exposes or masks the entire bundle; it cannot expose one component row while masking another.

The parent’s q_i in {0,1,2} is retained only after this bundle-first procedure, where q_i is the number of selected bundles with nonempty eventual report text. Let J_i be all selected CT/MRI bundles before text filtering (zero, one, or two), and let E_ij=1 if bundle j has nonempty stored report text. Empty bundles are kept in the acquisition/missingness audit and have no exposed content state.

## Population and temporal lock

Retain the parent’s population:

- In procedures, select the earliest valid start time whose normalized exact surgery is in the frozen reviewed dictionary of partial, segmental, hemihepatic, or liver-tumor resections. Exclude transplant, biopsy/puncture, ablation-only, gallbladder-only, metastatic-organ surgery, and explicit repeat/recurrence operations. Resolve exact-time ties by encounter number and normalized surgery; emit raw-value frequencies and all exclusions.
- Require age >=18 from the same-encounter encounters row and explicit HCC identification in same-encounter pathology text. Keep patients with undocumented or uncertain MVI grade in the denominator.
- Set t_dec = index procedures.Start time - 24 hours. Primary imaging acquisition must satisfy t_dec-90 days <= examinations.Start time < t_dec. Repeat 12-, 48-, and 72-hour buffers are sensitivity analyses.
- Exclude recorded prior HCC resection, transplant, TACE, ablation, radiotherapy, targeted therapy, or immunotherapy in [t_dec-365 days,t_dec) using reviewed dictionaries and valid source times. Analyze treated patients separately.
- Use 2015–2018 for development, 2019 for tuning and recalibration, and untouched 2020–2021 for the primary test. Keep one period per patient. Use later years only for extraction/template drift audits, never a contemporary performance claim.
- Freeze dictionaries, parser, bundle aggregation, masking, feature coding, robust objective, solver, threshold, bootstrap family, frontier grid, and interpretation gates before test outcomes are read.

All denominator counts are whole-frame counts after the frozen population/imaging definition, not counts restricted to V=1 or to report-visible patients.

## Documentary outcome and whole-frame uncertainty

For each index patient define Y_i as:

- {1} only when a position-aware parser and blinded adjudication assign explicit M2 to the index resection pathology;
- {0} for explicit M0 or M1;
- {0,1} when grade is missing, positive MVI is ungraded, the specimen linkage is uncertain, text conflicts, or documented sampling is inadequate.

Thus V_i=1 is a trustworthy documentary assignment and V_i=0 is an outcome interval, never a complete-case exclusion. The parser may use only the immediate selected value after a frozen anchored field, with definitions, historical clauses, other-specimen sections, unanchored M2, binary positive MVI, and conflicts treated as uncertain. Two independent parsers must agree on locked records. Blinded qualified Chinese-reading pathologists review every parsed M2, conflict, and test V=0 plus year/template samples of M0 and M1; a third resolves disagreements. Required PPV, sensitivity, kappa, and disagreement thresholds are frozen before test review.

Raw slides, block counts, vessel measurements, specimen identifiers, and sampling protocols are unavailable. No result may be called biological M2 or generalized beyond documentary M2.

For every fitted development/tuning model, use the same patient-level robust objective over label and bundle-state uncertainty:
sum_i max_{y in Y_i, r in Omega_i} log(1+exp(z_theta(x_i(r)))-y*z_theta(x_i(r))) + elastic-net penalty.
The exact preprocessing, penalty selection, nonnegative-slope recalibration, and solver are rebuilt inside each resample. This makes outcome uncertainty part of fitting rather than silently replacing unknown labels with a complete-case estimate.

## Bundle visibility and temporal uncertainty

For selected bundle j, define the latent state A_ij(t_dec) as whether the exact report version represented by the stored bundle was visible to the clinical decision process by t_dec. A_ij=0 for E_ij=0; for E_ij=1, A_ij is unknown and may be 0 or 1. The admissible patient state space is:
Omega_i = {a in {0,1}^{|J_i|}: a_j=0 whenever E_ij=0}.

No independence, monotonicity, missing-at-random, or relationship between visibility and outcome is assumed. Every compared score for a patient uses exactly the same bundle state and bit ordering. Acquisition facts (modality, acquisition time, bundle count, and development-frequency machine category) remain available when a report body is masked; all report-body-derived fields are masked together.

For P_store, expose the eventual stored text of every E_ij=1 bundle as a deliberately labeled potential-content state. Do not call this preoperative availability.

For P_dec, introduce T_ij=1 only when external evidence verifies that the exact text version used by the feature extractor was finalized/released (and preferably viewable) before t_dec. The decision-time semantic feature is present only when both A_ij=1 and T_ij=1. Since HCC has neither report timestamp nor version history, the decision-time identified set includes worlds in which all semantic text was post-cutoff; the data cannot support a positive decision-time semantic increment. An order, accession, or acquisition time is not a report-availability time.

## Models and estimands

Retain the parent’s interpretable elastic-net logistic models:

- B: age, sex, acquisition modality indicators, development-frequency machine category, and report-exposed structured maximum lesion diameter, lesion-count category, and explicit macrovascular tumor thrombus with unknown indicators.
- S: exactly B plus the frozen semantic block C_R from concatenated bundle text: capsule, irregular/non-smooth margin, satellite/peritumoral lesion or enhancement, arterial hyperenhancement, washout, and peritumoral hypointensity.
- S0: not refit. It is S’s exact fitted coefficients, intercept, preprocessing, penalty-selected pipeline, and recalibration with only C_R replaced by its frozen state-zero reference vector. Therefore score_S(i,r)=score_S0(i,r) for every state with no exposed bundle. This is a required invariant.
- W and A=W+C_R remain secondary process/provenance diagnostics only. Labs are never features, strata, gates, states, fits, or thresholds.

At threshold p, let w=p/(1-p), I_M(r,p)=1[score_M(r)>=p], and:
d_i^(M1,M0)(y,r,p) = [y-w(1-y)] [I_M1_i(r,p)-I_M0_i(r,p)].

Primary contrasts are D=(S,S0) for semantic content and C=(S,B) for complete strategy versus the independently optimized baseline. Defaults are F_all=(S,flag-all) and F_none=(S,flag-none). Every endpoint uses the whole target denominator N. For uncertain V=0 patients, optimize over y_i in Y_i; for V=1 use the adjudicated singleton.

The stored-content potential is the identified interval [L_D^store(p), U_D^store(p)] and [L_C^store(p), U_C^store(p)], obtained with all nonempty selected bundles exposed. The principal clinical margin is m=0.01 net benefit at p=0.30. A stored-content support claim requires the simultaneous lower confidence bounds of both D and C to exceed m, and the D and C point lower bounds to remain positive at p in {0.25,0.275,0.30,0.325,0.35}. This claim is about stored-content potential within the fixed pipelines.

For the partial-visibility frontier, let a_i(r)=1 if at least one selected bundle is exposed in state r. Let K_max=sum_i 1(|J_i|>0). For each attainable integer k from 0 to K_max, c=k/N, and j in {D,C,F_all,F_none}, compute:
L_j(c,p)=N^-1 min_{r_i in Omega_i, y_i in Y_i: sum_i a_i(r_i)>=k} sum_i d_i^j(y_i,r_i,p),
U_j(c,p)=N^-1 max_{r_i in Omega_i, y_i in Y_i: sum_i a_i(r_i)>=k} sum_i d_i^j(y_i,r_i,p).

This is an exact multiple-choice cardinality dynamic program over patient-level bundle states; it is not row weighting, averaging over states, or a probability model. Verify it against brute force on small fixtures, including two bundles whose rows have different report components. Report infeasible c>K_max/N. Coordinatewise lower bounds are valid for the conjunction because support requires each contrast to exceed the margin in every admissible state; do not present coordinatewise extrema as one common latent world.

Define the prespecified inference grid G as attainable k values snapped upward to the nearest 0.05 coverage level plus 0 and K_max/N. Define c* as the smallest g in G such that for every g' in G with g' >= g, the simultaneous lower bounds for D and C exceed m at p=.30, both default contrasts are positive by m, and the point lower bounds for D and C remain positive over the five p values above. If no such g exists, c* is undefined. The exact point frontier is still reported for every k; no isolated coverage or threshold may be selected after seeing results.

## Simultaneous inference and falsification

Resample patients within calendar period, preserving each patient’s complete bundle set, component rows, outcome interval, and all joins. Use 2,000 bootstrap refits of the robust B/S pipelines, recalibration, same-fit S0, all four contrasts, all k values needed for the point frontier and G for inference, and all five clinical-margin thresholds. Use one frozen max-deviation family over D, C, F_all, and F_none lower/upper endpoints, coverage grid G, and p in [.25,.275,.30,.325,.35]. The primary stored-content decision uses a one-sided 95% simultaneous lower band; pointwise intervals are descriptive only. More than 2.5% failed refits invalidates inferential support. The deployment/clock-locked gate uses a prespecified one-sided 97.5% bound for the external audit, with an explicit joint-error allocation or joint resampling if audit and model samples overlap.

Use 1,000 development/tuning-only process-matched semantic-null repetitions, permuting the complete C_R bundle block within frozen year, CT/MRI provenance, bundle-state cardinality, and formatting family. Refit S and A and reconstruct S0. Observed D must exceed the prespecified 97.5th null quantile; label-permutation and post-cutoff leakage fixtures must behave as null/leakage controls.

- Supportive stored-content result: all endpoint/parser/bundle/robust-fit gates pass; simultaneous lower bounds for D and C exceed .01 at .30; their point lower bounds stay positive over the five thresholds; S beats both defaults by the frozen margin; and the semantic-null control is passed. The strongest conclusion is materially favorable stored report semantics within S’s fixed scoring pipeline, with the complete S strategy exceeding B in this historical documentary-M2 frame under maximal stored exposure. It does not establish report visibility, exact preoperative availability, biological M2, clinician benefit, treatment effect, or deployment value.
- Adverse stored-content result: the simultaneous upper bound for D is below .01, or D’s identified interval is wholly non-supportive; or C/defaults fail with an identified interval wholly below the prespecified margin; or the semantic-null control is not exceeded. A failure in the all-exposed stored state cannot be rescued by greater visibility. AUC or discrimination cannot override an adverse net-benefit estimand.
- Mixed result: D supports but C does not means semantic content changes actions within S but the full strategy does not beat the optimized baseline; do not recommend S. C supports but D does not means refitting/shared-feature differences may help, but runtime semantic content is not shown valuable. A stored-content result supports while the timestamp-locked result is unavailable is also mixed/incomplete, not deployment support.
- Inconclusive result: the interval crosses the margin; any gate, parser, bundle linkage, outcome adjudication, robust fit, or simultaneous-inference requirement fails; test M2 or V=1 counts are inadequate; or c* is undefined. A positive point estimate, AUC, unrestricted-text ceiling, complete-case outcome analysis, or eventual-text-as-visible analysis is not support.
- Decision-time/deployment conditional result: call P_dec supported only if an external audit from the same workflow supplies per-selected-bundle finalization/release and preferably view timestamps, uses the same t_dec, bundle key and at-least-one-visible-patient unit, verifies the exact report version, and its one-sided 97.5% coverage bound overall and in the claimed CT/MRI strata is at least c*. Without this evidence, the decision-time claim is inconclusive regardless of P_store. Coverage below c* is adverse under the robust criterion; absent or mismatched clock evidence cannot be imputed.

The minimum global feasibility gates remain test N>=1,000, at least 75 adjudicated M2 outcomes, V=1>=85%, parser/radiologist thresholds, report text nonempty in >=80% of selected nonempty-report bundles, structured size/count jointly extractable in >=70%, no required-feature shift >15 percentage points, exact shared-state inference, and zero forbidden/laboratory lineage. Modality-stratum claims require at least 100 patients and 20 V=1 M2 outcomes per claimed stratum. Calibration and operating metrics are descriptive diagnostics and cannot replace the net-benefit gates.
