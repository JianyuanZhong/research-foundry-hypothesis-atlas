## Clinical question, present evidence, and unresolved hypotheses

The bounded decision question is whether, 24 hours before an adult's first eligible HCC resection, routine CT/MRI report semantics could add clinically material information to a laboratory-independent flag for multidisciplinary review of pathology-documented high-grade microvascular invasion (M2). The output is a historical review flag. It is not a recommendation for resection extent, transplant, neoadjuvant, adjuvant, systemic or locoregional therapy, or surveillance.

The inspected full XML of Li et al. (2025; DOI `10.1111/jcmm.70746`, PMCID `PMC12309289`; frozen source `[source checksum]`, [source checksum]) supports that MVI is pathology-determined, prognostically relevant, unavailable directly before surgery, and that management implications remain controversial. It does not validate M2, routine report text, report availability, this institution, or treatment benefit.

**Unresolved stored-content hypothesis P-A.** In the locked 2020–2021 whole first-resection test frame, after accession-first bundling and encounter-composite pathology, exposing every eligible nonempty eventual CT/MRI accession yields one-sided simultaneous 95% lower confidence limits above 0.01 net-benefit units at threshold 0.30 for both same-fit semantic attribution `D=S-S0` and complete-strategy value `C=S-B`; S also exceeds flag-all and flag-none by 0.01, and point lower bounds for D and C remain positive at 0.25, 0.275, 0.30, 0.325, and 0.35.

## Accession-first imaging construction

Deduplicate exact rows across all eight examination columns. A nonblank accession is all rows with the same `(患者主索引,就诊号,检查号)`, irrespective of exact `开始时间`. Blank IDs remain acquisition-row audits and never supply primary semantic features.

For each accession:

1. Retain every component `检查,检查所见,检查诊断,开始时间,机器型号`; never discard a row before eligibility and modality adjudication.
2. Parse every component start string. A primary semantic accession is time-eligible only when every nonduplicate component has a valid timestamp and all component times lie in `[t_dec-90 days,t_dec)`. Its conservative acquisition-completion clock is the maximum component time. If any component time is invalid or outside the window, the accession supplies no primary body-derived feature. This prevents a post-boundary component from entering through an earlier sibling row.
3. A blinded radiology/informatics mapping assigns the entire accession exactly one of CT, MRI, nonliver/ineligible, or X from all labels and machine values. Any cross-modality, reused-ID, or unexplained time-span concern remains one indivisible X accession with no primary semantic feature. It is never copied or split.
4. Concatenate all component findings and diagnosis fields deterministically with accession, field, component, and timestamp boundaries. Exact duplicate text is retained once and logged. Empty means only no non-whitespace character; clinically meaningful text such as `无` is not empty.
5. Select at most the latest eligible CT and latest eligible MRI accession per patient using maximum component time, then nonblank examination number, normalized label tuple, and stable whole-accession hash. Selection occurs before checking body emptiness.

The primary grain is justified by the explicit `检查号` field and avoids internally splitting one identifier. A locked sensitivity repeats the entire analysis under the parent's `(patient,encounter,examination number,start time)` split key. It cannot rescue P-A or T-A. If either primary conclusion or any all-report D/C point at 0.30 changes by at least 0.005 net-benefit units, label the result grain-sensitive and require source-system accession/version adjudication before any semantic-value conclusion. Independently, audit all multi-time accessions in the target frame; an unresolved reused-ID rate above 1% of selected accessions is inconclusive.

For selected accession j, `E_ij=1` only when its concatenated findings or diagnosis body is nonempty. Let `J_i` contain selected CT/MRI accessions, including empty bodies, and
`Omega_i={a in {0,1}^{|J_i|}: a_j=0 if E_ij=0}`
in CT-then-MRI order. Exposing an accession exposes all its component text-derived size, count, thrombus, formatting, and semantic features; masking it masks all together. Acquisition modality, maximum acquisition time, accession count, and development-frequency machine category remain available. No MAR, visibility independence, or monotone patient benefit is assumed.

The eventual nonempty pattern is `g=0` for no selected nonempty accession, `g=C` for CT only, `g=M` for MRI only, and `g=CM` for both. Thus `N=N_0+N_C+N_M+N_CM`.

Two independent context-aware parsers emit, for every row, candidate HCC-resection relevance and only immediate values after frozen MVI-grade anchors. Definitions, histories, negations, examples, unanchored M2, binary MVI, and other-specimen text cannot assign grade. Two qualified Chinese-reading hepatobiliary pathologists, blinded to predictors and scores, review every candidate M2, every row-level or cross-row conflict, every test V=0, every multirow test encounter, and stratified samples of at least 150 M0 and 150 M1 encounters. A third resolves disagreement.

Let R_i be all rows that either reviewer cannot exclude as belonging to the index liver resection. `Y_i={1}` only if every grade-bearing relevant row agrees on explicit M2 and linkage is trustworthy; `Y_i={0}` only if every grade-bearing relevant row agrees on explicit M0/M1 and none is M2; otherwise `Y_i={0,1}`. `sum_i max_{y in Y_i,r in Omega_i} [log(1+exp(z_theta(x_i(r))))-y*z_theta(x_i(r))] + elastic-net penalty`.

## Models and estimands

Preserve the parent’s interpretable robust elastic-net pipelines:

- B uses age, sex, acquisition indicators, development-frequency machine category and, only for exposed accessions, frozen lesion diameter, lesion-count category and explicit macrovascular thrombus with unknown indicators.
- S is exactly B plus present/absent/unknown capsule, irregular/non-smooth margin, satellite/peritumoral lesion or enhancement, arterial hyperenhancement, washout, and peritumoral hypointensity.
- S0 is not refit. It uses S's coefficients, intercept, preprocessing, selected penalty and recalibration while replacing only the semantic block by its frozen state-zero vector. Assert bitwise `score_S=score_S0` whenever no semantic accession is exposed.
- W and A=W+the identical semantic block remain secondary workflow/provenance diagnostics. Unrestricted text is a ceiling diagnostic only.

At threshold p, `w=p/(1-p)`, `I_Mi(r,p)=1[score_Mi(r)>=p]`, and for contrast j=(M1,M0),
`d_i^j(y,r,p)=[y-w(1-y)]*[I_M1i(r,p)-I_M0i(r,p)]`.
Primary contrasts are D=(S,S0) and C=(S,B); S versus flag-all and flag-none are required baselines. Every sum divides by whole-frame N.

## Falsification and interpretation

- **Supportive P-A:** every global and composite-endpoint gate passes; all-report simultaneous lower limits for D and C exceed .01; S beats both defaults; the threshold plateau and semantic-null gate pass; and grain sensitivity is <.005 with no conclusion change. Conclude only that accession-complete stored routine report semantics made materially favorable action changes within frozen S and that complete S beat B in this historical documentary-M2 frame.
- **Supportive T-A, audit absent:** P-A passes and the pattern support set is nonempty. Conclude only that the reported access vectors would suffice under adversarial accession visibility and documentary-outcome assignment. Actual decision-time availability remains unresolved.
- **Decision-time conditional:** the exact-version audit lower-bound vector lies in the jointly controlled model support set. Conclude conditional historical transport to that audited workflow, not patient benefit.
- **Adverse:** with all gates passing, all-accession D is nonpositive, its upper confidence limit is below .01, C/default/null gates fail, or the support set is empty. If the exact-time split analysis is favorable but accession-first analysis is adverse, the evidence specifically falsifies value attributable to indivisible reports.
- **Mixed:** D supportive/C adverse means runtime semantic values alter actions favorably within S but S does not beat optimized B. C supportive/D adverse means shared-feature/refitting differences rather than runtime semantics may explain value. Neither supports S.
- **Inconclusive:** any event, V, adjudication, parser, multi-time-accession, solver, bootstrap, extractability, sparse-pattern, or uncertainty gate fails; intervals cross a boundary; grain sensitivity is material; or the external audit is absent for a decision-time claim. Favorable AUC, unrestricted text, a point estimate, or one grid cell cannot rescue the claim.

No computation establishes Chinese semantic correctness, pathology relevance/linkage, biological M2, report finalization/view, audit representativeness, accepted threshold/workload, clinician response, treatment effect, recurrence, survival, harms, costs, or patient benefit. These require expert adjudication, source-system evidence, stakeholder review, prospective validation, or another study.
