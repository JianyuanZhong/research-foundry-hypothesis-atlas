# Episode 8 evolution — a 12-hour, no-early-EOL intensity/gap test of patient state versus documentation

Status: independent substantive child of assessed-valid `[prior hypothesis]`. No cohort count, fitted parameter, prediction, metric, or clinical result is claimed.

## Scientific opening and the precise unresolved claim

The parent established a useful boundary question: early laboratory-result process features may transport differently across eICU hospitals than laboratory values, but a positive process increment could reflect patient state, discharge/end-of-life selection, or hospital documentation practice. The parent already proposes a six-hour landmark, a >720-minute sensitivity, measured-eligibility weighting, and a value-state-matched process permutation. The remaining ambiguity is that its process vector is a single aggregate: it does not say whether the signal is concentrated in *recorded intensity* (more observations as illness changes) or *recorded gaps* (absence/spacing that can reflect workflow or feed behavior), nor does its state match include a source-defined vital-state block.

The strongest inspected external evidence supports only the premises that temporally structured EHR data can predict mortality across centers [K1], that information presence/missingness can be predictive in dynamic EHR risk work [K2; abstract-only inspection], and that external discrimination/calibration and local adaptation matter for transport [K3]. None establishes that an eICU process increment is physiology, clinician testing, a data-feed artifact, or a causal determinant of death.

The falsifiable hypothesis is:

> Among adults in a first ICU admission who remain in the ICU beyond 12 hours and have no recorded care-plan-EOL event in the first 12 hours, a process increment from the first six hours will remain above a prespecified negligible transport margin after matching the process assignment within hospital on admission variables and a value-only clinical-state risk score built from both laboratory and vital values. The increment will be concentrated in recorded intensity, not merely recorded gaps, if it is a patient-linked dynamic-state signal. If it disappears under the 12-hour/no-EOL boundary, or remains in the state-matched null and is hospital-concentrated, selection or documentation is the better explanation.

This is descriptive prediction and transportability evidence, not a causal claim about testing, observation, EOL care, or mortality.

## What the experiment would change

A positive process increment that survives the 12-hour/no-EOL restriction and is attenuated by state-matched reassignment would support using process variables only as patient-linked review features, with careful recalibration. A positive increment that vanishes at 12 hours/no-EOL would identify a selection boundary: the six-hour result should not be presented as a robust early review signal. A positive increment that survives state matching, especially for gap features and in one or a few hospitals, would redirect attention to interface harmonization and site-specific documentation rather than more testing. None of these outcomes validates an alert or changes monitoring, treatment, or goals-of-care decisions.

The modeled decision boundary is a policy scenario for senior review at predicted ICU-discharge mortality >=10%, with 5% and 20% secondary thresholds. Report alert burden and decision-curve net benefit versus treat-none/treat-all. A process benefit confined to EOL-documented stays is not deployment evidence because it may duplicate a care-plan record.

## Features and the decisive decomposition

The common clinical-state block X contains age, gender, ethnicity, admissionweight, and leakage-safe values. For labs, select up to 30 analytes by training-fold distinct-stay coverage among keys with >=1% coverage; ties use normalized key order. For vitals, use the fixed candidate numeric columns listed above, retain columns with >=1% training-stay coverage, and if more than 20 qualify retain the 20 highest-coverage columns with deterministic name tie-breaks. For each retained channel, take the latest valid value in [0,360] without carry-forward and impute by the training-fold median. Values are state measurements, not proof of physiology.

For each domain d in {lab, vital}, define a process vector from valid source rows in [0,360], independent of the row values:

- Recorded intensity I_d: log1p(valid row count), number of distinct exact observation offsets, number of distinct 30-minute bins with a valid row, and number of retained channels observed at least once.
- Recorded gap G_d: 360 minus the last valid offset (360 if none), the largest run of empty 30-minute bins, and the fraction of the 12 bins without a valid row.

For `lab`, a row is valid under the lab rules above. For `vital`, a value-column observation is valid when finite and its `observationoffset` is in [0,360]. Duplicate channel/offset rows are retained for intensity but their distinct-bin and gap calculations are set-based; this rule is fixed before fitting. These features are observation proxies, not confirmed orders, clinician decisions, bedside measurements, or interface completeness.

The primary contrasts are fitted on P12 and repeated on S720 and S6:

- X-only value-state baseline.
- X+I_lab, X+G_lab, X+I_vital, X+G_vital.
- X+I_lab+G_lab+I_vital+G_vital (full process).
- A domain-block additive model and a capacity-matched nonlinear model use the same feature blocks, folds, outcome, and uncertainty.

This is a smaller mechanism check than adding model capacity: it asks whether intensity or gap, and which source domain, carries the signal.

## Split, nulls, estimands and uncertainty

Sort viable hospital IDs by SHA-256(`"eicu-transport-v2\\0"+hospitalid`) and greedily balance S720 stays into five contiguous folds. External evaluation is each held-out hospital fold; internal evaluation is a fixed 20% patient-hash reference drawn only from training hospitals using SHA-256(`"eicu-internal-v2\\0"+patientunitstayid`). No patient-only split is called external validation. All preprocessing, analyte/channel selection, medians, class handling and propensity fits are training-fold-only.

Fit X-GBM within the training partition. For training stays use out-of-fold X-GBM risk; for held-out hospitals use the fold-fitted X-GBM. Form deterministic state cells from risk quintile plus age bin, admissionweight bin, gender and ethnicity. Merge adjacent cells only when a cell has <10 stays; save every merge. Within each hospital and state cell, cyclically reassign process vectors using SHA-256(`"eicu-state-null-v2\\0"+patientunitstayid`). The null preserves X, outcome and hospital, does not use outcome in assignment, and breaks patient linkage for process features while approximately matching recorded clinical state. Run separate nulls for each I/G block and a joint I+G null; retain the parent unrestricted same-hospital permutation and +180-minute offset displacement as secondary controls.

## Baseline, learned alternative, and resource choice

The transparent baseline is an elastic-net logistic model with additive domain blocks X, I_lab, G_lab, I_vital and G_vital. It reports standardized coefficients, block-level contrasts, calibration and policy metrics, so direction and domain attribution are inspectable. The substantive alternative is a capacity-matched histogram GBM with exactly the same inputs, target, hospital split, preprocessing isolation, null assignments and uncertainty. It can reveal nonlinear state-by-gap interactions that the additive baseline loses. A predictive gain alone is not scientific support; it must agree on the domain/intensity conclusion, survive the state/selection checks, and improve calibration or the policy contrast.

## Falsification and interpretation

Support for patient-linked dynamic state requires a positive P12 external increment above the 0.01 AUC margin (and preferably aligned calibration/10% net benefit), persistence from S720/S6 to P12 rather than concentration only near the landmark, and attenuation of the corresponding observed process increment under the state-matched null. Intensity being stronger than gap, with consistent lab/vital direction, would be the most specific supportive pattern. It remains descriptive evidence, not physiology or causality.

Support for selection/censoring is a positive S6 or S720 increment that falls below the margin in P12 or after excluding EOL12, especially when the selection audit shows changed prevalence or hospital composition. This means the six-hour signal is boundary-dependent; it does not prove EOL care caused the prediction.

Support for documentation/workflow is an increment that persists in the state-matched null, especially for G blocks, remains under the same-hospital permutation, or is concentrated in one hospital/fold while state and outcome distributions are similar. This supports a documentation-compatible explanation, not proof of an interface outage or clinician behavior. A lab-only or vital-only increment would identify a source channel for harmonization; a shared I+G increment with both domain nulls attenuated would support generic observation density rather than a unique lab mechanism.

Adverse evidence is a confidence interval wholly below the negligible margin for the primary external increment, with no calibration or policy benefit and no technical explanation. Mixed or imprecise results are inconclusive when intervals span the margin, P12 has insufficient hospitals/events, EOL12 is sparse, state cells require excessive merging, weights are unstable, hospital-level effects are heterogeneous, or feature selection changes materially. Do not treat an imprecise null as refutation.

The verifier can check source paths/hashes, row counts, joins, offsets, cohort flags, fold isolation, feature definitions, null assignments, predictions, metrics, bootstrap intervals and conclusion-to-output linkage. It cannot decide whether a row is a clinical order, specimen, bedside vital, device aggregation, interface omission, or EOL decision. Those claims require order/specimen/device/interface timestamps, clinician adjudication, a reliable death time, and prospective silent-deployment/impact evaluation. No result licenses a change in monitoring, treatment, or goals-of-care practice.
