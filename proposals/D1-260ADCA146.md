# Target-linked downstream documentation falsification amendment

## Status, parent, and scope

This is a substantive, narrowly bounded child of `[prior hypothesis]`. It preserves the parent's complete scientific schema and all inherited rules: the first-eligible adult, one-admission-per-subject, all-opportunity pulmonary denominator; reciprocal pre-departure radiology chronology; one canonical discharge summary (`DS`); exact recommendation atom `g=(E,terminal_service,W)`; unit-specific clocks and exhaustive `Y,V,H,Z` states; sealed route-concealed component panels; the pure route predicate and `AUTO > RECON > TIMING > DEFER > NOACTION` precedence; all-unit adverse routing; positive-probability two-phase whole-admission sampling; the `A<=900`, `C<=300` design; exact compatible-set inference with shared error; the reconciled `2,370` physician-hour/`84,000` packet-minute ledger; no rescue, switching, pooling, borrowing, or post-label reallocation; and the strict prospective-silent-only conclusion ceiling.

Only one secondary layer is added. It does not redefine the population, index time, recommendation atom, route, allocation, primary route/atom estimand, or any inherited gate. It asks whether a pre-departure text route has a reproducible, target-linked downstream documentation signal in the locally observable radiology record. All post-discharge observations are downstream outcomes and are opened only after the inherited selection and labels are sealed. The added layer cannot authorize an alert, order, referral, copied text, or patient-facing action.

The protocol hash must include this amendment, the exact parser and transformation manifest, the schema hashes, and all numerical gates before any real label or downstream outcome is opened. Synthetic fixtures are used to test implementation before labels.

## Evidence status and unresolved clinical question

The available evidence supports construction of an admission-linked pulmonary text opportunity and a reproducible atom/route audit from stored radiology and discharge text. It does not establish that a recommendation was clinically appropriate, that a clinician saw or signed the text at physical departure, that a target was communicated, that a follow-up study occurred, that a report reflects completion rather than incidental care, or that any observed association is causal.

The unresolved, falsifiable claim is narrower: among the exact atoms that pass the inherited retrospective text-routing gates, does the route identify a different rate of *MIMIC-observable, target-linked radiology documentation by the atom's prescribed due boundary* than a prespecified route-scrambled control? A positive result would connect the text construct to a downstream documentation/workflow proxy and identify which route signatures merit silent prospective observation. It would not establish completion, appropriateness, safety, benefit, or responsibility.

The directional hypothesis is registered before labels: among active target atoms with a fully observable follow-up window, `AUTO` has a higher target-linked-documentation rate by its due boundary than the combined `RECON/TIMING/DEFER` group. This is a descriptive, design-weighted contrast, not an intervention effect. The route-scrambled control must have no route-linked contrast after permutation; if it does, the proposed interpretation is falsified. If the directional contrast is absent, reversed, or too uncertain, the downstream layer does not support an `AUTO`-specific handoff signal, even if the inherited text reproducibility gate passes.

## Exact downstream target and boundary rules

For each inherited recommendation unit `u` with exact atom `g` and canonical index radiology store time `R_store,u`, let `D=admissions.dischtime` and `DS_store` be the inherited canonical discharge-summary store time. The downstream analysis uses only units that the inherited route algebra marks `PRESENT`, `Q=RESOLVED`, and `Z in {F_text,C_O_text}`. Units with `UNKNOWN`, `U_BOUNDARY`, unresolved reciprocal links, unknown `W`, malformed times, or a nonpositive inherited content clock remain adverse-compatible and are not silently moved into the downstream target set.

The inherited due interval `W` is not reinterpreted. Its frozen parser emits a finite coded interval with an integer upper boundary `w_hi` in days. For a unit, define the closed-open target window

`J_u = [max(D, R_store,u), max(D, R_store,u) + w_hi days)`.

The lower bound is inclusive and the upper bound is exclusive. A report with `storetime == D` is eligible; a report with `storetime == D+w_hi days` is outside. If `R_store,u > D`, the lower bound is `R_store,u`, retaining the inherited chronology rather than inventing an earlier opportunity. A report is never eligible merely because its `charttime` falls in the window: downstream observability is based on `storetime`, while `charttime` is retained for diagnostics. `storetime` null is not eligible and is counted as missingness.

The target-window report universe is every row in `note/radiology` for the same `subject_id` with non-null `storetime` in `J_u`, regardless of `hadm_id`; this intentionally captures later in-system documentation while not claiming that a null `hadm_id` is outpatient care. The index report and any reciprocal restatement of it are excluded by exact `(subject_id,note_id)` identity and by `storetime <= D` (the interval starts no earlier than `D`). A later report with the same `hadm_id` is eligible if its `storetime` is in `J_u`; a later admission report is eligible only as a downstream documentation observation, never as evidence of completion of the recommendation.

A candidate report is `TARGET_LINK=1` only if a route-blinded downstream reader, using a frozen codebook, records all of the following: (i) the report is not an index/restatement duplicate; (ii) its body contains an explicit target-cluster and modality assertion that matches the inherited unit under the same locked equality matcher; and (iii) the assertion is observational documentation of that target, not merely a generic history, family-history, hypothetical, negated, or unrelated mention. `TARGET_LINK=0` means the report is readable and explicitly fails at least one matching field. `TARGET_LINK=UNKNOWN` covers unreadable/empty text, missing required fields, unresolved target identity, or reader nonresponse. The reader never sees parent labels, routes, atom identity, weights, downstream counts, or the route-scrambled assignment.

The admission-level downstream endpoint is

`L_u = 1` iff at least one eligible candidate has TARGET_LINK=1;
`L_u = 0` iff all eligible candidates are readable, none has TARGET_LINK=1, and the target-control rules below are satisfied;
`L_u = UNKNOWN` otherwise.

The endpoint is a stored-documentation proxy, not an imaging-completion or care-delivery endpoint. Multiple reports are retained in the audit file, but the primary unit endpoint is the existential indicator above. A report cannot count for two distinct units unless it independently satisfies both exact target/modalities; this is retained as a possible shared-documentation state and reported, rather than deduplicated by admission.

## Observable-window and censoring states

For each `u`, compute `J_u_end=max(D,R_store,u)+w_hi days` using exact timestamp arithmetic. Use all source-available radiology rows for the same subject, including rows with `hadm_id` null, to calculate `T_last(subject)=max(storetime)` after parsing valid timestamps. Also use `patients.dod` only as an observed death indicator; it is never used to infer care.

Set one mutually exclusive window state before labels:

* `K_OBSERVED`: `T_last(subject) >= J_u_end`; the entire store-time window is observable in the local extract.
* `K_DEAD`: an observed `dod` is strictly earlier than `J_u_end` and no post-death report is eligible. If `dod` falls on the same calendar date as the boundary, use `K_UNKNOWN` rather than an assumed ordering.
* `K_UNKNOWN`: `T_last(subject) < J_u_end`, `T_last` is missing, the end boundary is malformed, or death/date ordering is unresolved.

`K_DEAD` and `K_UNKNOWN` never count as `L_u=0`. The primary estimand is conditional on `K_OBSERVED`; their weighted prevalence is reported as a separate missingness/observability estimand. This is a source-observation rule, not a claim that no outside care occurred. In sensitivity analysis, `K_UNKNOWN` is assigned the adverse-compatible value for certification bounds, never complete-case deleted.

If a subject has a later admission in `hosp/admissions` but no radiology row reaching `J_u_end`, that does not convert `K_UNKNOWN` to `K_OBSERVED`; hospital encounter presence is not proof that this note stream is complete. Conversely, a later radiology row makes the window observable in this extract but does not prove that the patient received the recommended test.

## Downstream reader separation and target-freeze controls

The downstream reader roster is disjoint from every parent component, minority-unit, H1/H2/H3, and analysis roster. Readers receive only a packet containing the candidate report text and its permitted `note_id`, `subject_id` pseudonym, `charttime`, `storetime`, `note_type`, and the frozen blinded target descriptor needed for matching. They do not receive `hadm_id`, route, terminal service, stratum, index report, DS text, post-window counts, or outcome status. The target descriptor is generated from the pre-label sealed atom as coded `(target_cluster, action_modality, polarity, due interval)`; no reader may alter it.

Each candidate report is read once by the downstream reader and a deterministic 20% hash-ranked subset is read by a second disjoint reader before either route results or downstream summaries are opened. The duplicate subset is allocated before labels and is not enriched for positive, missing, or disputed reports. Their disagreement is preserved as `TARGET_LINK_UNKNOWN` for the primary certification analysis, with exact compatible-set states retained. The reader codebook contains only `MATCH`, `NONMATCH`, `UNKNOWN`, and fixed exclusion reasons; no route category or clinical-appropriateness field is permitted.

To prevent target leakage, the downstream reader never sees the full index radiology report or DS, only the frozen coded target descriptor and the candidate report. To prevent outcome leakage, candidate selection and the hash-ranked duplicate subset are sealed before downstream labels. To prevent route circularity, no downstream label is used to modify the inherited atom atlas, route, sample, or challenge reservation.

## Primary estimands and control estimands

For each inherited route `r` and exact atom `g`, let `S_{g,r}` be the all-opportunity finite population of eligible units with `K_OBSERVED` and inherited route `r`; admission-level aggregation remains conservative: an admission contributes adversely if any of its eligible units is unresolved or adverse under the inherited route rules. The primary target-linked documentation rate is the finite-population unit-weighted rate

`theta_{g,r}= sum_i w_i I(K_OBSERVED_i) L_i(r,g) / sum_i w_i I(K_OBSERVED_i)`.

The primary contrast is `Delta_g = theta_{g,AUTO} - theta_{g,NONAUTO}`, where `NONAUTO` is the prespecified union of `RECON`, `TIMING`, and `DEFER`; `NOACTION` remains descriptive and is not pooled into `NONAUTO`. The exact contrast is reported only when both denominators are positive and the compatible-set denominator cannot be zero. Admission-level worst-unit routing is unchanged; if multiple units from one admission enter different route groups, the protocol reports the unit estimand and a separate admission-level `any-target-link` sensitivity, never silently treating units as independent subjects.

For every unit also calculate:

1. `theta_anyreport`: any eligible readable report, irrespective of target match;
2. `theta_target_specific`: TARGET_LINK=1 among readable eligible reports;
3. `theta_unknown`: unknown reader/candidate status plus `K_UNKNOWN`/`K_DEAD` separately;
4. `theta_first_link`: whether the earliest target-linked report is within `J_u` and its lag from `D`;
5. `theta_hadmbound`: target-linked reports whose `hadm_id` equals the index `hadm_id`, reported descriptively only.

The primary result is `theta_target_specific`, not any-report volume. These quantities are estimated with the inherited inclusion probabilities and finite-population weights. No complete-case, unweighted, route-triggered, or post-label reweighted estimate is allowed.

## Frozen negative controls and falsification criteria

All controls are constructed before downstream labels. Controls never rescue a failed atom or alter the primary estimand.

**N1, target-mismatch specificity control.** For each eligible unit with at least one readable candidate report, create a target descriptor by changing exactly one field to a pre-registered nonmatching value: action modality is changed to the lexicographically next modality in the finite modality dictionary, or, if unavailable, target cluster is changed to the lexicographically next cluster. The candidate report, timestamps, and window are unchanged. The expected result is `NONMATCH` unless the report independently contains the substituted target, in which case it is a documented decisive control exception and is retained. This measures whether the reader/codebook is merely calling any radiology report a match; the primary target estimate is not replaced by it.

**N2, route-scrambled control.** After the inherited route and downstream target packets are sealed but before opening downstream labels, permute route labels within exact `(possible-calendar class, terminal_service, workflow class, w_hi)` strata using a fixed hash permutation. Recompute the entire `Delta_g` procedure over 20,000 fixed permutations with no reallocation. A route-specific downstream signal must disappear under this control. An upper simultaneous absolute permuted contrast above `0.05` is a falsification of route specificity and blocks a supportive interpretation.

**N3, pre-departure placebo window.** For each `K_OBSERVED` unit, use the same duration as `J_u` in the immediately preceding interval `[D-w_hi days,D)`, excluding all reports with `storetime >= D` and all reciprocal index reports. The descriptor and target-link reader are unchanged, but this is not a downstream endpoint. A high placebo rate or a route contrast with simultaneous absolute bound above `0.05` signals generic text density, target prevalence, or reader leakage rather than a downstream handoff association. If the placebo window overlaps the index report or has unresolved lower boundary, that unit is `PLACEBO_INFEASIBLE`, retained in the control-infeasibility ledger and not complete-case deleted.

**N4, route-irrelevant text control.** On a hash-selected subset of candidate reports, replace a non-target, non-temporal sentence or section-order formatting with a provenance-matched sentence from another report while preserving all target and timing spans. The target-link result must remain unchanged. Any flip above the pre-registered exact flip gate `0.02` is a parser/reader leakage falsification.

A route-decisive synthetic control changing only the target descriptor's modality or target cluster is included in synthetic fixtures, not treated as evidence of clinical correctness. A failed control is adverse for the affected layer; no control is permitted to make a route pass.

## Compatible-set extension and uncertainty

The inherited exact `Omega_i` construction remains primary for route and atom states. For each downstream candidate report, add a finite observation state `MATCH`, `NONMATCH`, or `UNKNOWN`, plus duplicate-reader error flags. The all-ones shared-error assignment remains admissible; agreement is not truth. A missing candidate text, corrupted packet, missing timestamp, reader nonresponse, unresolved target field, `K_UNKNOWN`, `K_DEAD`, or placebo infeasibility remains an adverse-compatible state for certification.

For each unit, enumerate the Cartesian product of candidate-link states and reader error flags, retaining the joint `(L_u, K_u, report-count, first-link-lag)` contribution. Optimize numerator and denominator jointly over the inherited admission/unit compatible sets. For ratios and contrasts, retain linked numerator-denominator states and fail closed on a zero feasible denominator. Use exact rational arithmetic for finite-population totals and ratio extrema; apply the inherited finite-population inversion and 20,000 Rao-Wu max-statistic family over inherited and downstream gates. The result is an identified interval for an observable documentation functional, not a point estimate of true follow-up.

The downstream layer has a strict no-rescue rule: a favorable reader consensus, a high any-report rate, an `hadm_id` match, a passing route-scramble control, or a model-based imputation cannot narrow an adverse-compatible target-link interval. A latent-class model is diagnostic only and cannot certify an atom without an external identifying restriction sealed before labels.

## Frozen numerical gates and exact workload ledger

The amendment uses only the parent's already selected admissions and challenge cases; it adds no admissions, no adaptive sampling, and no new route-triggered review. The downstream parser and report-window enumeration are computational and use no physician hours. Downstream reader work is restricted to the parent's existing `independent audit lane` allocation on the preselected challenge cases: at most `0.20` physician-hours and `10` packet-minutes per challenge admission are reserved for downstream target-link review, leaving at least `0.30` physician-hours and `15` packet-minutes of that inherited `0.50`/`25` audit row for the inherited audit. This is a subdivision of an existing row, not an added charge. The parent ledger therefore remains exactly:

`120 + 0.30*900 + 0.45*900 + 0.50*900 + 0.45*900 + 0.50*300 + 0.50*300 + 0.35*300 + 0.15*300 = 2,370 physician-hours`,

and `9,000 + (10+20+25+15)*900 + (10+10+10+10)*300 = 84,000 packet-minutes`, with hard ceilings `A<=900`, `C<=300`, `5,100` physician-hours, and `84,000` packet-minutes. If the downstream packets cannot fit within the presealed challenge allocation, the downstream layer is `INCONCLUSIVE` and is not run; the inherited primary protocol is not changed or rescued.

The downstream layer has these pre-label gates, all simultaneous at `0.95` family coverage:

* at least 30 weighted eligible units in each claimed route group and at least 10 non-sentinel challenged admissions containing that route when feasible;
* both primary denominators positive, overall design ESS at least 150, and no normalized design weight above `0.10`;
* lower bound of target-link reader duplicate agreement `>=0.90` and upper bound of `TARGET_LINK_UNKNOWN` among `K_OBSERVED` units `<=0.05`;
* upper bound of N1 target-mismatch positives `<=0.05` and upper bound of N2 route-scrambled absolute contrast `<=0.05`;
* upper bound of N3 placebo absolute route contrast `<=0.05` and N4 route-irrelevant flips `<=0.02`;
* for a claim of the directional hypothesis, the simultaneous lower bound of `Delta_g` must exceed `0.05` absolute documentation-rate points; a bound containing zero is inconclusive, and a negative upper bound is adverse to the directional hypothesis;
* any target atom with a compatible-set state that makes the `AUTO` contrast or unknown rate fail is excluded from downstream nomination even if pooled routes pass; and
* downstream workload, packet integrity, seal order, and control feasibility must pass the inherited ledger and atom-specific no-rescue rules.

The `0.05` and `0.02` values are operational falsification margins, not safety thresholds or estimates of acceptable missed care. A gate failure excludes or renders inconclusive the affected exact atom/layer; it never establishes that the clinical workflow is unsafe or unnecessary.

## Interpretation ceiling

Supportive results require every inherited gate plus the downstream gates for each exact allow-listed atom. They support only a prospective, within-site, silent observation of the exact route and target-linked documentation signature, with actual dates and workflow events collected prospectively. An adverse result includes a failed target-specificity control, route-scramble/placebo signal, shared-error compatible state, unknown/censoring bound, reversed directional contrast, or atom-level workload/control failure. An inconclusive result includes sparse route cells, insufficient observable windows, zero denominators, reader nonresponse, infeasible controls, wide compatible sets, or broken seals. Neither adverse nor inconclusive results establish absence of care or clinical harm.

MIMIC cannot establish physical departure visibility, report finalization/signature semantics, contemporaneous awareness, communication, order/referral execution, scheduling, responsibility, patient preference, outside care, actual imaging completion, appropriateness, follow-up completion, safety, utility, benefit, causality, or transport. A target-linked radiology report is only a stored-documentation observation. Any stronger claim requires clinical adjudication and a prospective study with actual viewing/edit/sign/transmission, orders/referrals, scheduling, outside-plan capture, and patient outcomes. The only permitted retrospective conclusion remains a bounded, noncausal nomination for prospective silent validation; no retrospective automation or live intervention is authorized.

## What changed and what remains uncertain

Compared with the parent, this child adds one decision-relevant but deliberately weak bridge: a target-frozen, route-blinded, downstream radiology-documentation endpoint with exact windows, explicit observability/censoring states, reader compatible sets, target-mismatch, route-scramble, placebo, and nuisance-text controls, and fixed effect-size gates. It uses the existing sample and subdivides the existing audit workload, so inherited population, chronology, atom/route estimand, all-unit adverse routing, probabilities, ledger, and conclusion ceiling remain intact.

The substantive advance is that a passing text route must now show target-specific downstream documentation behavior rather than only agreement among pre-departure text panels. The remaining uncertainty is fundamental: downstream documentation may reflect incidental care, access, illness severity, coding, or outside processes; same-subject report availability is not complete follow-up; reader agreement is not truth; and no MIMIC field proves that anyone acted on a recommendation. These uncertainties are preserved as compatible states and are reasons for prospective silent validation, not grounds for overclaiming.
