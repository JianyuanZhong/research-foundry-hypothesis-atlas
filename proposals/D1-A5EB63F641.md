# Hypothesis Proposal: Learning Liver Function Trajectories Predicts TACE Response

## Unresolved Question

**Primary Question:** Can individual trajectories of pre-TACE liver function decline (captured by serial albumin and bilirubin measurements) predict treatment response and progression-free survival (PFS) better than baseline values alone?

**Secondary Question:** Do patients with steeper pre-TACE liver function decline trajectories have worse outcomes regardless of their baseline liver function score (Child-Pugh)?

## Clinical Importance

1. **Early Warning System**: Identifying patients with rapidly declining liver function could trigger earlier intervention or alternative treatment modalities before TACE is initiated.

2. **Personalized Treatment Selection**: Patients with steep decline trajectories might benefit more from systemic therapy or transplant evaluation rather than TACE, even if their baseline Child-Pugh score appears acceptable.

3. **Treatment Monitoring**: Understanding trajectory patterns could help clinicians monitor patients more intensively during treatment, anticipating complications in those with rapid decline.

4. **Prognostic Refinement**: Current prognostic models rely on static baseline measures; trajectory-based models could provide more dynamic and accurate predictions.

## Substantive Advance Over Existing Knowledge

Current literature focuses on:
- **Static baseline measures** (Child-Pugh score at diagnosis) predicting outcomes
- **Tumor characteristics** (size, number) as prognostic factors
- **Treatment timing** relative to diagnosis

This proposal addresses:
- **Temporal dynamics** of liver function before treatment initiation
- **Individual trajectories** vs. population averages
- **Trajectory-slope as a prognostic marker** independent of baseline level

The key insight: **The rate of liver function decline before treatment may be more informative than the absolute baseline value**. A patient with baseline Child-Pugh 7 but rapidly declining function may have worse outcomes than a patient with baseline Child-Pugh 8 but stable function.

## Data Requirements and Bindings

### Primary Dataset: HCC Clinical Registry

**Source Files:**
- `HCC/data_基本信息_2500296761891079109.csv` - Basic patient demographics (patient_id, encounter_id, age, sex)
- `HCC/data_诊断_7504718184492840569.csv` - HCC diagnoses with timing (patient_id, encounter_id, diagnosis_name, diagnosis_type, diagnosis_date)
- `HCC/data_手术_8024330590283626027.csv` - TACE procedures (patient_id, encounter_id, 手术, 开始时间，结束时间，手术来源)
- `HCC/data_检验_609065997844652188.csv` - Laboratory results (patient_id, encounter_id, 检查，定性结果，定量结果，目标类型，检查时间)
- `HCC/data_出入转_7369490831683459252.csv` - Admission/discharge/transfer events (patient_id, encounter_id)
- `HCC/data_病历文_8434587325530196878.csv` - Clinical documents (patient_id, encounter_id)

**Key Variables:**

1. **Primary Exposure**: Pre-TACE liver function trajectory
   - **Serial measurements**: Albumin (g/dL) and bilirubin (mg/dL) from multiple encounters before TACE
   - **Trajectory features**:
     - Slope of albumin decline (g/dL per month)
     - Slope of bilirubin decline (mg/dL per month)
     - Composite trajectory score (weighted combination)
     - Rate of change in Child-Pugh components
   - **Baseline trajectory**: Average trajectory in 3 months before TACE

2. **Outcome**: TACE Treatment Response
   - **Primary**: Progression-free survival (PFS) - time to tumor progression or death
   - **Secondary**: Decompensation within 30 days post-TACE
   - **Tumor response**: Reduction in tumor size/volume (from imaging if available)

3. **Covariates:**
   - Tumor characteristics: Number of tumors, largest tumor size (from diagnosis records)
   - Baseline liver function: Pre-TACE albumin, bilirubin, creatinine, PT/INR
   - Demographics: Age, sex
   - Concomitant therapy: Sorafenib, lenvatinib, immunotherapy
   - Performance status: From clinical documents

4. **Time Fields**: All timestamps in format `YYYY-MM-DD HH:MM:SS`

### Population Definition

- **Inclusion**:
  - Patients with confirmed HCC diagnosis
  - At least one TACE procedure performed
  - Multiple pre-TACE laboratory measurements (≥3) to compute trajectory
  - Post-TACE follow-up data available (for PFS estimation)

- **Exclusion**:
  - Pre-existing liver decompensation before TACE
  - Multiple TACE procedures (focus on first-line)
  - Missing critical laboratory values in pre-TACE period
  - Patients with <3 pre-TACE measurements (insufficient for trajectory)

- **Temporal Boundaries**:
  - Study period: Based on dataset range (likely 2000-2015)
  - Trajectory window: 3-6 months before first TACE
  - Follow-up: Until tumor progression, death, or 12 months post-TACE (whichever occurs first)

## Analysis Plan

### Baseline Approach
**Logistic regression / Cox proportional hazards** using baseline values:
```
outcome ~ albumin_baseline + bilirubin_baseline + child_pugh_score + tumor_burden + age + sex
```

Or for trajectory slope:
```
outcome ~ albumin_slope + bilirubin_slope + child_pugh_baseline + tumor_burden + age + sex
```

### Learned Alternative
**Longitudinal trajectory modeling** using machine learning:
- **Approach**: Fit individual trajectories using mixed-effects models or sequential modeling
- **Features**: Extract trajectory characteristics (slope, curvature, inflection points)
- **Model**: Gradient boosting or neural network to predict outcome from trajectory features
- **Advantages**: Captures non-linear trajectory effects, handles missing measurements, provides feature importance

### Key Comparisons
1. Baseline value vs. trajectory slope as predictors
2. Child-Pugh score vs. trajectory-based reserve score
3. Model performance comparison (C-index, AUC, calibration)
4. Risk reclassification: How many patients would be reclassified as high/low risk using trajectory vs. baseline

## Falsification Criteria

**Hypothesis will be falsified if:**
- Baseline values predict outcomes as well as or better than trajectory features
- No association between trajectory slope and outcome after adjusting for baseline
- Trajectory-based models show no improvement in prediction accuracy over baseline models
- Child-Pugh score remains the dominant predictor regardless of trajectory analysis

**Supportive Evidence:**
- Trajectory slope significantly predicts outcome independent of baseline (p < 0.01)
- Trajectory-based models show improved discrimination (ΔC-index > 0.05) over baseline models
- Patients with steep decline trajectories have worse outcomes even with favorable baseline
- Specific trajectory thresholds identify high-risk patients not identified by baseline alone

**Inconclusive:**
- Weak association with wide confidence intervals
- Effect modified by subgroup (e.g., only in patients without concomitant therapy)
- Need for larger sample size or external validation

## Missing Evidence and Clinical Adjudication

1. **Trajectory Computation**: Need to define the exact window (e.g., 3 months before TACE) and handle missing measurements (imputation strategy).

2. **Outcome Definition**: PFS requires tumor progression assessment; need to verify how progression is defined in the dataset (imaging review, clinical criteria).

3. **Trajectory Heterogeneity**: May need to cluster patients into trajectory subgroups (e.g., stable, declining, fluctuating) rather than using continuous slope.

4. **External Validation**: This analysis is internal; external validation would require another HCC cohort.

5. **Clinical Document Review**: May need manual review of clinical documents to confirm trajectory interpretation and outcome events.

## Expected Impact

If supported, this hypothesis could:
- **Identify high-risk patients** with steep decline trajectories who might benefit from alternative treatments or intensive monitoring
- **Improve prognostic accuracy** beyond static baseline measures
- **Guide treatment selection** by incorporating temporal dynamics of liver function
- **Enable early intervention** in patients with deteriorating liver function before irreversible damage occurs

## Method Comparison Rationale

**Baseline (Logistic/Cox with baseline values)**:
- Provides interpretable coefficients
- Handles censoring (for PFS)
- Establishes clear null hypothesis
- Directly tests main effect of liver function

**Learned Alternative (Trajectory modeling)**:
- Captures temporal dynamics and individual patterns
- Handles non-linear relationships in trajectory data
- Provides feature importance for clinical prioritization
- Can incorporate missing data more flexibly
- May reveal that trajectory slope is more informative than baseline level

**Scientific Information Gained**: The learned model may reveal that the *rate of change* in liver function is more predictive of treatment response than the absolute baseline value. This would fundamentally change clinical guidance from "baseline Child-Pugh score" to "trajectory-based reserve assessment."
