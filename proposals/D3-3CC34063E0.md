# Provisional hypothesis: E-MTAB-8873 macrophage context and donor composition

## Proposed relationship

In the frozen targeted human RA synovial FLS assay E-MTAB-8873, FLS transcript state associated with co-culture with MerTK/CD206-positive macrophages differs reproducibly from co-culture with MerTK/CD206-negative macrophages after accounting for recorded cell count and the complete contributing-donor set. This is an association/context hypothesis, not a causal macrophage-mechanism claim.

## Directly supported observations

The frozen design and matrix support the following design facts only:
- The design has 33 records and the matrix has 445 feature-instance rows.
- The design contains none-treatment MerTK/CD206-positive and MerTK/CD206-negative co-culture samples, reused donors, and a reconciled negative-versus-negative donor-composition sensitivity contrast.
- One record has conflicting donor metadata and is excluded from the primary contrast while retained in a data-quality report.
- The exact primary design contrasts and the negative-versus-negative sensitivity pair are specified in the frozen design; the matrix preserves duplicate feature symbols as distinct feature instances.

No expression contrast, model fit, uncertainty estimate, or biological result has been executed. The hypothesis is provisional and falsifiable, not an observed result.

## Population and temporal boundary

The primary population is the none-treatment samples whose condition is exactly:
- `co-cultured with MerTK/CD206pos macrophages`, or
- `co-cultured with MerTK/CD206neg macrophages`.

Exclude the malformed `R1_SA256A_FLS_SA260R_Mpos` record from the primary contrast because its donor metadata is conflicting; retain it in a data-quality report. Mixed positive/negative co-culture, LPS, inhibitor, and not-co-cultured samples are not substitutes for the primary contrast.

The prespecified contrasts are:
1. `R1_SA256A_FLS_SA259A_Mneg` versus `R1_SA256A_FLS_SA259A_Mpos` (491 versus 368 cells; donor set SA256A, SA259A).
2. `R2_SA257A_FLS_SA266A_Mneg` versus `R2_SA257A_FLS_SA266A_Mpos` (396 versus 383 cells; donor set SA257A, SA266A).
3. `R2_SA258R_FLS_SA266A_Mneg` versus `R2_SA258R_FLS_SA267R_Mpos` (1469 versus 1207 cells; macrophage donor composition differs).
4. `R5_SA263R_FLS_SA277A_Mneg` versus `R5_SA263R_FLS_SA278R_Mneg` (540 versus 440 cells; donor sets SA263R, SA277A versus SA263R, SA278R). This is a negative-versus-negative macrophage-donor-composition sensitivity contrast, not an Mpos/Mneg contrast and not independent biological replication.
5. `R5_SA266A_FLS_SA277A_Mneg` versus `R5_SA266A_FLS_SA277A_Mpos` (1144 versus 1060 cells; donor set SA266A, SA277A).

The actual positive sample for donor SA278R is `R5_SA263R_FLS_SA278R_Mpos` (none treatment, MerTK/CD206-positive condition, donor set SA263R, SA278R, 455 cells); it is not substituted into pair 4. Pairs 3 and 5 test whether a context signal survives changes in macrophage donor composition; pair 4 tests donor-composition dependence within the negative context.

## Baseline and substantive alternative

Baseline: for each feature instance, calculate Mpos-minus-Mneg on log(count + 1), with recorded `cells` as a prespecified offset or equivalent count model. Fit a regularized linear model with condition, cell-count offset, and complete contributing-donor-set indicators. Report pair-specific contrasts, donor-set indicators, and uncertainty.

Substantive alternative: fit a structured hierarchical model with a fixed context effect and random effects for the complete contributing-donor set (and FLS donor if estimable), preserving feature-instance identity and feature-level uncertainty. This alternative tests reproducibility across donor sets and decomposes donor-set/sampling dependence; the fixed-indicator baseline loses that decomposition.

The scientific deliverable is a newly fitted contrast/decomposition with uncertainty, a donor-set sensitivity report, and a feature-instance-level result table. No result is claimed here.

## Falsification and interpretation

Supportive: a stable context direction with uncertainty that survives donor-aware fitting, cell-count adjustment, and the stricter verified sensitivity subset. Results must be linked to computed outputs and uncertainty.

Adverse: the signal disappears after donor-set matching or cell-count adjustment, is driven by one donor set, reverses in the matched subset, or is not reproducible across the prespecified pairs.

Inconclusive: too few independent donor sets, unstable estimates, failed feature reconciliation, inability to separate context from treatment/batch, or insufficient information to fit the hierarchical alternative.

Neither supportive nor adverse results establish causality, mechanism, whole-tissue composition, effects on unmeasured genes, or clinical benefit. Those stronger claims require independent donor replication, complete batch/processing-order covariates, clinical adjudication of macrophage phenotype, and perturbation or another study.

## Missing evidence and limitations

The three-work inspected literature receipts and key-reference file remain incomplete at this checkpoint. The available evidence does not establish prior analysis of this exact contrast or novelty. The targeted assay does not measure absent genes. The design lacks complete batch/processing-order covariates and independent biological replication beyond recorded donor sets. The assay registry warns against ordinary donor t-tests because donors are reused and multiple donors contribute to samples.

## Method selection and resource estimate

The fixed-indicator baseline is selected as the primary computable check because it is transparent, uses exact available inputs, and directly tests the context contrast. The hierarchical alternative is retained because it answers the substantive donor-set reproducibility question. A neural or more complex predictive model is deferred: with 33 pseudobulk samples, reused donors, and no independent validation, added capacity would not resolve the primary donor-dependence uncertainty. Revisit it only with independent cohort or perturbation data.

Estimated future solver workload: CPU is sufficient for the 445-by-33 matrix and small linear/hierarchical fits; no GPU is scientifically required. This is a planning estimate, not an executed benchmark.
