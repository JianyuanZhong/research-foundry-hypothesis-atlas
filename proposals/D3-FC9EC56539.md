# E-MTAB-8873 repair note and provisional hypothesis

## Proposed relationship

In the prepared E-MTAB-8873 human RA synovial type B synovial cell (FLS) targeted assay, the context of MerTK/CD206-positive versus MerTK/CD206-negative macrophage coculture produces a reproducible, donor-aware change in the FLS transcript state that is not adequately explained by the recorded contributing-donor composition, cell count, or treatment. This is a provisional hypothesis; no expression contrast has been computed.

## Verified design and feature-map bindings

The frozen design is `[internal dataset path]` (33 records). The frozen matrix is `[internal dataset path]`, with 33 sample columns plus row key `feature`. The matrix columns exactly match the 33 design `sample_id` values in order.

The design fields are `sample_id`, `donor_id`, `donor_status`, `condition`, `treatment`, `cells`, `age`, `sex`, `tissue`, `cell_type`, and `source_metadata`. Every record has `donor_status=requires_contributing_donor_model`; all observed samples are adult female RA synovial membrane type B synovial cells. The condition counts are 13 Mpos, 11 Mneg, 6 not co-cultured, and 3 mixed Mpos/Mneg. Treatment is none for 23 samples, MerTK inhibitor for 5, and LPS for 5.

The 445 feature keys are unique. Four hundred forty-four have the form `symbol|transcript_id|assay_suffix`; suffixes are Reference_end (375), PolyA_1 (67), and PolyA_2 (2). One key is the bare symbol `TNFRSF11B`, so it must be retained as a distinct feature and not silently mapped to a transcript. Five symbols occur twice because of distinct assay/transcript instances (CD2, COL1A1, PGAM1, PRDM1, TNFAIP3); these must not be collapsed by symbol alone.

## Exact matched contrasts

The strongest primary contrast is the none-treatment Mpos versus Mneg comparison, using only samples whose condition is exactly `co-cultured with MerTK/CD206pos macrophages` or `co-cultured with MerTK/CD206neg macrophages` and whose treatment is exactly `none`. The design contains the following none-treatment context samples:

- R1: `R1_SA256A_FLS_SA259A_Mneg` versus `R1_SA256A_FLS_SA259A_Mpos` (donor string SA256A, SA259A; 491 versus 368 cells).
- R2: `R2_SA257A_FLS_SA266A_Mneg` versus `R2_SA257A_FLS_SA266A_Mpos` (donor string SA257A, SA266A; 396 versus 383 cells).
- R2: `R2_SA258R_FLS_SA266A_Mneg` versus `R2_SA258R_FLS_SA267R_Mpos` (donor strings SA258R, SA266A versus SA258R, SA267R, SA266A; 1469 versus 1207 cells).
- R5: `R5_SA263R_FLS_SA277A_Mneg` versus `R5_SA263R_FLS_SA278R_Mpos` (donor strings SA263R, SA277A versus SA263R, SA278R; 540 versus 455 cells).
- R5: `R5_SA266A_FLS_SA277A_Mneg` versus `R5_SA266A_FLS_SA277A_Mpos` (donor string SA266A, SA277A; 1144 versus 1060 cells).

These are not all perfectly matched at the individual-donor level: macrophage donor composition varies in the R2 and R5 pairs, and one donor string is malformed/ambiguous in the source (`R1_SA256A_FLS_SA260R_Mpos` has `donor_id=SA256A | SA256A, SA260R` and source metadata conflicts). Therefore the primary analysis must use the complete contributing-donor set as the unit, not pretend that each row is an independent donor. A stricter secondary analysis should retain only pairs with identical contributing-donor sets and the same FLS donor, and report how many contrasts remain; if none remain, the donor-specific claim is not identified and must be downgraded to a context-associated result.

The mixed Mpos/Mneg samples are not substitutes for pure Mpos/Mneg contrasts. LPS and MerTK-inhibitor samples are treatment-specific comparisons, not controls for the primary context contrast.

## Strongest rival explanations and executable test

The leading rival is sample construction: the observed difference may reflect the macrophage donor set, the number of contributing donors, or the recorded cell count rather than macrophage phenotype. A second rival is donor dependence: repeated samples share FLS and/or macrophage donors, so ordinary row-level inference can overstate precision. Treatment and batch/processing order are additional confounders; the available design does not expose a complete batch covariate, so this limitation must be reported rather than corrected away.

The executable next test is:

1. Parse the 33 design records and the 445-row matrix using the exact `sample_id` join and exact feature keys.
2. Restrict to the five none-treatment pure-context pairs above, normalize each feature by the recorded `cells` (or use a prespecified count model with `cells` as an offset), and calculate the Mpos-minus-Mneg contrast per pair.
3. Fit a simple donor-aware regularized linear baseline with contributing-donor-set indicators, cell-count offset, and condition, and compare it with a hierarchical model with random effects for the complete contributing-donor set and feature-level uncertainty. The alternative is scientifically substantive because it can distinguish a reproducible within-FLS context response from donor-set or sampling variation that the baseline loses.
4. Evaluate held-out donor-set generalization, paired contrast direction, feature-level uncertainty, and sensitivity to excluding the malformed/ambiguous donor row and to the stricter identical-donor-set subset. Report whether the result is stable across these analyses.
5. Falsification: supportive evidence is a reproducible contrast with stable direction and uncertainty across donor-aware fits and the sensitivity analyses; adverse evidence is disappearance under donor-set matching or cell-count adjustment, or a result driven by one donor set; inconclusive evidence is insufficient independent donor sets, unstable estimates, failed feature-map reconciliation, or inability to separate context from treatment/batch.

The assay can test only the 445 measured features and the recorded pseudobulk samples. It cannot establish a causal pathway, whole-tissue composition, effects on unmeasured genes, or clinical treatment benefit. Matched whole-tissue cell-abundance data and independent biological replication would be required for stronger mechanistic or clinical claims.

## Method comparison and deliverable

The baseline is a regularized linear contrast model using the exact recorded features, donor-set indicators, condition, and cell-count offset. The alternative is a donor-aware hierarchical model with random effects for the complete contributing-donor set and feature-level uncertainty. The alternative reveals whether the signal is reproducible across donor sets and whether uncertainty is driven by donor dependence, information the baseline loses. CPU is adequate for 33 samples and 445 features; no GPU is required. The deliverable is a newly fitted contrast/decomposition with uncertainty and sensitivity report, not a claimed mechanism or expression result.
