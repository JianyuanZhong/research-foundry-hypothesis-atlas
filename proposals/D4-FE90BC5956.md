## Audit findings requiring repair before any result

The script at `threshold_exec.py` ([source checksum]) is not certifiable as an independent audit implementation because:

1. `read_unique()` overwrites duplicate eids rather than aborting; assessment-stream duplicate eids are not checked.
2. Sequential exclusion accounting is incomplete: the repeat/date counter is unused, and distinct intersection, sex, date, age, analyte, positivity, and interval exclusions are not all reported.
3. Attendance diagnostics lack the required aggregate comparisons of target eGFR, baseline age, and sex between attenders and nonattenders.
4. No explicit complete/quasi-complete separation diagnostic is implemented.
5. Bootstrap p-values omit the predeclared finite-bootstrap plus-one convention unless independently confirmed from the compiled instructions.
6. There is no frozen two-direction simultaneous interval construction or exact Holm report.
7. The two directions use an implicit seed based on the first row's exposure rather than explicit direction labels.
8. The execution and audit are not independent implementations.

The parent support script is not a valid fallback: it has an exposure-specific attendance accounting bug (`z['R0' if exposure else 'R0'] += 1`), does not fit the frozen model or bootstrap, and points to an earlier workspace output path.
