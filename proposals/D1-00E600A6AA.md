# Provisional HCC trajectory hypothesis

## Hypothesis
Among HCC encounters in the HCC dataset, a time-stamped deterioration pattern in liver function, coagulation, renal function, or tumor-marker measurements during the first 7 days of admission will predict a subsequent clinically consequential deterioration event (inpatient death, ICU/escalation proxy, or a prespecified severe complication) better than a baseline laboratory snapshot and demographics, after accounting for treatment and documentation intensity.

This is a hypothesis, not an observed result. The exact outcome and cohort definition are pending a final schema/row audit.

## Evidence already inspected
- HCC README and metadata: 12 source files; joins are many-to-one from detail tables to encounters on 患者主索引 + 就诊号.
- Encounters source: HCC/data_基本信息_2500296761891079109.csv; table encounters; columns include 患者主索引, 就诊号, 年龄, 性别, 就诊时间, 入院时间, 出院时间, 就诊科室.
- Diagnoses source: HCC/data_诊断_7504718184492840569.csv; table diagnoses; columns 患者主索引, 就诊号, 诊断名称, 诊断类型. A scan found 1,810,646 diagnosis rows, including 346,290 rows whose 诊断名称 contains HCC-related terms; 肝细胞癌 is the most frequent exact match (336,570).
- Labs source: HCC/data_检验_609065997844652188.csv; table labs; columns 患者主索引, 就诊号, 检验, 定性结果, 定量结果, 标本类型, 检验时间. A scan found 28,159,928 lab rows and 1,810 test names. Relevant time-stamped tests include albumin, total bilirubin, INR, AFP, creatinine, ALT, AST, GGT, platelets and WBC.
- Procedures source: HCC/data_手术_8024330590283626027.csv; table procedures; columns 患者主索引, 就诊号, 手术, 开始时间, 结束时间, 手术来源.
- Medications source: HCC/data_用药_5693407050835159466.csv; table medications; columns include 患者主索引, 就诊号, 用药, 单次用药计量, 单次用药计量单位, 频次, 开始时间, 结束时间, 用药方式, 药品类型.
- Examinations source: HCC/data_检查_4203595081195465282.csv; table examinations; columns include 患者主索引, 就诊号, 检查, 检查所见, 检查诊断, 开始时间, 机器型号, 检查号.
- The metadata explicitly warns that lab numeric results have no separate unit column, so cross-assay pooling is unsupported; exact dates are local encounter dates and only within-participant intervals should be derived. Vitals, transfers, and front_page are identifier-only or nominal and cannot supply the proposed measurements.

## Prior-work context
[K1] Yang et al. (2026) reported that routine admission bilirubin, direct bilirubin, AST, and INR predicted day-7 total bilirubin in a small HBV cirrhosis cohort. This supports the clinical relevance of short-term laboratory response and motivates a snapshot comparator, but does not establish HCC prognosis or causal mechanisms.
[K2] Bui et al. (2026) reported that tumor stage, microvascular invasion, resection margin, and Child-Pugh status predicted postoperative disease-free survival in a retrospective HCC resection cohort, with modest discrimination. This bounds the claim that static tumor/liver factors are already important, but does not test early inpatient laboratory trajectories.
[K3] Millarch et al. (2026) reported that a temporal EHR model using ordered vitals, laboratory results, and medications predicted mortality across a nonlinear trauma trajectory and outperformed static severity scores. This motivates the sequence alternative, but is not HCC evidence and does not transfer automatically.

## Proposed computable experiment
1. Define the index cohort from encounters joined to diagnoses on 患者主索引 + 就诊号, requiring a prespecified HCC diagnosis and a valid 入院时间. Restrict to liver-tumor/肝胆 tumor departments only if this restriction is justified after inspecting diagnosis coverage; do not silently broaden to all diagnoses.
2. Set time zero to 入院时间. Use labs with 检验时间 from time zero through day 7, excluding post-discharge measurements. Parse 定量结果 only after unit/validity checks; retain missingness and specimen type.
3. Baseline model: prespecified logistic regression or penalized regression using demographics, admission department, baseline labs (first available values before day 7), and treatment/procedure indicators.
4. Alternative model: a patient-level sequence model or state-space model using ordered lab values, time since admission, missingness indicators, and treatment timing. It should test whether persistence/order/interaction of deterioration adds information lost by the snapshot baseline.
5. Outcome: define a clinically meaningful event before model fitting, preferably inpatient death or a documented severe complication/escalation. If no valid event field exists, use a transparent proxy only as exploratory and state that it cannot establish clinical harm.
6. Split by patient, never by row; use nested time-aware validation, calibration and uncertainty intervals. Compare baseline and sequence model on held-out data, with sensitivity analyses for documentation intensity, treatment, missingness, and department.
7. Falsification: the trajectory model is supportive only if it improves held-out discrimination/calibration beyond baseline with uncertainty excluding a prespecified trivial margin and remains directionally consistent in sensitivity analyses. A null or unstable result is adverse to incremental value; wide intervals, inadequate event support, or outcome ambiguity are inconclusive.

## Rival explanations and limits
Current severity, treatment intensity, admission selection, documentation intensity, delayed follow-up, and assay/unit heterogeneity may explain apparent trajectory value. Adjustment does not establish mechanism or causality. The dataset lacks verified lab units, images, waveforms, and complete external follow-up. Clinical adjudication is required for severe-event labels and treatment indication. No model has been fitted and no effect has been estimated.

## Method comparison
The snapshot regression is the simple, auditable baseline. The sequence/state-space alternative is scientifically substantive because it can reveal whether temporal persistence, ordering, or cross-marker interactions carry information that a single baseline loses. It is deferred until units, event support, and missingness are verified; a small CPU fit is appropriate for tabular baselines, while a GPU is not required unless the sequence model is selected.

## Missing evidence

- Valid outcome field and event ascertainment.
- Lab unit harmonization and assay validity.
- Complete row-level cohort counts, event support, and leakage audit.
