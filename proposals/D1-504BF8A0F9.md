## Question

Does the post-curative-treatment AFP trajectory (0–120 days) carry independent prognostic
information for 12-month HCC recurrence beyond baseline AFP and static risk factors,
after controlling for surveillance/testing-frequency artifacts?

## Why this matters

- Post-treatment AFP kinetics are used in practice to trigger early imaging and
  re-treatment. If the trajectory adds independent signal beyond baseline AFP, it
  justifies more targeted surveillance.
- If the apparent signal is driven by testing frequency (sicker patients get more
  labs), the practice is an artifact and should not be reinforced.
- The learned model test addresses a key unresolved question: is the confounding
  linear (logistic captures it) or nonlinear (only a tree-based model can separate
  true kinetics from intensity)?

## Interpretation

The AFP trajectory features (slope, time-to-normal, nadir) add substantial AUC beyond
baseline (ΔAUC ≈ +0.25–0.26), but this signal is almost entirely explained by the number
of AFP measurements and encounters (Model C). This holds for both logistic regression
and the learned HistGradientBoosting model. The learned model does NOT rescue a nonlinear
trajectory signal — ΔAUC B vs C is slightly negative (-0.005) for HGB.

This is a consequential clinical finding: the apparent prognostic value of AFP kinetics
is a **surveillance artifact**. Patients who are tested more frequently have more AFP
measurements, and the "trajectory" features are essentially proxies for testing intensity.

The sensitivity analysis (n_afp 3–8) confirms the same pattern: even in the mid-frequency
band where the parent candidate suggested a small residual signal, the trajectory adds
nothing beyond testing frequency (ΔAUC B vs C = -0.003 logistic, -0.002 HGB).

## Falsification

- Supportive: Model B AUC > Model C AUC by ≥0.02 with 95% CI excluding 0, in both
  logistic and HGB.
- Adverse: Model B AUC ≈ Model C AUC (ΔAUC < 0.01) in both models.
- **Observed: Adverse** — ΔAUC B vs C ≈ 0 in both logistic and HGB, in both main and
  sensitivity cohorts.

## Method alternatives

- Baseline: logistic regression with hand-crafted trajectory features (Model B).
- Learned: HistGradientBoostingClassifier (max_iter=200, max_depth=3, lr=0.1), 5-fold CV.
- Rationale: if the learned model substantially outperforms logistic on B vs C, the
  confounding is nonlinear and the logistic model may understate the trajectory signal.
  Observed: HGB B vs C ΔAUC = -0.005, confirming the linear model's finding.
- LightGBM was not available in this environment; HGB is the sklearn equivalent.
