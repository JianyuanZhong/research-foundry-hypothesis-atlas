# Donor-aware protective-versus-pathogenic target selectivity

Seed: D2-T2. Parent: [prior hypothesis].

## Question and clinical importance

Does an intervention-associated transcript pattern preferentially suppress a pathogenic fibroblast program while preserving a protective macrophage-linked state, such that a target ranked from an averaged signal is misleading? This matters because macrophage and fibroblast programs can have opposing roles in fibrotic or inflammatory disease: an intervention-associated change in one compartment may reflect a protective response, a pathogenic program, or simply differential cell composition and stimulation. Resolving the question would change whether a target is pursued as context-specific, requires a cell-type-resolved intervention, or is deprioritized.

## Hypothesis

An intervention-associated transcript pattern preferentially suppresses a pathogenic fibroblast program while preserving a protective macrophage-linked state, such that a target ranked from an averaged signal is misleading.

## Falsifiable test

Fit a donor-aware linear mixed model with donor random effects and condition fixed effects on the four configured sources. Compare the selectivity contrast (fibroblast program reduction versus macrophage-linked state preservation) against a negative-control gene set and a stimulation control. Support requires a positive selectivity contrast with donor-aware uncertainty excluding no selectivity and no comparable signal in the negative-control set. Adverse results show no selectivity or a signal only in controls. Inconclusive results arise from insufficient donors, unstable variance, or unresolved donor mapping.

## Competing explanations

1. The observed pattern reflects donor composition rather than a biological selectivity.
2. The observed pattern reflects a stimulation artifact rather than an intervention-specific response.
3. The observed pattern reflects a technical artifact (batch, library preparation, or normalization).
4. The observed pattern is a genuine protective-versus-pathogenic selectivity.

## Method comparison

A donor-pooled differential-expression analysis is simpler but loses donor-level uncertainty and cannot test whether selectivity persists across donors. A neural sequence model is not justified because the data are tabular counts with limited donors and the scientific question is a bounded selectivity estimand. A wet-lab perturbation would test direct target action but is unavailable in this campaign. The donor-aware linear mixed model is the most appropriate method for this question.
