## Frozen temporal and population rules

For each inherited selected admission i, let `D_i=admissions.dischtime`, `m_i` be sealed in `{3,6,12}`, and define the parent-identical calendar function, not elapsed-day arithmetic:

`calendar_add(D,m) = datetime(year(D)+(month(D)-1+m)//12, ((month(D)-1+m)%12)+1, min(day(D), days_in_that_result_month), D.hour, D.minute, D.second, D.microsecond)`.

If timezone metadata exists, preserve it; otherwise use the source naive timestamp. Thus 31-Jan + 1 month is the last day of February, and month-end behavior is deterministic. `T_i=calendar_add(D_i,m_i)`. All intervals use half-open source-time instants `[start,end)`; equality at start is included and equality at end is excluded. Calendar addition is used only for month offsets; `+30d` and `+180d` mean exact timedeltas of 30 and 180 days, respectively. A date-only `patients.dod` is normalized to `00:00:00` in the source-naive time convention. This function and convention must be unit-tested against the inherited parent fixture before any source text is opened; mismatch is `ANCHOR_NOT_RUN`.

Define due `Wdue=[T,T+30d)`, pre placebo `Wpre=[T-60d,T-30d)`, and post placebo `Wpost=[T+180d,T+210d)`. The post placebo has a structural eligibility flag: it is eligible only if the source snapshot can observe the whole interval under the rule below; otherwise it is `STRUCTURALLY_UNAVAILABLE`, excluded from the post contrast denominator (not coded zero), and its paired due value remains reportable. Define horizon `H=[D,T+30d)` only for opportunity reporting. Reports with `charttime<=D` are excluded from all post-D outcomes regardless of `storetime`; a report with charttime in a window is eligible even if stored later, while availability lag is separately reported using storetime.

Define subject last-observable time `C_i` as the maximum of all nonmissing `admissions.dischtime`, `admissions.deathtime`, normalized `patients.dod`, `radiology.charttime`, and `radiology.storetime` for that subject in the snapshot. A window `[a,b)` is fully observable iff `C_i>=b` or a recorded death time `d_i` exists with `a<=d_i<b`; otherwise it is right-censored at `C_i` if `C_i<b`. For the due window, retain every selected admission and code `RIGHT_CENSORED_DUE=1` when not fully observable; no unobserved value is imputed. For Wpre, use the same rule. For Wpost, mark `STRUCTURALLY_UNAVAILABLE` when not fully observable at the frozen index, before reading any outcome. Death before `a` is `DEATH_BEFORE_WINDOW`; death in `[a,b)` is `DEATH_IN_WINDOW`; death does not turn missing documentation into a negative. The due and pre denominators are all selected admissions, with states `observed`, `M0`, `K_U`, `DEATH_BEFORE_WINDOW`, `DEATH_IN_WINDOW`, or `RIGHT_CENSORED`; Wpost denominator is eligible pairs only, with unavailable count reported.

## Report identity, addenda, and labels

Include every radiology `note_type`, including addenda. Sort a report by `(charttime null-last, storetime null-last, note_id)`; null charttime cannot enter a time window. Deduplicate only exact `(subject_id,note_id)` identity. If duplicate physical rows share that key, retain one deterministic row after sorting by nonmissingness, then lexicographically smallest serialized values; record duplicate count. Do not deduplicate by text, hadm_id, note_seq, or addendum relation: each distinct note identity is a candidate document, while admission endpoint is `any`, so addenda cannot multiply a patient-level event. If an addendum explicitly references an earlier report, it remains separate and may support linkage; contradictory addendum evidence yields `K_U` for that window, not an analyst tie-break. Detail rows are ordered by numeric `field_ordinal` (ties by serialized field name/value) and concatenated only for reader display. A report is in a window iff its nonmissing charttime satisfies the half-open bounds and subject_id equals the index subject.

Two independent blinded readers adjudicate every packet containing at least one eligible report, with route, target order, phase-2 route labels, parent endpoint, and window identity masked. The codebook is frozen before real packets. `L=1` requires explicit support that the same pulmonary nodule/indeterminate focal opacity or its interval follow-up/comparison is the subject of a report; `L=0` means sufficient text, no such target link; `K_U` means insufficient, contradictory, unavailable text, or unresolved reader judgment. No report is `L=0` merely because none was found: no report is `M0`. The reader records note_id and exact evidence span. `P=1` is a clearly pulmonary/chest report or lung/chest anatomical reference, independent of target link. `N=1` is a clearly nonpulmonary/nonchest focus with no target-linked pulmonary statement; unclear anatomy is `K_U`. A packet-level positive is `any` report supporting the label; disagreement between readers is `K_U` unless both independently support the same label. Agreement and a blinded duplicate reread subset are reported.

## Additive workload ledger and executable stop rule

The inherited protocol has a ceiling, not an automatic charge. Before allocation, compute and freeze the parent worst-case charge from the inherited allocation and fixtures as `H_parent = H_parent_fixed + H_parent_variable + H_parent_controls + H_parent_qualification + H_parent_meetings + H_parent_access + H_parent_redaction + H_parent_reserve` and `R_parent = R_parent_roles + R_parent_adjudication + R_parent_reread`; these are charged at worst case even if realized work is smaller. The ancillary layer has no independent allowance. Its additive worst-case ledger is

`H_total = H_parent + H_anchor_fixed + H_anchor_variable + H_anchor_controls + H_anchor_qualification + H_anchor_meetings + H_anchor_access + H_anchor_redaction + H_anchor_reserve`;
`R_total = R_parent + R_anchor`.

Commit only if `H_total<=1,400 physician-hours`, `R_total<=96 reviewer-hours`, every week `H_parent,w+H_anchor,w<=6 physician-hours/week`, and all inherited roster/disjoint-role and 32-week constraints pass. If the computed parent charge already exhausts either ceiling, or if no integer allocation satisfies the additive ledger, return `ANCHOR_NOT_RUN` and preserve parent results; do not relabel the ceiling as available ancillary capacity. Each term is a declared nonnegative number from the frozen synthetic rehearsal: fixed qualification/packet setup, per-report reader minutes multiplied by the maximum number of reports in every selected packet, adjudication/re-read minutes, controls, redaction audit, meetings, access audit, and 15% variable reserve. `H_anchor_variable` is a sum over selected admissions and all eligible reports (including addenda), using the maximum observed packet count, not a mean. `R_anchor` is all anchor physician/reviewer role time, including both readers, adjudication, and reread; no person/role may overlap a parent C/S task. The ledger must publish each component, residual capacity `1,400-H_parent` and `96-R_parent`, weekly component totals, roster IDs/role-disjointness attestations, and the integer allocation proof. No hidden or donated time, post hoc workload averaging, replacement, or reduction of parent coverage is allowed.

## Estimands, controls, and interpretation

For due and each eligible placebo window, define `Y^L_{iw}=1` iff both readers support L=1; all other observed packets are not positive, while M0/K_U/censor/death remain separately tabulated and never silently collapsed. The primary estimand is the inherited design-weighted finite-population proportion of recorded target-linked documentation, with HT total and Hájek ratio, path weight `1/(pi1_i q_i)`, known target-cell denominator, and raw state counts. Paired contrasts use only admissions with both windows fully observable and non-K_U adjudication for the pair: `Delta_pre=P_w(Ydue=1-Ypre=1)` and `Delta_post=P_w(Ydue=1-Ypost=1)`, with the paired denominator and its exclusion/state counts explicitly reported. This complete-pair contrast is secondary; the primary denominator remains all selected admissions with unknown/censoring states displayed. For N, define `Y^N_{iw}=1` iff at least one adjudicated report is N and no report in the packet is L=1; its due specificity denominator is all due-window admissions with at least one fully adjudicable report (L/N/K_U states shown), not all admissions. Report `P_w(Y^N=1)`, `P_w(Y^L=1)`, and `P_w(Y^L=1 | report observed)`; never compare N to L using different hidden exclusions. P is a document opportunity control, also among report-observed due packets. A prespecified nonpulmonary specificity contrast is L prevalence minus N prevalence in the common report-observed, fully adjudicable due denominator; if no such denominator exists, it is undefined and the anchor is inconclusive.

Use inherited sequential HT/Hájek machinery, joint inclusion probabilities, and at least 20,000 nested Rao-Wu replicates preserving first-stage PSUs, phase-1 bands, phase-2 subcells, censuses, and frozen allocation. One simultaneous 95% max-statistic family covers parent gates/endpoints, theta_due, Delta_pre, Delta_post, missingness/censoring/death, L-vs-N, P, agreement, and workload. No complete-case estimate replaces the primary estimator.

Supportive means parent gates pass, additive ledger/roster passes, all windows and denominators are defined, controls and blinded adjudication pass, and preregistered simultaneous bounds show due temporal concentration and greater L than N. This supports only a MIMIC-observable documentation anchor warranting a separately approved prospective silent bridge. Adverse means adequate common report opportunity and controls exist but temporal concentration or specificity fails, or linkage is contradicted; downgrade bridge priority without claiming unsafe care or noncompletion. Inconclusive means `ANCHOR_NOT_RUN`, undefined post denominator, sparse target, high censoring/death/M0/K_U, low P, disagreement, or failed workload/roster; preserve the parent result and obtain actual workflow logs or a better linked dataset. No result is a completion or causal claim.
