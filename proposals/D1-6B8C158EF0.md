# Discharge recovery and procedure-associated versus non-procedure return after TACE in HCC

## Status, unresolved claim, and hypothesis

This is an episode-6 substantive successor to `[prior hypothesis]`. It is an observational prognostic study, not a treatment-effect, discharge-policy, or clinical-utility study.

The strongest claim supported by the inspected evidence is that hepatic reserve and post-locoregional-treatment complications are clinically relevant in other HCC cohorts. In the frozen full-text evidence actually inspected, Sanai et al. (Scientific Reports 2026, DOI `10.1038/s41598-026-54466-4`, PMCID `PMC13457603`, source ID `[source checksum]`) studied TACE/TARE at four tertiary centers and used ascites, variceal bleeding, or portosystemic encephalopathy as a decompensation definition. That supports plausibility, not the incremental value of routine time-ordered laboratory recovery in this HCC snapshot.

The unresolved primary claim remains:

> Among adults with HCC who have a first observed TACE episode and are discharged, does the early within-person change in liver/injury laboratory measurements add reproducible held-out information about a subsequent inpatient admission within 30 days beyond baseline reserve, prior utilization, demographics, and recorded disease history?

The episode-6 nested claim is:

> Among patients with at least 96 hours from observed TACE start to discharge and complete core laboratory windows, does discharge-proximal non-recovery add information about a 0–7-day subsequent inpatient encounter that has no TACE-class procedure documented during that return encounter, beyond baseline and early measurements? Is its incremental association larger for this non-procedure return proxy than for a return encounter containing a TACE-class procedure?

The distinction matters clinically: a discharge signal that predicts an acute-looking, non-procedure return would motivate prospective follow-up and adjudication; a signal confined to returns containing a TACE-class procedure may mainly reflect procedural scheduling or treatment pathway. The source cannot encode scheduling intent, so “non-procedure return” is an operational proxy, never “unplanned readmission.” A positive result cannot justify delaying discharge or changing TACE. A null result would caution against using routine laboratory trajectories as a stand-alone escalation rule. The substantive advance over the parent is a prespecified, transparent test of whether the discharge signal survives a clinically important utilization ambiguity, rather than a more complex model.

## Operational outcomes and procedure decomposition

The primary outcome is any subsequent inpatient admission within 30 days from `encounters`. The nested primary outcome is the first subsequent inpatient encounter in days 0–7.

For each first 0–7-day return, create a blinded, operational decomposition using the already frozen procedure dictionary and only procedure rows whose `患者主索引` and `就诊号` match the return encounter and whose `开始时间` is between return `入院时间` and `出院时间` (or, if discharge is missing, do not classify it as a confirmed procedure-associated return). Define:

- procedure-associated return proxy: at least one TACE-class procedure in that return encounter;
- non-procedure return proxy: no TACE-class procedure in that return encounter.

The latter does not mean unplanned, acute, or clinically severe. Report the number of returns with missing/inconsistent procedure times separately and do not force them into either class. Report all-cause, non-procedure, and procedure-associated outcomes separately; a subsequent return can be counted once in the mutually exclusive decomposition. The secondary liver-coded signal is any diagnosis on the return encounter containing one of `腹水`/`腹腔积液`, `肝性脑病`/`肝昏迷`, `食管胃底静脉曲张`, or `消化道出血`; report components separately and call it a code signal, not adjudicated decompensation.

## Models, baselines, and estimands

The broad primary estimand compares a baseline-only model with a trajectory model for any 30-day return. Baseline covariates are age, sex, index department, three baseline core medians, preceding-365-day encounter count, and prior recorded indicators for cirrhosis, portal-vein thrombosis, ascites, diabetes, and liver surgery, generated only from date-aligned encounters/diagnoses/procedures. These are recorded-code/utilization markers, not adjudicated disease.

Use patient-level five-fold cross-validation within discovery buckets 0–79 and a chronological split (2010–2022 derivation; 2023–2025-12-02 test), with all filtering decisions that use labels, imputation, scaling, and tuning confined to training data. Compare logistic baseline versus baseline+early changes as the primary analysis; a bounded elastic-net and shallow gradient-boosted model may be secondary model-form checks on identical blocks. Report out-of-fold Brier, AUROC/AUPRC, calibration intercept/slope, IQR-scaled adjusted odds ratios, risk differences at prespecified covariate patterns, global likelihood-ratio comparison, and patient-bootstrap intervals. No GPU is needed.

The nested estimand compares D0 (baseline plus early values/changes) with D1 (D0 plus discharge-minus-early core changes) for the first 0–7-day return, then repeats the same comparison for the non-procedure return proxy and procedure-associated proxy. Do not adjust the primary nested models for length of stay, post-index medications/orders, or later labs; use length of stay and pre-discharge observation density only in sensitivity/descriptive analyses because they can mediate recovery or leak discharge information. Require at least 20 events before inferential modeling of any primary outcome/stratum; otherwise publish counts and treat that stratum’s effect/interaction as inconclusive. The liver-coded endpoint additionally requires 20 events and otherwise remains descriptive.

The key contrast is the incremental D1 contribution for the non-procedure proxy versus the procedure-associated proxy, estimated with a prespecified interaction/heterogeneity test only when both strata pass the event gate. Do not interpret a wider or narrower coefficient as clinical effect modification if event counts are inadequate.

Prespecified robustness checks: complete-case versus missingness-indicator and inverse-observation-weighting sensitivity; minimum observations/maximum gaps; exact-label and procedure-source sensitivity; calendar/department selection tables; duplicate-key assertions; index-department and duration strata; timestamp shuffle/reversal within participant; a pre-index placebo trajectory; and a negative temporal-control audit proving no post-discharge lab/order rows enter features. The 30-day broad analysis remains primary if the nested decomposition is sparse.

## Falsification and interpretation

Support the broad early-trajectory hypothesis only if its block has global LR p<0.05, optimism-corrected out-of-fold Brier improvement with a 95% bootstrap interval excluding zero, no reversal in the chronological split, and no dependence solely on high-capacity models, dense recording, or timestamp order. Otherwise call it adverse/falsified when the apparent gain is absent or disappears/reverses under held-out, chronological, density/gap, or timestamp-shuffle checks; an in-sample AUROC gain with worse held-out calibration/Brier is adverse, not supportive.

Support the nested discharge hypothesis only if D1 improves held-out Brier over D0 for the 0–7-day all-cause outcome, passes the event gate, remains directionally/calibrationally stable chronologically and under density controls, and the non-procedure proxy shows the prespecified incremental evidence. If D1 supports all-cause but not the non-procedure proxy, retain only a coded all-return prognostic claim; do not claim acute vulnerability. If it supports the non-procedure proxy but not procedure-associated returns, that is consistent with—but does not prove—less dependence on documented procedural utilization. A significant heterogeneity test without stable held-out performance is not supportive.

Call results inconclusive if the dictionary or assay semantics cannot be reproduced, procedure-time classification fails, missingness/selection is strongly calendar- or department-dependent, any stratum fails its event gate, or intervals are too wide to distinguish no incremental information from a clinically meaningful gain. Supportive computation motivates a prospective cohort with adjudicated decompensation, reliable scheduling/intent, outpatient capture, stage and treatment details, and a predefined follow-up intervention. Adverse results caution against using the trajectory as a stand-alone escalation rule. Neither result establishes unplannedness, causality, treatment benefit/harm, safe discharge, mortality, tumor response, recurrence, transportability, or clinical utility.
