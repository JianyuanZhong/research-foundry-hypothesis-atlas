# Provisional hypothesis: context-specific MerTK-inhibitor response in E-MTAB-8873

## Status

Provisional draft for episode 8. This is not an executed result, a selected candidate, or a claim of clinical benefit.

## Proposed relationship

In the available E-MTAB-8873 RA macrophage–fibroblast assay, a MerTK-inhibitor-associated transcriptional response will differ by the macrophage context (MerTK/CD206-positive versus MerTK/CD206-negative macrophages). The primary estimand is a donor-aware, condition-verified context-by-inhibitor interaction, not a generic mean-expression change. A secondary descriptive question is whether the interaction separates a fibroblast-linked harmful program from a macrophage-linked resolving/protective program.

## What is known versus unresolved

The dataset catalog and domain guide establish that E-MTAB-8873 is a targeted assay with 33 recorded samples and 445 measured feature columns, with sample_id, donor_id, condition, treatment, age, sex, tissue, cell_type, and contributing-donor information in the prepared design. The design contains repeated and mixed/reused donor identities, so samples are not independent clinical replicates. The exact source files and hashes are recorded in datasets/therapeutic_targets/README.md and binding-template.json.

The strongest currently supported claim is therefore only that this assay can measure intervention-associated expression patterns under defined macrophage-coculture conditions while preserving the documented dependence structure. The unresolved claim is whether the inhibitor-associated pattern is context-specific after accounting for donor, condition, timing, composition, and measurement artifacts. No dataset-specific effect has been computed in this episode.

The available evidence does not establish that UNC106238 acts directly on MerTK, that the response is causal, that a “protective” program is preserved, or that any in-vitro pattern transfers to patients. Those claims require perturbation/mechanistic evidence, clinical adjudication, and independent validation.

## Falsifiable test

1. Audit the exact E-MTAB-8873 counts/design files and retain only contrasts with verified inhibitor, control, macrophage-context, and temporal labels.
2. Define macrophage-linked and fibroblast-linked programs from the 445 measured features without using unmeasured genes; retain source feature identifiers.
3. Fit a donor-aware additive baseline and compare it with a substantive context-by-inhibitor interaction model, using donor-clustered/permutation uncertainty or another dependence-aware method.
4. Treat a reproducible interaction with the prespecified direction as supportive; a null or reversed interaction as adverse to context specificity; unstable contrasts, missing controls, insufficient independent donor information, or feature-definition ambiguity as inconclusive.

## Method alternatives

The simple baseline is a donor-aware additive model for condition, treatment, and measured program expression. The substantive alternative adds the interaction and tests whether the inhibitor changes the macrophage-context contrast. This alternative can reveal a context-specific response that the additive baseline averages away, while also exposing whether an apparent effect is merely donor or composition structure. CPU is adequate for the planned tabular interaction analysis; no GPU is required.
