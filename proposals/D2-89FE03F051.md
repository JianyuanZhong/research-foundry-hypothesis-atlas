# Protective versus pathogenic macrophage–fibroblast target selectivity

Seed: D2-T2. Parent: [prior hypothesis].

## Question and clinical importance

Does an intervention-associated transcript pattern reduce a pathogenic fibroblast program while preserving a protective macrophage-linked state, such that a target prioritized from an averaged signal would be misleading? This matters because macrophage and fibroblast programs can have opposing roles in fibrotic or inflammatory disease: an intervention-associated change in one compartment may reflect a protective response, a pathogenic program, or simply differential cell composition and stimulation. Resolving the question would change whether a target is pursued as context-specific, requires a cell-type-resolved intervention, or is deprioritized.

## Design

- Population: macrophage and fibroblast samples from the four configured sources, with donor and condition metadata.
- Temporal boundaries: intervention-associated conditions are defined by the available condition labels; no temporal ordering is assumed beyond the condition labels.
- Variables: transcript counts, donor ID, condition label, cell-type context (macrophage vs fibroblast), stimulation control.
- Outcomes: protective macrophage-linked state (defined a priori from the available transcript signatures) and pathogenic fibroblast program (defined a priori from the available transcript signatures).
- Baselines: a simple pooled differential-expression ranking; a donor-aware linear mixed model with donor random effects and condition fixed effects.
- Analysis: donor-aware linear mixed model testing the interaction between intervention and cell-type context for the protective macrophage-linked state and the pathogenic fibroblast program, with adjustment for donor and stimulation controls. A negative-control gene set is used to test whether the pattern is specific to the proposed protective/pathogenic states.
- Falsification: failure to observe the interaction, or a pattern explained by composition/stimulation controls, would falsify the hypothesis.

## Competing explanations

1. The observed pattern reflects differential cell composition rather than a specific intervention effect.
2. The observed pattern reflects stimulation or donor-specific variation rather than a specific intervention effect.
3. The observed pattern is a consequence of the targeted assay design rather than a biological effect.

## Method comparison

A simple pooled differential-expression ranking is a transparent baseline but loses donor-level uncertainty and can be dominated by composition/stimulation artifacts. A learned multi-task model could capture nonlinear context dependence, but with only four small transcriptomic sources it risks overfitting and does not add a clear mechanistic test; it is deferred unless the donor-aware linear mixed model shows strong context-specific signal. A single-condition perturbation analysis would test causality but is unavailable in the configured datasets.

## Outcomes

- Supportive: the donor-aware linear mixed model shows a significant interaction between intervention and cell-type context for the protective macrophage-linked state and the pathogenic fibroblast program, with the interaction surviving adjustment for donor and stimulation controls. The negative-control gene set does not show the same pattern.
- Adverse: the interaction is not observed, or the pattern is explained by composition/stimulation controls.
- Inconclusive: the interaction is observed but is not robust to donor and stimulation controls, or the negative-control gene set shows a similar pattern.

## Limitations

- The hypothesis is not yet supported by executed analysis; it requires a donor-aware linear mixed model over the four configured sources.
- The targeted assay design limits the ability to measure absent genes.
- The distinction between expression association and direct target action is preserved; the hypothesis does not claim direct target action.
- Wet-lab validation is unavailable in the configured datasets.
