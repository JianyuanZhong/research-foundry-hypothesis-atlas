# Early post-TACE lab trajectories versus care-process and intensity rivals for 90-day non-TACE hospitalization

## Unresolved question

Among patients with hepatocellular carcinoma (HCC) undergoing their first recorded transarterial chemoembolization (TACE), it is unresolved whether **within-admission routine laboratory trajectories** carry prognostic information for **90-day non-TACE hospitalization** beyond:

1. a strong static pre-TACE baseline,
2. the latest pre-discharge levels of the same laboratory tests,
3. index length of stay and lab-order density/timing,
4. observed TACE treatment-intensity proxies.

The scientific question is not whether trajectory is statistically associated with readmission, but whether it adds **discrimination, calibration, and decision utility** after these more mundane EHR-process explanations have been removed.

## Clinical importance

A reproducible early-trajectory signal could help time discharge, prioritize closer post-TACE follow-up, and identify patients whose deterioration begins before clinical instability is obvious. Conversely, a null result would suggest that routine within-admission lab changes do not justify additional follow-up intensity beyond static liver reserve, latest levels, and care-process factors. This is a **prognostic information question**, not a claim that TACE causes readmission.

## Key references

- **[K1] Kohla et al. 2015** prospectively studied 102 Child-Pugh A patients after TACE. Post-TACE INR, bilirubin, ALT, AST, and albumin changed, but baseline tumor size, AFP, and albumin predicted one-month decompensation. This supports the clinical relevance of post-TACE lab changes but does not establish their incremental value for near-term hospitalization.
- **[K2] Han et al. 2020** showed that post-TACE response added prognostic information to baseline factors for overall survival in a large multicenter TACE cohort. This motivates testing whether earlier, routinely available post-treatment information improves prediction, but its endpoint is survival, not hospitalization.
- **[K3] Farinati et al. 2016** established and validated the albumin-bilirubin (ALBI) system, providing a strong static liver-function benchmark. The child design therefore requires trajectories to improve on a baseline that already contains static liver-function and tumor-risk information.

These works frame the unresolved increment. They do not establish that within-admission trajectories predict short-term readmission, and none directly tests the care-process or treatment-intensity rivals addressed here.

## Predictor windows

Use `labs` joined by `患者主索引` + `就诊号` and ordered by `检验时间`.

- **Pre-TACE window**: earliest available result from `入院时间` to 72 hours before index `开始时间`.
- **Post-TACE window**: all results from index `开始时间` through `出院时间`; the latest value before discharge is used for level features.
- **Core assays**: `总胆红素`, `白蛋白`, `肌酐`, `国际标准化比值`, `血小板计数`, `丙氨酸氨基转移酶`, `甲胎蛋白`, `活化部分凝血活酶时间`.
- Cross-assay pooling is prohibited because the lab table has no unit column; each assay is a separate exact-named feature.

## Nested model comparisons

The primary endpoint is **first non-TACE hospitalization within 90 days after index discharge**. Use the earliest qualifying admission date from later `encounters` rows. Exclude admissions whose `就诊号` has any TACE procedure row from the outcome search. Scheduled TACE admissions are ignored as events but do not otherwise alter the 90-day risk window.

Fit three nested logistic models, with the same patient-level temporal split:

1. **M0 — static baseline**
   - age, sex, index year, department;
   - pre-TACE levels of the eight core assays;
   - prespecified diagnosis flags for cirrhosis, hepatitis B, portal hypertension, ascites, and varices from the index encounter.

2. **M1 — latest-value, LOS, and ordering model**
   - M0 plus the latest pre-discharge value of each core assay;
   - index length of stay (`出院时间` − `入院时间`);
   - post-TACE length of stay (`出院时间` − index `开始时间`);
   - lab-order density/timing: total post-TACE lab results, distinct post-TACE lab timestamps, delay from TACE to first post-TACE lab, interval from latest lab to discharge, and missingness indicators for any core assay.

3. **M2 — trajectory model**
   - M1 plus assay-level trajectory features:
     - within-post last-minus-first change;
     - peak adverse excursion from pre-TACE value;
     - signed pre-to-post directional change;
     - explicit indicator for assays with only one post-TACE result.
   - Direction is prespecified as adverse for bilirubin, creatinine, INR, ALT, and APTT increase, and for albumin and platelet decrease. AFP direction is exploratory and not counted as adverse or protective.

This hierarchy directly tests the substantive increment: M1 captures current severity and care-process intensity, while M2 asks whether the **shape and direction of early post-TACE change** adds information beyond those rivals.

## Treatment-intensity sensitivity

Because the procedure table contains only the label `TACE`, timing, and source, it does not provide embolization extent, chemotherapy dose, tumor number, or selective versus lobar treatment. A definitive treatment-intensity model is therefore unavailable.

As a bounded sensitivity, refit M2 with observed intensity proxies from the index encounter:
- total procedure-row count between `入院时间` and `出院时间`;
- TACE-row count;
- non-TACE procedure-row count;
- interval from index TACE start to discharge;
- same-day non-TACE procedure indicator;
- total non-drug order count from `orders` within the index admission.

These proxies cannot exclude residual treatment-intensity confounding. A trajectory signal that survives them remains a **prognostic increment**, not proof of mechanism.

## Prespecified hepatic-decompensation secondary outcome

Define a secondary 90-day event as the first non-TACE admission whose `诊断名称` contains at least one prespecified decompensation term:

- `腹水` — ascites;
- `肝性脑病` — hepatic encephalopathy;
- `食管胃底静脉曲张破裂出血`, `上消化道出血`, or `消化道出血` — variceal or gastrointestinal bleeding;
- `黄疸` — jaundice;
- `肝肾综合征` — hepatorenal syndrome;
- `自发性腹膜炎` or `腹腔感染` — spontaneous bacterial peritonitis or abdominal infection.

This outcome is computed from readmission diagnoses only and is not clinically adjudicated. It tests whether any trajectory increment is concentrated in hepatic decompensation rather than nonspecific readmission. Because event counts may be small, it is secondary and may be inconclusive even when the primary endpoint is informative.

## Supportive, adverse, and inconclusive interpretations

- **Supportive**: M2 improves held-out discrimination and calibration over M1, with a likelihood-ratio test significant after correction for multiple trajectory families and a nontrivial decision-curve gain. This would support a prospective validation study of early post-TACE trajectories for risk stratification. It would not prove causality or biological mechanism.
- **Adverse**: M2 does not improve over M1 after adequate complete-case analysis. This would suggest that the apparent trajectory signal is largely explained by latest levels, length of stay, lab-order practice, or static risk.
- **Inconclusive**: wide confidence intervals, unstable calibration across time bins, or sparse secondary outcomes prevent a definitive conclusion.
- A significant association without calibration or decision-utility improvement is not sufficient to support clinical use.
- Improvement on the hepatic-decompensation secondary outcome would strengthen a physiology-oriented interpretation but still would not establish a causal pathway without adjudicated diagnoses or richer clinical detail.

Stronger conclusions require external validation, adjudicated unplanned-hospitalization status, mortality and out-of-system records, detailed TACE procedure data, imaging-based tumor burden, and prospective measurement of decompensation.

## Method exploration

- **Simple baseline**: M0 static pre-TACE model. It is transparent, fast, and clinically interpretable.
- **Substantive alternative**: M2 trajectory model using longitudinal assay shape. It directly tests whether dynamic physiology adds information beyond latest levels and care-process intensity.
- **Learned sequence model**: deferred. A neural sequence model could fit richer lab sequences, but the current scientific uncertainty is an explicit nested increment over strong rivals. Adding a complex learner would obscure attribution and inflate data demands without first showing that simple trajectories matter.
- **GPU choice**: unnecessary. The cohort is roughly 4,500 patients, the feature space is tabular and small, and nested logistic fits with bootstrap calibration are computationally light on CPU. GPU use would not improve the scientific question and would add avoidable operational cost.
- **Future revisit trigger**: if M2 shows a robust increment and richer sequence data become available, a regularized temporal learner could be evaluated as a secondary modeling study, not as a replacement for the primary nested test.
