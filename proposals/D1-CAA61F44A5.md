# Remote history beyond contemporaneous P: a minimal, compiler-ready HCC experiment

## Purpose and unresolved claim

The clinically relevant unresolved question is whether a leakage-safe remote same-assay history contributes reproducible prediction after the latest assay value available immediately before a recorded repeat TACE is known. The primary estimand is therefore the incremental out-of-fold prediction value of the remote anchor `B` beyond contemporaneous `P` and a minimal set of decision-time covariates. This is a prognostic prediction experiment for the next observed same-assay laboratory result, not a causal or treatment-effect study.

The strongest currently supported claim is availability and feasibility only. The direction-blind full scan supports the frozen pathway counts (319 systemic-record and 1,491 comparator patients), 159 and 526 first eligible repeat events, and complete triplets of albumin 40/118 and total bilirubin 41/119 (systemic/comparator). It does not support any direction, magnitude, clinical importance, toxicity, recovery, response, safety, treatment benefit, or decision utility.

The falsifiable hypothesis is: among selected patients with a complete triplet, adding `B` to a model containing `P` improves prediction of `Y` under a frozen, patient-level cross-fitting procedure. The result is interpreted only for this selected, observed episode population.

## Exact assay clocks and parser

Analyze exact labels `白蛋白` and `总胆红素` separately. Define:

- `B`: latest valid assay result on TACE2 calendar days −30 through −1.
- `P`: latest valid assay result in the selected repeat-event encounter during `[event−72 hours,event)`, strictly before event.
- `Y`: assay result in that encounter during `(event,event+72 hours]`, nearest nominal event+24 hours, earlier timestamp breaking an exact-distance tie.

A primary valid numeric result is a complete trimmed string matching a signed decimal/scientific number with an optional leading `<`, `>`, `≤`, or `≥`. Do not strip commas, accept trailing text, or coerce other formats. Preserve the inequality marker, specimen type, timestamp, and deterministic source order. Primary inference uses uncensored exact values only: rows with any inequality marker are excluded from the primary numeric candidate set, while parseable censored rows are counted separately in a parser audit and may be used only in a clearly labeled sensitivity. There is no laboratory-unit column; `标本类型` is not a unit.

For duplicate same-assay values at one timestamp, use the final source-order value only when numeric values agree; exclude discordant groups from the primary and report a concordant-only sensitivity. Audit seven known duplicate assay/timestamp groups, parsing attrition, missing clocks, ties, and selected event-to-panel hours. The expected complete-triplet audit targets are albumin 40/118 and bilirubin 41/119, with common-timestamp support 40/118; these are validation targets, not hard-coded assumptions.

## Leakage-safe history and locked models

For each complete triplet, `H` is the assay-specific observation history in `[TACE2,event−72 hours)`, excluding the selected P encounter and all observations at or after `P`. The primary history variable is only `B`. Do not include slopes, recency, department dummies, broad laboratory blocks, missing-history indicators, `P−B`, or `(P−B)/Δt` in the primary model. The direction-blind audit found remote observations in the locked window for 37/40 albumin systemic, 108/118 albumin comparator, 38/41 bilirubin systemic, and 108/119 bilirubin comparator cases; however, most have exactly one historical observation and only 18 per arm have at least two. Thus a slope/recency block is not supportable as a primary estimand. History count and `has_any_H` may be emitted descriptively and, only if requested by the Lead, as a secondary pre-registered sensitivity with no claim priority.

The compact primary covariate core, excluding the intercept, is exactly:

`P`, pathway arm, age, sex, TACE2-to-repeat interval in days, and event-minus-P lead time in hours.

This core is frozen before outcome fitting. It excludes variables whose definitions were ambiguous or whose dimensionality would be excessive in the systemic arm. `P` appears exactly once. No feature selection, baseline SMD screening, outcome-direction screening, or performance-based covariate choice is allowed.

Fit ordinary ridge linear regression separately by assay, with the same complete cases and frozen folds for every model. Standardize continuous predictors and impute only within the training fold. Use a fixed penalty grid `{0, 0.01, 0.1, 1, 10}` selected by inner leave-one-out MSE within each outer training fold; the intercept is unpenalized. If a training design is rank-deficient or preprocessing is not estimable, use the same model with the offending redundant column removed only under the pre-specified rank rule; if the six-column core itself is not estimable, the assay comparison is inconclusive. OLS with HC3 is a transparency sensitivity, not the estimand.

The primary nested comparison is:

```text
N0: Y ~ P + arm + age + sex + TACE2_to_repeat_days + P_lead_hours
N1: Y ~ P + B + arm + age + sex + TACE2_to_repeat_days + P_lead_hours
```

The old ordering `B` versus `B+P` is a secondary ordinary-persistence benchmark only. `P−B` is algebraically equivalent to adding `B` conditional on `P` and is not an independent discovery; no simultaneous B-plus-difference model is fitted.

## Folds, estimands, and uncertainty

For each assay, assign complete-triplet patients to five folds separately within arm by sorting a privacy-preserving SHA-256 hash of patient key, assay, repetition index, and fixed string, then round-robin. Freeze assignments before reading outcome values for model design. The primary assignment has systemic counts 8 per fold for albumin and 9,8,8,8,8 for bilirubin; comparator counts are 24,24,24,23,23. Use one primary assignment and 20 fixed hash repetitions as a partition-sensitivity analysis; never select a favorable repetition.

Each outer fold fits preprocessing, inner penalty selection, and coefficients only on training patients, then predicts held-out patients. Report pooled and fold-specific RMSE, MAE, standardized RMSE (`RMSE/SD(Y)`), standardized MAE, cross-fitted R-squared, prediction variance, calibration intercept and slope, sample counts by arm, outcome variance, and selected penalty. Define positive improvement as `ΔRMSE_std = RMSE_std(N0)−RMSE_std(N1)`; `ΔMAE_std` and `ΔR2` corroborate but cannot replace the primary metric.

Use 2,000 stratified patient-level bootstrap replicates of paired held-out predictions for the primary 95% interval, explicitly conditional on the fitted cross-fitting procedure. A 200-replicate full-pipeline refit bootstrap is a sensitivity if computationally feasible; it is not required to reinterpret the primary estimand. A result is uncertainty-unstable if fewer than 95% of bootstrap replicates are estimable. Require at least five held-out patients per arm per fold and nonzero held-out Y variance. These gates are feasible by count but must be checked computationally.

## Falsification and selection diagnostics

1. **History destruction.** Within each outer fold and arm, permute paired `(B,B_timestamp)` assignments among all patients in the analysis sample using 500 fixed permutations. Apply the same permutation to training and held-out rows before fitting/evaluating the placebo N1, leaving P, Y, and other covariates fixed. This destroys patient-history linkage without creating an inconsistent held-out definition. Compare the observed improvement with the placebo improvement distribution. This is a predictive randomization diagnostic, never a causal test.
2. **Pseudo-decision placebo.** Use only an additional strictly pre-event same-assay measurement in the event encounter, at least six hours before P and within 168 hours before the event, to define a pseudo-current/pseudo-next pair. Require 80 total and 20 systemic pseudo-triplets plus fold gates before interpreting it. The audit finds only 2 systemic and 4 comparator candidates for each assay, so this placebo is not estimable and must not block the generic remote-history analysis. Its non-estimability does prohibit any event-specific interpretation.
3. **Timing sensitivity.** Re-run the locked comparison under inherited latest-pre 24/48/72/168-hour, first-pre 72-hour, post +24/+48/first, calendar-day +1–3, and common-timestamp selectors. Count empirically distinct estimable variants only; nominally different selectors yielding identical rows are one variant, not multiple corroborations. No selector may be chosen by outcome direction.
4. **Influence and stability.** Report leave-one-patient-out changes, leverage, Cook's distance, and DFBETA for B in the OLS sensitivity. A conclusion that reverses after deletion of observations exceeding the pre-specified Cook `4/n` or DFBETA `2/sqrt(n)` threshold is inconclusive. Report the 20 fixed partition sensitivities without selecting a seed.
5. **Observation selection.** First report unweighted complete-triplet results. As a sensitivity, model repeat-event and assay-observation availability using only information available before the relevant observation, then report cross-fitted overlap/IP weights, arm-specific ESS, positivity, balance, coefficient of variation, maximum and concentration. Weighting cannot recover unobserved Y or remove collider bias. If weighted and unweighted conclusions materially conflict, label selection-sensitive.

## Deterministic branch precedence

Apply branches in this order, separately for each assay, before any prose interpretation:

1. **Reconstruction failure:** any mismatch in frozen cohort/event counts, parser/duplicate rules, clocks, joins, or audited triplet targets gives inconclusive and stops inference.
2. **Computational instability:** rank failure of the minimal core, fold support/variance failure, non-estimable bootstrap, or failed required preprocessing gives inconclusive.
3. **Selection sensitivity:** failed positivity/ESS/weight gates or material weighted-versus-unweighted conflict gives selection-sensitive/inconclusive; do not call this supportive even if the unweighted point estimate is favorable.
4. **Adverse degradation:** the primary 95% interval for `ΔRMSE_std` lies wholly below zero, or calibration materially worsens, gives adverse degradation.
5. **Supportive:** the primary point estimate is at least `δ=0.05`, its two-sided 95% interval excludes zero, `ΔMAE_std` and `ΔR2` are non-adverse, no influence/timing/history-destruction check contradicts it, and all estimability gates pass. `δ` is a design convention, not a clinical-benefit threshold.
6. **Precise null:** all computational gates pass and the upper 95% bound is below `δ` (whether or not the interval includes zero). This rules out only an improvement of at least 0.05 standardized RMSE under this selected sample and locked model; it is not equivalence or proof of no biological or clinical value.
7. **Ordinary persistence/no demonstrated remote increment:** if N0 is not improved by N1 but the secondary B-to-B+P ordering improves, or if history destruction is comparable, report that contemporaneous persistence explains the observed predictive signal and remote history is not demonstrated.
8. **Inconclusive:** all remaining cases, including broad intervals spanning degradation and `δ`, selector reversal, influence dependence, or non-estimable timing diagnostics.

A pseudo-placebo that is not estimable is reported as such and does not trigger branch 2; it blocks only event-specific claims. A single assay is assay-specific. A broader two-assay statement requires same-sign supportive branches for both assays with Holm-adjusted primary tests; no arm interaction or treatment-pathway claim is allowed.

## Limits and verifier obligations

The next observed laboratory result is an observation-process endpoint. The data lack validated units/reference ranges, imaging response or tumor burden, performance status, complete Child–Pugh context, repeat-TACE rationale/technical success/complications, transfusion or albumin/fluid balance, outside care, reliable mortality, and verified medication administration/adherence/dose. Conditioning on repeat TACE and complete measurement can induce selection/collider bias. No result can establish causality, toxicity, recovery, safety, benefit, treatment administration, mechanism, clinical utility, or that history should change a TACE decision.

A verifier can check source hashes and full-scan row counts, exact event and assay clocks, parser and censoring handling, duplicate resolution, joins, frozen folds, training-only preprocessing, model nesting, metrics, bootstrap arithmetic, placebo permutation consistency, timing variants, selection diagnostics, and branch precedence. It cannot adjudicate clinical importance, treatment rationale, actual administration, causal effects, or decision utility. Those claims require validated clinical outcomes, expert review, and prospective or external validation.
