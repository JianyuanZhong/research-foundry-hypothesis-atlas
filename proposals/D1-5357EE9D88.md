## 6. New accession-release frontier

This section is the only substantive addition.

For every reachable clean radiology unit u, introduce an operational release bit `r_u`. It is a hypothetical intervention on what the locked pipeline may read, not an imputed observation:

- `r_u=1`: the full source-eligible unit is exposed exactly as in the parent.
- `r_u=0`: preserve acquisition-only Z facts, but replace every report-derived `S,Q,X_clean` block from u by its development-defined operational-unavailable block in both `R_clean` and `G_clean`; apply the identical S/Q mask to `Gclean_mask`. B is unchanged.
- empty, corrupt, contaminated, nonreversible, or otherwise source-unavailable units remain unavailable regardless of r and are not counted as releasable.
- the same r is used across all model arms, contrasts, books, capacities, and paired undeleted/deleted computations. Reader interpretation of an exposed unit remains fixed by the selected corpus-wide book.

This whole-report mask intentionally differs from `Gclean_mask`: the latter removes semantics only while preserving the same visible nonsemantic report surface; r=0 removes everything that requires access to the report body. Thus `Delta_mask` under partial release still asks whether visible clean semantics matter within the locked full model, while `Delta_R` compares full versus nonsemantic use of exactly the same released reports.

Let `A_a(omega)` be all releasable clean accession units attached to eligible year-a patients in world omega. For `c in C`, where `C` is the sorted union of exact breakpoints `m/|A_a(omega)|` over both years/worlds plus 0 and 1, define admissible release patterns by
`sum_{u in A_a(omega)} r_u >= ceil(c |A_a(omega)|)`.
No distribution, independence, missing-at-random assumption, or equal state weight is used. Because the constraint is “at least,” feasible pattern sets are nested even if ranking changes nonmonotonically.

For each year-by-contrast coordinate e and c, compute exact attained undeleted and singleton-deleted lower/upper endpoints over the same source/pathology/book world and all release patterns satisfying the coverage constraint. After deletion, remove all of that patient's units and use `ceil(c |A_a(omega minus j)|)`; keep K fixed. A release frontier point is undefined, hence globally inconclusive, if any required world lacks K patients, exact optimization, or a complete releasable-unit ledger.

Define `c*` as the smallest breakpoint c such that all six undeleted lower endpoints and all six singleton lower endpoints are strictly greater than 5. Nested feasible sets make this the sharp sufficient release fraction within the declared finite world family. Report every attaining c* witness and the last failing breakpoint. If no breakpoint passes, c* is undefined. If the parent all-content state fails, no c* may be reported even if a partial pattern happens to perform better.

The operational hypothesis passes only if all parent confirmatory gates pass, c* exists, and c*<=.80. The .05/.20 K frontiers and 12/48/72-hour cutoffs are diagnostics and cannot rescue K_.10/24-hour failure. Compute CT-only and MRI-only release restrictions descriptively; neither rescues the joint primary.

A later external audit must use accession-level report version, authored/final/release time and preferably clinician-view time; reproduce the same cutoff, accession unit, releasable-quality denominator, and patient roster logic; and provide one-sided lower coverage bounds overall and by modality. Current HCC data contain none of these fields. Without that audit, “deployment-ready,” “historically available,” and “workflow-feasible” remain inconclusive even when c*<=.80.
