# Compiler-ready training-range partial-identification layer for missing Y

## Purpose and preserved scientific question

This is a targeted child of `[prior hypothesis]`. It preserves every frozen design choice: the HCC repeat-TACE complete-triplet reconstruction; exact B/P/event/Y clocks; event -> B -> P -> BP-eligible, outcome-blind support funnel; one selected event per patient; non-overlapping annual forward blocks; nested noncausal P-beyond-B prognostic RMSE estimand; and all executed denominator/clock/observation findings. It adds an executable, no-leakage partial-identification layer for the unresolved severe missing-Y problem. It does not replace, reweight, impute, or alter the primary complete-triplet estimand.

The falsifiable question is: for each fixed future block and assay, does the M1-versus-M0 predictive contrast retain its sign for every completion of missing post-repeat assay values in the pre-origin observed-Y range, and how far must a single transparent displacement of missing outcomes move to make the contrast zero? This is a mathematical sensitivity question about a prognostic prediction contrast, not a MAR, causal, treatment, utility, or clinical-truth claim.

## Executable partial-identification specification

For every assay and origin, create exactly one aggregate-analysis row per BP-eligible patient-assay episode containing a stable internal row key, arm, block, pre-Y features, `Y_observed`, fixed `p0`, fixed `p1`, and Y only in the private working table. Assert one row per patient-assay, and make released artifacts aggregate-only (no identifiers, raw Y, notes, or clinical free text).

Construct `L=min(Y_train)` and `U=max(Y_train)` from observed training complete-triplet Y values only, after the exact assay-specific parser and before reading any future Y. Require finite `L<U`. Independently test every observed future Y against `[L,U]`; if any is outside, mark that assay/origin `range_unsupported` and do not report finite bounds or a tipping point. Do not widen the range. A secondary full-source assay range may be calculated only as a clearly labelled non-temporal descriptive check, never for fitting or transport evidence.

Let `N` be all BP-eligible episodes in the block/origin, O observed-Y rows and M missing-Y rows. For each observed row calculate `d_i=(Y_i-p0_i)^2-(Y_i-p1_i)^2`. For each missing row and model j, use the sharp convex bounds

`lo_sse_j(i)=(clip(pj_i,L,U)-pj_i)^2`,
`hi_sse_j(i)=max((L-pj_i)^2,(U-pj_i)^2)`.

For the favorable contrast `C=MSE0-MSE1`, each missing-row contribution is the affine function
`d_i(y)=(y-p0_i)^2-(y-p1_i)^2 = (p1_i-p0_i)*(2y-p0_i-p1_i)`.
Thus calculate sharp `C_lo` and `C_hi` by adding observed d and, for each missing row, `min(d(L),d(U))` and `max(d(L),d(U))`, then divide by N. Also calculate model-specific MSE intervals and the induced RMSE-difference interval by evaluating the four endpoint combinations `(SSE0,SSE1)` consistent with the row-level endpoint choices; do not subtract unrelated independently optimized scalar intervals and call that sharp. Report all-BP-eligible bounds overall and separately by arm and annual block. The primary complete-triplet RMSE remains separately reported and unchanged.

### Deterministic tipping point

Define the locked common-displacement family relative to the observed-case training mean `mu_O=mean(Y_train observed)` as
`y_i(delta)=clip(mu_O+delta,L,U)` for every missing row; observed Y values remain fixed. This is a one-dimensional, explicitly artificial sensitivity path, not an imputation model. Define `C(delta)` by replacing each missing d with `d_i(y_i(delta))`. Search the closed domain `delta in [L-mu_O,U-mu_O]`. Because clipping makes C piecewise affine, find all breakpoints `L-mu_O` and `U-mu_O`, evaluate endpoints and the exact affine root in each interval (with tolerance `1e-12` in the contrast), and choose the root with smallest absolute `delta`; if multiple roots tie, choose smaller delta then the inherited deterministic ordering. Report signed delta, absolute displacement, common completed value (or clipped values), root existence, and whether zero lies in the endpoint interval. If no root exists, report `sign_robust_under_locked_common_displacement`; do not call that robustness over all arbitrary completions unless `[C_lo,C_hi]` also excludes zero. If `mu_O` is undefined or no missing rows exist, report `not_applicable`.

Additionally emit three locked mathematical completion rows: all missing Y=L; all missing Y=U; and per-episode least-favorable endpoint for M1 versus M0 (choose L or U that minimizes d_i for the adverse direction). These are bounds/scenarios, not plausible imputations. Report missing count/fraction, O/M/N, training range, observed-case contrast, C interval, endpoint scenario contrasts, tipping-point fields, and branch label for overall, each arm, and each calendar block. Use fixed training SD(Y) only as optional secondary scale; never use test SD with missing outcomes or relabel this as the primary standardized RMSE gain.

## Analysis contract, falsification, and interpretation

Supportive bounded robustness requires successful reconstruction, both outcome-blind and complete-triplet gates, adequate arm counts, prespecified favorable observed complete-triplet primary criterion, and `[C_lo,C_hi]` strictly favorable with no material arm-specific reversal. It supports only a short-horizon prognostic association under the stated training-range scenario in that selected calendar mixture.

Adverse means a supported locked observed contrast is nonpositive, repeated M1 degradation, or a bounded completion reverses sign. It challenges incremental prediction or shows selection sensitivity; it does not show B suffices, mechanism, harm, or treatment effect. If the observed contrast is favorable but `[C_lo,C_hi]` contains zero, label `selection_sensitive`/`inconclusive`, regardless of a favorable point estimate. Failed support, sparse arms, degenerate range, future Y outside training range, unidentified test SD, unstable numerics, or dependence on the non-temporal range is `inconclusive_unbounded`. A null is not equivalence.
