## Repair: formally indexed partial-identification layer

For each assay `a`, origin `o`, block `b`, and descriptive arm `g`, define the analysis universe `R_{aobg}` as every `BP_eligible` row in that block, including rows with missing Y. Let `n=|R|`, `O={i:Y_i observed}`, `M=R\O`, and freeze predictions `p0_i,p1_i` from the pre-origin fits for every row in `R`. The bound is computed only when there is at least one observed training Y and the temporal support status is supported.

Set assay-specific `L=min(Y_train)` and `U=max(Y_train)`, where `Y_train` is finite parsed Y from pre-origin complete triplets only. Construct `[L,U]` before reading any future Y. If `L==U`, or any observed future Y in the relevant block is outside `[L,U]`, set `support_status="unsupported"` and report no temporal bound. A full-source range, if computed, is descriptive only and cannot replace `[L,U]`. If no future Y is observed, retain the block as low-information and use the training mean solely as the tipping reference; do not manufacture a future mean.

For each observed row define `e0=(Y-p0)^2`, `e1=(Y-p1)^2`, `d=e0-e1`. For each missing row and model `j`, define

```text
e_j,min = (clip(p_j,L,U)-p_j)^2
e_j,max = max((L-p_j)^2,(U-p_j)^2)
```

For the improvement contrast use the exact affine function

```text
d_i(y) = (y-p0_i)^2 - (y-p1_i)^2
       = 2*y*(p1_i-p0_i) + p0_i^2-p1_i^2.
```

Thus `dmin_i=min(d_i(L),d_i(U))` and `dmax_i=max(d_i(L),d_i(U))`; no interior search is needed. Define explicitly, for each stratum and overall,

```text
Delta_lower = (sum_{i in O} d_i + sum_{i in M} dmin_i) / n
Delta_upper = (sum_{i in O} d_i + sum_{i in M} dmax_i) / n
MSEj_lower = (sum_{i in O} ej_i + sum_{i in M} ej,min) / n
MSEj_upper = (sum_{i in O} ej_i + sum_{i in M} ej,max) / n.
```

These are sharp bounds for the stated independent rectangular support scenario at MSE and SSE-contrast levels. Report `n`, observed/missing counts and fractions, and the assay/origin/block/arm index with every aggregate. A positive `Delta` means lower M1 squared error. Do not call `[sqrt(MSE0_lower)-sqrt(MSE1_upper), sqrt(MSE0_upper)-sqrt(MSE1_lower)]` a sharp RMSE-difference interval; if emitted, label it a conservative derived enclosure and never standardize it by an unidentified all-row test SD. The primary RMSE remains observed-complete-triplet only.

Use three deterministic audit scenarios: all missing Y set to L; all set to U; and each missing row set to the endpoint minimizing `d_i(y)` (the least favorable endpoint for M1 improvement). These are stress scenarios, not imputations or plausible clinical values. Check that endpoint scenario sums equal the formulas above and that observed rows remain unchanged.

### Corrected common-displacement tipping point

Let `m_ref` be the mean observed future Y in the same indexed block if any exists; otherwise use the pre-origin training-Y mean and set `reference_source="training"`. Define, for every missing row simultaneously, `y_i(delta)=clip(m_ref+delta,L,U)`. The resulting `Delta(delta)` is continuous piecewise affine, not quadratic. Build sorted breakpoints `{L-m_ref,U-m_ref}` plus the per-row clipping breakpoints implied by the common displacement, intersect with `[L-m_ref,U-m_ref]`, and evaluate each segment’s affine coefficients from the exact endpoint formulas. Find all roots in the closed interval by analytic linear solving, treating an identically zero segment as a zero-root segment; verify every reported root by direct recomputation. Report the root of smallest absolute displacement, breaking ties by smallest delta. If `Delta(0)==0`, report zero. If no root exists, report `sign_robust_common_displacement`; record whether `[Delta_lower,Delta_upper]` crosses zero. A tipping point is a mathematical sensitivity coordinate, not an estimate, probability, or clinical plausibility threshold.

Supportive results require reconstruction checks, adequate outcome-blind and complete-triplet arm gates, a prespecified positive primary result in an adequately supported block, no material ascertainment warning, and a positive all-risk-set `Delta` that does not cross zero under the declared support scenario. This supports only a selected short-horizon prognostic association in that calendar mixture.
