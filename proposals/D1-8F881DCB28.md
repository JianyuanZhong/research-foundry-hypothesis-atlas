## 1. Unresolved question and clinical importance

Discharging a patient alive from the ICU is a consequential, weakly standardised decision. The
adverse outcomes it is meant to prevent are **48 h unplanned ICU readmission** and **7-day
post-discharge death**. The parent established that a *decoupled* dynamic pre-discharge footprint
(fixed-cadence dispersion D1, per-patient standardised surprise D2, minus a value-free
monitoring-intensity block M-obs D3, with within-stay placebos D4) could in principle add held-out
discrimination beyond static severity and an explicit measurement block.

The parent's own assessment records the one *declared residual defect*: **the value-ordered / notes
care-escalation channel is not captured, so "genuine instability" vs "care-escalation common cause"
is not fully removed.** That is the unresolved claim this child attacks.

- **Leading claim (H1).** The footprint reflects loss of cardiorespiratory reserve, so its held-out
  increment should be **concentrated on cardiorespiratory readmissions** (respiratory failure, sepsis,
  heart failure, arrhythmia, shock) rather than spread uniformly over all readmission causes.
- **Strongest rival (H0).** The increment is a **generic monitoring / care-escalation practice
  artifact** ("sicker-and-watched-both"): patients charted more densely and re-admitted by habit, so
  the increment should be **non-specific** (≈ equal) across readmission categories.

These two explanations make *opposite* predictions about a single comparison that is computable from
already-bound MIMIC-IV tables. That is a genuinely discriminating test the parent does not contain.

**Key references (inspected, abstract-only).** A 48 h pre-ICU-discharge signal is learnable [K1]; but 31 AI
readmission models pool AUC ~0.82 with uniformly high risk of bias [K2], so a control-tested incremental
estimand is warranted rather than another performance claim. Most directly, on MIMIC-IV, associative
readmission models leaned on non-actionable frailty/administrative proxies [K3] - exactly the generic
measurement/practice artifact that H0 names, which [K3] describes but never tests for a dynamic
pre-discharge footprint or its outcome-category specificity.

## 2. Design (inherited, FIXED)

- **Population.** Adults (`hosp/patients.anchor_age >= 18`) discharged **alive** from their **first**
  ICU stay, ICU `los >= 1` day. Unit = ICU stay; key `(subject_id, hadm_id, stay_id)`.
- **Landmark.** `t0 =` `icu/icustays.outtime`; window `[t0 - 24h, t0)`; all features computed **only**
  from data at or before `t0` (no future leakage). Classification landmark `t0`, outcome observed
  after `t0`.
- **Outcomes (FIXED).** (a) 48 h **unplanned** ICU readmission = next `icu/icustays.intime` for the
  same `subject_id` within 48 h of `t0`; (b) 7-day post-discharge death = `hosp/patients.dod` within
  7 d of `hosp/admissions.dischtime`; composite = (a) OR (b).
- **Split.** Locked 70/30 **temporal** split, boundary `t0 = 2169-10-11 22:55:40`
  (dev 43,726 / held-out 18,740; events 2,964 / 1,521 / 4,267). Held-out is touched once.
- **Ladder (FIXED).** M0 static severity (age, admission_type, first-day SOFA-surrogate labs,
  Charlson/Elixhauser from `hosp/diagnoses_icd`) → M1 (+ level means only) → M2 (+ decoupled dynamics
  D1/D2), each with the M-obs control block. Paired ΔAUROC/ΔAUPRC, DeLong + 1000-bootstrap CIs.

## 3. NEW scientific addition — outcome-specificity negative control

**Specificity estimand.** On the held-out split, for the composite-relevant subset with an observed
readmission, classify each readmission's `hadm_id` by its **principal** diagnosis using
`hosp/diagnoses_icd` (`subject_id, hadm_id, seq_num, icd_code, icd_version`), joined to
`hosp/admissions` on `(subject_id, hadm_id)`:

- **CARDIORESP** block (ICD-10): chapter IX circulatory `I00-I99`; chapter X respiratory `J00-J99`;
  sepsis `A40*`, `A41*`; shock `R57*`; acute kidney injury `N17*` when co-coded with a
  cardiovascular principal (prespecified, reported as a sensitivity stratum).
- **NON-CARDIORESP**: all other principal codes.
- Tie-break: if principal code is absent/ill-defined, use the first non-`seq_num=1` code in the block;
  still ambiguous → excluded and the count reported.

**Discriminating contrast.** `Δ_spec = ΔAUROC_CARDIORESP(M2 vs M1) − ΔAUROC_NONCARDIORESP(M2 vs M1)`.

- **Supportive (H1):** `Δ_spec >= 0.02` with 95 % bootstrap CI lower bound `> 0`, **and** the
  NON-CARDIORESP increment `<= 0.5 ×` the CARDIORESP increment, **and** the CARDIORESP increment
  survives the escalation block E (below) with `>= 75 %` retention, **and** permuted-label
  specificity increment `<= 0.005`.
- **Adverse (H0 favoured):** `Δ_spec <= 0` OR CI includes 0 OR the increment is non-specific
  (NON-CARDIORESP `>= 0.8 ×` CARDIORESP). An adverse/non-specific result is a **valuable negative**
  finding: it would show the footprint is largely a practice/monitoring artifact.
- **Inconclusive:** in between, or wide CI, or a category has `< 30` held-out events.

**Escalation-event control block E (explicit rival features; the parent lacked these tables).**
Prespecified from bound tables and joined on `(subject_id, hadm_id)`, `[t0-24h, t0)` unless noted:
- `hosp/poe` (`poe_id, poe_seq, ordertime, order_type, order_subtype, transaction_type,
  order_provider_id, order_status`) — counts/novelty of order types, ICU-level consult/transfer orders.
- `hosp/emar` (`medication, event_txt, charttime, enter_provider_id`) — new vasoactive/antibiotic
  administrations, distinct entering providers.
- `icu/inputevents` (`itemid, rate, rateuom, starttime`) — vasopressor/inotrope starts (itemids read
  from `icu/d_items` at analysis time), and `icu/procedureevents` RRT/ventilation events.
- E predicts generic escalation; H0 predicts the specificity increment collapses after E, H1 predicts
  it is attenuated by `<25 %`.

Retained from parent: D1 fixed hourly cadence grid (±30 min), D2 per-patient standardised surprise,
M-obs value-free block (`chartevents.caregiver_id`, `storetime-charttime` documentation lag, cadence
regularity, carried-forward vitals, `warning`), within-stay placebos (P_sham cadence-anchored,
P_nonanchor `intime+8h`), permuted-label control.

## 4. Method comparison (baseline vs substantive alternative)

- **Baseline (interpretable, primary):** the nested M0 < M1 < M2 + M-obs/E blocks with penalised
  logistic regression; coefficient signs reported. This is the scientifically adequate primary model
  because the claim is about *incremental, category-specific* information, not raw accuracy.
- **Alternative (learned, secondary):** a small irregular-time encoder (GRU over the fixed-cadence
  grid, or a light 1-D CNN over the 24-bin grid) fitted on the **same** split and features. Purpose:
  test whether *within-window temporal ordering* reveals category-specific reserve loss that scalar
  SD/slope loses. Approximately 1 A100 GPU-hour; CPU-feasible fallback is the numeric ladder alone.
- Selection: baseline is primary; the learned model is a **deferred alternative** revisited only if
  the baseline `Δ_spec` is inconclusive but non-zero, per §5.

## 5. Falsification, decision, and what each outcome means

- Supportive → the footprint carries **cardiorespiratory-specific** reserve information; justifies a
  larger multi-centre / prospective readmission-readiness study and a notes-based adjudication.
- Adverse/non-specific → the footprint is largely an observation/escalation artifact; **park** the
  dynamic-footprint branch and prefer the notes/adjudication channel.
- Inconclusive → do not claim; escalate to the learned alternative and to notes-based category
  adjudication (external evidence).
