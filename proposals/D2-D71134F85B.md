## Question (falsifiable, unchanged)
Among RA synovial tissue macrophages, is there a DISTINCT, donor-consistent transcriptional program in patients who are RESISTANT to treatment versus patients in REMISSION — and is it distinct from (not merely a more extreme version of) the NAIVE/undifferentiated state? Does it nominate a therapeutic target / resistance signature?

## Clinical importance (unchanged)
~40% of RA patients respond inadequately to DMARDs; a subset remains refractory after cycling through agents of distinct mechanisms (the EULAR "difficult-to-treat" phenotype) [K1]. Identifying a macrophage-based treatment-resistance signature would (a) predict which patients will fail current therapy and (b) nominate the resistant-state program as a therapeutic target, informing mechanism-based therapeutic selection [K2]. De Lima 2023 showed tissue-resident macrophage states and TAM/MERTK signaling associated with treatment response in a different cohort [K3]; this proposal tests whether a complementary pseudobulk macrophage transcriptional contrast on E-MTAB-8322 carries a distinct resistant program.

## What changed from the parent (design_change)
1. **Proper normalization**: median-of-ratios (DESeq2-style) size factors on the 25 verified donors; log2(normalized+1) for contrasts; CPM as secondary normalization. (ep8 used log2(count+1) with no normalization.)
   - Implementation note (bug found & fixed this episode): the median-of-ratios must be restricted to genes expressed in >=10 donors. With ~44% of genes zero in a given donor, the full-matrix median ratio is 0 for 8/25 donors -> degenerate size factors (SF=0). Corrected SF range 0.25-4.87, tracks library size.
2. **Donor-label permutation** (1000 perms, exact p=(rank+1)/(nperm+1)) on the top-50 |log2FC| genes — the test ep8 deferred for compute budget.
3. **Internal positive control**: Naive vs Remission, identical pipeline, to test whether the pipeline can detect a signal at all.
4. **Leave-one-donor-out stability** of the top-50 |log2FC| set (13 donors).
5. **Module enrichment** under proper normalization (limited by an id-mapping bug, see limitations).

Analysis: analysis_8322_normalized.py (managed compute job [research job], succeeded, 2.1s).
Results: analysis-out/results.json, top_genes.csv, stability.csv.

- **PRIMARY CONTRAST Resistant vs Remission (normalized)**: 0 genes FDR<0.1 (also 0 for CPM normalization; ep8-style log2(count+1) also 0). min p = 2.2e-5, min FDR ~0.09 (no gene <0.1). Normalization does NOT create a genome-wide FDR signal.
- **Top-50 |log2FC| permutation**: observed statistic 1.77, permutation p = 0.0539 (NOT <0.05); 5/50 genes perm p<0.05. The top-50 set is only marginally non-random; does not survive exact permutation at 5%.
- **POSITIVE CONTROL Naive vs Remission (normalized)**: ALSO 0 genes FDR<0.1 (min p 5.4e-4). The pipeline is underpowered for genome-wide FDR at n=6/7; the FDR null is UNINTERPRETABLE (cannot distinguish "no signal" from "no power").
- **STABILITY**: leave-one-donor-out top-50 Jaccard ranges 0.33-0.67; ALL 13 donors flagged (<0.7). The top-50 set is NOT stable: with n=6/7, any single donor moves the top-50 by >30%. SA139 (naive) is not in the primary contrast, so the instability is a general small-n effect, not an SA139 outlier effect.
- **DISTINCTNESS (normalized)**: Jaccard top-100 Res-vs-Rem vs Naive-vs-Rem = 0.036 (was 0.205 in ep8); Spearman = 0.378 (was 0.606). Proper normalization makes the two programs MORE distinct, not less.
- **NORMALIZATION EFFECT ON TOP GENES**: Spearman of log2FC vectors (normalized vs ep8-style) = 0.547 (Res) / 0.739 (Naive). ep8's MMP-dominant top list is partly a library-size artifact; the normalized top-10 is different (ENSG00000277734 -3.92, ENSG00000255823 +3.70, ENSG00000237541 +3.49, ENSG00000126545 -3.43, ENSG00000167286 -3.30, ...).
- **MODULE ENRICHMENT**: NOT assessable this episode — see limitation 1 below.
- **CPM artifact**: ENSG00000183840 (counts 0-6/donor) reaches FDR 2.2e-4 under CPM normalization only — a low-count CPM artifact, not a biological signal; excluded from conclusions.

## Interpretation against the competing explanations
- **(a) library-size/normalization artifact**: PARTIALLY CONFIRMED. Proper normalization materially changes the top-gene list and the distinctness metrics (Jaccard 0.205->0.036, Spearman 0.606->0.378). ep8's MMP/S100A top list was partly a normalization artifact.
- **(b) SA139 outlier driving the signal**: NOT supported for the primary contrast (SA139 is naive, not in Res/Rem). The top-50 instability is a general small-n effect (all 13 donors flagged).
- **(c) low power (n=6/7)**: CONFIRMED as the dominant limitation. The biologically distinct Naive-vs-Remission positive control also yields 0 FDR<0.1, so the FDR null cannot reject a distinct resistant program.
- **(d) no distinct program (resistant = shared inflammatory axis)**: NOT supported, and now LESS supported than ep8 suggested. Under proper normalization the two programs are MORE distinct (Jaccard 0.036, Spearman 0.378 — both below the parent's "adverse" thresholds of >0.6 / >0.7). But with 0 FDR genes, an unstable top-50 set, and a non-significant permutation p (0.0539), distinctness is suggested, not established.

## Falsification criteria (unchanged from parent)
- SUPPORTIVE: >=20 genes FDR<0.1 (or a clear module-level signal); top module enriched for a specific axis; LOW overlap (<0.3) AND LOW correlation (<0.4) with naive-vs-rem on a STABLE top-gene set (leave-one-donor-out Jaccard >0.7).
- ADVERSE: No FDR<0.1 AND HIGH overlap (>0.6) AND HIGH correlation (>0.7) with naive-vs-rem on a stable top-gene set -> resistant is just more naive/inflammatory, no distinct program; OR group imbalance makes the contrast uninterpretable.
- INCONCLUSIVE: <5 FDR<0.1 AND (positive control also null, i.e. FDR test underpowered) AND distinctness metrics low/moderate but top-gene set unstable -> partially distinct suggested but unproven.
- **CURRENT RESULT: INCONCLUSIVE (confirmed and sharpened).** 0 FDR<0.1; positive control 0 FDR<0.1; Jaccard 0.036, Spearman 0.378; top-50 unstable (all 13 donors <0.7); permutation p 0.0539.

## What the result would and would not establish
- WOULD establish (not achieved): a stable, FDR-supported, module-enriched resistant macrophage program that nominates a therapeutic target.
- DOES establish: (1) ep8's top-gene list was partly a normalization artifact; (2) the FDR-based null at n=6/7 is uninterpretable (positive control also null); (3) the resistant-vs-remission and naive-vs-remission programs are more distinct than ep8 estimated, but unstably so.
- Does NOT establish: causality (cross-sectional), a validated biomarker, or a mechanism.

## Method alternatives (recorded)
- Baseline (used this episode): median-of-ratios normalization + donor-mean log2FC + Welch t (scipy T-distribution) + BH FDR + donor-label permutation (1000) + positive control + leave-one-donor-out stability + module enrichment. Simple, transparent, appropriate for n=6/7 donors.
- Alternative (deferred): per-donor subclustering (M1/M2/IFN) then cluster-proportion contrast. More mechanistic; may be informative at the proportion level where n=6/7 is underpowered for genome-wide FDR. Revisit next.
- Alternative (deferred): negative-binomial (DESeq2/edgeR) model per gene. Heavier; with n=6/7 the extra modeling is unlikely to change the FDR conclusion given the positive control is also null.
- Alternative (deferred): elastic-net classifier Resistant vs Rem with donor-blocked CV. Overkill for n=13 donors; overfitting risk.
