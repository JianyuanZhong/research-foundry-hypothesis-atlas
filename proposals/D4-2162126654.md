# Baseline-only incremental information for repeat kidney-function prioritization

## Why a substantive repair is needed

This is a targeted successor to `[prior hypothesis]`. The parent's fail-closed field-certification gate is necessary and is retained. Its remaining identifiability problem is that its primary comparator uses the **observed future repeat interval** `t=(date_1-date_0)/365.25` as a predictor. Even though the parent carefully labels the result schedule-marginal and non-actionable, `t` is not available at baseline and is partly determined by attendance/scheduling. It therefore cannot support even a baseline protocol-prioritization interpretation without an additional schedule model.

The repair removes `t` from both prediction algorithms. The interval remains an eligibility variable and a prespecified descriptive stratifier only. This makes the estimand a well-defined baseline-feature prediction contrast conditional on the observed repeat-attender cohort, while preserving the clinically bounded question and refusing to imply a test-ordering or patient-benefit effect.

## Question, evidence, and unresolved claim

The available parent result supports only an association in a selected complete-biomarker cohort between baseline cystatin-C-derived kidney function and a later creatinine-derived threshold crossing, after the parent's fixed adjustment. It does not establish incremental out-of-sample information, clinical utility, chronic kidney disease, progression, or benefit.

The falsifiable unresolved claim is:

> Among participants with certified baseline and qualifying complete repeat measurements who actually return for that repeat, does a binary baseline cystatin-C threshold indicator add reproducible baseline-predictive information beyond a flexible baseline creatinine/age/sex comparator for the protocol-defined repeat creatinine threshold outcome?

This is useful for the narrower decision of whether an already-observed baseline cystatin-C result can improve prioritization of review among patients enrolled in a repeat-measurement program. It does not identify whether cystatin-C should be ordered, changes attendance, changes treatment, or benefits patients.

## Estimand and model comparison

Let `A=1` denote membership in `S_A` (observed qualifying repeat with complete repeat biomarkers). For baseline covariates `X0=(eGFRcr_0, age_0, sex)`, define the primary schedule-agnostic predictive estimand in the observed protocol cohort:

`Delta_Brier = E[((Y-p0(X0))^2 - (Y-p1(X0,E))^2) | A=1]`.

Report it multiplied by 1000. This is a conditional predictive contrast, not a causal effect of measuring cystatin C and not a population-average effect, because nonattenders have no repeat outcome in these sources.

`M0` is ridge logistic regression using only baseline `eGFRcr_0`, baseline age, and sex. `M1` adds only `E` and `E*(eGFRcr_0-60)/10`. Use the parent's training-only restricted cubic spline specification for eGFR and age, sex interactions, centering/scaling, unpenalized intercept, fixed lambda grid `10^(-4),10^(-3.5),...,10^4`, and nested five-fold one-standard-error log-loss tuning. There is deliberately no `t`, no repeat biomarker, and no post-baseline variable in either model.

Use ten repeated outer five-fold cross-fits with seeds `260911` through `260920`, stratified by `E x Y`; inner seed is `outer_seed + 1000 + outer_fold`. All preprocessing, knots, and tuning are training-only and every test `eid` is disjoint from all training/tuning rows. Average ten out-of-fold probabilities per participant. Clip only log loss, if reported, to `[10^-6,1-10^-6]` and record clipping counts.

The secondary fixed-capacity diagnostic is `Delta_rank10 = 1000*(events in top-K M1 - events in top-K M0)/K`, `K=ceil(0.10*N)`, with exact ties broken by `SHA-256("direction-A-capacity-v2|"+eid)`. Call this a baseline protocol-ranking contrast within `S_A`, not events found by ordering a test. Report promoted/displaced and event counts only in aggregate. Do not use `t` to rank. Show `Delta_Brier` overall and descriptively within prespecified `t` bands `[2,4)`, `[4,6)`, `[6,8]`; the bands are not additional confirmatory tests and cannot rescue a failed primary result.

Use the fixed sequential test: test `Delta_Brier` first; only if it passes test `Delta_rank10`. For each, use paired participant bootstrap over the frozen ten-column prediction matrices, seed `260921`, 2,000 successful replicates, maximum 2,500 attempts, percentile 95% interval and plus-one symmetric null-centered p-value. Preserve convergence, cell-support, calibration, comparator-signal, split-sign, and aggregate-privacy gates from the parent.

## Null, falsification, and interpretation

The primary null is `Delta_Brier <= 0`; the secondary null is `Delta_rank10 <= 0`. A supportive result requires all certification/audit gates, exact cohort reconstruction, finite converged fits, fold isolation, calibration and comparator checks, adequate cell support, at least 8/10 positive repeat-specific contrasts, bootstrap completion, and a positive two-sided 95% interval-excluding-zero/p<0.05 primary contrast; only then may the secondary positive contrast be considered. The conclusion is limited to reproducible baseline incremental information and, if secondary criteria pass, baseline ranking concentration in `S_A`.

Adverse means a prespecified primary contrast is wholly below zero, M1 reproducibly loses calibration while M0 passes, or at least the required repeat-specific contrasts favor M0. This falsifies the claim that the baseline cystatin-C indicator adds useful information under the frozen comparator. Inconclusive means an interval includes zero, signs are unstable, model/support gates fail, or bootstrap completion fails; it is not equivalence.

Falsification checks include: permuting `E` within training folds (should eliminate incremental signal), replacing `E` with a training-fold-only random feature (should not reproduce gain), checking that any apparent gain is not confined to one outer repeat, and verifying that removing `t` does not cause hidden row selection or leakage. These are diagnostics, not post hoc alternate primary analyses. A failed negative-control check invalidates supportive interpretation and is adverse/inconclusive according to the prespecified gate.

A neutral stop is distinct from adverse/inconclusive: no biological result is computed when semantic, assay, or temporal certification fails. Computationally checkable claims are file identity, headers, keys, joins, certificate matching, missing-code policy, equations conditional on certified units, cohort masks, fold isolation, model arithmetic, bootstrap, and state transitions. Assay validity, specimen provenance, chronicity, true GFR, the reason for attendance, missing outcomes for nonattenders, clinical utility, and patient benefit require steward metadata, expert adjudication, external validation, or a decision-impact/randomized study.
