## Exact 2021 CKD-EPI equations and units

After certification, use the following equations exactly, in double precision, with age in years and female indicator `F=1` for certified sex code Female and `F=0` for Male. No race coefficient is used.

For serum creatinine `Scr` in mg/dL, let `(k,a)=(0.7,-0.241)` for female and `(0.9,-0.302)` for male:

`eGFRcr = 142 * min(Scr/k,1)^a * max(Scr/k,1)^(-1.200) * 0.9938^Age * 1.012^F`.

The source creatinine fields must be certified as serum creatinine in micromoles/L before conversion; then `Scr_mg_dL = raw_30700 / 88.4` exactly, retaining raw values for audit. If that unit is not certified, stop. For cystatin C `Scys` in mg/L:

`eGFRcys = 133 * min(Scys/0.8,1)^(-0.499) * max(Scys/0.8,1)^(-1.328) * 0.996^Age * 0.932^F`.

The source cystatin-C fields must be certified as cystatin C in mg/L, or a certified conversion to mg/L must be frozen in the certificate. No numeric-magnitude inference or undocumented conversion is allowed. Define `Z=log(eGFRcys_0/eGFRcr_0)`, primary `Ycr=I(eGFRcr_1<60)`, and secondary `Ycys=I(eGFRcys_1<60)` only when all required repeat fields are certified valid. These are equation-derived repeat statuses, not measured GFR, CKD, chronicity, kidney failure, or patient-important outcomes.

The equation provenance is frozen to Inker et al., 2021, DOI `10.1056/nejmoa2102953`, PMID `34554658`, PMCID `PMC8822996`, with public-search response [source checksum] and OpenAlex response [source checksum]. ## Exact baseline-only model implementation

All code must record Python version, `numpy`, `scipy`, `scikit-learn`, and `patsy` versions and hashes. Use Python 3.11+, NumPy float64, SciPy and scikit-learn versions frozen in a lock file supplied with the executable. The following is the complete model convention, replacing all unspecified inherited spline/L2 language.

For each training fold and each continuous variable x, create a four-column restricted cubic spline using the deterministic function `rcs4(x, lower, upper)` defined as follows. Let `u=clip(x, lower, upper)`, fixed knots `k1=lower`, `k2=lower+(upper-lower)/3`, `k3=lower+2*(upper-lower)/3`, `k4=upper`; let `d_j(t)=(max(t-k_j,0))^3/(k4-k_j)` for j=1,2,3; and define columns

`b1=u`, `b2=d1(u)-d3(u)`, `b3=d2(u)-d3(u)`, `b4=d3(u)`.

To ensure a restricted-linear tail and avoid scale ambiguity, center and scale each of these four columns using the training-fold mean and population standard deviation (ddof=0), replacing a zero SD by 1. Use fixed variable-specific bounds `age: lower=40, upper=80` and `eGFRcr: lower=60, upper=120`; clipping is part of the prespecified deployment transform and is not learned from the fold. This is a four-column, deterministic restricted-cubic basis, not a library default. Sex is numeric `F` and is centered/scaled with all other model columns in the training fold. For M1, append exactly one column `Z`, standardized by training-fold mean and ddof=0 SD (zero SD -> 1). No imputation is used in the primary S_A analysis.

Fit `sklearn.linear_model.LogisticRegression` with `penalty="l2"`, `C=1.0`, `solver="lbfgs"`, `fit_intercept=True`, `class_weight=None`, `max_iter=1000`, `tol=1e-10`, `random_state=0`, and float64 inputs. The intercept is unpenalized by scikit-learn's implementation; all listed columns are penalized with the exact L2 objective used by that version. Do not tune C, knots, bounds, solver, class weights, or convergence settings. M0 columns are `[F, rcs4(age,40,80), rcs4(eGFRcr,60,120)]` (10 standardized non-intercept columns); M1 is M0 plus standardized Z (11 columns). All preprocessing is fit on training data only.

Use ten deterministic outcome-stratified round-robin five-fold repeats with seeds `104729,104759,104773,104779,104789,104801,104827,104831,104849,104851`. For each repeat, assign labels after stable sort by `(label, eid)` and round-robin fold IDs 0–4 within each label; use the same algorithm for every label permutation, replacing label by the permuted label. Participant-independent tie ordering is ascending numeric `eid`, fixed before outcome inspection. Generate paired out-of-fold predictions for the same S_A participants. The exact model specification applies to the selection observation model too, except it uses A as label, excludes Z and all outcomes, and applies training-fold median imputation only to its baseline covariates.

## Gates and interpretation

Supportive predictive-prioritization evidence requires certificate status CERTIFIED, exact join and computation integrity, and either exact anchor reproduction or a documented certified reason for every discrepancy; complete null/bootstrap arithmetic; no material M1 calibration deterioration; a contiguous 5–15% capacity region whose simultaneous 98% lower DeltaC band is above zero; stability across repeats and supported strata; observed statistics more favorable than the corresponding fold-aware empirical label null; and no comparable predictor-null, reversed-label or leakage gain. Selection weighting is reported separately and cannot rescue a failed primary gate.

Adverse evidence is a reproducibly negative incremental curve, material calibration harm, null-compatible gain, leakage, nonfinite/incomplete computation, or certified assay incompatibility. Inconclusive evidence includes bands crossing zero, isolated gains, unstable schedule strata, extreme selection weights/poor positivity, anchor mismatch without certified explanation, or any `STOP_FIELD_UNCERTIFIED` status. Under STOP_FIELD_UNCERTIFIED, report only a technical non-result and do not claim the hypothesis was supported or refuted.

Even a supportive result is conditional on complete UKB repeat attenders and an observed schedule; it cannot establish that repeat testing improves outcomes, that a testing threshold is clinically justified, CKD chronicity, measured GFR accuracy, assay interchangeability, treatment benefit, cost-effectiveness, or transportability. Those require certified assay documentation, adjudicated persistent CKD and measured GFR, observed testing decisions and downstream treatment, utility/cost/harm data, and prospective external validation.
