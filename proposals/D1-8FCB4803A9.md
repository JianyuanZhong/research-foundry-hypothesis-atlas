## Fixed parser and endpoint

Write and hash `parser_freeze.json` before reading arm-specific respiratory rows. Matching is trimmed outer whitespace and case-sensitive, with no substring or synonym matching. The frozen `respiratoryCharting` map is FiO2 `{FiO2, FIO2 (%), Set Fraction of Inspired Oxygen (FIO2)}`, PEEP `{PEEP, PEEP/CPAP}`, pressure support `{Pressure Support, PS above PEEP}`, and set rate `{Vent Rate, VS RESP RATE}`. Peak/plateau/mean airway pressure, pressure-control, peak-flow, spontaneous/total-rate, and oxygen-flow labels are excluded from the primary map; peak pressure is a declared ablation only.

For every numeric field, trim and require the complete token `^[+-]?(?:\d+(?:\.\d*)?|\.\d+)(?:[eE][+-]?\d+)?$`; reject blanks, units, ranges, inequalities, nonnumeric and non-finite values, retaining raw value, parsed value, label, reason, and parser version. Use raw-scale bounds FiO2 `[21,100]`, PEEP/pressure support `[0,60]`, set rate `[0,100]`, SpO2 `[0,100]`, and respiration `[0,200]`. Do not rescale values such as `0.4`, interpolate, carry forward, or substitute components.

For every component and safety signal in `P`, `B`, `E`, and `T`, require at least two valid observations at distinct clinical offsets separated by at least 30 minutes. Collapse exact duplicate clinical-time/value records only after retaining IDs and deterministic `(clinical_offset, entry_offset, source_id)` order; distinct valid values at one clinical offset are `time_tie_conflict`, not an arbitrary pick. Summaries use medians and retain valid/rejected counts, distinct times, first/last offset, maximum gap, and reasons. A component is persistently reduced only if its `B`, `E`, and `T` medians exist, both post medians are no greater than B, and at least one non-peak component meets the fixed decrease threshold: FiO2 >= 0.05, PEEP >= 2, pressure support >= 2, or set rate >= 2. Safety passes only when in both E and T SpO2 is at most 2 points below B and respiration at most 4 breaths/min above B. Missing safety is not a pass. Primary airway corroboration requires at least one O-window `respiratoryCare` record with nonempty `airwaytype` or a genuinely nonmissing ventilator interval field; it is chart corroboration, not device truth.

## Explicit competing-risk state machine

For each frozen row, compute `exit_before_end = unitdischargeoffset is nonmissing and unitdischargeoffset <= D+1800`; retain the raw exit time, trimmed status/location, and normalization flags. Apply this mutually exclusive precedence before endpoint missingness:

1. If `exit_before_end` is true and trimmed status, case-folded, equals exactly `expired`, state `competing_exit_death`.
2. If `exit_before_end` is true and not death, state `competing_exit_discharge_transfer` when either status or location is a nonmissing, non-sentinel value. Sentinels are the case-insensitive trimmed set `{",", "", "unknown", "unk", "null", "na", "n/a", "not available", "not documented", "missing"}`; malformed values are also non-classifiable. This rule deliberately treats `Alive` and any documented non-death location as non-death exit, without inferring a clinical destination.
3. If `exit_before_end` is true but both status and location are missing/sentinel/malformed, state `competing_exit_truncation`.
4. If no competing exit occurs, set `no_post_washout_opportunity` when exit is nonmissing and `unitdischargeoffset <= D+360`; otherwise evaluate endpoint observation. An exit at exactly `D+1800` is competing. An exit after `D+1800` is not competing for this endpoint. Death always takes precedence over location; no row can have two competing-exit states.

For rows without a competing exit, classify in order as `endpoint_missing`, `persistent_improvement`, or `observed_non_improvement`. Endpoint missingness retains one primary reason by fixed precedence and all reason flags: no pre component, no early component, no late component, no safety, airway not observed, parser rejection, source absence, time-tie conflict, and source error. Fully observed but failing the improvement condition, including safety failure, is observed non-improvement. Report the four competing/endpoint states and all reasons by arm, hospital, and landmark. Never treat discharge as ordinary non-event, never impute a post-exit value, and never drop rows because exit or missingness differs by arm.

The primary complete-observed risk difference remains evaluation minus no-trial among rows with no competing exit and complete primary ascertainment. Also report cumulative state proportions over all 540 rows and a sensitivity with death, discharge/transfer, and truncation as distinct competing events. The competing-risk analysis is descriptive state accounting, not a causal survival estimand.

(3) Documentation-density negative controls use post-anchor counts, distinct times, and source presence without respiratory values; value-free label gains indicate opportunity/ascertainment rather than trajectory information.
