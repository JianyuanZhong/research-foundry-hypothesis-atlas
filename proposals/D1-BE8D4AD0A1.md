## Falsification and mutually exclusive interpretation

After all mandatory gates pass, each coordinate is exactly one of: `stable-supportive` if `L_e^0>5` and `L_e^-1>5`; `singleton-fragile` if `L_e^0>5` and `L_e^-1<=5`; `world-heterogeneous` if `L_e^0<=5<U_e^0`; or `all-world-adverse` if `U_e^0<=5`. Equality to 5 fails. These predicates are exhaustive and disjoint.

The global output is one-hot:

1. `inconclusive` takes precedence for any source, annotation, adequacy, fit or exact-solver failure;
2. `comparator-closed-supportive` iff all six coordinates are stable-supportive;
3. `universal-adverse` iff all six undeleted coordinates are all-world-adverse;
4. `mixed-or-heterogeneous` otherwise, with computable subtypes including `semantic-evidence-only` when all `Delta_R/Delta_mask` coordinates are stable-supportive but a `Delta_B` coordinate is not, plus comparator-, year-, reader-book-, source/pathology- and singleton-localized labels only when attained witnesses establish them.

Mixed/heterogeneous results falsify the universal conjunction and identify dependencies, not a correct reader/state; a fragile result does not make the deleted patient erroneous. Inconclusive is not adverse evidence.
