# Episode 2 evolution: audited first-recorded-TACE question

Status: repaired working proposal; no scientific model result has been computed. The source audits below are bounded observations used to repair feasibility and falsification, not evidence that the hypothesis is true.

## Scientific question and claim boundary

Among patients with a first locally recorded TACE in the HCC snapshot, does a post-index liver-state trajectory contain prognostic information for a second locally recorded TACE in days 43--180 beyond pre-index severity and the opportunity to observe the patient?

The testable claim is descriptive/predictive: among patients with an auditable exact-code index TACE and an observable outcome status, assay-specific state values and their ordered change during days 7--42 improve held-out prediction of a day-43--180 repeat exact-code TACE beyond pre-index severity and observation-process features.

The leading rival is a care-process explanation: patients who are sicker, scheduled for planned retreatment, or more intensively followed have more laboratories, examinations and encounters. Greater measurement opportunity can create both an apparent dynamic signal and a repeat procedure without a biological response signal. Repeat TACE is an operational endpoint, not tumor response, progression, treatment failure, or a causal effect of TACE.

[K1] supports retrospective biomarker associations after TACE but does not distinguish state from observation process. [K2] supports that HCC response requires viable-enhancement/necrosis assessment and that response criteria have practical limits; this record has no validated mRECIST/LR-TR labels. [K3] bounds the rival that surveillance signals can lag heterogeneous biology and should be adjunctive. The substantive advance is an exact-code, observation-complete, held-out state-versus-process test, not a reproduction of any demonstration paper.

## Population, index and endpoint

Use only the HCC snapshot. In procedures, require nonmissing 患者主索引, 就诊号 and 开始时间. Normalize only by trimming whitespace and case-folding; primary code is exactly 'tace'. Select the earliest dated strict-code row per 患者主索引 in available local history, deduplicating exact same patient/start rows. Inner-join to encounters on (患者主索引, 就诊号). This means first recorded in this snapshot, not first-ever TACE. Exclude only a prior dated strict-code TACE; undated prior rows remain an unresolvable-history limitation.

Index time is procedures.开始时间. The primary outcome is at least one later unique-start strict-code TACE with 43 <= (开始时间-index_time).days <= 180. A missing-start row is untimeable, never a negative. 结束时间 is optional. 手术来源 is descriptive and does not adjudicate planned versus rescue treatment, completion or clinical indication.

A separately reported sensitivity may use a frozen, narrowly defined high-specificity Chinese/TACE codebook. Broad substring matching, all locoregional procedures, ablation and resection are not the primary endpoint and must not be described as progression.

## Observation-complete status

Build obs_end as the latest nonmissing linked patient timestamp from:

- encounters: 就诊时间, 入院时间, 出院时间;
- procedures: 开始时间, 结束时间, for outcome ascertainment/follow-up only;
- examinations: 开始时间;
- labs: 检验时间;
- medications: 开始时间, 结束时间;
- orders: 开立时间, 开始时间, 结束时间.

Diagnoses has no temporal column and is used only through encounter linkage and fixed pre-index dictionary features. Clinical documents and pathology lack valid time fields and are excluded from primary longitudinal timing. vitals, transfers and front_page are identifier-only, not measurements.

Define status without administrative death assumption: Y=1 for an observed dated strict repeat TACE in days 43--180; Y=0 only with no such event and obs_end >= index+180 days; otherwise right-censored/unknown at obs_end (or first event), never Y=0. The primary same-estimand comparison uses this known-status cohort. A complementary all-index discrete-time hazard analysis runs from day 43 to repeat or censoring, with censoring weights fitted only within training folds; it is a sensitivity, not a replacement estimand.

## Assay identity and dynamic state

Freeze a codebook before outcome modelling. Primary assay channels are exact raw 检验 labels, not broad regex aliases. At minimum keep separate audited labels 甲胎蛋白, 白蛋白, 总胆红素, 直接胆红素, 丙氨酸氨基转移酶, 血小板 and 血小板计数; add other labels only after row-level frequency, value-type and alias review. Do not pool 前白蛋白 with albumin, direct with total bilirubin, or platelet indices with platelet count.

Use only ordinary numeric 定量结果 values. Preserve 定性结果, missingness and inequality/censoring flags; do not convert >60500 to an exact number. No units or reference ranges means no clinical thresholds, cross-assay pooling or conversion. Standardize within exact assay using training folds only. A paired change requires valid baseline (-365 to index) and response (days 7--42) observations; unpaired patients remain via missingness indicators. The full audit reports per-label rows/patients, numeric and censored fractions, blank specimen type and time coverage. If the full scan cannot establish stable assay identity, the state result is inconclusive and process-only models are not relabelled as biology.

## Leak-proof input boundary

All joins use (患者主索引, 就诊号) to encounters; longitudinal order uses each table's timestamp. Feature horizon is -365 through +42 days; no later row is a predictor.

The index TACE is an anchor token only. Exclude every post-index procedure token, including TACE in days 1--42, to prevent scheduling or early intervention from encoding the endpoint. Pre-index procedures contribute history counts only. Outcome procedures are read after feature materialization. Do not order documents/pathology by file order.

M0 severity/history uses age, sex, department, encounter counts and admission duration from encounters; fixed pre-index diagnosis dictionary counts; pre-index exact-assay summaries/directions; and pre-index procedure counts. Height/weight are sensitivity-only because units are unverified. Orders/medications are process/context, not evidence of receipt/adherence. Response-state inputs are exact-assay values, qualitative/censored flags, assay-specific changes and missingness. Response-process inputs are encounter/observed-day counts and gaps, lab counts by exact assay, examination counts/types/gaps, order counts/status and medication counts/classes. Examination text is not a validated response label.

## Same-estimand alternatives

Use one deterministic patient-level split: 80% development and 20% untouched test, stratified on known outcome status where possible. Use five grouped folds within development for all preprocessing/hyperparameters. Reuse the same patients, codebook, folds and test set for every model/permutation; no favorable peeking.

Transparent model: elastic-net logistic regression for binary known status, with fold-fitted scaling/imputation and missingness indicators.

- M0: pre-index severity/history;
- M_state: M0 plus response-state values/changes;
- M_process: M0 plus response-process features;
- M_both: M0 plus state and process.

Compare held-out log loss and calibration increments M_state versus M0/M_process and M_both versus M_process. Brier score, AUROC and AUPRC are secondary. A pooled-logistic hazard model is optional sensitivity only.

Learned alternative: compact GRU or equivalent gated sequence with dated encounter/lab/examination/medication/order tokens in -365 to +42, no post-index procedure tokens. Tokens carry event category, exact assay/type, numeric value only after audit, qualitative/censoring/missingness flags, time since index, time since prior token and state/process channel. Cap token length prospectively and report truncation.

Fit matched S0, S_state, S_process and S_both. Process-only carries timing/opportunity but no clinical values; state-only carries clinical values but no explicit order/test/encounter marks. Missingness is itself observational, so this is a controlled decomposition, not proof of biology. The sequence alternative is scientifically useful because it retains order, irregular gaps, transient changes and interactions that hand summaries lose.

Fix these controls before test evaluation: (1) permute response-window times within patient, preserving event/value multiset and counts; (2) permute process marks across patients within development folds matched on index calendar period and event-count strata; (3) shuffle same-assay response values across patients within fold; (4) fit a capacity-matched process-only model. These controls test whether process/timing alone reproduces the increment, not all unmeasured confounding.

## Metrics, uncertainty and decision rules

Primary test metrics are per-patient held-out log loss and Brier; require calibration slope/intercept and calibration plots. AUROC/AUPRC are secondary. Use paired patient bootstrap 95% intervals for differences and calibration, and three fixed sequence seeds with seed ranges. Report strict, each frozen coding sensitivity, and observation sensitivity without changing the estimand.

Supportive requires at least 50 observed events, completed code/assay audit, state improvement over process in held-out log loss and calibration with a paired 95% interval excluding no improvement, stable direction across seeds and coding/observation sensitivities, and no comparable gain from permutations. It supports incremental recorded-state information only.

Adverse, with adequate precision, is state increment loss after process adjustment, M0 comparable, or process/permuted features reproducing the gain; this supports severity/workflow/measurement explanations and argues against a response-triggered rule.

Inconclusive is fewer than 50 events, too few complete negatives, unstable coding/assay mapping, broad censoring or wide intervals. It is not a biological refutation.

No result establishes TACE intent, viable tumour, mRECIST/LR-TR response, progression, toxicity, transplant status, death, outside care or causal benefit. Those require expert adjudication, units/reference ranges, imaging and longitudinal linkage.
