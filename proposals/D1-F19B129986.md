# Episode 3 evolution: decision estimand for recorded post-TACE retreatment

Status: complete proposal branch; no predictive model, fitted result, or clinical conclusion has been computed in this episode.

## Decision-relevant question

Among patients with a first locally recorded exact-code TACE, does the recorded liver-state layer available by day 42 improve estimation of the probability of a later locally recorded repeat exact-code TACE in days 43–180, after accounting for baseline severity and the opportunity/planned-care process that generates observations?

The decision estimand is incremental prognostic information for a documented retreatment-planning signal, not a treatment effect. The intended next decision is whether a state signal is strong enough to justify a prospective, clinically adjudicated study of follow-up or retreatment planning. The experiment must not produce a rule to withhold or deliver TACE. Repeat TACE is consequential because it is an invasive, resource-intensive locoregional procedure; nevertheless, the code is only a record of performance. It does not establish planned versus rescue intent, radiologic response, viable tumour, progression, toxicity, transplant eligibility, outside care, or benefit.

This is a narrowed child of the parent question. The strongest available evidence is that the audited exact code occurs often enough to define a measurable retreatment process: 1,761 exact-code rows, 1,404 with a start time, 1,169 dated patients, and 112 patients with a later unique-start exact-code event 43–180 days after the first dated event. These are source-audit observations, not model results. [K1] supports associations between post-TACE biomarkers and prognosis in a retrospective TACE cohort, but does not separate state from observation opportunity. [K2] establishes why treatment effect normally needs viable-enhancement/necrosis assessment and why a procedure code or local examination text is not an mRECIST/LR-TR label. [K3] bounds the competing concern that surveillance signals can be heterogeneous or delayed and should not be treated as standalone treatment triggers. The unresolved claim is therefore narrow and falsifiable: after process adjustment, does recorded state add held-out information about documented repeat TACE?

## Competing explanations and falsification

The leading state explanation predicts that exact-assay values and their change in days 7–42 improve out-of-sample probabilities beyond baseline and process features, and that destroying state identity or temporal alignment removes that increment.

The strongest rival is planned-retreatment/observation intensity. Sicker patients, patients already scheduled for a repeat procedure, or patients seen more often generate more encounters, examinations, laboratory orders/results, and medication/order activity. This rival predicts that process-only inputs match the state increment, that process permutations preserve it, or that the apparent signal is driven by opportunity rather than values. A third, less separable explanation is unmeasured disease severity: recorded state may be a proxy for severity even after measured baseline adjustment. The design can falsify a pure process/timing account only; it cannot identify a biological mechanism or remove unmeasured confounding.

The smallest decisive check is a same-patient, same-split 2x2 decomposition:

- M0: pre-index severity/history.
- M_state: M0 plus exact-assay numeric values, qualitative/censored flags, missingness, and assay-specific changes in the response window.
- M_process: M0 plus dated observation/process features, with no laboratory values.
- M_both: M0 plus both layers.

The primary contrast is M_both versus M_process on held-out log loss and calibration. M_state versus M0 is a secondary incremental contrast. If M_both does not improve over M_process, the experiment does not support a state-triggered direction even if the combined model predicts repeat TACE well. If M_process predicts as well as M_both, the useful finding is a care-process/observation signal, not evidence of biological recovery or failure.

Pre-specified negative controls use the same patients, codebook, folds, and untouched test set: (1) shuffle response-window state values across patients within development folds while preserving assay and missingness structure; (2) scramble response-window times within patient while preserving each patient’s values and counts; (3) permute process marks across patients within calendar-period and event-count strata; and (4) compare with a capacity-matched process-only model. A state increment reproduced by these controls is not state-specific.

## Population, timing, and endpoint

Use only the HCC snapshot [source checksum]. In procedures, require nonmissing Patient master index, Encounter number, and Start time; trim and case-fold Surgery, then require exact equality to tace. Select the earliest dated strict-code row per patient in available local history, deduplicate exact same-patient/start rows for event counting, and inner-join the index row to encounters on (Patient master index, Encounter number). This is first recorded in this snapshot, not first-ever TACE. Exclude only prior dated strict-code TACE; undated prior rows remain an explicit history limitation.

The primary event is the first later unique-start strict-code TACE with 43 <= (repeat start time − index start time).days <= 180. Missing-start procedures are untimeable and never negatives. Procedure source is descriptive only: the audit found one source value (anesthesia system) for all 1,761 strict rows, which provides no intent adjudication. The 43-day boundary excludes index/early post-index procedure tokens from predictors and reduces direct encoding of immediate continuation, but it does not prove that a later procedure was rescue rather than scheduled.

Define obs_end as the latest nonmissing patient-linked timestamp from:
- encounters: encounter time, admission time, discharge time;
- procedures: start_time, end_time, for ascertainment/follow-up only;
- examinations: Start time;
- labs: Test time;
- medications: start time, end time;
- orders: order time, start time, end time.

The primary binary estimand is restricted to known status: Y=1 for a dated repeat event in the window; Y=0 only when no such event is observed and obs_end >= index+180 days. All other patients are censored/unknown, never negative. A pre-specified all-index discrete-time hazard sensitivity uses follow-up until event or obs_end, with censoring weights learned inside training folds. It is not a replacement for the known-status estimand and no administrative death assumption is made. The source audit found 105,044 encounter rows, dates spanning 2010-07-27 to 2026-01-01, 3,587 missing admission times and 252 missing discharge times; these facts reinforce the need for the observation-complete rule, but do not establish how many known-status endpoints remain.

## Baseline, substantive alternative, and evaluation

Use one deterministic patient-level 80/20 development/test split, stratified on known status when possible, with five grouped development folds. Fit all parsing, codebook, scaling, imputation, hyperparameters, censoring weights, and permutation operations inside development folds. The untouched test set is evaluated once.

The transparent baseline is fold-preprocessed elastic-net logistic regression for binary known status. Compare M0, M_state, M_process, and M_both above. The substantive alternative is a compact gated sequence model (GRU or equivalent) over dated encounter/lab/examination/medication/order tokens in -365 to +42. Each token carries event category, exact assay/type, numeric value only after the assay audit, qualitative/censoring/missingness flag, time since index, time since prior token, and state/process channel. Cap token length prospectively and report truncation. Fit matched S0/S_state/S_process/S_both. This alternative can reveal irregular timing, transient changes, order-sensitive interactions, and observation gaps that pre-specified summaries lose; its extra capacity is not evidence in its favor, so it must answer the same state-versus-process contrast.

Primary outputs are held-out per-patient log loss and calibration (slope/intercept and plots) for M_both−M_process; Brier is a secondary uncertainty measure. AUROC/AUPRC are secondary and cannot substitute for calibration. Use paired patient bootstrap 95% intervals for contrasts and three fixed sequence seeds with seed ranges. Report raw strict-code and any frozen high-specificity codebook sensitivity without changing the primary estimand.

Supportive outcome requires a completed endpoint/assay/observation audit, at least 50 observed repeat events and enough complete negatives for stable calibration, a state increment over M_process in held-out log loss with a paired 95% interval excluding zero, concordant calibration/Brier direction, stable direction across sequence seeds and coding/observation sensitivities, and no comparable increment in the state/time/value negative controls. It supports only incremental recorded-state information for documented retreatment planning.

Adverse outcome, with adequate precision, is no state increment after process adjustment, a process-only or process-permutation model matching the apparent gain, or a state/time/value permutation reproducing it. This favors severity/workflow/measurement explanations and argues against using the recorded state as a retreatment trigger.

Inconclusive outcome is fewer than 50 observed events, too few observation-complete negatives, broad censoring, unstable exact-label/assay mapping, failed leakage audit, wide intervals, or incomplete learned comparison. It is not a biological refutation. If only the sequence fit fails but elastic-net and controls are complete, report the transparent decomposition and defer the learned comparison; do not replace it with a claim of mechanistic discovery.

## Deliverable and next decision

Completion requires cohort_audit.json, assay_audit.json plus frozen codebook, observation_audit.json, deterministic split/folds and leakage report, per-patient held-out predictions for every 2x2 transparent and learned fit plus negative controls, bootstrap metrics/calibration, and a conclusion report linking each conclusion to an output. No scientific result is claimed in this memo.

A supportive result justifies a next study with expert review of imaging/viable enhancement, TACE intent, treatment indication, and clinically adjudicated response; it does not justify changing care. An adverse result redirects the project toward documenting workflow/observation intensity and may still inform scheduling or data-quality interventions. An inconclusive result calls for better follow-up ascertainment, assay units/reference ranges, or adjudicated imaging rather than a favorable interpretation. Claims about causal TACE benefit, response, progression, toxicity, survival, transplant, mortality, or outside care require unavailable evidence and another study.
