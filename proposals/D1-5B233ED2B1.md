# Transition-confirmed post-ICU failure after recorded recovery

## Scientific deliverable

The solver must newly fit and evaluate a leakage-safe MIMIC-IV 3.1 prognostic study that:

1. reconstructs the parent’s adult first-ICU-discharge cohort and source-concordant recent-versus-durable recorded-support exposure;
2. adds a prespecified outcome-topology label from dated hospital transfers, separating ICU return after an observed non-ICU interval from ICU return without such an interval;
3. estimates mutually exclusive competing cumulative incidences for transition-confirmed ICU return, transition-unconfirmed/immediate ICU return, in-hospital death, and observed alive hospital discharge at 6, 24, and 48 hours;
4. fits a transparent cause-specific baseline and a substantive duration-aware latent alternative using identical pre-outtime inputs and patient-level splits; and
5. reports held-out estimates, uncertainty, coverage/positivity, topology validity, calibration, and falsification results.

Completion requires these workspace outputs:

- `hourly_features.parquet`: one row per stay-hour in `[outtime-12h,outtime)`, containing chart-time physiology, masks, support evidence and no post-landmark field.
- `support_buffer_audit.parquet`: vasoactive and respiratory evidence ledgers, source-concordant/discordant/unobserved labels, valid endpoint flags and recent/durable buffers.
- `outcomes_topology.csv`: the aggregate parent event, topology-specific event, exact event times, transfer interval used for classification, follow-up, ties and observability flags.
- `baseline_test_predictions.parquet` and `latent_test_predictions.parquet`: locked patient-level test risks/CIFs for all four primary causes at 6/24/48 hours and for the parent aggregate-return sensitivity.
- `cif_associations.csv`: unadjusted Aalen–Johansen and adjusted cause-specific estimates, absolute CIF contrasts, and uncertainty.

## Remaining weakness and clinical importance

The parent’s evidence-tier repair makes the pre-outtime exposure more honest: it no longer treats missing respiratory observations as continuous support-free time. Its remaining decision-relevance weakness is the outcome label. A later `icustays.intime` is counted as “ICU return,” but that label combines two different observable pathways:

- the patient has an observed non-ICU interval before re-entry, which is compatible with deterioration after transition; and
- the patient re-enters ICU before any observed non-ICU interval, which may reflect an immediate transition, transfer-record incompleteness, or administrative timing.

Neither pathway can be called planned or unplanned from MIMIC. Pooling them can make a durable recorded-off marker appear clinically meaningful when it only predicts how the ICU/disposition process is recorded. Separating them is a decision-relevance repair: a signal that survives specifically for return after an observed non-ICU interval is more relevant to post-transition surveillance than a signal confined to immediate/uncertain re-entry, while still remaining a retrospective prognostic association.

## Population, landmark and outcomes

Use adults with `hosp/patients.anchor_age >= 18`, retaining MIMIC’s `anchor_age=91) representation, and select the earliest `icu/icustays.intime` per `subject_id,hadm_id`. Require:

- non-null ordered `intime < outtime < admissions.dischtime`;
- no `admissions.deathtime <= outtime);
- valid joins to `hosp/admissions` and `hosp/patients`; and
- `admissions.dischtime` available for the primary competing-discharge analysis.

The landmark is `icu/icustays.outtime`. Features use only source times in `[outtime-12h,outtime)), split into two six-hour halves. Chart observations use `chartevents.charttime), input/procedure evidence uses `starttime,endtime), and `storetime) is never used as the clinical exposure time. No transfer or note after outtime enters predictors.

Follow to `min(outtime+48 hours, admissions.dischtime)). The four mutually exclusive primary first events are:

1. transition-confirmed ICU return: a later `icustays.intime > outtime) within 48 hours for the same `subject_id,hadm_id`, with at least one valid `hosp/transfers` interval whose `intime >= outtime`, `outtime <= later icustays.intime`, and whose `careunit` is non-ICU;
2. transition-unconfirmed/immediate ICU return: the same later ICU return, but no such preceding non-ICU transfer interval is observed;
3. in-hospital death before the other events, using `admissions.deathtime > outtime) within 48 hours; and
4. alive hospital discharge before the other events, using `admissions.dischtime > outtime) within 48 hours.

A later ICU stay is defined from `icustays`, not from a transfer row alone. Define the ICU-careunit set without string heuristics as the distinct non-null values of `icustays.first_careunit` and `icustays.last_careunit) in the frozen snapshot; a transfer `careunit) outside that set is non-ICU. Require a non-null, ordered transfer interval (`intime < outtime)); retain missing/invalid topology as diagnostic counts. If event times tie, primary precedence is death, then transition-confirmed return, then transition-unconfirmed return, then alive discharge, with a timestamp-tolerance sensitivity. Report the parent aggregate ICU-return event as a prespecified sensitivity by collapsing the two return types. No return is labelled planned or unplanned.

The primary estimands are group-specific adjusted CIFs and absolute recent-versus-durable differences at 6/24/48 hours for each event, with cause-specific hazards as secondary associations. A secondary analysis censors at alive discharge only to expose the estimand change; it cannot replace the competing-event analysis.

## Exposure construction

Retain the parent’s locked construction. In the 12-hour pre-outtime window, compute one-hour medians and explicit masks for MAP (arterial/NIBP separately), respiratory burden (FiO2/O2-flow/PEEP channels separately), HR, RR and SpO2. Define low final burden as MAP-burden <1/3 and respiratory-burden <1/3 in the final six hours, requiring at least two observed MAP bins and two respiratory bins in each half. Build separate valid vasoactive intervals from `inputevents), charted respiratory evidence from `chartevents), and procedure transition corroboration from `procedureevents). Do not carry observations forward beyond their one-hour bin.

The primary exposure is recent versus durable recorded-off among low-final-burden, adequately observed, source-concordant stays. Recent requires preceding-half qualifying evidence and a 0 to <6 hour recorded buffer; durable requires no qualifying final-half evidence and a >=6 hour valid buffer or no qualifying evidence in the full 12 hours. Respiratory chart buffers remain recorded-observation buffers, not proof of continuous absence. Discordant, active, residual and unobserved strata are retained and reported, not collapsed. A parent-minimum-domain-buffer sensitivity is required.

## Matched baseline and substantive alternative

Use patient-level 70/15/15 train/validation/test splits by `subject_id), fixed seeds 17, 29 and 43, with all preprocessing and tuning fit on training data. The identical predictor set is restricted to pre-outtime information: exposure tier/buffer, final and preceding MAP/respiratory burdens, one-hour masks, source/channel flags, HR/RR/SpO2 summaries and prespecified demographics, ICU LOS, first/last careunit, admission type and limited admission covariates. Neither transfer topology, discharge location, nor any post-outtime field is a predictor.

Simple baseline: four cause-specific Cox models (one per primary event) with the locked exposure and compact trajectory summaries; report a nested snapshot-only Cox baseline that omits buffer/order and uses final values, masks, support presence and case mix. Estimate Aalen–Johansen CIFs, adjusted standardized CIFs, calibration, IPCW Brier scores and subject-bootstrap intervals. This baseline is scientifically useful because it tests whether the exposure’s association is specific to a transfer-confirmed post-transition return, not only whether a flexible model predicts.

Substantive alternative: a constrained four-state hidden semi-Markov model on exactly the same hourly features and splits, with states durable recorded-off/low burden, recent withdrawal/low burden, active recorded support, and residual/discordant/unobserved. Use sparse transitions, explicit dwell-time distributions, and competing discrete hazards for the four event types over eight six-hour bins. Fit state emissions/transitions and hazards only on training data, choose restrictions on validation, lock test predictions, and propagate posterior state probabilities. It can reveal whether ordered physiologic/support trajectories and persistent observation gaps identify different topology-specific hazards that a compact Cox summary loses. It is not retained merely for a score increase: retain the alternative only if state occupancy/dwell/transition diagnostics are reproducible and held-out CIF calibration or topology-specific separation is materially more informative under the prespecified margin. If it is non-identifiable, the baseline remains the scientific result.

Uncertainty uses bootstrap resampling at the patient level within locked test evaluations, 95% intervals, IPCW Brier uncertainty, calibration intervals, and reporting of effective sample size, event counts, positivity, transfer-topology missingness and exposure-stratum sizes. No binary clinical-importance or “safe” threshold may be declared without a clinician-approved absolute CIF margin.

## Falsification and interpretation

Predeclare:

- shuffle hourly feature order within stay while preserving values and masks;
- compare mask-only, mask-removed, physiology-only and support-removed inputs;
- substitute `storetime` for `charttime` and last-value coding for interval overlap as coding falsifications;
- exclude procedure corroboration, then use it only as corroboration;
- separate arterial/NIBP MAP and FiO2/O2-flow/PEEP channels;
- perturb the 6-hour buffer and 6/12-hour windows;
- compare joint, vasoactive-only and respiratory-only exposure strata;
- collapse topology back to parent aggregate ICU return and compare with topology-specific estimates;
- vary the non-ICU transfer interval rule (strict `intime>=outtime` versus a locked timestamp tolerance);
- test transfer-record missingness and careunit mapping, including a negative-control pseudo-landmark before outtime;
- stratify by first/last careunit and admission type;
- report alive discharge competing-risk results beside discharge-as-censoring sensitivity; and
- audit `admissions.discharge_location` descriptively by exposure and topology, never as a predictor.

Supportive results require adequate transfer observability and positivity, stable topology assignment, a reproducible recent-versus-durable contrast for transition-confirmed return that is not confined to unconfirmed return or discharge pathway, calibrated held-out predictions, and state diagnostics that survive order/mask/source/channel/window/topology falsifications. This supports a retrospective marker for external and clinician-adjudicated validation.

Adverse results are a null or reversed contrast, disappearance after transfer-topology control, a signal confined to transition-unconfirmed returns, strong dependence on censoring or topology rule, poor calibration, or latent non-identifiability. These weaken or falsify the claim that recorded durability marks post-transition deterioration.

Inconclusive results are rare return events, non-positivity, invalid or missing transfer intervals, topology disagreement, wide intervals, unstable event ties, or unavailable discharge/death times. Report no clinical rule.
