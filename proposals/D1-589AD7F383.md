## Question, hypothesis, and clinical boundary

The parent’s post-360 endpoint is a first confirmed recorded severe vital excursion: an abnormal value followed by a second abnormal value from the same channel within 120 minutes. It is potentially useful as a temporally separated boundary, but the word “severe” is not established by eICU alone. A row may be a bedside measurement, device output, interface transmission, or other recording; the fields do not provide a gold-standard deterioration time. Fixed thresholds may therefore identify a workflow-defined absolute value rather than a patient-linked state transition.

This child tests whether that endpoint is defensible as an *auditable operational recorded-transition endpoint*, without assigning it an unverified clinical meaning.

**Hypothesis.** In the six-hour landmark risk set, the parent process vector P will show a hospital-transportable increment for a later recorded transition only if the increment is present for both (a) the pre-specified absolute threshold/persistence event and (b) a source-defined, within-channel trajectory-change event, after the fixed state T, competing ICU exit, future-observation audits, and inherited process/state nulls. If the increment appears only for the absolute-threshold label, only for measurement-availability flags, or only in one hospital/workflow stratum, the parent endpoint is not transport evidence for a patient-linked transition. If both endpoint definitions agree and survive the same safeguards, the strongest supported claim is that early recording/state information predicts a later *recorded vital transition*; it still does not establish clinical deterioration, mechanism, treatment effect, or actionability.

This is a descriptive prognostic and transportability experiment, not a causal test of monitoring, treatment, EOL decisions, or mortality.

### What would be learned beyond the parent

The parent asks whether P predicts ICU-discharge mortality after measured state and a trajectory-state null. This child asks whether the post-360 boundary itself is stable under a substantively different endpoint construction. The threshold label tests absolute excursions; the trajectory label tests within-field change relative to the source’s pre-landmark measurement scale. Their cross-classification separates:

- threshold-only events: absolute cutoffs or unit/measurement workflow may drive the signal;
- trajectory-only events: clinically relevant-looking change can occur without crossing an absolute cutoff, but it remains only a recorded change;
- concordant events: stronger operational reproducibility, not clinical validation;
- neither/unknown: absence of a recorded transition cannot be interpreted as physiologic stability when future observation is sparse.

A threshold event is operationally defensible only after its source fields, units/scales, duplicate behavior, offsets, and persistence rule are auditable. Agreement with the trajectory alternative is a useful convergent check; it is not an adjudication of deterioration.

## Endpoint A: fixed absolute threshold and persistence

Call this label `D_thr_recorded`, not “clinical deterioration,” until the source/clinical audit passes.

For a finite value in one of the seven fixed fields, mark that channel abnormal only under the following pre-specified candidate thresholds:

- `sao2 < 88`;
- `heartrate < 40` or `heartrate > 140`;
- `respiration > 35`;
- `systemicmean < 55`;
- `noninvasivemean < 55`;
- `temperature < 35` or `temperature > 39.5`.

The endpoint is the earliest pair of abnormal values from the same channel at distinct `observationoffset` values, both strictly in (360,720] and before ICU exit, separated by no more than 120 minutes. The event time is the second qualifying value. Do not carry forward, interpolate, merge periodic and aperiodic values into one channel, or create an event from a discharge row. A one-reading label is an exploratory sensitivity only.

The threshold audit must save, by source field and hospital: raw finite-value counts and quantiles in pre/post windows; observed value ranges and boundary-adjacent counts; offset duplicates and same-offset duplicates; candidate threshold units and scale; whether the source dictionary supplies unit semantics; and whether the persistence pair can be distinguished from duplicate/interface rows. The audit must verify that a field’s scale is stable within a stay and across hospitals before any “severe” wording. The schema fields listed above contain no asserted unit column; do not assume Celsius versus Fahrenheit, percent, beats/minute, breaths/minute, or pressure units merely from field names. If source documentation or the raw audit cannot establish scale, retain only the neutral label “recorded threshold crossing” and mark a clinical endpoint invalid.

## Endpoint B: source-defined trajectory change

Call this label `D_traj_recorded`. It avoids absolute clinical cutoffs and asks whether the same source-defined field shows a reproducible within-channel change.

Use the same seven fields, the same [0,360] predictor boundary, and the same (360,720] follow-up. Construct non-overlapping 60-minute bin medians from finite values:

- baseline bin B0 = [240,360];
- post bins B1 = (360,420], B2 = (420,480], B3 = (480,540], B4 = (540,600], B5 = (600,660], B6 = (660,720].

The endpoint is eligible for channel c when B0 and the required successive post bins each have at least one finite value. In every training fold, estimate a channel-specific source-change threshold `tau_c` as the 90th percentile of absolute adjacent 60-minute-bin median changes from pre-landmark bins [0,360], using only training-fold stays and no outcome, post-window value, hospital-held-out row, or process label. Require at least 100 qualifying training-fold adjacent-bin changes; otherwise that channel is deferred and the solver reports the missing dependency. The threshold is a source-scale regularity, not a clinical normal range.

The first `D_traj_recorded` is the earliest end of B(j+1) for which one channel has three consecutive nonempty bins B(j-1), B(j), B(j+1), with both adjacent changes having the same sign and absolute magnitude at least `tau_c`:

`sign(m_c(Bj)-m_c(B(j-1))) = sign(m_c(B(j+1))-m_c(Bj))`, and each absolute change `>= tau_c`.

Here B0 is allowed as the prior bin, so the earliest candidate uses B0, B1, B2 and occurs at the end of B2. The event is before recorded ICU exit and no later than 720. Require a nonzero signed change; ties do not qualify. If a bin has multiple values, use its median; do not interpolate or carry forward. If multiple channels qualify at one endpoint time, retain the earliest time and all qualifying channels in the manifest.

This endpoint is deliberately not called worsening, instability, or deterioration. It detects a source-scale directional trajectory change with short persistence. It can reveal changes that never cross absolute clinical thresholds, and it can miss a genuine absolute threshold crossing when the field is sparsely recorded or changes abruptly only once. Those are the scientific reasons to compare it with `D_thr_recorded`, not reasons to select the more favorable label after looking at results.

Report a pre-specified sensitivity with `tau_c` set to the training-fold median plus 1.4826 MAD of pre-landmark adjacent-bin changes, but do not replace the primary 90th-percentile definition. The sensitivity is a robustness check for the source-scale choice, not an opportunity to tune toward a hypothesis.

## Interpretation and falsification criteria

Support for the narrow operational-transition claim requires all of the following:

1. The source audit confirms the fields are numeric, time-stamped by `observationoffset`, stable enough for within-field comparison, and free of an unresolved duplicate/interface ambiguity. Absolute units need to be validated before any clinical adjective.
2. At least five viable hospitals remain; endpoint and observation support, positivity, and per-hospital event counts are adequate and reported. The trajectory threshold has the required training-fold support.
3. Both learners show a directionally coherent external P increment after T, with a paired interval excluding the parent’s 0.01 AUC negligible margin where AUC is estimable and a coherent calibration or 10% net-benefit contrast.
4. The increment is not explained by M flags, observation weighting, the trajectory-state null, the discharge-time null, or a single hospital.
5. Threshold and trajectory manifests show meaningful, auditable agreement rather than one label being generated by a small unstable subset.

This would support: “the early recording/state vector is associated with a later recorded source-scale vital transition across held-out eICU hospitals.” It would not support “the patient deteriorated,” a monitoring mechanism, a treatment recommendation, or a causal effect.

The branch is adverse for a transportable operational transition if both endpoint definitions have adequate support but P adds no held-out-hospital increment after T, or if their apparent increments collapse under state/measurement/discharge nulls. It is adverse specifically to the parent threshold as a state-transition proxy if `D_thr_recorded` is threshold-positive while `D_traj_recorded` is absent, unstable, unit-sensitive, or dominated by one source/hospital. A threshold-only signal can still be a valid descriptive recording association; it cannot be called patient-linked deterioration.

Results are inconclusive/deferral, not negative, when source units or field stability are unresolved, too few hospitals/events exist, the trajectory scale cannot be estimated, future coverage is low, weighting has poor positivity/effective sample size, Apache or source joins reveal discordance, or uncertainty spans the negligible margin. A learner-only improvement, a signal confined to one hospital, or an interval that spans both meaningful and negligible effects does not establish transportability.

The smallest next decision is therefore:

- **continue to clinical endpoint adjudication** only if the two recorded-transition definitions agree sufficiently and the external, observation-robust process increment survives the inherited nulls;
- **revise toward measurement/workflow study** if P predicts M flags or discharge-time strata but not a robust endpoint;
- **defer or abandon the clinical-transition interpretation** if units, duplicate semantics, trajectory support, or event ascertainment fail;
- **retain the parent’s bounded recording-process/mortality result** when the new endpoint is invalid or under-supported.
