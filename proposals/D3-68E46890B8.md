# Robustness of the state-specific metabolic reprogramming signal in treatment-resistant RA macrophages to age and sex adjustment

**Child of [prior hypothesis]** (D3-M3 branch, mu 36.51, board leader).
**Status: EXECUTED** ([research job]; script `analysis.py`, outputs `results.json`).
**Verdict: INCONCLUSIVE (directionally supportive on magnitude, not on significance).**

## Question

The parent candidate executed a 5-condition gradient analysis on E-MTAB-8322 (25 verified
donors; SA149/SA149P excluded per domain guide). Pooled OLS
`metabolic_score ~ inflammatory_score + condition dummies (HC reference)` gave a
**Resistant coefficient of 0.7900 (SE 0.3443, p=0.0333), R²=0.824** — interpreted as
evidence that treatment-resistant RA macrophages carry a state-specific glycolytic/HIF-1a
metabolic program beyond inflammatory activation. The parent listed as competing
explanation #4: *"Age/disease duration: Not adjusted for in this analysis. Age ranges
from 22-77 across conditions."*

This child tests that declared competing explanation directly: **does the Resistant
coefficient survive adjustment for age and sex?** The design metadata shows a large age
gap (HC mean 30.0 vs RA/UPA means 56-64) and a strong sex imbalance (21/25 donors female;
HC 3 male / 1 female; all 21 RA/UPA donors female). Note: the sex confound is strong but
**not complete** — HC0732 (age 26) is female — so Models B/C are estimable, though the
sex term is nearly collinear with disease state (phi ≈ 0.9) and is not a pure sex effect.

## Hypothesis under test

H0: the parent's borderline Resistant coefficient is an artifact of the age/sex
composition difference between HC and RA donors (competing explanation #4).
H1: the Resistant coefficient is a genuine state-specific effect that survives
age/sex adjustment.

This is a robustness check on an observational association; it does not test causality or
mechanism.

## Methods

1. **Model 0** (reproduction of parent): metabolic ~ inflammatory + Naive + UPA +
   Remission + Resistant (HC reference).
2. **Model A**: Model 0 + age (continuous). **Model B**: Model 0 + sex (female=1).
   **Model C**: Model 0 + age + sex.
3. **Permutation test** for the Resistant coefficient under Model C: shuffle metabolic
   scores among the 25 donors with age/sex/inflammatory/condition fixed; refit Model C;
   N=10,000; seed=42. Two-sided p = fraction of |permuted coef| ≥ |observed|.
4. **Sensitivity**: repeat Models 0-C under log2(CPM+1) normalization.

## Interpretation

**Verdict: INCONCLUSIVE — leaning supportive on direction, not on significance.**

- **Against competing explanation #4 (age/sex artifact)**: the Resistant coefficient does
  NOT vanish under adjustment — it *increases* in magnitude under every model
  (0.79 → 1.19 → 1.11 → 1.61 log1p; 0.48 → 0.77 → 0.95 → 1.33 logCPM). The age coefficient
  is small and non-significant (−0.015, p≈0.27-0.39) and the sex coefficient is
  non-significant (−0.50, p≈0.42-0.50). The signal is therefore not explained by the
  age or sex composition difference between HC and RA donors.
- **Against the state-specificity claim itself**: the OLS p for Resistant stays ≤0.04 in
  Models A and C (log1p) but is borderline (0.072) in Model B; under logCPM no model
  reaches p<0.05 (best: Model C p=0.078). The model-free permutation p under Model C is
  0.31 (two-sided) / 0.15 (one-sided) under log1p — the OLS p is optimistic relative to
  the permutation distribution (n=25, 7 parameters). The result is thus **not robustly
  established** by this robustness check.
- **What the adjustment reveals that the baseline loses**: the parent's unadjusted OLS
  cannot distinguish a genuine resistant-state effect from an age/sex composition
  artifact, because those covariates were never modeled. The adjusted models show the
  artifact hypothesis is not supported (coefficient grows, covariates null), but they
  also expose that the borderline significance is fragile: it depends on normalization
  (log1p vs logCPM) and on the inference method (OLS vs permutation).
- **Estimand caveat**: because 21/25 donors are female and the HC reference cell is
  mixed-sex (3M/1F), the sex term is not a pure sex effect (it is an HC-male-vs-RA-female
  contrast), and the Model C Resistant coefficient is effectively a within-female
  comparison. A true sex-specific analysis is not possible with one female HC donor.

## Falsification criteria (pre-specified for this check)

- **Supportive**: adjusted Resistant coefficient positive and significant (OLS p<0.05 AND
  permutation p<0.05) under both normalizations, with age and sex non-significant.
- **Adverse**: adjusted Resistant coefficient non-significant (p>0.10) or sign-reversed
  under adjustment → the parent's finding is an age/sex artifact.
- **Inconclusive**: borderline OLS p (0.05-0.10) and/or non-significant permutation p,
  and/or normalization-dependent results.

**Observed outcome: INCONCLUSIVE** (log1p Model C OLS p=0.040 but permutation p=0.31;
logCPM Model C OLS p=0.078, permutation p1s=0.031; direction and magnitude consistent
across all models and normalizations).

## What each outcome would mean for the D3-M3 branch

- Supportive → the branch flagship claim (state-specific metabolic program in resistant
  macrophages) is strengthened; proceed to cell-type validation (E-MTAB-8316) and
  perturbation (HK2/PHGDH knockdown).
- Adverse → the flagship claim is an age/sex artifact; abandon state-specificity,
  reframe as inflammatory scaling.
- Inconclusive (observed) → the age/sex rival is rejected but the claim is not robustly
  established; the next decision is a larger, age/sex-balanced cohort with treatment
  history, not further adjustments on this dataset (which are exhausted: no other
  covariates are available in the design metadata).

## Limitations

1. Cross-sectional, one sample per donor; no within-donor replication.
2. n=25 with 7 parameters in Model C; low power; OLS vs permutation p discrepancy.
3. Sex nearly collinear with condition (21/25 female); sex term not a pure sex effect;
   only one female HC donor.
4. Treatment history unavailable in design metadata (resistant donors' DMARD/biologic
   exposure unknown) — a separate, untestable confound.
5. Normalization sensitivity (log1p vs logCPM) materially changes significance.
6. Pseudobulk: cell-type composition differences (M1/M2 ratio) could mimic metabolic
   reprogramming.
7. The 10-gene inflammatory score may not capture all inflammatory pathways.

## Method comparison

- **Baseline (parent, executed)**: unadjusted pooled OLS + non-parametric tests.
  Loses: any ability to attribute the Resistant coefficient to state vs donor composition.
- **Alternative (this child, executed)**: adjusted OLS (age, sex, age+sex) + model-free
  permutation test + normalization sensitivity. Reveals: (a) the coefficient is not an
  age/sex artifact (magnitude increases, covariates null); (b) the borderline
  significance is fragile (permutation p 0.31; normalization-dependent).
- **Not chosen**: mixed-effects models (infeasible — one sample per donor); ML
  classifiers (would not answer the confounding question); per-gene adjusted regressions
  (underpowered: 19 genes × 7 parameters on n=25).
