## Baseline and alternative

The additive baseline asks whether inhibitor and macrophage context each have average effects but no context-dependent inhibitor effect. The interaction alternative asks whether the inhibitor effect changes with macrophage context. The alternative can reveal a microenvironment-dependent response that the additive model loses; it does not identify a mechanism.

A simple donor-aware linear interaction model is the primary method because the design is small and the scientific question is interpretable. A more flexible hierarchical or regularized feature model could be considered only if the verified design has enough independent donors and the added model is needed to estimate donor/context heterogeneity; it is not selected merely for predictive gain. Any such model must use the same donor-aware split and uncertainty evaluation.

## Interpretation and falsification

Supportive evidence would be a reproducible interaction with uncertainty excluding the null, stable direction across independent donor contributions, and no indication that it is driven by a single reused donor or assay batch. This would support context-dependent inhibitor-associated expression, not direct MerTK target action.

Adverse evidence would be a robust null interaction, a reversal across donors, or a result explained by donor/batch/condition assignment. This would weaken the proposed context-dependence claim.

Inconclusive evidence includes failed key or assay verification, too few independent donors, high imprecision, unstable donor-level estimates, or inability to separate inhibitor from macrophage context. An imprecise null is not decisive refutation.
