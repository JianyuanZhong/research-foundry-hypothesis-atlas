# Temporally and incidence-matched negative controls support respiratory-specific documentation signal, not generic documentation propensity or semantic expansion

## Substantive child and unresolved question

This is a substantive child of assessed-valid `[prior hypothesis]`. The parent preserved a target-independent cohort and found a partial endpoint reversal: after generic classification-window care-plan process features, the model containing all four exported `Ventilated -` indicators improved hospital-held-out prediction of later respiratory-documentation persistence under every airway bound, although it did not stably improve over the exact two-label model. That finding did not determine whether the apparent gain represented information specific to later respiratory documentation or merely a stay/site tendency to generate any later documentation.

The strongest claim supported before this child was therefore limited: exported Ventilation semantic indicators contain reproducible information for a later respiratory-chart persistence endpoint beyond the inherited generic care-plan process controls, while the two newly added strings do not rescue the exact encoding and the original adverse non-peak setting-reduction result remains intact.

The unresolved falsifiable hypothesis is: **the broader-versus-process gain for later respiratory-chart persistence is larger than its gain for temporally aligned, hospital-by-landmark incidence-matched non-respiratory documentation-opportunity controls.** The clinical advance is measurement-specific. If the same semantic block predicts arbitrary later documentation equally well, the endpoint reversal is a generic charting-intensity artifact and should not motivate respiratory interpretation. If it selectively predicts respiratory-chart persistence, it identifies a reproducible respiratory workflow-documentation association worth local interface adjudication, while still not validating actual ventilation, daily evaluation, SBT, extubation, readiness, quality, benefit, harm, or causality.

## Matched documentation-opportunity outcomes

For each respiratory endpoint, airway definition, and `hospitalid x landmark` risk set, each generic source is ranked by its number of distinct endpoint-window offsets. Exactly as many rows are labeled positive as the respiratory endpoint has positives in that same risk set. Highest generic-offset counts are selected first; SHA-256 of the fixed seed, modality, respiratory endpoint, `sid`, and landmark breaks ties. Thus respiratory and control outcomes have identical row counts, hospital distribution, landmark distribution, and event prevalence. The matching never reads `label3`, any `broad_*` indicator, any classification-window process feature, or the original setting-reduction outcome.

This is deliberately a matched documentation-opportunity control, not a claim that a row promoted to match a high respiratory prevalence had an actual goal or note event. Because respiratory persistence is extremely prevalent, many matched-positive rows have zero generic events: depending on endpoint/bound, 792-2,910 for goal controls and 459-1,952 for note controls. The control asks whether the exposure predicts the most documentation-prone rows within a generic modality under an exactly aligned outcome margin; it does not redefine absence of a source event as presence.

Each control is evaluated on exactly the respiratory endpoint's eligible held-out hospitals. This avoids manufacturing specificity by changing the hospital set. Hospital counts and held-out rows remain those inherited from the parent: for `doc_any`, 22 hospitals/3,130 rows unbounded, 18/2,290 at 24h, 15/1,593 at 12h, and 13/1,019 at 6h; for `doc_repeated`, 26/3,256, 19/2,321, 16/1,624, and 14/1,050.

## Prespecified contrasts, uncertainty, and gates

The primary model contrast is broader minus process log loss; negative values favor the semantic indicator block. Specificity is the paired difference:

`(respiratory broader-minus-process) - (matched-control broader-minus-process)`.

Negative values mean a larger improvement for respiratory persistence. Both micro and equal-hospital macro points are required. In 250 replicates, stays are sampled with replacement within each fixed held-out hospital, repeated landmarks remain clustered, and the identical sampled clusters are applied to respiratory, goal, and note predictions. Predictions are fixed, as in the parent; uncertainty therefore reflects held-out stay composition, not model-fitting or new-hospital uncertainty.

A supportive respiratory-specificity result requires, for both respiratory endpoints in unbounded and at least two bounded definitions: respiratory broader-minus-process micro and macro points below zero with its paired-bootstrap 97.5th percentile below zero; and respiratory-minus-control micro and macro points below zero with the paired 97.5th percentile below zero for both generic controls. A semantic-expansion rescue separately requires stable broader-minus-exact evidence; that remains absent.

An adverse generic-propensity result requires, over the same endpoint/bound pattern, at least one generic control to show reproducible broader-minus-process improvement while respiratory does not reproducibly exceed both controls. Discordant endpoints, insufficient airway replication, or intervals crossing zero for specificity are inconclusive.

The adverse generic-documentation-propensity gate does not pass. This sharpens the parent's result: within the observed hospitals and matched documentation margins, the semantic indicator block's gain is specific to persistence in the respiratoryCharting export rather than a general tendency to have later care-plan-goal or note documentation.

## Meaning and limits

Supportive specificity means a purely generic later-documentation propensity is an inadequate explanation for the parent's respiratory-persistence gain under two temporally aligned, incidence- and risk-set-matched modalities. It motivates local interface/workflow review to learn why the exported Ventilation field forecasts respiratory-chart continuity. It does not show that any patient was invasively ventilated, evaluated daily, given an SBT, extubated, ready for liberation, helped, harmed, or managed at higher quality.

The result would be adverse if generic controls reproduced the gain and respiratory did not exceed them; that did not occur. It would be inconclusive if matched-control construction, fixed predictions, or new hospitals materially changed the contrasts. Goal and note exports are only two generic modalities and do not capture every possible charting workflow. Their sparse raw incidence forced many zero-event rows into prevalence-matched positive ranks, which makes this an opportunity-ranking falsification rather than an ordinary binary event comparison. Local interface metadata are required to establish whether fields were available, mandatory, copied forward, or selectively exported. Clinical adjudication and direct time-resolved device/SBT/extubation evidence are required for bedside meaning. New hospitals and nested refitting are required for stronger transport uncertainty.

An automatic verifier can check support and source hashes; exact columns, join keys, offsets, and window inequalities; complete source scan counts; 9,153-row filtering and zero respiratory row-count mismatches; raw outcome counts; exact hospital-by-landmark matched event margins; exposure-blind stable tie breaking; held-out hospital separation; model definitions; micro/macro loss contrasts; paired stay-cluster sampling; and whether reported conclusions obey the gates. It cannot verify bedside state, clinical intent, quality, benefit, harm, causality, interface semantics, or external transport.
