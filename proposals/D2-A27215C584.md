# D2-T1 successor: specificity of the intervention-associated macrophage response

## Question and clinical importance

The parent established a context-by-intervention question: does a macrophage transcriptional response differ when macrophages are exposed to synovial fibroblasts? The unresolved successor question is narrower and more consequential: is any intervention-associated macrophage response specific to a fibroblast-linked program, or is it generic macrophage stimulation, donor composition, or assay/feature artifacts? This matters because reciprocal stromal–myeloid signaling can sustain rheumatoid arthritis inflammation and may explain why a drug that appears effective in isolated macrophages behaves differently in the synovial microenvironment [K1]. Resolving specificity would inform whether therapeutic screening must include fibroblast-containing context and whether an apparent drug response is informative about a fibroblast-linked program or merely generic activation.

The hypothesis is observational: the intervention-associated transcriptional response is enriched in a fibroblast-linked program relative to a prespecified generic-stimulation/technical reference. The data do not establish direct target action, causal mediation, clinical efficacy, or a mechanism in vivo. A fibroblast-derived factor study supports context-dependent macrophage profiles [K2], and multicellular models support context-aware therapeutic testing [K3]; neither validates this dataset or proves efficacy.

## Specificity estimand and program construction

For each verified intervention and matched MT/MTF pair, define the macrophage intervention response as log2 fold-change from its corresponding control. Define the fibroblast-linked program before inspecting intervention effects: use a prespecified, frozen set of FLS-responsive features selected from the E-MTAB-8316 `condition=none` versus `UNC106238` contrast, requiring a minimum expression/coverage filter and a prespecified effect threshold; retain feature identities exactly and do not merge ambiguous GSE95588 labels. If no prespecified set is available, derive the component only from the FLS dataset, freeze it before macrophage analysis, and report its feature list. The generic reference is an unstimulated/context control and/or a prespecified broad macrophage activation signature, constructed with the same normalization and feature-selection rules and without using the intervention effect. The primary specificity estimand is the difference in intervention response between the frozen fibroblast-linked program and this generic reference, within donor/condition dependence units. Report both context contrast (MTF minus MT) and specificity contrast with donor-aware uncertainty.

## Baseline and substantive alternative

Simple baseline: estimate each intervention’s MT and MTF response separately, then compute paired context and specificity contrasts using a donor/condition-blocked paired test or permutation. Use the same feature set, normalization, and control definition for both assays. This directly answers whether the observed response is enriched in the fibroblast-linked program relative to generic stimulation.

Substantive alternative: fit a joint hierarchical model of intervention, context (MT versus MTF), program (fibroblast-linked versus generic reference), donor/condition random effects, and an intervention-by-context-by-program interaction, with shrinkage across interventions and genes and a prespecified negative-control program (generic activation or ambiguous/technical features). It can reveal a shared context-dependent program or intervention-specific reversal that the baseline loses. Evaluate with donor-blocked cross-validation, uncertainty intervals, and held-out prediction of the context-specific contrast; compare interaction and specificity estimates, not merely overall predictive accuracy. CPU is sufficient for the small tabular fits; no GPU is required.

## Interpretation and falsification

- Supportive: a reproducible specificity contrast with uncertainty excluding the prespecified null, consistent direction across available donors/conditions, and greater contrast than the generic reference and negative-control/ambiguous-feature checks. This supports a context-specific transcriptional association, not direct target action.
- Adverse: no specificity contrast, disappearance after donor/condition and feature-identity checks, or a comparable generic response. This weakens the fibroblast-linked specificity claim; it does not prove drugs have no context effects in vivo.
- Inconclusive: unresolved GSE95588 donor/GSM mapping, insufficient matched contrasts, high uncertainty, or contradictory assay-specific results. This motivates metadata repair or a new donor-resolved experiment rather than a negative biological conclusion.

## Limitations and next evidence

E-MTAB-8316 is FLS readout after macrophage pretreatment, whereas GSE95588 is macrophage readout; cross-dataset claims must remain assay/context-specific. GSE95588 donor identity is unresolved, so donor-aware inference is gated on verified GSM-to-column mapping. Ambiguous feature-map rows must remain distinct and cannot be merged. No wet-lab target validation, clinical outcome, or direct mechanistic perturbation is available. A supportive result would justify a donor-resolved experiment with direct target perturbation and clinical readouts; an adverse result would redirect screening toward isolated macrophage effects or other mechanisms.

## Method comparison and actual deliverable

The baseline is a transparent, paired donor-aware contrast of intervention response in MT versus MTF and against the frozen generic reference. The alternative is a hierarchical interaction model that borrows information across interventions and genes and can distinguish a shared fibroblast-linked program from intervention-specific reversal, information the baseline loses. The future solver must newly fit both, report the interaction and specificity estimates with uncertainty, evaluate held-out donor-blocked predictions, and report whether the fibroblast-linked program is distinguishable from generic stimulation and technical controls. This is an adaptation, not a reproduction of any demonstration paper.
