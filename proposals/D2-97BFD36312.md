## 1. Unresolved question (the opening)

The island has repeatedly established, per-FLS-cell, that a MerTK/CD206pos (MRC1+) macrophage coculture is associated with a lower RA FLS effector readout than a CD206neg coculture, using a specificity control (F1 non-effector set) and an ambient-RNA control (F2). Every version of that test is **observational**: it contrasts a state (CD206pos vs CD206neg macrophages) that could also be explained by static composition (the two macrophage preparations differ in more than MerTK), by donor/state selection, or by preparation handling, with no perturbation that must move the FLS readout if the brake is causally MerTK-dependent. The island leader's own recorded weakness is a single-FLS-donor ladder for the discriminating contrast.

The unresolved claim tested here: **is the CD206pos-macrophage suppression of the RA FLS effector program MerTK-pathway dependent**, i.e. does pharmacologic MerTK inhibition of the CD206pos macrophage *release* the FLS effector program toward the CD206neg-coculture state, reproducibly across independent FLS donors within the same donors where both a CD206pos-brake magnitude and an inhibitor arm exist?

- Leading claim (H_brake): the suppression is an active, MerTK-dependent brake; inhibiting MerTK in the CD206pos macrophage releases the FLS effector program.
- Strongest rival (H_compose): the CD206pos/CD206neg FLS difference is a static composition/state or handling correlation, so MerTK inhibition need not systematically release it, and any change is shared with a generic stimulus (the preLPS arms).
- Observation that separates them: within the same FLS donor, the paired per-cell FLS effector response to MerTK-inhibitor pre-treatment of CD206pos macrophages (Δ_inhib), compared with (i) the CD206pos→CD206neg brake magnitude already observed (Δ_brake) and (ii) the response of a matched non-effector gene set and the preLPS stress arms.

## 2. Why this is consequential

If the brake is MerTK-dependent, MerTK/TAM signaling is a *target* whose pharmacologic engagement can restore resolution-program access in the RA joint — turning an association into an actionable perturbation hypothesis (relevant to the "resolution-restoring" therapeutic direction). If it is not (Δ_inhib ≈ 0 or fully non-specific vs preLPS/F1), the island's central claim narrows to a state correlation and the MerTK-target rationale weakens. Both outcomes are informative and change the next decision (proceed to orthogonal protein/efferocytosis assay vs park the MerTK-brake branch).

## 4. Population, estimand, analysis

- Unit: FLS-donor paired sample (n = 4 Mpos inhibitor pairs over 3 FLS donors). Repeated contexts within donor are averaged first; no independent-donor (n=12) claim; dependence modeled by FLS donor and shared macrophage donor (SA259A/SA266A appear in multiple arms) — treat donor as a random effect / use donor-level pairing, not an ordinary t-test.
- Effector score: pre-registered RA FLS effector set (e.g. inflammatory/protease/cytokine genes present in the 445-feature panel — fixed before looking at the inhibitor contrast; e.g. CXCL/IL/MMP-family members present). Recorded explicitly with the panel-derived gene list at analysis time.
- Δ_inhib = effector(Mpos_Inhibitor) − effector(Mpos), per FLS donor.
- Δ_brake = effector(Mneg) − effector(Mpos), per FLS donor (island's established brake magnitude).
- Baseline (simple): pseudobulk mean difference vs the CD206neg state.
- Substantive alternative: per-donor paired, ambient-adjusted (F2) effect with a donor random effect and a matched non-effector control set (F1), i.e. the *specificity-controlled* alternative. The learned/mechanistic alternative adds what the baseline loses: it separates a MerTK-pathway release signal from (a) a global shift of all transcripts (composition/handling) and (b) a generic inflammatory stress response (preLPS).

## 5. Falsification criteria (pre-registered)

Supportive (H_brake): Δ_inhib shares sign with Δ_brake and recovers a substantial fraction of it in ≥2 of 3 FLS donors, while the F1 non-effector set does not move comparably and the LPS stress arm is distinguishable (different sign/magnitude profile).
Adverse (H_compose favored): Δ_inhib ≈ 0 across donors, or the F1 non-effector set moves as much as the effector set, or the preLPS arm reproduces the effector release equally strongly (non-specific).
Inconclusive: inconsistent donor directions, or effector and non-effector sets indistinguishable within the small donor count, or panel lacks the required effector genes to score.
Falsifiers are exact and computable from the matrix; a reference solution is optional.
