# Does one leakage-safe intermediate albumin or bilirubin value improve the near-term laboratory forecast beyond current state, a remote anchor, and measurement intensity before repeat TACE?

## Clinical question, supported evidence, and unresolved hypothesis

For an adult already selected for a recorded first repeat TACE, test whether reviewing one additional leakage-safe same-assay value from the interval since TACE2 improves prediction of the next observed albumin or total-bilirubin value after the model already knows the current pre-repeat value `P`, the remote pre-TACE2 anchor `B`, compact pre-event covariates, and whether, how often, and how recently that assay was measured.

Longitudinal liver-function state is clinically relevant to retreatment assessment, but neither available literature nor this dataset establishes that a single intermediate value adds information once the current value and measurement process are known. The strongest evidence currently supported is feasibility: complete-source, outcome-direction-blind audits reconstructed the cohort and found adequate assay-specific triplets and leakage-safe intermediate values. No outcome direction, predictor-outcome association, or model performance was inspected.

The unresolved falsifiable hypothesis, separately for exact assay labels `Albumin` and `Total Bilirubin`, is:

> Adding the latest eligible intermediate numeric value `L` reduces out-of-sample RMSE by at least 0.05 outcome SD relative to an otherwise identical observation-process-aware model without `L`.

This is a prognostic information experiment. It does not test whether an assay should be ordered, whether repeat TACE should proceed, toxicity, hepatic failure, treatment benefit, or clinical utility.

## Parsimonious paired experiment

Per assay use all triplets, including `H_any=0`:

`M_obs: Y ~ P + B + arm + age + sex + TACE2_to_repeat_days + P_lead_hours + H_any + logN + R_hours`

`M_value: Y ~ P + B + L + arm + age + sex + TACE2_to_repeat_days + P_lead_hours + H_any + logN + R_hours`

where `TACE2_to_repeat_days=(event_day-tace2_day)` and `P_lead_hours=(event_time-P_time)`.

Use deterministic leave-one-patient-out cross-fitting. In each held-out iteration, preprocess using training patients only and fit OLS with an unpenalized intercept:

1. Numeric age is training-median imputed. Define age-missing, literal female, and sex-unknown indicators. Literal `male` is reference; unknown includes every value other than literal `male` or `female`, including missing.
2. For `H_any=0`, training-median impute `R_hours` using observed (`H_any=1`) training values and impute `L` using observed training `L`; if either observed training set is empty, stop computationally inconclusive.
3. The shared candidate columns are `P,B,arm,age,age_missing,female,sex_unknown,TACE2_to_repeat_days,P_lead_hours,H_any,logN,R_hours`. Before scaling, drop any non-intercept shared column with zero/nonfinite training SD from both models. `L` is the sole added candidate in `M_value`; if imputed `L` has zero/nonfinite training SD, stop computationally inconclusive rather than silently making models identical. This rule resolves any zero-variance measurement feature while preserving that the fitted models differ only by `L`.
4. Center and scale all retained continuous/binary predictors using the training mean and population SD (`ddof=0`). Apply those parameters to the held-out patient. Require both post-drop training matrices, including intercept, to be full column rank and all values finite; otherwise stop.
5. Fit by QR/lstsq with fixed rank tolerance `max(n,p)*eps*largest_singular_value`; require reported rank equal to column count. No feature selection, regularization, alternate algorithm, nonlinear term, interaction, or arm-specific effect.

The sole primary estimand is `Delta_value=[RMSE(M_obs)-RMSE(M_value)]/sample_SD(Y,ddof=1)`, using paired pooled LOOCV predictions and one full-cohort SD. Report native RMSE/MAE, standardized `Delta_MAE`, cross-fitted R-squared, prediction variance, calibration intercept/slope, arm-stratified descriptive errors, and patient-level paired squared-error contributions. Coefficients are descriptive only.

## Uncertainty and falsification

1. **Paired bootstrap:** use NumPy `Generator(PCG64(20260910))`. For each of 2,000 replicates, independently sample with replacement `n_arm` indices within each arm from frozen tuples `(arm,Y,pred_obs,pred_value)` and concatenate arms in systemic-then-comparator order. Recompute RMSEs, sample SD, and delta. Skip only zero/nonfinite-SD replicates; require >=1,900 estimable. Report 2.5/97.5 percentiles using NumPy linear quantiles and one-sided `(1+#delta<=0)/(1+#estimable)`. Holm-adjust the two assay p-values for assay-family claims. This is conditional fixed-prediction uncertainty.
2. **Linkage destruction:** among `H_any=1`, within each arm separately, permute only observed `L` values; preserve all other fields and rerun exact LOOCV. If an arm has 0 or 1 eligible patient, leave it unchanged and report it; if fewer than two patients are permutable across all arms, the linkage check is non-estimable and favorable evidence is linkage-inconclusive. Generate 500 permutations sequentially with a fresh `Generator(PCG64(20260911))`; support requires observed delta strictly above the NumPy linear 95th percentile.
3. **Missing-history sensitivity:** rerun identical LOOCV in `H_any=1` only. A favorable all-triplet estimate whose sensitivity reverses sign is missing-history-inconclusive.
4. **Triplet observation selection:** among all selected repeat-event patients, deterministic folds are assigned separately within arm by sorting `SHA256("hcc-repeat-tace-triplet-observation-v1|"+assay_label+"|"+patient_key)` and rank modulo five. In each outer fold fit unpenalized binomial logistic regression with intercept and fixed predictors arm, numeric age, age-missing, female, sex-unknown, TACE2-to-repeat days, and event year. Apply training-only median imputation, shared zero-variance dropping, and scaling as above. Optimize negative log likelihood by Newton/IRLS for at most 100 iterations, clipping probabilities to `[1e-8,1-1e-8]`; converge when maximum absolute coefficient change `<1e-8` and maximum absolute score `<1e-6`. A singular Hessian, separation/nonconvergence, or nonfinite prediction makes this sensitivity non-estimable and any favorable result selection-inconclusive. Stabilized weights among triplets are `Pr(O=1 within arm)/p_hat`, truncated to the empirical 1st/99th percentiles using NumPy linear quantiles and rescaled to mean one. Recompute weighted paired RMSE and weighted outcome SD. Report probability range, weight concentration, maximum share, and arm ESS. Favorable evidence is selection-inconclusive if systemic ESS<30, comparator ESS<80, one patient has >10% total normalized weight, weighted delta reverses sign, or absolute weighted-unweighted difference >0.05. This MAR diagnostic cannot recover missing outcomes or remove collider bias.
5. **Timing sensitivities:** repeat with (a) `P` latest in `[event_time-48h,event_time)` and (b) `Y` first eligible in `(event_time,event_time+72h]`, rebuilding triplets and H. A favorable result is timing-inconclusive if an empirically distinct variant retains >=75% of primary patients and reverses sign.
6. **Influence:** using frozen primary LOOCV predictions, recompute aggregate delta after deleting each patient. A favorable result is influence-inconclusive if any deletion reverses sign or changes delta by >0.05.
7. **Repeat/triplet selection:** report 319/1,491 to 159/526 and stage availability. Do not weight to patients without a repeat event because the endpoint is undefined.

## Ordered interpretation branches

Apply separately by assay; sensitivity gates only downgrade favorable claims and never convert adverse/null results into support.

1. **Reconstruction-inconclusive:** snapshot/hash/source/column mismatch; unexplained failure of eligible-base, exclusion-category, pathway, event, triplet, parser/duplicate, or primary history-support gates; join multiplication; or clock/leakage violation. Stop inference; do not tune ontology or widen windows.
2. **Computationally inconclusive:** LOOCV preprocessing/rank/variance/OLS fails, SD(Y)=0, or fewer than 95% bootstraps are estimable.
3. **Fragile favorable/inconclusive:** point estimate is favorable but linkage, missing-history, selection, timing, or influence rule fails or is non-estimable as specified. Name the mechanism and retain the conditional estimate.
4. **Adverse degradation:** prior computational gates pass and the 95% interval lies wholly below zero. Conclude only that adding `L` worsened generalization under this locked model.
5. **Supportive numeric-history evidence:** prior gates pass; delta>=0.05; unadjusted 95% interval excludes zero; Holm-adjusted one-sided p<0.05; standardized Delta_MAE>=0; observed delta exceeds the linkage 95th percentile; and no favorable-result fragility gate fails. Conclude only that this one prespecified leakage-safe numeric value adds reproducible short-horizon prediction in selected observed repeat-TACE episodes.
6. **Precise null for the design-sized increment:** prior gates pass and interval upper bound <+0.05. Conclude that this design rules out a gain of 0.05 standardized RMSE under the model and conditional uncertainty convention, not all history effects, biology, equivalence, or a recommendation to omit testing.
7. **No demonstrated numeric-history increment:** point estimate <0.05 or linkage permutation is comparable, without a wholly adverse or precise-null interval. State that `P`, `B`, and/or observation-pattern information may exhaust available signal.
8. **Inconclusive:** interval spans both meaningful degradation and +0.05 or a remaining prescribed ambiguity exists.

A two-assay supportive statement requires both assays to meet branch 5 after Holm correction. Discordant assays are separate. The 0.05 margin is a design convention, not a validated clinically important difference.

## Clinical and verifier limits

HCC lacks laboratory units/reference ranges and analyzer harmonization, adjudicated hepatic decompensation or complications, Child-Pugh/MELD context, tumor burden/radiographic response, technical TACE success or intent, albumin infusion/transfusion/fluid balance, infection/bleeding, verified drug administration/adherence/dose, outside care, and reliable mortality. `Y` is a clinician-timed observed assay, not toxicity, failure, benefit, disposition, or utility; repeat-event and triplet conditioning may induce selection/collider bias.

A verifier can check source hashes and columns, full scans, exact ontology precedence, population/event reconstruction, parser/duplicates, clocks, preprocessing, LOOCV, uncertainty, sensitivities, and ordered branch logic. It cannot establish clinical importance, causal treatment effects, toxicity, mechanism, administration, decision utility, or policy. Stronger claims require unit-validated assays, adjudicated actionable outcomes, fuller clinical context, complete follow-up, external/prospective validation, and expert decision-utility review.
