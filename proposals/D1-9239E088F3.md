# Positive nuisance-refit bootstrap repairs the observation-identification uncertainty gap without changing the target

## Question and substantive advance

This child repairs `[prior hypothesis]` by quantifying uncertainty for the already-frozen hospital-held-out pattern-mixture comparisons. It does not change the target-independent population, temporal boundaries, four airway definitions, competing-state precedence, all-row scoring task, delta grid, outcome, or documentation-only semantics. The unresolved question remains whether post-classification observation departures could overturn the apparent lack of predictive rescue from exact or broader care-plan encodings. The advance is a positive, explicitly accounted nuisance-refit stay-cluster bootstrap rather than the parent's zero-replicate feasibility path.

The strongest pre-existing evidence remains that, at the observed-receipt / delta-0 reference, exact and broader care-plan encodings do not improve hospital-held-out prediction of the structured respiratory-chart reduction over process controls. Point-estimated favorable reversals at positive deltas remain assumption-dependent and do not identify missing chart outcomes. This repair tests uncertainty around those comparisons; it does not establish ventilation, SBT, extubation, liberation, benefit, harm, quality, or causality.

## Frozen data binding and algorithm

The read-only eICU bindings are unchanged: `carePlanGeneral.csv.gz` (`patientunitstayid`, `cplitemoffset`, `cplgroup`, `cplitemvalue`) joined to the derived stay key `sid`; `respiratoryCharting.csv.gz` (`patientunitstayid`, `respchartoffset`, `respchartentryoffset`, `respcharttypecat`, `respchartvaluelabel`, `respchartvalue`) joined on `patientunitstayid=sid`; and `patient.csv.gz` (`patientunitstayid`, `hospitalid`, `unitdischargeoffset`, `unitdischargestatus`, `unitdischargelocation`) joined on `patientunitstayid=sid`. The complete catalog schemas are `datasets/eicu/table-33b82ae7a5609587.json`, `datasets/eicu/table-339bf06c7eef27e0.json`, and `datasets/eicu/table-ab037c09d7df9a3c.json`; each source is the ordinary file archive member documented in `datasets/eicu/README.md`.

The frozen derived input is `observation_competing_state_rows.csv`, [source checksum], with 9,153 classification-complete rows, keyed by `definition,sid,landmark`. The first qualifying ICU stay per person, landmarks 1,440/2,880/4,320/5,760/7,200 minutes, classification window `[L,L+360]`, later chart window `(L+360,L+1080]`, and the eight-value ventilation vocabulary are inherited unchanged. State precedence remains `icu_death`, `live_icu_discharge`, `complete_computable_outcome`, `still_adequate_chart_no_paired_outcome`, `still_sparse_no_respiratory_documentation`. Death and live discharge are excluded from the binary latent chart-proxy estimand and receive no fabricated clinical outcome.

For each definition and delta in `[-3,-2,-1,0,1,2,3]` log-odds units, complete rows retain the inherited binary structured respiratory-setting reduction. Missing rows receive the observed complete-row rate within receipt class, with definition-wide fallback, shifted by delta. Process, exact, and broader logistic nuisance models are refit with fractional labels in each leave-one-hospital-out fold, using only other hospitals. The reported estimands are hospital-macro and row-micro added-model-minus-process expected log-loss contrasts; positive means the added model is worse.

The bootstrap resamples stays with replacement within each fixed eligible held-out hospital, keeps the eligible hospital list fixed, then refits every process/exact/broad nuisance model in every LOHO fold for every replicate. It uses B=10 positive replicates, seed 20260911 with the inherited definition/delta offsets, and records requested, successful, and failed counts. This is a bounded feasibility uncertainty analysis, not a high-precision inferential interval.

## Computation and results

Executable repair: `pattern_mixture_refit_bootstrap.py`. Derived result: `pattern_mixture_refit_bootstrap_results.json`, [source checksum]. All requested bootstrap replicates completed: 10/10 successful and 0 failed for every executed contrast; no replicate was silently dropped. Bootstrap was run at delta 0 for all four definitions and at every delta for the 6-hour definition to characterize tipping. The all-row multinomial observed-state score was recomputed unchanged.

At delta 0, the point broader-minus-process macro contrasts were +0.000483 (unbounded), +0.001804 (24-hour), +0.002322 (12-hour), and +0.005833 (6-hour). ## Interpretation and limits

Supportive of the repair: every requested replicate succeeded, delta-0 point estimates and interval behavior are now available, and the adverse/near-null delta region is not a bootstrap artifact at the stricter definitions. Adverse to a rescue claim: delta 0 remains positive for all broader comparisons, and favorable reversals appear only after imposing positive untestable missing-outcome departures; +1 intervals overlap zero. Inconclusive: B=10 percentile intervals are intentionally rough and cannot settle small contrasts, especially unbounded and 24-hour delta 0; a larger prespecified bootstrap would be needed for stable interval estimation.

Computationally checkable claims are the exact source paths, table columns, joins, time windows, frozen hash, row/state counts, state precedence, fractional-label algorithm, fixed-hospital LOHO separation, resampling unit, nuisance refitting, replicate accounting, log-loss contrasts, and interval arithmetic. Clinical adjudication or additional data are still required to establish whether any respiratory-chart value represents invasive ventilation, bedside assessment, SBT, extubation, readiness, liberation, or documentation failure; claims about benefit, harm, quality, causality, or transport require device events, workflow/interface metadata, severity and treatment context, adjudication, and external/prospective validation.
