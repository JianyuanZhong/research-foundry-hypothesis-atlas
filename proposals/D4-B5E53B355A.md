# Cross-disease association breadth of UKB-Olink plasma proteins: a generic severity/ageing marker or a disease-specific signal? (episode 3, branch gen-branch-1)

Parent: [prior hypothesis] (episode 3, valid, mu 31). Operation: evolve.
Complementary falsifiable branch on the SAME question family as the parent ("do shared
systemic-inflammatory/ageing axes explain 'disease-specific' plasma-protein signals").
This branch does **not** copy the parent's latent-factor attenuation design; it tests a
different, separable prediction: whether a protein's **cross-disease association breadth**
is explained by a protein-specific biological axis, by **chronological/nonlinear age alone**,
or by neither. Status: design + data bindings verified; **no association results claimed**.

## 1. Scientific opening, leading claim and strongest rival

Observed regularity (from inspected work): plasma-protein levels encode many health states
at once and show strong shared age structure [K1, K3]; organ-specific protein ageing predicts
organ-matched diseases, while a minority show accelerated multi-organ ageing [K2]. The
unresolved question for a *specific* protein that predicts many different incident diseases
is: does its **breadth** carry information beyond a generic systemic-ageing/severity axis?

- **Leading claim (H_generic).** Broad cross-disease association breadth is a generic
  severity/ageing correlate: after flexible age adjustment **and** removal of a shared
  protein-matrix axis estimated leave-one-protein-out (LOO), most breadth collapses.
- **Strongest rival (H_specific).** Breadth reflects a protein-specific biological axis whose
  cross-disease prediction survives age-spline adjustment and LOO-axis removal.
- **Second rival (H_age).** Breadth is *entirely* chronological age (linear or nonlinear);
  a flexible natural-spline age adjustment alone removes it, and the LOO axis is redundant.

These separate on a concrete comparison (Section 4): the number of incident diseases a
protein predicts after (a) age+sex linear adjustment (baseline), (b) age-spline (4 df) + sex,
and (c) age-spline + sex + LOO shared axis.

**Circularity fix inherited from the parent critique.** The parent estimated a shared axis
from the same proteins being tested. Here the shared axis used to adjust protein *p* is the
first principal component (PC1) of the protein matrix computed with **protein p held out**, so
the adjustment for p never contains p. This is the substantive methodological repair.

**What the alternative reveals that the baseline loses.** A per-protein age+sex association
count loses the multivariate shared structure: two proteins can have equal breadth yet one is
mostly a proxy for the cohort-wide ageing component while the other adds disease-specific
information. The LOO-axis model separates (i) breadth attributable to the cohort shared axis,
(ii) breadth attributable to nonlinear age, and (iii) residual protein-specific breadth — three
quantities the single-protein baseline conflates. This is not a chase for a small predictive
gain: the estimand is the **decomposition of breadth**, and it changes the interpretation of
any "disease-specific" protein hit.

## 4. Baseline vs substantive alternative (same question, comparable specifications)

- **Baseline (per-protein, age+sex linear).** For each protein *p* and disease D, fit logistic
  regression `case_D ~ z(p) + age + sex`; count `B_lin(p)` = number of diseases with
  FDR-significant association (BH across all p×D tests, q<0.05). This is what "breadth" usually
  means and the current standard.
- **Age-flexible alternative.** Repeat with `case_D ~ z(p) + ns(age, df=4) + sex`; count
  `B_spline(p)`. Directly tests the **strongest rival H_age** (breadth = nonlinear chronological
  age).
- **LOO shared-axis alternative.** Compute PC1 of the standardized protein matrix on the
  analysis set **with protein p held out** (leave-one-protein-out); repeat the spline model
  adding `PC1_{-p}`; count `B_loo(p)`. Tests H_generic vs H_specific without circularity.
- **Targets**: per-protein breadth counts `B_lin`, `B_spline`, `B_loo` (integers 0–10); primary
  estimand = the attenuation distribution `(B_lin - B_loo)/B_lin` across the set of broadly
  associated proteins (baseline `B_lin ≥ 3`), and the fraction of those proteins that remain
  broadly associated (`B_loo ≥ 3`) vs collapse (`B_loo ≤ 1`).
- **Split / leakage control**: estimate the normalization and PC1 on a random 70% protein/
  participant-derivation split but evaluate associations on the 30% held-out fold (out-of-fold
  estimates). If row counts are limiting, use participant-level 5-fold out-of-fold scores with
  the LOO-protein PC and report the fold with lowest power. All estimates use out-of-sample
  protein scores to avoid optimistic leakage.
- **Baseline justification**: simple, interpretable, and it is what most screens report; the
  LOO-axis model is scientifically necessary because the question is explicitly about shared
  versus protein-specific structure, which the single-protein baseline cannot represent.
- **Positive and negative controls (required).** (i) *Positive*: GDF15 (and, if present, IL6,
  CRP-family members) must show the largest `B_lin` — a sanity check that the pipeline recovers
  known broad markers. (ii) *Negative*: a random half of proteins permuted across participants
  must yield breadth indistinguishable from chance (≈ FDR-level false positives only), and a
  known organ-restricted marker (e.g. a cardiac-specific protein for D3) should show narrow,
  not broad, breadth. Controls are pre-registered; failure invalidates the run, not the hypothesis.

## 5. Multiplicity, uncertainty, analysis

- Multiplicity: BH-FDR q<0.05 per protein×disease family (baseline, spline, LOO models each
  controlled separately; report raw and FDR counts). Breadth counts use FDR-significant cells
  only.
- Uncertainty: **10,000 participant-level bootstrap resamples** (block bootstrap by assessment
  centre if stratum sizes permit) to obtain CIs on `B_lin`, `B_spline`, `B_loo` and on the
  attenuation fraction. Report 95% CIs; no point estimate without CI.
- Pre-specified primary contrast: the attenuation fraction `(B_lin - B_loo)/B_lin` for proteins
  with `B_lin ≥ 3`, compared against a **permutation null** that shuffles protein labels across
  the protein matrix (preserving the protein-level covariance among the shuffled set only for
  the negative control; the axis permutation preserves D outcomes).

## 6. Falsification criteria (supportive / adverse / inconclusive)

- **Supportive of H_generic** (shared/ageing axis dominates): median attenuation ≥50% AND
  majority of broadly-associated proteins drop to `B_loo ≤ 1`; the age-flexible model shows a
  large drop from `B_lin` to `B_spline`.
- **Adverse to H_generic (supports H_specific)**: median attenuation <20% AND majority retain
  `B_loo ≥ 3`; LOO axis adds no breadth loss beyond the spline.
- **Supportive of H_age (rival wins)**: `B_spline` collapse is large while `B_loo` adds little
  beyond `B_spline` (LOO increment ≈0), i.e. the shared axis is largely chronological age.
- **Inconclusive / not refuted**: wide bootstrap CIs overlapping both thresholds, or a disease
  block under-ascertained (<150 cases) driving the breadth count. An imprecise null does **not**
  refute specificity.

Continue/revise/stop: if H_age wins cleanly, the "shared sickness axis" framing should be
revised to an age axis and the direction deferred/stopped pending richer ascertainment; if
H_generic wins, proceed to a validation study in an independent proteomic cohort; if
inconclusive, add outpatient/GP ascertainment before any specificity claim.

## 7. What would NOT be established

- Association breadth and its attenuation are **not** mechanism, and LOO-axis attenuation is
  **not** proof of reverse causation or of a physiological "sickness axis".
- The 41270/41280 arrays encode **first-occurrence inpatient diagnoses only**; outpatient/
  primary-care (41271/41272, GP records) are absent, so incidence is under-ascertained and
  breadth is biased downward for diseases managed mainly in primary care. This is a measurement
  limitation requiring clinical adjudication, not computable from the bound tables.
- BMI/smoking/ethnicity/alcohol are present in the assessment-centre parquet (verified), but
  they are covariates that may be on the causal path; they are **not** used to define the primary
  estimand, only reported in a sensitivity model. Townsend (`189`) is absent from the bound files.
- Confirmatory claims require external replication, outpatient ascertainment, and expert clinical
  review — none of which this bound dataset alone can supply.

## 8. Feasibility and budget (discovery estimates vs solver envelope)

- 53k participants × 2,923 proteins × 10 diseases ≈ 29k logistic fits per model × 3 models +
  10,000 bootstraps. Matrix ops ~O(53k×2,923); a bounded pilot is minutes on CPU. Primary fit is
  CPU-feasible; the LOO PC over 2,923 held-out proteins reuses one covariance/SVD each, cacheable.
- Solver planning envelope (from inputs.json): 16 cpus / 8 GPUs / 262,144 MB / 28,800 s. GPU not
  required for the primary fit; 1 GPU slot only if repeated bootstrap fits dominate. These are
  estimates, **not measured** at delivery time; a bounded diagnostic remains to be run by the solver.
