# Target-linked discharge documentation and workflow falsification layer

## Status, scope, and inheritance

This is a single targeted successor to `[prior hypothesis]`. It is a binding amendment, not a replacement protocol. Every parent rule about the pulmonary population, first-eligible all-opportunity denominator, index chronology, exact atomic evidence and route predicates, canonical discharge artifact, unit-specific clocks, route-blinded split panels, all-unit adverse routing, positive-probability audit, finite-population inference, and the prospective-silent-only conclusion ceiling remains unchanged. If this document is less specific than the parent, the parent controls. No threshold below may be used to redefine eligibility, an atom, a route, or the parent estimand.

The amendment asks one narrowly bounded question: among the parent's already-defined eligible report opportunities, does a route-positive versus route-negative assignment have a reproducible, target-linked downstream discharge-documentation signal? This is an observable workflow/documentation proxy, not a clinical outcome and not a test of appropriateness, safety, completion, or benefit.

## Unresolved claim and falsifiable hypothesis

Existing text routing can show reproducible agreement or conservative compatibility with audited labels, but agreement does not establish that a routed finding is carried into a discharge workflow. The unresolved claim is that a passing text-only pulmonary route identifies opportunities more likely to receive target-linked discharge documentation after the index report.

**H1 (falsifiable):** in the frozen parent population, after fixing the parent's route assignment, the finite-population difference

`Delta = P(Y=1 | parent route is positive) - P(Y=1 | parent route is negative)`

is greater than 0.05, where `Y` is the frozen downstream documentation proxy below. The primary comparison is descriptive and does not identify a causal effect of routing; route-positive and route-negative opportunities may differ clinically.

The primary result must also pass a specificity control: the same contrast for a temporally downstream but target-unrelated discharge workflow marker must have absolute value no greater than 0.05. Failure of that control falsifies the interpretation that any observed association is target-linked rather than general documentation intensity or admission selection.

## Frozen documentation proxy

Before opening any route summary or outcome file, hash and seal this dictionary and the exact implementation. Matching is case-insensitive after Unicode normalization, whitespace collapsing, and punctuation normalization; negation is not inferred by a model. The proxy is positive only if all three components occur in the canonical discharge text:

1. A target mention: a pulmonary/imaging target token already defined by the parent's atom dictionary, or its exact parent-approved canonical synonym, occurring in the **IMAGING/PERTINENT RESULTS/HOSPITAL COURSE** sections. Do not add synonyms here.
2. An action or status phrase: one of the frozen exact phrase families `follow[- ]?up`, `repeat (?:imaging|ct|x[- ]?ray|radiograph)`, `outpatient (?:pulmonary|respiratory|clinic)`, `return precautions`, `pending (?:study|result|results)`, or `recommend(?:ed|ation)` within 500 characters after the target mention or within the same section.
3. A disposition anchor: one of the exact section headers or fields `FOLLOW[- ]?UP`, `DISCHARGE INSTRUCTIONS`, `PENDING RESULTS`, `OUTPATIENT`, or `DISPOSITION`.

Section extraction uses the parent's canonical artifact parser if one exists; otherwise use headings consisting of an all-capital line after trimming. If no qualifying section can be parsed, `Y=NA` rather than zero. A target mention inside a negation window beginning with `no`, `without`, `negative for`, or `rule[d]? out` and ending at the next sentence boundary is not counted. This conservative string rule is deliberately not a clinical adjudication.

The positive value means only “the discharge artifact contains this reproducible textual pattern.” It does not mean the recommendation was correct, reviewed, completed, communicated, or beneficial.

## Frozen negative control and workload ledger

The negative-control outcome `C` is a general discharge-workflow marker: the same canonical artifact must contain both `MEDICATIONS` (or `DISCHARGE MEDICATIONS`) and `ACTIVITY` (or `DIET`) section anchors. It uses no pulmonary tokens and is evaluated with the same timestamp, section, missingness, and normalization rules. It tests whether route status merely tracks verbose or complete discharge summaries. No control is selected post hoc.

The amendment adds **zero human review workload** and no new patient sampling. The exact computational ledger is fixed before execution:

`W = N_parent_eligible + N_parent_route_positive + N_parent_route_negative + N_Y_missing + N_C_missing + 2,000 permutation rows`,

where each quantity is a count emitted by the one-pass manifest, and the `2,000` rows are generated with a fixed seed `271828` by independently permuting route labels within `(anchor_year_group, discharge_location, canonical-note-availability)` strata, preserving each stratum's positive count. If fewer than 2,000 valid permutations exist, enumerate all valid permutations and record that fact; never top up with replacement. The permutation is a diagnostic null, not a replacement for the parent inference. No route or outcome summary is opened before the manifest and protocol hash are sealed.

## Analysis and numerical gates

Use the parent's exact finite-population interval method and compatible-set handling for the primary route contrast; do not substitute a model-based probability or a conventional asymptotic CI. Report counts, denominators, missingness, `Delta`, two-sided 95% interval, and the complete route-by-stratum ledger. The permutation diagnostic reports the fraction of valid permutations with an absolute contrast at least as large as observed and its 95% Monte Carlo interval (or exact enumerated result).

A documentation layer is **computationally passing** only if all gates hold:

* at least 0.90 of parent-eligible opportunities have nonmissing `Y` and at least 0.90 have nonmissing `C`;
* the primary 95% interval lower bound for `Delta` is greater than 0.05;
* the 95% interval for the control contrast is contained in `[-0.05, 0.05]`;
* at least 1,000 valid fixed-seed permutations are available and the permutation-tail estimate is below 0.05.

It is **adverse/falsifying** if documentability is at least 0.90 but the primary interval upper bound is at most 0.05, or if the control interval lies outside `[-0.10, 0.10]`, or if the observed primary contrast is no larger than the 95th percentile of the fixed permutation null. It is **inconclusive** if documentability is below 0.90, fewer than 1,000 permutations are available, or none of the passing/adverse conditions is met. These labels are reporting states, not validity scores.

A passing result supports only that the parent route status is associated with this target-linked textual proxy under the frozen retrospective chronology. An adverse result argues against that association or against the proxy's specificity. An inconclusive result identifies missing timestamps, unavailable artifacts, or insufficient separability. No result supports a claim of clinical appropriateness, safety, workflow completion, communication, adherence, or benefit; those require timestamped order/task logs, clinician/patient adjudication, and preferably prospective silent deployment.

## Falsification, leakage, and sensitivity checks

The pipeline must fail closed if a downstream artifact is used to choose the canonical parent artifact, derive route features, tune phrase families, or set thresholds. Route labels are read from the sealed parent output, not recomputed using downstream text. The primary analysis is repeated excluding cases where `discharge.storetime <= index.storetime` (these are already `Y=NA` in the primary definition) and stratified by discharge destination; this is a sensitivity description, not a new estimand. A second implementation must reproduce `Y` and `C` from the same frozen dictionary on a blinded hash-selected 10% of rows; disagreement above 1% invalidates the layer as a software result.

The positive-probability parent audit remains untouched. Audit labels cannot be used to relabel `Y`; if reviewers determine that a target mention is clinically wrong, incomplete, or not communicated, that is an essential adjudication result outside this computable layer. The parent prospective-silent-only ceiling is preserved: even a computational pass cannot establish prospective performance or patient benefit.

## Substantive advance

The successor connects the parent's auditable route construct to a decision-relevant but deliberately modest downstream observable: whether a target-linked discharge action/status pattern appears after the report. It distinguishes target-specific documentation from generic discharge completeness, fixes chronology and workload, and makes failure informative without laundering documentation into clinical truth. This is a falsifiable workflow bridge while preserving the parent's population, exact atom/route estimand, all-unit adverse routing, audit design, leakage resistance, and partial-identification ceiling.
