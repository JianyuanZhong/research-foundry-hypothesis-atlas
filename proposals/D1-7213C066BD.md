# Episode 7 representation-boundary memo

Status: substantive child of [prior hypothesis]. Design only; no cohort fit, model result, or favorable finding is claimed.

## Decision

The inherited elastic-net versus compact GRU comparison is scientifically useful but not sufficient by itself to distinguish recorded assay state from workflow/lead-time.

The elastic-net is an appropriate transparent primary baseline: it fixes the estimand, permits channel ablations, and exposes whether the recorded assay channel adds calibrated held-out information beyond matched observation and care-process summaries. The compact GRU is a justified learned sensitivity because it can preserve irregular event order, elapsed time, and nonlinear trajectories that summaries lose. However, a better GRU score would still be ambiguous. Its interleaved process and assay streams can use the timing and occurrence of measurements as a proxy for a planned retreatment, and its informative missingness representation does not make the observation process separable from assay content. Conversely, residualizing all assay values would remove real state information that is predictable because clinicians observe it. The remaining uncertainty is therefore not a small predictive-gain question: it is whether content that is not explained by the recorded observation process carries reusable information.

I add one bounded alternative, the process-conditioned assay-innovation sensitivity (PCAS), while retaining both inherited models. PCAS is diagnostic and does not replace the primary estimand.

## Scientific question and clinically interpretable next decision

The exact question remains:

> Among patients observable at day 42 after a first locally recorded exact-code TACE, does adding recorded assay content at the day-42 landmark improve calibrated prediction of a later locally recorded exact-code repeat-TACE event beyond matched observation and care-process information?

The strongest claim supported before fitting is only that later recorded repeat TACE may be predictable from routine longitudinal records. The unresolved claim is whether the assay increment survives a process-conditioned test. The leading rival is workflow/lead-time: follow-up schedules, orders, encounters, repeated testing, current severity and planned retreatment can generate both assay records and a later recorded procedure. A GRU-versus-elastic-net difference cannot adjudicate that rival.

The clinically interpretable next decision is data-acquisition prioritization, not treatment:

- If raw state and PCAS increments both survive the same held-out, calibration, observation-weighted, and 7-day checks while process-matched permutations fail, proceed to an adjudication study linking assay content to imaging response, treatment intent, and outside-care events.
- If raw state helps but PCAS does not, prioritize scheduling/order/intent and outside-care linkage; the observed increment is workflow-compatible.
- If process-only features match or exceed the assay increment, do not escalate an assay-biology interpretation.
- If support, calibration, or precision gates fail, the result is inconclusive and the next decision is improved measurement/adjudication, not abandonment or deployment.

No result establishes tumor response, a causal assay effect, treatment benefit, a treatment rule, or clinical utility.

## Channels and inherited models

M0 contains pre-index age, sex, department, encounter/admission history, diagnosis counts through matched encounters, procedure counts, and exact-assay summaries in [-365,0).

S contains only the eight assay labels in (0,42], audited numeric values, qualitative/inequality flags, and assay-specific changes from a valid pre-index observation in [-365,0). It contains no request or missingness indicator.

P_obs contains dated encounter, examination, medication/order/lab observation counts, distinct dates/gaps, assay-label request/result counts, and availability/missingness indicators in (0,42], with no assay values or qualitative results.

P_care contains dated non-TACE procedure tokens, non-drug-order tokens, medication starts/ends, department/visit marks, and timing in (0,42], with no assay values.

The primary transparent baseline is elastic-net pooled-logistic discrete-time hazards for bins 43–90 and 91–180, with a fixed low-degree time spline. Fit M0, M0+P_obs, M0+P_care, A=M0+P_obs+P_care, M0+P_obs+S, and B=A+S. The confirmatory state contrast is D_state = loss(A)-loss(B); the workflow contrast is D_workflow = loss(M0+P_obs)-loss(A). Positive means lower loss after adding the named channel. Report weighted log loss, Brier/integrated Brier, calibration slope/intercept, and secondary AUROC/AUPRC.

The compact time-aware GRU remains a matched sensitivity on the same stream, ablations, target, split, IPCW/observation weights, metrics, and three fixed development seeds. Its possible scientific contribution is nonlinear trajectory and irregular timing information, not proof of state biology. A failed GRU does not refute the question.

## Bounded alternative: process-conditioned assay innovations (PCAS)

PCAS tests a narrower, explicit estimand: does assay content that is not predictable from recorded observation/care process and pre-index history add information for the same later event?

For each of the eight labels, create assay observation marks from labs in (0,42], using 检验时间, 定性结果, 定量结果, and 标本类型, after exact duplicate collapse and label/calendar-scale audit. Use the same pre-index last valid observation in [-365,0) when defining a change. No assay text or value is sent to a web query or external service.

Within every development fold only:

1. Fit a cross-fitted observation-process model for each assay label/window: the probability of an assay observation by each prespecified 7-day window, using only M0, elapsed time, prior assay history, and process marks available before that window from encounters, examinations, medications, orders, non-TACE procedures, and matched-encounter diagnoses. It may use assay label/request counts but never assay values or qualitative results.
2. Among observed assay marks, fit a cross-fitted content model for the audited numeric rank/scale, qualitative category, inequality/censoring flag, and change-from-pre-index content, conditional on the same process history, label, and elapsed time. Numeric values are rank/robust-scaled within label and development fold only; no clinical cutpoint, unit conversion, reference-range claim, or cross-label pooling is allowed.
3. For held-out patients, form S_PCAS from out-of-fold innovations: numeric residual/rank innovation, qualitative multinomial residual or held-out deviance score, inequality/censoring innovation, and change innovation. Do not include observation indicators in S_PCAS; those stay in P_obs. A patient without an observed assay has no imputed assay content.
4. Fit B_PCAS=A+S_PCAS using the same pooled-logistic hazard baseline, same target and all preprocessing inside development folds. The primary comparison remains A versus raw B; A versus B_PCAS is a labeled sensitivity. The alternative does not claim that process-predictable assay content is clinically irrelevant; it asks whether the less process-explained component is reproducibly useful.

The two-stage nuisance fits are intentionally compact: regularized one-label models with fixed prespecified feature sets, no outcome use, no hyperparameter sweep, and no neural point-process search. This makes the added contrast auditable and keeps its scientific meaning distinct from a predictive leaderboard.

## Alternatives selected and deferred

Selected: elastic-net as the primary auditable model; compact GRU as a matched trajectory sensitivity; PCAS as the only new bounded alternative because it directly addresses observation-process/state ambiguity at fixed endpoint and split.

Deferred:

- A larger transformer or continuous-time neural point-process model could represent irregular timing, but its extra flexibility would not identify workflow from state in this snapshot and would add tuning without a new clinical comparison.
- A GRU-D-like missingness-aware RNN is not selected separately because the inherited GRU already receives elapsed time, channel tags, and observation/missingness process features; it would mainly duplicate the same ambiguity.
- Causal treatment-policy, mediation, or g-formula analysis is unavailable without treatment intent, complete outside-care capture, imaging response, and valid comparative treatment timing.
- Imaging-response modeling is unavailable because the examination text is not an adjudicated response endpoint and no image payload is bound.

Approximate future solver budget: elastic-net plus PCAS are expected to fit on CPU in a bounded 8-CPU/32-GiB job in roughly 1–3 hours after one chunked source scan; the inherited GRU sensitivity is expected to require a separate 1-GPU job of roughly 2–6 hours with a compact sequence and three fixed seeds. These are planning estimates, not measured runs in this discovery episode. The run’s authoritative inputs.json and solver limits were not mounted at the assigned workspace path, so the compiler must reconcile these estimates with the configured hard envelope before scheduling. No GPU is needed for PCAS; GPU allocation is a feasibility tradeoff for the inherited GRU, not a scientific requirement.

## Scientific deliverable and completion criteria

The new deliverable is a newly fitted, leakage-safe process-conditioned assay-innovation sensitivity with frozen nuisance specifications, support/overlap audits, patient-held-out predictions, paired losses, calibration and uncertainty, process-matched falsification outputs, and an explicit claim-output map. Completion requires these artifacts and an honest supportive, adverse, or inconclusive interpretation. A positive prediction result is not completion by itself.

The study can computationally check exact-code cohort construction, timing, channel separation, held-out predictive contrasts, calibration, support, uncertainty, and falsification behavior.
