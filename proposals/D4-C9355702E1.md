# Does the ORDER of first cardiometabolic diagnoses carry prognostic information beyond co-presence? (episode 28 evolution)

## Unresolved question and clinical importance
Multimorbidity risk models and staging tools treat disease burden as a **set** or a **count**. Clinicians reason about **sequence** (diabetes-then-hypertension vs hypertension-then-diabetes). It is unknown whether the **order** of first diagnosis of two co-present cardiometabolic diseases carries prognostic information about downstream accrual, or whether order is a proxy for age at onset, care intensity/ascertainment, or the mere presence of both. Resolving this decides whether sequence should enter multimorbidity stratification. Useful negative finding: if Δ_order collapses, the set/count view is adequate.

## Leading claim vs strongest rivals, and their discriminating observation
- **Leading claim (A):** given co-presence of diseases A and B, order (A-first vs B-first) predicts downstream accrual of *new* conditions.
- **Rival B1 (ascertainment/care-intensity):** the first-diagnosed disease reflects earlier/more intense healthcare contact.
- **Rival B2 (timing/age):** A-first occurs earlier in life; downstream counts scale with elapsed time/age.
- **Rival B3 (null/co-presence suffices):** once both diagnoses and prior burden are fixed, order adds nothing.
- **Discriminating statistic:** co-presence-fixed **Δ_order** = difference in downstream accrual between A-first and B-first, adjusted for age at first index date, sex, inter-diagnosis interval and pre-index diagnosis count (B1/B2), evaluated against a within-stratum permutation null. A survives only if Δ_order exceeds the null band; B3 is favoured if it collapses.

## Baseline vs substantive alternatives (method comparison)
Full reasoning in `work/lead-ep28/method-comparison.md`.
- **Baseline (standard set/count view):** co-presence-only model (disease count, age, sex, prior burden) predicting downstream accrual.
- **Substantive learned alternative:** add a temporal-order feature (A-before-B indicator + inter-diagnosis interval) and learn a data-driven ordered-pair effect by penalised regression / gradient boosting under proper cross-validation (train half, held-out half). **What it reveals the baseline loses:** whether directional pairwise ORDER adds held-out predictive information over unordered co-presence, and which ordered pairs deviate from exchangeability. **Deferral rule:** if the order feature adds no held-out gain beyond age/sex/prior count, the sequence hypothesis is not supported (adverse) and the count view is adequate.
- **Mechanistic/tie variant:** an ordered-pair effect model with an explicit same-day tie category, which the diagnostic shows is required (the baseline and the parent ignored it).

## Pre-specified supportive / adverse / inconclusive outcomes
- **Supportive:** Δ_order exceeds the within-stratum permutation null band (≥1,000 permutations) in a pre-registered majority of powered discordant index pairs after adjustment; the order feature improves held-out accrual prediction.
- **Adverse:** Δ_order null/attenuated to within the band after age/interval/prior-count adjustment (order explained by timing/ascertainment) — refutes the claim; valuable negative.
- **Inconclusive:** insufficient powered **discordant** index pairs after tie exclusion, or the effect is entirely attributable to a care-intensity proxy not measurable here.
