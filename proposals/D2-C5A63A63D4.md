# Fibroblast-induced MTF context attenuates auranofin response on the MTF-specific gene program: drug-specific context-dependent drug response in rheumatoid arthritis

## Seed
D2-T1 (Context-specific intervention response)

## Domain
Therapeutic Target Prioritization

## Parent
[prior hypothesis] (JAK inhibitor context-dependent transcript response in synovial cocultures)

## Question
Does fibroblast-induced MTF (macrophage+T cell+FLS) context specifically attenuate auranofin
(TrxR/NF-kB inhibitor) response on the MTF-specific gene program, while JAK inhibitor (A77)
response is NOT context-dependent?

## Background
Kuo et al. 2019 [K1] defined HBEGF+ inflammatory macrophages in RA synovial tissue using
single-cell RNA sequencing. They showed that "most medications used to treat RA patients
targeted HBEGF+ inflammatory macrophages; however, in some cases, medication redirected them
into a state that is not expected to resolve inflammation." This established that drug response
in synovial tissue depends on the cellular context and that different drugs may have
context-dependent effects.

The parent candidate ([prior hypothesis]) tested whether JAK inhibitor (A77)
transcript response depends on fibroblast presence (MTF vs MT context). Discovery-level evidence
showed context-dependent responses in JAK1 (p=0.007), TYK2 (p=0.014), STAT5A (p=0.014) and
IL1B/PTGS2 context reversal.

This candidate extends the question to a drug-specific hypothesis: the MTF-specific gene program
(genes upregulated by fibroblast crosstalk) shows attenuated drug response in MTF vs MT context
for auranofin (TrxR/NF-kB inhibitor) but NOT for A77 (JAK inhibitor).

Auranofin is a gold(I) compound initially developed for RA treatment. Its predominant molecular
mechanism is inhibition of thioredoxin reductase (TrxR), with additional effects on ROS induction
and NF-kB signaling [K2]. ER stress in RA exhibits stage-dependent and cell-type-specific
patterns, with FLS showing apoptosis resistance and context-dependent pathogenic functions [K3].

## Discovery-level evidence (executed this episode)
Data: GSE95588_d1d2d3d4_counts.counts.tsv.gz (23,710 genes x 70 samples)
- Donors: P1(25), P2(27), P3(15) have drug treatments; P4(3) no drugs
- Contexts: M, MT, MTF; drugs: A77, AG, Aur, Dex, Dic, GW, Hy, Meth, Nap, Sul, Tof, aIL6
- MTF-specific program: 1,524 genes up >0.5 log2CPM in MTF vs MT in >=2/3 donors

Per-drug paired t-test (MTF response - MT response) on MTF-specific genes:
- A77 (JAK inhibitor): 0 FDR<0.1 genes; per-donor attenuation 0.42/0.59/0.51 (~chance)
  → ADVERSE for MTF drug resistance via JAK inhibition
- Aur (auranofin): 0 FDR<0.1 genes; per-donor attenuation 0.86/0.70/0.73 (mean 0.76)
  vs control 0.44/0.48/0.42 (mean 0.44)
  → SUPPORTIVE: MTF-spec genes systematically less suppressed in MTF, all 3 donors consistent
- All other drugs: no robust signal

Top Aur MTF-spec genes (all 3 donors consistent):

## Hypothesis
Fibroblast-induced MTF context specifically attenuates auranofin (TrxR/NF-kB inhibitor) response
on the MTF-specific gene program, because fibroblast-derived signals (e.g., Trx system, ROS
modulation, NF-kB feedback) counteract auranofin's mechanism of action in the MTF context.
This is drug-specific: JAK inhibitor (A77) response is NOT attenuated in MTF context, because
JAK/STAT signaling is not the primary target of fibroblast crosstalk in this system.

## Key distinction from parent
Parent (c7add9e7) tested JAK inhibitor context-dependence broadly. This candidate tests a
drug-specific hypothesis: auranofin response is context-dependent but A77 response is not.
This is a more specific and falsifiable claim with direct therapeutic implications: auranofin
may be less effective in fibroblast-rich synovial tissue, while JAK inhibitors may not be
affected by fibroblast context.

## Analysis plan
1. MTF-specific gene program: genes up >0.5 log2CPM in MTF vs MT in >=2/3 donors (P1-P3)
2. Per-drug paired t-test: MTF response - MT response on MTF-specific genes (n=3 donors for Aur/A77)
3. Per-donor signed attenuation: fraction of MTF-spec genes where MTF response > MT response
4. Control: all expressed genes (max>10) for comparison
5. BH FDR correction
6. Cross-dataset validation: E-MTAB-8316 (if auranofin or TrxR-related contrasts available)

## Falsification criteria
- Supportive: Aur shows per-donor attenuation >0.7 in all 3 donors AND A77 shows per-donor
  attenuation ~0.5 (chance) AND at least 5 MTF-spec genes with p<0.01 for Aur
- Adverse: Aur shows per-donor attenuation ~0.5 (chance) OR A77 shows per-donor attenuation
  >0.7 (i.e., A77 is context-dependent but Aur is not)
- Inconclusive: <2 donors with data OR FDR eliminates all significance OR per-donor attenuation
  inconsistent across donors

## Competing explanations
1. Bulk RNA-seq confounds macrophage vs fibroblast transcriptional changes
2. MTF-specific genes may simply be more highly expressed, making them harder to suppress
3. Vehicle control is unstimulated (not stimulated+vehicle), so drug response includes stimulation effect
4. Small n (3 donors) limits power; 0 FDR-significant genes for all drugs
5. Auranofin's mechanism (TrxR inhibition) may have off-target effects that confound interpretation
6. Donor IDs unresolved (P1-P4 labels, not verified GSM accessions)

## Limitations
- 1 replicate per condition per donor (no biological replicates within donor)
- Donor IDs unresolved (P1-P4 labels)
- Bulk RNA-seq: cannot distinguish macrophage vs fibroblast transcriptional changes
- Small n per drug (2-3 donors); 0 FDR-significant genes for all drugs
- A77 result is adverse; Aur result is underpowered but directionally consistent
- No wet-lab validation
