# Episode 8 successor: strict pre-draw pH forecasting is not inferentially feasible in EICU

## Decision and evidence boundary

The unresolved clinical question is whether an already available acidic pH can identify a ventilated adult whose monitor SpO2 is 96–97% but whose arterial PaO2 will exceed 120 mm Hg shortly afterward. A reliable signal could justify prospective selective-ABG or oxygen-reassessment research. Same-panel pH cannot answer this because it becomes available only after the outcome gas is drawn.

The inherited effect hypothesis was an observation-standardized risk difference (RD) of at least +10 percentage points for PaO2 >120 comparing prior acidemia (pH <7.35) with prior normal pH (7.35–7.45), using pH sampled 5–60 minutes before outcome. The +10 value is a materiality target, not an established effect. This successor does not estimate that effect in EICU: the complete time-correct cohort fails fixed feasibility gates by more than an order of magnitude. It freezes a computable feasibility experiment and stop rule. The effect remains unresolved and needs another source or prospective study.

I inspected the full-text XML of Delgado et al., Antioxidants 2026 (DOI 10.3390/antiox15020235; PMCID PMC12938712; source [source checksum]; [source checksum]). Its 2017–2022 single-center retrospective cohort contained 21,406 adults and 717,064 synchronized measurements. It aligned preceding-five-minute median SpO2/FiO2 to arterial gases and reports higher PaO2 in acidotic states at comparable SpO2; SpO2 96–97% generally corresponded to physiologic PaO2 and FiO2 modified risk. This supports concurrent physiologic plausibility, not lagged prediction, transportability, selective-ABG benefit, or treatment benefit. The article refers to supplementary quality-control details; that supplement was not inspected here.

## Temporal defects repaired

Public eICU documentation defines labResultOffset as draw time and labResultRevisedOffset as when the revised value was entered. It distinguishes respiratory value time from entry time. It describes vitalPeriodic as unvalidated monitor data generally archived as five-minute medians, without defining whether observationOffset anchors the window start, midpoint, or end.

The inherited lagged design therefore had four defects: it never required prior pH to be entered by forecast origin; it adjusted for index-draw PaCO2, which is post-origin; its FiO2/SpO2 windows extended to outcome draw despite claiming five minutes of lead; and it unnecessarily required index pH. A further source anomaly is decisive: labresultrevisedoffset is earlier than labresultoffset in 10/29 nominal repaired 60-minute rows. Strict validity requires prior_ph_offset <= prior_ph_revisedoffset <= forecast_origin. Such reversed rows require informatics adjudication and cannot establish availability.

## Frozen feasibility experiment

Use EICU snapshot [source checksum]. Sources are ordinary read-only CSV.GZ files, with no inner archive member, under [internal dataset path] 2.0 data/.

1. In patient, retain numeric age >=18 (map released “> 89” to 90 only for adjustment), unitvisitnumber=1, nonmissing unitdischargeoffset, and outcome draws from 0 through min(4320, unitdischargeoffset). This is first ICU-unit visit in a health-system stay, not first lifetime admission. Cluster people by uniquepid.
2. In lab, retain exact labtypeid=7 and labname values paO2, pH, and optional paCO2, with PaO2 20–760, pH 6.80–7.80, and PaCO2 10–150. Within patientunitstayid + labresultoffset + labname, order by greatest labresultrevisedoffset then labid; exclude a retained tie with distinct valid values. A primary index needs PaO2, not index pH.
3. Require respiratoryCare airwaytype in {Oral ETT, Nasal ETT, Tracheostomy, Double-Lumen Tube, Cricothyrotomy}, ventstartoffset <= index_draw, and either a positive closed interval containing the draw or ventendoffset=0 with index_draw <= respcarestatusoffset. This is a retrospective proxy, not adjudicated ventilation.
4. Define pseudo-forecast origin tau = index_draw minus 5 minutes. Choose the latest respiratoryCharting exact-label FiO2 with respchartoffset in [tau-30,tau] and respchartentryoffset <= tau; tie-break by chart offset, entry offset, then respchartid. Convert 0.21–1.00 to percent and retain 21–100.
5. In vitalPeriodic, require sao2 70–100 and observationoffset in [tau-5,tau]; use the median and require 96–97. Preserve row and distinct-offset counts and last lag. Undefined five-minute archive anchoring means this is only pseudo-pre-origin.
6. Select the latest same-stay pH draw with index_draw-60 <= ph_offset <= tau and ph_offset <= ph_revisedoffset <= tau. Expose pH <7.35 versus 7.35–7.45. Prior PaCO2 is optional only at that prior-panel offset with valid draw/entry ordering. Never use index pH, index PaCO2, PaO2, or post-tau data as predictors.
7. Keep every eligible observed PaO2 draw. The target is conditional on a future gas being obtained; it is not latent hyperoxemia prevalence at all bedside moments.

Before modeling require all inherited gates: >=200 observations, >=20 events, and >=5 hospitals each with >=20 acidemic and >=20 normal rows. Site adequacy is based only on exposure/documentation counts; the overall event gate is a stability stop and never selects sites.

## Complete no-sampling audit and result

A full-file DuckDB run succeeded in 140.6 seconds (job [research job]):

- 157,883 adult first-unit rows;
- 1,243,877 valid blood-gas analyte rows and 1,235,307 selected analyte-time groups;
- 173,310 PaO2 outcome draws; 169,783 also had exact-offset pH;
- 21,156 PaO2 draws under the airway proxy; 20,946 also had index pH;
- 6,533 with strict FiO2 at tau and 5,269 also with preceding SpO2;
- 29 target-band rows with 5–60-minute pH if only revisedoffset <= tau is required;
- 19 strict rows after valid entry ordering: 18 stays/people, 8 hospitals, 16 acidemic, 3 normal, and zero PaO2 >120 events.

Hospital acidemic/normal counts are 420 (9/0), 458 (2/1), 443 (1/1), 110 (1/0), 208 (1/0), 254 (1/0), 318 (0/1), and 459 (1/0). No site has five per group, much less 20. The feasibility hypothesis is falsified; inference must stop.

Horizon sensitivities at 120, 180, and 360 minutes yield 90/12, 160/18, and 266/29 observations/events after valid entry ordering. At six hours, 174 are acidemic and 92 normal across 37 hospitals, but only hospitals 420 and 458 have >=20 per group. Most information is concentrated in a few sites, and six-hour pH tests persistence of severity rather than short-lag physiology. These post-audit horizons cannot rescue the frozen question or justify transportability.

## Analysis allowed only in a new source that passes gates

The estimand would be the observation-weighted marginal standardized RD for PaO2 >120 comparing prior acidemia with prior normal pH among eligible observed future ABGs.

B0 is intercept + pre-origin SpO2 centered at 96.5 + FiO2 per 10 points + six-hour ICU block. B1 adds prior-panel PaCO2 per 10 and missing indicator. B2 adds prior acidemia. The acidemia-by-FiO2 interaction is sensitivity-only if there are >=10 events per resulting coefficient. B3 sensitivity adds age, sex, unit type, and admission source. Collapse predictor levels with <10 rows before outcome inspection. No hospital ID or post-origin field enters a model.

Fit logistic GEE with exchangeable correlation by uniquepid. Standardize by setting only prior acidemia to 1 and 0 over the same rows. Use 1,000 hospital-cluster bootstrap replicates, relabeling copied hospitals and people; report percentile 95% intervals, failures, cluster concentration, and person-cluster sandwich intervals. Sensitivities: earliest row per stay, equal-stay weighting, first 24 hours, last SpO2, FiO2 lookbacks 5/60 minutes, pH windows 10–30 and 5–120, complete prior PaCO2, entry-order anomalies, and adequate-site deletions. The concurrent parent analysis is secondary only and can never support actionability.

## Falsification and interpretation

If a future source passes gates:

- Supportive of material lagged association requires B2 RD lower 95% bound >=+10, positive direction in >=70% of exposure-adequate hospitals, no adequate-site deletion reversing direction, and no primary timing sensitivity shifting RD >5 points or reversing it. The strongest claim is an association among clinician-selected future ABGs warranting prospective validation.
- Adverse to +10 magnitude means upper 95% bound <+10; upper bound <0 supports an opposite association. A precise +6 is adverse to materiality, not proof of no association.
- Inconclusive means any gate fails, interval spans +10, >10% bootstrap failures, inadequate overlap, sparse site support, or timing sensitivity >5 points. Current EICU is infeasible/inconclusive, not adverse: 19 rows and zero events cannot falsify the effect.
- Supportive concurrent results with inconclusive lagged results establish only a current measurement correlate.
- Secondary PaO2 >150, continuous PaO2, and PaO2 <60 cannot rescue primary failure.
