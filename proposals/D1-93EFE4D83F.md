# Hospital transportability of measurement-process signals in early ICU deterioration prediction

## Scientific question and hypothesis

The unresolved question is whether apparent predictive value of laboratory testing frequency and missingness is stable patient information or a hospital-specific observation process. Hypothesis: among adult eICU ICU stays with an evaluable first-6-hour prediction window, a model using laboratory values plus testing-process features will lose more discrimination, calibration, and decision-curve net benefit on held-out hospitals than a model using the same physiologic values but no process features, after accounting for case mix and outcome prevalence.

The strongest prior evidence supports only that missingness can be informative and that retaining it can improve within-setting prediction. It does not establish that such signals fail across hospitals, nor that failure is caused by workflow rather than case-mix, label, or timing shift. [K1] describes this transportability problem using synthetic data; [K2] reports a single-setting deterioration model in which informative laboratory handling performed well; [K3] demonstrates the clinical importance and feasibility of multisite external evaluation. This study adds a direct hospital-held-out comparison in eICU and decomposes the source of transport degradation.

Supportive evidence would be a larger held-out-hospital drop for the process-aware model, with similar physiology-only performance and attenuation after removing process features or recalibrating to the target hospital. This supports workflow dependence as a transportability explanation, not a causal claim about clinician behavior. Adverse evidence would be equal or smaller degradation for the process-aware model, or degradation explained by case-mix/prevalence adjustment. Inconclusive evidence would be insufficient event/site support, wide uncertainty, or unstable results across hospital splits.

## Population, time, outcomes and exclusions

Use adult ICU stays in patient.csv.gz, table patient. The stay key is patientunitstayid; hospitalid, age, gender, ethnicity, unitadmitsource, unitadmitoffset, unitdischargeoffset, unitdischargestatus, unitdischargelocation and hospitaldischargestatus are available. Define index time as ICU admission and use offsets in [0, 360] minutes. Exclude missing/invalid age, stays with less than 360 minutes of ICU observation, and hospitals below a prespecified minimum such as 200 eligible stays and 20 outcome events, finalized only after readiness counts.

Primary outcome should be ICU mortality by end of stay because it is available in patient and has less label ambiguity. A secondary prospective outcome may be death or a transparent deterioration proxy within 24 hours after the six-hour cutoff, but it requires an explicit adjudication rule and event audit. No result establishes clinical deterioration truth without expert adjudication.

Exact temporal sources and fields:

- lab.csv.gz, table lab: patientunitstayid, labresultoffset, labname, labresult, labresulttext, labmeasurenamesystem, labmeasurenameinterface.
- vitalPeriodic.csv.gz, table vitalPeriodic: patientunitstayid, observationoffset, temperature, sao2, heartrate, respiration, systemicmean.
- vitalAperiodic.csv.gz, table vitalAperiodic: patientunitstayid, observationoffset, noninvasivemean, noninvasivesystolic, noninvasivediastolic.
- apacheApsVar.csv.gz, table apacheApsVar: patientunitstayid, meanbp, heartrate, creatinine, wbc, pao2, fio2 and other admission physiology.
- apachePatientResult.csv.gz, table apachePatientResult: patientunitstayid, acutephysiologyscore, apachescore and actual discharge/ventilation outcomes; use only if timing is pre-index or as a comparator.
- hospital.csv.gz, table hospital: hospitalid, numbedscategory, teachingstatus, region.

All joins use patientunitstayid, except patient.hospitalid to hospital.hospitalid. Offsets are ICU-relative minutes. The guide states that vitalPeriodic is a five-minute summary, not raw waveform. Each source is an ordinary CSV member of a gzip archive; no archive-member selection is required. Raw sources are read-only.

## Estimand and analysis

The primary estimand is the difference in held-out-hospital performance between physiology-only and process-aware models, averaged across prespecified target hospitals: AUROC, AUPRC, calibration intercept/slope, Brier score, and decision-curve net benefit over a prespecified risk range. Report bootstrap or hospital-cluster uncertainty and prediction intervals across target hospitals, not only pooled confidence intervals.

Fit two matched model families on identical patient splits:

1. Baseline: penalized logistic regression, with a gradient-boosted tabular sensitivity analysis, using prespecified early vital/lab values and trends; impute values without missingness indicators, and include age, sex, admission source and pre-index severity.
2. Substantive alternative: a time-aware model fitted to 0-6-hour lab/vital sequences, retaining measurement times, per-lab counts/intervals, missingness indicators and last observed values. Use a modest LSTM, temporal convolution or attention model only if event/site support permits; otherwise use a hierarchical discrete-time logistic model with splines for time since measurement. Its purpose is to represent trajectory and observation process jointly, not to chase a small score gain.

Split by hospital into training, validation and untouched target hospitals. Repeat prespecified hospital partitions or use leave-one-hospital-group-out when support permits. Fit preprocessing and imputation on training hospitals only. Compare process-aware versus physiology-only models, process-feature permutation within hospital, and target-hospital intercept recalibration. Adjusted analyses standardize or reweight case mix using age, sex, admission source, baseline severity and hospital descriptors. Never use post-cutoff treatment.

## Falsification and limits

Falsify the process explanation if process ablation does not preferentially reduce transport performance, if within-hospital random splits show the same degradation as hospital holdouts, or if degradation disappears after case-mix/prevalence adjustment while process-feature importance is not site-specific. Audit leakage with post-cutoff fields excluded from the primary model. Use a stable admission-only outcome as a negative control where feasible.

Computationally checkable outputs are cohort counts, timestamp and split integrity, fitted predictions, calibration, net-benefit, ablation differences and uncertainty. Clinical adjudication is required for deterioration labels, clinical threshold selection and any claim that workflow change improves care. This study cannot establish hospital causation, a biologic missingness mechanism, or deployment safety; those require prospective validation, workflow audit and clinician review.

## Baseline versus learned alternative and compute

The penalized logistic baseline is transparent and CPU-feasible. The temporal learned alternative can reveal whether trajectory shape and observation timing jointly encode transportable physiology that a static summary loses; the baseline cannot distinguish a stable value from a changing value or represent irregular intervals. Defer the learned model if readiness finds too few events per held-out hospital, unstable timestamps or no reproducible lab identity mapping; use the hierarchical discrete-time model as a scientifically stated fallback.

The future solver must newly fit both model families, estimate held-out-hospital performance and uncertainty, and produce ablation and recalibration outputs. Discovery used no GPU result. inputs.json permits a planning envelope of 16 CPUs, 262144 MiB, 8 GPUs and 28800 seconds. CPU is the default for the tabular baseline; an optional one-GPU temporal fit must explicitly request the cached GPU image. These are planning estimates, not measured full-study runtime. The failed 600-second discovery scan is a runtime limitation, not evidence of absent events.

## Demonstrations and seed dispositions

The natural-history transformer demonstration motivates dated sequence representations and is adapted only as a possible temporal alternative because local eICU has structured sequences but not the UKB cohort or Danish validation. The Bayesian longitudinal demonstration motivates latent trajectories, but its genetic inputs are unavailable and are not needed for this EHR-only adaptation. The multimodal cancer demonstration cannot be reproduced because local images and the main article/STAR Methods are unavailable; its lab-only ablation logic is relevant only as a comparison principle.

The selected parent is expert seed eICU-02. eICU-03 hypotension is a plausible physiology-focused alternative, but this question better isolates a deployment-critical source of transport failure. eICU-08 reduced testing overlaps the process question but risks confounding reduced testing with discharge or end-of-life censoring, so it is deferred. Hyperoxia, ventilation, nighttime discharge, hypoglycemia and hospital-recovery seeds require more specialized adjudication or treatment-timing assumptions than are currently verified.
