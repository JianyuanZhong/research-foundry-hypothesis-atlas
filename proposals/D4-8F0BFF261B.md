## 1. Parent recap (fixed design; unchanged unless stated)
The parent tests a **disease-preferential residual** in plasma proteins via a case-case specificity gap
`Delta_D` between two diseases `D` vs a pre-specified comparison disease `D'`, estimated on **diseased-only
held-out** individuals, with **operative-treatment state held fixed** by restricting to an "unrelated"
OPCS-4 procedure family, **age/sex residualization**, and a **within-stratum permutation null** (1,000 label
permutations of `D`/`D'` within joint age-decile x sex x comorbidity-count strata). Baseline = a single 1-D
shared-axis score; learned alternative = elastic-net / latent-axis model on the same estimand. The parent's
own strongest named unfinished limitation: the **"unrelated" OPCS block set and the ICD-10 `D'` code list
were chosen by clinical assertion and require clinical code-list adjudication**, which is not available here.

## 2. THE ADVANCE — replace asserted unrelatedness with a PRE-REGISTERED, DATA-DRIVEN rule
Clinical adjudication of "which procedure is unrelated to disease `D`" is unavailable in this environment.
The scientifically honest, computable move is to make **unrelatedness an observable, pre-registered property**
of the frozen data rather than an assertion, and to state the identification consequence when it fails.

**Rule (fixed before any outcome is seen; deterministic given the data):**
For each disease block `D` (ICD-10 3-char block), candidate treatment-proxy families are OPCS-4 3-char
procedure blocks `P` taken from `s_41200_0_*`. On the **training half only** compute, over Olink
`n_eid` participants:
- `nD = |D|`, `nP = |P|`, `nDP = |D and P|` (participant carries at least one 3-char code of each block),
- `lift(D,P) = (nDP / N) / ((nD / N) * (nP / N)) = nDP * N / (nD * nP)`,
- `phi(D,P)` = Pearson phi between indicators `1[D]` and `1[P]` (equivalently signed `sqrt(chi2/N)`).

**Eligibility (well-populated):** `nDP >= 200` **and** `nP >= 500`.
**Unrelatedness (minimally associated):** among eligible `P`, the selected family is the eligible block with the
lowest `lift`; it is accepted as the **treatment-safe stratum** only if `lift_lower95 <= 1.00` (independence
not rejected) **and** `|phi| <= 0.05`. Thresholds are pre-registered constants, not tuned to `Delta_D`.
**Fallback (pre-registered):** if no eligible block satisfies the strict rule but eligible blocks exist
(`nDP>=200`, `nP>=500`), select the minimum-`lift` eligible block, label the stratum
`least_associated_non_independent`, and downgrade `Delta_D^treat` to a **secondary/sensitivity** estimand that
cannot by itself exclude the treatment rival. If **no** eligible block exists at all, report
`unrelated_stratum = NOT_IDENTIFIED`.
**Identification consequence (stated up front):** if no well-populated, minimally-associated `P` exists, the
treatment-safe estimand `Delta_D` is **NOT identified** for that `D`; the claim must be narrowed from
"disease-preferential residual net of operative state" to "disease-preferential residual within the observed
treatment mix", which **cannot** discriminate disease biology (A) from a treatment/operative correlate (C).
The rule uses the training half only; the chosen `P` is frozen and applied to the held-out half to avoid
selection leakage.

## 3. Estimand, baseline vs alternative, split, uncertainty, falsification
- **Primary estimand:** `Delta_D^treat` = AUC separating `D` from `D'` from a protein-derived score on the
  **participant-level held-out half**, computed **within the data-driven unrelated-procedure stratum**,
  minus the **within-stratum permutation null** (1,000 `D`/`D'` label permutations within age-decile x sex x
  comorbidity-count strata). Secondary: `Delta_D^raw`, `Delta_D^resid` on the same split; sensitivity:
  fallback-stratum `Delta_D`.
- **Split:** participant-level 50/50, disease-stratified; unrelatedness rule learned on the train half only.
- **Baseline (1-D shared axis):** first principal component (or a pre-specified aggregate) of the 2,923 NPX
  proteins — one number per participant.
- **Learned alternative (same estimand, same split):** elastic-net over the 2,923 proteins, and/or a jointly
  estimated latent-axis model. **What the alternative reveals that the baseline loses:** a single shared-axis
  score collapses all proteins onto one dimension and therefore *cannot* show which individual proteins, if
  any, retain a disease-preferential residual once the shared axis, co-occurrence and operative state are
  removed; the learned model yields per-protein weights/residuals, so it can both localize candidate proteins
  and test whether the shared axis alone already explains the transfer gap. This is a substantive question
  (per-protein specificity), not a hunt for a small predictive gain; a near-zero learned gain would itself be
  informative (shared axis suffices).
- **Falsification criteria (pre-specified):**
  - **Supportive:** `Delta_D^treat` exceeds the permutation band (e.g. >97.5th percentile) for >=1
    pre-registered `D` that has an **identified** unrelated stratum, with the same sign in the held-out half.
    Establishes a disease-preferential residual *within the observed unrelated-treatment stratum* — not a
    mechanism, not incidence.
  - **Adverse:** `Delta_D^raw > 0` but `Delta_D^treat` ~ null after the unrelated-procedure restriction
    (rival C and/or shared morbidity B favored: the signal was shared operative/morbidity structure).
  - **Inconclusive:** no well-populated, minimally-associated procedure block exists -> stratum
    `NOT_IDENTIFIED`; A vs C cannot be separated with these data (an honest null, not refutation of A).
- **Required solver outputs:** `results.json`, `split_manifest.json`, `code_list.json`, plus
  `procedure_unrelatedness_rule.json` (per-`D` `{selected_P, nDP, nP, lift, phi, eligible, accepted, fallback}`).

## 5. Honest limits
- **Cross-sectional / prevalent only:** no draw/death date in this namespace -> no incidence, temporal-order or
  causal claim; the estimand is a descriptive specificity gap.
- **Under-ascertainment:** ICD-10/OPCS here are hospital/inpatient-coded; under-ascertainment may bias
  co-occurrence `lift`/`phi` and the selection of the unrelated stratum.
- **The data-driven unrelatedness rule is a PROXY** for clinical unrelatedness, not a substitute for expert
  code-list adjudication; a low-`lift` block can still be clinically related to `D` (or share an unmeasured
  common cause) in ways the co-occurrence statistic cannot see. Any such adjudication remains an explicit,
  unmet dependency.
- Co-occurrence is computed from the same prevalent snapshot used for the outcome; it characterizes observed
  treatment mix, not treatment history.
- Comorbidity count is a coarse severity proxy; `D'` list and thresholds should be re-checked by a clinician.
