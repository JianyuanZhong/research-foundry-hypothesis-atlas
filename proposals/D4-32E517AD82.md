2. Pair code position j only with date position j.
3. Let T17 be the earliest strictly parsed paired date whose code begins exactly with `N17).
4. Let T18 be the earliest strictly parsed paired date whose code begins exactly with `N18).
5. Let TK be the earliest of T17 and T18.
6. Let Tdeath be the earliest strictly parsed nonblank date among `40000-0.0` and `40000-1.0). Do not use `40001` or `40002`.

The primary composite is:

```
EK_i = 1{ t1_i < TK_i <= t5_i
          and (Tdeath_i absent or TK_i < Tdeath_i) }.
```

A kidney code on t1 is pre-index; a code after t5 is outside the endpoint; a code on the same date as death does not qualify because death competes strictly first. Death is never counted as EK.

Prespecified component indicators are:

```
E17_i = 1{ t1_i < T17_i <= t5_i
           and (Tdeath_i absent or T17_i < Tdeath_i) }

E18_i = 1{ t1_i < T18_i <= t5_i
```
