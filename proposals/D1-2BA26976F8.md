# Episode 90 successor: absolute-risk threshold validity is not fixed-capacity queue utility

## Unresolved question and clinical importance

A receiving ICU can use the same prognostic score in two materially different ways:

1. display an absolute-risk threshold, such as “seven-day in-hospital death risk at least 0.10”, to trigger a review rule; or
2. review a fixed number or fraction of patients, selecting the highest-ranked patients when staff capacity is fixed.

These decisions require different evidence. A score can display accurate probabilities after local recalibration while adding little event concentration over a simpler process-only ranker. Conversely, it can rank a useful queue while its 0.10 probability threshold is badly shifted by local practice. Calling either result “the model works” collapses two clinically different claims.

The assigned Episode 86 parent established the right remedy candidate—intercept-only, target-label recalibration learned with a leave-one-target-hospital-out procedure—and explicitly noted that an intercept shift cannot change ordering. This successor turns that distinction into the primary experiment. It asks whether a locally recalibrated absolute-risk threshold is valid and, independently, whether the same score has clinically meaningful fixed-capacity rank enrichment beyond the parent’s R_process baseline. The central advance is a prespecified decision matrix that prevents threshold calibration from being used as evidence of queue value, or queue enrichment from being used as evidence that a displayed absolute risk is valid.

The strongest available evidence supports only a narrower claim: repeat lactate and observation/process representation can be prognostically informative in selected critical-care prediction settings. The inherited evidence record reports modest incremental discrimination from 24-hour lactate in a measured sepsis cohort and concerns about missing observation/process representation in prediction studies. Neither establishes transfer of a 0.10 risk threshold between EICU practices, nor establishes that a recalibrated score improves a fixed-capacity review queue. No execution result is assumed here. The unavailable cancer demonstration main article and its full STAR Methods are not treated as inspected; only the availability limitations in the research-ambition README are relied upon.

## Falsifiable hypothesis and exact estimands

Let the two directed practice transfers be d=low to high and d=high to low, where practice is defined only by the frozen repeat-lactate availability strata in the audited cohort. For a target hospital h, let eta_full,i be the source-trained parent R_full linear predictor, p_source,i=expit(eta_full,i), and p_local,i=expit(eta_full,i+delta_h) be the held-out local intercept-recalibrated prediction. The local intercept uses D7 labels from target hospitals other than h; no label from h enters its prediction.

The compound hypothesis is:

> Local target-label recalibration can make the 0.10 absolute-risk threshold transport-valid, but threshold validity and fixed-capacity rank utility are distinct properties. The experiment must therefore estimate both; it must not infer the second from the first.

This is tested by two linked, separately falsifiable gates.

### Absolute-risk threshold gate

For each direction and each F_available by z cell, where z=1[p>=0.10], define calibration error E=mean(D7-p). Define q_source(d)=max_cells |E_source| and q_local(d)=max_cells |E_local|. The primary threshold estimands are I(d)=q_source(d)-q_local(d), I_*=min_d I(d), and q_*=max_d q_local(d).

The threshold hypothesis is supported only if the local partition has at least 30 people in each of its eight cells, the two-sided 95% interval has lower(I_*) >= 0.02, and upper(q_*) <= 0.05. These are absolute prediction-error criteria, not clinical benefit criteria.

For transparency, report for source and local predictions in every direction and cell: n, D7 events/non-events, fraction flagged, mean observed D7 risk, mean predicted risk, and E. Also report the local threshold capacity C_T,h = sum_i 1[p_local,i>=0.10]/n_h for every target hospital. This reveals when a valid 0.10 threshold produces a workload far from any fixed capacity.

### Fixed-capacity rank gate

For model m in {full, process}, target hospital h, and capacity fraction c in the prespecified set {0.05, 0.075, 0.10, 0.125, 0.15, 0.175, 0.20}, define k_h(c)=ceil(c*n_h), and select exactly k_h(c) people by descending raw linear predictor for that model, breaking ties by ascending patientunitstayid. Let Q_m(h,c) be that queue. Define the equal-hospital event-concentration functional U_m^Y(c,d) = (1/|H_d|) times the sum over h of [mean(Y_i among Q_m(h,c)) - mean(Y_i among h)] for Y=D7 as primary and Y=Dinf as secondary. This is a rank-enrichment/event-yield functional, not a measure of patient benefit or a causal utility function.

The primary rank estimands at c=0.10 are U_full^D7(0.10,d), whether the full score concentrates D7 events over the hospital baseline, and G^D7(0.10,d)=U_full^D7(0.10,d)-U_process^D7(0.10,d), whether adding the parent’s state/attention/lactate features provides a clinically meaningful rank increment over the process-only baseline.

Predeclare an absolute D7 event-rate increment of 0.02 as the minimum meaningful rank-enrichment difference for this experiment. Report paired two-sided 95% intervals. A rank-enrichment result is rank-supportive if lower(U_full^D7) >= 0.02; the full-score incremental rank claim is increment-supportive if lower(G^D7) >= 0.02. If upper(G^D7) < 0.02, report that the full score did not demonstrate the prespecified incremental rank value; this is not evidence that review has no value. All capacities and both outcomes remain reported so that a conclusion cannot be selected after seeing one favorable capacity.

Because local recalibration is an intercept shift, it should preserve each hospital’s ordering exactly. The experiment must nevertheless verify that the queue formed by p_local equals the queue formed by the raw R_full predictor at every c, up to explicitly reported numeric ties. It must also compare the threshold set T_h={i:p_local,i>=0.10} with the capacity-matched queue at k=|T_h|. This is an auditable bridge between the two decisions, not a claim that the decisions have the same clinical meaning.

### Prespecified interpretation matrix

| Threshold gate | Rank gate | Meaning allowed |
|---|---|---|
| supportive | increment-supportive | Historical cross-fitted evidence supports both target threshold calibration and incremental rank enrichment in this EICU experiment. |
| supportive | increment not supported | A calibrated 0.10 display may be defensible under the stated validation design, but it does not justify claiming added fixed-capacity queue value over R_process. |
| adverse/inconclusive | increment-supportive | The score may be useful for ordering a fixed queue, but its displayed 0.10 probability is not validated; do not use threshold language. |
| adverse/inconclusive | increment not supported | Neither proposed decision claim is established. |

The first row does not establish that any review action improves survival. The second row is the clinically important separation result that the successor is designed to detect.

## Analysis and uncertainty

The primary analysis uses out-of-fold target predictions from all target hospitals, with no averaging of hospital-level q values and no outcome-based cell selection. Threshold cells are defined using the relevant prediction (p_source or p_local), including exact equality at 0.10. Rank queues always have exact k_h(c) membership, with patientunitstayid tie-breaking.

Run 2,000 copied-hospital refit replicates with seed 20260973. Sample source and target hospitals independently with replacement within fixed practice strata. In each replicate, refit all source preprocessing and required models, rescore target people, and recompute every held-out local intercept using only copies whose original hospital differs from the held-out original hospital. A copied version of the held-out hospital is therefore also excluded from its calibration labels. Recompute every threshold cell, q_source, q_local, I, all queue capacities, U, G, threshold capacities, set-overlap diagnostics, and both D7/Dinf outcomes.

A replicate is finite only if every required source fit, score, local root, cell count, queue, and functional is finite; all eight required local cells have at least 30 people; and threshold and rank outputs are present. Report the finite count and two-sided percentile intervals, requiring at least 1,900 finite joint replicates. Do not silently pool labels when a copied sample leaves no valid leave-one-original-hospital-out calibration set.

Also report:

- threshold-selected versus capacity-matched queue membership, Jaccard overlap, selected counts, and exact tie counts by hospital;
- U_full, U_process, and G for every prespecified capacity and for D7/Dinf;
- addition/removal, overlap, M/rho/G/Psi, and deletion diagnostics inherited from the parent, with their definitions unchanged;
- fixed-design leave-one-original-hospital-out deletion for both q_local and the primary rank contrasts;
- number of hospitals driving each gate and whether any conclusion changes under one-hospital deletion.

The equality of local-prediction and raw-score rankings is a deterministic audit consequence of an intercept shift and must be checked, not used as a statistical result. If it fails, the experiment is not-computable because the implementation changed the estimand.

## Falsification hierarchy and interpretation limits

First classify the experiment as not-computable for any source/snapshot/hash/header/schema/key mismatch; failure to reproduce the audited cohort or outcome counts; changed clocks, feature construction, practice strata, folds, queue capacities, or tie rules; use of target-hospital labels in held-out predictions; nonfinite fits/roots; wrong queue cardinality; altered threshold cells; or fewer than 1,900 finite joint replicates.

If computation is valid, classify the threshold dimension independently:

- supportive only when all eight local cells pass, finite-replicate requirements pass, lower(I_*)>=0.02, and upper(q_*)<=0.05;
- adverse when lower(q_*)>0.05 or upper(I_*)<0.02;
- inconclusive otherwise, including support that depends on more than 30% of hospital deletions.

Classify the rank dimension independently:

- rank-enrichment supportive when lower(U_full^D7(0.10))>=0.02;
- incremental rank supportive when lower(G^D7(0.10))>=0.02;
- incremental rank not supported when upper(G^D7(0.10))<0.02;
- inconclusive when neither gate is decisive or the result is deletion-sensitive.

A threshold-supportive/rank-not-supported result means only that a historically cross-fitted 0.10 display met the specified EICU calibration screen; it does not establish a useful review queue. A rank-supportive/threshold-adverse result means only that the raw score concentrated observed events in a fixed-capacity historical screen; it does not validate an absolute probability or a clinical action. Even when both dimensions are supportive, the experiment cannot establish that reviewers would identify preventable deterioration, that staffing/capacity is adequate, that the queue changes treatment, or that patients benefit.

The available EICU fields do not adjudicate true norepinephrine administration versus documentation, lactate specimen/assay validity, ordering/release/viewing workflow, clinical review, preventability, fairness, or review workload. vitalPeriodic is not raw waveform data, and narrative notes are removed according to the EICU guide. Stronger claims require expert adjudication of medication and measurement provenance, stakeholder-defined capacity and utility, subgroup review, independent temporal or external validation, and ultimately an impact study or randomized evaluation. Reference execution would establish computational feasibility only, never clinical truth or causal benefit.
