# Structured-to-documentary medication-transition concordance at hospital discharge

## Decision question and clinically important unresolved claim

The current MIMIC board has repeatedly refined a pulmonary-radiology discharge-routing audit. This proposal is a distinct medication-safety experiment, not another pulmonary-documentation child. The decision bottleneck is whether a computable, retrospective signal can identify admissions in which the **structured discharge medication plan is not concordant with the immediately preceding inpatient medication record and the canonical discharge document**, and whether that signal marks a subgroup with unusually high subsequent acute-care utilization. Such a signal could prioritize a prospective medication-reconciliation audit or silent pharmacist-review workflow.

The strongest claim supported by the available evidence is only that MIMIC contains temporally ordered medication orders/prescriptions, medication administration records, and discharge narrative text linked to admissions. It does not show the patient's true pre-admission medication list, clinician intent, patient access/adherence, pharmacy fill, communication, or whether a medication difference was clinically appropriate. The unresolved, falsifiable claim is narrower:

> After fixing a medication-name normalization and timing algorithm before outcome analysis, a discharge-transition discordance phenotype will be measurable and will have higher 30-day subsequent-admission incidence than a concordant phenotype, with the contrast persisting in prespecified strata and negative controls.

This is an association hypothesis, not a treatment effect or causal claim. It is clinically valuable because medication discrepancies at transitions can be a high-consequence, workflow-addressable failure mode, while the experiment explicitly prevents intentional discontinuations from being mislabeled as errors.

## Population and temporal index

Use the MIMIC-IV 3.1 `hosp/admissions` population from all admissions with nonmissing `admittime` and `dischtime`, `dischtime > admittime`, and an observable canonical discharge summary (`note_type == 'DS'`) linked on `(subject_id, hadm_id)`. Restrict to adults using `hosp/patients.anchor_age >= 18`; retain age `91` as the MIMIC top-coded class. Exclude admissions with `hospital_expire_flag == 1` or `deathtime <= dischtime`, because the discharge-transition construct requires a live departure. Do not restrict to one admission per subject in the primary estimand: later admissions are needed for the outcome, and all eligible index admissions are retained. A sensitivity analysis uses the first eligible admission per subject, chosen by `admittime` and then `hadm_id`.

Let `D = dischtime`. The predeparture medication window is `[D-24 hours, D)` using within-subject shifted timestamps. The discharge-order window is all `hosp/pharmacy.starttime`, `stoptime`, `entertime`, and `verifiedtime` records linked to the index admission; a prescription is eligible if its start/stop interval overlaps `D` under a frozen half-open convention, with explicit missing-time states. The administration window is `hosp/emar.charttime` in `[D-24h,D)` and linked `hosp/emar_detail` rows when available. No record after `D` enters exposure construction.

The outcome window is `(D, D+30 days]` in the patient's shifted within-subject time: a subsequent `hosp/admissions.admittime` for the same `subject_id` and a different `hadm_id`, with an admission time in that interval. Report separately `hospital_expire_flag`/`deathtime` during the index admission and subsequent admission; do not infer outpatient ED visits that are not represented as admissions. A 30-day outcome is right-censored as `UNOBSERVABLE` if the available patient record ends before the window for any predeclared data-coverage reason; do not treat missing follow-up as no event. A 7-day subsequent-admission endpoint is secondary.

## Pre-label medication objects and exposure

Construct a deterministic medication object with fields `(canonical_name, dose, dose_unit, route, frequency, source, event_time, status)`. Canonical name is a frozen string transform applied identically to `pharmacy.medication`, `prescriptions.drug`, and `emar.medication`: Unicode lowercase, trim, collapse whitespace, remove punctuation except clinically meaningful slash, and remove only a preregistered list of formulation/strength suffixes after preserving the raw value. Do not use an external drug dictionary or infer therapeutic equivalence; `furosemide` and `Lasix`, for example, remain distinct unless a mapping was frozen before labels. Preserve raw strings and emit `UNMAPPED_NAME` rather than silently merging.

For each admission, define the **structured discharge set** `S_D` from `hosp/pharmacy` rows whose medication order interval overlaps `D` and whose `status` is not an explicit discontinued/cancelled status before `D`; independently define `S_P` from `hosp/prescriptions` rows whose `[starttime,stoptime)` overlaps `D`, retaining missing or contradictory intervals as `UNKNOWN_ORDER`. If multiple rows have the same canonical name, select the deterministic latest verified/entered record and retain a duplicate/conflict flag; no post-label selection is allowed. The primary order set is `S_D`; `S_P` is a source concordance sensitivity analysis, not a pooled rescue.

Define the **recent-administration set** `S_A` from distinct canonical names in `hosp/emar` with `event_txt == 'Administered'` and `charttime in [D-24h,D)`. `hosp/emar_detail` contributes dose/route completion detail only when joined by `(subject_id, emar_id)`; because the catalog identifies `subject_id` as its only reliable identity key, retain all detail rows and do not assume a unique `emar_seq` parent beyond the explicit `emar_id` linkage.

Define a **discharge-document set** `S_T` only from the canonical DS `note/discharge.text` using an exact, preregistered lexical match against names in `S_D ∪ S_A`, with section boundaries and negation/conditional markers frozen before outcomes are inspected. A matched name in a medication section is `MENTION_POSITIVE`, a negated or stopped mention is `MENTION_NEGATED`, and a name outside a medication section is `MENTION_UNLOCATED`; ambiguous context is `TEXT_UNKNOWN`. `note/discharge_detail` is retained as ordered field-level provenance (`note_id, field_name, field_value, field_ordinal`) but cannot be treated as a medication ontology. No LLM-generated labels, post hoc synonym dictionary, or free-text reviewer consensus may alter the primary exposure.

The primary exposure is a three-state transition phenotype:

* `CONCORDANT`: every structured discharge medication has a positive, non-negated DS match with compatible route when route is present and compatible dose/frequency when those fields are present, and every medication administered in the last 24h that is continued in `S_D` has compatible documentary support;
* `DOCUMENTARY_DISCORDANCE`: at least one `S_D` medication lacks a positive DS match or has a conflicting dose/route/frequency, while the record is otherwise parseable;
* `STRUCTURED_UNCERTAIN`: missing/contradictory order interval, unmapped medication name, duplicate conflict, unavailable canonical DS, or unresolvable text context prevents classification.

A separate `TRANSITION_CHANGE` flag records names in `S_A` absent from `S_D` and names in `S_D` absent from `S_A`; it is descriptive, not an error label. This distinction prevents the common invalid inference that stopping an inpatient medication is unsafe. A medication-level table is primary for process measurement; the admission-level indicator is the worst-case rule (`DOCUMENTARY_DISCORDANCE` dominates `CONCORDANT`, and any uncertainty dominates only when the discordance cannot be established).

## Prespecified hypothesis, estimands, and baselines

Primary descriptive estimand: weighted/unweighted prevalence of `DOCUMENTARY_DISCORDANCE` among all eligible index admissions, with Wilson or exact binomial intervals and a complete accounting of `STRUCTURED_UNCERTAIN`.

Primary prognostic estimand: absolute 30-day subsequent-admission risk difference and risk ratio comparing `DOCUMENTARY_DISCORDANCE` with `CONCORDANT`, with `STRUCTURED_UNCERTAIN` shown as a third category rather than complete-case deletion. Use robust standard errors clustered by `subject_id` because a subject may contribute multiple index admissions. The primary association model is a prespecified log-binomial or Poisson model with robust variance, adjusted only for baseline variables available before `D`: age class, sex, admission type, index length of stay, ICU exposure before `D`, and discharge location. Report the unadjusted contrast first; adjustment is prognostic standardization, not causal confounding control.

Prespecified clinical strata are ICU exposure (`icu/icustays.intime < D`), discharge location, and medication burden (`|S_D|` categories 0, 1-4, 5-9, >=10). The primary result must be directionally consistent in at least two of three nonempty strata to be described as reproducible; otherwise it is inconclusive. A negative control uses a **documentation-format control**: compare concordance for two independently ordered medication fields (route versus frequency) in admissions where both are present, testing whether the proposed parser creates artificial discordance from punctuation or section layout. A temporal negative control uses an outcome window before `D` (last 30 days before admission) only as a calibration association, never as evidence for the post-discharge mechanism.

Sensitivity analyses freeze, rather than select after seeing outcomes: (1) pharmacy-only versus prescriptions-only `S_D`; (2) 6-hour and 48-hour administration windows; (3) exact-name-only versus preregistered synonym-free normalization; (4) excluding admissions with any `TEXT_UNKNOWN`; (5) first admission per subject; and (6) competing descriptive outcomes for death during follow-up when available. Multiplicity is controlled by a single primary contrast and clearly labeled secondary analyses; no threshold is chosen to maximize association.

Falsification criteria are:

1. If parser-invariant formatting controls show discordance comparable to the primary signal, the medication phenotype is not validated and no workflow nomination is permitted.
2. If `STRUCTURED_UNCERTAIN` exceeds 20% or any key source join has >5% unexplained linkage loss, report feasibility failure rather than prevalence in the affected domain.
3. If the primary association reverses across the prespecified ICU and non-ICU strata or disappears under exact-name and source-restricted sensitivities, the result is considered non-robust/inconclusive, not confirmation.
4. A negative or null 30-day association does not refute medication harm or prove safety; it means this stored-data phenotype has not demonstrated prognostic separation.
5. A positive association is supportive only of prognostic enrichment and prioritization for prospective validation. It cannot establish that a discrepancy caused readmission, that a medication was inappropriate, or that reconciliation would improve outcomes.

## Evidence boundary and interpretation

MIMIC can measure stored medication orders, recorded administrations, discharge-document mentions, temporal concordance, and subsequent admissions/death fields. It cannot establish pre-admission medication truth, intentionality, appropriateness, allergy/contraindication status, patient understanding, dispensing, adherence, viewing, communication, responsible clinician, outpatient completion, or causal effect on readmission. A subsequent admission is not necessarily medication-related. Clinical adjudication of a sampled discrepancy set and prospective medication histories, pharmacy fill data, reconciliation actions, and workflow logs are required before any live alert or intervention. Supportive results nominate only a prospective silent feasibility study; adverse or inconclusive results block nomination or restrict it to a better-defined source/field subset.
