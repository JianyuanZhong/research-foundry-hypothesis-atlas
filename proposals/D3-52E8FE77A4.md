# Composition versus within-cell regulation of macrophage inflammatory signatures in RA

Seed: D3-M1
Domain: Disease Mechanisms & Pathway Hypotheses

## Unresolved question

In rheumatoid arthritis (RA), is the macrophage inflammatory signature (e.g., M1-like polarization) better explained by changes in macrophage cell abundance/composition, or by within-cell state changes (e.g., polarization, activation), or both? This question is consequential because it determines whether therapeutic intervention should target macrophage recruitment/abundance or macrophage polarization/activation.

## Evidence for the opening

- [K1] Batashkov et al. (2026) describe RA as a biologically heterogeneous immune-mediated disease with substantial variability in therapeutic response. The review discusses tissue immunophenotype and biomarkers of treatment response, but does not directly test whether macrophage inflammatory signatures are driven by cell composition or within-cell state changes.
- [K2] Mathew et al. (2026) describe FLS as key tumor-like mediators of RA. In the inflamed synovium, they expand, resist apoptosis, and secrete pro-inflammatory cytokines, chemokines, and proteases that sustain disease. The review discusses engineered immune cells to target FLS, but does not directly test whether macrophage inflammatory signatures are driven by cell composition or within-cell state changes.
- [K3] Wei and Xu (2026) describe refractory disease as an active failure of the program meant to end inflammation. Single-cell and spatial dissection of the synovium lets us recast the rheumatoid joint as a niche of failed resolution. The review discusses stromal-myeloid crosstalk and emerging resolution-restoring therapies, but does not directly test whether macrophage inflammatory signatures are driven by cell composition or within-cell state changes.
- E-MTAB-8322 contains pseudobulk macrophage expression data from RA and healthy donors. The pseudobulk design measures macrophages only, not whole tissue or a cell-state-resolved analysis. This provides a baseline for comparing inflammatory state markers but cannot directly measure cell abundance.
- E-MTAB-8873 provides a targeted assay (445 measured features) with FLS/coculture pseudobulk samples, enabling measurement of specific inflammatory markers in the same experimental system. The targeted assay cannot measure absent genes.
- E-MTAB-8316 contains four FLS donor clusters with six nested monocyte donors and twelve condition samples. The nested design allows donor-aware paired comparisons of monocyte/macrophone expression under the same donor context, including conditions with and without fibroblast contact.
- GSE95588 coculture data provide additional paired condition comparisons, though r1/r2 includes earlier GSE57723 data and cannot count as independent validation.

## Hypothesis

The macrophage inflammatory signature in RA is primarily driven by within-cell state changes (polarization/activation) rather than changes in macrophage cell abundance/composition. This hypothesis is testable by comparing the magnitude of inflammatory marker changes within the same donor context (within-cell state) versus across different donor contexts (composition).

## Competing explanations

1. **Composition-driven**: The inflammatory signature is primarily driven by changes in macrophage cell abundance/composition. This would be supported if inflammatory marker changes are larger across different donor contexts than within the same donor context.
2. **Within-cell state-driven**: The inflammatory signature is primarily driven by within-cell state changes (polarization/activation). This would be supported if inflammatory marker changes are larger within the same donor context than across different donor contexts.
3. **Both**: The inflammatory signature is driven by both composition and within-cell state changes. This would be supported if inflammatory marker changes are significant in both within-donor and across-donor comparisons.

## Falsifiable test

Compare the magnitude of inflammatory marker changes within the same donor context (within-cell state) versus across different donor contexts (composition) using donor-aware paired comparisons. If the within-donor changes are significantly larger than the across-donor changes, this supports the within-cell state-driven hypothesis. If the across-donor changes are significantly larger, this supports the composition-driven hypothesis. If both are significant, this supports the both hypothesis.

## Measurable outcomes

- **Supportive**: Within-donor inflammatory marker changes are significantly larger than across-donor changes, supporting the within-cell state-driven hypothesis.
- **Adverse**: Across-donor inflammatory marker changes are significantly larger than within-donor changes, supporting the composition-driven hypothesis.
- **Inconclusive**: Both within-donor and across-donor changes are significant, supporting the both hypothesis.

## Limitations

- The pseudobulk design of E-MTAB-8322 measures macrophages only, not whole tissue or a cell-state-resolved analysis. This limits the ability to directly measure cell abundance.
- The targeted assay of E-MTAB-8873 only measures 445 features, and unmeasured genes are unavailable.
- The nested design of E-MTAB-8316 has only four FLS donor clusters and six nested monocyte donors, limiting the generalizability of the results.
- The coculture data of GSE95588 includes earlier GSE57723 data and cannot count as independent validation.
