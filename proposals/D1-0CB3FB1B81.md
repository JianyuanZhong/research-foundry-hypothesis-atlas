# Joint assay-validity and missing-Y/ascertainment contract for frozen HCC repeat-TACE P-beyond-B validation

## Targeted repair and single remaining weakness

This is a substantive two-parent successor of `[prior hypothesis]` and `[prior hypothesis]`. It preserves the frozen adult HCC repeat-TACE population, systemic-record/comparator ontology, selected repeat-event rule, B/P/event/Y clocks, annual forward origins and blocks, nested ridge models, observed complete-triplet standardized held-out RMSE estimand, assay separation, patient-frequency bootstrap, and strict noncausal boundary.

The most consequential remaining weakness is an interface failure between the two otherwise strong repairs: assay-validity/heterogeneity warnings are audited downstream, while the missing-Y bounds can still be computed from a raw finite-value stream without a single typed contract saying which rows, ranges, predictions, and interpretation labels are allowed to flow together. This leaves a compiler able to report a favorable raw complete-case gain, a mathematically valid-looking all-BP bound, and an assay-comparability warning without deterministically resolving whether the result is supportive, selection-sensitive, inconclusive, or unsupported. The repair makes one joint, fail-closed data lineage explicit. It does not change the scientific estimand or claim that missing Y has been observed.

The unresolved question remains: in selected adult HCC repeat-TACE episodes, does contemporaneous pre-repeat recorded assay P add short-horizon prognostic information beyond remote B and the locked pre-event core for the subsequently recorded same-assay Y? The result is a prognostic association on a recorded-value scale only. It is not treatment response, a treatment effect, laboratory validity, liver function, tumor response, safety, utility, actionability, or benefit.

## One typed row ledger and data-flow contract

Every exact-target labs row receives a retained immutable ledger record before any window selection. Required fields are source row ordinal (assigned during a single deterministic full scan), patient/encounter keys, exact assay, parsed result time, raw quantitative and qualitative strings, specimen-label-present flag, and one mutually exclusive `row_status`.

1. `assay_non_target` if `检验` is not exactly `白蛋白` or `总胆红素`; it can never enter a target stream.
2. `time_invalid` if `检验时间` is missing, malformed, non-finite, or cannot be parsed by the one declared timezone-naive parser. No timezone conversion or inferred collection time is allowed.
3. `qualitative_only` if `定性结果` is nonempty but `定量结果` is not a valid scalar; it can never become B/P/Y.
4. `numeric_invalid` if the quantitative string is empty/null, NaN/Inf, interval/censored (`<`, `>`, `≤`, `≥`), mixed text, or not consumed in full by a strict numeric grammar after only documented whitespace trimming. Do not use `定性结果` as fallback.
5. `numeric_valid_unknown_specimen` if the scalar and time are valid but `标本类型` is empty/unknown.
6. `numeric_valid_specimen_labeled` if the scalar/time are valid and `标本类型` is nonempty. This means label present, never adequacy, serum/plasma equivalence, collection provenance, analyzer, method, or final status.

Only statuses 5 and 6 can be candidates for B/P/Y, and both are retained in the **primary raw recorded-value stream** so the frozen finite-value estimand is not changed. A separate `specimen-labeled sensitivity stream` uses status 6 only; it is never silently substituted for primary. Exact assay identity is carried through every downstream key; albumin and bilirubin are never pooled.

For equal assay/patient/encounter/timestamp candidates, select with the inherited tie rule, but first assert that the rule is present and deterministic in the compiled implementation. If duplicate rows remain unresolved after that rule, emit `duplicate_time_unresolved` and stop the affected assay/block as `unsupported`. The source ordinal is a tie-break audit key only, not a clinical ordering claim.

## Joint missing-Y bounds and assay audit

Run the missing-Y contract separately per assay, origin, block, and arm on the exact all-`BP_eligible` set produced by the primary raw stream. Let N be all BP rows (or N_a in an arm), not complete triplets. Fit on observed complete raw triplets only and freeze finite p0/p1 for every BP row. `L_train` and `U_train` are the min/max accepted raw Y values in the exact finite training parser, before future Y inspection. Empty/degenerate range, nonfinite predictions, or observed future Y outside the training range makes that block's temporal bound `unsupported`; never widen using future or full-source values.

For observed rows use `d_i=(Y_i-p0_i)^2-(Y_i-p1_i)^2`. For missing rows use the exact endpoint contrast
`min/max{2*y*(p1_i-p0_i)+p0_i^2-p1_i^2 : y in {L_train,U_train}}`.
The all-BP affine contrast bounds are the sums of observed d and missing-row minima/maxima divided by N (or N_a). Report all-L, all-U, and least-favorable missing-Y scenarios. Separately report model-specific MSE endpoint intervals and the conservative non-primary RMSE-difference enclosure; never call it sharp and never standardize it by an unidentified test SD. Fixed predictions and the original test-Y SD are retained for the optional paired patient bootstrap; bounds are not confidence intervals and never become weights or imputations.

The audit must be joined to these exact row sets by assay, patient/event key, origin, and block, and must report for each raw and specimen-labeled stream: row-status counts, duplicate/tie counts, N/BP/Y counts, observation fractions, calendar year, encounter department (not site/analyzer), selected-event versus B encounter, specimen-label presence, qualitative-only/invalid categories, and outcome-blind exam/follow-up/document opportunity strata. The diagnostic observation model uses only pre-Y B/P/age/sex/timing/arm and outcome-blind flags; it is descriptive, not MAR evidence, an imputation, or a primary weight. Train-only rank-normal and within-assay robust transforms are diagnostics only, with no units or clinical thresholds.

A raw primary result cannot be labeled supportive merely because its bound is positive. A valid assay audit must also show no material row-status/observation/department/calendar gradient under the predeclared minimum (formal cells require at least 10 BP rows; smaller cells are descriptive/inconclusive), and every estimable assay-specific audit scale must agree in direction. If specimen metadata are required for the requested claim, the claim is unavailable rather than inferred.

## Ordered verifier and fail-closed interpretation

The compiler emits a machine-readable `joint_status` with reasons and row-set hashes. Apply this precedence, never allowing a lower row to override a higher one.

1. `unsupported`: source/schema/hash/header mismatch; duplicate-causing join; unresolved tie; fuzzy assay match; invalid/full-consumption parser; non-target or qualitative coercion; post-event leakage into P, transforms, range, or support; missing native time used as a clock; negative-control failure; or any clinical/unit/site/analyzer claim not supported by fields.
2. `inconclusive`: failed inherited cohort/BP/complete-triplet gate; empty/degenerate training range; out-of-range future Y; nonfinite predictions; zero/undefined SD; insufficient training support for a transform; sparse/degenerate audit strata; unavailable specimen/final-result metadata when required; or nonestimable bootstrap.
3. `adverse_primary`: only a nonpositive adequately supported frozen primary contrast or wholly nonpositive all-BP global envelope. Assay warnings alone are not adverse clinical evidence.
4. `selection_sensitive`: the primary observed gain is favorable but any all-BP envelope crosses zero, raw versus any estimable within-assay audit transform disagrees materially, specimen-label restriction changes direction, or material observation/row-status/calendar/department heterogeneity is present. It is not supportive.
5. `supported_recorded_scale_association`: only if all inherited gates pass, raw and every estimable assay-specific audit scale have concordant direction with declared uncertainty, no material validity/heterogeneity warning exists, and the global all-BP bound is strictly positive throughout the declared training-range scenario. This supports only a selected short-horizon association on the recorded-value scale.

`unsupported` outranks `inconclusive`, which outranks `adverse_primary`, which outranks `selection_sensitive`, which outranks `supported_recorded_scale_association`. A successful formula oracle, parent executed audit, or favorable observed complete-case estimate cannot override a failed full-source joint pass. No status supports units, analyte comparability across laboratories, specimen adequacy, final result status, collection-time validity, physiologic meaning, imaging response, treatment administration/intention, mortality, external-care capture, causality, utility, or benefit.
