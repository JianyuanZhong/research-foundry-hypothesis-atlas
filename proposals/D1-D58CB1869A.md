# Modality-pattern-specific report-access requirements for documentary-M2 triage

## Unresolved clinical question and advance

The decision remains narrow: 24 hours before an adult patient's first eligible liver resection, can routine CT/MRI report semantics add enough information to a laboratory-independent risk flag to justify multidisciplinary review for pathology-documented high-grade microvascular invasion (M2)? The output is a historical classification/review flag, not a recommendation for resection extent, transplant, systemic or locoregional therapy, or surveillance.

**Strongest evidence-supported claim.** The HCC snapshot contains operation start times, imaging acquisition start times, eventual CT/MRI report text, and untimed same-encounter pathology text. It does not contain radiology report authored/final/release/view times, pathology time or specimen identifiers, images/slides, pathology sampling, recurrence, survival, clinician action, or treatment benefit. The lab source has only one ambiguous `检验时间` and lacks collection, finalization, release/view, accession/panel and units; laboratory data therefore have zero primary lineage. These are source facts, not evidence that a model works.

The inspected full XML of Li et al. (2025; DOI `10.1111/jcmm.70746`, PMCID `PMC12309289`, source `[source checksum]`, [source checksum]) supports that MVI is pathology-defined, prognostically relevant and unavailable directly before surgery, while management and predictive evidence remain controversial. The inspected full HTML of Huang et al. (2026; DOI `10.3389/fonc.2026.1821034`, source `[source checksum]`, [source checksum]) reports a retrospective multicenter binary-MVI CT/AFP model (487 development, 256 external validation; AUC 0.740 and 0.781), with complete-data eligibility, raw-image review and specified pathology sampling. It does not validate M2, stored report semantics, report availability, this institution, or treatment benefit.

The selected parent validly separates semantic action changes within the same fitted model (`D=S-S0`) from the value of the complete semantic strategy against an independently optimized baseline (`C=S-B`), and gives a conservative scalar frontier indexed by the fraction with at least one report visible. The remaining question is whether that pooled requirement is clinically informative when stored report patterns and access can differ for CT-only, MRI-only and dual-modality patients. A scalar frontier is valid but can hide that support depends almost entirely on one modality or impose adversarial modality mixtures contradicted by an eventual audit.

**Primary stored-content hypothesis P (retained).** In the locked 2020–2021 whole target frame with every selected nonempty stored report exposed, simultaneous 95% lower confidence limits for both D and C at threshold 0.30 exceed the clinical margin 0.01; both point lower bounds remain positive at every threshold 0.25–0.35; S beats flag-all and flag-none.

**New transport hypothesis T.** There is a nonempty prespecified set of minimum access guarantees stratified by stored-report pattern under which simultaneous lower limits for D and C exceed 0.01 and S beats both defaults, even after adversarial assignment of visibility and unresolved Y within each pattern. T is not a claim that those guarantees hold. Deployment support additionally requires a separate source-system audit whose joint lower confidence bounds satisfy one supportive guarantee. Without that audit, Harbor can establish stored-content potential and an access service-level requirement, not historical visibility or deployment value.

The substantive advance is an exact bridge between model value and the modality-pattern access table that an operational audit can measure. It can show that a pooled favorable result is MRI-dependent, CT-dependent, robust to access mix, impossible at any access mix, or simply unresolved.

## Frozen population, clocks and endpoint

The unit is one patient (`患者主索引`) and the earliest eligible liver resection.

1. In `procedures`, use a frozen clinically reviewed exact-`手术` dictionary for partial, segmental, hemihepatic or liver-tumor resection. Exclude transplant, biopsy/puncture, ablation-only, gallbladder-only, metastatic-organ and explicit repeat/recurrence operations. Require valid `开始时间`; break ties by `就诊号` then normalized `手术`. Emit all raw values/frequencies, exclusions, invalid times and ties before outcome access.
2. Require age >=18 and same-encounter pathology explicitly identifying HCC. This is a retrospectively resected, pathology-confirmed frame, not proof of preoperative certainty, curative intent or biological treatment-naivety.
3. Define `t_dec=procedures.开始时间-24 hours`; no record at or after t_dec predicts. Lock 12-, 48- and 72-hour sensitivities.
4. Using a clinically reviewed exact-`检查` dictionary, select liver CT/MRI acquired in `[t_dec-90 days,t_dec)`. Deduplicate exact rows; bundle by `(患者主索引,就诊号,检查号,开始时间)`, with missing `检查号` creating a row bundle. Select at most the latest CT and latest MRI, using `开始时间`, `检查号`, normalized `检查` as tie breakers. Require at least one eligible bundle. Acquisition does not prove report availability.
5. Exclude recorded HCC resection, transplant, TACE, ablation, radiotherapy, targeted therapy or immunotherapy in `[t_dec-365 days,t_dec)` from frozen dictionaries in procedures, medications and non-drug orders with valid source times. Report invalid times and exclusions by source; previously treated patients are separate.
6. Development 2015–2018; penalty selection and recalibration 2019; untouched test 2020–2021. One period per patient; exclude 2013–2014. Use 2022–2025-11-11 only for extraction/template and endpoint-identifiability audit, never contemporary performance.
7. Freeze dictionaries, parsers, features, state order, preprocessing, penalties, solver, thresholds, bootstrap family, access-grid and gates before test outcomes.

Report actual attrition, invalid clocks, duplicates, join multiplicity, dictionary frequencies, selected/discarded bundles, report storage patterns, state cardinalities, endpoint states, and period/event counts. A lead audit using deliberately broad, non-adjudicated regexes found 25,401 possible first resections and selected nonempty patterns of 11,701 MRI-only, 368 CT-only, 204 dual and 13,128 none. These counts only motivate the exact pattern table: HCC pathology and prior-treatment exclusions were not applied and the dictionaries are not final, so they cannot be used as prevalence or feasibility gates.

The endpoint is documentary M2. `Y=1` only for pathology-assigned M2 and `Y=0` for assigned M0/M1. `V=1` requires trustworthy index-specimen assignment under a frozen position-aware parser and blinded clinical adjudication. Missing grade, binary positive MVI, conflict, uncertain specimen linkage or inadequate documented sampling is `V=0`, retained in the denominator.

Only an immediate selected value after an anchored field such as `MVI提示风险分级[:：]`, stopping before definitions/history/another specimen, or a frozen synonymous construction can assign grade. Two independent parsers must agree. Two qualified Chinese-reading pathologists blinded to predictors/scores review every parsed M2, every conflict, every test V=0, and >=150 M0 plus >=150 M1 stratified by year/template; a third resolves disagreement. Require class PPV >=0.98, sensitivity >=0.95, kappa >=0.90 and parser disagreement <=5%. Raw slides, sampling and biological M2 require another study.

## Report states, models and baselines

For patient i retain at most one selected CT bundle and one selected MRI bundle. Let the stored-report pattern `g_i` be C, M or CM according to which selected bundles have nonempty eventual `检查所见` or `检查诊断`. Empty text has only unavailable state. Feasible visibility states are `Omega_i={0,1}^{q_i}` in frozen CT-then-MRI order. A visible bit exposes that bundle's stored body; unavailable masks every body-derived size, count, thrombus, formatting and semantic item. Preserve acquisition-only modality, time, bundle count, distinct ID count without ID, and development-frequency machine category. No probability or independence assumption is allowed.

All primary models are interpretable elastic-net logistic regressions fit, tuned, recalibrated, bootstrapped and null-refit with the parent's exact patient-wise worst-state convex logistic objective. Equal-state, all-report and no-report fits are diagnostics.

- B: age, sex, acquisition indicators, development-frequency machine category and, only when the report is exposed, frozen maximum lesion diameter, count category and explicit macrovascular thrombus with unknown indicators.
- S: exactly B plus frozen present/absent/unknown report-semantic features for capsule, irregular margin, satellite/peritumoral lesion or enhancement, arterial hyperenhancement, washout and peritumoral hypointensity.
- S0: never refit. Use S's exact fit, preprocessing and recalibration but set only the semantic block to its state-zero vector. Require exact `score_S=score_S0` whenever no semantic report is exposed.
- W and A=W+the identical semantic block remain secondary workflow/provenance diagnostics. Unrestricted text is a ceiling only.

No laboratory value, row presence, assay/specimen, count, missingness or time may enter any primary matrix, state, fit, threshold, stratum or gate. Prove zero lineage.

Two blinded radiologists adjudicate extraction by year, modality and storage pattern. Require size agreement within 5 mm or 10% in >=90%, count agreement >=90% and kappa >=0.80, and PPV/sensitivity >=0.85 for every binary semantic feature in every claimed year/modality stratum.

## Estimands and exact access requirements

At threshold p let `w=p/(1-p)`, `I_Mi(r,p)=1[score_Mi(r)>=p]`, and for contrast j=(M1,M0):
`d_i^j(y,r,p)=[y-w(1-y)]*[I_M1i(r,p)-I_M0i(r,p)]`.
Primary contrasts are D=(S,S0) and C=(S,B). For V=0 enumerate y in {0,1}; V=1 uses adjudicated Y. Never impute or drop.

Compute the parent's all-report potential and one-dimensional any-visible frontier unchanged as a conservative benchmark.

For the new pattern frontier define binary access indicators `a_Ci(r)`, `a_Mi(r)`, and `a_Ai(r)=max(a_Ci,a_Mi)`. Freeze a finite service-level grid G before test access: 0,0.05,...,1.00, rounded upward to integer counts on the whole N. A grid point `h=(h_A,h_C,h_M)` imposes `sum a_A>=ceil(Nh_A)`, `sum a_C>=ceil(Nh_C)`, and `sum a_M>=ceil(Nh_M)`, while each patient's state must remain in Omega_i. Mark structural infeasibility from stored-pattern counts.

For each feasible h, j and p compute sharp
`L_j(h,p)=N^-1 min_{r_i in Omega_i,y_i} sum d_i^j(y_i,r_i,p)`
and the corresponding maximum. Fold `min_y`/`max_y` into each patient-state cost, then solve the one-state-per-patient 0–1 linear program with the three access constraints using a deterministic open-source MILP solver, zero gap tolerance, fixed version/seed and exported certificates/status. Verify against brute-force enumeration on all fixtures with N<=10 and against the scalar dynamic program when h_C=h_M=0. More than 0.1% unsolved grid cells or any nonzero certified gap fails inference. Coordinatewise extrema are not one latent world.

A grid point is supportive only if at p=0.30 simultaneous lower limits for D and C both exceed 0.01, S exceeds both defaults, and point lower bounds for D/C are positive for p=0.25,...,0.35. The support set is upward closed because constraints are lower bounds; machine-check this and report its Pareto-minimal antichain. Empty support set is adverse when all gates pass. The parent scalar c* remains the most conservative one-number summary.

An external audit must sample the same target workflow and apply t_dec and identical bundle selection. For every selected stored bundle it must obtain final/release time and preferably clinician-view time, then report on the whole target denominator the joint CT-visible, MRI-visible and any-visible counts, including the stored-pattern cross-tab C/M/CM. Report a simultaneous one-sided 97.5% lower confidence region for (h_A,h_C,h_M), accounting for clustering/repeated workflow and modality. A deployment-conditional claim requires every point compatible with that confidence region after conservative grid rounding to lie in the model support set. Use 97.5% simultaneous model bounds; Bonferroni across independent model and audit components gives joint error <=5%, otherwise use joint resampling. Order/acquisition time or nonempty eventual text is insufficient. This evidence is unavailable here.

## Inference, gates and falsification

Use 2,000 patient bootstraps within calendar period, rebuilding states and refitting the complete pipeline. Use a max-absolute-centered-deviation band jointly over D/C lower and upper endpoints, all prespecified thresholds, scalar frontier points and feasible pattern-grid points. Pointwise intervals are descriptive. More than 2.5% failed bootstrap fits fails inference.

Retain 1,000 semantic-null repetitions permuting the whole semantic block within frozen year, modality/storage pattern, state cardinality and formatting availability in development/tuning only, followed by full robust refit and S0 reconstruction. All-report D at 0.30 must exceed its 97.5th null percentile. Label permutation must be null; post-cutoff injection must trigger leakage controls.

Global gates: test N>=1,000; >=75 adjudicated V=1 M2; V=1>=85%; every test V=0 reviewed; all parser/radiologist thresholds pass; nonempty report text >=80%; size/count jointly extractable >=70%; missingness shift from 2019 to either test year <=15 percentage points; exact robust/MILP convergence; complete inference; identical states within contrasts; and zero forbidden/lab lineage. Any modality-specific claim additionally needs >=100 patients and >=20 V=1 M2 in that modality/storage stratum. Report AUPRC, AUROC, Brier, calibration intercept/slope, sensitivity, specificity, PPV and NPV among V=1 in all/no-report diagnostics. A global strategy claim requires slope 0.80–1.20, intercept -0.10–0.10, sensitivity >=0.70 and PPV >=0.50 at 0.30 in both diagnostics.

- **Supportive P:** every gate passes; all-report simultaneous lower limits for D and C exceed 0.01; threshold plateau/default/null gates pass. Conclude only that stored routine report semantics made materially favorable action changes within frozen S and complete S beat B in this historical documentary-M2 frame under maximal stored content.
- **Supportive T, audit absent:** P passes and the pattern support set is nonempty. Conclude only that specified access guarantees would be sufficient under adversarial visibility/outcome assignment; deployment remains inconclusive.
- **Deployment-conditional:** the external audit confidence region lies wholly in the support set under the joint error rule. Conclude conditional historical transport to that audited workflow, not clinical benefit.
- **Adverse:** gates pass but all-report D is nonpositive or its upper limit is below 0.01, C/default/null gates fail, or the pattern support set is empty. More visibility cannot rescue all-report failure.
- **Mixed:** D supportive/C adverse means semantic values improve actions within S but S does not beat optimized B; C supportive/D adverse means refitting/shared-feature changes, not runtime semantics, may explain value. Do not recommend S.
- **Inconclusive:** any gate/solver/adjudication/event threshold fails, intervals cross boundaries, report-pattern cells are too sparse for a claimed modality, or audit is absent for deployment. AUC, a point estimate, one grid cell or unrestricted text cannot rescue it.

No result identifies actual report availability from this snapshot, latent biological M2, accepted workload/threshold, clinician response, treatment effect, recurrence, survival, harms, costs or patient benefit. These require source-system evidence, expert/stakeholder review, prospective validation or another study.

## Compiler and verifier contract

The compiler must preserve population, t_dec/windows, temporal split, Y/V whole-frame endpoint, report states, robust fits, zero lab lineage, fitted S/non-refitted S0, D/C, all-report P, scalar benchmark, pattern constraints, exact MILP, simultaneous inference and result zones. Replacing lower constraints with average/random visibility, collapsing patterns before the new frontier, using separately fitted S0, complete-case Y, or treating eventual text as visible is a scientific change.

Computational checks include hashes/headers, dictionaries, joins, clocks, masks/order, storage patterns, zero forbidden lineage, robust objective, S=S0 at semantic-zero, Y/V enumeration, whole N, MILP certificates and brute-force fixtures, scalar equivalence, upward closure/Pareto antichain, bootstrap/null families, audit-presence gate and conclusion linkage. Fixtures must include supportive P without audit (deployment rejected), supportive conditional transport, MRI-dependent and CT-dependent mixed patterns, all-report adverse, sparse/inconclusive, S0-refit, fabricated timing, equal-state fitting, pointwise-as-simultaneous, favorable AUC/adverse NB, and numerically correct outputs paired with unsupported treatment/survival/biological-M2 claims.

The verifier cannot establish Chinese semantics, reviewer credentials, actual report finalization/view, audit representativeness, pathology linkage/sampling, biological M2, threshold/workload acceptability, clinician action, treatment effect, recurrence, survival, harms, costs or patient benefit. Reference execution proves computation and conclusion linkage, not scientific truth.
