# Ventilatory burden and liberation from mechanical ventilation: construct-valid repair

## Scientific question and unresolved claim

The clinically important question is whether a prespecified ventilatory-burden measure contains information about failure to liberate from mechanical ventilation that is not present in a simple tidal-volume model, after accounting for death and transfer/discharge. This could justify a prospective multicenter study of weaning risk and could identify whether pressure-related information is useful for an automated alert. It is not a treatment-effect study.

The parent hypothesis is retained, but its strongest claim is narrowed. The available eICU source does not validate that the named fields are measured tidal volume or plateau pressure. Therefore the test is no longer “ventilatory burden” as if those fields were physiology. It is a prespecified, explicitly labeled **ventilatory burden proxy**, whose scientific value is whether it adds information beyond tidal volume. If the proxy is not clinically interpretable, the result is adverse to the original burden hypothesis and the direction should be deferred.

The strongest evidence currently supports only that eICU contains longitudinal respiratory-care and vital-sign records with timestamps and patient-level identifiers. It does not establish that any named field is a measured physiology, that a ventilator interval is complete, or that discharge weight is available at the index. The experiment will test an association/prediction claim, not a causal or mechanistic claim.

## Construct validity and source audit

- `vitalPeriodic.csv.gz` has `vitalperiodicid`, `patientunitstayid`, `observationoffset`, `sao2`, `heartrate`, `respiration`, `cvp`, `etco2`, and vital signs.
- `hospital.csv.gz` has `hospitalid`, `numbedscategory`, `teachingstatus`, and `region`.

The actual header audit found 865,381 respiratory-care rows with 34 columns. The explicit airway categories are `Oral ETT`, `No Artificial Airway`, `Tracheostomy`, `Nasal ETT`, `Other`, `Double-Lumen Tube`, and `Cricothyrotomy`; `airwayposition` contains center/right/left and numeric values, plus many nonstandard values. `cuffpressure` has values in the plausible range (e.g., 20, 22, 24, 25, 26, 28, 30 mmHg), but it is not validated as cuff pressure in this snapshot. The `*limit` fields are populated in many rows (for example `lowexhtvlimit` 100, 200, 300; `lowpeakpreslimit` 2, 3, 5, 8; `hirespratelimit` 20–50; `lowrespratelimit` 1–20; `cpaplimit` 0–20), whereas `ventstartoffset` is `0` in 685,205 of 865,381 rows and `ventendoffset` is `0` in 865,224 rows. These patterns are consistent with status rows and alarm/setting fields, not validated measured physiology. The exact headers and counts are recorded in the attached audit.

No public search or full-text acquisition established the meaning of these eICU fields. The available literature was used only as a caution: cuff-pressure monitoring can be measured, but this field is not certified as such here; alarm limits and status timestamps do not establish ventilation volume or plateau pressure.

## Population, index, and temporal boundaries

Use ICU-stay rows from `patient`, joined by `patientunitstayid` to `respiratoryCare`, `vitalPeriodic`, and `hospital`. Do not treat rows with the same `patientunitstayid` as independent observations.

Include a stay only if all of the following are true:

1. `unitstaytype` is exactly `ventilator` or `ventilator_vent`.
2. `unitadmittime24` and `unitdischargeoffset` are valid.
3. At least 24 hours of respiratory-care rows exist after admission.
4. At least 48 hours of valid `vitalPeriodic` rows exist after admission.
5. At least one respiratory-care row has an explicit ventilator airway type and a valid `ventstartoffset > 0`.
6. The first valid `ventendoffset` is at least 24 hours after admission and at most 72 hours after admission.
7. There is at least one respiratory-care row after the first valid `ventendoffset` and before the first event.

The time origin is ICU admission (`unitadmittime24`). The index is the first valid `ventendoffset` in the 24–72-hour window, not the first ventilator start. The primary outcome window is 0–48 hours after index. A patient who dies, is transferred, or leaves the ICU before 48 hours has a competing event at that time. A patient discharged alive from the ICU with no recorded ventilator interval in the window is censored at 48 hours.

Exclude stays with multiple ventilation intervals in the index window. Report a sensitivity analysis using all eligible intervals and excluding stays with any prior interval. Do not use `priorventstartoffset` or `priorventendoffset` as primary physiology.

## Variables

The primary exposure is a 15-minute interval-level proxy defined only from explicitly labeled fields:

- **tidal volume proxy:** `lowexhtvlimit` only if the source header and row semantics are explicitly validated as tidal volume. It is not used unless that validation is added by a future solver.
- **plateau pressure proxy:** `meanairwaypreslimit` only if explicitly validated as plateau pressure. It is not used unless that validation is added.
- **respiratory rate proxy:** `hirespratelimit` only if explicitly validated as respiratory rate.
- **oxygenation:** the latest valid `sao2` in the 15-minute interval.
- **body size:** admission height from `patient`; weight is excluded from the primary analysis.
- **monitoring density:** the number of valid respiratory-care and `vitalPeriodic` observations per 24 hours, missingness counts for each measured field, and time since the last observation.

The primary burden proxy is a standardized weighted sum of the validated tidal-volume, plateau-pressure, and respiratory-rate components divided by admission height. It is a descriptive proxy, not a treatment assignment. If any component is not explicitly validated, use the prespecified single-component tidal-volume model and report the burden model as unavailable. The burden model must not be interpreted as measured physiology.

The simple baseline uses tidal volume, admission height, monitoring density, and hospital effects. The substantive alternative adds the validated plateau-pressure and respiratory-rate components to the burden proxy. This comparison tests whether pressure and rate add information that the tidal-volume proxy loses; it does not claim that the alternative is clinically causal.

A secondary, exploratory analysis may use `cuffpressure` only if the solver obtains a trustworthy field-level validation. It would be labeled an airway-cuff-pressure proxy, not cuff pressure, and would not be substituted for plateau pressure.

## Outcomes, estimand, and analysis

The primary outcome is time from index to the first of:

1. liberation from mechanical ventilation: no recorded ventilator interval after the index and no subsequent ventilator status in the 48-hour window;
2. death; or
3. transfer/discharge from the ICU.

Use the time to the first event. A patient with no event by 48 hours is censored at 48 hours. Report the restricted mean time to liberation from index to 48 hours, cumulative incidence functions, cause-specific hazards for liberation, death, and transfer/discharge, and the difference in restricted mean time to liberation between the burden model and the tidal-volume baseline with a 95% confidence interval and two-sided test.

The primary estimand is the difference in restricted mean time to liberation at 48 hours, conditional on the prespecified population and index. Report calibration intercept/slope, calibration-in-the-large, Brier score, and discrimination metrics. Use hospital as a fixed effect because hospital characteristics are available. Do not use hospital as an instrumental variable or make a causal claim. Report event counts, censoring, missingness, and hospital-level estimates. Use a prespecified bootstrap or cluster-robust standard error with clustering at `patientunitstayid` and at the hospital level.

## Baseline and substantive alternative

The baseline is a transparent competing-risk model with tidal volume, admission height, monitoring density, and hospital effects. The alternative is a transparent mechanistic/physiologic model adding validated plateau pressure and respiratory rate to the burden proxy. Both use the same population, index, outcome window, covariates, and evaluation. The alternative can reveal whether pressure and rate add information that a tidal-volume proxy loses; a small predictive improvement is not sufficient for clinical value.

A neural sequence model is deferred because the available longitudinal rows are sparse and the primary question is a bounded physiologic comparison. Revisit it only if complete patient-level trajectories and computational resources justify it, with whole-hospital holdout and explicit calibration. A mechanistic ventilator model using plateau pressure and airway resistance is deferred because plateau pressure is not validated here. A treatment-effect study requires a randomized or adequately identified intervention, treatment adherence, and outcomes not represented in this snapshot.

## Falsification and interpretation

Supportive evidence requires a clinically meaningful, precisely estimated improvement in the burden proxy over the tidal-volume baseline, with better discrimination/calibration and a positive difference in restricted mean time to liberation, while the improvement persists after hospital and monitoring-density adjustment. It would support the hypothesis that the proxy adds information; it would not establish that increasing tidal volume improves outcomes or that the proxy is a causal treatment target.

Adverse evidence is a null or negative difference, or a burden model that performs worse or is less well calibrated than the tidal-volume baseline. This argues against adding pressure/rate components to this risk measure and against interpreting the seed as a basis for a new alert.

Inconclusive evidence includes a wide confidence interval, unstable event counts, excessive missingness or unknown ventilation states, or a result that disappears after hospital and monitoring-density adjustment. It would justify narrowing the question or collecting more complete data rather than changing the interpretation.

Falsification checks are:

1. Exclude patients with sparse or highly irregular recording density; the burden effect should not be driven by monitoring intensity.
2. Exclude unknown ventilation states and report the proportion excluded.
3. Repeat with the alternative state definition and with 48-hour versus 72-hour index windows.
4. Repeat with death as the only competing event and with transfer/discharge as a separate event.
5. Compare the pooled estimate with hospital-level estimates and exclude the top 20% of hospitals by event count.
6. Remove the burden proxy; if the apparent burden effect disappears, the result is not robustly attributable to the added physiology.
7. Verify that no derived file is written to the configured source paths and that source rows remain read-only.

A supportive result would justify a prospective multicenter study with explicit ventilator measurements, sedation, organ-support, and treatment data. It would not justify changing bedside ventilation settings from this retrospective analysis. A causal effect, mechanism, or recommendation for a specific target requires expert review, more complete clinical data, and ideally a randomized or adequately identified interventional study.

## What is and is not acceptable

- **Measured physiology:** Only fields explicitly validated as measured physiology may be called physiology. In this snapshot, `cuffpressure` is the only plausible measured pressure field, but it must be validated before use. `lowexhtvlimit`, `lowpeakpreslimit`, `meanairwaypreslimit`, `hirespratelimit`, `lowrespratelimit`, `sighpreslimit`, `peeplimit`, and `cpaplimit` are not validated as measured physiology.
- **Alarm limits:** The `*limit` fields are not treated as physiology. They may be described as alarm/setting fields and are used only for missingness and monitoring-density variables.
- **Ventilator intervals:** `ventstartoffset` and `ventendoffset` are status timestamps, not validated ventilator intervals. The index and outcome use them only with the explicit rules above; absent or contradictory values are unknown and excluded from the primary state definition.
- **Discharge weight:** `dischargeweight` is available in `patient`, but it is not available at the ICU-admission index and may reflect later ICU discharge or transfer. It is excluded from the primary analysis and used only as a sensitivity analysis if the solver can justify its timing.
- **Unknown states:** Unknown airway type, position, or interval are retained in the sensitivity analysis and cannot be silently imputed. They are reported as a limitation.
