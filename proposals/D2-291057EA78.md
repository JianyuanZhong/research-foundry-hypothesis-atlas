## Estimand and analysis
For each target gene, estimate the difference in intervention-associated log2 fold change between the fibroblast-enriched context and the macrophage-enriched context, using donor-aware paired contrasts. The primary estimand is the context-by-intervention interaction: (Δlog2FC_fibroblast) − (Δlog2FC_macrophage), where Δlog2FC is the intervention-minus-control change within each context. Use donor-level pseudo-bulk summaries and a permutation test that preserves donor pairing. Report effect size, 95% confidence interval, and permutation p-value.

## Competing explanations
1. The context difference reflects baseline expression differences rather than a true interaction.
2. Donor composition or technical batch effects drive the apparent context dependence.
3. The intervention response is indirect (e.g., via macrophage-derived signals) rather than a direct target effect.
4. The assay does not capture the relevant cell state or time point.

## Falsification
The hypothesis is falsified if the context-by-intervention interaction is not significantly different from zero after donor-aware permutation testing, or if the apparent interaction is explained by baseline expression or batch effects.

## Method comparison
- Baseline: donor-aware paired permutation test on pseudo-bulk log2 fold changes.
- Alternative: a simple linear model with donor and context fixed effects, estimated by ridge regression, to quantify the interaction while controlling for donor-level confounding.
- The alternative could reveal whether the interaction is robust to donor-level confounding, which the baseline permutation test does not explicitly model.

## Supportive, adverse, and inconclusive outcomes
- Supportive: a target shows a significant context-by-intervention interaction with a direction consistent with altering a pathogenic fibroblast program.
- Adverse: no target shows a significant interaction, or the interaction is explained by baseline expression or batch effects.
- Inconclusive: the interaction is borderline significant, or the donor-aware analysis is underpowered.
