## 1. Unresolved question and why it matters

SHR / relative glycemia is *associated* with short-term mortality in HbA1c-defined ICU cohorts
(K2: HR 1.37 in MIMIC-IV, 2.04 in NWICU). But SHR is **defined by the presence of a same-admission
HbA1c**, so the analytic cohort is *selected by whether the test was ordered*. K1 shows, across 272
lab tests, that the mere **presence of a test order independently predicts survival** in 86% of tests —
the exact mechanism that can manufacture an apparent relative-glycemia -> mortality association.

Unresolved (and potentially fatal) objection: at the same absolute admission glucose and severity, does the
relative component `RG = log(G_adm) - log(Gc)` carry 28-day-mortality information that is (i) not attributable
to `G_adm`, and (ii) **not produced by same-stay HbA1c measurement selection (R-select)** or HbA1c invalidity?
Read descriptively/predictively; this tests incremental prognostic information and separability, not mechanism.

The parent already predeclares a value-free negative-control exposure and an equivalence margin. The two
defects this child must resolve: (A) the **power gate / cohort prevalence was never computed** and the one
attempt returned a structurally impossible zero join (definite pipeline defect); (B) the primary estimand
still needed tightening, and a substantive **learned/mechanistic alternative** to the plain regression ladder
was not yet specified.

## 3. Primary estimand (tightened)

- M0 = G_adm + severity (SOFA-style) + age/sex (+ admission_type). M1 = M0 + RG (separable log-ratio).
- Primary estimand: **ΔAUC(M0->M1)** and ΔMcFadden-R²(M0->M1) with bootstrap 95% CI, plus the adjusted RG coefficient.
  Equivalence / non-inferiority margin predeclared: ΔAUC <= 0.005 **and** RG coefficient CI inside ±0.05/unit is a
  *declared null of no incremental information* (an informative negative, not inconclusive).
- M2 = M1 + HbA1c-measurement/care-intensity propensity. Decisive contrast: (M1->M2) change is the R-select
  discriminator — does the value RG survive modelling *who was measured*?
- M3 = value-free negative-control exposure (measured-HbA1c indicator, no value) and a negative-control outcome.
- Predeclared artifact signatures S1 (label permutation of Gc collapses the M1->M2 increment to the margin),
  S2 (measurement-only Δ within an equivalence band of value Δ), S3 (no value RG->NCO association).

## 4. Method comparison (required baseline vs substantive alternative)

- **Baseline B0** = interpretable penalized-logistic M0->M1->M2 ladder with the above margins (CPU).
- **Alternative A1** = selection-aware **joint latent model**: a HbA1c-measurement-selection equation
  (probit/logit on severity/care-intensity covariates) jointly fitted with the 28-day outcome equation
  (Heckman-type / shared-parameter, EM or full-likelihood, CPU). What A1 reveals that B0 cannot: it estimates
  the value effect while explicitly modelling the *latent* selection that governs measurement, instead of
  absorbing it in an ad-hoc negative-control covariate; identification rests on an exclusion restriction /
  functional form, and its failure modes (weak exclusion, non-Gaussian errors) are predeclared.
- Supplementary (only if a margin-relevant nonlinearity is suspected): a bounded gradient-boosted
  outcome model as a **flexibility check**, not a primary claim (small predictive gains are not the object).
- Budget: CPU-only; cohort ~O(10^3-10^4) rows after the HbA1c intersection; minutes-to-tens-of-minutes per
  bootstrap replicate set. GPU not required and not requested.

## 5. Falsification criteria (prespecified)

- **Supportive (H-relative)**: ΔAUC(M0->M1) >= 0.02 with 95% CI excluding 0, AND the value-RG increment exceeds
  the value-free measurement-only control by more than the margin (S2), AND S1 collapse and S3 null are satisfied.
- **Adverse (artifact / R-select)**: ≤0.005 within ±0.01 equivalence band, OR the measurement-only control
  reproduces a materially similar increment to value RG, OR S3 shows a non-null RG->NCO association.
- **Inconclusive**: power gate unmet (event count/CI half-width insufficient) despite a correct pipeline; reported as
  a genuine inconclusive, never as supportive.

## 7. Honest limits / what would need more data

Single-centre retrospective; no causal/mechanistic claim. HbA1c value itself is an imperfect chronic-glycemia
anchor and is unreliable in anemia/hemoglobinopathy (K3 boundary). No true marker-independent renal/chronic
truth standard available. The negative-control outcome necessity requires clinical adjudication (glycemia-independent).
External validation would require another cohort or an explicit cross-dataset (non-join) replication design.
