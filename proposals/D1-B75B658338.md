Title: Literal RT Vent Off versus Suspended: multisite transportability, within-stay sequence dependence, and fixed-horizon documentation durability in eICU

Parents
- [prior hypothesis]: frozen full-source literal RT transition cohort, fixed 6/24/48-hour recurrence and observation partitions, five-family setting marker, controls, and strict nonclinical interpretation.
- [prior hypothesis]: hospital common-support, concentration, leave-one-hospital-out, heterogeneity, and falsification framework. Its separate care-plan population is not imported.

Unresolved question and clinical importance
The parent audit showed that literal structured respiratoryCharting values RT Vent On/Off = Off and Suspended have different later structured-record trajectories, but it could not determine whether this distinction was reproducible beyond a dominant site or was generated by local documentation workflow and repeated entries within a small number of stays. This matters because analysts may otherwise pool the two values or treat one as a clinical ventilation-discontinuation event. The computable question is deliberately narrower: among eligible literal Off and Suspended documentation episodes, are differences in later literal Start recurrence and structured setting-family positivity directionally reproducible across hospitals with common label support after accounting for hospital concentration and within-stay repeated episodes?

Strongest evidence-supported claim before this child
The inherited evidence supports only that Off and Suspended identify different structured respiratory-documentation regimes in the observed eICU records and should not automatically be pooled. It does not establish actual invasive ventilation state, extubation, liberation, reintubation, bedside device state, clinician intent, causal effect, quality, or benefit.

Hypothesis tested by this child
In hospitals with common support for both labels, Suspended will retain the inherited direction of higher later structured respiratory activity than Off: higher fixed-horizon literal Start recurrence and higher positivity of the inherited setting-family marker. Reproducibility requires enough supported hospitals, a site-standardized uncertainty interval excluding zero in the inherited direction, and direction preservation after omission of each supported hospital. Adverse evidence is hospital-level reversal or leave-one-supported-hospital-out reversal. The experiment also tests whether raw episode contrasts are materially generated by repeated episodes and transition sequences within stays.

Literal extraction, deduplication, population, and time boundaries
- Scan the entire respiratoryCharting source. Normalize case and surrounding whitespace solely for matching.
- Target respchartvaluelabel is literal RT Vent On/Off. Decisive values are Start, Off, and Suspended. Continued is retained as the inherited nontransition control and is never a recurrence event.
- Collapse exact duplicates on (patientunitstayid, respchartoffset, normalized decisive value, respchartentryoffset, respcharttypecat); respchartid differences do not multiply an otherwise identical tuple.
- Within each stay, sort exact-unique decisive records and form earliest-anchor clusters containing records from the anchor through anchor+30 minutes. Do not use transitive/chained clustering.
- Classify a cluster as pure Start, pure Off, pure Suspended, mixed-direction conflict if it contains Start plus an off-direction value, or mixed Off+Suspended ambiguity. Exclude both mixed classes from index and recurrence events but retain their counts.
- Index episodes are every pure Off or pure Suspended cluster with T >= 360 minutes, T <= unitdischargeoffset, known linked patient row, and known unitdischargeoffset. Do not exclude an index because a later Start exists. Multiple index episodes per stay remain eligible; dependence is analyzed rather than erased.
- Recurrent Start by horizon h is the first later deduplicated pure literal Start satisfying T < Start <= T+h and Start <= unitdischargeoffset. It is a structured documentation recurrence, never reintubation.
- Fixed horizons are h=360, 1440, and 2880 minutes. The inherited competing observation status precedence is recurrent_start, complete_no_recurrence, icu_death_before_horizon, live_icu_discharge_before_horizon, unknown_truncation. Primary risks use complete-window episodes, exactly as in the parent; status counts retain early recurrence and competing observation categories.

Inherited structured setting marker and controls
Use only contemporaneous respiratoryCharting values; no carry-forward. A setting window is positive only when at least two distinct families have physiologically bounded values in that exact window:
- set respiratory rate: Adult Con Setting Set RR or Vent Rate, 4-40;
- set tidal volume: Adult Con Setting Set Vt or Tidal Volume (set), 100-1200;
- machine minute volume: Adult Con Pt/Vent MinuteVentil or Exhaled MV, >0-50;
- machine tidal volume: Adult Con Pt/Vent InspiratorTV, Exhaled TV (machine), Tidal Volume Observed (VT), or Exhaled Vt, >0-2000;
- machine pressure: Pressure Control or Mean Airway Pressure, >0-80.
Fixed bins are [T-360,T), [T,T+360), [T+360,T+1440), and [T+1440,T+2880). The transportability outcomes use 6-24 and 24-48 hours among episodes observed through each bin end. The inherited Start directionality, Continued nontransition behavior, conflict accounting, no-carry-forward rule, and the parent’s negative airway/device corroboration remain controls and semantic safeguards; this child does not reinterpret them.

Pass 1 extracted literal transitions; pass 2 extracted setting families only for the resulting index stays. It retained 60,151 bounded setting rows. The transition value profile was 55,981 Continued, 1,018 Off, 2,734 Start, and 368 Suspended source rows.

Hospital concentration and common support
Eight hospitals contained both labels, six had at least 5 total index episodes of each label, and four had at least 10 of each label; those four contributed 938/1,063 episodes (88.2%). Hospital 73 alone contributed 467/713 Off (65.5%) and 286/350 Suspended (81.7%). Off HHI was 0.450 (effective hospital count 2.22; top-three share 83.2%); Suspended HHI was 0.675 (effective count 1.48; top-three share 92.0%). Hospital explained eta-squared 0.056 of binary label variation, reflecting overlap at the dominant hospital rather than broad geographic transportability. Thus absolute concentration is severe even though both labels co-occur at several sites.

This is a regularized site-standardized descriptive posterior, not a causal model and not population-level proof.

Within-stay sequences and repeated-episode dependence
Across all deduplicated pure decisive events, adjacent pairs were Start->Off 835, Start->Start 234, Start->Suspended 130, Suspended->Suspended 193, Off->Start 72, Suspended->Start 48, Off->Off 28, Suspended->Off 32, and Off->Suspended 14. Median adjacent gaps included Start->Off 830 minutes, Start->Suspended 4,070, Off->Start 1,745, Suspended->Start 1,341.5, and Suspended->Suspended 1,441. Repeated Suspended documentation is therefore a major sequence feature rather than independent sampling.

Forty-three stays contained both index labels. One hundred stays had more than one index episode, and 38.95% of all episodes occurred in those repeated-episode stays. Off was usually one per stay (623 stays with one Off; 39 with 2-5), whereas Suspended was highly concentrated within stays (78 stays with one, but some stays had 11, 12, 13, 17, 20, or 30). Among index Off episodes, the next pure transition was Start for 60, Off for 25, Suspended for 14, and absent for 614. Among index Suspended episodes it was Start for 42, Off for 30, Suspended for 193, and absent for 85.

Dependence sensitivities do not erase the intermediate-horizon direction but show why episode-level independence is untenable. For first occurrence of each label per stay, Suspended-Off recurrence differences were +0.08 points at 6 hours (2/127 versus 9/601), +3.09 at 24 hours (8/121 versus 19/540), and +2.09 at 48 hours (10/105 versus 27/363), compared with raw episode differences +0.76, +3.63, and +3.47. First overall index episodes gave +0.49, +3.86, and +3.86 points. Repeated/later episodes generally had higher recurrence within both labels: for example at 24 hours Off later-any-index was 7/62=11.29% versus first 16/521=3.07%, while Suspended was 18/229=7.86% versus first 7/101=6.93%. Inference must therefore stay clustered by stay and hospital, and first-episode estimates are sensitivity estimands rather than replacements for the inherited episode estimand.

Prespecified falsification and interpretation gates
- Supportive documentation reproducibility: at least five hospitals have at least five eligible/complete episodes of each label; the equal-hospital Jeffreys posterior 95% interval excludes zero in the inherited direction; and every leave-one-supported-hospital-out equal-site contrast preserves that direction.
- Adverse site/workflow specificity: fewer than three common-support hospitals, supported-site point estimates reverse, or leave-one-supported-hospital-out direction reverses.
- Inconclusive: only three to four supported hospitals, or uncertainty includes zero without a decisive stable contrast. A gate can differ by horizon/outcome; no gate upgrades the labels to clinical ventilation states.

Executed disposition under these gates
The Off-versus-Suspended distinction is neither a pure one-site artifact nor broadly transportable as one invariant event contrast. It is reproducible across five common-support hospitals for 6-24-hour structured setting-family positivity and for the direction of 24-hour literal Start recurrence, including after omission of the dominant hospital. Conversely, 6-hour and 48-hour recurrence show supported-site or leave-one-out reversal, and the 24-48-hour setting result has only four supported hospitals. The defensible advance is therefore a mixed, falsifiable one: Off and Suspended should remain separate because they mark reproducibly different intermediate-horizon structured documentation trajectories in several hospitals, but recurrence magnitude and late durability are horizon- and workflow-sensitive. The data reject both indiscriminate pooling and a universal quantitative interpretation.

Clinical semantics, unavailable evidence, and adjudication
These findings are about structured documentation behavior only. eICU lacks raw ventilator/device logs and waveforms, and the inherited independent audit found zero usable event-window airwaytype observations and no valid local treatment/narrative corroboration; ventilator-history fields behaved as historical documentation rather than active-state evidence. Public eICU note fields do not supply genuine narrative context adequate for event adjudication. Neither Off nor Suspended may be labeled extubation, ventilator liberation, interruption of invasive ventilation, failed extubation, or reintubation.

A stronger clinical-state conclusion requires a separate validation study with synchronized device connectivity/logs, invasive versus noninvasive modality, airway insertion/removal and extubation/reintubation timestamps, post-event oxygen device, RT and nursing narrative, post-ICU respiratory support, and blinded clinician adjudication sampled across multiple hospitals and both labels. Whether site differences represent interface configuration, RT workflow, unit case mix, or real care-state differences cannot be resolved automatically here. Expert review is also needed before any clinical decision support or quality interpretation.

Unresolved uncertainties
Hospital 73 dominates both labels; only five hospitals support the intermediate outcomes and four support late outcomes. The site-standardized posterior does not model case mix, calendar/interface version, or a superpopulation of hospitals. Episodes within a patient across separate ICU stays were not modeled beyond stay clustering, although patient-level grouping is available through uniquepid. Structured setting positivity is documentation-sensitive and is not an independent device-state gold standard. Repeated Suspended sequences may reflect workflow batching, persistent status, or real repeated transitions; available data cannot distinguish them. The outcome-specific support sets and small site event counts leave recurrence estimates imprecise. These limitations are part of the result, not grounds for a clinical semantic upgrade.
