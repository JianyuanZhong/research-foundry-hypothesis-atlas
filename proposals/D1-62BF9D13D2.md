## 1. Unresolved question, clinical importance, substantive advance
After liver-directed therapy (LDT: TACE / ablation / resection) for HCC, clinicians repeat AFP and liver-panel labs at every
follow-up and must decide when to re-image. The parent branch tests whether the **within-patient AFP slope** over the
6-month post-index window carries progression information beyond baseline and beyond surveillance intensity, within an
imaging-negative landmark stratum (IMGneg). **The remaining, unresolved mechanistic claim is that this slope is an early
* tumour-burden* signal.** The strongest live rival is **procedure-induced release (R_decay)**: LDT/ablation/resection injures
hepatocytes and provokes regeneration and a systemic inflammatory/ischaemia-reperfusion response [K2], and tumour lysis can
release AFP; a positive slope-outcome association could therefore be manufactured by the *periprocedural* AFP pulse (which
itself correlates with tumour burden and procedure intensity) rather than by sustained residual-disease AFP production.
This matters because the decision (adjunct AFP-guided early re-imaging) is only justified if the slope is not merely a
procedure epiphenomenon. **Advance over inspected work:** the parent's M0/M7 test cannot separate these, because both use
all draws in (index, t*], including periprocedural ones. This child makes the rival falsifiable with a pre-specified,
decision-changing estimator (the decay-clean slope) rather than another variable.

## 2. Inherited frozen design (verbatim)
- **Population:** patients with an HCC diagnosis (diagnoses `诊断名称`) AND >=1 liver-directed procedure (procedures `手术`).
- **Index** = earliest qualifying liver-directed procedure `开始时间`; **t\*** = index + 180d (90d sensitivity).
- **Exposure (parent M0):** per-patient OLS slope of log10(AFP) over draws with `检验时间` in (index, t\*]; AFP from labs
  `检验`='甲胎蛋白', numeric `定量结果`; **same-draw** pairing of albumin + total bilirubin within +/-2d of `检验时间`;
  ALBI = 0.66*log10(bilirubin) - 0.085*albumin. Draws must pass AFP/albumin/bilirubin look-alike exclusions
  (e.g. 甲胎蛋白异质体/AFP-L3, 白蛋白/球蛋白比值, 总胆汁酸).
- **Landmark imaging status** over `检查` `开始时间` in [t\*-45d, t\*+45d]: IMGneg = a qualifying abdominal study whose
  `检查所见` AND `检查诊断` contain none of {增大,进展,复发,新发,增多,转移}; IMGpos otherwise; IMGmissing if none.
- **Outcome:** modality-restricted abdominal **local progression** (lexical event = any of {增大,进展,复发,新发,增多}) with
  转移 as competing event; censor via encounters `出院时间`. Secondary: retreatment proxy. M7 corroboration (parent):
  first post-landmark qualifying report confirmed by a second distinct report >=30d later (distinct `检查号` AND
  distinct `开始时间`; witness `检查号` must not match a pre-/landmark study).
- **Covariates/controls:** age, sex, baseline tumour/procedure variables, surveillance-intensity (draw count, imaging cadence),
  ALBI-slope negative control; **four rivals** and conjunctive falsification; no survival/mRECIST claim.

## 4. The ONE pre-specified, decision-changing element: the decay-clean slope (R_decay)
Refit the **same** landmark Cox within IMGneg using the **decay-clean AFP slope** D = OLS slope of log10(AFP) over draws in
(index, t\*] that are **>=30 days after every LDT `开始时间`** of that patient (i.e. exclude any draw sitting inside any
[procedure, procedure+30d] window), with a 45d sensitivity. Report per-1-SD HR(D) + 95% CI and the paired 1-df LRT of
slope-definition (all-draw M0 vs decay-clean M_decay) x AFP-slope. Everything else is unchanged. M_decay reads the same
biomarker but on a draw set purged of the periprocedural release window; a change in the slope-outcome association under
this purge is directly attributable to periprocedural release, not to circularity (unlike the parent's retired M6).

**What D adds that M0 loses:** M0 cannot represent a transient, procedure-timed AFP pulse, so a positive M0 cannot be
attributed to tumour burden. D is the smallest estimator whose result distinguishes "sustained burden-driven AFP production"
from "transient release artefact" — the exact separation the clinical decision needs.

## 5. Branches (pre-specified, on M_decay vs M0 within IMGneg; conjunctive)
- **Supportive:** M_decay HR>1 with 95% CI excluding 1, >=20 M_decay events, attenuation vs M0 < 40%, and slope-definition
  LRT p>0.05. => the slope is not merely procedure-induced release; AFP-guided adjunct surveillance is worth prospective testing.
- **Adverse = R_decay:** M_decay CI includes 1 (or sign reversal) with >=20 events while M0 CI excludes 1, **or** LRT
  p<0.05 with M0 more extreme than M_decay. => the parent's association is substantially a periprocedural-release artefact;
  the "early tumour-burden warning" claim is **retracted** for this cohort.
- **Inconclusive:** <20 M_decay events, or <50% of IMGneg patients have >=2 decay-clean draws in the window, or procedure
  timestamps missing for the decay map. => no decision; report attainability, do not read as null.
- **Precise-null:** both M0 and M_decay within +/-0.10 of 1 with tight CIs and a flat ALBI-slope control. => no AFP-slope
  incremental value; reassign monitoring weight to imaging/other markers.
All branch calls must be reported with the *also-computed* M0 HR so a reader can attribute any change correctly.

## 6. Baseline vs alternative (method comparison, recorded)
- **Baseline M0:** parent's landmark Cox with all-draw AFP slope.
- **Alternative M_decay (chosen):** decay-clean slope + slope-definition LRT. CPU-only, minutes-scale on the frozen parquet/
  CSV views; **no GPU required** (bounded OLS + Cox). This is the "explicitly revised question" form of a robustness refit.
- **Deferred alternative:** a shared-parameter joint model of the AFP trajectory (with an explicit periprocedural pulse term)
  and event time. Deferred because the branch budget is a discovery episode and the decay-clean refit already isolates the
  pulse; **revisit condition:** if M_decay is *inconclusive* but M0 is positive, fit the joint model to model the pulse
  explicitly rather than dropping draws.
- Simpler baselines deliberately not used as the primary: whole-cohort (non-IMGneg) Cox, and marker-free clinical model.

## 7. Falsification / what each outcome would and would not establish
The design **can overturn** the parent (Adverse arm), because M_decay is computed on the same estimator with a purged draw
set. A supportive result establishes only that the association survives the release purge **in this single-centre lexical
endpoint**; it does **not** establish causation, mRECIST progression-free survival, or clinical benefit. An inconclusive
result is not evidence against the claim.
