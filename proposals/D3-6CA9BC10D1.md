# Provisional hypothesis: macrophage context changes FLS state beyond composition

## Proposed relationship
In the available E-MTAB-8873 human RA synovial type B synovial cell (FLS) targeted assay, exposure to MerTK/CD206-positive versus MerTK/CD206-negative macrophage coculture produces a reproducible, donor-aware change in FLS transcript state that is not adequately explained by the recorded contributing-donor composition, cell count, or treatment. This is a provisional hypothesis, not an executed result.

## Falsifiable test
Compare log-transformed or otherwise appropriately normalized FLS feature states between none-treatment Mpos and Mneg samples, using a donor-aware paired/hierarchical model and a prespecified baseline that accounts for contributing-donor composition and cell count. Support would be a reproducible directionally consistent state change across donors with uncertainty excluding the prespecified null and not attributable to composition; adverse evidence would be no reproducible change or a change fully explained by composition/measurement; inconclusive evidence would be too few independent donor contrasts, unresolved donor conflicts, or imprecise estimates. A subsequent perturbation or independent assay would be required for a mechanistic claim.

## Method comparison
The simple baseline is a donor-aware paired contrast with composition/cell-count adjustment. A substantive alternative is a hierarchical feature-state model that borrows strength across the 445 features and tests whether the context effect is structured (for example, a reproducible pathway/state signature) rather than isolated noise. The alternative could reveal coordinated state information lost by feature-wise summaries, but it cannot establish a causal mechanism without perturbation or independent validation. This checkpoint does not select the alternative on a performance claim.
