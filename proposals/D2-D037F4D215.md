# Replication of the auranofin-specific context-dependent drug response: the previously reported effect is not reproducible

## Question
Does fibroblast-induced MTF (macrophage+T cell+FLS) context specifically attenuate auranofin
(TrxR/NF-kB inhibitor) response on the MTF-specific gene program, while the JAK inhibitor (A77) response is
NOT context-dependent? — as claimed by the parent candidate.

## What this replication found (executed this episode, [research job])
Data: GSE95588_d1d2d3d4_counts.counts.tsv.gz (23,710 genes x 70 samples; donors P1-P3 have Aur+A77 in both
MT and MTF contexts; P4 has no drugs). Method matches the parent: MTF-specific program = genes up >0.5
log2CPM in MTF vs MT in >=2/3 donors; per-donor drug response resp_MTF = log2CPM(MTF_drug)-log2CPM(MTF),
resp_MT = log2CPM(MT_drug)-log2CPM(MT); diff = resp_MTF - resp_MT; per-donor signed attenuation = fraction of
MTF-specific genes with diff>0; control set = all expressed genes (max>10).

Parent claimed: MTF-specific program n=1,524; Aur per-donor attenuation 0.86/0.70/0.73 (mean 0.76) vs control
0.44; A77 ~chance (0.42/0.59/0.51).

Replication (program thr=0.5, minup=3 => n=1,514, matching the parent's ~1,524):
- Aur attenuation: 0.47 / 0.44 / 0.39  (NOT >0.7 in any donor)
- A77 attenuation: 0.09 / 0.30 / 0.22  (NOT ~chance; consistently LOWER than Aur)
- Control Aur: 0.41/0.44/0.37; Control A77: 0.53/0.60/0.50

Robustness across every program definition (thr x minup):

## Interpretation
- The parent's falsification criterion "supportive: Aur >0.7 all 3 donors AND A77 ~chance" is NOT met.
  The data are ADVERSE to the auranofin-specific attenuation hypothesis: Aur attenuation is at/below chance
  and A77 is not context-dependent (it is lower).
- The MTF-specific program is defined on the same MT/MTF contrast used to compute the response, so a generic
  "upregulated genes resist suppression" effect is a live confound; the control set (all expressed genes)
  shows the same order (Aur ~0.4, A77 ~0.5), so neither drug shows a program-specific context effect.
- The parent's numbers cannot be recovered by any reasonable program definition; the discrepancy is most
  consistent with a computational artifact (e.g., a sign/baseline error) in the parent's analysis.

## Residual (unresolved) question
Whether ANY context-dependent drug response in this system is cell-type-specific (macrophage vs FLS) and thus
invisible to bulk coculture RNA-seq. The bulk data cannot resolve this; a cell-type-resolved (single-cell or
FACS-sorted) measurement of auranofin vs A77 response is the appropriate next test.

## Falsification criteria (as in parent; now evaluated)
- Supportive: Aur >0.7 all 3 donors AND A77 ~chance AND >=5 MTF-spec genes p<0.01 for Aur. NOT met.
- Adverse: Aur ~chance OR A77 >0.7. MET (Aur at/below chance; A77 lower than Aur).
- Inconclusive: <2 donors OR FDR eliminates all OR inconsistent. Not the primary classification; the
  auranofin-specific claim is ADVERSE, with the bulk-confound caveat that a cell-type-specific effect cannot
  be excluded.

## Competing explanations
1. Bulk RNA-seq confounds macrophage vs fibroblast transcriptional changes; the MTF-specific program is
   defined on the same MT/MTF contrast used to compute the response (generic "upregulated genes resist
   suppression" confound; control set shows the same order).
2. The parent's numbers are most consistent with a computational artifact (sign/baseline error), not a real
   effect.
3. Vehicle control is unstimulated (not stimulated+vehicle), so "drug response" includes the stimulation effect.
4. Small n (3 donors, 1 replicate per condition); per-gene FDR is not a meaningful discriminator.
5. Donor IDs (P1-P4) are unresolved labels; GSE95588 coculture r1/r2 reuses GSE57723 (not independent validation).

## Limitations
- 1 replicate per condition per donor; donor IDs unresolved; bulk RNA-seq cannot separate cell types.
- This is a replication/correction, not a new positive finding; the informative result is that the
  auranofin-specific claim is not supported by the bound data.
- No wet-lab validation; a cell-type-resolved experiment is required to resolve the residual question.
