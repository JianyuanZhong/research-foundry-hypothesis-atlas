> Conditional on every inherited data, annotation, ascertainment, fit, and exact-solver gate passing, and conditional on genuine joint escalation-decision heterogeneity, perfect resolution of at least one single predeclared uncertainty class—source chronology C, corpus-wide radiology-book identity R, or corpus-wide pathology-book plus terminal identity P—is sufficient to make the strict greater-than-5-per-100 escalation decision invariant to both remaining classes in every attainable resolved-evidence branch.

“Perfect resolution” means observing a pre-outcome evidence value and conditioning on its entire equivalence cell. It does not mean choosing a favorable value. The hypothesis is false if each singleton class has an attained same-evidence pair of worlds on opposite sides of the decision threshold. The experiment still reports all inclusion-minimal two-class or three-class stabilizers when the singleton hypothesis is adverse.

The substantive advance is a deterministic, exact value-of-information result for the actual finite corpus: whether one evidence class, a joint package, or all three would be needed to determine the funding gate. It is not expected monetary value, because no defensible probabilities, acquisition costs, target-population sampling law, or utilities are available.

## 3. Joint escalation margin: separating coordinate heterogeneity from decision heterogeneity

Let E contain the four year-by-contrast coordinates. For each coordinate e, let J_e contain the undeleted state 0 and every singleton whole-patient deletion in the frozen test universe; deleting a patient outside e’s year is retained as a no-op audit duplicate but may be deduplicated after equality is proven.

For a fully specified world with all adequacy gates passing, define the joint decision margin

H(omega) = min over e in E and j in J_e of Delta_e,j(omega).

The fully resolved binary decision is D(omega)=FUND if H(omega)>5 and DO-NOT-FUND-ON-THIS-SIGNAL if H(omega)<=5. Equality is adverse to the strict threshold. This bundles the inherited universal conjuncts but does not weaken any of them.

Compute exact attained H_min=min over Omega H(omega) and H_max=max over Omega H(omega), with complete witnesses.

- H_min>5 is the inherited stable whole-panel universal supportive result.
- H_max<=5 means the funding decision is already invariantly negative even if different worlds fail different coordinates. Coordinate-level heterogeneity does not by itself create value for uncertainty resolution.
- H_min<=5<H_max is genuine joint decision heterogeneity and triggers the new value-of-information analysis.

The primary parent intervals, singleton lower endpoints, and one-hot conclusion remain reported unchanged. H_max is a new joint optimization, not the maximum of separately optimized coordinate maxima.

## 4. Three predeclared uncertainty classes and exact stabilization

The class universe is frozen before any test result:

- C, source chronology: the complete corpus-wide vector of coherent s_i choices governing qualifying operation identity and clock, year, preoperative cutoff, CT/MRI window membership, and prior-treatment membership. It does not include a made-up report-release state.
- R, radiology interpretation: the one corpus-wide j_R in {R1,R2,RA}. All item forms belonging to that book move together.
- P, pathology interpretation and terminal: the one corpus-wide j_P in {P1,P2,PA} plus the complete vector of allowed tau_i values from that same book. HCC-frame and grade remain indivisible.

For each nonempty S among {C},{R},{P},{C,R},{C,P},{R,P},{C,R,P}, let pi_S(omega) be the complete value of the classes in S. For every attainable z in pi_S(Omega), define the evidence cell Omega_S(z)={omega:pi_S(omega)=z} and exact conditional limits

l_S(z)=min over Omega_S(z) H(omega)
and
u_S(z)=max over Omega_S(z) H(omega).

S is globally decision-stabilizing exactly when every attainable cell is one-sided: either l_S(z)>5 or u_S(z)<=5. A cell with l_S(z)<=5<u_S(z) is unstable and must emit an attained opposite-decision witness pair sharing byte-identical pi_S. Resolution makes the decision conditionally invariant after the evidence value is observed; it cannot make all possible observed values lead to the same decision. Requiring the latter would merely restate the original universal gate and no evidence intervention could repair genuine heterogeneity.

Report all inclusion-minimal stabilizers M={S:S stabilizes and no proper subset stabilizes}. Also report k_min=min |S| over M. No arbitrary winner is chosen among incomparable minimal sets and no acquisition-cost ranking is inferred.

The confirmatory child hypothesis is supported only if H_min<=5<H_max and k_min=1. It is adverse if joint heterogeneity is proven but all three singleton classes fail to stabilize. A two-class or all-three minimal result is clinically informative but adverse to the singleton hypothesis. If inherited gates fail, H endpoints or any required cell cannot be certified exactly, the result is inconclusive.

Each failed singleton must have a necessity certificate: two complete worlds with the same resolved class value, opposite D values, full coordinate/deletion witnesses, identical fixed models/K, and raw/form backpointers. For a minimal pair, both singleton failures and pair sufficiency must be certified. Within C witnesses, tag whether operation clock/identity, examination-window boundary, prior-treatment boundary, or a combination differs. Within P, tag book, terminal, or both. These are descriptive exact attributions and do not create additional post-hoc classes.

## 5. Resolution protocol and the no-favorable-adjudication rule

All class definitions, projection hashes, reader forms, source-state generators, test roster, models, K, threshold, and solver code are frozen before test outcomes or scores are unsealed.

The analysis first evaluates all nine original whole-book pairs and every terminal/source state. RA and PA remain books in the primary envelope. A favorable RA/PA result cannot rescue a failed nine-pair universal claim. A resolution intervention reveals or operationally fixes an evidence value; the solver then retains every world consistent with it. It never searches for the value yielding FUND.

For actual follow-up, an observed evidence package z_star is hashed before outcome recomputation. FUND is permitted as a retrospective escalation recommendation only if l_S(z_star)>5; DO-NOT-FUND-ON-THIS-SIGNAL if u_S(z_star)<=5; a crossing cell remains inconclusive. Any new consensus book, new image read, new specimen read, altered terminal rubric, altered report-availability rule, or altered population creates a new study/proposed child and cannot be inserted into this result.

## 6. What can be reviewed now and what is genuinely unavailable

None of the six required reader/adjudicator form sets is present in the configured snapshot; they are prospectively obtainable expert evidence under the frozen rosters and rubrics, not existing labels.

C is only partially represented. The current procedures table has 手术,开始时间,结束时间,手术来源 and the examinations table has 检查号,检查,开始时间, eventual 检查所见/检查诊断. Blinded record review can resolve some duplicate rows, obvious same-day procedure identity, and text-visible modality/context without looking at outcomes. It cannot recover absent operation events or establish report availability. The supplied HCC examination source has no report version identifier, author time, preliminary/final status, finalization time, release time, amendment time, viewer event, MDT-list time, or display log. Clinical documents have no temporal columns. Therefore accession-linked report timing is genuinely unavailable in the configured snapshot and may not be imputed.

A fundable chronology acquisition must provide a read-only crosswalk on 患者主索引,就诊号,检查号 plus source-system accession/order ID; every report version ID and text hash; created, preliminary, final, release, amendment/retraction times and status; viewer-event time and role or an explicit statement that view logs do not exist; verified operation event ID, anesthesia start and provenance; and extract timezone/version. The current C analysis can show whether chronology is necessary or sufficient within the eventual-report estimand. It cannot compute real-time performance. Incorporating report versions available by c_d would change the information set and requires Lead approval as a new study.

R disagreement is obtainable as operational blinded review of the stored eventual report text: complete R1, R2, and RA forms can be collected for every frozen unit before outcomes/scores are revealed. But no raw CT/MRI images are configured, so text adjudication cannot establish image truth or unseen-reader robustness. A third read is an operational adjudication book, not a latent-truth oracle.

P has two parts. Complete P1, P2, and PA reading of the encounter composite is obtainable by blinded text review. Terminal ambiguity caused by absent pathology time, specimen/accession, gross description linkage, block, slide, sampling site/distance, and adequacy is not resolvable from these CSVs. True P resolution therefore requires external LIS/grossing/specimen/slide-block crosswalks and, where the text remains inadequate, qualified slide/specimen review under a prespecified sampling rubric. A PA text book alone cannot collapse unanchored terminals.

Thus a minimal set containing only R is potentially obtainable with the frozen report corpus; a set containing C requires external chronology acquisition for full resolution; and a set containing P may require both blinded review and external pathology linkage. These are evidence-burden statements, not rankings by cost.

## 7. Exact computation and feasibility

Reuse the parent’s exact nine-book enumeration, robust fits, state-expanded mixed-integer top-K endpoints, lazy rank-inversion constraints, deterministic tie order, and raw replay. Compute H_min by the existing all-coordinate/all-deletion lower endpoint. Compute H_max as one exact maximin problem: maximize h subject to Delta_e,j>=h for every coordinate and deletion in one coherent world. Cutting planes add violated coordinate/deletion constraints until none remain. Zero unresolved integer gap and numerical feasibility gap at most 1e-8 are mandatory.

For each S, an exact projection-partition branch-and-bound begins with pi_S signatures symbolic, solves l_S and u_S over each cell, and splits only on unresolved values in S until each reachable signature is certified one-sided or yields a crossing witness. A separate paired-world formulation searches for omega_minus and omega_plus with identical pi_S, H(omega_minus)<=5, and H(omega_plus)>5. Partition and paired-world implementations must agree for every S. All three global books remain indivisible; patientwise book mosaics are impossible by construction.

Certification retains the parent’s exhaustive synthetic equality through 12 patients, exhaustive/raw equality on real-data shards through 20 patients, quotient and order replay, all tied optimizers, and complete source/form/book/deletion backpointers. Add fixtures in which: coordinate intervals cross but no single all-positive world exists; a singleton has an opposite-decision same-projection pair; a pair but neither singleton stabilizes; two incomparable minimal sets exist; equality occurs at 5; a gate fails in only one cell; the adjudicator is chosen after seeing outcomes; a P book is fixed but terminals are silently optimized; C invents report-release times; and K/model/book changes after resolution. No state cap, sampling, beam search, approximate bound, favorable incumbent, or timeout can support or falsify the hypothesis.

## 8. Decision interpretation and funding logic

Results are interpreted in this order:

1. Any mandatory source, annotation, adequacy, fit, or exact-solver failure is inconclusive.
2. H_min>5 is stable universal support under the parent claim; the new conditional VOI question is not needed.
3. H_max<=5 is invariant DO-NOT-FUND-ON-THIS-SIGNAL. It may coexist with localized coordinate heterogeneity and does not mean report semantics are useless.
4. If H_min<=5<H_max, report all minimal stabilizers and all witness pairs.
5. After a permitted evidence package is actually obtained, use only its frozen z_star cell. A supportive cell may justify considering the next evidence stage; an adverse cell falsifies the strict escalation margin for that resolved branch; a crossing cell remains inconclusive.

If {C} is minimal, acquisition of verified source chronology is sufficient to determine the retrospective gate, but not guaranteed to make it positive. Accession-linked report timing should be funded only as a learning step, and a real-time rerun remains necessary. If {R} is minimal, complete blinded report adjudication can determine the retrospective gate; timing is still required before silent mode. If {P} is minimal, pathology text review is sufficient only when no unanchored terminal remains; otherwise external specimen linkage is part of P. If every minimal set includes C, chronology is necessary but may not be sufficient. If minimal sets exclude C, report-timing acquisition alone cannot resolve the retrospective ambiguity, though timing remains an essential later real-time gate. Incomparable minimal sets require external cost, feasibility, and clinical review; the algorithm cannot choose the cheaper package.

A prospective silent-mode MDT study is considered only after an observed resolved cell is supportive, accession-linked pre-cutoff report availability is established, and the model/information set is relocked. It must measure consecutive candidate flow, review time, staffing, queue overflow, missed/late reports, clinician actions, disagreement, harms, and no-action counterfactuals. This proposal does not establish capacity, benefit, or deployment readiness.

## 11. Claim limits and stronger evidence

A supportive singleton result supports only that, in this frozen finite eventual-report corpus, observing one predeclared class would determine whether every fixed-K documentary-M2 contrast and singleton stress exceeds 5 under the two unresolved classes. It does not say what evidence value will be observed or that funding is cost-effective.

An adverse singleton result says one class alone cannot determine the gate; it does not refute report semantics or make a joint evidence package valueless. A minimal P result is documentary unless specimen linkage and sampling evidence are acquired. A minimal C result is not real-time validation because release/view versions are absent. Any gate or exactness failure is inconclusive.

Biological M2 requires pathology time, specimen/accession/slide/block links, documented sampling site/extent, and expert adjudication under a recognized protocol. Real-time use requires accession-linked report versions and final/release/view timestamps plus validated operation clocks. Population inference requires a defined target population, consecutive ascertainment or known inclusion probabilities, site/calendar coverage, and a prespecified inferential design; later or external locked validation is preferable. Silent-mode feasibility requires prospective flow, staffing, timing, action, and harm measurements. Clinical benefit requires a controlled outcomes study.
