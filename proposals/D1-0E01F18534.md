# Persistence is the clinically relevant benchmark for repeat-TACE assay forecasting

## Status and substantive change

This is a targeted child of `[prior hypothesis]`. It preserves that candidate's frozen HCC snapshot, population and event construction, exact source bindings, assay clocks, complete-triplet denominators, five-fold outer partitions, nested M0/M1 definition, and noncausal evidence boundary. The material unresolved defect is benchmark validity: the inherited result establishes that adding contemporaneous pre-repeat assay `P` improves prediction beyond remote baseline `B` and a compact core, but it does not establish improvement over the transparent decision-time forecast `Yhat=P`. Because short-lag assay persistence is expected, that omission leaves open whether the learned model is clinically more informative than simply carrying the latest measurement forward.

The child makes the persistence forecast the primary comparator and adds a leakage-safe calibrated-persistence comparator. It does not reinterpret a laboratory forecast as toxicity, hepatic injury, treatment response, safety, benefit, or clinical utility.

## Question and claim ladder

The falsifiable question is:

> In the selected complete B/P/Y triplets from the frozen repeat-TACE cohort, does the learned contemporaneous-state model produce lower out-of-fold error for the next observed same-assay value Y than the raw persistence forecast Yhat=P, and does any advantage survive a training-fold-only affine calibration of persistence?

The strongest evidence already supported by the parent is narrower: correctly linked P contains reproducible prognostic information for Y beyond B and a compact core, with positive nested-model gains in both assays and stable restricted linkage-placebo diagnostics. That is not the same as superiority to P, because P is itself a highly competitive forecast and is present in M1 as a predictor.

The untested claim is superiority at the decision time. Support requires that the pre-specified learned model beat raw persistence on paired held-out loss and retain a clinically interpretable advantage over calibrated persistence. A result showing only M1 > M0 but M1 no better than P is an important adverse benchmark result: the learned model may be redundant with ordinary persistence. Conversely, M1 > P would support incremental forecast refinement, still only for the recorded laboratory endpoint in the selected complete-triplet episodes.

## Pre-registered benchmark panel

Use the inherited deterministic arm-balanced five-fold outer partitions, fixed before outcome use and shared by every comparator. Keep patient rows and fold membership fixed across all methods. Each fold's test predictions are generated without using that row's Y or any other test-row outcome.

For each assay and held-out row, produce the following forecasts.

1. **Raw persistence P (primary naive benchmark):** `q_raw = P`. This has no training fit and is not standardized before calculating loss. It is the exact transparent forecast a clinician could construct from the latest pre-repeat value.
2. **Training-fold-only calibrated persistence (secondary, but essential benchmark):** fit `Y = alpha + beta*P` on the outer training rows only, with the same assay and no test outcomes; predict `q_cal = alpha_train + beta_train*P_test`. Fit alpha and beta jointly by ordinary least squares with a documented fallback to `beta=0, alpha=mean_train(Y)` if training-fold P has zero variance. Do not pool assays. Do not fit calibration on all rows, on out-of-fold predictions, or on bootstrap test rows. A robust Huber version may be a sensitivity analysis only, not a replacement unless declared before seeing results.
3. **Inherited M0:** ridge model `Y ~ B + systemic_arm + age + sex + days + P_lead_hours`.
4. **Inherited M1:** same core plus contemporaneous P, `Y ~ B + systemic_arm + age + sex + days + P_lead_hours + P`.

For M0/M1, retain all inherited outer-training-only preprocessing: age median and missing indicator, sex encoding, zero-variance filtering, standardization, and ridge alpha selection over `{0.01, 0.1, 1, 10, 100}` by inner training-only procedure. The fixed raw persistence benchmark is intentionally not subjected to model preprocessing. If a software implementation standardizes P internally, reverse-transform predictions to assay-native numeric scale before loss calculation; otherwise the comparison is not valid.

The primary scientific contrast is M1 versus raw persistence. Secondary contrasts are M1 versus calibrated persistence, M0 versus raw persistence, and M1 versus M0. Report all contrasts with the direction `loss(benchmark) - loss(M1)`, so positive means M1 improves on the stated benchmark. Do not infer superiority from M1 versus M0 alone.

## Metrics and standardization

Use identical held-out rows and paired losses for every method. Primary metrics are pooled RMSE and MAE separately by assay. Also report arm-specific values descriptively, but do not treat arm differences as causal.

For each assay, define `sY` once from the complete-triplet outcome values Y across the full frozen analytic sample using sample standard deviation (`ddof=1`), strictly for dimensionless reporting. The standardized RMSE gain of M1 over benchmark k is

`[RMSE(q_k) - RMSE(q_M1)] / sY`.

The standardized MAE gain uses the same denominator `sY`, while MAE itself remains in the assay's unverified source numeric scale. Do not standardize Y separately within folds, arms, bootstrap replicates, or methods, because that would make the benchmark denominators incomparable. Report raw RMSE/MAE alongside standardized gains and state that no clinical unit conversion or reference-range interpretation is possible. If a fold has an undefined training calibration because of zero P variance, use the locked fallback and report its frequency; never silently omit rows.

Add calibration diagnostics for every method that produces a fitted forecast. On held-out predictions, report calibration intercept and slope from `Y = c + d*q` with HC3 uncertainty, but treat this pooled regression as descriptive because it uses held-out predictions. The calibrated-persistence slope/intercept used to generate predictions must be training-fold-only. For raw P, the identity line is not estimated; its held-out calibration diagnostic is separate from its unfit forecast definition.

## Regression-to-the-mean and measurement-error checks

Raw P is not an oracle. Because P is selected as a recent measurement and Y is a subsequent measurement, random assay error and selection on an unusually high or low P can cause regression toward the mean. That is a reason to include raw P, not a reason to discard it or silently replace it with a fitted correction. The principal result must state whether a learned model beats the observed persistence strategy under this measurement process.

Pre-specify these checks without changing the primary estimand:

- report `Y-P` mean, SD, and signed direction by assay and by P quintile (quantile cutpoints determined without using Y, using P only); this is descriptive evidence of mean reversion, not a clinical deterioration endpoint;
- report benchmark loss and M1 gain within P quintiles, with sparse-quintile warnings and no post hoc pooling;
- compare raw P with calibrated P. A large calibrated-persistence improvement over raw P indicates systematic scale/offset or regression-to-mean correction that a fair learned-model claim must overcome;
- fit a pre-specified attenuation/shrinkage sensitivity only as a training-fold-only affine calibration (already represented by q_cal), not as an outcome-informed post hoc transformation;
- retain timing variables and report `P_lead_hours` distributions, because variable lag can induce apparent regression-to-mean or differential measurement opportunity;
- use a negative-control timing forecast, where feasible without changing the frozen rows: use the immediately preceding valid assay before P under a clearly locked window and predict Y, or otherwise state that no valid timing negative control is estimable. This cannot be substituted for raw persistence and must not use data after P.

No units mean that a clinically meaningful error margin cannot be declared. A numerical improvement, even if stable, is not evidence of improved care.

## Uncertainty, pairing, and falsification

Compute row-paired OOF losses for all methods and their per-row differences. The uncertainty unit is the patient, not an arbitrary assay row: use a patient-cluster paired bootstrap resampling `患者主索引` with replacement, retaining all rows from each sampled patient and their inherited outer-fold assignment. If the frozen construction guarantees one selected event per patient, state and verify that; still implement the cluster bootstrap contract. For each bootstrap replicate, calculate losses on the resampled held-out predictions for fixed-prediction inference. Report percentile 95% intervals for each M1-versus-benchmark gain and the fraction of replicates above zero. Use the parent's full-pipeline multinomial cluster bootstrap as a secondary analysis; in it, integer cluster multiplicities are expanded/frequency counts, all training-fold preprocessing, alpha selection, and persistence calibration are refit, and standardized denominators use the expanded-sample `ddof=1` convention. Never treat noninteger weights as expanded counts.

Retain the parent's 20 outcome-blind partition sensitivity analysis, but every partition must compare M1 to raw and calibrated persistence as well as M0. Recompute OOF predictions under each partition and report sign, median, and range of each gain. Retain the corrected P-linkage placebo only as a secondary diagnostic of P linkage; it does not substitute for persistence benchmarking.

Primary supportive branch for an assay requires all of the following: denominator gates pass; M1-versus-raw-P paired OOF RMSE gain is positive; its patient-cluster interval is not materially compatible with zero under the locked threshold; the gain is positive in most outcome-blind partitions; and M1 also improves on calibrated persistence or the difference is explicitly declared unresolved. The two assays must be reported separately; no pooled cross-assay claim is allowed.

Adverse branch: M1 fails to beat raw P, or the gain is unstable/negative, or calibrated persistence matches or beats M1. This means the learned model has not demonstrated value beyond ordinary persistence, even if the inherited M1-versus-M0 result remains positive. If raw persistence beats M0/M1, the parsimonious clinical conclusion is that the latest assay is a strong baseline and added covariates did not improve it.

Inconclusive branch: any denominator or clock mismatch, inability to generate complete OOF predictions, calibration leakage, unestimable patient bootstrap, assay-scale inconsistency, or inability to distinguish native-scale predictions from standardized training features. Wide intervals, sparse arm folds, or no clinically interpretable unit/reference range also limit the strength of any practical conclusion, even when computation succeeds.

## Exact defects in the assigned parent benchmark

The parent is valid for its stated nested prognostic contrast, but it is incomplete for the assigned benchmark question in four specific ways.

1. **No direct P forecast:** M1 contains P, but no result compares its OOF predictions with the unfit forecast `Yhat=P`. M1 > M0 can coexist with M1 <= P.
2. **Potential calibration ambiguity:** the parent reports calibration intercept/slope but does not make clear that any correction to P must be estimated training-fold-only. A calibration fit using all Y, including held-out outcomes, would leak outcome information and invalidate the comparison. This child locks the fit and fallback.
3. **Metric-scale ambiguity:** standardized RMSE gains are useful dimensionless summaries, but raw P and model predictions must be evaluated on the same assay-native numeric scale, with one assay-specific full-sample `sY` denominator. The missing unit column prevents claims about clinical magnitude.
4. **Regression-to-mean is unseparated from predictive refinement:** a learned gain could reflect correction of systematic offset or mean reversion, whereas a gain over raw persistence asks the decision-relevant question directly. P-quintile and raw-versus-calibrated checks reveal, without pretending to identify biological change, whether the result is concentrated in extreme P values.

The inherited corrected linkage placebo remains restricted: it reassigns P within arm/fold/era strata and is not an exact conditional randomization test because it changes P's dependence on B/core. This child does not upgrade that placebo. It also does not repair complete-panel selection, missing outside care, absent laboratory units, absent validated reference ranges, unavailable albumin administration/transfusion/fluid records, unverified medication administration, or missing adjudicated toxicity, response, mortality, and clinical outcomes. Those require additional data, expert adjudication, or prospective validation.

## Expected scientific advance and boundaries

The advance is not a more complicated model. It is a fair, transparent decision-time benchmark that distinguishes ordinary short-lag persistence from reproducible incremental forecasting. If M1 cannot beat P, the study prevents overclaiming and identifies persistence as the appropriate benchmark for future validation. If it beats both raw and training-fold-calibrated P for both assays with stable paired uncertainty, the evidence supports a stronger but still narrow claim: B/core information and contemporaneous state modeling refine prediction of the next recorded assay beyond simply carrying P forward. Neither outcome establishes a treatment effect, hepatic decompensation, toxicity, recovery, safety, benefit, or clinical utility.
