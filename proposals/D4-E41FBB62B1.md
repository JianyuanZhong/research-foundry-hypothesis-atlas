## Reproducibility audit and inferential repair

Two audit findings matter.

First, the parent diagnostic called `nested_predictions` with a different outer/inner split seed for each permutation, although the observed statistic used a single seed. That unnecessarily mixed split-randomness variation with label permutation. It did not create a false positive in the pilot (`p=0.2376`), but it was not a permutation of one fixed deterministic statistic. The completed run repairs this implementation error by applying the identical seed schedule to observed and every permuted label vector. The repaired result (`p=0.2118`) reconciles rather than contradicts the 100-permutation diagnostic.

Second, permuting CRC labels within lag-by-sex is exchangeable only for the strong null that labels are unrelated to all remaining predictors conditional on those strata. It destroys label associations with age and current CBC comparator variables, so it is not, absent that stronger assumption, an exact conditional randomization test of the narrower hypothesis that slopes add no information beyond the comparator. Retuning both models does not itself solve this exchangeability problem. Therefore the frozen p-value is scientifically honest as a complete-pipeline random-label falsification guard, but it must not be promoted to sufficient confirmatory inference for adjusted incremental prediction. A valid narrower conditional test would require a new null-generating mechanism, such as a prespecified conditional-randomization/model-X procedure with audited nuisance-model validity, and that would be a new scientific method rather than a mechanical change to this frozen analysis. This limitation is immaterial to the present hierarchy decision because the observed p is not significant even under the stronger random-label null.

The prior paired participant bootstrap is conditional on the realized averaged predictions; it quantifies resampling variation of that fixed prediction contrast but not full training/tuning instability. Its narrow log-loss interval therefore cannot override the complete-pipeline null result. A full refit bootstrap of performance would be a distinct estimand/computation and was not silently substituted.

## Coefficient-bootstrap resolution

The parent requested coefficient signs with bootstrap intervals but did not define which coefficient when each participant enters ten test predictions and the trajectory model is fitted 50 times under fold-specific scaling and lambda selection. This child makes the ambiguity explicit and reports one reproducible algorithmic summary without treating it as a biological effect: for each marker, the mean standardized coefficient across the 50 outer-training trajectory fits. A stratified participant multinomial-weight bootstrap keeps repeated copies grouped by participant, reruns all 50 outer fits and all inner tuning, and computes that summary in 500 replicates (1,150,000/1,150,000 fits converged). This avoids the leakage that literal duplicated rows could create across participant-level folds.

Percentile 95% stability intervals were:

- adverse Hb slope: observed `-0.0000146`, interval `[-0.04289, 0.01839]`, 46.6% positive;
- adverse MCV slope: observed `-0.000418`, interval `[-0.06849, 0.00371]`, 15.8% positive;
- adverse platelet-30080 slope: observed `-0.000228`, interval `[-0.04402, 0.00931]`, 28.2% positive.

All include zero, and all observed signs oppose the prespecified adverse direction. Because coefficients are penalized, fold-standardized, and selected under varying lambdas, these are algorithmic shrinkage/sign-stability intervals, not confidence intervals for unpenalized biological associations. Five hundred replicates adequately resolve the qualitative zero-inclusion/sign question; the parent's generic wording did not freeze 2,000 coefficient replicates. More bootstrap replicates would reduce Monte Carlo error but cannot turn these summaries into mechanistic-effect estimates.
