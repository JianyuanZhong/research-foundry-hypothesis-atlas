# A partially distinct macrophage transcriptional program in treatment-resistant rheumatoid arthritis: a donor-aware contrast on E-MTAB-8322

## Seed
D2-T2 (Protective versus pathogenic states)

## Domain
Therapeutic Target Prioritization

## Type
New direction (restart). This is the first candidate on E-MTAB-8322 (single-cell macrophages, 27 donors, 5 disease states), a dataset not previously mined in this campaign. The D2-T1 bulk context branch (GSE95588) was mined in ep3-6 and its headline corrected as non-reproducible (ep6, candidate-bbfe9a41); the D2-T2 MerTK branch (candidate-6eda0349) is valid/ready but its "selective abolition" claim is beyond what expression alone proves. This candidate opens a new, data-bound direction.

## Question (falsifiable)
Among RA synovial tissue macrophages, is there a DISTINCT, donor-consistent transcriptional program in patients who are RESISTANT to treatment versus patients in REMISSION — and is it distinct from (not merely a more extreme version of) the NAIVE/undifferentiated state? Does it nominate a therapeutic target / resistance signature?

## Clinical importance
~40% of RA patients respond inadequately to DMARDs; a subset remains refractory after cycling through agents of distinct mechanisms (the EULAR "difficult-to-treat" phenotype) [K1]. Identifying a macrophage-based treatment-resistance signature would (a) predict which patients will fail current therapy and (b) nominate the resistant-state program as a therapeutic target. This directly informs a consequential clinical decision: mechanism-based therapeutic selection for the difficult-to-treat subset [K2]. De Lima 2023 showed that tissue-resident macrophage states and TAM/MERTK signaling are associated with treatment response in a different cohort [K3]; this proposal tests whether a complementary, bulk-pseudobulk macrophage transcriptional contrast on E-MTAB-8322 carries a distinct resistant program.

## Discovery-level evidence (EXECUTED this episode)
Analysis: work/lead/episode7/analysis_8322.py (Welch t-test on per-donor log2(count+1) means, BH FDR across 16,131 expressed genes; distinctness test via Jaccard/Spearman). Results: work/lead/episode7/analysis-out/.

- PRIMARY CONTRAST Resistant vs Remission: 0 genes at FDR<0.1 (low power, n=6/7). Top up-regulated genes (by log2FC): MMP12 (matrix metalloproteinase, tissue remodeling), MT1H and MT1G (metallothioneins, oxidative stress/metal homeostasis). Top down-regulated: ZFP57 (zinc finger protein).
- DISTINCTNESS TEST (the key scientific check): Jaccard overlap of top-100 Res-vs-Rem vs Naive-vs-Rem genes = 0.205 (LOW, <0.3 -> partial distinctness); Spearman rank correlation of the log2FC vectors = 0.606 (MODERATE -> shared inflammatory axis).
- INTERPRETATION: The resistant macrophage state is PARTIALLY DISTINCT from the naive state — it is not simply "more naive/inflammatory" (low top-gene overlap), but it shares a common inflammatory axis (moderate correlation). This is an INCONCLUSIVE-to-PARTIALLY-SUPPORTIVE result: a partially distinct resistant program is suggested, but the contrast is underpowered for genome-wide FDR (0 genes), so the distinctness metrics are the primary informative check.

## Competing explanations (addressed)
1. Cross-sectional confound: Resistant vs Remission are different patients, not a within-patient transition; no causal/temporal claim.
2. "Resistant = more naive/inflammatory": tested by the distinctness test (Jaccard 0.205 low, Spearman 0.606 moderate -> partially distinct, shared axis).
3. Donor/age/sex confound: all female (no sex confound); age balanced.
4. Library-size/batch: log2(count+1) used, not a full normalization; a proper pseudobulk normalization could change the picture.
5. Cell-state composition: pseudobulk macrophages only; subclustering could change the picture (future test).
6. Low power: n=6 vs 7 -> 0 FDR<0.1; the distinctness test is the primary informative check.

## Falsification criteria
- SUPPORTIVE: >=20 genes FDR<0.1 (or a clear module-level signal); top module enriched for a specific axis (e.g. pro-resolving/TAM-MERTK down in resistant); LOW overlap (<0.3) AND LOW correlation (<0.4) with naive-vs-rem -> distinct resistant program.
- ADVERSE: No FDR<0.1 AND HIGH overlap (>0.6) AND HIGH correlation (>0.7) with naive-vs-rem -> resistant is just more naive/inflammatory, no distinct program; OR group imbalance makes the contrast uninterpretable.
- INCONCLUSIVE: <5 FDR<0.1 (as observed: 0) AND MODERATE overlap (0.2-0.5) AND MODERATE correlation (0.4-0.7) -> partially distinct but underpowered; needs larger cohort or subclustering.

## What the result would and would not establish
- WOULD establish (if supportive): a partially distinct, donor-consistent resistant macrophage program that could seed a resistance signature and nominate a therapeutic target (e.g. the pro-resolving/TAM-MERTK axis if specifically down in resistant disease).
- WOULD NOT establish: causality (cross-sectional), a validated clinical biomarker (needs external validation), or a specific mechanism (needs perturbation/subclustering).
- The current INCONCLUSIVE result (0 FDR, Jaccard 0.205, Spearman 0.606) means: a partially distinct resistant program is suggested but not confirmed; the next test (module enrichment + subclustering + proper normalization + independent validation) is required to resolve it.

## Method alternatives (recorded)
- Baseline (used): donor-mean log2FC + Welch t + BH FDR + Jaccard/Spearman distinctness. Simple, transparent, appropriate for n=6/7 donors.
- Alternative (deferred): per-donor subclustering (M1/M2/IFN) then cluster-proportion contrast. More mechanistic but heavier; revisit if the pseudobulk contrast is inconclusive (as it is).
- Alternative (deferred): elastic-net classifier Resistant vs Rem with donor-blocked CV. Overkill for n=13 donors; overfitting risk; not justified now.
- Alternative (deferred): proper pseudobulk normalization (DESeq2/SCT) + donor-level permutation test for exact p-values. Recommended as the next step to resolve the low-power FDR.
