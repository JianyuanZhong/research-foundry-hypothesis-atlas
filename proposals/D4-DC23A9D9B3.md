## Supported evidence, unresolved claim, and advance

The strongest evidence currently supports only these bounded claims. Large creatinine/cystatin-C eGFR differences are common in UK Biobank and have several kidney and non-GFR predictors [K1]. Such differences carry frailty and broad outcome information in SPRINT, and a combined eGFR may discard some of that prognostic information [K2]. Administrative AKI codes can have incomplete, subgroup-dependent recognition relative to creatinine-based KDIGO AKI [K3]. None establishes that a fixed-combined-eGFR profile preferentially forecasts biological AKI rather than CKD, or that UKB N17/N18 first appearances are equally observed.

The unresolved hypothesis is therefore deliberately about recorded transitions: among supported UKB adults aged 40–69 in the common day-30 N17/N18-free state, the profile `P−: 2021 combined eGFR G=90, eGFRcys−eGFRcr=−15`, versus `P0: G=90, delta=0`, has a larger adjusted 10-year relative-risk contrast for first recorded inpatient N17 than for first recorded inpatient N18, and this selectivity is not explained by the observable code-emission process.

Let `theta17=log RR10(N17_first; P−/P0)`, `theta18=log RR10(N18_first; P−/P0)`, and `D=theta17−theta18`. The scientific advance over the parent is not another positive-association search. It asks whether `D` survives three observations on which biological selectivity and coding opportunity differ: baseline nonrenal code history, principal-position confirmation, and a prospectively learned lagged nonrenal code-emission state. A robust result could justify an encounter/laboratory-validated AKI study; a coding-dependent result would redirect or park the branch.

This remains a descriptive joint-marker profile estimand, not an intervention, causal effect, true-GFR contrast, renal-reserve mechanism, or treatment rule.

## Substantive learned alternative: lagged code-emission state model

The baseline compresses observation history to one count and loses timing, diagnostic mix, and transitions between low- and high-emission periods. Fit an outcome-blind 2- versus 3-state hidden Markov model on monthly counts of new non-N17/N18 all-position code first appearances and new principal-position first appearances from index to month 120. These are “code-emission states,” never called admissions or clinical severity. Select state count by validation log likelihood and require stable state ordering across three seeds. The HMM is learned in the training participants without N17/N18 labels.

Then fit the parent’s endpoint-specific discrete-time GAM competing-risk model using only lagged (through the prior month) posterior code-emission probabilities, baseline five-year count, `te(G,delta)`, inherited covariates and calendar time. Compare it with (i) the transparent Cox baseline and (ii) a shared-`G/delta` surface ablation. Participant split is 70/15/15, stratified by sex and aggregate transition class, seeds 20260923–20260925. Evaluate held-out calibration-in-the-large/slope, endpoint and multiclass IPCW Brier scores, time-dependent AUC, HMM held-out likelihood, state stability, and exact P−/P0 `theta17`, `theta18`, `D`.

This alternative asks whether apparent endpoint selectivity remains after representing the observed timing and principal/all-position mix of coding. It does not identify healthcare contact: nonrenal first-code emission may itself reflect disease severity, is depleted as codes accrue, and post-baseline conditioning changes interpretation. Therefore use it as a rival-explanation stress test, never as a “deconfounded causal” estimate.

A neural sequence model is deferred: the exact scientific alternative is low-dimensional code-emission state, and high-dimensional code identity could learn morbidity rather than observation. Revisit only if the HMM fails held-out emission calibration and a preregistered sequence architecture can improve that target, not merely renal AUC. ## Supportive, adverse, and inconclusive patterns

All interpretations require verified export censoring, units/code semantics, exact-risk-set support, model convergence and calibrated held-out predictions.

- **Supportive for recorded N17 selectivity robust to observable coding opportunity:** all-position `theta17` lower 95% bound >0 and `D` lower bound >0; matched `Dmatch` agrees; baseline-code adjustment and lagged code-emission model preserve positive D with compatible intervals; principal-position estimates do not reverse; profile does not show a comparably strong association with broad nonrenal code emission. This supports prognostic information for recorded transitions only.
- **Adverse / coding-opportunity rival favored:** D is precisely null or reversed after baseline code-history adjustment; the profile predicts broad code emission similarly; the learned estimate concentrates in high-emission states and loses N17 selectivity; or principal-position D reverses with uncertainty excluding the all-position estimate. Do not rescue by changing target profiles, windows, endpoints, or HMM state count after test review.
- **Adverse / chronic or shared renal information:** `theta18>0` with `D<=0`, or both endpoint contrasts are similar with adequate precision.
- **Inconclusive:** export linkage remains unverified; principal N18 remains too sparse; state/model calibration fails; methods materially disagree without precise adjudication; ties change direction; or intervals cannot separate the patterns. An imprecise null is not refutation.

Even a fully supportive pattern does not establish KDIGO AKI, biochemical CKD onset, renal reserve, true GFR, mechanism, treatment benefit, or transportability. Those require record-level encounters, longitudinal creatinine/cystatin C/albuminuria, nation/provider metadata, clinician adjudication, external validation and—before care recommendations—an intervention study.
