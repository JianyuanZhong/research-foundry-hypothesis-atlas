# Provisional hypothesis: tissue signal is driven by cell composition rather than within-cell state

Seed context: D3-M1 (composition versus within-cell regulation).

## Proposed relationship
In the available whole-tissue transcriptomic context, apparent disease-associated expression differences are more strongly explained by donor-aware changes in measured cell-type abundance than by changes in expression within a fixed cell type. This is a provisional hypothesis, not an established result.

## Uncertainties and missing evidence

## Falsifiable test
Using only verified available tables and join keys, fit two donor-aware models on the same samples: (A) a composition-only model using measured cell-type proportions/abundances and relevant technical covariates, and (B) a within-cell model using cell-type-specific expression/state features, with a joint model as the substantive alternative. Compare held-out or cross-donor prediction and calibration of the tissue-level outcome, plus coefficient/decomposition stability. Support would be a reproducible composition advantage with within-cell effects attenuated; adverse evidence would be a stable within-cell signal after composition adjustment; inconclusive evidence would be poor separation, insufficient donors/replicates, or unstable estimates. The result would not establish causality or a treatment mechanism.

## Method comparison and deliverable
The simple baseline is a regularized linear/elastic-net composition model. The substantive alternative is a donor-aware joint decomposition or hierarchical model separating mixture proportions from within-cell expression; it can reveal whether a tissue signal is a macroscopic composition effect, a cell-intrinsic state effect, or both, which the baseline loses.
