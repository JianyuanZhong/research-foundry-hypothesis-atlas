# Route-blinded documentation-to-actionability bridge (binding child of [prior hypothesis])

## Scope, precedence, and unchanged inherited design

This is a targeted child of `[prior hypothesis]`. The first-eligible adult, one-admission-per-subject pulmonary-opportunity population; reciprocal pre-departure radiology chronology; exact canonical DS artifact; unit-specific clocks and exhaustive `Y,V,H,Z`; exact atom `g=(possible-calendar class, terminal curr_service, workflow class)`; all-unit adverse routing; `AUTO/RECON/TIMING/DEFER` precedence; support-atlas construction; stratified sampling, inclusion probabilities and hash-rank challenge selection; compatible-set inference; no-rescue rules; hard ceilings (`A<=900`, `C<=300`, 2,370 displayed worst-case physician hours, 84,000 packet minutes); and the prospective-silent-only conclusion ceiling are frozen. No admission, route, atom, time boundary, baseline, primary outcome, or causal estimand is added or redefined.

This amendment adds a pre-label, route-blinded bridge inside the already budgeted holistic challenge and existing packet-review activities. It separates an observable documentation property from a clinically consequential actionability claim that these MIMIC sources cannot establish. It therefore makes the bridge more decision-relevant without treating text agreement as clinical truth, workflow delivery, or outcome evidence.

The amendment must be protocol-hashed and sealed before challenge selection is disclosed, before any parent route, atom, stratum, weight, outcome summary, or compatible-set result is opened to a reviewer. The same selected admissions and the same route-blinded packets are used. No extra admissions, top-ups, adaptive enrichment, post-label control, or additional review pass is allowed.

## Evidence ceiling and unresolved decision question

The strongest claim available from these files is that a first-eligible admission frame and a reproducible, admission-linked text packet can be constructed with pre-departure reciprocal radiology evidence, a canonical DS note, and structured service/ICU/disposition proxies. The files do **not** establish that a clinician saw a note before physical departure, that a note was finalized or signed, that a recommendation was communicated, that an order/referral was placed or executed, that a person or team accepted responsibility, that a patient could follow the plan, that follow-up occurred, or that any outcome or harm followed.

The unresolved bridge question is narrower and falsifiable: among exact frozen atoms and routes, can independent route-blinded reviewers (i) reproduce the same route-defining documentation and (ii) separately determine whether the supplied artifact contains enough explicit information to specify a next action without inventing recipient, timing, replacement, or workflow facts? The hypothesis is that some parent-supported signatures will be documentation-reproducible but not text-actionability-ready, and that the gap will identify precisely which additional prospective workflow fields are needed. A result showing no gap would support a better specified silent bridge packet, not clinical safety or benefit.

`D` (documentation reproducibility) and `A_text` (textual actionability readiness) are distinct observable constructs. Neither is a latent clinical truth label. The prospective bridge must not be approved merely because `D` is high or because route panels agree.

## Exact pre-label bridge packet and route blinding

For every already selected challenge admission, construct one sealed packet from the same inherited extraction. It contains only the permitted reciprocal pre-`D` radiology chain, permitted admission/death/disposition fields, canonical exact DS artifact and permitted DS detail artifact, plus an explicit availability manifest. It excludes parent component labels, route, candidate route, route-defining atom, stratum, inclusion weight, challenge status, all post-`D` text, POE/POE-detail, later outcomes, and any route or atom summary.

Use the existing disjoint H1/H2/H3 holistic challenge roster and its existing three 10-minute challenge rows. Add the following fields to those already sealed forms; there is no extra panel, pass, admission, or time allowance. If a reviewer cannot complete the fields within the pre-existing row maximum, record `NONRESPONSE`/`BRIDGE_INFEASIBLE` and apply the inherited adverse-compatible missingness rule rather than extending the budget.

* **H1 documentation lane (`D`):** independently inventory distinct recommendation units and code the locked target cluster, action/modality, due interval, polarity, recipient/responsibility, replacement, conflict, supporting artifact span, and whether each field is explicit, absent, contradictory, or unreadable. H1 computes no route and sees no route table output. H1 records `D_REPRO`, `D_PARTIAL`, `D_NONREPRO`, or `D_UNKNOWN` only after the atomic inventory is sealed.
* **H2 actionability lane (`A_text`):** using a separately worded codebook and the same packet, first performs its own unit inventory without H1 output, then answers a separate question: could a receiving clinician identify a concrete next action from this artifact without adding an unstated target, action, due interval, recipient/responsibility, replacement rule, or conflict resolution? H2 records `A_TEXT_COMPLETE`, `A_TEXT_CONDITIONAL`, `A_TEXT_INCOMPLETE`, or `A_TEXT_UNKNOWN`. `A_TEXT_COMPLETE` means only that the text has explicit fields; it does not mean an action was delivered, appropriate, feasible, accepted, or completed.
* **H3 evidence-boundary lane (`E_gap`):** after H1/H2 packets are append-only sealed, H3 independently codes whether each required bridge fact is actually observed in the packet/source: `VIEWED_BEFORE_DEPARTURE`, `FINALIZED_SIGNED`, `COMMUNICATED`, `ORDER_OR_REFERRAL_EXECUTED`, `RESPONSIBLE_TEAM_ACCEPTED`, `SCHEDULED_OR_HANDOFF_CONFIRMED`, `PATIENT_OR_CAREGIVER_CAPACITY_PREFERENCE`, and `POST-DISCHARGE_FOLLOWUP_OR_OUTCOME`. Each field is `OBSERVED`, `NOT_PRESENT_IN_AVAILABLE_SOURCES`, `CONTRADICTED`, or `UNKNOWN`; `NOT_PRESENT_IN_AVAILABLE_SOURCES` is not converted to `NO` or to a clinical failure. H3 also records whether the text itself supplies a missing actionability field, but cannot fill it by inference.

The panel records a structured reason vector, not a free-text favorable vote. A missing, unreadable, nonresponse, unresolved reciprocal link, or packet corruption is `UNKNOWN` and remains adverse-compatible under the inherited compatible-set construction. H1/H2/H3 rosters, pseudonyms, packet ordering, codebooks, source hashes, and append-only seal ordering remain disjoint and independently auditable.

## Frozen bridge algebra

For admission `i`, let `U_i` be the inherited canonical distinct-unit list after reciprocal-restatement handling. Let `F_i` be the set of required route-defining fields for all units. Define:

```text
D_REPRO_i = 1 iff both independent H1 and H2 inventories agree on every
             non-unknown unit identity and every non-unknown field in F_i,
             with no unresolved duplicate/restatement, and both packets are valid.
             Otherwise D_REPRO_i=0; missing/corrupt/nonresponse is UNKNOWN.

A_TEXT_COMPLETE_i = 1 iff H2 marks every required field in every retained unit
                    explicit and internally nonconflicting, and no field is
                    inferred from a proxy. It is a text property, not workflow proof.

A_TEXT_GAP_i = 1 iff D_REPRO_i is true but A_TEXT_COMPLETE_i is false.

E_WORKFLOW_GAP_i = 1 iff any of the eight bridge facts is
                   NOT_PRESENT_IN_AVAILABLE_SOURCES or UNKNOWN.

E_OUTCOME_GAP_i = 1 iff follow-up/outcome is NOT_PRESENT_IN_AVAILABLE_SOURCES
                  or UNKNOWN.
```

For a no-unit `NOACTION` descriptive state, `D_REPRO=1` only if both panels independently record an empty unit inventory and packet validity; `A_TEXT_COMPLETE=NA`, never favorable-matched. For inherited `DEFER`, unresolved fields remain `D_UNKNOWN`/`A_TEXT_UNKNOWN` rather than being converted to complete. Distinct units are never collapsed merely because their text is similar. `D_REPRO` must be computed from the sealed atomic inventories, not from parent/H1/H2 route agreement.

The primary inherited route and all route estimands remain exactly as already specified. Bridge quantities are secondary, route-blinded diagnostics and do not alter `route(U)`, `Omega_i`, the atom definition, or the sample. Report the weighted joint matrix by frozen atom and inherited route:

`(D_REPRO, A_TEXT_COMPLETE, A_TEXT_GAP, workflow-gap reason vector, outcome-gap indicator)`.

Report design-weighted proportions and simultaneous finite-population intervals using the inherited inclusion probabilities and compatible-set machinery. Challenge-only results are explicitly conditional on challenge inclusion. No complete-case, favorable-consensus, unweighted, or model-imputed replacement is permitted.

The key decision quantity is the **documentation-to-text-actionability gap** among documentation-reproducible records,

`G_text = P_w(A_TEXT_GAP=1 | D_REPRO=1, atom, inherited route)`,

with numerator and denominator retained jointly in each compatible state. A route-blinded panel may estimate this observable gap; it may not estimate clinical actionability. A second required table reports `P_w(E_WORKFLOW_GAP=1 | D_REPRO=1, A_TEXT_COMPLETE=1)` and lists the exact unavailable bridge facts. Because MIMIC has no prospective workflow feed, a high workflow-gap result is expected evidence limitation, not evidence that care failed.

For compatible-set analysis, retain all admissible H1/H2/H3 atomic states and error flags exactly as in the parent. If a field is unknown, both favorable and adverse-compatible states remain where the inherited rules permit, while `NOT_PRESENT_IN_AVAILABLE_SOURCES` is preserved as an evidence-availability category and cannot be relabeled as observed. Optimize joint `(D_REPRO, A_TEXT_COMPLETE, G_text numerator, G_text denominator)` contributions; never optimize their extrema independently. Unanimous panels do not eliminate the shared-wrong state. The bridge output is `INCONCLUSIVE` when its endpoint is wide, any required field is unresolved, or challenge/workload/seal gates fail.

## Interpretation and falsification criteria

Supportive bridge evidence is a bounded, reproducible pattern in which at least one exact inherited atom has a sufficiently narrow, non-adverse-compatible estimate of `D_REPRO`, a reported finite `G_text`, and a stable list of missing workflow facts. This supports only a more informative prospective silent data-collection specification: the future bridge must capture actual viewing/availability, finalization, communication, responsible team, order/referral execution, scheduling/handoff, patient/caregiver feasibility, and follow-up/outcome fields. It does not support clinical actionability, safety, appropriateness, benefit, or transport.

Adverse bridge evidence is a high or wide documentation-to-text-actionability gap, route-invariant changes in either panel's documentation/actionability classification, unresolved cross-panel units, or a supported atom whose actionability fields can be made adverse-compatible. The affected atom is not nominated for a silent bridge unless the missing field is explicitly added to the prospective collection plan. If the only adverse finding is `E_WORKFLOW_GAP` because a fact is absent from MIMIC, report evidence limitation rather than clinical failure and do not change the inherited route.

Inconclusive evidence includes insufficient pre-label challenge cases, nonresponse, packet corruption, broken seals, infeasible controls, wide compatible-set intervals, unresolved timestamps, or a workflow/outcome field that cannot be classified as unavailable versus unknown. Inconclusive is not evidence of safety or non-actionability.

Falsification occurs if any reviewer sees route/atom/weight information before sealing; if a bridge field changes population, route, atom, sampling, chronology, adverse precedence, or compatible-set state; if a route-invariant text perturbation changes `D_REPRO` or `A_TEXT_COMPLETE`; if a decisive one-field perturbation fails to change only the prescribed inherited atomic state; if missing evidence is silently imputed as observed; if joint ratio bounds are obtained from incompatible marginal extrema; if a pooled bridge result rescues an atom-level failure; or if any report calls `A_TEXT_COMPLETE` clinical actionability or calls absent MIMIC workflow/outcome evidence a negative clinical outcome.
