## Defect and clinical importance

The selected child says that H120 RRT harms use “exact ICU procedure/input evidence” and instructs the compiler to apply the parent’s “exact RRT-input grammar.” No such RRT input grammar is actually frozen in the parent/ancestor. More importantly, a treatment- and outcome-blind source audit of the exact archive found no dialysis-labelled item whose `d_items.linksto` is `inputevents`. Dialysis-labelled items link to `procedureevents`, `chartevents`, or `datetimeevents`; the only renal-labelled `inputevents` items are enteral renal nutrition products. The full `icu/inputevents` scan contains 10,953,713 rows, with no dialysis-category input item. Thus “RRT input evidence” is not an executable dialysis ascertainment rule in this snapshot. Including an unspecified input grammar could silently use nutrition or another non-dialysis input as RRT, changing harm bounds, Holm inputs and the clinical meaning of the safety gate.

This is a semantic endpoint repair, not a claim that the remaining records prove dialysis delivery or renal injury.
