## Method comparison and deliverable

The simple baseline is a regularized linear model of measured FLS features against context, donor, and recorded cell counts. The substantive alternative is a donor-aware hierarchical/joint state model that can separate within-cell response from sample-level context and quantify uncertainty; it reveals information the baseline loses about dependence and whether the signal is a reproducible FLS state rather than a sampling artifact. The solver must newly fit both models, report held-out/donor-aware uncertainty, and produce a contrast/decomposition. CPU is expected to suffice for this small targeted panel; GPU use is not scientifically required. The actual deliverable is a fitted comparison and uncertainty report, not a claimed mechanism.
