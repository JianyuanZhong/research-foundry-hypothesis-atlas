# Episode 4 successor: does repeated instability add information beyond ICU charting intensity?

Parent: `[prior hypothesis]`, assessed valid and highest-ranked on the MIMIC board (mu 33.915; sigma 6.373; one completed comparison). This is a substantive successor, not a cosmetic compiler edit. It preserves the parent’s ICU-transition question but makes the clinically decisive unresolved issue explicit: whether a repeated physiologic signal remains informative after accounting for how intensively the patient was observed.

## Clinical question and falsifiable hypothesis

ICU-to-ward transfer determines whether a patient remains in a high-observation environment. A final isolated vital sign can look acceptable even when instability is recurrent, but repeated observations are also more likely in patients who are sicker or whose clinicians are worried. If repeated instability adds information beyond the last value *and* beyond observation intensity, it could justify prospective evaluation of targeted post-ICU surveillance. If it does not, a high-performing signal may be a documentation/acuity proxy and should not be treated as a discharge-readiness marker.

The strongest claim supported before this experiment is a provenance/feasibility claim: the configured MIMIC-IV 3.1 core snapshot contains linked admissions, ICU stays, timestamped chart events, ICU item dictionary labels, hospital transfers, and in-hospital death/discharge fields. The exact item labels and schema fields are present. The seed and earlier candidate do not establish that recurrent instability predicts failure, that it is independent of chart density, or that changing discharge or monitoring improves outcomes.

Primary hypothesis:

> Among adults whose first eligible ICU stay in a MIMIC-IV hospital admission ends while the admission continues, final-24-hour repeated vital abnormality and charted oxygen-support intensity will be associated with higher 7-day first ICU return or death-before-return, and the repeated-physiology features will improve held-out calibration and Brier score beyond a last-observation snapshot plus measurement-density features.

This is a prognostic association hypothesis. It does not assert that discharge caused the outcome, that delaying discharge helps, or that charted oxygen equals delivered oxygen.

- Inspired O2 Fraction `223835`; O2 Delivery Device(s) `226732`; Code Status `223758`.

For numeric rows use `valuenum` and preserve `value, valueuom, warning` in an audit. Validity is fixed before analysis: HR 20–250, RR 4–80, SpO2 50–100, each MAP 20–200, temperature 30–43°C after converting Fahrenheit by `(F-32)/1.8`, nonnegative oxygen flow, and FiO2 either 0.21–1.00 or 1–100 with values >1 divided by 100. Invalid values are counted and excluded from derived numeric features; they are not silently repaired.

A block is vital-covered if it contains at least one valid HR, either MAP source, RR, SpO2, or temperature. A block is abnormal if any valid vital is abnormal using fixed rules HR <50 or >100, RR <8 or >24, SpO2 <92%, MAP <65, or temperature <36 or >=38°C. Retain arterial and non-invasive MAP separately and define combined MAP as the minimum valid source within a block. The main repeated-physiology variable is abnormal-block count divided by covered-vital-block count. Preserve abnormal count, covered count, total valid rows, domain-specific counts, and per-domain missing indicators.

For each numeric domain, the last snapshot is the median of valid observations at the latest `charttime`; if no observation is valid, retain missingness. Oxygen features are maximum valid flow across the three flow items and maximum normalized FiO2, with item-specific maxima and observed indicators. Device and code-status text contribute only observed/not-observed indicators and audited raw-value frequencies. They must not be interpreted as a validated device mode or treatment-limitation decision.

Observation-intensity variables, calculated from the same pre-`t0` window, are the six-block vital coverage count, total valid vital rows, per-domain valid-row counts, per-domain observation indicators, oxygen observation indicators, and their fixed log-transformed counts where used. They are potential ascertainment proxies, not confounder-adjusted truth.

## Outcomes and estimands

Set `tau = min(t0 + 7 days, admissions.dischtime)`; include events at `tau`. A later ICU stay is a candidate return only when it has the same `subject_id, hadm_id`, a different `stay_id`, and `intime >= t0`. Select the earliest candidate by `intime), then numeric `stay_id`. Do not count overlapping stays with `intime < t0` as returns; report these chronology anomalies.

The competing outcomes are:

1. first candidate ICU return by `tau`;
2. death after `t0` and by `tau`, strictly earlier than the first candidate ICU return.

If return and death have exactly equal timestamps, label the record tie/indeterminate and exclude it from the primary competing-risk fit; report sensitivities assigning all ties to each cause. Death after a return is not cause 2. No event by `tau` is censored at `tau`. The primary composite is either cause. Report 48-hour and 12-hour versions and all-hospitalization follow-up as prespecified secondary descriptions.

The primary scientific estimand is the held-out incremental prognostic value of repeated physiology beyond (i) baseline/index information, (ii) the last snapshot, and (iii) observation-intensity features. Report 7-day Aalen–Johansen cumulative incidence for each cause and the composite, cause-specific hazard-ratio associations per development-set SD, calibration slope/intercept, integrated or fixed-horizon Brier score, AUROC/AUPRC as secondary measures, and absolute-risk strata. These are associations and predictions within this snapshot, not causal effects or validated bedside thresholds.

## Baselines and analysis

Use identical index records, outcome labels, subject partitions, preprocessing and locked test set for all models:

- B0: gender, anchor_age, anchor_year_group as a descriptive stratum, admission_type/location, insurance, first/last careunit, ICU LOS, hours from `admittime` to `t0`, and number of earlier ICU stays ending by `t0`, with missing indicators.
- B_last: B0 plus the last valid HR, separate/combined MAP, RR, SpO2, temperature, oxygen flow and FiO2, source indicators and missing indicators.
- B_density: B_last plus all fixed observation-intensity variables, with no repeated-abnormality burden.
- B_full: B_density plus abnormal-block burden, abnormal count/fraction, per-domain abnormal indicators, and oxygen intensity features.

The primary incremental contrast is B_full versus B_density. B_last and B_density show whether any gain is merely a last-value or ascertainment gain; B0 is context. Fit two ridge-penalized cause-specific Cox models for return and death-before-return, selecting penalty only by inner development cross-validation. Derive cumulative incidence from the fitted cause-specific hazards, while treating competing causes as events in Aalen–Johansen estimates. Use subject-level 60/20/20 development/validation/test partitions based on the fixed SHA-256 participant partition rule; all stays from one subject remain together. Development data alone determine imputation, one-hot levels, scaling, penalty and any coverage model.

Use 1,000 fixed-seed subject bootstrap resamples of the locked test set for 95% intervals of metrics and paired model differences; use robust/clustered uncertainty for coefficients. If an event or partition gate is not met, report the corresponding estimate as infeasible rather than changing the design.

## Feasibility, missingness and falsification

Before fitting, write a manifest containing total admissions/patients/ICU stays, adult chronology exclusions, index count, six-block coverage, valid/invalid counts for every item, oxygen/device/code-status observation rates, ICU-return/death/tie/censor counts, overlapping-stay anomalies, and counts by careunit and anchor-year group. The episode-4 audit script `work_mimic_episode4_audit.py` is a derived workspace artifact; its first implementation failed on compressed-member decoding and was corrected/resubmitted. Any successful output is evidence of computation only, not evidence for the hypothesis.

The primary composite fit requires at least 1,000 indexes and 100 composite events. Cause-specific inference requires at least 50 returns and 50 deaths-before-return; otherwise provide descriptive cumulative incidence with a sparse-event/inconclusive label. At least 60% of all eligible indexes must have >=4/6 covered vital blocks for the coverage design to be feasible. These thresholds are fixed execution gates.

Use development-only median/mode imputation with missing indicators. Report coverage and density by burden, outcome, careunit and partition. A sensitivity uses stabilized inverse-probability-of-coverage weights estimated from B0 and careunit, truncated at the 1st/99th percentiles; it is an ascertainment sensitivity, not a causal correction.

Required checks:

1. Fail closed on any feature row with `charttime >= t0`, another stay, `storetime`-based eligibility, post-index field, duplicated primary index, invalid event chronology, or prohibited predictor.
2. Shift the exposure window to `[t0-48h,t0-24h)` with the same index/outcomes. A similar or stronger effect suggests general severity or documentation rather than discharge-proximal residual instability.
3. Fit a density-only model and use earlier-window density as a negative-control predictor. If density explains the signal while B_full adds nothing, do not call the result physiologic.
4. Permute outcome labels within locked subject partitions while preserving coverage; performance must return to chance within bootstrap uncertainty. Failure invalidates the computation.
5. Repeat with arterial versus non-invasive MAP, 2-hour return-gap restriction, tie assignments, and 48-hour/12-hour horizons.
6. Compare all eligible index stays with the primary first-index cohort, clustering by subject/admission. Large divergence is selection dependence.
7. Audit raw code-status and device values without auto-classifying goals of care or support mode.

Supportive results require a prespecified positive/monotonic burden association and a B_full improvement over B_density in locked-test calibration/Brier with uncertainty excluding trivial/no improvement, directionally consistent across density, earlier-window, MAP-source, return-gap and tie sensitivities, and a successful permutation check. A small AUC increase without calibration or absolute-risk separation is not clinically supportive.

Adverse results are a null/negative burden association, no B_full improvement, or reversal after density/earlier-window/competing-risk/source checks. This would suggest repeated charted instability adds no reliable information beyond snapshot and observation intensity, or is mainly general acuity.

Inconclusive results include failed event/coverage gates, sparse or unstable estimates, contradictory source/tie sensitivities, inability to separate chart density from physiology, or a failed permutation check. A failed permutation check invalidates computation rather than falsifying the clinical hypothesis.
