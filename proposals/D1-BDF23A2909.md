# A hospital-stratified bound on the end-of-life anticipation rival in the eICU draw-intensity branch

Lead working proposal — eICU 2.0 island, **episode 27**. Operation: **evolve** of true parent
`[prior hypothesis]` (valid, delivery-complete, mu 32.47, episode-26 bounded evolve;
seed origin `[starting question]`). Status: **design owned by the Lead for compilation.**
Discovery executed one bounded read-only probe; no solver/reference pipeline was run. Readiness only.

## 1. Unresolved question and clinical importance

The parent branch tests whether a **within-hospital** drop in clinical-panel lab-draw intensity marks
**unmet monitoring need** (fewer draws while unstable → escalation) or a **between-hospital draw-practice
fingerprint**, using a within-vs-between decomposition with an E-value and a leave-one-hospital-out
(LOHO) transport test. The parent's *remaining* opening is the **anticipation rival R5**: clinicians
stop drawing labs *because they already judge the patient will deteriorate/die*. The parent bounded R5
using only a **global** documented end-of-life (EOL) care-plan prevalence (0.71%).

Clinical decision at stake: "**is less ICU lab testing harmful here, or is it low-value testing we can
safely reduce?**" — the exact question under randomized de-implementation test by [K2] WICH-ICU. Whether
R5 (documented anticipation) or H1 (unmet need) supplies a within-hospital signal changes whether a
draw-rate drop should trigger a monitoring review or be treated as normal practice variation.

## 2. Already supported vs the unresolved claim

- **Already supported (not re-claimed):** laboratory test *presence and timing* carry survival signal
  independent of the value ([K1] Agniel 2018: order presence significant in 233/272 tests; timing beat
  the value in 118/174); sicker patients receive more monitoring; a severity-adjusted within-patient
  panel draw-rate change is associated with later escalation (parent branch).
- **Unresolved claim this experiment tests:** the within-**hospital** β_W is a patient-level
  unmet-need signal that is *not* explained by documented comfort-care transitions, **and the R5 bound
  is not an artifact of pooling hospitals where EOL is never coded.** The strongest rival R5 denies the
  first part and can also be diluted by the second.

## 3. Leading claim H1 vs strongest rival R5, and the separating observation

- **H1 (leading, falsifiable):** β_W < 0 (draw-rate drop → later escalation), high within-hospital
  variance share S_W, E-value ≥ 2.0, stable LOHO transport, **and β_W materially unchanged after
  censoring/excluding documented EOL transitions** — *in both EOL-coding and non-EOL-coding hospitals*.
- **R5 (target rival):** the within-hospital association is anticipation — clinicians taper monitoring
  while planning/implementing a comfort-care transition. **Separating observation (this child's new
  test):** EOL is *structurally absent* where it is never documented. Pre-specify a **hospital-stratum
  contrast**: (i) hospitals with ≥1 documented EOL care plan, and (ii) hospitals with **zero**
  documented EOL (112/208). Under R5, `β_W^(EOL-coding hospitals)` should attenuate toward 0 after
  documented-EOL censoring; under H1, `β_W^(non-EOL hospitals)` must remain clearly negative because
  documented-EOL anticipation is impossible there. A global E-value **cannot** make this stratum
  contrast; the parent treated EOL as a single pooled prevalence.
- **Other rivals kept:** R2 between-hospital fingerprint (β_W≈0, β_B≠0, low S_W, poor LOHO); R4 reverse
  ordering (strict temporal ordering + washout + hour-12 placebo landmark); residual severity (hour-24
  APACHE-IVa + trajectory).

stratum for the R5 test above. This probe does **not** measure the exposure (draw rate) or the outcome
(escalation); it quantifies only the hospital distribution of the documented-EOL channel.

## 6. Baseline vs substantive alternative (method exploration)

- **Simple baseline:** fixed-effect cause-specific logistic model for escalation with a **single
  uncentered** linear `logR` draw-rate, adjusted for hour-24 severity. This confounds within- and
  between-hospital components and cannot separate H1 from R2/R5.
- **Substantive alternative:** mixed-effects (hospital random intercept + random slope on `logR`)
  model decomposing `logR_ih = (logR_ih − μ_h) + μ_h` into `β_W` (within, hospital-mean-centered) and
  `β_B` (between), with a **pre-specified EOL-stratum interaction**, plus a cause-specific
  time-to-escalation hazard with a time-varying exposure. The alternative reveals whether the signal is
  a person-level within-hospital need (H1) or a hospital-level practice/anticipation structure
  (R2/R5) — information the pooled baseline coefficient cannot produce. CPU-feasible.
- **Decision rule (both):** H1 requires β_W<0 with E-value ≥2.0 **and** β_W retained after EOL censoring
  **and** β_W clearly negative in the zero-EOL hospital stratum.

## 7. Falsification criteria (pre-specified)

- **Supportive (H1):** β_W<0, E-value≥2.0, small |Δβ_W| after documented-EOL censoring, and a clearly
  negative β_W in the 112 zero-EOL hospitals; LOHO transport stable.
- **Adverse (R5):** β_W in zero-EOL hospitals ≈ 0, OR β_W attenuates materially toward 0 after
  censoring documented EOL in EOL-coding hospitals.
- **Inconclusive:** zero-EOL stratum too small/imbalanced for a stable estimate, or CIs include both
  the H1 and R5 predictions.

## 8. Honest limits (not claimed as results)

- Readiness only: multilevel/E-value/LOHO/stratum estimators are **NOT executed** at discovery; the
  probe covers only EOL hospital distribution, not the exposure or outcome.
- EOL is under-coded; the bound covers **documented** transitions only, not undocumented prognostication.
- E-value is a single-confounder risk-ratio bound; OR→RR approximation flagged.
- LOHO is internal transport, not external validation. Causal/unmet-need and policy claims require
  stewardship/quality-registry data or the randomized WICH-ICU result. [K2] numeric target NOT asserted.
