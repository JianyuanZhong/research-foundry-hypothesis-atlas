# Reversibility of macrophage inflammatory state in RA: persistence versus remission

Seed: D3-M3
Domain: Disease Mechanisms & Pathway Hypotheses

## Unresolved question

In rheumatoid arthritis (RA), is the macrophage inflammatory state (M1-like polarization) a persistent, self-reinforcing state that survives removal of the initial stimulus, or is it a transient response that resolves when the stimulus (e.g., fibroblast-derived signals) is removed? This question is consequential because it determines whether anti-inflammatory therapy needs to be sustained indefinitely or whether a time-limited intervention can achieve durable remission.

## Evidence for the opening

- E-MTAB-8322 contains pseudobulk macrophage expression data from RA and healthy donors. The cross-sectional design cannot establish transitions, but it provides a baseline for comparing inflammatory state markers.
- E-MTAB-8316 contains four FLS donor clusters with six nested monocyte donors and twelve condition samples. The nested design allows donor-aware paired comparisons of monocyte/macrophone expression under the same donor context, including conditions with and without fibroblast contact.
- GSE95588 coculture data provide additional paired condition comparisons, though r1/r2 includes earlier GSE57723 data and cannot count as independent validation.

## Hypothesis

The macrophage inflammatory state in RA is a persistent, self-reinforcing state that does not fully resolve upon removal of fibroblast-derived signals. Specifically, macrophages exposed to RA-FLS-derived signals will retain elevated expression of inflammatory markers (e.g., IL6, TNF, CXCL8) even after the stimulus is removed, compared to macrophages that were never exposed.

## Competing explanations

1. **Transient response**: The inflammatory state is a direct, reversible response to fibroblast-derived signals. Upon removal of the stimulus, macrophages return to baseline. This would support time-limited anti-inflammatory therapy.
2. **Disease-driven persistence**: The inflammatory state is driven by intrinsic disease factors (e.g., genetic predisposition, epigenetic reprogramming) that persist regardless of external stimuli. This would suggest that anti-inflammatory therapy needs to be sustained.
3. **Treatment artifact**: Differences in inflammatory state may reflect treatment status rather than disease biology. Cross-sectional data cannot distinguish these.

## Falsifiable test

1. **Primary test**: In E-MTAB-8316, compare macrophage expression of inflammatory markers (IL6, TNF, CXCL8) between:
   - Condition A: monocytes exposed to RA-FLS-derived signals (coculture)
   - Condition B: monocytes not exposed to RA-FLS-derived signals (control)
   - Condition C: monocytes previously exposed to RA-FLS-derived signals, then washed and cultured without stimulus (recovery)

   If the inflammatory state is persistent, Condition C will retain elevated inflammatory markers compared to Condition B. If transient, Condition C will return to baseline.

2. **Secondary test**: In E-MTAB-8322, compare inflammatory markers between RA and healthy donor macrophages. If the state is disease-driven, RA macrophages will show elevated inflammatory markers even without external stimuli.

## Outcomes

- **Supportive**: Condition C (recovery) retains elevated inflammatory markers compared to Condition B (control), and RA macrophages in E-MTAB-8322 show elevated inflammatory markers. This supports the persistence hypothesis.
- **Adverse**: Condition C returns to baseline inflammatory markers, and RA macrophages do not show elevated inflammatory markers. This supports the transient response hypothesis.
- **Inconclusive**: Mixed results, or insufficient donor overlap to make a definitive comparison. This would require additional experiments or data.

## Limitations

- Cross-sectional data cannot establish longitudinal transitions. The recovery condition (Condition C) is a proxy for stimulus removal, not a true time-course experiment.
- The targeted assay (E-MTAB-8873) only measures 445 features; unmeasured genes are unavailable.
- GSE95588 r1/r2 includes earlier GSE57723 data and cannot count as independent validation.
- Treatment status is not available in all datasets, limiting the ability to distinguish disease-driven from treatment-driven effects.

## Next steps

1. Verify that the recovery condition (Condition C) is available in E-MTAB-8316.
2. Perform donor-aware paired comparisons of inflammatory markers across conditions.
3. If supportive, design a prospective time-course experiment to confirm persistence.
4. If adverse, investigate the mechanism of transient response and its implications for time-limited therapy.
