# Intervention-specificity test for protective-versus-pathogenic target selectivity

Seed: D2-T2. Parent: [prior hypothesis].

## Question and clinical importance

Does an intervention-associated transcript pattern reduce a pathogenic fibroblast program while preserving a protective macrophage-linked state, such that a target prioritized from an averaged signal would be misleading? This matters because macrophage and fibroblast programs can have opposing roles in fibrotic or inflammatory disease: an intervention-associated change in one compartment may reflect a protective response, a pathogenic program, or simply differential cell composition and stimulation. Resolving the question would change whether a target is pursued as context-specific, requires a cell-type-resolved intervention, or is deprioritized.

## Strongest currently supported claim

The strongest claim supported by the available evidence is that the four configured sources contain macrophage/fibroblast-related conditions and intervention-associated transcript changes. The datasets are available as prepared counts and design metadata. This is descriptive evidence, not evidence that a specific transcriptomic signature is intervention-specific or that a target is directly actionable.

## Unresolved claim

The unresolved claim is whether the proposed selectivity (reduced pathogenic fibroblast program with preserved protective macrophage-linked state) is an intervention-specific signal or a consequence of donor composition or stimulation. This is the key competing explanation that must be discriminated before a target can be prioritized.

## Operational definitions

- Protective macrophage-linked state: defined by a gene set enriched in macrophage-associated protective functions (e.g., anti-inflammatory, tissue-repair) from the available transcript data.
- Pathogenic fibroblast program: defined by a gene set enriched in fibroblast-associated pathogenic functions (e.g., pro-fibrotic, ECM-remodeling) from the available transcript data.
- Negative-control gene set: a gene set with no expected intervention-specific effect, chosen a priori to test for composition/stimulation artifacts.
- Stimulation control: a condition with known stimulation but no intervention, used to test for stimulation-driven changes.

## Competing explanations

- Donor composition: differences in donor composition may drive the observed pattern.
- Stimulation: differences in stimulation may drive the observed pattern.
- Intervention-specific signal: the observed pattern is specific to the intervention.

## Falsification criteria

- If the negative-control gene set shows a similar pattern to the protective/pathogenic gene sets, the observed pattern is likely an artifact of composition or stimulation.
- If the stimulation control shows a similar pattern to the intervention, the observed pattern is likely driven by stimulation.
- If the intervention-specific signal is not significant after donor-aware adjustment, the observed pattern is not intervention-specific.

## Supportive, adverse, and inconclusive outcomes

- Supportive: the intervention-specific signal is significant after donor-aware adjustment, and the negative-control gene set and stimulation control do not show a similar pattern.
- Adverse: the negative-control gene set or stimulation control shows a similar pattern to the protective/pathogenic gene sets, indicating that the observed pattern is an artifact.
- Inconclusive: the intervention-specific signal is not significant after donor-aware adjustment, or the negative-control gene set and stimulation control are not available.
