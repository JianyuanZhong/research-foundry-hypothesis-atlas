# Residual instability before ICU-to-ward transfer: separable evidence contract

Status: proposed substantive child of `[prior hypothesis]`; no outcome model has been fit and no hypothesis result is claimed. The fixed population, index transfer, 24-hour exposure window, 48-hour outcome horizon, exact MIMIC-IV 3.1 bindings, S0/T1 comparison, and subject-level split are unchanged.

## Why a child is scientifically necessary

The parent is valid, but its single conjunctive “supportive” label entangles four different questions:

1. Does final-24-hour value history add held-out prognostic information beyond the endpoint snapshot?
2. Is the increment large enough to matter at prespecified clinical decisions?
3. Is the increment attributable to measured-value content and temporal order rather than observation or discharge processes?
4. Is the composite endpoint sufficiently valid for the intended interpretation?

A statistically real but subthreshold increment is neither supportive of clinical materiality nor adverse to incremental information. Likewise, masks-only performance does not erase a separately present value contribution, and a composite gain can conceal opposing ICU-return and death behavior. The parent’s patient-level value permutation tests whether patients’ values matter, but destroys value levels, trajectories, and cross-channel relations simultaneously; it cannot isolate temporal order. GRU-D also learns directly from masks and time gaps, so a GRU-D gain does not distinguish physiology from care process.

A second computability problem is prospective availability. `icu/chartevents` has both `charttime` and `storetime`. Requiring only `charttime < t0` can admit a retrospectively entered record that was unavailable at the transfer decision. The repaired primary analysis therefore requires both `charttime in [t0-24h,t0)` and `storetime < t0` for every chart-derived predictor. The charttime-only analysis remains a clearly labeled retrospective sensitivity. This does not change the biological exposure window; it makes the decision-time information set honest.

## Evidence boundary and unresolved claim

The strongest inspected evidence supports three bounded claims. A 2026 MIMIC-IV/external-hospital study found GRU-D++ discriminated seven-day ICU readmission/death better than SWIFT, while using daily averages and acknowledging unresolved operational factors, DNR status, and composite-component differences [K1]. A systematic review found that higher-performing ICU-readmission models often used homogeneous populations, explicit outcomes, and longitudinal routinely collected predictors, but outcome windows and composite definitions varied [K2]. A large EHR study showed that whether and when measurements occur can predict outcomes independently of values, because records encode healthcare processes as well as physiology [K3].

These works do not establish that short-timescale residual instability in the final 24 hours before a fixed ICU-to-general-ward transfer adds decision-time 48-hour information beyond endpoint state; that any increment is clinically material; that temporal order rather than value distribution or observation policy carries it; or that ICU return and death support the same interpretation.

**Primary falsifiable hypothesis.** In the parent’s fixed cohort, T1’s prespecified value-trajectory features improve held-out 48-hour three-state prediction over S0 after enforcing decision-time availability, and measured-value content adds information beyond the observation process. Clinical materiality and temporal-order dependence are distinct secondary claims and are not required to conclude that incremental prognostic information exists.

This remains a prognostic and measurement-discrimination study. No available automatic analysis can identify a biological mechanism or show that delaying transfer or increasing monitoring helps.

## Models: same inputs and target, more diagnostic alternative

### S0 and T1

Retain the parent’s ridge multinomial S0 and nested T1 formulas, plausibility rules, two-hour bins, persistence/volatility summaries, training-fitted preprocessing, and identical three-state target. Both models use only decision-time-available records in the primary analysis. S0 already includes measurement density, recency, store lag, caregiver count, endpoint values, support state, transfer context, and code status. T1 adds only the frozen trajectory-value summaries.

The primary incremental estimand remains paired test `Brier(S0)-Brier(T1)`. To avoid confusing explanation with risk contrast, the parent’s adjusted high-versus-low trajectory-burden risk difference is retained as a descriptive standardized association, not evidence that the burden caused deterioration.

### O1 observation-process model

Fit the parent’s measurement-only model on static transfer context plus decision-time-known masks, counts, recency, store-lag distributions, and caregiver counts, with no measured values. Counts of records entered after `t0` are leakage-audit outputs only and are never predictors. Report O1 versus static context and versus S0. O1 performance quantifies usable process signal; it does not by itself prove that T1’s separate value increment is artifactual.

### L1 GRU-D benchmark

Retain compact GRU-D on the same 12 bins, static inputs, target, split, tuning grid, calibration, and five seeds. It is useful as a flexible benchmark but not as the main attribution model because it deliberately entangles values, masks, and gaps.

### L2 two-stream masked temporal convolutional alternative

Add a compact two-stream TCN on the identical twelve bins and target:

- value stream: standardized observed values plus forward-filled values, with no mask or gap channel;
- process stream: masks, time since last measurement, within-bin counts, store-lag summaries computed only from records available by `t0`, and caregiver counts, with no measured values;
- static stream: exactly S0 transfer context;
- fusion: separate two-layer causal 1-D convolution encoders (kernel 3, dilations 1 and 2, 32 or 64 channels, dropout 0 or 0.2), concatenated with static context before the three-class head.

Fit five fixed seeds with Adam (`1e-3` or `3e-4`), validation log-loss early stopping, and validation-only temperature scaling. L2 is scientifically preferable to replacing GRU-D because its stream-specific predictions and ablations directly estimate what value history adds over process history while retaining nonlinear cross-channel timing. It can represent late relapse and local order that T1 summaries lose; unlike a latent physiological-state model, it does not claim identifiable biology.

Mandatory L2 contrasts on the untouched test set:

- full L2 versus process+static stream;
- full L2 versus value+static stream;
- value+static stream versus S0;
- full L2 versus T1;
- **within-person pre-endpoint bin-order permutation** of the value stream: keep the final two-hour bin fixed and apply one shared permutation of the preceding 11 bins across all value channels, leaving that person’s pre-endpoint value multiset, masks/process stream, static inputs, and endpoint snapshot fixed; average predictions across 20 frozen permutations;
- **patient-level value-sequence permutation** within destination, S0-risk decile, and density quintile, as in the parent.

The within-person pre-endpoint permutation asks whether ordering before the frozen endpoint matters beyond value distribution. The patient-level permutation asks whether the person-specific value trajectory matters at all. Neither manipulation proves biology: value responses may reflect treatment, clinician reaction, or measurement error.

A joint latent physiological/observation model remains deferred. From one observational site, its latent-state separation would depend on unverifiable assumptions and would not identify biology. Revisit only with independent continuous-monitor data, staffing/monitoring metadata, or adjudicated observation-policy changes.

## Split, evaluation, and four-axis interpretation

Retain the frozen subject split seed 20260923 (60/20/20), validation-only model selection/calibration, one test opening, and 2,000 subject-cluster bootstrap replicates.

Report four axes separately; never collapse them into one supportive/adverse label.

### A. Incremental prognostic information

- **Supported:** paired `Brier(S0)-Brier(T1) > 0` with 95% CI entirely above zero, acceptable calibration after validation-only recalibration, and no leakage/readiness failure.
- **Falsified at the material bound:** the 95% upper bound is <0.002 with adequate events/coverage. This rules out the prespecified material Brier gain, not every nonzero gain.
- **Inconclusive:** CI crosses zero or calibration/event/coverage gates fail.

### B. Clinical materiality

- **Supported:** point Brier gain >=0.002, positive incremental net benefit of T1 over S0 at at least two of 2%, 5%, 10%, and prespecified risk-category reclassification/clinical counts are reported; the standardized burden contrast >=2 percentage points with CI above zero is corroborative, not required to prove model utility.
- **Not demonstrated:** information gain is statistically supported but any materiality criterion fails.
- **Inconclusive:** uncertainty spans thresholds or calibration invalidates decision analysis.

Thus a real gain below one threshold is reported as “incremental but not clinically material by this contract,” not adverse.

### C. Source and temporal structure of signal

Classify the evidence pattern, allowing mixed results:

- **value-history contribution:** T1>S0 and L2 full>process+static, with patient-level value permutation removing most of that increment;
- **order contribution:** L2 full exceeds the mean within-person order-permuted L2 with paired CI above zero; if not, value distribution/persistence may matter without fine order;
- **process-dominant:** O1/process-stream carries most performance and value additions have CIs including zero;
- **mixed value/process:** both streams add; this is expected and must not be forced into a biological/artifact dichotomy.

Repeat these contrasts in the dense core-vital stratum, no-treatment-limitation stratum, daytime transfer stratum, and charttime-only retrospective sensitivity. Attenuation is reported quantitatively. No ablation establishes biological residual instability.

### D. Endpoint/component validity

Fit secondary four-state multinomial S0c/T1c models on the same split to estimate component-specific Brier differences; retain first-event cumulative incidences as descriptive checks. With approximately 661 deaths overall, a test split may be underpowered for a clinically material death-specific gain, which yields component uncertainty rather than forced consistency.

- **Component-consistent:** T1-S0 Brier direction and clinically relevant risk ordering agree for ICU return and death, without a sensitivity reversal.
- **Component-specific:** one component carries the composite gain; state which.
- **Endpoint-ambiguous:** directions conflict, PACU-precursor proxy exclusion materially reverses ICU-return results, or treatment-limit strata reverse death results.
- **Adjudication-required:** a random stratified sample of predicted high-risk positives and controls is needed to estimate planned-return and expected-death misclassification with blinded dual clinician review.

A composite signal remains prognostically checkable even when endpoint interpretation is ambiguous, but it cannot be called evidence of preventable deterioration.

## Supportive, adverse, and inconclusive overall reports

The solver must output the four-axis vector before a narrative:

- A supportive overall report requires A supported; it must qualify whether B is material, C is value/order/process/mixed, and D is consistent/component-specific/ambiguous.
- An adverse report is appropriate only when adequate precision rules out the 0.002 material increment or value history adds nothing beyond S0/process; it does not prove biological stability.
- An inconclusive report is required for insufficient precision, leakage failure, poor calibration, inadequate events/coverage, or unresolved endpoint reversal.

Examples the verifier must reject include: claiming biological instability from T1 or L2 gain; claiming no information because the 2-point burden threshold fails while Brier gain is supported; calling masks-only performance proof that values do not matter despite a positive full-versus-process contrast; or calling the composite preventable when only death or procedurally preceded returns drive it.

## What is computable and what is not

Computationally checkable: source hashes/headers, joins, population, windows, `charttime/storetime` availability, item dictionaries, event chronology, component labels, exact PACU-predecessor path, split integrity, all model inputs/ablations, calibration, paired metrics, bootstrap intervals, decision curves, and whether conclusion text matches the four-axis thresholds.

Not automatically establishable: true discharge intent, planned versus unplanned return, treatment preferences, expected death, adequacy of ward staffing/monitoring, biological mechanism, benefit of delaying transfer or extra monitoring, and external transportability. These require clinician adjudication, operational data, a prospective impact study, or external validation.
