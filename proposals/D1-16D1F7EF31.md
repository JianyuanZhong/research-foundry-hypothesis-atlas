# Does hypotension DURATION add AKI risk beyond DEPTH? Completing the within-depth-stratum feasibility bound in eICU 2.0

Lead working proposal — eICU 2.0 island, **episode 32**. Operation: **evolve** of the valid,
delivery-complete leader `[prior hypothesis]` (mu 32.08). Status: **design +
bounded executed dependency probe**; the full fitted estimator (interaction beta, E-value, transport

not a solved result.

## 1. Unresolved question, clinical importance, advance
ICU teams titrate fluids/vasopressors to a MAP target. Time-weighted MAP<65 burden predicts
creatinine-KDIGO AKI ([K1] AUC 0.725), and cumulative MAP<65 duration tracks downstream organ
outcomes ([K2] aOR 1.78 for >=30 min). Both model burden/duration additively as a scalar exposure.
The decision-facing question is unresolved: **once a patient's deepest MAP is known, does cumulative
time-below-65 add AKI risk (conditional effect), or does depth alone suffice?** If conditional
duration adds risk, "time below target" is a distinct monitoring target; if it does not, duration
alarms add no information beyond a single worst value. Advance over [K1]/[K2]: a *depth-conditioned*
contrast with channel-disjoint ascertainment and a recurrence rival [K2(Ren)] rather than another
additive burden model. [K3] bounds transportability.

## 2. Leading claim vs strongest rival
- H1 (leading): within a fixed depth stratum (quintile of min MAP in (0,24]h), longer cumulative
  time with MAP<65 in (0,24]h raises (24,72]h KDIGO creatinine-AKI odds — a positive duration x depth
  interaction.
- Rival: any apparent duration effect is explained by (a) depth/severity confounding, (b) temporal
  PATTERN/recurrence of episodes [K2], or (c) sampling-intensity/measurement artefact (more monitoring
  => more detection). The design separates (a) via within-stratum ORs + interaction, (b) via an
  episode-count/recurrence term, and (c) via a lab-draw-rate control + channel-disjoint confirm.

## 3. Design (frozen from parent)
- Population: adult eICU 2.0, age >=16, alive at 24h landmark (`unitdischargeoffset`>=1440), with
  baseline and follow-up creatinine.
- Exposure: (0,24]h MAP burden from `vitalPeriodic.systemicmean` (min MAP = depth; minutes/area with
  MAP<65 = duration), offsets in MINUTES.
- Landmark: 24h. Outcome: (24,72]h KDIGO creatinine-AKI (follow-up/baseline >=1.5) from `lab`
  (`labname`='creatinine'); urine-output ascertainment used only as a channel-disjoint confirm.
- Adjustment: APACHE/severity, age, gender, vasopressor exposure (`infusionDrug`); hospital fixed
  effects; leave-one-hospital-out (LOHO) transport; calibration (slope/intercept) per [K3].
- Key test: within-min-MAP-stratum ORs and duration x min-MAP (and duration x recurrence) interaction.

## 6. Falsification / outcomes
- Supportive H1: interaction OR >1 with CI excluding 1 and a monotone within-stratum duration trend,
  robust to the lab-draw-rate control.
- Adverse H1: within-stratum duration effect ~null / interaction CI spans 1 even where the MDE bound
  says a real conditional effect was detectable => depth alone suffices.
- Inconclusive: MAP coverage too sparse in a stratum, or transport/calibration unstable => cannot
  separate H1 from rival (a)/(c).
