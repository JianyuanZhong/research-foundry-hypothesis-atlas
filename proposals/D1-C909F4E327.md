# Working proposal — MIMIC-IV island, episode 25 (ADVERSARIAL negative-control-first sibling)

Crossover child of `[prior hypothesis]` (additive separable log-ratio

able to DISCONFIRM the relative-glycemia (H-relative) claim.

Status: **DESIGN STAGE. No cohort outcome rows were analysed in this discovery episode.**
Itemids, columns, keys and archive members were re-verified THIS episode directly against

## 0. Hypothesis vs conclusion (what is already supported, what is untested)

Supported (NOT re-tested here): SHR / relative glycemia is *associated* with short-term
mortality in selected ICU cohorts; HbA1c is *selectively* measured in MIMIC-IV [K2, K3].
This is a settled descriptive regularity.

Untested claim this experiment tries to FAIL: at the same absolute admission glucose
`G_adm` and the same severity, the *relative* (acute-on-chronic) glycemia component
`RG = log(G_adm) − log(Gc)` carries incremental 28-day-mortality information that is
(i) not attributable to `G_adm`, and (ii) not produced by same-stay HbA1c measurement
selection or HbA1c measurement invalidity. Read descriptively/predictively: this tests
incremental prognostic information and separability, not mechanism or causation.

## 1. Predeclared artifact signature (negative control FIRST)

If the apparent independent `RG` effect is a **measurement-selection / informative-
observation artifact** rather than signal, we predeclare its signature BEFORE fitting:

- **S1 (order/label permutation).** Permute HbA1c-derived `Gc` across subjects (keeping the
  observed instrumentation and the set of measured labs fixed) and refit M1→M2. Under a
  genuine value signal the increment must COLLAPSE to the equivalence margin. Under
  R-select, the increment is driven by *who got measured* (K2's "presence of a test order"),
  so a **negative-control EXPOSURE = measured-HbA1c indicator / chronic-anchor-availability
  indicator alone** (no value) should reproduce a *materially similar* M1→M2 increment to the
  value-carrying `RG`. Predeclared sign: **positive** (measured/anchor-available ⇒ higher
  observed risk through observation intensity).
- **S2 (magnitude equivalence).** Predeclared: if the artifact explanation is correct, the
  M1→M2 McFadden ΔR² from the *measurement-only* negative control lies within the
  equivalence band of the ΔR² from the *value* `RG` (both CIs inside ±band). If instead the
  value `RG` exceeds the measurement-only control by more than the margin, the artifact
  explanation is disfavored.
- **S3 (negative-control OUTCOME).** A prespecified outcome not plausibly caused by glycemia
  (bounded composite; see §4) must show no `RG` association; a non-null `RG`→NCO association
  is predeclared as evidence of residual confounding/selection.

## 2. Population, temporal boundaries, variables (frozen; identical to crossover)

- Adults ≥18; **first ICU stay per subject** = earliest `icustays.intime`.
- `t0` = `icu/icustays.intime`. Keys `subject_id`, `hadm_id`, `stay_id`.
- **G_adm**: first `hosp/labevents` glucose itemid **50931** (sensitivity 50809, 52027,
  52569) in `[t0−6h, t0+24h]`, from `valuenum`.
- **Same-stay HbA1c**: itemid **50852** (sensitivity **50854**) in `[t0−24h, t0+24h]` — used
  ONLY for the negative-control exposure/measurement-selection arm, NOT the primary exposure.
- **HbA1c-independent anchor (sensitivity arm)**: most recent glucose/HbA1c in an **earlier
  `hadm_id`** (by `subject_id`, `charttime < t0`, **365-day lookback**) or an outpatient
  `hosp/omr` value (`result_name` glucose/HbA1c-style) before `t0`.
- **Outcome**: 28-day all-cause mortality from `hosp/admissions.deathtime`; interval-censored
  at `deathtime`-null → `dischtime` (hospital-recorded mortality only).
- **Covariates**: age (`anchor_age`), gender, `admission_type`, sepsis flag, known-diabetes
  flag, baseline creatinine (52546/50912), anemia/transfusion flags, severity/SOFA-style
  score.
- **Split**: locked earliest-70% / latest-30% by `intime` (date-shift makes this an ordering
  proxy). No cross-dataset joins (MIMIC-IV only).

## 3. Primary estimand (M0→M1 incremental information, with equivalence margin)

- **M0** = `G_adm` + severity + age/sex (+ admission_type).
- **M1** = M0 + `RG` (separable log-ratio term).
- **Estimand**: ΔAUC(M0→M1) and ΔMcFadden-R²(M0→M1), each with bootstrap 95% CI, plus the
  adjusted `RG` coefficient. **Predeclared equivalence/non-inferiority margin: ΔAUC ≤ 0.005
  and the `RG` coefficient CI inside ±0.05 per unit** constitute a *declared null of no
  incremental information* — an INFORMATIVE NEGATIVE, not an inconclusive one.
- **M2** = M1 + HbA1c-measurement/care-intensity propensity (IPW or covariate). **M3** =
  negative-control exposure and negative-control outcome.
- **Decisive contrast**: the M1→M2 change is the R-select discriminator; the M1→M2Δ vs the
  M0→M1Δ is the object the crossover claims as "substantive unresolved".

## 4. Stratum-stability test (HbA1c validity + R-select)

`RG` effect estimated within prespecified strata: **anemia (Hb-range proxy), transfusion in
`[t0−24h,t0+24h]`, renal function (baseline creatinine CKD-style bands), and diabetes flag.**
Predeclared: if the signal is real, the stratum-specific `RG` effects are homogeneous
(overlap of CIs; no monotone drift with renal function). If it is an HbA1c-validity artifact
[K3], the effect **drifts with anemia/transfusion/renal stratum**. Negative-control OUTCOME:
a bounded composite not plausibly glycemia-caused (prespecified; itemids for the composite
require clinical adjudication — see §6).

## 5. Bounded power gate (numeric; honest INCONCLUSIVE)

Evaluate on the anchored analysis set, THEN branch:
- **PROCEED** if ≥300 anchored patients AND ≥60 deaths AND ≥40 patients in each primary
  stratum (anemia / transfusion / renal band).
- **INCONCLUSIVE (report as such)** if 120–299 patients or 20–59 deaths or any stratum <40 —
  no primary claim; report design and observed uncertainty only.
- **STOP/UNDERPOWERED** if <120 patients or <20 deaths — declare the question not resolvable
  in this snapshot.
The gate runs on measured cohort counts at compile time; the discovery episode does NOT
measure them.

## 6. Method exploration on the SAME question (B0 vs A1)

- **B0 (interpretable, CPU):** penalized (ridge/elastic-net) logistic on M0/M1 with adjusted
  ORs for `G_adm` and `RG`, bootstrap CIs for ΔAUC/ΔR², restricted cubic spline for shape.
  Fast, auditable, gives the calibrated equivalence-margin test.
- **A1 (substantive alternative, CPU):** a **joint latent measurement-selection + outcome
  model** — a two-equation selection (HbA1c-measured / anchor-available) latent-variable
  model coupled to the mortality outcome (EM or GBM-with-propensity-offset, calibrated
  uncertainty via bootstrap). **What A1 reveals that B0 cannot:** B0 conditions on selection
  by *adjustment* and assumes missingness is captured by observed covariates; A1 models the
  latent selection process explicitly, so it can separate "value `RG` predicts death" from
  "probability-of-measurement predicts death" — i.e. it attacks the R-select rival directly
  and yields a selection-corrected `RG` estimate B0 cannot identify. Resource budget: CPU,
  ≤1h, <8 GB (estimate; unverified).
- If A1 is not supportable, document the missing dependency (identifying instrument /
  clinical adjudication) rather than substituting a smaller model.

## 7. What each outcome means (supportive / adverse / inconclusive)

- **Supportive (H-relative):** M0→M1 CIs exclude the equivalence band with the expected sign;
  negative-control EXPOSURE far below the value increment; NCO null; strata homogeneous.
  → relative glycemia adds separable prognostic information.
- **Adverse (R-select / R-validity / R-absolute):** M0→M1 within the equivalence band
  (informative negative) OR the measurement-only negative control reproduces the increment
  OR the NCO is non-null OR the effect drifts across anemia/transfusion/renal strata
  (R-validity). → the "independent relative-glycemia" claim is **disfavored**; SHR should not
  be deployed as a stratification/enrichment marker on this evidence.
- **Inconclusive:** power-gate INCONCLUSIVE band, or a `RG` interval crossing the margin.
  → no scientific claim; report design and state the required evidence.

## 8. Honest limits and unavailable evidence

Hospital-recorded mortality only (no death-registry linkage); single-centre retrospective;
association/prognostic-information only; anchor population is itself selected (prior
admission/OMR availability); HbA1c invalidity *mitigated, not removed*, by the sensitivity
arm; the negative-control-outcome composite itemids require **clinical adjudication**;
`52027`/`52569` were rare/absent in the bounded head probe so whole-file frequency is
UNMEASURED; cohort size, HbA1c prevalence and event count are UNMEASURED (power gate
unresolved). Claims requiring causal identification, external validation or CGM/cystatin-C
ground truth need additional data or another study.
