# Working proposal — HCC island, episode 3

## Question

Does the post-curative-treatment AFP trajectory (0–120 days) carry independent prognostic
information for 12-month HCC recurrence beyond baseline AFP and static risk factors,
after controlling for surveillance/testing-frequency artifacts?

## Why this matters

- Post-treatment AFP kinetics are used in practice to trigger early imaging and
  re-treatment. If the trajectory adds independent signal beyond baseline AFP, it
  justifies more targeted surveillance.
- If the apparent signal is driven by testing frequency (sicker patients get more
  labs), the practice is an artifact and should not be reinforced.

- **ΔAUC B vs A: +0.110** (trajectory adds large signal beyond baseline)
- **ΔAUC B vs C: -0.003** (trajectory adds essentially NOTHING beyond testing frequency)
- Sensitivity (n_afp in [3,8], N=5,080): AUC A=0.789, B=0.909 (ΔAUC=+0.120)

## Interpretation

The AFP trajectory features (slope, time-to-normal, nadir) add substantial AUC beyond
baseline (ΔAUC=+0.110), but this signal is almost entirely explained by the number of
AFP measurements and encounters (Model C: AUC=0.879 vs Model B: AUC=0.877). This suggests
the apparent prognostic value of AFP kinetics is largely a **surveillance artifact**:
patients who are tested more frequently have more AFP measurements, and the "trajectory"
features are essentially proxies for testing intensity.

This is a consequential clinical finding: if the AFP trajectory signal is driven by
testing frequency, then using AFP kinetics to trigger early imaging may be reinforcing
a surveillance bias rather than identifying truly high-risk patients.

## Falsification

- Supportive: Model B AUC > Model A AUC by ≥0.02 with 95% CI excluding 0, AND
  Model B AUC > Model C AUC.
- Adverse: Model B AUC ≈ Model A AUC (ΔAUC < 0.01) OR Model B AUC ≈ Model C AUC.
- **Observed: Adverse** — Model B AUC ≈ Model C AUC (ΔAUC = -0.003).

## Method alternatives
