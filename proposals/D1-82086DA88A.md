# Post-treatment marker trajectories vs liver-reserve trajectories in HCC: a head-to-head prognostic test

Island: hcc (Chinese hospital hepatocellular-carcinoma records). Episode 2, fresh island (episode 0 died in runtime with no candidates).
Status: design + verified bindings; results are NOT computed here (discovery only).

## 1. Unresolved question and clinical importance

After liver-directed therapy (TACE, resection, ablation) for HCC, clinicians repeat routine serum
panels (AFP, albumin, bilirubin, transaminases) at every follow-up. It is unclear whether the
*within-patient trajectory* of these markers carries prognostic information that the
*pre-treatment baseline value* does not, and whether a tumour-burden marker (AFP) adds information
beyond a liver-reserve marker (ALBI = 0.66*log10(bilirubin[umol/L]) - 0.085*albumin[g/L]) measured in
the same draws.

Why it matters: surveillance panels and imaging intervals are the main levers a hepatology/IR clinic
controls after TACE. If AFP kinetics carry independent information, AFP-guided early re-imaging or
early treatment switching is justified. If only liver-reserve kinetics carry information, AFP-only
monitoring should be de-emphasised and reserve-based monitoring strengthened. Either direction is a
consequential, actionable result; a well-powered null (trajectory adds nothing beyond baseline and
surveillance intensity) is itself decision-relevant because it argues against trajectory-based
protocol triggers.

Leading claim (tested): post-treatment trajectory of at least one marker carries prognostic
information for progression/death **beyond** baseline value, treatment type, and surveillance
intensity; and AFP trajectory and ALBI trajectory are not redundant with each other.

Strongest rivals (each predicts a different pattern):
- R1 Baseline-severity artefact: trajectory is a proxy for baseline tumour burden / liver reserve.
  Prediction: trajectory effect attenuates to null once baseline AFP/ALBI and tumour-directed
  treatment count are in the model.
- R2 Surveillance-intensity / informative-observation artefact: sicker or more closely observed
  patients get more draws with more extreme values. Prediction: trajectory effect attenuates once
  number of draws and follow-up time are modelled, and strengthens in patients with a fixed
  minimum surveillance schedule (>=2 post-index measurements in a fixed window).
- R3 Treatment-effect (peri-procedural) artefact: post-TACE transaminitis/bilirubin rise is transient
  procedure effect, not tumour biology. Prediction: the ALBI signal concentrates in the first
  ~30 days after each procedure and disappears if the window starts >30 days after the last
  procedure.

The experiment separates these by requiring a joint model with all three adjustment families and
by a fixed-window sensitivity analysis (R2) and a window-shifted analysis (R3).

## 2. Evidence vs conjecture

Established by evidence (abstract-level, inspected): post-TACE ALBI trajectories separate into
improve/stable/decline groups with different OS/PFS and trajectories were an independent risk factor
for OS in 501 BCLC B/C patients [K1]. Longitudinal marker trajectories preceding HCC diagnosis
separate into distinct latent AFP classes [K2]. Joint modelling of a longitudinal marker with PFS is
feasible in TACE cohorts (Tregs, n=30) [K3].
Conjecture tested here: (i) AFP trajectory adds information beyond baseline and beyond ALBI
trajectory, and (ii) trajectory effects survive surveillance-intensity adjustment. Neither has been
shown by [K1]-[K3]: [K1] did not use AFP or adjust for draw intensity; [K3] is 30 patients and one
marker with no baseline-comparison design; [K2] is pre-diagnostic detection, not post-treatment
prognosis.

## 3. Design (frozen for compilation)

Population: patients with (a) >=1 row in `diagnoses` whose `诊断名称` contains 肝细胞癌|原发性肝癌|肝癌|
肝恶性肿瘤, and (b) >=1 row in `procedures` whose `手术` contains TACE|肝切除|消融|射频. Index date
= first such procedure `开始时间`. Adults only (`年龄` >= 18).
Temporal boundaries: index date 2010-07-27..2026-01-01 (observed encounter range). Baseline marker
value = last measurement 90 days before index date. Post-index window = index date .. index+180 d.
Follow-up for the outcome = index date .. last encounter `出院时间` (administrative censoring).
Exposure (per marker, per patient): (1) baseline value; (2) slope per 30 days from a linear
mixed-effects model on log-transformed values; (3) optional latent class / k-means trajectory group.
Outcome (primary): all-cause death documented in `clinical_documents` (出院情况 or 出院诊断 contains
死亡) after index date. Secondary: progression proxy = discharge text contains 复发|转移|进展, or a
subsequent liver-directed procedure strictly after index (repeat-encounter/procedure endpoint).
Baseline models to compare (same question, same data):
- M0 (simple baseline): age, sex, treatment type (first procedure class), baseline AFP, baseline ALBI.
- M1: M0 + AFP trajectory slope.
- M2: M0 + ALBI trajectory slope.
- M3 (head-to-head): M0 + both slopes.
- M4 (mechanistic/learned alternative): M1/M2 plus latent trajectory class (GBTM/k-means) and a
  spline in time to allow non-linear (R3) shape; compared with continuous-slope baseline.
All of M1-M4 additionally include number of marker draws and follow-up days (R2 adjustment).
Evaluation: hazard ratio per SD of slope with 95% CI; added discrimination (Delta C-index / Delta
time-dependent AUC) with bootstrap CI; calibration of predicted 180-day risk. Held-out split:
patient-level 70/30 train/test (no patient crosses splits).
Falsification criteria (pre-specified): the hypothesis is rejected if, after R2/R3 adjustment,
(a) the slope HR 95% CI includes 1.0 in M3 for both markers, and (b) Delta C-index of M3 vs M0 has
95% CI including 0 (equivalence margin 0.01). It is *confirmed* only if both slopes are non-null or
one is non-null with a Delta C-index lower bound > 0.
Interpretation: supportive = trajectory adds independent information -> justifies testing
trajectory-triggered surveillance in a prospective study. Adverse = null after adjustment ->
trajectory-based triggers unsupported; monitoring should rely on baseline risk and imaging.
Inconclusive = < ~300 patients with both pre- and post-index measurements for a marker, or < ~50
documented deaths -> widen window/outcome or treat as descriptive only.

## 5. Method comparison (recorded before selection)

Simple baseline M0 vs mixed-effects/joint alternative M3/M4: M0 is adequate if trajectories are only
baseline proxies; the mixed/joint alternative is required because it estimates within-patient change,
handles unequal numbers of draws and irregular spacing, and lets the survival sub-model use the
*current* value and slope — information M0 cannot express. Continuous slope (M1-M3) vs latent classes
(M4): classes are interpretable and match [K1]'s GBTM and [K2]'s LCA, but continuous slopes avoid
arbitrary class-number choices; comparing both, on the same question and data, distinguishes
"no trajectory information" from "non-linear/threshold trajectory information". Both are computable
from the frozen tables (no GPU strictly required; mixed/joint fits and bootstrap are CPU-feasible
within the solver envelope).

## 6. Limits, adjudication, missing evidence

- Death ascertainment is incomplete (out-of-hospital deaths, no national registry): primary outcome
  is a documented-death/progression composite with misclassification; a definitive mortality claim
  needs a registry link or clinical adjudication.
- Progression must be adjudicated by clinicians (imaging/response per mRECIST requires imaging
  reports/images; the archive has no image files and text extraction is unvalidated).
- Exact dates are withheld (relative intervals only); units for height/weight unverified; labs have
  no unit column, so cross-assay pooling is not supported (per metadata conventions).
- Single-institution Chinese cohort with practice-pattern confounding (TACE scheduling); external
  validation not available here.
- Whether AFP is routinely ordered in this hospital is an empirical question (checked in genA
  feasibility counts); if AFP coverage is sparse the AFP branch becomes descriptive only.
