# Generic documentation intensity does not fully explain the broader `Ventilated -` gain, but the endpoint-specificity result remains documentation-only

## Parent, goal, and substantive change

This is an executed child of assessed-valid `[prior hypothesis]`. It preserves the parent's frozen target-independent cohort, first qualifying stay selection, five landmarks, four airway bounds, post-freeze label classification, exact/broader/process models, hospital-held-out micro and equal-hospital estimands, stay clustering, and the original adverse result for the later non-peak structured respiratory-setting-reduction proxy. It adds prespecified, temporally aligned negative-control outcomes from `carePlanGeneral` that do not inspect `cplitemvalue` and exclude the `Ventilation` group for the primary controls.

The unresolved question is whether the parent's broader-versus-process improvement for later respiratory-chart persistence is respiratory-specific information or merely generic documentation intensity. This is clinically important because a signal that survives a generic documentation opportunity control is more informative about respiratory-workflow documentation, whereas a signal that disappears would indicate a site/stay documentation propensity artifact. Neither result validates bedside ventilation, an SBT, extubation, readiness, quality, benefit, harm, or causality.

## Evidence already supported versus claim tested

Before this child, the strongest supported claim was narrow: for the inherited later non-peak structured respiratory-setting-reduction proxy, outcome-blind expansion from two exact `carePlanGeneral` Ventilation strings to all four exported `ventilated -` strings added little coverage and did not consistently improve hospital-held-out prediction. A separate parent analysis found a partial endpoint reversal: broader indicators improved prediction of later respiratory-charting persistence over generic process controls, but generally did not stably beat the exact labels.

The new falsifiable claim is that this apparent respiratory-documentation gain should be attenuated or absent for temporally aligned non-respiratory care-plan documentation outcomes if it reflects respiratory-specific information. Conversely, persistence of a broader-minus-process gain on generic care-plan controls would support a generic documentation-intensity explanation. A negative control is not expected to be clinically desirable; it tests specificity of information, not benefit.

## Results

The existing respiratory-documentation positive control was reproduced exactly. For `doc_any` (at least one distinct respiratory-chart offset), broader-minus-process micro deltas were -0.01276, -0.02476, -0.02711, and -0.02720 for unbounded, 24-hour, 12-hour, and 6-hour bounds; equal-hospital macro deltas were -0.00791, -0.01146, -0.01206, and -0.01369. Fixed-prediction bootstrap 97.5th-percentile micro bounds were -0.00803, -0.01544, -0.01676, and -0.01696. For `doc_repeated` (at least two distinct respiratory offsets), the corresponding micro deltas were -0.02105, -0.03099, -0.03553, and -0.02565, with macro deltas -0.00859, -0.00824, -0.00789, and -0.00577; all fixed-prediction bootstrap upper bounds were below zero.

The strict `cp_nonvent_repeated_post` control was more directionally favorable to broader encoding, but still much smaller than the respiratory positive control: micro deltas were -0.00250, -0.00846, -0.01065, and -0.00848; macro deltas were -0.00357, -0.00779, -0.00851, and -0.00916. Thus the strict repeated non-Ventilation control supports a residual generic documentation component, while the magnitude and direction are not equivalent to the respiratory endpoint.

The all-group `cp_any_post` opportunity/intensity control was weakest and unstable: micro deltas were -0.00150, +0.00022, +0.00034, and +0.00642, while macro deltas were -0.00198, -0.00211, -0.00267, and -0.00085. Its micro bootstrap upper bounds were +0.00016, +0.00340, +0.00567, and +0.01501. This does not support a stable broad gain for generic chart presence.

Compared with exact labels, the broader-minus-exact contrasts for the negative controls were not a stable semantic rescue. For `cp_nonvent_any_post`, micro/macro deltas were -0.00042/-0.00036, +0.00150/-0.00015, +0.00277/-0.00061, and +0.00503/+0.00048 across the four bounds. These controls cannot establish that any string has a shared bedside meaning.

## Prespecified specificity gates and interpretation

A supportive specificity result would show a materially larger and consistently more precise broader-minus-process gain for respiratory documentation than for non-Ventilation care-plan outcomes, with attenuation toward zero for generic controls, across unbounded and at least two bounded airway definitions. That pattern is present in magnitude: respiratory positive-control micro gains are approximately 0.013-0.036 log-loss units, versus approximately 0.001-0.011 for the primary/strict generic controls, and the all-group control is near zero or adverse. However, the strict non-Ventilation repeated outcome still shows a consistent negative point estimate in all bounds, so generic documentation intensity is not eliminated as a component. The appropriate conclusion is partial specificity, not pure respiratory specificity.

An adverse specificity result would show comparable respiratory and generic gains, or disappearance of the respiratory gain after generic controls. That did not occur. An inconclusive result would arise if nested refitting, additional temporally matched opportunity controls, or external hospitals materially changed the contrast; the current fixed-prediction bootstrap is not a full uncertainty analysis.

The child therefore sharpens the parent's partial endpoint reversal: broader `Ventilated -` indicators carry reproducible incremental information for later respiratory-chart persistence beyond the inherited process features, and this gain is substantially larger than gains for generic non-Ventilation documentation. Nonetheless, a residual generic documentation propensity is detectable, especially with repeated non-Ventilation chart offsets. The two added broader strings still do not stably beat exact labels and do not repair the original adverse semantic-undercoverage result for the structured setting-reduction proxy.

## Falsification criteria and strict semantic limits

The specificity interpretation would be falsified by a replication in which generic non-Ventilation controls match the respiratory gain, the respiratory gain disappears after a generic opportunity/intensity adjustment, the sign reverses consistently in new hospitals, or nested refitting widens uncertainty enough that the claimed directional separation is no longer supported. It would also be falsified as a clinical interpretation by blinded adjudication showing that the exported documentation is unrelated to the claimed bedside state.

The experiment does not show actual ventilation, daily evaluation, SBT, extubation, readiness, liberation, quality, benefit, harm, or causality. A care-plan or respiratory-chart row is an exported documentation event. Absence of a row is not absence of care. Generic care-plan offsets measure exported documentation opportunity/intensity, not an unobserved interface footprint or clinician intent. Stronger conclusions require local interface/workflow metadata, direct time-resolved device/ventilator-mode/SBT/extubation data, blinded clinical adjudication, nested refitting, and external prospective validation.
