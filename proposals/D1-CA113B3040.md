# Episode 7 domain-generation note — laboratory-result versus vital-observation process

Status: independent scientific assessment for an evolution child of [prior hypothesis]. No cohort counts, fitted parameters, predictions, metric, or hypothesis result is claimed here. The expert seed [prior hypothesis] is context for the question only; this note does not treat its suggested wording as an operational instruction.

## Decision: this is the smallest clinically informative advance

The assessed-valid parent already asks whether a combined recording-process vector transports beyond a compact temporal patient-state model. The remaining ambiguity is not whether to add more model capacity or another modality. It is whether the combined increment is primarily a laboratory-result process signal, a vital-observation process signal, or generic observation density shared by both. Splitting the existing process block into two source-defined blocks answers that ambiguity while preserving the parent’s population, [0,360] minute feature window, ICU-discharge mortality outcome, hospital-held-out estimand, selection/EOL audits, and state-matched nulls.

This is smaller and more informative than adding a raw-event neural model: it changes only the scientific contrast, not the cohort or temporal representation. It also avoids attributing a laboratory signal to “monitoring” or a vital signal to physiology. A block-specific result can change the next action:

- laboratory-specific transport signal: investigate analyte/result harmonization and laboratory workflow;
- vital-specific signal: investigate observation/monitoring workflow and vital feed semantics;
- both signals disappearing after state matching: defer process features and prefer state-only transport;
- both remaining site-specific or boundary-dependent: abandon actionable process interpretation and require prospective measurement validation.

None of these data support a treatment recommendation or a causal claim about ordering, bedside monitoring, or mortality.

## Scientific opening, evidence, and unresolved claim

The closest inspected evidence supports only bounded premises. Rajkomar et al. [K1] show that sequential EHR representations can predict mortality across centers, but do not isolate observation process from patient state. Gao et al. [K2, abstract-only inspection] report that information-presence/missingness features can be predictive and that changing missingness can affect transportability, but the work is not an eICU laboratory-versus-vital decomposition and does not establish a mechanism. Hadler et al. [K3] show why external discrimination, calibration, and local data-pattern assessment should be considered together, but do not identify whether site effects arise from physiology, workflow, or documentation. These are reused from the parent’s receipt-hashed evidence package; no inaccessible full text is claimed.

The parent’s strongest supported premise is therefore: a hospital-held-out difference in a model that uses recorded process features could reflect patient-linked information, stable case mix, site workflow, measurement coverage, or selection. The unresolved claim for this child is narrower:

> Conditional on the same admission variables, laboratory values, and compact within-window vital state, does either the laboratory-result process block or the vital-observation process block provide a reproducible, hospital-transportable increment at the prespecified decision thresholds, and does that increment survive its domain-specific state-matched null and the parent’s selection/EOL audits?

This remains descriptive transportability. A surviving association is not evidence that a domain reflects inadequate monitoring, clinician intent, physiology, or a causal intervention effect.

## Rivals and predictions

1. **Patient state.** A domain’s process increment is a proxy for unrepresented acuity. Adding the compact vital trajectory and laboratory values should attenuate it; domain-specific state matching should remove most of the residual increment.

2. **Generic observation density.** Lab rows and vital rows are correlated manifestations of how intensely a stay is observed or documented. Lab-only and vital-only increments should be similar, highly correlated across hospitals, and add little when the other process block is already present. A domain-specific null should attenuate each block, but the data cannot prove which shared workflow created the density.

3. **Site workflow or feed behavior.** A domain increment should vary by held-out hospital, be concentrated in a small number of hospitals, survive state matching, or disappear under the domain-specific timing null. The hospital table may stratify/report this pattern, but hospital characteristics are not predictors.

4. **Discharge/EOL selection.** The six-hour risk set selects patients who remain observable and in the ICU. A process increment that is large for S6 but attenuates for S720, no-EOL, or measured-eligibility weighting is compatible with selection/documentation timing rather than transportable state information. carePlanEOL is an audit, not a clinical decision timestamp.

5. **Measurement/revision artifacts.** A lab result row can reflect revision or interface behavior rather than a new specimen/order; vital summaries are not raw waveforms. The primary process features retain the parent’s eligibility rules and report revision/duplicate audits. Excluding or de-duplicating revised lab records is a prespecified sensitivity only if the solver can define it from labid and revision offsets without using outcomes. No result-text parsing is permitted.

These comparisons separate plausible explanations only partially. There is no order status, specimen-collection time, interface-outage indicator, bedside-device provenance, clinician rationale, or death time. Even a clean domain result cannot establish mechanism.

Call this value/trajectory state vector T (with V and VS retained as parent controls).

Partition the parent process features without changing their definitions:

- L: for each selected analyte, finite-result row count, distinct-result-offset count, first and last valid labresultoffset, observed-bin count, and presence; report labid/revision audits. These are recorded-result proxies, not orders.
- Q: for each eligible vital table/field and overall vital channel, finite-row count, distinct-observation-offset count, first/last observationoffset, observed-bin count, and presence. Q is the vital-observation process block, not a measurement-quality label.

## Transparent baseline versus learned alternative

Both method families use the identical cohort, label, five hospital folds, internal reference, feature blocks, preprocessing isolation, seeds, null assignments, sensitivity cohorts, and cluster-bootstrap resamples.

- **Transparent baseline: domain-block elastic-net logistic regression.** Fit T-Logit, TL-Logit, TQ-Logit, and TB-Logit. Standardize continuous features and fit category encoding/imputation within the training partition. Use fixed parent regularization and no post hoc feature selection. Report coefficients, odds-ratio direction, block-level standardized contribution, calibration intercept/slope, Brier score, AUROC/AUPRC, alert burden and policy-scenario net benefit at 5/10/20%. This baseline shows whether a domain has a stable direction and whether the decision boundary moves without hiding the result in nonlinear interactions.
- **Learned alternative: capacity-matched histogram GBM.** Fit T-GBM, TL-GBM, TQ-GBM, and TB-GBM with the parent’s fixed hyperparameters, seeds, preprocessing and learner capacity. The learned model can reveal nonlinear thresholding and state-by-domain interactions—e.g., whether a lab-density signal appears only at particular vital instability levels—that the transparent additive baseline loses. Report held-out partial/block permutation importance only as descriptive diagnostics, not mechanism evidence.

The primary scientific comparison is domain block versus T, then whether the learned alternative changes the domain conclusion relative to the transparent baseline. A small predictive gain with unstable calibration, site concentration, or failure of null attenuation is not a clinically meaningful advance. No GPU is required: these are tabular CPU fits, and CPU choice is based on the workload rather than a prohibition on neural methods.

## Falsification and interpretation criteria

Support for a domain-specific, patient-linked transport signal requires all of the following:

1. Its held-out increment over T is directionally positive with a prespecified clinically negligible margin and uncertainty that excludes that margin, with paired calibration and policy-scenario net-benefit support at at least one threshold.
2. The domain increment attenuates under its state-matched null and is not explained solely by the combined block, one hospital, one fold, S6 selection, EOL documentation, or the +180-minute timing control.
3. The direction is materially coherent between the transparent and learned alternatives and broadly coherent in S720, no-EOL, and measured-IPW analyses.

Adverse evidence includes an upper interval below the negligible-benefit margin; no held-out calibration or net-benefit support; a domain effect that survives its state null while concentrating in one hospital (workflow/documentation); or a domain effect that disappears under S720/no-EOL/IPW (selection boundary). If T+L and T+Q both improve similarly but T+B adds little, generic observation density is more plausible than a uniquely actionable domain. If only one domain improves and its increment remains after conditioning on the other block, that is the strongest computational evidence for domain-specific transport, but still not evidence of a causal workflow or physiology. If the transparent baseline is null but GBM is positive, report nonlinear interaction evidence only if held-out calibration/utility and null controls agree; otherwise treat it as model-sensitive.

Inconclusive results include intervals spanning the prespecified margin, fewer than five viable hospitals, unstable propensity weights/effective sample size, sparse EOL strata, field-coverage collapse, block collinearity that makes conditional increments unstable, material fold/feature-selection instability, failed row-count or leakage audits, or inability to define revision-safe lab features from available columns. Do not treat an imprecise null as refutation.

The verifier can check rows, joins, offsets, fold isolation, block membership, model parity, null assignments, predictions, metrics, bootstrap intervals, and conclusion-to-output linkage. Clinical adjudication is required to decide whether a lab row represents an order, specimen, revised result, or interface artifact and whether a vital row represents bedside measurement, device aggregation, or missing feed. A prospective silent deployment with those timestamps, clinician review, actionable treatment definitions, and follow-up is required before claiming a changed clinical practice or validated decision threshold.

## Alternatives not chosen and revisit criteria

- **Raw-event neural/sequence encoder:** deferred because the immediate ambiguity is source-domain attribution, while eICU supplies summary observations and lacks specimen/order/interface semantics. Revisit only if a bounded readiness check shows fixed summaries erase domain-specific ordering that changes the prespecified held-out contrasts; keep identical target, folds, uncertainty, and nulls.
- **Hierarchical hospital random-effects model:** not primary because the estimand is hospital-held-out transport, and random effects can absorb site behavior rather than test transportability. Revisit as a descriptive heterogeneity analysis if at least five viable hospitals and enough within-hospital support remain.
- **Causal monitoring/testing intervention analysis:** unavailable: no intervention assignment, order/specimen timestamps, interface outage, death time, or clinician-adjudicated decision. Do not replace the transportability estimand with a causal one.
- **Adding nurse charting, treatment, respiratory, or note tables:** deferred because it would broaden the process channel and obscure the minimal lab-versus-vital contrast. Revisit only after this decomposition identifies a domain with reproducible residual transport signal and a new proposal defines why the added source distinguishes a specific rival.
- **A new cohort or changed time boundary:** not chosen. The domain result is only interpretable while preserving the parent’s S6, W0, Y, S720, EOL, hospital folds, and audits.

Continue to domain-specific workflow/harmonization review only if a domain has a coherent held-out increment, null attenuation, and selection robustness. Revise toward state-only transport if both blocks attenuate after T/state-null controls. Defer or abandon process interpretation when evidence is inconclusive, site-specific, or inseparable from revision/interface/EOL selection.
