## Question (unchanged from parent)
Does the transcript response to the JAK inhibitor A77 (tofacitinib) in synovial macrophage cocultures depend on the presence of fibroblast-like synoviocytes (FLS), as measured by the difference in drug response between macrophage+T cell (MT) and macrophage+T cell+FLS (MTF) contexts? Specifically, do JAK/STAT pathway genes show attenuated drug response in the presence of fibroblasts, and is the context-dependent gene set reproducible in an independent synovial dataset?

### Key results
1. **Genome-wide context effect is real and robust**: All 3 donors show highly significant positive mean attenuation with the Triple vehicle (P1: mean=0.028, p=6.7e-45; P2: mean=0.211, p=5.9e-290; P3: mean=0.038, p=3.1e-43). 5,539 genes at FDR<0.1. The MTF context does produce a different transcript response than MT for A77.
2. **JAK/STAT pathway signal is control-dependent**: With the Triple vehicle, JAK1 (per-donor 0.52/0.38/0.49), TYK2 (0.24/0.32/0.36), STAT3 (-0.12/-0.12/-0.19), STAT5A (0.10/0.12/0.08) all reach FDR<0.1 with consistent direction across all 3 donors. With the unstimulated control (ep12), none do. The Triple vehicle is itself a transcriptional perturbation (it contains a JAK inhibitor component in the original assay), so the choice of baseline materially changes the pathway-specific conclusion.
3. **Top context-dependent genes are NOT JAK/STAT**: FRMD7, SEPHS1, NCLN, DNASE1L2, CEP78, APOBEC3D, PLXNA3, TIGD4, ALAS1, DDX54 (all FDR<0.002, direction-consistent across 3 donors). These are not JAK/STAT pathway genes.
4. **Cross-dataset validation is unpowered**: E-MTAB-8873's 445-gene symbol panel contains only 2 of the top-50 GSE95588 context-dependent genes (KLRK1, NCR3). The parent's E-MTAB-8316 validation had 0 overlap (ENSEMBL-labeled features, no symbol mapping). Neither dataset can currently replicate the top-gene list.

## Clinical importance
JAK inhibitors (tofacitinib, baricitinib, upadacitinib) are approved for RA but ~40% of patients respond inadequately. Wei & Xu 2026 [K3] report that JAK inhibitors act directly on synovial fibroblasts (lowering IL-6 output and trans-signaling responsiveness) and that non-responders to targeted therapy are enriched for a stromal/fibroblast signature. Kuo et al. 2019 [K1] showed in the same ex vivo system that medications can redirect HBEGF+ inflammatory macrophages into non-resolving states. Hu et al. 2026 [K2] frame the translational direction as precision modulation of discrete, context-dependent signaling modules. A fibroblast-context-dependent JAK/STAT transcript response would nominate the JAK1/TYK2/STAT3/STAT5A module as a context-dependent target and provide a mechanistic candidate for inadequate JAK inhibitor response. The current INCONCLUSIVE result means this specific claim is NOT established: it holds under one control and fails under the other, and cannot yet be replicated in an independent dataset.

## Analysis (executed, [research job])
1. Load GSE95588_d1d2d3d4 counts (23,710 genes x 70 samples); CPM normalization per sample.
2. Per gene, per donor: drug effect in each context = log2(CPM_drug/CPM_vehicle); context-dependent attenuation = effect_MTF - effect_MT.
3. Genome-wide: one-sample t-test of attenuation vs 0 per donor (scipy t-distribution).
4. Per gene: t-test of attenuation across 3 donors; BH FDR across 23,710 genes.
5. Pre-specified JAK/STAT core panel (12 genes): report per-donor attenuation, t, p, FDR.
6. E-MTAB-8873: intersect top-50 context-dependent genes with the 445-gene panel; for overlaps, compute paired Mpos vs Mneg log2FC (4 pairs).
7. Classification per pre-specified criteria (supportive: >=5 JAK/STAT FDR<0.1; adverse: 0 JAK/STAT FDR<0.1 with genome-wide effect real; inconclusive: otherwise).

## Falsification criteria (pre-specified, unchanged from parent)
- **Supportive**: >=5 JAK/STAT core genes FDR<0.1 with consistent direction across >=2 donors, AND >=5 of top-50 context-dependent genes replicate direction in E-MTAB-8873.
- **Adverse**: 0 JAK/STAT core genes FDR<0.1 under both vehicle controls, OR no directional replication of top-50 genes in E-MTAB-8873.
- **Inconclusive**: 1-4 JAK/STAT core genes FDR<0.1, OR <2 donors with consistent direction, OR validation overlap <3 genes. (Current result: 4 genes, 3-donor consistent, 2-gene overlap -> INCONCLUSIVE.)

## What each outcome would mean
- **Supportive**: the JAK/STAT module is a context-dependent target of JAK inhibitors in the synovium; fibroblast presence reshapes the macrophage JAK inhibitor response; nominate JAK1/TYK2/STAT3/STAT5A for combination-therapy design. Would still require single-cell validation to rule out bulk composition confound.
- **Adverse**: JAK inhibitor transcript response is context-independent at the pathway level; the ~40% inadequate-response problem is not explained by fibroblast-context modulation of macrophage JAK/STAT signaling; redirect to other mechanisms (epigenetic fibroblast imprint, resolution failure per [K3]).
- **Inconclusive (current)**: the pathway-specific claim is control-dependent and unreplicated; the genome-wide context effect is real but does not nominate a specific target. Next test: unstimulated-vehicle sensitivity (done here), fourth donor, single-cell RNA-seq.

## Limitations (honest)
1. **Bulk RNA-seq composition confound**: MT vs MTF samples differ in total cell number; the genome-wide context effect could partly reflect composition. Single-cell or FACS-sorted data required to resolve.
2. **Control dependence**: the 4-gene JAK/STAT result holds with the Triple vehicle but not the unstimulated control. The Triple vehicle contains a JAK inhibitor component in the original assay, so the "drug effect" estimated against it is a relative effect.
3. **n=3 donors**: per-gene power is limited; the 4 JAK/STAT genes may be false positives under donor-level multiple testing.
4. **Validation unpowered**: 2/50 top-gene overlap with E-MTAB-8873; 0 overlap with E-MTAB-8316 (ENSEMBL-labeled). No independent replication of the top-gene list is currently possible.
5. **Donor IDs unresolved** in the prepared design (donor_status=unresolved); P1-P3 labels are column-derived, not GSM-verified.
6. **A77 identity**: GSM metadata confirms A77 = Tofa = tofacitinib, but concentration is not recorded in the prepared design.
