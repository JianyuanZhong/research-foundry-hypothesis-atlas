# Certified Direction-A kidney-function experiment with an executable outcome-state verifier

## Lineage and substantive repair

This is a targeted, substantive successor of assessed-valid `[prior hypothesis]`, with parent `[prior hypothesis]`. It preserves the clinically bounded question, selected repeat-attender estimand, UKB snapshot, source files, field-instance bindings, equations conditional on certified units, repeated nested cross-fitting, fixed-capacity protocol-ranking contrast, and aggregate-only privacy boundary. It does not reinterpret the parent's reported anchors as evidence and does not claim that the experiment has been run.

The remaining execution blocker is not the scientific question but the boundary between a well-specified stop and a well-specified result. The parent requires several inherited “gates” without an output contract that says exactly which machine checks are run, how their failures are ordered, or how an independent verifier distinguishes a certification stop, a valid adverse result, and an inconclusive computation. It also allows a certificate to be described as valid without a canonical schema that prevents omitted field-level entries, duplicate entries, unbound evidence, or an unacknowledged age/date mismatch. This child repairs that blocker by adding:

1. a canonical, closed-world certificate and run-manifest contract bound to exact source and schema hashes;
2. a formal state-transition and result-status precedence table;
3. explicit numeric gate definitions, including support, fit, fold isolation, calibration, split-sign, and bootstrap checks;
4. an aggregate result artifact whose fields are sufficient for an independent verifier to recompute every claim without receiving participant rows; and
5. a claim-to-status matrix that makes supportive, adverse, inconclusive, and `NEUTRAL_STOP` outcomes mutually exclusive and computable.

This is a design repair, not a cosmetic rewrite. It leaves unresolved the essential need for a steward-supplied certificate: the current workspace does not contain certified assay units, missing-value meanings, or field-53 assessment-date semantics, so a run on the current files must stop before named biomarker/eGFR outputs.

## Question, evidence boundary, and clinical importance

The strongest claim supported by the existing parent evidence is narrow: within a selected complete-biomarker group that returned for a qualifying repeat assessment, a baseline cystatin-C threshold state was associated with a later repeat creatinine-derived threshold state after fixed adjustment. That observation does not establish valid assay interpretation, CKD, chronicity, measured GFR, progression, a four-year risk, a causal testing strategy, or patient benefit.

The unresolved and falsifiable claim is:

> After the exact UKB fields, units, missing-value rules, assay/instance comparability, and assessment-date semantics are independently certified, does baseline cystatin-C threshold discordance add reproducible out-of-sample information beyond a flexible baseline creatinine-derived eGFR, age, sex, and observed-repeat-interval comparator for the repeat creatinine-derived threshold state among participants with a qualifying complete repeat observation?

This matters because confirming an abnormal kidney-function signal is clinically consequential, but the available export can only test incremental information in an observed repeat-attender protocol. If supportive, it would justify a subsequent study of baseline-deployable repeat-assessment prioritization. It would not justify ordering cystatin C, intensifying surveillance, referral, treatment, or any claim of patient benefit. The substantive advance over the parent is an executable certification-to-verdict contract that prevents an apparently positive model result from being produced under uncertified field meanings, and prevents a technical or statistical failure from being mislabeled as evidence against the biomarker.

## State machine and fail-closed behavior

The runner writes a state log with exactly one terminal state. States are ordered:

1. `SOURCE_SCHEMA_PASS`: all file, schema, header, key, overlap, and join checks pass.
2. `SEMANTIC_CERT_PASS`: the closed-world certificate parses, has exactly the nine required bindings, matches snapshot/source/schema hashes, and all field-level semantic and evidence requirements pass.
3. `ASSAY_EQUATION_PASS`: certified units, analyte identity, conversion direction, assay comparability, and exact equation version pass. Apply only the certificate's stated conversion; never assume multiplication/division by 88.4.
4. `TEMPORAL_CERT_PASS`: both field-53 values are certified relevant assessment dates, with an accepted parse rule and no impossible date ordering after parsing.
5. `COHORT_RECONSTRUCTION_PASS`: all deterministic masks, counts, and support checks are reproduced from the joined data and the run manifest.
6. `ANALYSIS_PASS`: all fits, cross-fitting, inference, and verifier inputs pass.
7. terminal result state: `SUPPORTIVE`, `ADVERSE`, `INCONCLUSIVE`, or `NEUTRAL_STOP`.

Any failure in states 1–4 is a `NEUTRAL_STOP`; no eGFR, named exposure/outcome, event cells, predictions, Brier values, ranks, p-values, or biological interpretation may be emitted. The only permitted output is an aggregate stop object containing state, reason code, source/schema hashes, source row and join counts, certificate hash if present, and mask counts only up to the failed state. A missing certificate has reason code `NEUTRAL_STOP_NO_CERTIFICATE`. A cohort reconstruction or analysis failure is not a biomarker finding: if it occurs after certified reconstruction, it is `INCONCLUSIVE` unless a valid completed analysis satisfies the adverse criteria below. State transitions are append-only and signed/hashed in the run manifest; the verifier rejects a terminal result whose predecessor states are absent or out of order.

## Certified population, time, estimand, and equations

After states 1–4 pass, reconstruct the selected protocol cohort. Let `B` require the one-to-one three-table intersection, certified sex code 0/1, finite positive certified `21003-0.0`, finite parseable `53-0.0`, and finite positive baseline creatinine and cystatin C after only certificate-authorized missing handling. Let `R` require finite positive `21003-1.0`, finite repeat creatinine and cystatin C, and finite parseable `53-1.0`. Define `t=(date_1-date_0)/365.25` and require inclusive `2 <= t <= 8`. Apply `R` jointly within `B`; do not define repeat eligibility among participants excluded from baseline eligibility.

For certified creatinine, apply the certificate's conversion only when it says conversion is required. With sex 0 female and 1 male, use the certified equation version and, for the inherited 2021 CKD-EPI creatinine equation, coefficients `(kappa, alpha, female_factor)=(0.7,-0.241,1.012)` for female and `(0.9,-0.302,1)` for male:

`eGFRcr = 142 * min(Scr/kappa,1)^alpha * max(Scr/kappa,1)^(-1.200) * 0.9938^age * female_factor`.

For cystatin C use:

`eGFRcys = 133 * min(Scys/0.8,1)^(-0.499) * max(Scys/0.8,1)^(-1.328) * 0.996^age * female_factor`,

where the female factor is `0.932` and the male factor is `1`. The certificate must affirm that the exported analytes and units are compatible with these equations; a different equation version is a stop, not an analyst choice.

Define `T_A = B ∩ {eGFRcr_0 >= 60}`, `S_A = T_A ∩ R`, `E = 1{eGFRcys_0 < 60}`, `Y = 1{eGFRcr_1 < 60}`. `S_A` is an observed complete-biomarker repeat-attender protocol cohort, not a baseline population. `Y` is an observed repeat creatinine-derived threshold state, not adjudicated CKD, chronicity, progression, or measured GFR. The primary estimand is the conditional predictive contrast in `S_A`, with `t` observed and included in the comparator. It is not fixed-horizon baseline risk because repeat timing and attendance are selected.

## Prespecified models and inference

`M0` is ridge logistic regression using baseline `eGFRcr_0`, baseline age `21003-0.0`, sex, and observed repeat interval `t`. Use training-only restricted cubic splines: five eGFR knots at quantiles `(0.05,0.275,0.50,0.725,0.95)` and four age/time knots at `(0.05,0.35,0.65,0.95)`, all eGFR-by-time and sex-by-eGFR products, training-only centering/scaling, unpenalized intercept, and lambda grid `10^(-4),10^(-3.5),...,10^4`. Choose lambda independently by nested five-fold training-only log-loss one-standard-error rule. `M1` adds only `E` and `E*(eGFRcr_0-60)/10`; no repeat biomarker enters either model.

Run ten repeated outer five-fold cross-fits with outer seeds `[260911,260912,260913,260914,260915,260916,260917,260918,260919,260920]`, stratifying only by `E x Y`. Inner seeds are `outer_seed + 1000 + outer_fold`. Every test `eid` must have zero overlap with all training/tuning rows used to obtain that prediction. Average the ten out-of-fold probabilities per participant. Clip only log loss inputs to `[10^-6,1-10^-6]`; record clipping counts. Primary contrast is `Delta_Brier = 1000*[mean((Y-p0)^2)-mean((Y-p1)^2)]`.

For `K=ceil(0.10*N)`, rank by each participant's averaged out-of-fold probability; break exact ties by `SHA-256("direction-A-capacity-v1|"+eid)`. Define `Delta_rank10 = 1000*(events in top-K M1 - events in top-K M0)/K`. This is a schedule-marginal, capacity-constrained protocol-ranking contrast among observed complete repeat attenders. It is not additional events caused by ordering cystatin C, net benefit, a treatment rule, or a recommendation.

Use a fixed sequential hierarchy: test `Delta_Brier` first; test `Delta_rank10` only if the Brier gate passes. Use paired participant bootstrap over the frozen ten-column prediction matrices, 2,000 successful replicates with seed `260921` and at most 2,500 attempts, percentile 95% intervals, and plus-one symmetric null-centered p-values. The bootstrap must resample participant rows, preserve all ten prediction columns, and never refit models or alter folds.

## Explicit numeric gates and aggregate verifier inputs

The following constants are immutable run-manifest values inherited from the parent; they are not post hoc choices or compiler repairs.

* Fold cell support: in every outer training partition, outer test partition, and inner training partition, all four `E x Y` cells must be nonempty. A fold allocation or fit with an empty cell is a hard analysis failure.
* Outer test support: every outer test fold must contain at least 50 total outcomes and at least 8 participants with `E=1,Y=1`.
* Fit validity: every declared fit must converge, produce finite coefficients and finite probabilities, and use only the declared ridge penalty. Fewer than 1% of predictions may be clipped for log-loss evaluation. Any failed fit, non-finite transform, or excessive clipping fails the analysis gate.
* Calibration: retain both inherited calibration checks for each model on the frozen out-of-fold predictions: observed/expected ratio in `[0.90,1.10]` and recalibration slope in `[0.80,1.20]`, with finite estimates. Calibration failure is not silently converted into evidence against the biomarker.
* Comparator signal: `M0`'s out-of-fold Brier score must be better than the intercept-only prevalence predictor, and all comparator metrics must be finite. This is a prespecified validity gate, not an AUC or clinical-value claim.
* Repeat-specific stability: compute the ten outer-repeat participant-level contrasts before averaging; at least 8 of 10 repeat-specific Brier contrasts must be positive, and at least 8 of 10 rank contrasts must be positive if the fixed sequence reaches the rank stage.
* Bootstrap: obtain at least 2,000 successful finite paired participant-level replicates within 2,500 attempts, using the declared seed and no duplicated seed stream.
* Privacy and provenance: no output artifact may contain `eid`, row-level predictions, fold membership, or certificate evidence contents. The aggregate result must include hashes of the source manifest, schema files, certificate, run manifest, and protected prediction matrix; missing or mismatched identity is a hard provenance failure.

The verifier recomputes from declared aggregate files and, where needed, the protected prediction matrix: state sequence, mask counts, `N`, all `E x Y` cell counts, outer-fold support, all ten repeat-specific contrasts, means, confidence intervals, p-values, clipping counts, `K`, rank event counts, calibration slopes/intercepts and observed/expected ratios, comparator-vs-intercept status, fit/support booleans, and bootstrap success/attempt counts. It compares floating-point values to a declared tolerance of `1e-10` relative plus `1e-12` absolute and rejects missing or extra metric keys. It need not receive participant rows when the protected prediction matrix is available to the verifier, and that matrix must never be published.

## Terminal status decision table

Status is assigned in this order.

**`NEUTRAL_STOP`** is mandatory if source/schema identity, certificate presence/structure/hash, assay/equation certification, or temporal certification fails. It is also mandatory if a purported result emits named biomarker quantities before the relevant gate. The reason code is one of the closed set `NEUTRAL_STOP_SOURCE_HASH`, `NEUTRAL_STOP_SCHEMA`, `NEUTRAL_STOP_JOIN`, `NEUTRAL_STOP_NO_CERTIFICATE`, `NEUTRAL_STOP_FIELD_CERTIFICATE_INVALID`, `NEUTRAL_STOP_ASSAY_OR_EQUATION`, or `NEUTRAL_STOP_TEMPORAL_CERTIFICATE`.

**`INCONCLUSIVE`** is mandatory after all semantic gates pass when cohort support, fold support, convergence, finite arithmetic, calibration, repeat-specific stability, bootstrap completion, or output reproducibility fails, or when a primary confidence interval includes zero. This means the experiment did not resolve the predictive question; it is not equivalence and is not a biomarker-null conclusion.

**`ADVERSE`** is assigned only after a complete, certified, reproducible analysis passes technical support and provenance checks but the added cystatin-C model is demonstrably worse. Specifically, the primary Brier contrast must have a finite two-sided 95% interval wholly below zero and p<0.05. If and only if the Brier stage passes positively, the fixed sequence advances to rank; a rank contrast wholly below zero and p<0.05 can then be adverse only if the Brier contrast is non-positive, a condition that is unreachable after a positive Brier gate and therefore cannot be used to override the fixed sequence. A calibration or support failure alone is not adverse; it is inconclusive because it prevents a clean comparison. An adverse result weakens the claim that baseline cystatin-C threshold discordance adds reproducible information under this comparator and protocol.

**`SUPPORTIVE`** requires every certification and reconstruction state to pass, all technical/support/calibration gates to pass, at least 8 of 10 positive repeat-specific Brier contrasts, at least 2,000 successful bootstrap replicates, a positive Brier contrast with two-sided 95% interval excluding zero and p<0.05, and, only after that first stage, a positive rank contrast with its interval excluding zero and p<0.05 plus at least 8 of 10 positive rank repeats. This is deliberately stringent. The conclusion is limited to reproducible incremental predictive information and fixed-capacity protocol ranking in `S_A`.

A valid but non-significant contrast is `INCONCLUSIVE`, not “neutral” and not evidence of no effect. A missing certificate is `NEUTRAL_STOP`, not `INCONCLUSIVE`. The verifier checks that exactly one terminal status is present and that the submitted prose claim is a member of the allowed claim code for that status; a supportive numerical artifact paired with a causal or clinical-utility sentence is rejected as an unsupported conclusion.

## Falsification and interpretation limits

The primary falsification is the frozen, preregistered comparison itself: held-out predictions, repeat-specific signs, calibration, comparator validity, and the fixed-capacity ranking contrast must all be reproduced under the declared splits and bootstrap. No post hoc label permutation is introduced, because permuting `E` within an `E x Y` stratum leaves `E` unchanged and is therefore a no-op. Any meaningful negative-control or label-permutation study would require a separately specified design and is outside this targeted repair.

Supportive means only that, in the certified selected complete-biomarker repeat-attender protocol, adding the baseline cystatin-C threshold indicator and its prespecified interaction improved cross-fitted prediction and concentrated observed repeat threshold events at the fixed ranking capacity. It does not show that cystatin-C measures true GFR better, that threshold crossing is CKD or progression, that testing changes attendance or treatment, or that patients benefit. Adverse means the added feature worsened the prespecified predictive contrast in a valid run. Inconclusive means uncertainty or technical gates prevented resolution. Neutral stop means interpretation of required source fields could not be certified.

Unidentified quantities requiring another study include baseline risk at a fixed horizon, outcomes among nonattenders, counterfactual testing/order actions, assay costs and harms, referral or treatment consequences, net benefit, number needed to test, measured GFR, chronicity, adjudicated CKD, causal effects, and transportability. Assay validity and specimen provenance require steward documentation and expert review. A clinical action claim requires a baseline-deployable horizon, follow-up for attenders and nonattenders, an explicit action policy, consequences/utilities, and external or prospective validation.
