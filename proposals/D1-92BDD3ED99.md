# Hypotension Duration and Acute Kidney Injury in eICU

## Parent

## Question and Clinical Importance

In ICU patients with shock, the **duration** of hypotension (time with MAP < 65 mmHg) is a candidate resuscitation endpoint that may predict organ injury more informatively than the **nadir** (minimum) MAP alone. Current practice often summarizes hypotension by a single nadir value, losing information about how long the patient was hypotensive. If duration carries independent prognostic signal for AKI, it would:

1. Support using time-weighted hypotension burden as a resuscitation endpoint in trials.
2. Identify patients at higher risk of AKI who may benefit from more aggressive perfusion support.
3. Explain why some patients with similar nadir MAP have different outcomes.

**Unresolved claim:** After adjusting for nadir MAP and baseline severity, does hypotension duration in a 24h window independently predict 7-day AKI?

**Strongest rival explanation:** Duration is a proxy for illness severity or vasopressor use; once these are accounted for, duration adds no independent signal.

**Closest prior work:**
- [K1] (Matos et al., 2024) describes eICU-CRD as a large multi-center ICU database with vital signs, labs, and medications, but does not test the hypotension-duration → AKI question.
- [K2] (Jakobsen et al., 2026) reviews AKI definitions in sepsis research, highlighting inconsistent application of creatinine-based criteria; it does not test hypotension duration as an exposure.
- [K3] (Liu et al., 2026) shows cumulative MAP < 65 duration is associated with postoperative ICU admission, supporting duration as a clinically relevant exposure, but in a perioperative (not ICU) setting and with a different outcome.

**Join key:** `patientunitstayid` (all tables). Hospital-level: `hospitalid`.

**Inclusion criteria:**
- ≥24h of MAP data (span of systemicmean observations ≥ 1440 min)
- ≥2 creatinine values (labname containing "creatinine")
- unitdischargeoffset ≥ 1440 (still in ICU at 24h, to avoid censoring)

**Exclusion criteria:**
- unitdischargestatus = "Expired" before 24h (censoring)
- <2 creatinine values (cannot define AKI)

## Index Window and Outcome

**Index window:** First 24h of MAP data. Start = first systemicmean observation offset; end = start + 1440 min.

**AKI outcome (KDIGO creatinine criteria) [K2]:** Within 7 days (10080 min) of index window start:
- Stage 1: ≥0.3 mg/dL increase from baseline, OR ≥1.5× baseline
- Stage 2: ≥2.0× baseline
- Stage 3: ≥3.0× baseline, OR ≥4.0 mg/dL, OR RRT

**Baseline creatinine:** First creatinine in the 24h before index window start. If none, first creatinine in the index window.

**Outcome window:** Index window start to index window start + 10080 min (7 days).

## Exposure Definition

**Hypotension duration:** Minutes with MAP < 65 mmHg in the 24h index window. Computed by linear interpolation between consecutive MAP observations: for each interval [t_i, t_{i+1}], if both MAP < 65, add full interval; if one < 65 and one ≥ 65, add half interval.

**Nadir MAP:** Minimum systemicmean in the 24h index window.

## Method Comparison

**Baseline model (M1):** Logistic regression:
- Outcome: AKI (yes/no)
- Predictors: nadir MAP, age, gender, apacheadmissiondx category, hospital (random effect)

**Alternative model (M2):** Logistic regression:
- Outcome: AKI (yes/no)
- Predictors: nadir MAP, **hypotension duration**, age, gender, apacheadmissiondx category, vasopressor exposure (any vasopressor in index window), hospital (random effect)

**Within-hospital check:** Fit M1 and M2 within hospitals with ≥50 eligible patients. Report consistency of duration effect across hospitals.

**What M2 reveals that M1 loses:** Duration captures the *extent* of hypoperfusion, not just the worst moment. If duration adds signal after nadir adjustment, it suggests cumulative ischemic injury rather than a single nadir event. If it does not, nadir is sufficient.

## Falsification Criteria

- **Supportive:** Duration remains significant (p < 0.05) in M2 after nadir adjustment, OR > 1 per 60 min of hypotension; consistent direction in ≥50% of hospitals.
- **Adverse:** Duration is not significant in M2 (p ≥ 0.10), OR ≈ 1 (95% CI crosses 1.0); no hospital-level signal.
- **Inconclusive:** <50 AKI events in the highest duration quartile; or vasopressor confounding cannot be resolved (e.g., <10% of patients on vasopressors).

## Limitations and Alternatives

1. **MAP charting density varies:** Linear interpolation may misestimate duration if charting is sparse. Mitigation: sensitivity analysis with ≥1 MAP/hour requirement.
2. **Vasopressor timing confounds:** Patients given vasopressors may have different hypotension patterns. Mitigation: include vasopressor exposure as covariate; sensitivity analysis excluding vasopressor patients.
3. **AKI definition is creatinine-only:** Urine output data in `intakeOutput.csv.gz` could refine but adds complexity. Deferred to future work.
4. **eICU is multi-center:** Hospital-level random effects account for center variation, but transportability to other ICUs unknown.
5. **Observational design:** Association, not causation. Duration may be a marker of unmeasured severity.
