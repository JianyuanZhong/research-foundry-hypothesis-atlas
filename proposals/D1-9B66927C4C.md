## 0. Relationship to the parent and to this episode's designated child
The parent tests whether the decay-clean within-patient AFP slope `M_decay` (OLS slope of log10(AFP) over
draws `>=30 d` after every LDT `开始时间`) predicts progression in the imaging-negative landmark stratum
IMGneg, and reads attenuation vs the all-draw slope `M0` as evidence for the release rival `R_decay`.
The parent explicitly deferred a joint model and named the revisit condition: **"if `M_decay` is
*inconclusive* but `M0` is positive, fit the joint model to model the pulse explicitly rather than dropping
draws."** This branch develops that deferred alternative so the baseline-vs-alternative comparison is
concrete and pre-specified. It does not replace the Lead's designated `M0_res` evolution child: it is the
competing mechanistic candidate on the same question, isolating a different confound (release vs. patient
selection).

## 1. Unresolved question, evidence, and substantive advance
**Observed / supported by evidence (not in question here):**
- Post-treatment HCC relapse is biologically residual-disease-linked, so a rising tumour-burden marker is a
  plausible relapse signal [K1].
- A *transient* AFP rise ("flare") after liver-directed therapy is real and can occur **without** progression
  [K2]; hepatectomy/ablation also perturbs circulating analytes via injury/regeneration.
- A dynamic biomarker should be linked to the hazard through a joint longitudinal–survival model, not a
  plug-in concurrent value [K3].

**Unresolved claim (the experiment tests this):** whether, *within the same patients and using every draw*,
the post-LDT AFP trajectory contains a **tumour-burden slope** that predicts progression **after** an
explicit procedure-timed release component is estimated.

**Why the parent cannot answer it.** `M_decay` removes the release window by **filtering draws**. Filtering
simultaneously (a) removes periprocedural draws and (b) shrinks/changes the eligible **patient set** (only
patients with procedures spaced enough to keep `>=2` decay-clean draws), and it (c) *still* cannot represent a
transient release that extends past 30 d. A `M0`-vs-`M_decay` gap is therefore **not yet attributable** to
tumour biology.

**Strongest live rival — `R_pulse` (this candidate's target):** the post-LDT AFP slope–outcome association is
**procedure-timed release** whose shape is fully separable by joint modelling; once the pulse is estimated
the residual tumour-burden slope does not predict progression.

**Advance over the parent's estimator:** the joint model estimates a per-patient release **amplitude** `A_i`
and decay rate `τ` **inside** the same likelihood as the tumour slope `b_i` and the hazard, so
tumour-burden slope and procedure-induced release are separated **within the same patients** (no population
selection), and `A_i` becomes a directly testable rival predictor. The parent's filter cannot do either.

## 2. What must be newly FITTED (state the scientific deliverable)
Fit a **shared-parameter joint model** of the log10(AFP) trajectory and the progression hazard on the IMGneg
landmark cohort. Unknown parameters to estimate (all newly fitted; none computed here):
- **Longitudinal submodel** for log10(AFP) over `(index, t*]`:
  `log10 AFP_ij = μ + u_i + b_i·(t_ij − t0) + Σ_j A_i·exp(−max(0, t_ij − s_ij)/τ) + ε_ij`,
  where `u_i` = random intercept, `b_i` = **tumour-burden slope** (random), `A_i` = **periprocedural release
  amplitude** (random, per procedure-event), `τ` = decay time-constant (population or per-patient), `s_ij` =
  LDT `开始时间` for the most recent procedure at draw `t_ij`, `ε_ij` = measurement error.
- **Survival submodel** (progression hazard on `[t*, censor]`):
  `λ_i(t) = λ0(t)·exp(β_b·b_i + β_A·A_i + γ'X_i)`.
- **Association parameters of interest:** `β_b` (tumour-slope HR) and `β_A` (release-amplitude HR); `λ0` via
  a flexible baseline (B-spline/Weibull), estimated by maximising the joint observed-data log-likelihood
  (Laplace/AGQ for the random effects).
**Completion outputs:** point estimate + 95% CI of HR per 1-SD of `b_i` (the parent's key contrast) and of
`A_i`; the decay time constant `τ̂`; convergence/identifiability diagnostics; and exactly one branch call.

## 3. Fit split / data used
- **Population (identical to the parent, no filtering):** HCC-diagnosed patients (`诊断名称`) with `>=1`

- **Draws:** **ALL** AFP draws with `检验时间` in `(index, t*]` — deliberately NOT decay-clean, so the same

- **No train/test split** in this cohort-scale design; uncertainty from patient-level bootstrap (Section 5).

  bias, per [K3]/the parent's guarantee-time discipline.
- Baseline comparators, refit by the solver on the SAME snapshot and population: **`M0`** (parent all-draw
  OLS-slope Cox) and **`M_decay`** (parent decay-clean slope Cox).

## 6. Baseline vs alternative, selection/deferral reasoning, resource budget
- **Baseline (simple):** parent `M0` OLS-slope landmark Cox, refit on the same IMGneg population. It loses the
  release signal entirely (a straight-line slope cannot represent a pulse) and cannot separate release from
  burden.
- **Alternative (substantive learned/mechanistic):** shared-parameter joint model with an explicit
  periprocedural exponential-release term. It reveals what the baseline/`M_decay` lose: a within-patient
  decomposition of the AFP trajectory into a **tumour slope** and a **procedure-timed release amplitude**, and
  a per-patient `A_i` testable as a rival progression predictor.
- **Selection/deferral reason:** choose the joint model when the pulse window is populated and the
  decay-clean filter would exclude many IMGneg patients (population selection); **defer** it (report
  Inconclusive, do not redefine) if the pulse component is non-identifiable (Section 7). Simpler `M0`/`M_decay`
  remain the primary parent estimators; this is the competing mechanistic candidate on the same question, not a
  silent replacement.
- **Resource/time budget (CPU; GPU not required):** low-dimensional random effects (intercept, slope,
  amplitude) on a few-hundred-patient IMGneg sample with minutes-scale OLS/Cox fits elsewhere; a joint
  fit + 500 bootstraps is CPU-bound and fits `4` CPUs / `8 GB`. **GPU is not justified**: the design matrix is
  small and the cost is repeated gradient/Laplace evaluations, not tensor throughput. Estimate ~10–60 min per
  fit family; ~1–3 h wall for the bootstrap envelope — to be confirmed by the solver. (Discovery budget is
  separate; no fits run here.)

## 7. Pre-committed branches (on the joint model vs `M0`/`M_decay`, IMGneg; conjunctive; numeric)
- **Supportive:** HR(β_b) > 1 with 95% CI excluding 1, **>=20** IMGneg progression events, attenuation vs the
  all-draw `M0` HR **<40 %**, and a convergent pulse fit (`τ̂` CI finite) while the release-amplitude term
  HR(β_A) is not the dominant term. => a tumour-burden slope survives pulse estimation in the same patients;
  the parent's mechanistic read is supported (in this cohort, lexical endpoint only).
- **Adverse = `R_pulse`:** HR(β_b) CI includes 1 (or sign reversal) **AND** HR(β_A) > 1 with 95% CI excluding 1
  and `τ̂` identifiable, with >=20 events. => the post-LDT slope association is procedure-timed release, not
  tumour burden; the parent's central read is **retracted** for this cohort.
- **Inconclusive:** <20 IMGneg events, **or** `τ` non-identifiable (profile CI for `τ` spans more than a 2×
  range, or the joint model fails to converge), **or** <40 % of IMGneg patients have any draw inside a
  periprocedural window near a procedure. => no decision; report attainability, do NOT read as null.
- **Precise-null:** both HR(β_b) and HR(β_A) within ±0.10 of 1 with tight CIs and a flat ALBI-slope control.
  => no AFP-slope incremental value; reassign monitoring weight to imaging/other markers.
Every branch call must be reported with the also-computed `M0` and `M_decay` HRs.

## 8. Falsification, scope, and required adjudication (honest)
- The design **can overturn** the parent (Adverse arm): the joint model is fitted on the same estimator family
  over the same patients/draws but with the pulse explicitly modelled.
- A **Supportive** result establishes only that the slope survives explicit pulse estimation in **this
  single-centre lexical endpoint**; it does **not** establish causation, mRECIST PFS or clinical benefit.
- **Inconclusive is not evidence against** the claim, and an imprecise null does not refute it.
- **Required clinical adjudication / missing evidence:** progression is a **lexical** endpoint
  (`检查所见`/`检查诊断` descriptors) requiring radiologist **mRECIST adjudication** for any clinical-truth
  claim; no mortality/PFS; no lab units; `IMGmissing` is large (~96 %) so the primary fits only the small
  IMGneg stratum. Collector-timing of `检验时间` (which draw sits in which pulse window) is a **solver
  feasibility input**, not assumed here. Claims that are computationally checkable: HRs, CIs, LRT, convergence.
  Claims requiring adjudication/another study: mRECIST progression truth, transportability beyond this centre.
