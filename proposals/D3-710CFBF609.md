# Temporal Feedback Structure of Macrophage-FLS Inflammatory Signaling in RA Synovial Tissue

## Scientific Opening

In rheumatoid arthritis (RA), synovial tissue exhibits a self-reinforcing inflammatory loop between macrophages and fibroblast-like synoviocytes (FLS) [K1]. The crosstalk is well documented: FLS secrete IL-34, CCL2, and CXCL12 that recruit and polarize macrophages toward the M1 phenotype, while M1 macrophage-derived TNF-α, IL-6, and IL-1β further activate FLS [K1]. However, the **temporal ordering** of this feedback is unresolved. Three non-equivalent explanations are compatible with the current evidence:

1. **Unidirectional macrophage-driven model**: Macrophage activation precedes and drives the FLS inflammatory response. FLS are passive recipients of macrophage-derived signals.
2. **Bidirectional feedback loop**: Macrophage and FLS activation are mutually reinforcing with no clear temporal precedence. Both cell types can initiate the loop.
3. **Composition-driven model**: The apparent "feedback" is an artifact of changes in cell composition (e.g., increased macrophage infiltration) rather than a genuine dynamic interaction between cell types.

This distinction is clinically consequential: if the loop is bidirectional, anti-inflammatory strategies must target both cell types simultaneously; if unidirectional, targeting the initiating cell type may suffice.

## Hypothesis

**Hypothesis**: In RA synovial tissue, macrophage activation state (Mpos vs Mneg) has a significant positive interaction effect on FLS inflammatory gene expression (IL6, TNF, IL1B), with the interaction coefficient β_3 > 0 in a donor-aware mixed model. This supports a bidirectional feedback loop rather than a unidirectional macrophage-driven model.

## Concrete Estimand

The primary estimand is the **interaction coefficient β_3** in the donor-aware mixed model:

```
y_ijk = β_0 + β_1*Mpos_i + β_2*FLS_gene_j + β_3*(Mpos_i × FLS_gene_j) + u_k + ε_ijk
```

Where:
- `y_ijk` = expression of FLS inflammatory gene j in cell i from donor k
- `Mpos_i` = macrophage activation state (1 = Mpos, 0 = Mneg)
- `FLS_gene_j` = FLS inflammatory gene expression (IL6, TNF, IL1B)
- `u_k ~ N(0, σ²_donor)` = donor random effect
- `ε_ijk ~ N(0, σ²)` = residual error

β_3 quantifies the change in FLS inflammatory gene expression per unit change in macrophage activation state, conditional on donor. A positive β_3 indicates that macrophage activation amplifies FLS inflammatory signaling, supporting bidirectional feedback.

## Competing Explanations

### 1. Unidirectional Macrophage-Driven Model
- **Mechanism**: Macrophage-derived TNF-α, IL-6, and IL-1β activate FLS through NF-κB and JAK-STAT pathways. FLS are passive recipients.
- **Observable prediction**: β_3 > 0, but the effect is driven by macrophage-to-FLS signaling only. No reciprocal FLS-to-macrophage effect.
- **Clinical implication**: Targeting macrophage signaling (e.g., anti-TNF, anti-IL-6) should be sufficient to break the loop.
- **Discriminating observation**: If β_3 > 0 but no FLS-to-macrophage interaction is observed, this model is favored.

### 2. Bidirectional Feedback Loop
- **Mechanism**: Macrophage and FLS activation are mutually reinforcing. Macrophage-derived cytokines activate FLS, and FLS-derived IL-34, CCL2, CXCL12 recruit and polarize macrophages.
- **Observable prediction**: β_3 > 0 AND reciprocal FLS-to-macrophage interaction > 0.
- **Clinical implication**: Dual-targeting strategies (e.g., anti-TNF + FLS reprogramming) are needed to break the loop.
- **Discriminating observation**: If both macrophage-to-FLS and FLS-to-macrophage interactions are positive, this model is favored.

### 3. Composition-Driven Model
- **Mechanism**: The apparent "feedback" is an artifact of changes in cell composition (e.g., increased macrophage infiltration in RA synovium) rather than a genuine dynamic interaction.
- **Observable prediction**: β_3 ≈ 0 after adjusting for cell composition. The apparent interaction is explained by differential cell abundance.
- **Clinical implication**: Targeting cell infiltration (e.g., anti-CCR2) should be sufficient.
- **Discriminating observation**: If β_3 becomes non-significant after composition adjustment, this model is favored.

### 4. Donor-Specific Model
- **Mechanism**: The macrophage-FLS interaction is driven by a single donor with an unusually high baseline inflammatory state.
- **Observable prediction**: β_3 > 0 but driven by a single donor. Removing that donor makes β_3 non-significant.
- **Clinical implication**: The result is not generalizable. Donor-specific factors (e.g., genetic background, disease severity) drive the interaction.
- **Discriminating observation**: If β_3 becomes non-significant after removing the top contributor, this model is favored.

## Falsifiable Test

**Test**: Fit the donor-aware mixed model on E-MTAB-8873 and GSE95588 data.

**Supportive result**: β_3 > 0 with p < 0.05 after donor adjustment, and the effect is consistent across donors. This supports the bidirectional feedback hypothesis.

**Adverse result**: β_3 ≈ 0 or β_3 < 0 with p < 0.05. This refutes the bidirectional feedback hypothesis and favors the unidirectional or composition-driven model.

**Inconclusive result**: β_3 > 0 but p > 0.05, or β_3 > 0 but driven by a single donor. This is inconclusive and requires additional data or a different analysis.

## Method Alternatives

1. **Donor-aware mixed model** (selected): Interpretable, donor-adjusted, compatible with cross-sectional data.
2. **XGBoost with donor-aware cross-validation**: Could capture non-linear interactions but less interpretable and harder to establish causal direction.
3. **ODE-based dynamical systems model**: Could model temporal feedback explicitly but requires time-series data not available in the cross-sectional datasets.
4. **Simple linear regression without donor random effects**: Would ignore donor-specific baseline states and inflate Type I error.
