## Unresolved question and clinical importance
Plasma-proteomic screens nominate single circulating proteins (GDF15, FABP1, CHI3L1, IL-6/CRP family)
as preclinical, disease-specific biomarkers. The parent tested whether a protein signature's
disease association is disease-specific (claim A) or a shared systemic morbidity/inflammation axis
(claim B) using a held-out cross-disease *transfer gap* Delta_D = AUC(D) - mean_AUC(D'), with
age/sex residualization and a within-age-decile x sex matched null. That test conflates two very
different sources of "shared" signal:
- **B1 - a shared systemic-morbidity axis**: the proteins track cumulative organ dysregulation, so
  they separate *any* diseased person from a healthy one and raise AUC for many diagnoses [K2].
- **B2 - co-occurrence / case-mix confounding**: cases of D often also carry D' (disease co-occurrence
  is pervasive and non-random [K3]), so a signature trained on D can separate D' cases because those
  D' cases are simply *sicker and more multimorbid*, not because any protein axis is
  disease-preferential.
The parent already ruled out the rival that age/sex is a common cause (via residualization). The
**strongest remaining rival is disease co-occurrence/severity**: a large Delta_D can survive sample
splitting, age/sex residualization and even a matched permutation null that preserves age/sex
structure, yet still be produced by differential multimorbidity burden between the D and D' groups
rather than by a disease-preferential proteomic process. Resolving this decides whether a circulating
protein or composite axis is a credible disease-specific early-detection/target candidate or merely a
generic sickness/multimorbidity reporter - the same consequential decision the branch is building
toward.

## Leading claim vs rival, and the observation on which they differ
- **Leading claim (A, disease-preferential):** part of the protein signal is specific to D's biology,
  so a D-trained signature should still separate D-cases from D'-cases *after* conditioning on being
  diseased and on multimorbidity burden.
- **Rival (B2, co-occurrence/severity):** the signal is a shared healthy-vs-diseased / severity axis;
  once both groups consist of sick people matched on comorbidity count, the D-vs-D' discrimination
  collapses toward chance.
These make **different predictions about the same held-out comparison**: A predicts a positive
case-case AUC gap; B2 predicts it is ~0 while the healthy-vs-diseased gap remains positive. The
parent's raw gap cannot distinguish them because its contrast includes healthy controls; the
case-case restriction removes that shared contrast.

## This child's scientific delta: a diseased-only (case-case) specificity estimand
Retain the parent's participant split and re-derive:
1. **Primary (new, decisive): case-case transfer gap.** For each target disease D and its
   pre-specified unrelated-chapter set D', restrict evaluation to held-out individuals who have
   >=1 of {D} U D' (the "diseased-only" set), train the D signature on discovery-half D vs
   discovery-half healthy, then compute AUC_casecase(D vs D') = discrimination of D-cases from
   D'-cases within the diseased-only held-out set. Define
   Delta_D^casecase = AUC_casecase(D vs D') - (co-occurrence-matched permutation null).
   - Claim A: Delta_D^casecase > 0 and excludes the matched-null band for >=1 pre-specified target D
     after age/sex residualization.
   - Claim B2: Delta_D^raw > 0 but Delta_D^casecase ~ null (specificity was shared multimorbidity).
2. **Co-occurrence-matched permutation null (new).** Permute the D/D' label *within joint
   age-decile x sex x comorbidity-count strata* of the diseased-only set, so the null preserves both
   demographic structure and multimorbidity burden; a genuine disease-preferential signal must beat
   this null. Comorbidity count = number of distinct ICD-10 3-character blocks (>=200 cases) present
   in that individual; the strata grid and any pooling of sparse cells are pre-specified.
3. **Secondary estimands on the same split (parent, recomputed):** Delta_D^raw (parent's raw transfer
   gap) and Delta_D^resid (parent's age/sex-residualized gap), so the change from raw -> resid ->
   casecase is a single, comparable decomposition per disease.
4. **Baseline vs learned alternative on the same estimand.**
   - Baseline: a single 1-D **shared-axis score** (leave-one-protein-out or the parent's data-driven
     axis) - a generic healthy-vs-diseased/severity score.
   - Learned alternative: an **elastic-net multi-protein signature** fit per disease inside the
     discovery half, evaluated on the identical case-case estimand.
   Rationale for the alternative: a single linear axis by construction can only carry one direction
   of shared signal and cannot represent distributed, non-linear, disease-enriched multi-protein
   structure. If the elastic-net signature shows case-case discrimination where the 1-D axis does
   not, the surviving signal is a *distributed disease-enriched* pattern rather than one generic
   severity axis; if the elastic-net also collapses to the null, the disease-preferential claim is
   not supported. This is a substantive scientific comparison (what structure the shared signal has),
   not a small-performance chase.
5. **Positive- and negative-control blocks.** Two pre-specified diseases expected to share
   inflammatory/metabolic biology act as a "should-transfer" positive control; the unrelated-chapter
   set D' and the external-cause block V01-Y98 act as "should-not-transfer" negative controls.

## Decision rules and falsification
- **Supportive of claim A:** Delta_D^casecase > 0 and excludes the co-occurrence-matched null band
  for >=1 pre-specified target D after age/sex residualization; ideally survives the elastic-net
  alternative.
- **Adverse for claim A / supportive of B2:** Delta_D^raw > 0 but Delta_D^casecase ~ null - the
  apparent specificity was shared multimorbidity/severity. (An informative negative finding.)
- **Inconclusive:** too few co-diagnosed cases (diseased-only sets below the pre-specified minimum
  n), sparse comorbidity strata forcing heavy pooling, or wide null bands / sign instability across
  code-list and age-spline sensitivity analyses.
The mechanism-relevant prediction is **refuted** if the co-occurrence-matched null (which preserves
age/sex and comorbidity structure) reproduces the raw D-vs-D' gap.

## What each outcome would and would not establish
- Supportive case-case gap => the D-vs-D' discrimination is not explained by age/sex or by
  differential comorbidity burden; it is a disease-preferential *association*. It still does **not**
  establish causation, direction, or mechanism (prevalent cross-sectional data).
- Adverse (raw positive, case-case null) => the protein signal behaves as a generic
  sick/multimorbid-patient axis; strong evidence against a disease-specific biomarker reading for
  the tested diseases, but a null in the tested set does not prove no disease-specific signal exists
  anywhere.
- A null elastic-net result is *not* proof the shared signal is a single axis; it bounds the
  distributed-signature hypothesis under this panel/sample size only.

## Computationally checkable vs needing adjudication/other studies
- **Computationally checkable:** the n_eid intersection, the case-case and matched-null estimands,
  AUCs, band widths, elastic-net-vs-axis comparison, and control-block direction.
- **Requires clinical adjudication / missing evidence:** the ICD-10 block code list and the
  unrelated-chapter D' assignment need expert review; inpatient `s_41270` ascertainment is incomplete
  and asymmetric across diseases, so apparent co-occurrence can be ascertainment-driven; comorbidity
