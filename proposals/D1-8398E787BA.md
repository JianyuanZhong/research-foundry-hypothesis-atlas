# Preregistration and compatible-set repair (binding amendment to the inherited protocol)

**Status and precedence.** This is a complete child protocol based on `[prior hypothesis]`. The inherited scientific schema, first-eligible all-opportunity denominator, reciprocal pre-departure chronology, canonical discharge artifact, unit-specific clocks, split/route-blinded panels, all-unit adverse routing, positive-probability two-phase audit, exact finite-population inference, and prospective-silent-only conclusion ceiling are unchanged. The rules below are frozen additions and, where they are more specific, take precedence over any less-specific inherited wording. They must be hashed, signed by governance, and sealed before the first real label, before challenge selection is revealed to reviewers, and before any outcome or route summary is opened.

## What changed and why

The parent correctly warns that agreement is not a gold standard, but its compatible-set language could be implemented differently by different analysts, and its governance margins and review workload were not all numerical before labels. This child makes the operational estimand, label categories, thresholds, selection algorithm, error-compatible sets, and finite workload ledger executable. It does **not** turn H1/H2/H3 into truth labels. Correlated shared error remains a limitation; the primary result is a conservative interval for an observable audit state and for adverse-compatible routing, not a prevalence of clinical error.

## Frozen governance dictionary and categories

The protocol hash fixes the following ordered categories and no synonyms are permitted in analysis.

* Atomic evidence status: `SUPPORT`, `CONTRADICT`, `INDETERMINATE`, `NOT_PRESENT`, `UNREADABLE`, `NONRESPONSE`.
* Unit status: `U_RESOLVED`, `U_OPEN`, `U_TIMING`, `U_CLOSED`, `U_DEFER`, `U_BOUNDARY`.
* Departure state: `F`, `C_O`, `C_I`, `R`, `A`, `U_D`; availability: `V_D`, `V_24`, `V_72`, `V_168`, `V_late`, `V_U`; lag: `H_stale`, `H_0_6`, `H_6_24`, `H_24_72`, `H_72plus`, `H_U`; eventual text state: `F_text`, `C_O_text`, `C_I_text`, `R_text`, `U_text`.
* Admission route, in precedence order, is exactly `AUTO`, `RECON`, `TIMING`, `DEFER`; `NOACTION` is retained as a descriptive non-route state and `MIXED` is nested in `RECON`.
* A panel's route-defining assertion is a tuple `(unit_id,target_cluster,action_modality,due_interval,polarity,recipient,responsibility,replacement,conflict)`. Each field is either the applicable coded value, `ABSENT`, or `UNKNOWN`; no free-text vote is an analysis category.
* The panel-level whole-admission result is `ROUTE_{AUTO,RECON,TIMING,DEFER,NOACTION}` or `UNKNOWN`. Confidence is not used to override a category. A missing field, nonresponse, unreadable packet, or unresolved reciprocal link is `UNKNOWN` and remains adverse-compatible.
* Control outcomes are `INVARIANT_PASS`, `INVARIANT_FLIP`, `DECISIVE_EXPECTED`, `DECISIVE_UNEXPECTED`, or `CONTROL_INFEASIBLE`.

The locked route table is a finite table, not a human consensus: apply the inherited unit cross-product and precedence to all admissible lane combinations. Any `UNKNOWN`, `U_BOUNDARY`, unresolved timing, conflict, or nonresponse maps to the adverse route set specified below; it can never be silently imputed or favorable-matched. Categories are frozen before labels and are never merged, renamed, or collapsed after seeing frequencies.

Governance thresholds, frozen before labels, are: simultaneous family coverage `1-alpha=0.95`; `tau_AUTO=0.05`; `tau_leak=0.02`; `tau_D_MIX=0.10`; lower confirmation `rho=0.90`; lower `AC1=0.70`; lower `Se_RECON=0.95`; lower `PPV_RECON=0.80`; lower `Se_DEFER=0.95`; lower `PPV_TIMING=0.95`; invariant-control flip upper bound `0.02`; decisive-control violation upper bound `0.05`; missing/unknown/control-infeasible upper bound `0.05`; minimum sampled route-positive count 30; minimum non-sentinel challenge count 10; minimum route-denominator ESS 50; minimum atom population `max(30, ceil(0.02*N_A))`; normalized maximum design weight `0.10`; overall design ESS 150; minimum `N_A=200`; minimum `E_A=60`; and all inherited burden/event/precision gates. These are operational nomination criteria, not clinical harm tolerances. Any missing governance signature is `NO_SELECTION`.

## Deterministic selection and finite workload ledger

First compute the inherited `N_A`, five strata, final pre-label support atlas, exact atom `g=(E,terminal_service,W)`, and residual cells. Then execute the following pseudocode with no label input.

```text
for each noncensus cell c=(h,g or RESIDUAL_h):
    reserve k_c=min(2,N_c) admissions by hash-rank(protocol_hash||c||admission_key)
solve the declared integer allocation for the unchanged n_h:
    k_c <= n_c <= N_c; sum_c n_c=n_h
    maximize lexicographically (minimum n_c/N_c over certifiable g,
                                minimum n_c over certifiable g,
                                negative projected max normalized weight)
    then minimize sum_c |n_c - n_h*N_c/N_h|;
    break ties by lexicographic (h,E,service,W)
if any occupied certifiable cell cannot receive k_c, move it to RESIDUAL
and rerun once; never move cells after labels.
draw each cell's n_c records without replacement by the same hash-rank.
for each selected admission i: pi_i=n_c/N_c (or 1 in census); w_i=1/pi_i.
challenge candidates are selected before labels by hash-rank(protocol_hash||"challenge"||i)
subject to q=1/3, |C|<=300, and inclusion of the first two hash-ranked
records in every occupied final-atlas atom whenever those records exist.
if those reservations require |C|>300 or exceed the sampled frame, set NO_SELECTION.
```

The actual integer solver must be a deterministic exhaustive branch-and-bound or an exact integer-program solver with pinned version; it writes objective, constraints, solver version, unique optimum/tie-break, cell counts, ordered IDs, `pi_i`, and `pi_ij` before labels. If more than one allocation survives all tie-breaks, the run is invalid rather than analyst-selected. The challenge fraction is exactly `q=1/3` rounded down after the per-atom reservations; no outcome-, route-, disagreement-, or workload-based enrichment is allowed. Challenge inclusion is conditional on the already drawn sample and is recorded; challenge estimates use inherited design weights and are never presented as an all-sample estimate.

The hard admission budget is **900 distinct admissions total**, inclusive of sentinel census, formula samples, and challenge cases. Repeated units, duplicate readings, controls, and H1/H2/H3 packets do not count as admissions. The hard physician-time ledger, fixed before labels, is:

| required activity per selected admission | maximum hours |
|---|---:|
| eligibility and retrieval-negative review | 0.30 |
| index recommendation lane(s) and context lane(s) | 0.45 |
| independent audit lane(s) | 0.50 |
| redaction/access QA and minority-unit safety audit | 0.45 |
| **inherited base total** | **2.00** |
| H1 holistic challenge, if challenged | 0.50 |
| H2 independently coded holistic challenge, if challenged | 0.50 |
| H3 assertion-support challenge, if challenged | 0.35 |
| locked controls and packet integrity check, if challenged | 0.15 |
| **challenge increment** | **1.50** |

A fixed 120-hour setup/closeout allowance covers codebook writing, hashing, training on synthetic fixtures only, packet generation QA, seal verification, and prespecified statistical computation; it cannot be used for extra real admissions. Thus the maximum is `120 + 2.00*900 + 1.50*300 = 5,070 physician-hours`, under the frozen **5,100-hour absolute budget**. The protocol records actual minutes, but exceeding any per-activity maximum, the 900-admission ceiling, the 300-challenge ceiling, or 5,100 hours invalidates selection. Every selected admission receives the base ledger; every challenged admission receives every challenge activity, regardless of apparent route.

For each final atlas atom, the workload gate is simultaneously `upper physician-hours per 100 atom admissions <=400`, `upper median packet time <=45 minutes`, and `upper nonresponse/control-infeasibility <=0.05`; the atom also has to satisfy the inherited route-specific workload gate. The 400-hour limit includes the design-weighted base and challenge work, so a workload failure cannot be hidden by a pooled average. If an atom's challenge reservation is impossible, it is unsupported/inconclusive and cannot enter the allow-list.

## Executable compatible-set partial identification

### Target and notation

For admission `i`, let `O_i` contain the sealed outputs from the two parent lanes and H1/H2/H3, including all atomic fields, route outputs, missingness, packet integrity, and safety-auditor findings. Let `r_i^P` be the inherited locked parent route and let `r_i^H` be the route computed from the H1/H2/H3 cross-product. Define the binary operational adverse event `A_i(r)=1` when a route `r` is not defensible under at least one admissible reading, including `RECON`, `TIMING`, `DEFER`, `UNKNOWN`, or a minority-unit conflict; it is **not** a claim of clinical harm.

The latent clinical truth of an assertion is deliberately not introduced. Instead, the protocol reports the identified set for the observable audit quantity under explicit compatible assignments. This prevents an analyst from silently treating a panel as a gold standard.

### Frozen compatible-set construction

Construct `Omega_i` by the following deterministic function, with all list ordering fixed lexicographically.

1. Parse each panel into its complete finite atomic tuple. Reject malformed tuples to `UNKNOWN`; preserve missing fields.
2. Enumerate all cross-products of the two index lanes, two audit lanes, the minority-unit auditor, and H1/H2/H3. Deduplicate only reciprocal restatements sharing the same locked unit identity; never deduplicate distinct units.
3. Apply the locked unit matcher. A match is admissible only when target cluster, action/modality, due interval, polarity, and recipient/responsibility are equal; otherwise include both `MATCH` and `NONMATCH` whenever either side has an `UNKNOWN` field. No favorable match is permitted.
4. For every resulting cross-product `z`, compute the route with the locked precedence. Let `b_i(z)` be the binary adverse indicator (`1` for `RECON`, `TIMING`, `DEFER`, `UNKNOWN`, or any safety-auditor unresolved minority unit; `0` only for a fully resolved `AUTO`/`NOACTION` cross-product).
5. Add `z` to `Omega_i` if and only if it satisfies the following fixed compatibility rules: (a) all observed nonmissing fields are retained exactly; (b) every `CONTRADICT` assertion can be reconciled only by assigning that panel's assertion an error flag; (c) error flags may be shared by any subset of panels, including all panels, so correlated error is not ruled out; (d) no field may be changed, deleted, or imputed; and (e) the route table and unit precedence must hold. The error flag is a bookkeeping possibility, not an estimated probability.
6. If any panel is missing/nonresponsive, if the packet is corrupted, or if a reciprocal/time/unit boundary is unresolved, retain only the adverse-compatible route states for certification and set the missingness component to 1. If all three holistic panels say `SUPPORT` on every route-defining field, retain the favorable observed state for the lower endpoint **and** retain an adverse state for the upper endpoint because shared error is allowed. Thus unanimous agreement is never interpreted as proof of truth.
7. For each estimand `q_i` (confirmation, disagreement, `C_AUTO`, `D_MIX`, leakage, capture, workload), store the finite set of all binary/finite-valued contributions induced by `Omega_i`, not just its midpoint. The admissible contribution interval is `[min_{z in Omega_i} q_i(z), max_{z in Omega_i} q_i(z)]`; for a route ratio, numerator and denominator contributions are stored jointly.

Because shared error is unconstrained without an external reference, `Omega_i` may be wide, including both favorable and adverse assignments after unanimous agreement. That width is the intended result, not a computational failure. The implementation must report `|Omega_i|`, the exact reason for every member, and the fraction of records whose upper/lower endpoints differ.

### Sharp bounds and uncertainty

For each finite-population cell and each bootstrap replicate, optimize over the Cartesian product `Omega=product_i Omega_i` subject only to the frozen per-admission constraints above. For totals, minimize and maximize the sum of contributions. For a ratio `T_y/T_d`, solve two linear-fractional programs (Dinkelbach algorithm with rational arithmetic or exhaustive enumeration when the state space is small), retaining numerator and denominator totals; zero denominator yields no ratio. For nested route/event quantities, jointly optimize all numerator and denominator states so incompatible assignments cannot be combined. The resulting interval is the sharp bound under the declared compatibility rules. Use the widest of sharp compatible bounds, exact stratified finite-population inversion, and the common 20,000 Rao-Wu max-statistic family. All noncensus cells retain their design weights; census cells are fixed.

The primary `C_AUTO` upper endpoint is therefore the maximum weighted ratio in which each index-`AUTO` admission may take any adverse-compatible state. The lower endpoint is the minimum analogous ratio. If H1/H2/H3 all agree but the shared-error allowance leaves an adverse state compatible, the upper endpoint remains adverse; if that makes the gate fail, no `AUTO` certification is allowed. The same algorithm is applied to `D_MIX`, `leak_AUTO`, confirmation, capture, workload, and every route-specific atom. There is no latent-class point estimate, consensus override, or model-based narrowing. A separately acquired blinded reference subset can add constraints only if its ascertainment, codebook, roster, and timing were sealed before use; it is not a gold standard and cannot retrospectively relax a failed bound.

### Exact interpretation of the partial-identification result

A narrow interval means that the **declared observable audit functional** is constrained by the recorded panel outputs and design, not that correlated expert error is absent. A wide interval is inconclusive and blocks certification. If an unconstrained shared-error allowance makes every upper endpoint 1, that is an honest non-identification result; the protocol must report `NO_SELECTION` rather than inventing independence. The only stronger route-truth or clinical-safety claim would require an external validated reference, actual workflow evidence, or prospective adjudication, none of which is available in these MIMIC files.

## Additional verification fixtures for this repair

In addition to every inherited fixture, the verifier must execute: (1) unanimous shared-wrong H1/H2/H3 labels, which must leave an adverse-compatible assignment and block `AUTO` when the bound crosses 0.05; (2) one-panel missingness, which must widen rather than narrow `Omega_i`; (3) a two-admission ratio where independent extrema would be incompatible, which must differ from the jointly optimized ratio; (4) two different integer allocations with identical objective, which must invalidate absent the declared tie-break; (5) challenge reservations exceeding 300, which must produce `NO_SELECTION`; (6) exact ledger arithmetic `120+2*900+1.5*300=5070`; and (7) a workload failure in one atom with pooled workload passing, which must exclude only that atom. A result claiming that H1/H2/H3 agreement establishes truth, or that a latent-class estimate narrows the primary bound without a pre-label identifying restriction, is computationally rejected.

## Remaining limitations and conclusion ceiling

This repair makes preregistration and computation reproducible, not clinically complete. MIMIC shifted timestamps prevent cross-subject calendar comparisons; `anchor_year_group` yields only the inherited widened possible-calendar class. `hosp/services.curr_service` and ICU exposure are workflow proxies, not validated responsible-team labels. The available artifacts do not establish physical departure visibility, finalization/signature, communication, order/referral execution, responsibility, patient preference, outside care, appropriateness, follow-up, harm, utility, or benefit. Radiology text is not imaging. Correlated adjudicator error is not identifiable without an external reference, and the conservative compatible set may make selection infeasible. A supportive result permits only a separately approved prospective, within-site, silent bridge for the exact allow-list signatures; adverse excludes the affected atom; inconclusive means no certification and is not evidence of safety or transport. No retrospective automation, live safety, causal, outcome, temporal-transport, or external-generalizability claim is permitted.

## Adversarial counterfactual and negative-pair controls

Generate controls before labels using a locked transformation manifest and store transformed text separately from source text. Controls never alter the primary MIMIC labels or estimands. For each feasible challenge case, include:

1. a **route-irrelevant negative pair** that preserves target/action/timing/polarity and all route-relevant spans while permuting unrelated section order or replacing a non-target, non-temporal sentence with a provenance-matched sentence from another admission; expected route and unit inventory must remain unchanged;
2. a **route-decisive negative pair** that changes exactly one locked atomic field (for example explicit replacement versus no replacement, or ample versus under-24-hour opportunity) while preserving all other text; expected route must change only as specified by the locked route table;
3. a **counterfactual omission/addition pair** in which a recommendation or explicit discharge-plan statement is masked or inserted at a prespecified location, with the expected compatibility-set transition frozen before review; and
4. a **nuisance-feature pair** changing author/signature-like or formatting tokens while preserving semantics, where no route change is allowed.

Transformations are applied only when the requisite spans and times are unambiguous under a pre-label parser; otherwise the case is marked control-infeasible, never hand-edited. H1/H2 review randomized pair order and are blinded to the transformation type and expected answer. A route-invariant pair is a **negative control**; a route-decisive pair is a **positive control** for sensitivity, not evidence of clinical correctness. Any observed change in a route-invariant pair, or any change outside the locked route table for a decisive pair, is a falsification signal. Controls cannot rescue an atom with poor real-case purity.

## Identifiable partial identification of shared error

Do not fit a latent-class model as a primary analysis: without an external gold standard, conditional independence is not identifiable and shared expert error cannot be estimated as a point prevalence. Instead report sharp compatible bounds. For each atom and route, define observed panel outputs `(H1,H2,H3)` and the parent's sealed component outputs. The lower endpoint assumes only jointly observed support is valid; the upper endpoint assigns every unresolved or disagreement pattern to the adverse route-compatible state. Report interval bounds for holistic agreement, parent-versus-holistic discordance, `C_AUTO`, `D_MIX`, `leak_AUTO`, route capture, and workload. A sensitivity family may vary a prespecified dependence parameter only as a transparent assumption analysis; it cannot alter certification. If a separately blinded expert reference subset is obtained, use it only as an external measurement subset and state its ascertainment; do not call it a gold standard.

A useful sensitivity is a three-rater latent-class model only if an independently justified conditional-independence or validation constraint is documented before labels and the model has finite-sample identifiability. Otherwise the model is diagnostic, and its estimates cannot narrow adverse bounds or certify an atom. The primary report must include a Fréchet-style worst-case shared-error envelope, exact finite-population inversion for binary challenge outcomes, and 20,000 Rao-Wu replicates retaining all admission-level labels together. Use one max-statistic simultaneous 95% family over inherited gates, atom gates, holistic disagreement, control invariance, and minimax endpoints; missing challenge labels, packet corruption, control infeasibility, or unknowns are adverse-compatible, not complete-case deletions.

## Canonical admission object and route predicate

After the inherited pre-label extraction, each admission is represented by an ordered list of distinct recommendation units `U=(u_1,...,u_m)`, sorted by `(target_cluster, action_modality, due_interval, polarity, recipient, responsibility, unit_id)`. A reciprocal restatement is assigned the same `unit_id`; a distinct target or competing plan is not deduplicated. Each unit has the following finite coded fields.

* `Q` is `RESOLVED` or `UNKNOWN`; `Q=UNKNOWN` includes missing, malformed, unreadable, nonresponsive, unresolved reciprocal links, and `U_BOUNDARY`/`U_TIMING`/`U_DEFER` states.
* `P` is `PRESENT`, `ABSENT`, or `UNKNOWN`, denoting the recommendation atom after the locked parser. `PRESENT` is not a clinical-truth assertion.
* `V` is one of `V_D,V_24,V_72,V_168,V_late,V_U`; it is derived only from the sealed departure/availability state and the inherited `D` and `DS_store` conventions.
* `H` is one of `H_stale,H_0_6,H_6_24,H_24_72,H_72plus,H_U`; it is the inherited unit lag category. `H_stale` is adverse and is never silently converted to timely.
* `Z` is one of `F_text,C_O_text,C_I_text,R_text,U_text`, the inherited eventual text state.
* `Rpl` is `0` or `1` for an explicit replacement/superseding plan; `K` is `0` or `1` for a conflict with another non-restatement unit. A missing value in either field sets `Q=UNKNOWN`.

The following derived predicates are pure functions, not reviewer votes:

```text
known(u)       := (Q_u == RESOLVED) and P_u != UNKNOWN and V_u != V_U
active(u)      := known(u) and P_u == PRESENT and Z_u in {F_text,C_O_text}
timely(u)      := active(u) and V_u in {V_D,V_24} and H_u in {H_0_6,H_6_24}
late(u)        := active(u) and (V_u in {V_72,V_168,V_late} or
                                  H_u in {H_24_72,H_72plus,H_stale})
recon_unit(u)  := known(u) and (Rpl_u == 1 or K_u == 1 or Z_u == C_I_text)
```

A normalized route-defining tuple is parsed with the locked equality matcher: target cluster, action/modality, due interval, polarity, and recipient/responsibility must all agree. If any compared field is `UNKNOWN`, both `MATCH` and `NONMATCH` are retained in the compatible set; no favorable match is selected. The admission route is the following total, short-circuit function, evaluated in the displayed order.

```text
route(U):
  if m == 0: return NOACTION
  if any(not known(u) for u in U): return DEFER
  if any(recon_unit(u) for u in U): return RECON
  if any(K_u == 1 for u in U): return RECON
  if all(not active(u) for u in U): return NOACTION
  if any(active(u) and late(u) for u in U): return TIMING
  if all(timely(u) for u in U if active(u)) and
     all(not active(u) for u in U if not timely(u)): return AUTO
  return DEFER
```

The final `return DEFER` is fail-closed for a state not represented by the preceding rows. `NOACTION` is descriptive only and never an allow-list route. A minority unresolved or conflicting unit therefore controls the whole admission. The route of a panel is never accepted as an input to this function: routes are computed only from its sealed atomic tuple. For a panel-level whole-admission assertion, `UNKNOWN` is converted to `Q=UNKNOWN` before this function is applied.

The `AUTO` row is deliberately narrower than mere agreement: all active units must be timely and every unit must be known and non-conflicting. `RECON` precedes `TIMING`; `DEFER` precedes every favorable interpretation when uncertainty is present. This preserves all-unit adverse routing and the inherited route estimand.
