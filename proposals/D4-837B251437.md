# Does a repeated UKB biomarker panel add information beyond the current panel?

Parent: [prior hypothesis]

## Clinical question and falsifiable hypothesis

For a person who has a current (instance 1) blood-biomarker panel, does the preceding measurement (instance 0), summarized as within-person change, improve prediction of a first later cardiorenal/metabolic multimorbidity event beyond the current panel, age and sex?

This addresses a consequential monitoring decision: whether a prior measurement contains enough information to change risk triage or justify trajectory-aware follow-up after the current assessment. A null result would support using the current level alone for this prognostic task and would weaken the case for retaining repeat-measurement history. A positive result would justify a prospective clinical study of trajectory-aware monitoring; it would not by itself justify a treatment threshold or more frequent testing.

The falsifiable hypothesis is:

> In UKB participants with valid paired values for the prespecified eight-field panel, no recorded target-domain event before the landmark, and a verified pre-landmark instance-1 assessment, adding standardized instance-1 minus instance-0 changes to current instance-1 values, age and sex will improve cross-fitted prediction of a first post-landmark recorded two-domain event. The increment must be reproducible in held-out data and relevant to a prespecified risk-based decision.

This is a prognostic-information hypothesis, not a causal hypothesis about biomarker change, repeat testing, or treatment.

## Timing, semantic and repeat-selection gates

These gates are part of the executable study, not optional post hoc interpretation.

1. Schema gate: verify that every listed column exists in the biological_samples schema, that eids are unique within each joined table, and that the catalog one-to-one horizontal-join rule holds.

2. Semantic gate: before fitting, obtain an approved field dictionary for all eight field IDs. It must verify that instance 0 and instance 1 are the same analyte/measurement, that units are equal or have a documented conversion, and which values are valid versus missing or assay-failure codes. If any field fails, the eight-field primary estimand is not run; a reduced panel is a separate exploratory study, not a silent repair.

3. Timing gate: verify from approved UKB documentation that instance 1 for these fields is completed by 2013-12-31. The local files cannot establish this: their schemas have no biomarker temporal columns, and instance numbers are not elapsed-time values. The frozen administrative landmark is 2014-01-01. If pre-landmark timing cannot be verified, the solver may report schema/feasibility results, but must not label the analysis prospective or make the primary clinical claim.

4. Repeat-selection gate: use exactly instance 0 and instance 1 for every participant and every field. Do not select a participant last available value, substitute later instances, or choose values by outcome date. The primary cohort requires all 16 panel cells to pass the semantic validity rules, plus age and sex. Raw nonempty counts are availability checks only; the final valid count must be recomputed after the dictionary and missing-code gates.

## Population and temporal outcome definition

Construct the analytic population as the eid intersection of all 16 exposure cells valid under the verified field dictionary; valid 21022-0.0 and 31-0.0; at least one usable outcome row after exact code/date pairing and a defensible follow-up record; and no target-domain code with a valid date on or before 2013-12-31.

The exclusion means “no recorded target-domain event in these arrays before the landmark,” not disease-free. A code without a valid paired date cannot establish timing and is not used as an incident event.

Normalize outcome codes only by documented formatting operations (trim whitespace, uppercase, retain ICD code content). Define operational domains by prefix: metabolic E10-E14; renal N18-N19; cardiovascular I20-I25 or I50. These are recorded code domains, not adjudicated disease onset. For each participant, the primary event date is the earliest date strictly after 2013-12-31 on which two distinct domains have been recorded; simultaneous dates count as simultaneous domains. Secondary outcomes are first event in each domain and first single-domain event.

The primary prediction horizon is five years: 2014-01-01 through 2018-12-31, inclusive. Ten-year prediction through 2023-12-31 is secondary. Death before the target event is a competing event; use the valid post-landmark death date from 40000-0.0 or 40000-1.0 when available. For survival scoring, censor at death or the maximum defensible post-landmark outcome date, whichever comes first, and use a prespecified inverse-censoring/competing-risk scoring procedure. Report the number and fraction censored before each horizon. The exact observed follow-up range and endpoint counts must be computed and included in the flow table.

## Models, estimand and evaluation

Use one fixed participant-level five-fold split for all models, generated by a documented deterministic hash of eid. All validity filtering, scaling, imputation, tuning and feature selection occur inside training folds. No outcome or post-landmark field may enter exposure preprocessing.

M0, the simple current-level baseline, uses age, sex and the eight valid instance-1 field values. Fit cause-specific target/death survival models and derive each participant five- and ten-year cumulative incidence of the target event.

M1, the simple longitudinal test, adds the eight within-person differences D_j = value(instance 1, j) minus value(instance 0, j) to M0. Standardize each current value and each difference using training-fold parameters only. The primary inferential association is the joint change block; field-specific coefficients are secondary and multiplicity-controlled. Fit the same cause-specific model family as M0.

M2, the substantive learned alternative, uses the same current values, differences, age and sex and prespecified current-by-change interactions. Fit discrete-time gradient-boosted cause-specific hazard models for target and death, producing the same competing-risk cumulative-incidence output. Tune only within training folds. M2 is retained because it can reveal threshold and discordant trajectory patterns that additive M1 loses; it is not included merely to seek a small AUC gain. Summarize grouped importance for current versus change inputs and only report trajectory patterns stable across folds and sensitivity definitions.

The primary estimand is the cross-fitted incremental predictive utility of M1 over M0 for five-year target cumulative incidence, quantified as DeltaBS5 = Brier5(M1) minus Brier5(M0), using the same competing-risk/censoring weights and held-out predictions in both models; lower is better. The clinical-decision counterpart is held-out decision-curve net-benefit contrast DeltaNB5(p) at risk thresholds p=0.05 and p=0.10, plus the prespecified average contrast over p in [0.02, 0.10] when that range is supported by observed risk.

Use participant-clustered bootstrap resampling of held-out predictions, repeated within the fixed folds, for 95% confidence intervals. Also report time-dependent AUC, average precision where defined, calibration intercept/slope, calibration plots, joint change-block likelihood-ratio/Wald results, and 10-year and domain-specific analogues. Decision curves indicate information for a risk-threshold action; they do not identify the utilities, harms or treatment threshold of a real clinic.

The actual deliverable is newly fitted M0/M1/M2 models, fold assignments, fold-safe preprocessing records, out-of-fold predictions, population and exclusion flow counts, endpoint counts, uncertainty intervals, calibration and decision-curve outputs, grouped M2 pattern summaries, and machine-readable control results. No scientific conclusion may be reported from readiness or packaging alone.

## Falsification and interpretation rules

Hard implementation checks are: every incident target date is strictly after 2013-12-31 and every code/date pair uses the same array index; the timing and semantic gates pass before any prospective label is used; no outcome/death column is read by exposure construction; all splits are participant-level and all learned preprocessing is fold-local; shuffling the eight change vectors within age/sex strata while retaining current values and outcomes removes the M1 increment within uncertainty; permuting outcome dates within participant or independently breaking code/date position pairing cannot improve the claimed primary result; and a complete-case selection audit reports missingness by field and compares eligible-versus-complete characteristics without changing the primary estimand.

Supportive evidence requires all of: a passed timing/semantic gate; DeltaBS5 95% upper confidence bound below zero; positive DeltaNB5 at both 0.05 and 0.10 without material calibration degradation; and directionally compatible improvement in the 10-year or at least one domain-specific analysis. Stable M2 threshold/discordance patterns strengthen the scientific explanation but are not required to claim a linear change increment.

Adverse evidence is a near-null or worse M1 performance with the change block, a confidence interval excluding clinically useful improvement, no decision-curve gain, or a change increment that disappears under the age/sex-stratified permutation or code/date leakage controls. This falsifies the added-information claim for this operational panel and favors current values alone.

The result is inconclusive if any gate fails, fewer than 100 primary events remain after exclusions, follow-up is inadequate for the declared horizon, confidence intervals span both useful improvement and harm, estimates vary materially across folds or outcome definitions, or complete-case selection and missingness handling change the conclusion. “Inconclusive” is not evidence that biomarker trajectories have no clinical value.

The invalid future-change-versus-pre-index-disease control from the earlier draft is deliberately not used: without individual blood-draw dates, change may not be future relative to a pre-2014 diagnosis. Pre-index codes are used only for eligibility and baseline descriptive audits.

## Unavailable evidence and boundaries

This study cannot establish causal effects, biological turning points, treatment benefit, screening thresholds, the value of ordering a repeat test, or transportability. Stronger claims require individual blood-draw dates, verified assay units and batch/quality metadata, primary-care and self-report histories, medication and treatment changes, adjudicated CKD/heart-failure definitions, serial clinical creatinine/urine-output data for AKI, and an external cohort. The code arrays represent recorded inpatient events and do not establish disease onset.

The kidney-discordance branch remains deferred because an acute kidney-injury claim would require an adjudicated acute episode, serial labs, urine output and treatment context that are not available in this snapshot. A mechanistic deterioration score is also deferred: two field instances cannot identify a turning point, and unverified units/timing would make a biologically signed score overinterpretable. Either branch can be revisited after the missing dependencies are verified.
