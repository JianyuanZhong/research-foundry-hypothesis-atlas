# Benefit-dominant or adverse-dominant? A donor-paired test of macrophage MerTK pre-inhibition in RA synovial cocultures

**Domain:** Therapeutic Target Prioritization (D2) · **Parent:** [prior hypothesis] (evolved; seed D2-T2) · **Episode:** 2

## 1. Scientific change from the parent (episode-2 verified facts)

This child keeps the parent's scientific question — does MerTK-pathway inhibition in the macrophage compartment reduce the harmful fibroblast program while eroding the protective macrophage program? — and restructures the estimand because direct inspection this episode (E-MTAB-8873.design.json, E-MTAB-8316.design.json, assay-registry.json, counts matrices) found:

1. **The parent's central test is run-confounded.** The E-MTAB-8873 inhibitor arm has only 5 samples: 4 Mpos-context (R1×3, R2×1, R5×1) and exactly 1 Mneg-context (R1_SA256A_FLS_SA259A_Mneg_Inhibitor, run R1 only). A Mpos-vs-Mneg inhibitor interaction therefore contrasts one run against three; the state-dependence claim cannot be separated from run effects as designed.
2. **Treatment semantics are now resolved from the design metadata.** All five inhibitor-arm samples — whether labeled `_Inhibitor` (R1) or `_preInhibitor` (R2/R5) — carry the same `Factor Value[stimulus]`: "macrophages pre-treated with MerTK inhibitor". The label variant tracks run (R1 vs R2/R5), not a distinct intervention. A run-sensitivity analysis (with/without R1) is pre-specified.
3. **An anomalous well must be excluded.** `R1_SA256A_FLS_Inhibitor` is annotated "not co-cultured", stimulus "none", treatment "none", cells 425 — despite the "Inhibitor" suffix in its sample ID and its presence as a column in the counts matrix. It is excluded from the FLS-only baseline and from all inhibitor contrasts; whether it was an FLS-direct-inhibitor well requires protocol adjudication that the ArrayExpress metadata cannot settle.
4. **E-MTAB-8316 is the properly paired primary instrument.** Assay registry confirms 4 verified single donors (SA049, SA051, SA104, SA114), 12 samples forming 6 paired none-vs-UNC106238 instances, all under a constant LPS 1 ng/mL stimulus (verified in per-sample Characteristics[stimulus]), with 58,302 measured features. ## 2. Unresolved question and clinical importance

The target-prioritization decision is directional and currently unresolved: inhibiting macrophage MerTK signaling could (a) suppress the macrophage→FLS inflammatory/matrix axis (benefit) while (b) dismantling the MERTK/MRC1/AXL/CD163 pro-resolving, efferocytosis-linked macrophage state itself (adverse). Which readout dominates under the *same* intervention has not been measured with separated benefit and adverse modules in any inspected work. The harmful HBEGF+ macrophage→FLS axis [K1] and the protective MERTK+ resolution program [K2] are established separately; remission-cohort work shows anti-rheumatic suppression does not by itself reinstate protective myeloid states [K3]. A recent review frames the same gap as the "failed-resolution switch": blocking single mediators can lower inflammatory output while leaving resolution unrestored (Wei & Xu, Front Immunol 2026, PMID 42769565 — additional citation, not a key work).

If MerTK inhibition is benefit-dominant, the axis is a candidate for context-specific targeting with explicit pro-resolving-state safety monitoring; if adverse-dominant, resources shift away from MerTK inhibition toward sparing or agonizing pro-resolving TAM signaling. Either resolution changes the next research decision.

## 3. Hypothesis (testable claim)

**H1′:** In LPS-stimulated RA synovial FLS–macrophage cocultures (E-MTAB-8316), macrophage pre-treatment with UNC106238 produces a *benefit-dominant* profile: the paired donor delta of the harmful FLS inflammatory/matrix module exceeds (is more negative than) the paired delta of the pro-resolving macrophage module — dominance index D = Δ_harmful − Δ_proresolving > 0 — while the pro-resolving module is itself measasurably depleted (Δ_proresolving < 0, adverse signal present but smaller). Exploratory (E-MTAB-8873): within Mpos cocultures the inhibitor reduces the FLS harmful-program score relative to untreated, run-stratified; the Mneg-inhibitor contrast is R1-internal only and reported with its run-confounding caveat.

**Rivals:** R1 (non-selective suppression): both modules fall proportionally (D ≈ 0), i.e., a global anti-inflammatory shutdown, not a separable profile. R2 (no signal): no detectable paired effect at this dose/duration. R3 (run/batch artifact in 8873): effects track R1/R2/R5 rather than treatment. R4 (composition): apparent FLS-program changes reflect cell-mixture shifts, not per-cell transcription. R5 (off-target): UNC106238 effects are not MerTK-specific — expression data cannot exclude this.

## 5. Analysis design

**Modules (fixed a priori; all genes verified present):**
- Harmful FLS program: IL6, IL11, IL1B, MMP1, MMP2, MMP3, MMP9, MMP12, MMP13, MMP14, CXCL1, CXCL2, CXCL3, CXCL5, CXCL8, CCL2 (log-normalized module score).
- Pro-resolving macrophage module: MERTK, MRC1, AXL, CD163, CD200, ARG1, APOE, C1QA, C1QB; plus an empirical remission module derived in E-MTAB-8322 (pseudobulk remission vs active-RA DE, donor-aware, SA149/SA149P excluded), intersected with the 8873 panel for cross-application.

**Primary test (8316):** per-sample log-normalized module scores → paired deltas (UNC106238 − none) per module per pair → donor-level averaging first (SA049, SA114 each contribute 2 pairs → 4 donor-level observations; pair-level n=6 reported alongside) → D = Δ_harmful − Δ_proresolving with sign/Wilcoxon and paired t; consistency across donors reported. Gene-level paired DE (donor-blocked GLM, edgeR/DESeq2-style) for module genes with FDR control. Secondary direction checks on HBEGF, NOTCH3, HPGD (whole-transcriptome only).

**Secondary test (8873, exploratory):** run-stratified contrasts of module scores, Mpos-inhibitor (n=4) vs untreated Mpos (n=8); Mneg-inhibitor contrast R1-internal only (n=1) with run-confounding caveat; pre-specified R1-sensitivity re-run of all inhibitor contrasts.

**Baseline vs alternative method comparison (unchanged in substance, refined):** baseline = the paired/stratified module-score contrasts above (transparent, matches n=4–6 effective units). Alternative = (i) composition-corrected model in 8873 using marker genes PTPRC/CD14 (myeloid) vs COL1A1/COL3A1 (fibroblast) to test rival R4, and (ii) elastic-net interaction model for non-additivity. The alternative separates per-cell transcriptional change from cell-mixture change, which the baseline cannot. With 4–6 effective units a learned model risks overfitting, so baseline is primary and the alternative is a pre-specified sensitivity control — both CPU-minutes-scale. No GPU needed.

**Falsification criteria:**
- *Supportive for H1′:* D > 0 (significance at donor level with consistent pair-level direction) AND Δ_proresolving < 0 — benefit with a bounded adverse signal.
- *Adverse-dominant (inverts the prioritization):* D < 0 — the pro-resolving module is depleted more than the harmful program; supports sparing/agonizing rather than inhibiting MerTK.
- *Rival R1 supported:* both modules reduced with D statistically indistinguishable from 0 — non-selective suppression; no separable benefit/adverse profile.
- *Inconclusive:* no detectable paired effect (power: n=4 donors — sign-test floor), or between-pair heterogeneity swamping; next step per-cell analysis of original 8873 matrices and larger donor panels.

**Honest limits:** expression-only (no protein/efferocytosis/invasion readout); UNC106238 off-target effects not excludable; 8316 cell-type label conflict unresolved (bulk readout interpretation); in-vitro LPS context ≠ synovium; remission module is a cross-sectional comparator, not a treatment effect; source publication for the three E-MTAB accessions not identifiable in Europe PMC (searches returned 0 hits for UNC106238) — ArrayExpress metadata is the data provenance.
