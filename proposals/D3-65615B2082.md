# Provisional hypothesis: macrophage context changes FLS transcript state beyond donor composition

## Proposed relationship
In the frozen E-MTAB-8873 human synovial type B synovial cell (FLS) targeted assay, FLS cells co-cultured with MerTK/CD206-positive macrophages have a reproducible, donor-set-aware difference in measured transcript state from FLS cells co-cultured with MerTK/CD206-negative macrophages, beyond the recorded contributing-donor composition and cell count. This is a context-associated hypothesis, not a causal macrophage-mechanism claim.

## What is known versus unresolved
The assay is a targeted FLS coculture panel, so it can test whether the measured FLS response differs across macrophage context while controlling for donor set and recorded covariates. It cannot establish that macrophages directly caused a pathway change, identify whole-tissue cell composition, or provide longitudinal persistence/remission. No expression contrast, model fit, or biological result has been computed in this draft.

## Falsifiable test
Compare none-treatment Mpos versus Mneg samples using a donor-set-aware baseline (paired donor contrasts with recorded cell count and available covariates) against a hierarchical/structured alternative that allows a shared macrophage-context effect across features while preserving donor uncertainty. Use a prespecified feature-wise and global contrast summary, uncertainty intervals, and donor-level sensitivity analysis. Support requires a reproducible context effect with uncertainty excluding the prespecified null and robustness to donor-set handling; adverse evidence is a precise null or reversal; inconclusive evidence is wide uncertainty, too few independent donor sets, or failure to reconcile the feature map.
