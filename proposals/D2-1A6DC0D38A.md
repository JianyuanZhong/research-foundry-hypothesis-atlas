# Provisional hypothesis: macrophage–fibroblast context modifies the intervention-associated fibroblast transcript response

Seed: D2-T1
Status: provisional, evidence-bound draft; no inferential result has been computed yet.

## Proposed relationship

Among rheumatoid-arthritis fibroblast-like synoviocytes (FLS) exposed to the interventions represented in the available E-MTAB-8316 assay, the direction and magnitude of the intervention-associated transcript response will depend on the macrophage context (monocyte/macrophage phenotype or coculture condition), rather than being a context-independent FLS response. Operationally, a context-dependent effect is a reproducible interaction between intervention and macrophage context after accounting for donor pairing and repeated context measurements.

This is a hypothesis about an intervention-associated expression pattern, not a claim that any drug acts directly on a specific target or that the expression change is causal.

## Clinical importance and substantive advance

Target prioritization is consequential when an intervention appears effective in one inflammatory microenvironment but ineffective or potentially harmful in another. A context-independent response would support a simpler prioritization rule; a reproducible context interaction would motivate microenvironment-specific target evaluation and would identify which biological state should be measured before testing a candidate intervention. This advances beyond a descriptive drug-response table by testing whether macrophage context changes the intervention contrast while retaining donor-matched controls.

## Closest evidence and unresolved claim

The available evidence supports that the configured molecular assay contains intervention, macrophage/condition, and donor-related metadata and expression measurements, but it does not establish a context-dependent effect. The unresolved claim is whether intervention-by-macrophage-context interaction is reproducible after donor-aware adjustment, rather than being explained by donor composition, batch, or condition assignment. Existing evidence does not establish direct target action, clinical efficacy, or a mechanism.

Required fields are the intervention/treatment labels, macrophage or coculture-context labels, donor/patient identifiers, technical batch or assay fields where present, and gene-expression values. The exact local source paths, archive members, table names, columns, and join keys must be verified against datasets/README.md and the assay registry before execution; this draft does not claim those bindings were re-inspected in this checkpoint.

The baseline is a donor-aware additive model for expression response with separate intervention and macrophage-context terms and no interaction. The substantive alternative adds the intervention-by-context interaction and uses donor-aware cross-validation or a prespecified held-out donor split. Evaluate effect estimates with uncertainty intervals and permutation or bootstrap calibration where the design permits. A positive result requires a reproducible interaction, not merely a larger expression change; an adverse result is a consistent null or reversal that rejects context dependence; an inconclusive result is imprecision, insufficient independent donors, or failure of design verification.

## Alternatives and limitations

A donor-aware additive model is the simple baseline. The interaction model is scientifically substantive because it tests whether the intervention effect changes with microenvironment, not merely whether expression predicts context. A mechanistic perturbation or target-specific validation would be needed to distinguish direct target action from indirect transcriptional response; it is not available from this expression dataset alone. Missing clinical outcomes, direct target measurements, independent technical replicates, and a verified assay registry prevent causal or clinical claims. The three demonstration papers are not being reproduced: their EHR/sequence or multimodal methods are not the scientific comparison here, and any adaptation would require a separately justified design.

## Falsifiable next test

Fit the donor-aware additive and interaction models on the verified E-MTAB-8316 samples, with the interaction estimated only where the design supports it. Support requires a prespecified interaction effect with uncertainty excluding the null and stability across donors; adverse evidence is a robust null/reversal; inconclusive evidence is insufficient independent donors, failed key verification, or wide uncertainty. No result from this screening can establish direct target causality or clinical benefit.
