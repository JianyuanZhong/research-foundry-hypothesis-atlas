Prior adverse evidence is a stopping guard against relabeling another small loss improvement as deployment evidence, not a reason to assume the new policy is adverse.

The clinical advance, if supported, would be limited but consequential: it would show that cystatin-C information changes a prespecified baseline-only monitoring-prioritization rule in this observed-repeat evaluation sample, beyond the established creatinine score, rather than merely improve conditional log loss or exploit future visit timing. If adverse, it would close this same-snapshot practical-policy direction despite any residual biological association. If inconclusive, it would identify whether missing field semantics, selection, calibration, or schedule support—not a null biological effect—prevents a decision claim.

## Machine-readable certificate state machine

The compiler receives immutable inputs `field_certificate.json`, `equation_certificate.json`, and, only for the neutral diagnostic lane, an optional `assumption_manifest.json`. These are inputs, not generated conclusions. Each is canonical UTF-8 JSON with recursively sorted object keys, preserved array order, no insignificant whitespace, and a separately supplied digest. Hashes are recomputed before use; a self-declared status or self-referential digest is ignored and rejected. Certificates are read-only after hashing.

`field_certificate.json` has exact top-level keys:

```text
certificate_schema_version, certificate_id, catalog_sha256, snapshot_id,
required_fields, field_evidence, cross_instance_evidence, deficiencies,
certificate_sha256
```

`required_fields` must be exactly, once each:

```text
31-0.0, 21003-0.0, 21003-1.0, 53-0.0, 53-1.0,
30700-0.0, 30700-1.0, 30720-0.0, 30720-1.0
```

Each field record must bind logical table, source ID and SHA, exact schema path and both schema hashes, field/instance/array, data type, semantic label, valid range, exhaustive raw missing-token list, and the applicable sex, age, date, analyte, matrix, unit, assay, and method concepts. Each evidence item records evidence class, directness, source URL or local artifact, source version, retrieval date, artifact SHA, and the exact claim text. `ASSUMED` or `MISSING` evidence never authorizes a scientific run. Unknown keys, duplicate fields, unlisted tokens, hash mismatch, or conflict are hard failures.

`cross_instance_evidence` must independently certify (a) that instance 1 is an exported repeat field but not necessarily the first clinical test, (b) comparability of date representations, (c) creatinine analyte/specimen/unit/assay compatibility across instances, and (d) cystatin-C compatibility across instances. An operator assertion without frozen evidence is not verification. A source disagreement is `CERTIFICATE_CONFLICT`; it is never resolved by choosing the more favorable interpretation.

`equation_certificate.json` must bind equation name/version, canonical formula text, constants, input units, sex coding, source identifier and artifact hash, implementation hash, and numerical test vectors with tolerances. This proposal uses the following primary equations after certificate-authorized conversions:

```text
Scr_mg_dL = raw_30700 / 88.4                 # only if the certificate proves µmol/L

For female F=1: k=0.7, alpha=-0.241; for male F=0: k=0.9, alpha=-0.302
EGFRcr = 142 * min(Scr/k,1)^alpha * max(Scr/k,1)^(-1.200)
        * 0.9938^Age * 1.012^F

EGFRcys = 133 * min(Scys/0.8,1)^(-0.499)
         * max(Scys/0.8,1)^(-1.328)
         * 0.996^Age * 0.932^F

Z = log(EGFRcys_0 / EGFRcr_0)
```

The cystatin-C formula is the inherited 2012 cystatin-C-only equation, not the 2021 combined equation. It must be named as such in the certificate; no compiler may silently substitute a newer formula. Formula provenance does not certify the exported assay. Synthetic equation vectors are mandatory and must be frozen in the certificate, including `(Scr,Age,sex)=(0.9,50,male) -> 104.0490129932253`, `(0.7,60,female) -> 98.94831465668567`, `(1.2,70,male) -> 65.0565950204461`, and `(Scys,Age,sex)=(0.8,50,male) -> 116.21314799600616`, `(0.7,60,female) -> 111.2250331094537`, `(1.0,70,male) -> 79.75272605816541`, with absolute and relative tolerance `1e-10` unless the certificate supplies a stricter frozen tolerance.

The executor uses the following monotone states, with no implicit transitions:

```text
SOURCE_INTEGRITY_FAIL
  -> STRUCTURAL_READY
  -> CERTIFICATE_MISSING | CERTIFICATE_INVALID | CERTIFICATE_INCOMPLETE
     | CERTIFICATE_CONFLICT
  -> NEUTRAL_QA_PASS | NEUTRAL_QA_FAIL
  -> CERTIFIED_READY
  -> CERTIFIED_ANALYSIS_COMPLETE | CERTIFIED_ANALYSIS_FAIL
```

`SOURCE_INTEGRITY_FAIL`, all certificate failure states, and `NEUTRAL_QA_*` are `NO_SCIENTIFIC_RESULT`. They may report only source/schema/header/key hashes and aggregate structural counts, plus synthetic tests that contain no real field values, dates, eGFR, cohort masks, outcomes, predictions, selections, or metrics. `CERTIFIED_READY` requires every applicable field and equation claim to be directly or validated-harmonization supported, with no assumed/missing/conflicting claim. The certificate cannot authorize its own truth; external assay and clinical semantics remain expert-verification responsibilities.

If no complete certificate exists, the default run is structural/neutral and stops. An optional `assumption_manifest.json` may be used only to diagnose what would change under explicit assumptions. It must contain a stable bundle ID and an entry for every required field, unit, missing tokens, date representation, instance interpretation, assay compatibility, equation version, reason, source, and alternatives. Every such entry is marked `ASSUMED`; bundles are run independently and never selected by favorable result. The fallback may emit only aggregate parser, mask, and metric diagnostics carrying `ASSUMPTION_CONDITIONED_UNVERIFIED`; it can never emit `SUPPORTIVE`, `ADVERSE`, biological wording, or a certified clinical conclusion. It must not be used to promote an assumption into a certificate. The compiler must fail if a fallback output is consumed by the certified decision gate.

## Exact baseline-only feature and model contract

Use ten deterministic outcome-stratified participant-level five-fold repeats with seeds
`104729, 104759, 104773, 104779, 104789, 104801, 104827, 104831, 104849, 104851`.
Within each outcome stratum, stable-sort by `(label, numeric eid)` and assign round-robin fold IDs. Folds are created using the primary outcome once, then reused for paired models; every participant has exactly one held-out prediction per model per repeat. No participant-specific repeat date, elapsed time, repeat age, repeat biomarker, attendance indicator, outcome, or future measurement may enter a score matrix.

Define a single unambiguous four-column fixed-bound cubic basis `C(u)` for each continuous variable. For age use bounds `[40,80]`; for baseline eGFRcr use `[60,120]`. Clip only for basis evaluation at the stated bounds. Let `k1=a`, `k2=a+(b-a)/3`, `k3=a+2(b-a)/3`, and `k4=b`; define

```text
d_j(u) = max(u-k_j,0)^3 / (k4-k_j), j=1,2,3
C(u) = [u, d_1(u)-d_3(u), d_2(u)-d_3(u), d_3(u)]
```

This is a fixed cubic hinge basis with four and only four columns; it is not an unspecified library natural-spline default. Within each training fold, center and scale each of the four columns using training participants only; apply those moments to the held-out fold. A zero training standard deviation is `FAIL_MODEL_SPEC`, not silently replaced. The baseline sex column `F` is standardized with training-fold moments under the same rule. `Z` is one additional training-standardized linear column.

The ordered feature contract is exact:

```text
M0-B = [F, C(age), C(EGFRcr_0)]          # 1 + 4 + 4 = 9 non-intercept columns
Mc-B = [F, C(age), C(EGFRcr_0), Z]       # 9 + 1 = 10 non-intercept columns
```

Persist the ordered names, source field lineage, fold-specific means/scales, and dimensions privately. Any other dimension, duplicated raw age/eGFRcr column, use of elapsed time, non-training preprocessing, or feature-order mismatch is `FAIL_MODEL_SPEC`. Fit float64 `sklearn.linear_model.LogisticRegression(penalty='l2', C=1.0, solver='lbfgs', fit_intercept=True, class_weight=None, tol=1e-10, max_iter=2000, random_state=0)`. A convergence warning, `n_iter_ >= 2000`, nonfinite coefficient, nonfinite prediction, absent outcome class in a training fold, or incomplete OOF coverage is `CERTIFIED_ANALYSIS_FAIL`.

The prior executed adverse incremental-information result means log loss is a secondary diagnostic only. Report paired held-out log loss and Brier score, but neither can satisfy a decision gate or be described as a clinical benefit. The primary question is whether `Mc-B` changes prespecified actions relative to `M0-B`.

## Prespecified decision estimands and selection policy

For probability threshold `p`, define `A_m(p)=I(p_m>=p)` from raw held-out probabilities and

```text
NB_m(p) = TP_m/n - FP_m/n * p/(1-p)
DeltaNB(p) = NB_Mc-B(p) - NB_M0-B(p)
```

The primary threshold is `p=0.02`, reported per 1,000 participants. The one-to-49 exchange rate is an explicitly operational sensitivity, not a clinically validated utility. Secondary thresholds are `p=0.01` and `p=0.05`; they are not allowed to replace a failed primary gate. Report treat-none and treat-all curves as mathematical references only.

The co-primary capacity policy selects exactly `K=1,637` people, equal to the inherited 10% capacity after flooring-plus-largest-remainder allocation within each held-out fold and repeat. Within each fold, rank descending held-out probability and break ties by ascending numeric `eid`; `eid` is a deterministic private tie-breaker and is never published. Define `E10_m` as the number of observed primary outcomes among selected people and `DeltaE10=E10_Mc-B-E10_M0-B`. The worthwhile floors are `DeltaNB(0.02)>=0.001` (one net-positive equivalent per 1,000) and `DeltaE10>=5` outcomes per 1,637 slots. These are operational protocol floors, not evidence of patient benefit.

Predeclared capacity sensitivities are 5% (`K=819`) and 15% (`K=2,456`), using the same fold quotas, tie rule, and paired participants. They are descriptive unless the 10% co-primary capacity gate passes. For each capacity report selected N, event count, event fraction, entrants, leavers, overlap/Jaccard, and event difference. Do not choose a capacity after seeing results. Capacity metrics are counts, not the ambiguous `DeltaC` event-fraction notation used in an earlier branch.

At 2%, report the four paired reclassification cells (baseline-only action only, cystatin-informed action only, both, neither), with event and non-event counts. Verify that their weighted cell contributions equal `DeltaNB` exactly up to declared floating tolerance. At 10%, decompose entrants-minus-leavers and event difference by baseline eGFR strata `[60,75)` and `>=75`; the stratum contributions must sum exactly to pooled `DeltaE10`. These identities are arithmetic audits, not rescue mechanisms.

## Decision gates and result semantics

The executor emits exactly one scientific label only from `CERTIFIED_ANALYSIS_COMPLETE` and only after source, certificate, model, OOF, calibration, uncertainty, and falsification gates pass.

**Supportive joint baseline-policy signal** requires all of the following:

- `DeltaNB(0.02)` point estimate at least `0.001`, 98% lower bound above zero, and positive in at least 8 of 10 repeats.
- `DeltaE10` point estimate at least `+5`, 98% lower bound above zero, and positive in at least 8 of 10 repeats.
- `Mc-B` passes threshold calibration/action/event support and has positive net benefit versus both treat-none and treat-all at 2%; this remains a schedule-marginal operational statement.
- No comparable predictor-null, reversed-label, or leakage gain; no material M1 calibration harm; no unexplained anchor or arithmetic failure.
- Attendance weighting does not reverse the direction with an assessable effective sample size, and no assessable timing band has a simultaneous upper bound below zero. If a timing band is underpowered, the label is supportive but `schedule-robust=unassessable`, never schedule-robust.

This supports only external prospective validation of a baseline-only prioritization signal in a defined observed-repeat population. It does not support testing benefit, CKD diagnosis, chronicity, or a patient-level threshold recommendation.

**Threshold-specific only** applies when the 2% threshold gate passes but the 10% capacity floor does not. It means probability movements may be useful under the declared exchange rate but do not justify a fixed-capacity rank policy. It does not overturn the prior adverse fixed-capacity evidence by itself.

**Capacity-specific only** applies when the 10% capacity gate passes but threshold calibration or the 2% gate fails. It supports rank concentration for the observed label only and forbids probability-threshold interpretation.

**Adverse to the worthwhile incremental baseline policy** requires certified computation, complete gates, and both primary practical upper-bound criteria: the 98% upper bound for `DeltaNB(0.02)` is below `0.001` and the 98% upper bound for `DeltaE10` is below `+5`. If either upper bound is below zero with at least 8 adverse repeats, that axis is directionally adverse. This falsifies the prespecified worthwhile joint policy in this selected observed-repeat setting; it is not evidence against cystatin-C biology, assay validity, CKD, or other populations. A null-compatible result with a failed practical floor is not automatically adverse.

**Inconclusive / no scientific verdict** includes certificate missing/conflict, assumption-conditioned fallback, schema or anchor failure, model or OOF failure, threshold-policy uncertification, incomplete null controls, poor attendance positivity, timing underpowering that prevents the required interpretation, practical intervals crossing the floors, or disagreement between axes without a named mixed label. Non-significance is not equivalence. `STOP_UNIDENTIFIED_FIXED_HORIZON` is an identification stop, not an adverse result.
