# D2-T1 successor: specificity of the intervention-associated macrophage response

## Current question

The parent established a context-by-intervention question: does a macrophage transcriptional response differ when macrophages are exposed to synovial fibroblasts? The unresolved successor question is narrower and more consequential: is any intervention-associated macrophage response specific to a fibroblast-linked program, or is it generic macrophage stimulation, donor composition, or assay/feature artifacts?

This is an observational hypothesis. The available assays do not establish direct target action, causal mediation, clinical efficacy, or a mechanism in vivo.

## Specificity estimand

For each verified intervention and matched MT/MTF pair, define the macrophage intervention response as log2 fold-change from its corresponding control. Define a fibroblast-linked program indicator from the E-MTAB-8316 FLS response (for example, a prespecified set of FLS-responsive features or a data-derived but frozen component), without using ambiguous GSE95588 feature labels as gene identity. The primary specificity estimand is the difference in intervention response between the fibroblast-linked program and a matched generic-stimulation reference, within the same donor/condition dependence units.

The generic reference should be constructed before looking at the intervention effect: use the unstimulated/context control and/or a prespecified broad macrophage activation signature, with the same feature-selection and normalization rules. Do not select the reference from the intervention effect. Report both the context contrast (MTF minus MT) and the specificity contrast (fibroblast-linked response minus generic reference), with donor-aware uncertainty.

## Baseline and substantive alternative

### Transparent donor-aware baseline
Estimate each intervention's MT and MTF response separately, then compute the paired context contrast and specificity contrast using a donor/condition-blocked paired test or permutation. Use the same feature set, normalization, and control definition for both assays. This directly answers whether the observed intervention response is enriched in the fibroblast-linked program relative to generic stimulation.

### Hierarchical/mechanistic alternative
Fit a joint hierarchical model with intervention, context (MT versus MTF), program (fibroblast-linked versus generic reference), donor/condition random effects, and an intervention-by-context-by-program interaction. Use shrinkage across interventions and genes, and a prespecified negative-control program (generic activation or ambiguous/technical features). The model can distinguish a shared fibroblast-linked response from intervention-specific reversal and can quantify whether the interaction is stronger than generic stimulation. Evaluate with donor-blocked cross-validation, uncertainty intervals, and held-out prediction of the context-specific contrast. Compare the interaction and specificity estimates, not merely overall predictive accuracy.

The alternative reveals whether the signal is a coherent program with a consistent direction across donors and interventions, or whether it is intervention-specific/noise; the baseline loses this decomposition. CPU is sufficient for the small tabular fits; no GPU is required.

## Falsification and interpretation

- Supportive: the specificity contrast is reproducible with uncertainty excluding the prespecified null, direction is consistent across available donors/conditions, and it exceeds the generic reference and negative-control/ambiguous-feature checks. This supports a context-specific transcriptional association, not direct target action.
- Adverse: no specificity contrast, disappearance after donor/condition and feature-identity checks, or a comparable generic response. This weakens the fibroblast-linked specificity claim; it does not prove absence of context effects in vivo.
- Inconclusive: unresolved GSE95588 donor/GSM mapping, insufficient matched contrasts, high uncertainty, or contradictory assay-specific results. This motivates metadata repair or a new donor-resolved experiment rather than a negative biological conclusion.

## Limitations and next evidence

E-MTAB-8316 is an FLS readout after macrophage pretreatment, while GSE95588 is a macrophage readout; cross-dataset claims remain assay/context-specific. GSE95588 donor identity is unresolved, so donor-aware inference is gated on verified GSM-to-column mapping. Ambiguous feature-map rows must remain distinct and cannot be merged. No wet-lab target validation, clinical outcome, or direct perturbation is available. A supportive result would justify a donor-resolved experiment with direct target perturbation and clinical readouts; an adverse result would redirect screening toward isolated macrophage effects or other mechanisms.
