# Certificate-gated baseline cystatin-C/creatinine discordance and repeat kidney status

## Lineage, question, and scientific boundary

This is a targeted compilation successor of assessed-valid `[prior hypothesis]`. It does not change the estimand. Among adults with certified baseline creatinine-equation eGFR at least 60 and a complete qualifying first available repeat assessment 2–8 years after baseline, test whether baseline cystatin-C/creatinine discordance improves baseline-only prioritization of repeat creatinine-equation biomarker status beyond sex, age, and baseline creatinine-equation eGFR. The schedule-marginal outcome is the status observed at that variable, observed repeat interval; it is not a fixed-horizon risk, onset time, CKD diagnosis, chronicity, measured GFR, treatment benefit, or causal utility estimand.

The strongest claim available before this experiment is only that the specified discordance feature is a candidate incremental predictor if the UKB field semantics, units, missing codes, assay comparability, and date semantics are independently certified. No participant result, field certificate, cohort count, or biological conclusion is asserted here. The unresolved claim is the predeclared out-of-fold incremental contrast in the selected repeat-attender cohort. The substantive advance is a mechanically auditable contract: every data dependency, certificate claim, equation constant, gate transition, and permitted aggregate conclusion has an explicit check and provenance.

## Equation protocol and executable unit tests

Use the race-free 2021 CKD-EPI equations only after certificate verification, with `Scr` in mg/dL, `Scys` in mg/L, age in years, and `F=1` for female and `F=0` for male:

```text
female: k=0.7, alpha=-0.241
male:   k=0.9, alpha=-0.302

eGFRcr = 142 * min(Scr/k,1)^alpha * max(Scr/k,1)^(-1.200)
             * 0.9938^Age * 1.012^F

eGFRcys = 133 * min(Scys/0.8,1)^(-0.499) * max(Scys/0.8,1)^(-1.328)
              * 0.9961^Age * 0.932^F

eGFRcr_cys = 135 * min(Scr/k,1)^alpha * max(Scr/k,1)^(-0.544)
                 * min(Scys/0.8,1)^(-0.323) * max(Scys/0.8,1)^(-0.778)
                 * 0.9961^Age * 0.963^F
```

The sex coding conversion is explicit: certified UKB code `0` (female) maps to `F=1`, and code `1` (male) maps to `F=0`; no other code is accepted. `Scr=30700/88.4` is allowed only if the certificate says field 30700 is micromol/L; otherwise conversion is prohibited. Cystatin conversion is allowed only if explicitly required by its certified unit. Apply only certified field-specific missing codes, then require finite positive values; never globally recode negative numbers.

Before participant computation, run two independently written implementations (the production function and a separately coded scalar reference with no shared helper or constants object). Assert the serialized constant map and unit/conversion map are exactly equal before evaluating any vector. The unit-test matrix must include both sexes and all branch combinations, including boundary equality: `(sex=female, Scr=0.6, Scys=0.6, age=40)` (both min branches), `(female, Scr=1.4, Scys=1.2, age=70)` (both max branches), `(male, Scr=0.9, Scys=0.8, age=55)` (boundary values), and mixed cases `(male, Scr=0.9, Scys=1.2, age=55)` and `(female, Scr=1.4, Scys=0.6, age=70)`. For each vector, compare `eGFRcr`, `eGFRcys`, and `eGFRcr_cys` at relative tolerance `1e-12` and absolute tolerance `1e-12`; explicitly assert the branch predicate and sex map. Add metamorphic tests that increasing age lowers each equation, and that changing only sex changes only the certified sex factors/k-alpha path. A test failure is the equation neutral stop, never a participant-level partial result. The public provenance is Inker et al., DOI `10.1056/NEJMoa2102953`, with the frozen corroborating artifact recorded by the certificate; provenance does not certify local UKB fields.

## Falsification and interpretation contract

Run, without changing the primary estimand, the following predeclared checks: static leakage audit; 200 within-baseline-stratum label permutations with fold reconstruction and refitting (seed 520242), using randomized-plus-one statistic-specific tails; within-sex/baseline-eGFRcr-decile permutations of `Z`; reversed-label `1-Ycr`; interval-band and secondary-equation analyses; complete-case versus attendance-weighted descriptive sensitivity; and repeat-level stability. A deliberately leaked model may run only as a private debugging sentinel and can never enter output. Null completion, bootstrap completion, and privacy checks are hard gates.

The aggregate verifier must link every reported statistic to a manifest entry containing the exact output filename/hash, analysis state, cohort definition hash, feature/outcome lists, fold/repeat seeds, and certificate digest. It must reject a conclusion that lacks the corresponding computed output, treats a neutral stop as adverse/inconclusive, reports a positive result from an unapproved isolated q point or subgroup, or calls a schedule-marginal contrast a fixed-horizon risk. It must independently recalculate aggregate Brier differences, capacity ordering, interval inclusion, null-tail comparison, repeat-majority rule, and state-specific output permissions from aggregate files; it must not infer clinical meaning from statistical direction.

- **Supportive** is permitted only in `REPORTABLE_SUPPORTIVE` after all integrity, certificate, equation, leakage, null, bootstrap, timing, and stability gates pass; M1 must favor the paired Brier contrast and have simultaneous 98% uncertainty supporting that direction over the contiguous 5–15% capacity region, with a prespecified majority of repeats supportive and no materially adverse repeat. The conclusion is limited to baseline conditional ranking in the selected complete-repeat schedule.
- **Adverse** is permitted only after all technical gates pass when M1 reproducibly worsens calibration or capacity capture / is unfavorable across the predeclared region and repeat checks. It argues against incremental prioritization in this selected schedule, not against cystatin C in other uses.
- **Inconclusive** is permitted only after all technical gates pass when uncertainty crosses the null over the region, repeat or interval heterogeneity is material, or improvement is isolated to one q or one unadjudicated equation. No threshold recommendation follows.
- **Neutral technical stop** means certification or computation was not authorized. It is not evidence for or against the biological hypothesis and licenses no biomarker cohort, eGFR, event, model, null, or bootstrap output.

Even a supportive result cannot establish clinical CKD/chronicity, measured-GFR accuracy, assay interchangeability, causality, benefit from ordering tests, acceptable false-positive burden, cost-effectiveness, treatment benefit, or transportability. Those require authoritative steward evidence and expert review, clinical adjudication/repeated records, measured GFR, or prospective testing decisions, harms, costs, preferences, and downstream outcomes.
