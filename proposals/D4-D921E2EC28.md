## Falsification and interpretation

Let `m=1000/466=2.145922746781116` per 1,000 assays, exactly one endpoint at the fixed capacity.

`interval_robust_supportive` requires every gate, the already-emitted parent label `grip_unique_over_FFM_supportive`, and for all four E,s components: sharp-lower point `Q^L_E,s>=0` and simultaneous lower limit `L_E,s>-m`. Thus neither observed/bounded stratum contribution is negative and uncertainty excludes a loss of one or more findings per 466 assays.

`interval_fragility_adverse` requires every gate, parent support, and at least one component with sharp-upper point `Q^U_E,s<=-m` and simultaneous upper limit `U_E,s<=-m`. Equality is adverse because it is exactly one fewer endpoint at the fixed capacity. This falsifies temporal robustness; it does not prove AF1 superiority overall.

Every other result after parent support is `interval_qualification_inconclusive`: mixed H/D directions, point neutrality with limits crossing -m, a negative point not uncertainty-supported, one stratum supportive and the other unresolved, sparse events, missingness, zero variance, fallback instability, or any integrity failure. Inconclusive is not equivalence.

If the parent is adverse or inconclusive, still compute/report the interval table when inputs are valid but emit `parent_not_supported_interval_nonrescuing`; favorable strata cannot rescue or relabel the parent. The parent AG1:A1, low-UACR, and AG1:AF1 labels remain first and unchanged.

A supportive result means only that a parent-supported equation-phenotype allocation advantage showed no one-event-scale reversal across this prespecified interval split in this selected repeat-assessment cohort. It supports carrying both timing strata into prospective study design. An adverse result means the pooled advantage is interval-fragile and argues against an unqualified prospective grip preference. An inconclusive result leaves transportability unresolved.

None establishes measured GFR, persistent CKD, sarcopenia, mechanism, equitable performance, assay-order chronology, causal treatment benefit, cost-effectiveness, or routine cystatin ordering.
