# Evolution trajectory critique: is process signal a missing temporal state?

Status: independent substantive child proposal of `[prior hypothesis]`. This branch reports no cohort count, fitted coefficient, prediction, metric, or scientific result. It records a pre-specified experiment for the Lead to accept or reject.

## Decision and unresolved question

The parent’s strongest evidence-supported claim is descriptive: laboratory-result and vital-recording intensity/gap features may add a transport-sensitive increment beyond demographic and latest-in-window value summaries, but the increment could reflect measured severity, discharge/EOL selection, or hospital recording practice. The parent already tightens the feature/outcome boundary to [0,360] ICU-relative minutes, makes P12 (discharge offset >720 and no recorded EOL event through 720 minutes) primary, retains S720 and S6, and uses a value-state-matched process null.

The remaining consequential rival is evolving severity inside the existing six-hour window. A single latest value can miss a transient deterioration, recovery, or instability that prompts more observations. Conversely, a trajectory representation can appear to “explain” process density simply because its missingness and timing encode the same recording process. The smallest informative test is therefore not a raw-event model: it is a fixed-bin value trajectory added to the parent’s existing latest-value state, with all explicit observation-process variables kept separate.

The falsifiable hypothesis is:

> In the parent’s P12 population, if the observed lab/vital process increment is principally an unmodeled measured temporal-state proxy, adding pre-specified fixed-bin lab/vital value trajectories from the same [0,360] window will reduce the held-out-hospital process increment beyond the parent latest-value state by more than the 0.01 AUC negligible margin, with corresponding attenuation in calibration or the 10% review net-benefit contrast and no comparable residual in a trajectory-state-matched process null. If the process increment persists after this augmentation, or remains in the trajectory-state-matched null, the available data do not support temporal-state sufficiency; workflow, selection, or unmeasured severity remain better live explanations.

This is a descriptive sufficiency/transportability test. It cannot establish physiology, a monitoring adequacy effect, an order or clinician action, or a causal effect on ICU mortality.

## Clinical importance and advance

If the increment is absorbed by measured trajectories, recording density should not be presented as a stand-alone worsening or monitoring signal; the defensible descriptive carrier is the observed state trajectory, subject to calibration. If it persists after the trajectory test but is attenuated by P12/no-EOL boundaries or concentrated in particular hospitals, the next decision is selection audit, feed harmonization, or clinical adjudication rather than a more complex predictor. If it persists in held-out hospitals and after the trajectory-state null, it is evidence that the current value trajectory is insufficient, not evidence that recording causes mortality.

This advances the parent by testing the exact latest-value weakness while preserving its hospital-held-out P12/S720/S6 estimands, state-matched nulls, lab/vital intensity-versus-gap decomposition, and clinical interpretation limits. It does not add a new source, a post-landmark treatment covariate, or a new clinical endpoint.

[K1] Rajkomar et al. supports the general value of temporally structured EHR histories for cross-center mortality prediction, but does not identify an observation-process mechanism. The present test asks whether a process increment survives a deliberately small temporal-state augmentation.

[K2] Gao et al. (abstract-only inspection) supports treating information presence/missingness as potentially predictive and transport-sensitive, but does not establish whether it represents severity, workflow, or interface behavior. The present design makes explicit value trajectories and process summaries separate channels.

[K3] Hadler et al. supports external discrimination/calibration assessment and local adaptation when EHR patterns differ across hospitals, but does not identify physiology or clinical action. The present design uses the same hospital-held-out logic to test state sufficiency and site-specific recording rivals.

## State and process variables

### Parent state X

Use the parent’s fold-isolated X exactly: age, gender, ethnicity, admissionweight, up to 30 lab analytes selected by training-fold distinct-stay coverage among keys with >=1% coverage, and up to 20 qualifying vital numeric channels selected by training-fold coverage with deterministic name tie-breaks. For every retained lab/vital channel, X takes the latest valid value in [0,360], without carry-forward, with training-fold median imputation. X is a value summary, not proof of physiology.

### New temporal state T

Use the same fold-selected channels as X. For every selected lab analyte and every selected vital field, partition the fixed window into [0,120), [120,240), and [240,360] minutes. Within each channel/bin, compute the median of finite valid values. Standardize using training-fold location/scale and impute an empty channel/bin with the training-fold median for that channel/bin. Do not add missingness indicators.

T is the concatenation of X and these fixed-bin values. It uses no row counts, number of distinct offsets, first/last offset, gap length, observed-bin count, presence flag, result revision timing, treatment, care, discharge, or EOL fields. Thus the explicit recording-process block cannot be reconstructed intentionally from T. An all-empty bin is still audited, but its absence is not a modeled state feature. No carry-forward or interpolation is allowed. If a channel’s training coverage fails the parent rule it is omitted for that fold; test-fold coverage never rescues it.

This representation can reveal a direction or level change that latest X loses, while remaining small enough for a transparent additive fit. It cannot represent unobserved physiology, and imputed values do not make a missing measurement observed.

### Process P

Retain the parent’s four explicit blocks, all computed from valid rows in [0,360] independently of row values:

- lab intensity: log1p(valid row count), distinct exact offsets, distinct 30-minute bins with a valid row, and retained channels observed at least once;
- lab gap: 360 minus last valid offset, largest empty 30-minute run, and fraction of 12 bins without a valid row;
- vital intensity and vital gap: the same definitions, with a value-column observation finite and offset-valid. Duplicate channel/offset rows count for intensity but are set-based for bins/gaps.

P variables are recording proxies, not confirmed orders, specimen collection, bedside measurement, device output, clinician decisions, or interface completeness.

## Baseline, learned alternative, split, estimands, and uncertainty

The simple baseline is elastic-net logistic regression with identical preprocessing and fixed feature blocks. For each process block or full P, fit:

- X-only and X+P;
- T-only and T+P.

The substantive learned alternative is a capacity-matched histogram gradient-boosting model with the same X/T/P inputs, target, folds, preprocessing isolation, random seeds, and uncertainty. It is included because nonlinear interactions between a trajectory change and a gap/intensity block may be invisible to the additive baseline. A predictive gain alone is not evidence for the state explanation; both learners must be read through the same attenuation and null contrasts.

For model m and evaluation e, with error signs oriented so positive is better:

`Q_P^X(e)=metric(X+P,e)-metric(X,e)`

`Q_P^T(e)=metric(T+P,e)-metric(T,e)`

`A_T(e)=Q_P^X(e)-Q_P^T(e)`.

Report AUC, AUPRC, Brier, calibration-in-the-large, calibration intercept/slope, alert burden, and decision-curve net benefit at 5%, 10%, and 20%. ## State-matched nulls and selection/documentation rivals

Preserve the parent’s unrestricted same-hospital process permutation, parent X-state null, and +180-minute offset displacement as secondary controls. Add one pre-specified trajectory-state null:

1. Fit the value-only T risk score within each training partition; use out-of-fold T risk for training stays and the fold-fitted score for held-out hospitals.
2. Form cells from risk quintile plus age bin, admissionweight bin, gender, and ethnicity. Merge only cells with fewer than 10 stays with the adjacent quintile, saving every merge.
3. Within hospital and cell, cyclically reassign complete P vectors using SHA-256(`"eicu-trajectory-state-null-v1\\0"+patientunitstayid`). Keep X/T, hospital, outcome, and all population flags fixed; never use outcome or P for assignment.
4. Fit/evaluate the null with the same learner, folds, predictions, metrics, and bootstrap indices. Compare observed `Q_P^T) to the null increment and retain separate lab-intensity, lab-gap, vital-intensity, vital-gap, and joint nulls.

The new null asks whether process linkage persists after a richer observed value state is matched. It is not causal matching and does not remove unmeasured severity or within-cell hospital practice.

Rival-specific observations:

- Unmeasured or evolving severity: the process increment falls materially from `Q_P^X) to `Q_P^T), with the observed trajectory-state null showing corresponding attenuation. This supports measured temporal-state sufficiency only; it does not identify physiology or eliminate unmeasured severity.
- Terminal decline/early-discharge selection: a process increment present in S6/S720 but absent or materially smaller in P12/no-EOL12, or strongly concentrated in hospitals/strata with altered boundary composition. The experiment does not infer a death time and cannot distinguish early death from early discharge when the fields do not provide that evidence.
- Hospital recording practice: persistence in the trajectory-state null, large held-out hospital heterogeneity, a gap-dominant effect, or a positive null increment despite similar T/outcome distributions. This is compatible with workflow/feed behavior, not proof of an outage or clinician practice.

## Falsification and interpretation

Support for the specific temporal-state sufficiency hypothesis requires all of the following on the prespecified P12 external estimand, with directionally coherent internal results and learner agreement:

1. `Q_P^X(external)>0.01) AUC (or corresponding calibrated/policy signal) establishes that there was a non-negligible parent process increment to explain.
2. `A_T(external)>0.01) AUC and `Q_P^T(external)<=0.01) AUC, with paired uncertainty intervals reported; the analogous 10% net-benefit attenuation exceeds 0.005 where the parent increment is present.
3. The observed trajectory-state process increment is larger than the trajectory-state-null increment, or the null attenuates comparably, and the result is not confined to one hospital.
4. The attenuation is directionally retained in S720 and S6, while P12/no-EOL12 is not rescued by changing the window, outcome, or subgroup.

This supports “the tested value trajectory explains much of the recorded-process increment” and no stronger claim.

The temporal-state sufficiency claim is falsified for this data if P12 external `Q_P^T) remains above the 0.01 AUC margin with an interval excluding the margin, or if `A_T) is below the 0.01 attenuation margin while the parent process increment is present. That result leaves residual process information, workflow, selection, or unmeasured severity alive. It does not prove a clinical mechanism. Persistence in the null, gap dominance, or one-hospital concentration strengthens the documentation/workflow rival. A positive S6/S720 increment that disappears in P12 supports a boundary-dependent selection interpretation, not an EOL causal claim.

Adverse evidence is an interval wholly below the negligible margin for the process increment with no calibration or policy support after technical checks. Inconclusive evidence includes intervals spanning the margins, fewer than five viable hospitals or fewer than 100 P12 events, excessive trajectory imputation/coverage collapse, unstable state-cell merging, unstable IPW effective sample size, material fold/channel-selection instability, Apache-label discordance that prevents a usable audit, or failed source/join/leakage checks. An imprecise null is not refutation.

## Alternative methods and resource decision

The retained baseline/alternative pair is elastic-net additive blocks versus capacity-matched histogram GBM. Inputs, target, [0,360] fitting window, hospital-held-out split, state-null assignment, metrics, and paired bootstrap are identical. The baseline exposes direction and domain attribution; the GBM can reveal nonlinear trajectory-by-process interactions that the baseline loses. The planned future solver envelope remains 16 CPUs, up to 262,144 MiB RAM, and 28,800 seconds; this is a planned estimate, not a measured full-study runtime. The current discovery verified source/schema availability but did not fit the study or measure full extraction time. A bounded readiness probe should time selected-column extraction and one outer-fold fit before execution.

CPU is selected: this is tabular gzip extraction, fixed-bin aggregation, five hospital folds, two learners, null permutations, and cluster bootstrap. An A100 would not resolve the severity-versus-workflow ambiguity; GPU use is neither prohibited nor scientifically informative here. A raw-event neural/sequence encoder is deferred because the smallest question is whether fixed-bin measured values suffice, the available fields lack order/specimen/device/interface semantics, and a larger representation would make the attribution harder. Revisit it only if the bounded diagnostic shows that fixed bins lose clinically relevant ordering and the same P12/S720/S6 estimands, nulls, uncertainty, and held-out hospitals can be preserved. A hierarchical hospital random-effects model is also deferred: it can describe heterogeneity but can absorb the site behavior that the held-out test is meant to expose. A causal monitoring/testing or EOL intervention study is unavailable without intervention assignment, order/specimen timestamps, clinician rationale, reliable death time, and adjudication.

## Missing evidence and verifier boundary

The available fields cannot establish whether a row is an order, specimen result, bedside measurement, device aggregation, interface transmission, or clinician decision; they also lack a reliable death timestamp and treatment assignment. `carePlanEOL` is a recorded care-plan field, not an adjudicated goals-of-care decision; a missing row is not proof that no decision occurred. Apache `actualicumortality` is an audit field, not an independent gold standard for the parent ICU-discharge label. Clinical interpretation requires source-level measurement validation, order/specimen/device/interface timestamps, clinician adjudication, and prospective silent-deployment/impact evaluation. No result licenses a change in monitoring, treatment, or goals-of-care practice.

The verifier can check exact source hashes, table/column bindings, joins, offsets, cohort flags, no-use of post-window fields, training-only preprocessing, channel selection, fixed bins, trajectory imputation, process definitions, fold isolation, null assignment, predictions, metrics, bootstrap intervals, and whether conclusions cite computed output rows. It cannot automatically adjudicate physiology, clinical utility, causal mechanism, terminal decline, or whether a process feature reflects hospital workflow. Those claims require the missing evidence or another study.

## Alternatives not chosen and revisit evidence

The deferred raw-event sequence model would become appropriate only if a bounded, pre-registered comparison shows that three fixed value bins materially lose ordering information relevant to the process attenuation contrast, not merely if it improves AUC. A richer latent trajectory model would require the same target, folds, process null, uncertainty, and a demonstrated information loss in T.
