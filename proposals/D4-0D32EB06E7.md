# Repeated biomarker history: prospective value when certified, record-triage value when it is not

Parent: [prior hypothesis]

## Scientific question and evidence boundary

When a participant has two measurements of an eight-field blood-biomarker panel, does retaining the earlier panel add clinically useful information beyond the later panel, age, and sex?

The clinically important hypothesis is that within-person change from instance 0 to instance 1 improves held-out identification of a first later recorded cardiorenal/metabolic two-domain event. This is a monitoring and risk-triage hypothesis, not a causal claim about ordering tests, treatment, or outcomes.

The strongest available evidence supports only the presence of paired field-instance columns, participant joins, assessment-date fields, and position-paired recorded code/date arrays. The local evidence does not establish analyte identity, units, assay quality, exact specimen dates, disease onset, or complete observation. The unresolved claim is incremental prognostic value of change, and it must remain unresolved if the gates fail.

## Population and primary prospective estimand

After join audits, include participants with dictionary-verified numeric values for all 16 exposure cells, valid age/sex, valid `T0=53-0.0` and `T1=53-1.0`, `T1>T0`, and `T1<=2013-12-31). Require a prespecified minimum interval of 0.25 years and an upper interval bound fixed before fitting; exclude impossible intervals. Require a field/protocol record showing instance 0 was collected at or around T0 and instance 1 at or before T1. Without that record, this branch is temporally unresolved and cannot be labelled prospective.

Define the primary horizon as five calendar years after T1, ending no later than 2018-12-31. Exclude participants with a valid target-domain record on or before T1, explicitly meaning no recorded event in these arrays rather than disease-free. Domains are metabolic E10--E14, renal N18--N19, and cardiovascular I20--I25 or I50. The target event is the earliest post-T1 date at which two distinct domains have valid same-position code/date pairs; same-date domains count together. Death is the earliest valid date in `40000-0.0/1.0`, treated as competing and assigned on a same-day tie.

Require an ascertainment certificate for complete diagnosis/date and death capture through each participant's five-year horizon, or defensible individual observation-end dates. Empty arrays, a row in the table, or the maximum observed date are not evidence of follow-up completeness. If the specimen-alignment or ascertainment gate fails, output the gate result, join audit, flow counts, and integrity checks only; do not fit or interpret a prospective model.

For a passed gate, compare five-fold out-of-fold M0 current-only and M1 trajectory models using the same discrete-time cause-specific hazard family, fold-local imputation/scaling/tuning, target cumulative incidence, and competing-death/censoring rules. M0 contains eight instance-1 values, age, sex, T1 calendar year, and elapsed interval. M1 adds eight annualized changes `(instance1-instance0)/((T1-T0)/365.2425)`; raw change is sensitivity. Primary estimand is `DeltaBS5=BS5(M1)-BS5(M0)`, with lower better. Report 95% participant-clustered bootstrap intervals, calibration intercept/slope, time-dependent discrimination, decision-curve contrasts at 0.05 and 0.10, joint change-block inference, and fold heterogeneity. A learned M2 adds only prespecified current-by-change interactions and uses a fold-tuned gradient-boosted cause-specific hazard model; grouped current/change/timing/interaction summaries are required.

## Valid fallback estimand if timing or ascertainment cannot be certified

This branch is not a claim that a failed primary gate has been repaired. It answers a related record-triage question: among participants with paired panel values and a nominal second assessment date, does instance 0 improve held-out classification of already-recorded multimorbidity by that assessment?

Use the same exposure, covariates, joins, code/date pairs, and numeric/code dictionaries. Set `A_i=T1=53-1.0`. Define `Y_record=1` if, by A_i, at least two distinct target domains have valid same-position code/date pairs; `Y_record=0` if not. The negative label means “not recorded under this operational rule by A_i,” not absence of disease. Do not call this incident, prospective, current-specimen, or risk-of-disease prediction. No future ascertainment certificate is needed, and no specimen-date alignment is asserted; the estimand is an association between nominal biomarker fields and an assessment-bounded record status. Participants with no valid T1, invalid code/date pairing, or unresolvable numeric/mapping codes are excluded and counted.

Fit M0 and additive M1 with the same deterministic participant-level five-fold split, fold-local preprocessing and regularized logistic loss; M2 is a fold-tuned gradient-boosted logistic model with the same inputs plus current-by-change interactions. Primary fallback estimand is `DeltaBrier_record=BS(M1)-BS(M0)`; report log loss, Brier score, AUROC/AUPRC where defined, calibration, decision-curve net benefit for prespecified record-review thresholds, joint change-block inference and 95% cluster-bootstrap intervals. Require sensitivity analyses using strict versus permissive date/code rules, no-date-code exclusions, and complete-case/missingness selection audits. This fallback is useful only as reproducible record prioritization; it cannot justify repeat testing, treatment, screening, causal, mechanistic, onset, or transport claims.

## Falsification and interpretation

For both branches, enforce participant-level separation, fold-local imputation/scaling/tuning, no outcome/death fields in exposure construction, exact same-position code/date pairing, and a machine-readable leakage audit. Permuting change vectors within age/sex strata should remove any incremental M1 signal while preserving current values and outcomes. Breaking code/date positions or permuting outcome dates must not improve the primary statistic. Report missingness and eligible-versus-complete flow rather than silently changing the population.

Prospective support requires both gates, at least 100 target events, DeltaBS5 95% upper bound below zero, positive net benefit at both analysis thresholds without material calibration degradation, and compatible raw-change, tie, and domain sensitivities. Adverse evidence is near-null/worse M1, a confidence interval excluding useful improvement, no decision benefit, or disappearance under permutation/integrity controls; it favors current values alone for prospective prognostic use. Inconclusive evidence includes a failed gate, inadequate follow-up, fewer than 100 events, intervals spanning useful gain and harm, fold/endpoint instability, or missingness-dependent conclusions.

Fallback support means only reproducible improvement in held-out classification of `Y_record`, calibrated and robust to date/code sensitivities, sufficient for a record-review triage hypothesis. Fallback adverse evidence favors instance-1 values alone for that record-status task. Fallback inconclusive evidence includes unstable labels, poor calibration, sparse positives, or a result dependent on permissive coding. Neither fallback outcome updates the prospective claim.

Computationally checkable claims include headers, schema bindings, `eid` joins, value/date parsing, code/date positions, fold separation, preprocessing locality, model outputs, uncertainty, and the two estimands' numerical metrics. Whether codes are true diagnoses, whether specimens align to visits, whether outcomes are completely captured, whether repeat monitoring benefits patients, and whether thresholds or treatment changes help require external documentation, clinical adjudication, a prospective intervention, or validation in another cohort.

## Alternatives and scientific deliverable

The actual deliverable is newly fitted M0, M1, and M2 for the prospective branch if both gates pass, or for the explicitly labelled record-status fallback when the primary cannot be estimated. Outputs must include gate certificates, exact flow and joins, fold assignments, preprocessing records, held-out predictions, uncertainty, calibration, decision curves, joint change inference, grouped learned patterns, and falsification controls. A gate failure is a valid feasibility result, not support or refutation.

A mechanistic signed-deterioration score is retained but deferred because the catalog lacks verified analyte units, assay/batch quality, exact specimen dates, a validated direction of harm, and more than two dated measurements. The AKI/kidney-discordance alternative is deferred because no adjudicated AKI outcome, serial creatinine/urine-output trajectory, or treatment context is bound. A disease-history sequence model is deferred because this design has only two biomarker instances and no verified dated disease-history sequence. These branches should be revisited only if those dependencies are supplied. The learned M2 alternative is retained because interactions can reveal scientifically relevant discordant current-versus-history patterns, not merely because it is more complex.
