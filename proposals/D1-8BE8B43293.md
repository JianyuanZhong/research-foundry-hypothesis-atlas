# Early post-TACE lab trajectories versus static, latest-level, care-process, and treatment-intensity rivals for 90-day non-TACE hospitalization

## Executive hypothesis

Among patients undergoing their first recorded transarterial chemoembolization (TACE) for hepatocellular carcinoma (HCC), the unresolved question is whether **prespecified within-admission laboratory trajectory information** predicts **non-TACE hospitalization within 90 days after index discharge** beyond:

1. **Static pre-TACE severity**: demographics, index year and department, pre-TACE core laboratory levels, and index-encounter diagnosis flags.
2. **Latest-level severity**: the latest pre-discharge level of each core assay.
3. **Care-process severity and measurement practice**: index and post-TACE length of stay, number and timing of post-TACE laboratory results, and missingness indicators.
4. **Bounded treatment-intensity proxies**: procedure-row counts, same-day non-TACE procedures, and non-drug order counts.

The primary claim to be tested is an **incremental prognostic-information claim**, not a causal or mechanistic claim. A trajectory signal would support near-discharge risk stratification and prospective validation; a well-powered null would discourage using routine within-admission changes when static and latest levels already capture the risk.

## Clinical importance

Post-TACE deterioration can begin before clinical instability is obvious. If trajectories add information beyond current severity and care-process intensity, they could help time discharge and prioritize follow-up. If they do not, clinical attention and resources should remain focused on baseline liver reserve, latest levels, and care-process factors. This distinction affects a common decision—how intensely to monitor patients after first TACE—without asserting that the laboratory changes cause readmission.

## Key references and scientific boundary

- **[K1] Kohla et al. 2015** prospectively studied 102 Child-Pugh A patients after TACE. Post-TACE INR, bilirubin, ALT, AST, and albumin changed, but baseline tumor size, AFP, and albumin predicted one-month decompensation. This supports the clinical relevance of post-TACE laboratory changes but does not establish incremental near-term hospitalization prediction.
- **[K2] Han et al. 2020** showed that post-TACE radiologic response added prognostic information to baseline factors for overall survival in a large multicenter TACE cohort. This motivates testing earlier routinely available post-treatment information, but its endpoint is survival and its response measure is not available at discharge.
- **[K3] Farinati et al. 2016** established and validated the albumin-bilirubin (ALBI) prognostic system. This creates a strong static liver-function rival; trajectories must add information beyond baseline albumin, bilirubin, and other routine risk markers.

None of these works tests the near-discharge increment against latest-level, order-density, LOS, or treatment-intensity rivals. The proposed study addresses that narrower unresolved question.

## Exact cohort construction

Perform the following steps in order and retain every exclusion count in `cohort_flow.json`.

1. **Parse encounters.** Read the seven required encounter columns. Parse `入院时间` and `出院时间` as `%Y-%m-%d %H:%M:%S`. Keep rows with nonmissing `患者主索引`, `就诊号`, `年龄`, `性别`, `入院时间`, `出院时间`, and `就诊科室`, and with `入院时间 <= 出院时间`.
2. **Resolve encounter duplicates.** Group by `患者主索引` + `就诊号`. If multiple encounter rows have identical required fields, retain one. If they conflict, exclude the key as ambiguous and record the count; do not silently choose a row.
3. **Identify first TACE.** In `procedures`, require `str(手术).str.strip().str.upper() == "TACE"` and nonmissing parsed `开始时间`. For each `患者主索引`, select the earliest TACE row by `开始时间`; break exact ties by `就诊号` and then source-row order, and report tie count.
4. **Match to one index encounter.** Inner-join the first TACE to `encounters` on `患者主索引` + `就诊号`. Require `入院时间 <= TACE开始时间 <= 出院时间`. Exclude unmatched or out-of-interval procedures.
5. **Define the primary analytic cohort.** For each index encounter, require at least one numeric pre-TACE result and at least one numeric post-TACE result for every core assay listed below. Numeric means `pd.to_numeric(定量结果, errors="coerce")` is finite. Exclude rows with nonpositive age. One patient contributes exactly one row.
6. **Ensure 90-day administrative follow-up.** Define `snapshot_end` as the maximum parsed `入院时间` in the complete `encounters` source. A patient is eligible for the primary outcome only if `index出院时间 + 90 days <= snapshot_end`. Exclude otherwise as administratively censored and report the count by split. This prevents classifying incomplete follow-up as event-free.
7. **No outcome leakage into predictors.** Predictor fields are restricted to the index encounter and to laboratory timestamps from `入院时间` through `出院时间`. Later encounters are used only to determine the outcome.

The prior discovery count of approximately **4,471 first-TACE patients** is a feasibility observation, not a result and not the final analytic cohort count.

## Prespecified laboratory assays and windows

Use only exact assay names in `检验`; cross-assay pooling is prohibited because `labs` has no unit column.

**Core assays (8):** `总胆红素`, `白蛋白`, `肌酐`, `国际标准化比值`, `血小板计数`, `丙氨酸氨基转移酶`, `甲胎蛋白`, `活化部分凝血活酶时间`.

For each assay:

- **Pre-TACE baseline:** the latest numeric result in `[入院时间, TACE开始时间)`. Prefer a result within 72 hours before TACE; if none exists, use the latest earlier result in the same admission and set `baseline_outside_72h = 1`. Never carry a value from a prior encounter.
- **Post-TACE sequence:** all numeric results in `[TACE开始时间, 出院时间]`, ordered by `检验时间`. Ties are ordered by source-row order.
- **Latest post-TACE level:** the last value in that sequence.
- **Within-post change:** last post-TACE value minus first post-TACE value; if only one post result exists, set this change to 0 and set the assay-specific singleton indicator to 1.
- **Pre-to-post change:** latest post-TACE value minus pre-TACE baseline.
- **Adverse directional change:** the pre-to-post change multiplied by +1 for assays where increase is adverse (`总胆红素`, `肌酐`, `国际标准化比值`, `丙氨酸氨基转移酶`, `活化部分凝血活酶时间`) and by −1 for assays where decrease is adverse (`白蛋白`, `血小板计数`). `甲胎蛋白` has no prespecified adverse direction and is analyzed only as a signed level/change and in the exploratory full-shape model.

## Exact model inputs

All continuous predictors are standardized using training-split median and interquartile range, then applied unchanged to validation and test. Continuous predictors are winsorized at the training 1st and 99th percentiles before standardization. Categorical levels unseen in training are pooled as `Other`.

### M0 — static pre-TACE baseline

- Age (years) and sex (`男`/`女`).
- Index calendar year, continuous.
- Department: one-hot encoding of training departments with at least 50 index patients; all others are `Other`.
- Pre-TACE levels of all eight core assays.
- Hours from baseline laboratory result to TACE start and assay-specific `baseline_outside_72h` indicators.
- Index-encounter lexical diagnosis flags: HCC (`肝细胞癌` or `肝癌`), cirrhosis (`肝硬化`), hepatitis B (`乙型肝炎` or `乙肝`), portal hypertension (`门静脉高压`), ascites (`腹水`), and varices (`静脉曲张`). These are encounter-level flags; the diagnosis table has no timestamp.

### M1 — latest-level, LOS, and care-process rival

M0 plus:

- Latest pre-discharge level of each core assay.
- Index LOS: `出院时间 − 入院时间`, in days.
- Post-TACE LOS: `出院时间 − TACE开始时间`, in days.
- Time from TACE to first post-TACE core-lab result, in hours.
- Time from latest core-lab result to discharge, in hours.
- Count of post-TACE core-lab results.
- Count of distinct post-TACE core-lab timestamps.
- Assay-specific indicators for one post-TACE result.
- Assay-specific indicators for baseline obtained more than 72 hours before TACE.

M1 is the principal rival model. It contains current severity, observation duration, and measurement intensity, so a trajectory increment cannot be explained merely by a sicker patient staying longer or receiving more laboratory tests.

### M2a — primary prespecified adverse-trajectory model

M1 plus, for each of the seven assays with prespecified adverse direction:

- adverse pre-to-post change;
- within-post last-minus-first change, signed in the adverse direction;
- an indicator that both changes move in the adverse direction;
- an indicator for a single post-TACE result.

The primary scientific increment is **M2a versus M1**. It tests whether directional early change adds information after current levels and care-process factors.

### M2b — exploratory full-shape model

M2a plus all non-adverse/signed `甲胎蛋白` trajectory features and assay-specific absolute within-post change. M2b is secondary, must be labeled exploratory, and is not used to rescue M2a.

## Missing-data handling

- **Primary analysis:** complete-case for all eight core assays (at least one pre and one post numeric result each). One-post assays remain eligible; their trajectory changes use the singleton rule above.
- **Imputation sensitivity:** for patients excluded only because one or two core assays are missing, impute each missing baseline/latest value using the training-split median conditional on split and observed core assays. Add explicit missing indicators. Apply training medians without recomputation on validation/test. Fit M1, M2a, and M2b again.
- **Reduced-core sensitivity:** retain only the six assays with the lowest observed missingness in the training split, refit M1 and M2a, and report whether the direction and magnitude of the increment remain stable.
- **Leakage control:** no outcome, later-encounter, or post-discharge information enters imputation or feature standardization.
- **Reporting:** report missingness by assay, split, outcome, and year; compare complete-case and imputed cohorts on age, sex, department, LOS, and event rate.

## Primary outcome and event handling

The primary endpoint is **first non-TACE hospitalization within 90 days after index discharge**.

1. For each patient, find later `encounters` rows with the same `患者主索引` and `入院时间 > index出院时间`.
2. Consider an admission eligible only if `入院时间 <= index出院时间 + 90 days`.
3. Exclude an admission from the event search if its `就诊号` has any exact TACE row in `procedures` (same trimmed uppercase rule). Scheduled and unscheduled TACE admissions cannot be distinguished, so both are excluded.
4. The event time is the earliest remaining admission `入院时间`. The risk window remains anchored to index discharge; it is not reset by an intervening TACE admission.
5. Event indicator is 1 if such an admission exists and 0 otherwise, among patients with complete 90-day administrative follow-up.

This is a hospitalization endpoint, not an adjudicated unplanned-readmission endpoint. Out-of-system care, death, and emergency visits not recorded as encounters are unavailable.

Among primary events, define hepatic decompensation if the event encounter’s `诊断名称` contains at least one of:

Evaluate M1 versus M2a for this secondary outcome using the same split and complete-case population. Diagnosis strings are not clinician-adjudicated, so this analysis can suggest physiological concentration but cannot establish mechanism.

3. Brier score, calibration slope, and calibration-in-the-large on test predictions.
4. Decision-curve net benefit at thresholds 2%, 5%, and 10%, and paired M2a−M1 net-benefit differences.

## Sensitivity analyses

1. **No diagnosis flags:** refit M1 and M2a without lexical diagnosis flags because diagnosis rows lack timestamps and could encode post-TACE conditions.
2. **Order-density rival:** replace lab counts and distinct timestamps with per-post-TACE-day rates and repeat the primary comparison.
3. **Treatment-intensity proxies:** refit M1 and M2a with:
   - total procedure-row count in the index encounter;
   - TACE-row count;
   - non-TACE procedure-row count;
   - same-day non-TACE procedure indicator;
   - total non-drug order count within the index admission;
   - post-TACE order rate per day.
4. **Long-stay sensitivity:** exclude index stays longer than the training 99th percentile and repeat M2a versus M1.
5. **Baseline-window sensitivity:** restrict baseline to results within 72 hours before TACE and repeat the analysis.
6. **Complete case versus imputation:** compare primary and imputed estimates as specified above.

Treatment-intensity proxies are not true treatment intensity: embolization extent, chemotherapy dose, tumor number, and selective versus lobar treatment are unavailable.

## Supportive, adverse, and inconclusive criteria

### Supportive

All four conditions must hold:

1. Development-set likelihood-ratio/profile-likelihood evidence for M2a over M1 with multiplicity-adjusted two-sided `p < 0.025` (Holm correction for the primary and exploratory trajectory families).
2. Test ΔAUC ≥ 0.02, with the paired bootstrap 95% confidence interval excluding zero.
3. M2a calibration is not degraded: test calibration slope between 0.80 and 1.25, absolute calibration-in-the-large ≤ 0.03, and Brier score no worse than M1 by more than 0.005.
4. M2a net benefit exceeds M1 by at least 0.005 at the 5% threshold, with the bootstrap 95% confidence interval excluding zero; report the same at 2% and 10%.

A supportive result supports prospective validation of near-discharge trajectories. It does not prove causality, biological mechanism, or readiness for clinical deployment.

### Adverse

All of the following must hold:

1. At least 100 test events and at least 1,000 complete-case test patients.
2. The paired ΔAUC 95% confidence interval lies entirely at or below 0.02.
3. No net-benefit gain of at least 0.005 at 5% with a confidence interval excluding zero.
4. Calibration is not materially better for M2a than M1.
5. The conclusion is stable across complete-case, imputation, no-diagnosis-flag, order-density, long-stay, and treatment-intensity sensitivity analyses.

An adverse result would mean that, in this snapshot, routine within-admission trajectories do not add clinically material information beyond static and latest levels plus care-process factors. It would not rule out signals requiring richer measurement, external systems, or longer observation.

### Inconclusive

Classify as inconclusive if any of the following occurs:

- fewer than 100 test events or fewer than 1,000 complete-case test patients;
- the ΔAUC confidence interval includes zero but its half-width exceeds 0.03;
- complete-case and imputation analyses move in opposite directions with materially different conclusions;
- calibration is unstable (slope outside 0.75–1.30) for both M1 and M2a;
- separation, sparse departments, or temporal shift prevents stable fitting;
- the primary analytic cohort falls below 2,000 patients after complete-case and administrative-censoring exclusions.

An inconclusive result is a valid scientific outcome and must not be described as evidence of no effect.

## Method exploration and compute decision

- **Simple baseline M0:** transparent static model, useful as the minimum clinically interpretable comparator.
- **Substantive alternative M2a:** directly tests prespecified directional trajectory information against a strong latest-level and care-process rival.
- **Exploratory M2b:** tests whether richer shape adds information, but cannot substitute for the prespecified M2a comparison.
- **Learned sequence model:** deferred. The unresolved scientific question is an explicit incremental-information comparison, not maximizing predictive accuracy. A neural sequence learner would add tuning, opacity, and data demands without clarifying which rival explains the association. If M2a is robust, a regularized sequence model is a justified secondary study.
- **CPU/GPU choice:** CPU is appropriate. The expected tabular cohort is a few thousand patients, and fixed logistic fits, bootstrap intervals, and decision curves are computationally light. GPU use would not address a scientific limitation.

## Clinical-adjudication and evidence limits

- Diagnosis flags and secondary decompensation outcomes are lexical, not adjudicated.
- The data cannot distinguish planned from unplanned non-TACE admissions.
- Death, out-of-system hospitalization, emergency visits outside `encounters`, and medication adherence are unavailable.
- TACE dose, embolization extent, tumor burden, vascular invasion, performance status, Child-Pugh class, and radiologic response are unavailable.
- Lab units are absent, so cross-assay standardization must use within-assay training transforms only.
- Department and ordering practices may change over time; the temporal split tests transport but cannot remove all process drift.
- A stronger deployment claim requires external validation, adjudicated unplanned hospitalization, mortality linkage, detailed TACE procedure data, imaging-based tumor burden, and prospective measurement.
