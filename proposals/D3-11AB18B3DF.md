# Working proposal (episode 20): Does an Mpos->FLS program need MerTK signalling, donor-intrinsic FLS state, or just Mpos abundance?

Domain: disease_mechanisms. Operation: evolve. Parent: [prior hypothesis]
(valid, board leader mu 32.0; the reference-complete repair of the D3-M2 branch).
Seed: D3-M2 (directional macrophage->FLS crosstalk), benchmarked by D3-M1 and D3-M3.
Status: hypothesis-stage, data-bound. Adds (i) an EVIDENCE-BASED resolution of the parent's
`preInhibitor` vs `Inhibitor` timing ambiguity, (ii) a THIRD rival (donor-intrinsic FLS state) with
a discriminating prediction, and (iii) a fresh EXECUTED bounded binding/effect check (this episode).
NO confirmatory/causal result is claimed.

## 1. Unresolved question (unchanged core, sharpened)
Alivernini 2020 [K1] associates a MerTK+CD206+ (Mpos) synovial macrophage state with drug-free RA
remission, but is cross-sectional and does not show the state DRIVES other joint cells. The parent
asked whether a macrophage->FLS program requires MerTK signalling beyond Mpos abundance. It left two
residual limitations, both closed here:
 (a) ambiguous `preInhibitor` vs `Inhibitor` sample timing;
 (b) donor-dependence with only n=4 matched Mpos inhibitor samples.

Falsifiable claim:
H1 (MerTK-signalling dependence): at MATCHED Mpos composition and FLS donor, MERTK blockade
   (UNC106238 pre-treatment of macrophages) still shifts the co-cultured FLS transcriptome in a
   direction that is NOT collinear with the Mpos-abundance (composition) effect.
H0 (composition/abundance-only rival): the FLS program tracks only how many Mpos macrophages are
   present; the inhibitor arm adds nothing beyond the composition-dose axis.
H2 (NEW third rival, donor-intrinsic FLS state): the FLS donor's baseline (FLS-only) state sets the
   resolution program; the Mpos and inhibitor effects are largely FLS-donor-determined.

## 2. Clinical importance
If H1 holds, MERTK engagement in resolution-state macrophages is an effector node shaping the
fibroblast compartment -- support for MerTK/resolution-directed strategies and a mechanism for why
remission-associated Mpos cells predict drug-free remission. If H0 holds, the remission association
is a composition marker without an independent intra-coculture step -- an argument against
MerTK-directed monotherapy and toward macrophage-composition strategies. If H2 holds, the FLS donor
state (not the macrophage) dominates the readout, redirecting toward a fibroblast-stratification
hypothesis. Each resolution, including bounded inconclusive, changes the next experiment.

## 4. THIRD RIVAL (parent limitation (b) reframed) and the discriminating comparison
Three rival explanations of the FLS co-culture program, each with different observable predictions:
- H1 MerTK-signalling dependence: within FLS donor, inhibitor collapses the Mpos effect.
- H0 Mpos abundance (composition): the FLS program scales with the Mpos FRACTION, donor-independent slope.
- H2 donor-intrinsic FLS state: the FLS donor's FLS-only baseline score predicts the co-culture score,
  and within-donor Mpos vs Mneg vs inhibitor differences are small relative to between-donor variance.
DISCRIMINATING COMPARISON (uses only columns/conditions that exist): the composition titration samples
with the SAME FLS donor (SA258R) and SAME Mpos donor (SA267R) but reversed Mpos:Mneg ratio --
`R2_SA258R_FLS_SA267R_1Mpos_SA266A_3Mneg` (1364 cells) vs
`R2_SA258R_FLS_SA267R_3Mpos_SA266A_1Mneg` (1145 cells) -- together with their FLS-only baseline
`R2_SA258R_FLS_only` (1332 cells).
- H0 (abundance) predicts a monotone dose-response: program(3Mpos:1Mneg) > program(1Mpos:3Mneg), with
  a slope shared across FLS donors.
- H1 (MerTK) predicts the Mpos-vs-Mneg and Mpos-vs-MposInhibitor effect vectors are near-orthogonal
  within donor and reproduce across the n=4 pairs.
- H2 (donor state) predicts `R2_SA258R_FLS_only` baseline score explains more variance of the two
  titration samples than the 1:3 vs 3:1 ratio does, i.e. once the FLS donor is fixed the composition
  slope is small, while cross-donor differences track each donor's FLS-only baseline.
Outcome that separates them: H0 and H2 both predict a positive composition slope, so the decisive test
is whether the slope SURVIVES conditioning on the FLS-only baseline donor factor. A composition slope
that survives donor-conditioning supports H0 over H2; a slope that collapses supports H2 over H0.

## 5. Alternatives on the SAME question (baseline vs substantive model)
BASELINE (simple, pooled): per-gene log2(CPM+1) ~ Mpos fraction f (pooled dose-response) pooled over
all samples; inhibitor effect = paired sign test over the n=4 matched pairs, null by sign-flip
permutation within matched FLS/macrophage donor sets. Inputs: counts matrix + design `condition`/`treatment`.
Target fitted: per-gene intercept and slope on f.
SUBSTANTIVE MODEL (what the baseline loses): donor-aware model = linear mixed model
log2(CPM+1) ~ f + inhibitor + LPS + (1+f | FLS_donor) + (1 | Mpos_donor), PLUS a low-rank factor model
(PCA/NMF, rank 1-3) on the donor x gene pseudobulk that absorbs the dominant donor/composition latent
structure; a "program" is credited only if it survives removal of the dominant donor factor. The
baseline loses the ability to attribute variance to donor-intrinsic state vs composition vs treatment;
the model reports variance components and cross-validated held-out prediction.
Split / held-out: leave-one-FLS-donor-out cross-validation (3 FLS donors with inhibitor pairs;
up to 5 FLS donors total). Uncertainty: nonparametric bootstrap over cells for pseudobulk and over
donors for the mixed model; report CIs, not p-value-only.
Resource budget: pseudobulk 33 samples x 445 features (this panel) is CPU-trivial (<5 CPU-min,
no GPU); PCA/NMF and mixed-model fits with ~200-bootstrap replicates fit well within a CPU allocation
(cpus=4, memory_mb=8192, gpus=0). Device choice: CPU is adequate; GPU adds nothing at this n.
REJECTED alternative (and why): a per-cell neural / scVI-style deep model was REJECTED because with
n=4 matched pairs and 3-5 FLS donors it cannot be identified or validated and adds no discriminating
power over the donor-aware pseudobulk model; it would only add overfitting risk. Evidence that would
justify revisiting: >=8-10 FLS donors with matched inhibitor pairs, where a donor-aware neural
hierarchy could test donor x treatment interactions the mixed model cannot.

## 7. Falsification and outcome meanings
- Supportive (H1): inhibitor effect survives the donor-aware model + low-rank residualization and is
  near-orthogonal to the composition vector, consistent across the n=4 matched pairs.
- Adverse (H0): inhibitor effect is collinear with / fully attenuated by the composition-dose vector
  (residual ~0) -> MERTK arm adds nothing beyond abundance.
- Adverse (H2): composition slope collapses after conditioning on the FLS-only baseline -> donor state
  dominates; macrophage-side effects are not the driver.
- Inconclusive: weak non-zero signal swamped by donor/composition variance, or too few matched sets.
Falsifier: if the inhibitor effect is explained by the composition vector (residual ~0) under the
donor-aware model, H1 is falsified for this readout; if the composition slope is explained by the
FLS-only baseline, H0 is falsified in favor of H2.
