## 0. Hypothesis vs. already-supported conclusion

Already supported (NOT the novel claim): absolute/stress hyperglycemia is *associated* with
short-term ICU mortality (descriptive regularity across cohorts); SHR / relative (acute-on-chronic)
glycemia is reported associated with mortality in MIMIC-IV v3.1 [K2]; HbA1c-derived glycemic-gap
terms can improve model FIT while adding only modest DISCRIMINATION beyond absolute glucose [K3];
lab-test order presence/timing alone predicts survival, so observation processes can manufacture an
apparent effect [K1]. This is settled descriptive regularity, not a mechanism.

Unresolved, falsifiable claim this experiment tries to FAIL (H-rel): at the same absolute admission
glucose `G_adm` and severity, the admission-anchored relative-glycemia ratio carries incremental
28-day-mortality information that is (i) not attributable to `G_adm` and (ii) NOT produced by the
measurement/observation process (who is tested, when, how often, and whether an anchor exists).

Strongest rival (H0): the apparent ratio increment is a measurement-selection / observation-intensity
artifact of the exact form demonstrated by [K1], not a value-carrying physiological signal.

## 4. R1 - First-class PREDECLARED ANCHOR GATE (computable)

Two anchor definitions, both bound to real tables/columns:

- **(a) HbA1c-based anchor** `Gc_hba1c`: `hosp/labevents` itemid **50852** (sens **50854**),
  earliest `charttime` in `[t0-365d, t0+24h]` for the same `subject_id`; label via `hosp/d_labitems`.
  Used ONLY for the negative-control exposure arm / cross-check, NOT for the primary factor.
- **(b) HbA1c-INDEPENDENT anchor** `Gc_indep`: most recent `hosp/labevents` glucose itemid
  **50931** (sens **50809**) with `charttime` in `[t0-365d, t0-24h]` for the same `subject_id`
  (value in `valuenum`, mg/dL). The OMR path is REMOVED (computed to be empty, §3).
  `Gc_indep` is the primary anchor; `RG = log(G_adm) - log(Gc_indep)`.
- **N_anchor** = count of eligible index-stay patients with a qualifying `Gc_indep`.
- **deaths_anchor** = count of those with the 28-day mortality outcome = 1.
- **Predeclared minimum gate**: `N_anchor >= 2,000` AND `deaths_anchor >= 100`.
- **Fallback**: if `N_anchor < 2,000` OR `deaths_anchor < 100`, the primary RG test is
  **UNDERPOWERED -> INCONCLUSIVE** (explicitly NOT a negative result and NOT evidence for H0).
- Feasibility bound (COMPUTED): 289,265 subjects have >= 1 glucose lab and 16,242 subjects have
  >= 2 ICU stays, so the gate is plausibly reachable; the exact windowed yield remains NOT-COMPUTED
  and MUST be computed before the primary fit is read. The gate itself is an executable feasibility
  job (`work/ev37/` design; see resume-note for the exact query).

## 5. R2 - Decouple the observation-intensity rival (predeclared matched comparison)

Predeclared BEFORE fitting:
- **Exposure**: SHR/relative-glycemia `RG` (continuous primary; high-vs-low tertile secondary).
- **Matched comparison**: 1:1 nearest-neighbour (or full matching) of `RG`-exposed (top tertile)
  vs unexposed (bottom tertile) on: (i) **number** of glucose measurements in the admission window
  `[t0-6h, t0+24h]` (and `[t0, t0+72h]`); (ii) **timing** features (time of day, day of week,
  hours from `t0` to first/last glucose); (iii) **propensity to have an anchor measured**
  (HbA1c present in-window; prior glucose present). Match caliper predeclared.
- **Value-free measurement-only negative control (NOW)**: a model using ONLY the measurement-process
  features (counts + timing + anchor-presence propensity), with NO glucose/HbA1c VALUES, predicting
  the same 28-day outcome, on the SAME matched set.
- **Equivalence margin**: `Delta AUC = AUC(B1 with RG) - AUC(value-free measurement-only) <= 0.005`
  is predeclared as "measurement process explains the RG increment" (i.e. the NCO is non-inferior to
  the value-carrying model within the margin).
- **R2 interpretation**: if the RG coefficient/DeltaAUC survives matching AND the value-free control
  is inferior by more than the margin, the increment is less parsimoniously explained by order
  presence alone; if the value-free control matches B1 within the margin, H0 (artifact) is favoured.

## 6. Falsifiers (S1-S4 inherited; wording updated)

- **S1 (label permutation).** Permute `Gc`/`Gc_indep` across subjects (instrumentation and measured
  lab set fixed); refit B0->B1. Under a genuine value signal the RG increment COLLAPSES to the
  equivalence margin; under selection it is driven by *who got measured*.
- **S2 (value-free measurement-only control).** As §5; equivalence margin `Delta AUC <= 0.005`.
- **S3 (negative-control outcome).** A diagnosis plausibly unrelated to acute glycemia must not show
  the same RG increment (falsifies a purely process-driven association).
- **S4 (within-subject discordance).** Among the 16,242 multi-stay subjects (COMPUTED), test whether
  the *within-patient* change in RG tracks the within-patient change in 28-day mortality risk.
  Between-patient confounding/observation-intensity does not replicate within-patient; failure to
  replicate within-subject favours H0.

## 7. Predeclared supportive / adverse / inconclusive rules

- **SUPPORTIVE** of H-rel: after R2 matching, `Delta AUC(B1 - B0) > 0.005` on the locked 30% test
  set with bootstrap 95% CI excluding 0; S1 permutation collapses the increment to <= margin;
  S2 value-free control inferior by > margin; S4 within-subject RG change has the same sign and a
  95% CI excluding 0; R1 gate passes.
- **ADVERSE** (favours H0): `Delta AUC <= 0.005`, OR S2 value-free control non-inferior within the
  margin, OR S1 permutation leaves the increment intact/undiminished, OR S4 within-subject does not
  replicate.
- **INCONCLUSIVE**: R1 gate fails (UNDERPOWERED, per §4); OR CI spans both 0 and the margin; OR
  matching degrades balance beyond the predeclared caliper so the comparison is not identified.
  An inconclusive result is NOT read as support for H0.
