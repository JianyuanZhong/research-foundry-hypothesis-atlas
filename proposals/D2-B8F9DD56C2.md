# Cross-drug context-dependence test in GSE95588: the JAK/STAT context effect is a general property of the MTF context, not drug-specific

## Seed
D2-T1 (Context-specific intervention response)

## Domain
Therapeutic Target Prioritization

## Parent
[prior hypothesis] (JAK A77 context-dependence, mu 31.03)

## Question (falsifiable)
Is the JAK/STAT context-dependence in GSE95588 drug-specific (A77-specific) or a general property of the MTF (macrophage+T cell+FLS) context? Specifically: does the JAK inhibitor A77 (tofacitinib) show a significantly greater number of context-dependent genes (FDR<0.1) or JAK/STAT pathway genes with nominal p<0.05 than the non-JAK drugs auranofin (Aur) and naproxen (Nap)?

## Background
The parent candidate (a7ab5e6c) tested whether the transcript response to the JAK inhibitor A77 (tofacitinib) in synovial macrophage cocultures depends on fibroblast presence (MTF vs MT context). It found 4 JAK/STAT genes (JAK1, TYK2, STAT3, STAT5A) at FDR<0.1 with the Triple vehicle control, and classified the result as INCONCLUSIVE because the finding was control-dependent (0 JAK/STAT genes FDR<0.1 with unstimulated control) and the E-MTAB-8873 validation was unpowered (2/50 top-gene overlap).

The key unresolved question was: is the JAK/STAT pathway-specificity a genuine drug-specific effect (A77 specifically affects JAK/STAT genes in a context-dependent manner) or a general property of the MTF context (all drugs show similar context-dependence because MTF samples have more total cells, creating a bulk composition confound)?

Kuo et al. 2019 [K1] established that drug response in synovial tissue depends on cellular context, with HBEGF+ inflammatory macrophages being redirected by different medications. Hu et al. 2026 [K2] described therapeutic signaling in the RA synovium as context-dependent (stage-dependent, cell type-specific). Wei & Xu 2026 [K3] provided the mechanistic rationale: JAK inhibitors act directly on synovial fibroblasts (lowering IL-6 output), so the macrophage transcript response to a JAK inhibitor should depend on fibroblast presence.

This proposal tests the drug-specificity question directly by comparing 3 drugs (A77, Aur, Nap) across 3 donors in both MT and MTF contexts, using the Triple vehicle as the common control.

## Analysis plan (executed)
1. CPM normalization per sample
2. Per drug (A77, Aur, Nap), per donor: drug effect in each context = log2(CPM_drug/CPM_Triple_vehicle)
3. Context-dependent attenuation = effect_MTF - effect_MT
4. Per gene, per drug: one-sample t-test of attenuation across available donors (scipy.stats.ttest_1samp, sample std ddof=1)
5. BH FDR across 23,710 genes per drug
6. Cross-drug comparison:
   - Genome-wide: count FDR<0.1 genes per drug; Fisher's exact test (A77 vs Aur, A77 vs Nap)
   - JAK/STAT core panel (12 genes): nominal p<0.05 count per drug; Fisher's exact test
7. Classification per pre-specified criteria

### Statistical method note
The parent's script used `statistics.pstdev` (population std, ddof=0) for the t-test, which inflates t by sqrt(n/(n-1)) = sqrt(3/2) ≈ 1.22x for n=3 donors. This analysis uses the correct `scipy.stats.ttest_1samp` (sample std, ddof=1). The parent's reported 5539 FDR<0.1 genes could not be reproduced with the parent's own script (which gives 0 FDR<0.1 with pstdev p-values), suggesting the parent's results.json was produced by a different script version or data. This discrepancy is documented as a limitation.

## Falsification criteria (pre-specified)
- **Supportive (drug-specific)**: A77 has >=2x more FDR<0.1 genes than median of Aur/Nap AND >=5 JAK/STAT core genes nominal p<0.05 for A77
- **Adverse (general property)**: All 3 drugs have similar FDR<0.1 counts (max/min < 1.5) OR 0 JAK/STAT core genes nominal p<0.05 for A77
- **Inconclusive**: Otherwise

**Result**: ADVERSE_GENERAL_PROPERTY (max/min=1.00 < 1.5)

## What the results mean
- **Adverse result (observed)**: The JAK/STAT context-dependence is NOT drug-specific. All 3 drugs show essentially identical genome-wide context effects (23,614-23,677 genes FDR<0.1), and the JAK/STAT panel shows only a non-significant trend toward more p<0.05 genes for A77 (4 vs 3 vs 2). This supports the bulk composition confound explanation: the MTF context (more total cells) creates a genome-wide transcript shift that affects all drugs equally, and the JAK/STAT "enrichment" observed in the parent is a statistical artifact of the genome-wide effect.
- **What would have been supportive**: If A77 had >=2x more FDR<0.1 genes than Aur/Nap AND >=5 JAK/STAT genes p<0.05, this would have supported a drug-specific JAK/STAT context effect.
- **What would have been inconclusive**: If A77 had 1-4 JAK/STAT genes p<0.05 and the FDR counts were not clearly different.

## Limitations
1. **P2_MTF_Nap missing**: Nap analysis uses only 2 donors (P1, P3), reducing power for the Nap comparison.
2. **Triple vehicle is a 3-drug cocktail**: The "drug effect" is a relative effect against a perturbed baseline, not an absolute drug response. The Triple cocktail contains a JAK inhibitor component, so the A77 effect against Triple is a relative JAKi effect.
3. **Bulk RNA-seq composition confound**: The genome-wide context effect (23,600+ genes FDR<0.1) is almost certainly driven by differences in total cell number between MT and MTF samples. This is the dominant signal and makes pathway-specificity questions essentially unresolvable at FDR<0.1.
4. **n=3 donors (2 for Nap)**: Per-gene power is limited. The JAK/STAT panel comparison (4 vs 3 vs 2) is underpowered for a definitive drug-specificity claim.
5. **Donor IDs unresolved**: P1-P3 are column-derived labels, not GSM-verified.
6. **Parent's FDR discrepancy**: The parent's reported 5539 FDR<0.1 genes could not be reproduced with the parent's script (which uses pstdev, giving 0 FDR<0.1). The parent's results.json may have been produced by a different script version. This analysis uses the correct scipy ttest_1samp.
7. **No independent validation**: The cross-dataset validation (E-MTAB-8873) was not repeated in this analysis; the parent's 2/50 overlap remains unpowered.

## Next tests
1. **Single-cell or FACS-sorted macrophage RNA-seq**: Remove the bulk composition confound by analyzing macrophages alone. This is the definitive test for whether the JAK/STAT context-dependence is a per-cell drug response or a composition artifact.
2. **Cell number normalization**: If single-cell data is not available, normalize by estimated cell number (e.g., from total RNA content or housekeeping gene counts) to remove the composition confound.
3. **Additional donors**: P4 has A77 MT/MTF in the GSM metadata but no vehicle in the prepared matrix. Re-deriving P4 data would increase power.
4. **Different vehicle control**: Use unstimulated samples as the control instead of Triple vehicle, to test whether the JAK/STAT context-dependence is vehicle-dependent.
