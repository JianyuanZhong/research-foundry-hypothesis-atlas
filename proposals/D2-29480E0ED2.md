# Context-specific macrophage–fibroblast intervention response

Seed: D2-T1. Parent: [prior hypothesis].

## Question and clinical importance

Does a transcript response associated with a macrophage–fibroblast intervention differ systematically between macrophage and fibroblast contexts, such that a target prioritized from an averaged or single-cell-type signal would be misleading? This matters because macrophage and fibroblast programs can have opposing roles in fibrotic or inflammatory disease: an intervention-associated change in one compartment may reflect a protective response, a pathogenic program, or simply differential cell composition and stimulation. Resolving the question would change whether a target is pursued as context-specific, requires a cell-type-resolved intervention, or is deprioritized.

## Evidence and unresolved claim

The seed and domain guide identify four configured sources: GSE95588 coculture and d1d2d3d4 counts, E-MTAB-8316, E-MTAB-8873 and E-MTAB-8322. These are available as prepared counts and design metadata. The strongest current evidence is descriptive: the datasets contain macrophage/fibroblast-related conditions and intervention-associated measurements, but they do not establish causality or independent validation. The unresolved claim is that the intervention-associated transcript response is context-dependent in a reproducible donor-aware pattern, rather than being explained by donor, stimulation, cell composition, batch, or targeted-assay coverage.

## Data-bound experiment

### Population and temporal boundaries

Use only samples with verified cell-type and condition labels in the corresponding design metadata. For GSE95588, retain the source rows and feature-map records for duplicate/date-like labels; do not merge them. For E-MTAB-8316, use the four FLS donor clusters and six nested monocyte donors, averaging repeated context measurements within each donor/condition before paired exploratory inference. For E-MTAB-8873, use the targeted 445 measured feature columns and preserve transcript identifiers; do not infer absent genes. For E-MTAB-8322, use measured macrophage pseudobulk only and exclude SA149/SA149P from simple independent-donor screens until relatedness is resolved.

Temporal boundaries are the recorded pre-intervention/unstimulated state and the recorded post-intervention/stimulated state within each assay. Do not treat cross-sectional disease or treatment groups as transitions. If an assay lacks a true vehicle/unstimulated control, label that comparison as exploratory and do not call it a causal intervention contrast.

### Variables and outcomes

Primary variable: normalized log2 expression change for each verified transcript from the recorded baseline state to the recorded intervention-associated state, computed within each donor and cell-type context where the design permits. Secondary variables: cell-type context (macrophage versus fibroblast), donor, condition, stimulation, batch/source file, and measured feature coverage. Primary outcome: a context-by-intervention interaction effect, estimated with donor-aware paired or stratified contrasts. Secondary outcome: whether the interaction is reproducible across independent assay contexts without reusing the same donor as an independent unit.

### Analysis and controls

Baseline: donor-aware paired/stratified analysis. Average repeated measurements within donor/condition, then estimate within-donor intervention-associated changes and compare macrophage versus fibroblast contexts using a paired or donor-stratified interaction test. Use vehicle/unstimulated and condition controls only where actually present. Report effect sizes, uncertainty, donor-level dependence, and sensitivity to excluding nested/reused donors.

Alternative: a donor-aware regularized mixed-effect model or a small mechanistic state model, fitted to the same donor-level summaries, could estimate context-specific response and donor random effects while borrowing strength across transcripts. This is scientifically useful only if it improves uncertainty estimation or reveals a reproducible context pattern not captured by the paired baseline. It must not be treated as causal evidence.

### Falsification and interpretation

Supportive: a reproducible context-by-intervention interaction with donor-aware uncertainty, consistent direction in independent assay contexts, and no explanation by cell composition, stimulation, batch, or targeted coverage. This would justify a context-specific target hypothesis and a next wet-lab perturbation test.

Adverse: no reproducible interaction, or the apparent interaction is explained by donor, composition, stimulation, batch, or assay coverage. This would deprioritize context-specific target claims and support an averaged or single-context analysis.

Inconclusive: insufficient independent donors, missing controls, or unstable estimates. This would call for a bounded diagnostic or new evidence acquisition, not a claim of context specificity.

## Competing explanations

1. Donor or selection bias: nested donors and reused donors can create apparent context effects.
2. Cell composition: differences in macrophage/fibroblast proportions can mimic context-specific response.
3. Stimulation or batch: differences in stimulation, batch, or source file can drive apparent intervention effects.
4. Targeted-assay coverage: E-MTAB-8873 measures only 445 features; absent genes are unavailable.
5. Medication response versus direct target action: an intervention-associated expression change does not prove direct target causality.

## Method comparison

The donor-aware paired/stratified baseline is the primary method because it directly tests the context-by-intervention interaction while preserving donor dependence. The learned/mixed-effect alternative could reveal whether a reproducible context pattern survives donor-level uncertainty and transcript-level borrowing of strength. If the baseline is unstable or the alternative does not improve uncertainty, defer the learned model. No GPU is required for the planned CPU analysis.
