# Baseline cystatin-C/creatinine discordance and repeat kidney status: fail-closed assay certification and executable race-free equations

## Lineage, unresolved question, and clinical advance

This is a targeted successor of `[prior hypothesis]`. It preserves the parent’s scientifically useful question, baseline-only feature boundary, observed-schedule estimand, 2–8 year repeat window, and evidence limits. The two compilation defects are repaired by binding every schema reference to an exact absolute path in the current workspace and by specifying an executable, fail-closed certificate interface rather than claiming that unavailable UK Biobank field metadata has been inspected. The 2021 CKD-EPI equations are frozen below with all coefficients and exponents.

The falsifiable question is:

> Among adults with a valid baseline creatinine-based 2021 CKD-EPI eGFR of at least 60 and a qualifying complete first available repeat assessment 2–8 years later, does baseline cystatin-C/creatinine discordance improve baseline-only prioritization of repeat creatinine-equation kidney-status below 60 beyond age, sex, and baseline creatinine-equation eGFR?

The action represented is prioritization of a repeat kidney-function assessment. This experiment does not estimate whether ordering a test improves health outcomes, and it does not identify a clinically actionable threshold.

Existing clinical guidance and prior literature support confirming an abnormal kidney marker and considering cystatin C or a combined estimate when creatinine may be misleading and kidney-function classification affects a decision. That evidence does not establish that this UK Biobank discordance score improves testing decisions, nor that a single pair of measurements establishes CKD chronicity, measured GFR, assay interchangeability, causal benefit, or transportability. The substantive advance is a reproducible, schedule-marginal predictive test with an auditable laboratory-field gate and an explicit boundary around unavailable metadata, rather than an unsupported causal or utility claim.

Public literature may be used only to document general provenance of the 2021 CKD-EPI equations. No private rows, eids, notes, or local files may be sent to public search or retrieval services.

## Required field certificate and hard fail-closed gate

### Certificate status in this workspace

No per-field UKB Showcase/dictionary certificate for fields 30700 or 30720 is supplied in the current workspace. The proposal therefore does **not** claim that 30700 is creatinine, that 30720 is cystatin C, that either is serum/plasma, that values use a particular unit, or that baseline and instance 1 use the same assay. The general 2021 CKD-EPI equation provenance is not a substitute for analyte/units/platform metadata.

Before any cohort count, value conversion, eGFR calculation, outcome construction, model fitting, or release of biological results, the compiler must require a steward-supplied certificate input at a path supplied as a job input, for example `field_certificate.json`. The certificate is an input artifact, not a guessed constant and not a private row projection. If it is absent, malformed, unhashable, stale relative to the declared export, missing any required field, or inconsistent with the raw values, execution must terminate with status `STOP_FIELD_UNCERTIFIED` and nonzero exit code before reading participant data. The run may report only that technical stop; it must not report a biological adverse or inconclusive result.

The certificate JSON must contain, for **each of** `30700-0.0`, `30700-1.0`, `30720-0.0`, and `30720-1.0`:

1. exact field ID and instance/array designation;
2. field label and analyte identity;
3. specimen or matrix;
4. numeric unit and, if applicable, unit conversion factor;
5. assay/platform or measurement method;
6. permitted values or range information and the definition of any special values;
7. instance semantics and whether the field is the same measurement definition at instances 0 and 1;
8. field-specific missing codes, including whether blank/NA is missing;
9. source URL or document identifier, retrieval date, source/version identifier, and SHA-256 of the retrieved metadata artifact;
10. certificate creation date, certificate SHA-256, responsible data steward, and the export/snapshot to which it applies.

The certificate must also state whether `30700-0.0` and `30700-1.0` are harmonized, whether `30720-0.0` and `30720-1.0` are harmonized, and whether any platform or unit change is present. A certificate that says “unknown,” “assumed,” or “likely” for any required item fails the gate. A public web page that cannot be frozen with a hash and version is not sufficient. If authorized metadata cannot be obtained, the correct output is `STOP_FIELD_UNCERTIFIED`; there is no fallback to familiar UKB conventions.

The gate is executable as the following ordered contract, expressed here as normative pseudocode for the compiler:

The gate must be independently rerun by a second implementation. It must emit a private machine-readable certificate result containing `PASS` or `STOP_FIELD_UNCERTIFIED`, certificate hash, schema hashes, source hashes, required-column checks, and reason codes. It must never emit a fabricated “certified” record from the equation reference, field number, or a column name.

After a valid certificate passes, retain raw values and converted values privately. For each field and instance, print aggregate counts only: raw nonblank, certificate-defined missing, nonnumeric/nonfinite, nonpositive, outside certificate-permitted range, and plausible values. Do not publish participant rows or eids. Reproduction of these aggregate counts by an independent implementation is required. Negative values are not globally recoded; only field-specific certificate-defined missing codes are treated as missing. An otherwise unrecognized negative or implausible value fails the positive-finite/plausibility check rather than being silently discarded.

If the certificate documents a unit or platform change, the primary analysis may proceed only with a certificate-defined harmonization rule fixed before outcome inspection; otherwise the run must stop. If harmonization cannot be justified, report technical `STOP_FIELD_UNCERTIFIED`, not a biological result.

## Frozen race-free 2021 CKD-EPI equations

After the field certificate passes, convert biomarkers exactly as certified. Let `Scr_t` be serum creatinine in mg/dL, `Scys_t` cystatin C in mg/L, and `Age_t` age in years at assessment `t`. The equations below are the 2021 CKD-EPI race-free equations, with no race multiplier. Use baseline sex `31-0.0` for both times; do not use repeat sex. Let `Female=1` only for the certified sex code corresponding to female and `Female=0` for male; if the certificate or coding audit cannot establish the sex coding, stop before calculation.

For creatinine alone:

```text
eGFRcr_t = 142
           * min(Scr_t / k, 1)^alpha
           * max(Scr_t / k, 1)^(-1.200)
           * 0.9938^(Age_t)
           * 1.012^(Female)

k     = 0.7 if Female=1, otherwise 0.9
alpha = -0.241 if Female=1, otherwise -0.302
```

For cystatin C alone:

```text
eGFRcys_t = 133
            * min(Scys_t / 0.8, 1)^(-0.499)
            * max(Scys_t / 0.8, 1)^(-1.328)
            * 0.9961^(Age_t)
            * 0.932^(Female)
```

For the combined creatinine–cystatin C equation:

```text
eGFRcr_cys_t = 135
               * min(Scr_t / k, 1)^alpha
               * max(Scr_t / k, 1)^(-0.544)
               * min(Scys_t / 0.8, 1)^(-0.323)
               * max(Scys_t / 0.8, 1)^(-0.778)
               * 0.9961^(Age_t)
               * 1.012^(Female)

k     = 0.7 if Female=1, otherwise 0.9
alpha = -0.219 if Female=1, otherwise -0.144
```

All constants, thresholds, exponents, and female factors are immutable. Implement them in a tested reference function and an independently coded reproduction; test exact equality within declared floating-point tolerance on fixed synthetic values spanning both sides of each min/max breakpoint and both sexes. Do not substitute the 2009 CKD-EPI equation, a race multiplier, an unspecified library implementation, or a formula selected after inspecting results. General equation provenance may cite the 2021 CKD-EPI publication or an authoritative public equation source; that provenance does not certify the UKB field mapping.

Define at baseline and repeat:

* `eGFRcr_t` using `Scr_t`, corresponding age, and the first equation;
* `eGFRcys_t` using `Scys_t`, corresponding age, and the second equation;
* `eGFRcr_cys_t` using both markers, corresponding age, and the third equation;
* baseline discordance `Z = log(eGFRcys_0 / eGFRcr_0)`, only when both certified baseline assays pass.

## Outcomes and prohibited interpretations

The primary repeat outcome is `Ycr = I(eGFRcr_1 < 60)`, a repeat creatinine-equation threshold state over a variable 2–8 year interval. Prespecified secondary outcomes, each reported separately, are `Ycys = I(eGFRcys_1 < 60)`, `Ycomb = I(eGFRcr_cys_1 < 60)`, and the four-level repeat status `(I(eGFRcr_1<60), I(eGFRcys_1<60))`. These are biomarker-derived repeat statuses. They are not CKD, chronicity, measured GFR, kidney failure, or adjudicated disease. Equation disagreement is an assay-dependent sensitivity observation, not adjudicated truth.

## Baseline-only models and estimands

Freeze the feature list and all preprocessing before reading repeat outcomes. No feature may use `53-1.0`, repeat age, repeat biomarkers, repeat completeness, attendance, interval, or any future-derived quantity.

Fit paired, outcome-stratified-round-robin five-fold cross-fitted models over ten fixed repeats. Preprocessing is learned inside each training fold. Use fixed L2 logistic regression, no tuning, and no class weighting.

* `M0`: sex, baseline age, and baseline `eGFRcr_0`, using the inherited fixed natural-cubic-spline basis for age and baseline eGFR plus sex.
* `M1`: `M0` plus one training-fold-standardized linear baseline discordance column `Z`.

Produce paired out-of-fold risks for `Ycr`; rerun the identical frozen pipeline for `Ycys` and `Ycomb` as secondary outcomes. Repeat cystatin C is never a predictor.

The primary fixed-capacity grid is exactly `q=0.01,0.02,...,0.20`, with inherited `q=0.10` displayed for continuity. At each q, select `ceil(q*n)` by out-of-fold risk using a fixed participant-independent tie order. Report event capture, fraction of all events captured, PPV, and `DeltaC(q)=C_M1(q)-C_M0(q)` with paired simultaneous 98% max-|T| bands. This is a ranking estimand, not a threshold recommendation. The evidence gate requires a positive uncertainty-supported and repeat-stable curve throughout the contiguous prespecified capacity region 5–15%; an isolated q or arbitrary event increment is insufficient.

For transparency only, report the assumption-indexed threshold curve for
`p_t={0.001,0.0025,0.005,0.0075,0.010,0.015,0.020,0.030,0.040,0.050,0.075,0.100,0.150,0.200}`:

```text
NB = TP/n - FP/n * p_t/(1-p_t)
```

Include test-all, test-none, and `DeltaNB`. These curves index an externally assumed relative harm-to-benefit exchange rate; it is not estimated here. Without external harms, benefits, costs, preferences, and observed testing actions, no clinically justified net-benefit threshold or clinical-utility claim is identifiable.

Use 4,000 paired participant-bootstrap draws with seed 520241, recomputing complete capacity grids and calibration contrasts. Label intervals as conditional on cross-fitted predictions. Report between-repeat variation, calibration-in-the-large, calibration slope, Brier score, and stratum/risk-bin calibration. Do not make a directional subgroup claim unless the subgroup has at least 1,000 participants and 20 events.

## Falsification, negative controls, and technical integrity

1. **Certificate and source audit.** Independently reproduce exact schema paths, required columns, source hashes, one-to-one joins, certificate hash/provenance, units, field-instance mapping, conversion, and aggregate raw/missing/plausibility counts. Failure is `STOP_FIELD_UNCERTIFIED` or a source-integrity stop and blocks all biological interpretation.
2. **Leakage sentinel.** Audit code and feature manifests to prove that repeat date, repeat assays, repeat age, attendance, interval, completeness, and future-derived fields are absent from M0/M1. A deliberately leaked model may be run only as a private debugging sentinel and cannot support a result.
3. **Fold-aware label null.** For 200 within-baseline-stratum outcome permutations, seed 520242, reconstruct outcome-stratified folds under each permuted label, refit both models, and recompute all capacity and threshold statistics. Compare observed statistics with their statistic-specific empirical null, not zero, using randomized-plus-one tail fractions. If the observed primary curve is not more favorable than the prespecified 98% favorable-tail null envelope, incremental predictive evidence is not certified.
4. **Predictor null.** Permute `Z` within baseline eGFR deciles and sex, preserving the identical folds and preprocessing. Incremental curves should collapse toward their empirical null; persistent gains indicate leakage or implementation error.
5. **Reversed-label control.** Rerun the frozen pipeline for `1-Ycr`. A discordance-specific conclusion cannot depend on an equally large gain for this artificial target.
6. **Timing sensitivity.** Report `[2,3)`, `[3,5)`, and `[5,8]` bands and the secondary equation outcomes without changing the primary estimand. Direction confined to one band or one unadjudicated equation is not a general kidney-status finding.
7. **Selection sensitivity.** Compare complete-case and predeclared weighted descriptive results. Large selection dependence is uncertainty about the observed-schedule cohort, not something to repair with causal language.
8. **Equation reproduction.** Compare the primary implementation against an independently coded implementation on fixed synthetic inputs and aggregate outputs; any mismatch blocks equation-derived outcomes.

A failed technical gate is not evidence of biological harm or evidence that discordance is irrelevant. Keep technical failure distinct from adverse biological findings and from inconclusive statistical results.

## Decision rules and evidence limits

**Supportive for baseline conditional predictive prioritization only** requires: the source and certificate audits pass; M1 is not materially worse calibrated than M0; the simultaneous 98% lower band for `DeltaC(q)` is positive over the contiguous 5–15% capacity region and stable over model repeats and prespecified baseline strata; and the observed improvement survives the empirical label-null and predictor-null checks. Concordance with at least one prespecified repeat-status sensitivity strengthens interpretation but is not required for the primary creatinine-status claim. The conclusion is limited to ranking within the selected complete-repeat UKB cohort.

**Adverse** means that, after all technical gates pass, M1 reproducibly worsens calibration or capacity capture, or the apparent gain is null-compatible, leakage-related, or strongly selection-fragile. This argues against incremental prioritization value in this evidence boundary, not against cystatin C in every clinical use.

**Inconclusive** means that technical gates pass but bands cross zero across the capacity region, results vary materially by repeat or stratum, null refits are incomplete, or only isolated threshold points improve. No threshold recommendation follows.

**Technical stop** means the field certificate is absent, incomplete, unversioned, unhashable, inconsistent with the export, or unable to establish analyte/unit/matrix/platform/instance semantics. The run must terminate before cohort counts and must publish only an aggregate technical-stop record. It must not be relabeled adverse or inconclusive.

Even a supportive result cannot establish benefit from ordering a repeat test, acceptable false-positive burden, cost-effectiveness, downstream treatment benefit, causal utility, CKD chronicity, measured-GFR accuracy, assay interchangeability, or transportability. Those claims require external utility and cost data, prospective observation of testing decisions, clinical expert adjudication, and preferably measured GFR or repeated clinical records. Available data also lack verified raw imaging, raw waveforms, sequence variants, and verified narrative clinical text; none may be implied as present.
