## Bounded primary computation

The primary analysis is M0 (pre-D state plus value-blind opportunity) versus M1 (M0 plus exact current label), with Mopp as the opportunity-only comparator. Use deterministic leave-one-hospital-out folds, assigning all rows for each `patientunitstayid` to one fold. Fold-local imputation, scaling, feature selection, regularization, calibration, state/opportunity cutpoints, and threshold selection are mandatory. Use a fixed low-dimensional prespecified model family (multinomial logistic regression for five-state K probabilities with fixed regularization grid and deterministic tie-break), rather than unconstrained model search. This is not a change to the estimand; it is a reproducibility and compute bound.

Fit each observed fold once, cache out-of-fold predictions and fold manifests, then calculate micro and equal-hospital macro log loss, Brier score, calibration summaries, review-policy tables, and all-row contrasts from those cached predictions. Do not refit an identical observed pipeline separately for every downstream table. A test fold with fewer than two outcome classes remains scored with proper multiclass log loss but is marked site-support-limited; no fold is dropped from micro accounting. Equal-hospital macro is reported only over prespecified supported test hospitals and with its denominator shown.

Use the fixed state/opportunity partition from training-fold cutpoints, crossed with landmark, only as a diagnostic. Supported cells require at least 10 rows per exact arm and 20 total. Never use label, K, H, effect direction, or held-out outcomes to define bins or merge cells. Unsupported cells are unavailable, not pooled post hoc.

## Valid stay-cluster conditional null

The parent row-level instruction cannot simultaneously preserve repeated-stay clustering and arbitrary per-landmark cell counts when rows from one stay occupy different cells. Replace it with this exact constrained null.

For each held-out hospital, define each stay's complete signature before seeing labels as the ordered tuple over all its observed landmarks of `(landmark, training-derived state bin, training-derived opportunity bin, row-availability/status)`. A permutation block contains stays with identical complete signatures. Permute the entire vector of exact labels across stays within each block; never permute individual landmark rows. This preserves every stay's repeated-landmark composition, each landmark's arm counts within each cell, hospital membership, and the within-stay correlation structure of labels. It is a label-exchangeability null conditional on the pre-D signature, not a causal randomization test.

For every proposed permutation, assert vector lengths, unchanged per-cell/per-landmark arm counts, unchanged stay IDs and signatures, and no label outside the two exact arms. Use a deterministic seeded Fisher-Yates generator and 1,000 attempts per supported block set, or all unique permutations when fewer exist. Report attempted and valid permutations per hospital/block, number of unique null arrangements, and the number of hospitals/cells lost. If no block has at least two exchangeable stays, if cluster preservation fails, or if fewer than five hospitals and 20 valid global arrangements remain, the conditional-null claim is inconclusive, never negative. Do not claim the null preserves arbitrary per-row cells when it does not.

Evaluate the null with a fixed-design, bounded statistic: retain the observed fold definitions, preprocessing maps, and model hyperparameters; refit only the M1 label coefficient within each training fold using the cached design matrix and the same deterministic solver, while M0 and Mopp remain cached. This is a computationally explicit conditional randomization diagnostic of incremental label information. The observed primary M1-vs-M0 estimate remains the fully fitted, honest cross-fitted estimate. Null p-values and envelopes are labeled conditional-null diagnostics, not confidence intervals. Do not nest bootstrap replicates inside permutations.

Use stay-cluster bootstrap seed `61061`, target 1,000 valid replicates and minimum 500. Each replicate refits the full *observed* cross-fitted pipeline once, including fold-local preprocessing, and recomputes the primary loss increments, all-row K probabilities/contrasts, supported cells, transport envelope, and fixed review metrics. Cache source-derived endpoint and predictor matrices so bootstrap never reparses source files. Because 74 leave-one-hospital-out fits times 1,000 bootstrap replicates is still expensive, the job must run in deterministic chunks with a hard resource/time budget and checkpoint files. Use one fold-parallel job per chunk only within declared CPU/memory limits; on timeout, preserve completed chunks and emit `bootstrap_status=insufficient_compute`, not a partial confidence claim. A priori reduce to the minimum 500 valid replicates if the declared budget cannot produce 1,000. Never substitute a row bootstrap, unseeded early stopping, or a different model after seeing results.
