The equation section must name a versioned authoritative source and include, in machine-readable form, every constant, exponent, sex convention, age convention, input unit, output interpretation, creatinine conversion, and exact map from each equation input to a required column. ### Canonical certificate digest

To make hashing executable, the certificate file must contain `certificate_schema_version`, `snapshot_id`, `protocol_id`, `claims`, `evidence`, `equations`, and `scientific_interpretation_authorized`, but **must not contain a self-referential digest inside the hashed payload**. Define the canonical payload as UTF-8 JSON with recursively sorted object keys, arrays in listed order, no insignificant whitespace, and no `certificate_sha256` member. Compute `certificate_sha256 = SHA256(canonical_payload)` and record it in the external manifest `inputs/ukb_biomarker_field_certificate.manifest.json` together with the certificate path, byte hash, snapshot ID, and protocol ID. The verifier recomputes both the canonical digest and raw-byte SHA-256; a mismatch stops. This replaces the parents' ambiguous requirement that the certificate contain its own hash.

The required coverage matrix has at least these claim IDs:

The evidence audit must emit an aggregate table of claim ID, support status, number of evidence records, distinct frozen source hashes, and contradiction flag. ## Executable state machine and stop outputs

Record one immutable aggregate transition artifact per state. Allowed states are:

`SOURCE_SCHEMA_PASS -> SEMANTIC_CERT_PASS -> ASSAY_EQUATION_PASS -> TEMPORAL_CERT_PASS -> COHORT_RECONSTRUCTION_PASS -> ANALYSIS_PASS`.

`SOURCE_SCHEMA_FAIL`, `NEUTRAL_STOP_CERTIFICATE`, `NEUTRAL_STOP_ASSAY_EQUATION`, `NEUTRAL_STOP_TEMPORAL`, `STOP_COHORT_RECONSTRUCTION`, and `STOP_ANALYSIS` are terminal states. No transition may skip a state or move backward. A technical stop is not an adverse or inconclusive biological result.

- `SOURCE_SCHEMA_PASS` checks hashes, snapshot, table IDs, required headers, ordinary-file bindings, unique `eid` keys, and overlap agreement. Only structural audit counts may be emitted on failure.
- `SEMANTIC_CERT_PASS` checks manifest byte hash, canonical certificate digest, snapshot/source/schema binding, evidence hashes/locators, claim coverage, and contradiction status. On failure emit only terminal state, reason code, input hashes, and structural audit.
- `ASSAY_EQUATION_PASS` checks certified units/conversions, equation constants and field map, certified missing-code handling, finite positive inputs after only certified handling, and no unapproved recoding. On failure emit no named eGFR, masks, cohort or event result.
- `TEMPORAL_CERT_PASS` checks certified date representation, strict `date_1 > date_0`, deterministic calendar parsing, and the inclusive interval rule. On failure emit no cohort or outcome result.
- `COHORT_RECONSTRUCTION_PASS` checks one-to-one joins, sequential masks, finite values, and expected anchors as diagnostics only. A mismatch stops with `STOP_COHORT_RECONSTRUCTION`; anchors never alter rows.
- `ANALYSIS_PASS` requires fold isolation, finite converged fits, all declared gates, completed bootstrap, and claim-to-output branch consistency.

On any certificate/assay/temporal stop, do not emit named eGFRs, biomarker summaries, B/R/T/S counts, outcome/exposure counts, cells, predictions, model metrics, ranking results, p-values, or bootstrap intervals. Synthetic toy QA may test parsing, state transitions, equations, folds, and stop behavior, but must be in a separately labeled artifact and never merged with UKB output.

## Baseline-only models and estimands

Let `N=|S_A|`. `M0` is ridge logistic regression using sex, a four-column restricted-cubic-spline basis for baseline `eGFRcr_0`, a three-column restricted-cubic-spline basis for baseline age, all 12 products of the eGFR and age bases, and four sex-by-eGFR products. The five eGFR knots are training quantiles `(0.05,0.275,0.50,0.725,0.95)` and the four age knots are training quantiles `(0.05,0.35,0.65,0.95)`, with standard Harrell restricted-cubic truncated-power basis and first/last boundary knots. Center and scale nonbinary columns with training-only means/SDs; zero variance or coincident knots invalidates that fit.

`M1` contains every `M0` term plus exactly `E` and `E*(eGFRcr_0-60)/10`. No continuous cystatin value, repeat biomarker, date, `t`, additional covariate, screening, outcome-guided transformation, or alternate threshold is allowed. Penalize all non-intercept terms equally. Tune each model separately over `10^(-4),10^(-3.5),...,10^4` using nested five-fold unweighted Bernoulli log loss and the largest one-standard-error lambda.

Use ten outer repeats with seeds `[260911,260912,260913,260914,260915,260916,260917,260918,260919,260920]`, five outer folds stratified within all four `E×Y` cells by seeded permutation and round-robin, and inner seed `outer_seed+1000+outer_fold`. Use identical assignments for both models and retain ten out-of-fold probabilities per participant. Average them arithmetically. Clip only log-loss probabilities to `[10^-6,1-10^-6]`; never clip Brier or ranking probabilities and report aggregate clipping counts.

The primary paired contrast is

`Delta_Brier = 1000 * [mean((Y-p0)^2) - mean((Y-p1)^2)]`.

The secondary fixed-capacity contrast is `K=ceil(0.10*N)` and

`Delta_rank10 = 1000 * (sum_{topK(M1)}Y - sum_{topK(M0)}Y)/K`.

Ties use ascending SHA-256 of UTF-8 `direction-A-capacity-v2|` plus the participant identifier; the hash and identifier are never published. This is a schedule-marginal ranking contrast among the same observed attenders, not a testing or treatment policy. Test the Brier contrast first; only if its full supportive gate passes test the ranking contrast. Use paired participant bootstrap over frozen ten-column predictions, seed 260921, 2,000 successful replicates, maximum 2,500 attempts, percentile 95% intervals, and the symmetric null-centered plus-one p-value.

## Falsification and predeclared evidence diagnostics

The primary falsification is an exposure-label permutation performed **within each outer training partition and its inner folds**, with the test-fold exposure left untouched for evaluation and the same feature construction, tuning, seeds, and model dimensions. The permutation is generated from a recorded fixed seed distinct from all primary seeds. Repeat it for all ten outer repeats. A true incremental signal should not be reproducibly recreated by the permuted exposure; a materially positive permuted gain, especially with comparable signs and support, is a leakage/implementation warning and blocks supportive interpretation. This is a diagnostic, not an alternative result or a new hypothesis.

A second negative-control falsifier replaces `E` and its interaction in M1 with a training-fold-only random Bernoulli feature generated from a separate fixed seed, preserving prevalence within each training fold and never using Y or test data. It must not reproduce the primary gain. Failure blocks support and is classified adverse or inconclusive under the declared branch rules.

Also audit, before interpretation, that (i) every outer test identifier is disjoint from all fitting/tuning rows, (ii) removing `t` changes neither row eligibility nor any feature/tuning/ranking input, (iii) M0 beats the intercept-only prevalence predictor, (iv) top-K sets have identical eligible membership and exactly K weighted members, and (v) no result is driven by one outer repeat. These are falsification/audit gates, not post hoc rescue analyses.

## Decision rules and evidence boundary

Supportive requires certificate authorization, all state transitions, exact cohort reconstruction, finite fits, comparator signal, calibration/support/event gates, at least 8/10 positive repeat-specific Brier gains, successful bootstrap, and a positive Brier interval excluding zero with p<0.05. Only then may a positive rank contrast be reported as fixed-capacity concentration. The conclusion is limited to reproducible baseline incremental information for the protocol-defined repeat state among `S_A`.

Adverse means the authorized primary contrast is wholly negative, M1 reproducibly loses calibration while M0 passes, or repeat-specific signs favor M0. This is evidence against incremental information under this frozen comparator and cohort, not evidence that cystatin C has no value elsewhere. Inconclusive means intervals cross zero, metrics conflict, support/calibration/sign gates fail, sparse cells or unstable fits prevent the declared analysis, or bootstrap completion fails. Neutral technical stop means certification/evidence/state prerequisites failed; it is not biological evidence.

Automatic verification can establish file identity, exact columns and joins, certificate digest and evidence coverage, state ordering, certified missing-code handling, equations conditional on certification, cohort masks, fold isolation, no-`t` leakage, model dimensions, prediction arithmetic, falsifier execution, calibration, capacity, bootstrap, and branch consistency. It cannot establish that certificate evidence is truthful beyond its frozen provenance, that an assay is analytically valid or comparable in clinical use, that an estimated filtration value is measured GFR, that threshold status is CKD/chronicity/progression, why anyone attended, outcomes for nonattenders, causal utility, benefit, harms, or transportability. Those require steward metadata, clinical adjudication, external validation, and a prospective decision-impact or randomized study.
