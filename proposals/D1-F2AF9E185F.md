# Deterministic unit matching and evidence-availability repair for the route-blinded documentation-to-actionability bridge

It repairs only the three executable ambiguities identified in that candidate: deterministic matching and ordering for the H1/H2 inventories, separation of the H3 evidence-availability audit from the documentation reproducibility functional, and an explicit eligibility/NA table for no-unit and deferred cases. The inherited primary estimand remains route reproducibility/contamination, not clinical correctness, workflow delivery, safety, benefit, or causality.

## Unresolved question and hypothesis

Stored-text agreement may overstate readiness for a downstream handoff. The falsifiable secondary question is: within an already selected admission packet, can independent route-blinded readers reproduce the exact recommendation units and explicit route-defining fields, and—separately—does the artifact contain explicit information sufficient to specify a next action without inventing a target, modality, timing, recipient, replacement, or conflict resolution?

The hypothesis is that at least one supported inherited atom-route cell will show documentation reproducibility but a nonzero documentation-to-text-actionability gap. A null gap would support only a better specified prospective **silent** data-collection bridge. Neither result establishes that a clinician saw, accepted, communicated, ordered, scheduled, completed, or appropriately acted on the recommendation, nor that any patient outcome occurred.

## Fixed packet, roles, and pre-label availability audit

Use the already selected challenge admissions and existing three 10-minute holistic challenge rows; no new admissions, rows, top-ups, or adaptive selection are permitted. Before real labels, hash and seal the protocol, source manifest, codebooks, rosters, packet ordering, and inherited atlas/sample. A packet contains only the inherited permitted reciprocal pre-`D` radiology chain, permitted admission/death/disposition fields, canonical exact DS artifact and its permitted detail rows, and an availability manifest. It excludes parent labels, route, atom, stratum, weight, challenge status, post-`D` text, and POE/POE-detail.

H1 and H2 receive identical packet content but independently worded codebooks and independent rosters. H1 inventories recommendation units and route-defining fields. H2 performs its own inventory and separately evaluates explicit next-action sufficiency. H3 is a third, independent evidence-boundary audit after H1/H2 seals; H3 never supplies a label to D or A.

The availability manifest is frozen before labels. MIMIC contains note text, note chart/store timestamps, structured admission/service/transfer/ICU proxies, and death/disposition fields, but contains no event log for actual viewing, finalization/signature, communication, responsibility acceptance, order/referral execution, scheduling/handoff confirmation, patient preference/capacity, or follow-up/outcome. Thus H3 codes each actual workflow/outcome fact as `NOT_PRESENT_IN_AVAILABLE_SOURCES` by predeclared source audit unless a permitted structured source genuinely contains that event. A phrase in a note saying that an action occurred is retained as a separately tagged `TEXT_ASSERTION`, never upgraded to `OBSERVED` workflow. `UNKNOWN` is reserved for a source field whose availability is established but whose value is unreadable, contradictory, missing, or unresolved. `CONTRADICTED` requires two permitted source observations that conflict. This prevents absence of an event feed from being misinterpreted as a negative clinical outcome.

## Deterministic atomic inventory and matching

Every panel emits an append-only list of atomic units. A unit is serialized as the tuple

`u=(target_cluster, action_modality, due_interval, polarity, recipient_responsibility, replacement, conflict, source_spans)`.

The codebook supplies finite normalized vocabularies for each field. Normalization is only Unicode normalization, ASCII case-folding, whitespace collapse, and exact codebook mapping; no synonym expansion, coreference resolution, inferred pronouns, or clinical interpretation is allowed. `source_spans` are immutable `(container_id, ordinal/start, ordinal/end)` coordinates, not text snippets copied into a new document. The container IDs are the unique `(subject_id,note_id)` for the radiology/discharge artifacts and the unique `(subject_id,note_id,field_ordinal)` for each detail row; canonical DS text and each detail row remain separate containers, with no hidden concatenation.

A unit's canonical key is the lexicographically serialized tuple of normalized fields plus the sorted source-span coordinates. Sort units by `(target_cluster, action_modality, due_interval, polarity, recipient_responsibility, replacement, conflict, source_span_coordinates)`, using an explicit total order for `ABSENT < EXPLICIT < CONTRADICTORY < UNREADABLE < UNKNOWN`. Duplicate units are retained until the duplicate rule is applied: identical canonical keys are one unit with all source spans retained; units with the same target/action but different due, replacement, conflict, or span are distinct. A panel may mark a duplicate/restatement relation only when an explicit reciprocal parent/addendum field or exact inherited chronology rule supports it; otherwise both units remain and disagreement is adverse.

The inherited canonical matcher is now fixed as follows. Match H1 and H2 sorted lists by exact canonical key first. For unmatched units, permit a one-to-one match only if the full normalized route-defining tuple excluding source spans is equal **and** the inherited reciprocal-restatement rule declares the spans equivalent; choose the lexicographically smallest maximum-cardinality matching, and mark all remaining unmatched units. No fuzzy, many-to-one, order-dependent, or reviewer-selected matching is allowed. If multiple maximum-cardinality matchings remain after these rules, the admission's D state is `UNKNOWN` and all compatible states retain the unresolved alternatives. This matcher is run before any route, atom, weight, or outcome summary is revealed.

## Frozen labels and NA/adverse table

For a retained nonempty unit inventory, the required field set `F_i` is the inherited route-defining field set. `D_REPRO=1` iff both valid H1/H2 inventories have the same matched unit cardinality, every unit has a unique deterministic match, and every non-unknown field in `F_i` agrees exactly; unresolved, contradictory, unreadable, unmatched, or nonresponse states are `D_UNKNOWN` and remain adverse-compatible. H3 is not an input to `D_REPRO`.

`A_TEXT_COMPLETE=1` iff, in H2's sealed inventory, every required field for every retained unit is explicit and internally nonconflicting and no field is supplied by proxy or inference. `A_TEXT_INCOMPLETE=0` if the packet is valid and a required field is explicitly absent or contradictory. `A_TEXT_UNKNOWN` applies to unreadable/corrupt/nonresponse/unresolved cases. The H2 actionability lane never evaluates appropriateness or feasibility.

The eligibility and NA table is fixed before labels:

| inherited state | unit inventory eligibility | D_REPRO | A_TEXT_COMPLETE | gap contribution |
|---|---|---|---|---|
| one or more retained units, valid packet | eligible | 1/0/UNKNOWN by rules above | 1/0/UNKNOWN by rules above | eligible for `G_text` only when D=1 |
| valid packet, independently empty inventory and inherited `NOACTION` | eligible for descriptive census only | 1 if both sealed inventories are empty, else UNKNOWN | `NA` (not 0 or 1) | excluded from actionability numerator and denominator |
| inherited `DEFER`, zero units | descriptive only | 1 if both sealed inventories independently empty, else UNKNOWN | `NA` | no gap estimate; report count |
| inherited `DEFER`, one or more units | eligible for audit, never auto-released | as above | as above; unresolved fields remain UNKNOWN | gap estimable only if D=1 |
| invalid/corrupt packet, broken seal, nonresponse, unresolved canonical match | ineligible for favorable complete-case analysis | UNKNOWN/adverse-compatible | UNKNOWN/adverse-compatible | denominator retained in compatible worlds; no complete-case deletion |

`A_TEXT_GAP=1` iff `D_REPRO=1` and `A_TEXT_COMPLETE=0`; it is undefined/NA when D is not 1 or the inventory is empty. Report the full joint state, including counts and design-weighted bounds, rather than silently dropping NA or unknown states. The primary inherited route and all route estimands cannot be changed by any bridge field.

H3 codes the following actual evidence fields independently: viewed before departure; finalized/signed; communicated; order/referral executed; responsible team accepted; scheduled/handoff confirmed; patient/caregiver preference or capacity; and post-discharge follow-up/outcome. For each, retain `OBSERVED`, `NOT_PRESENT_IN_AVAILABLE_SOURCES`, `CONTRADICTED`, or `UNKNOWN`, with the pre-label availability rule above. Report `E_WORKFLOW_GAP=1` when any required field is unavailable or unknown, and `E_OUTCOME_GAP=1` when follow-up/outcome is unavailable or unknown. These are evidence-gap indicators, not failures of care.

## Estimands, inference, and falsification

For every frozen atom-route cell, report design-weighted finite-population proportions and simultaneous intervals using inherited first- and second-order inclusion probabilities and compatible-set inference. Optimize joint numerator/denominator states for `G_text=P_w(A_TEXT_GAP=1 | D_REPRO=1, atom, route)`; never combine extrema from incompatible marginal worlds. Challenge-only results are labeled conditional on challenge inclusion. Unknown, missing, and unresolved states remain adverse-compatible; empty compatible sets, zero denominators, failed positivity, or insufficient challenge support return `INCONCLUSIVE`/`DEFER`, never a favorable substitute.

Supportive evidence is a narrow, non-adverse-compatible D estimate in at least one pre-supported atom-route cell, a finite reported `G_text`, and a stable, explicitly listed evidence-gap vector. It supports only prospective silent validation with real workflow provenance. Adverse evidence is a supported nonzero/wide actionability gap, reproducibility failure, unresolved unit matching, or route-invariant sensitivity to nuisance text. Inconclusive evidence includes sparse support, wide compatible bounds, nonresponse, unavailable denominator, broken seals, invalid controls, or unresolved chronology. An H3 unavailability result alone is an evidence ceiling, not evidence of failed care.

Pre-label synthetic fixtures must include: identical explicit plan (D=1,A=1); missing recipient (D=1,A=0); one panel missing due interval (D=UNKNOWN); valid empty NOACTION (D=1,A=NA); DEFER with units (audited but not released); DEFER with empty inventory (A=NA); duplicate restatement with explicit reciprocal parent (one matched unit); same target/action with different due interval (two units); multiple maximum matchings (D=UNKNOWN); explicit text claim of an order with no event source (`TEXT_ASSERTION`, not OBSERVED); route-irrelevant formatting perturbation (D/A unchanged); decisive one-field perturbation (only prescribed atomic field changes); and shared-wrong agreement (compatible bounds remain broad). An independent interpreter must reproduce every fixture and prove that H3 cannot alter D, A, route, atom, sampling, or weights.

Falsification occurs if any pre-label matcher rule is applied inconsistently; unit order or matching is non-deterministic; H3 enters D or A; empty/DEFER cases are scored as favorable completeness; text assertions are promoted to workflow observations; unknowns are deleted or imputed; route/atom/weight information is exposed before seals; compatible ratios use incompatible extrema; or any bridge finding changes the inherited route or primary estimand. A route-invariant formatting change that changes D/A, or a prescribed decisive field change that changes unrelated fields, also falsifies the implementation.
