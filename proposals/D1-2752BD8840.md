# Episode 29: content-versus-documentation-artifact test for fixed-budget HCC M2 ranking

## Clinical question and substantive advance

The consequential decision is whether a scarce future multidisciplinary review list should be populated preferentially with adults approaching a first eligible liver resection because the resection specimen may document high-grade microvascular invasion (M2). The proposed experiment does not recommend resection extent, transplantation, neoadjuvant/adjuvant therapy, locoregional/systemic therapy, surveillance, or any patient treatment.

The strongest claim supported before this experiment is only that this HCC snapshot contains patient-linked operative records, CT/MRI examination rows with acquisition time and eventual narrative text, and same-encounter pathology narratives that can be used to define a retrospective documentary endpoint. The source has no report-authored/final/released/viewed time, immutable report-version key, pathology time/specimen/slide/block identifier, sampling protocol, raw images, review roster, capacity, clinician action, treatment, recurrence, survival, or benefit. Thus an eventual stored report is not evidence that a clinician could have seen it at the operative decision.

Current public evidence motivates, but does not establish, this question. A frozen Europe PMC search retrieved small retrospective preoperative MVI studies with internal or limited external validation and reported model performance, including a 79-patient PET/CT study and a 219-patient dual-center CT-radiomics/serum study (search source IDs [source checksum] and [source checksum]). Those abstracts support the need for temporal validation, calibration, and external adjudication; they do not support report-text value in this dataset. I inspected references/research-ambition/README.md for demonstration availability and limitations only; I do not claim to have read unavailable main-text or supplementary methods beyond what that README states.

The unresolved claim is narrower and falsifiable:

> Among the retrospectively defined, recorded-treatment-naive adults who undergo a first eligible HCC resection, does clinically adjudicated CT/MRI report content improve ranking of documentary-M2 cases within a fixed number of ranking positions, beyond a nonsemantic baseline, and does that improvement survive a documentation-surface negative control?

The advance over the parent is that a positive semantic contrast is not accepted merely because it is predictive. The experiment must show incremental value of prespecified clinical content while a matched surface/style-only model fails to reach the same clinical margin. This addresses the clinically important possibility that apparent semantic value is actually documentation style, report length, source/template, or acquisition recency.

## Estimand and hypotheses

Let s be one complete coherent source state, y be test year 2020 or 2021, d be a 12-, 24-, 48-, or 72-hour operative buffer, and h be one prespecified report-access sensitivity cell. All state choices are coupled: membership, first operation, operative clock, selected encounter, prior-treatment history, index order, examination bundle/identity, modality, report text, hypothetical access, pathology composite, and outcome are never borrowed across states.

For each state, construct the completed-resection index without pathology grade, report semantics, or test outcomes. Let N_a(s) be state-specific index size in development/calibration year a for a=2015,...,2019; N_ref=min over states and a of N_a(s); and K_q=floor(q*N_ref) for q in {0.05, 0.10, 0.20}.

Freeze K_q before looking at 2020/2021 outcomes, access cells, or bootstrap results. The primary analysis is feasible only if N_ref >=500, every claimed K_q >=50, and every claimed test state contains at least K_q members. There is no test-year redefinition of K.

For model m, rank every member of a test-year state by locked score and then a frozen patient hash plus raw episode backpointer. Let R_K(m;s,y,d,h) be the first K_q members and let Y_i be documentary M2, with unresolved pathology outcomes retained as an interval rather than dropped. The primary fixed-budget ranking-potential estimand is:

T_m = 100/K_q times the sum of Y_i over i in R_K(m)

documentary-M2 cases per 100 fixed ranking positions.

Use four predeclared model families:

- B: independently fitted nonsemantic baseline: age, sex, CT/MRI/other acquisition indicators, eligible source-unit count, acquisition-to-decision recency, component count, report-identity ambiguity, and development-frequency Machine model category. It contains no report text, pathology, diagnoses, labs, identifiers, year, or post-cutoff facts.
- C: clinically adjudicated, prespecified report-content flags from the selected whole CT/MRI unit, added to the B variables: maximum lesion diameter, lesion count, capsule, margin, arterial hyperenhancement, washout, peritumoral enhancement/hypointensity, satellite lesion, portal/hepatic-vein tumor thrombus, cirrhosis, and ascites, each coded present/absent/uncertain/not-mentioned.
- C0: the same fitted C model with all content flags masked to the training-defined missing/unknown code. It is never refit. This is a same-fit attribution control.
- F: independently fitted B plus documentation-surface features that do not encode a clinical finding: whole-unit character count and field-presence indicators for examination findings and examination diagnosis, digit/punctuation/whitespace/Chinese-character proportions, report component-row count, source/accession ambiguity, acquisition recency, and machine model category. F is explicitly a documentation-form negative control, not a clinical model.

The primary contrasts are D_C=T_C-T_C0 (same-fit incremental content attribution), A_C=T_C-T_B (independent nonsemantic comparison), and A_F=T_F-T_B (documentation-surface contrast).

The hypothesis is that D_C and A_C exceed five additional documentary-M2 cases per 100 fixed ranking positions, while A_F does not exceed five. The number five is a fixed practical ranking margin, not a treatment-effect threshold. None of these contrasts is causal, a patient-level benefit, a common-opportunity comparison, or real service performance.

All models select exactly K_q; consequently utilization is identically one and the contrast is a ranking-set composition difference. No Shapley/utilization term is interpreted as mediation or capacity. An outcome-aware top-K oracle may be reported only as an unattainable ceiling diagnostic.

## Population, temporal boundaries, and coherent states

The person key is Patient Master Index; same-encounter joins use (Patient Master Index, Encounter Number). Preserve raw row ordinal, duplicates, unmatched rows, and multiplicity before exact-row deduplication.

Two hepatobiliary surgeons and a surgical informatician must freeze a resection dictionary and reconcile procedure documentation sources, including Surgery source, Anesthesia system, and Medical record surgery. A clinically linked anesthesia-system start is exact only after validation. Date-like or midnight case-record timestamps are intervals [date,date+24 hours) rather than exact instants. Missing, competing, same-day, and adjacent-day clocks remain alternatives. The primary decision proxy is t_dec=t_op-24 hours; 12-, 48-, and 72-hour buffers are locked sensitivity states.

Membership in each state requires: age >=18 on the selected encounter; all same-encounter pathology rows explicitly supporting HCC; and no recorded prior HCC resection, transplant, TACE, ablation, radiotherapy, targeted therapy, or immunotherapy in [t_dec-365 days,t_dec), using only state-matched dated procedures, medications, and orders.

This is recorded-treatment-naive, not biologically treatment-naive. Untimed diagnoses are corroboration/audit only. Completion and postoperative pathology define a retrospective evaluation frame; nonmembers are not controls or outcome negatives. Development is 2015-2018, 2019 is calibration and score-locking only, and 2020 and 2021 are separate locked tests. Patients with possible later-period membership are quarantined from earlier fitting. 2022 onward is an ascertainment/drift audit, never primary validation.

## Report identity, access, and content adjudication

Form one indivisible nonblank examination unit before modality labeling or masking using (Patient Master Index, Encounter Number, Examination Number) and retain every component row. Blank Examination Number rows remain in acquisition audits but cannot supply identity-safe text. Conflicting modalities, clocks differing by >24 hours, or identity ambiguity create coupled alternative states including the accession bundle and a deterministic (Examination, calendar-date) partition; the partition is a sensitivity state, not a license to split the primary unit.

Two blinded abdominal radiologists map examination to CT, MRI, non-target, or unresolved and independently annotate every selected CT/MRI unit for the eleven content features above using a frozen bilingual rubric. A third radiologist adjudicates disagreements. They are blinded to pathology outcome, model score, and test-year result. If full-unit expert annotation is unavailable, the semantic claim is inconclusive even if an automated lexical parser runs. A local lexical detector is not treated as a clinical diagnosis extractor.

For each patient retain at most the latest eligible CT and latest eligible MRI, using conservative maximum component start, raw ordinal, and frozen hash tie-breaks. Concatenate examination findings and examination diagnosis in frozen raw order. Visibility exposes a complete source unit, never selected phrases.

The examination table supplies acquisition start time only. It does not identify report authoring, finalization, release, clinician view, version history, or access. Therefore evaluate a 0.05-grid of hypothetical content-access cells: h_C is the fraction of C-pattern members for whom eventual CT content is exposed; h_M is the analogous MRI fraction; h_A is at least one modality exposed among CM-pattern members; and h_B is both modalities exposed among CM-pattern members, with h_B <= h_A.

O/C/M/CM members remain in every denominator. H0 masks all content; H1(h) exposes eventual stored text under a hypothetical guarantee. C uses H1(h) and C0 masks content in the same fit. No h is called observed availability or a report-release probability. A future deployment claim requires an external, version-matched report-finalization/release/view audit and is outside this experiment.

## Fitting, calibration, inference, and falsification

Fit B, C, and F independently in 2015-2018 with patient-wise worst-state elastic-net logistic loss. Retain all preprocessing, coefficients, calibration, and state alternatives. Use 2019 only for locked calibration and threshold-independent score-locking; do not use test outcomes or test report text to select features, K, access cells, or thresholds. C0 inherits every C choice and masks only the content features.

The primary result is a patient-cluster bootstrap with 2,000 refit replicates. Each replicate rebuilds coherent states, development fits, 2019 calibration/score locks, access states, ranking sets, and pathology outcome envelopes. Construct one max-centered simultaneous 97.5% confidence family across D_C, A_C, A_F, both years, three q values, four buffers, all claimed access cells, modality patterns, and prespecified null checks. Every row reports estimate, simultaneous interval, state extrema, K, selected M2 count, source-state count, adjudicated and unresolved outcome envelopes, gate vector, and raw trace locator.

Run 1,000 development semantic-content block permutations, stratified by year, modality pattern, source-unit cardinality, identity ambiguity, and documentation-surface bins. The permutation null must preserve report surface structure while breaking content/outcome alignment. The semantic contrast must clear the simultaneous one-sided 0.025 null envelope. Complete content masking must make C and C0 bitwise identical in features, scores, ranking sets, counts, traces, and D_C=0.

Required gates include N_ref>=500, K_q>=50, K_q members in every claimed coherent test state; at least 50 adjudicated M2 events per claimed year envelope; anchored grade >=85%; all test unknowns adjudicated or retained in the unresolved envelope; pathology-parser kappa >=0.90, M2 PPV >=0.98, sensitivity >=0.95; radiologist modality agreement >=0.95 and unresolved modality <=1%; at least 100 members and 20 M2 events for each claimed O/C/M/CM pattern; content-annotation inter-rater kappa >=0.90, content-feature PPV/sensitivity >=0.85 on the adjudicated audit, and no required-feature/pattern shift >15 percentage points from 2019; B, C, and F calibration slope 0.80-1.20 and intercept -0.10 to 0.10; exact joins, coupled-state/backpointer completeness, patient quarantine, future-row invariance, optimizer/brute-force equality on N<=12 fixtures, zero forbidden predictor lineage, and <=2.5% failed bootstrap replicates.

Add a predeclared sensitivity in which F surface features are omitted one at a time, and a within-surface-bin permutation. These are diagnostics, not post hoc rescue choices.

## Supportive, adverse, and inconclusive result rules

Support for the clinically interpretable content hypothesis requires all gates, complete state enumeration, a nonempty claimed access set, simultaneous lower limits strictly greater than 5 for both D_C and A_C in every claimed year, q, buffer, coherent identity/outcome state, and access cell, plus a simultaneous upper limit at most 5 for A_F in the same scope. A lower limit exactly 5 is not supportive. Report the coordinatewise-minimal access set satisfying this rule only as a hypothetical stored-content frontier.

An adverse content result is a valid computation with a simultaneous upper limit at most 5 for either universal content contrast in a required scope, or an empty access set because all fully enumerated cells fail. An upper limit below zero supports lower ranking potential for content in that scope. If A_F exceeds 5 while D_C does not, the appropriate adverse interpretation is that documentation form may carry ranking signal but interpretable content has not been shown to add robust value. If C and C0 are not bitwise identical under complete masking, the computation fails and is inconclusive.

Inconclusive includes intervals crossing 5, incompatible years/q/buffers/access states, failed expert annotation or pathology adjudication, unresolved clock/identity states, insufficient events, calibration/permutation/temporal gates, missing backpointers, undefined/non-K ranking sets, or missing conclusion-to-result links. Gate failure is not evidence that biological MVI is absent.

A supportive result would justify a prospective silent-mode review-list study with real report-version/access timestamps, an externally defined eligible population including non-resected candidates, clinician adjudication of the intended review action, and capacity/workload measurement. It would not establish biological M2, causal prioritization, treatment benefit, recurrence, survival, safety, fairness, cost-effectiveness, or transportability. An adverse result would be clinically useful by discouraging deployment of report semantics for this ranking purpose and directing attention to better-measured data. An inconclusive result identifies whether the barrier is label ascertainment, clinical annotation, operative/report identity, report access, temporal drift, or sample size.
