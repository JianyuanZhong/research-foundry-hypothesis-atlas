## Exact row-level bounds and signs

For a block let `I` be all `BP_eligible` rows, `O={i in I:Y_i observed}`, and `M=I\\O`. Let `N=|I|`, `n_o=|O|`, `n_m=|M|`. For each row, predictions are frozen and finite; otherwise set `prediction_status=invalid` and do not interpret the block.

For `i in O`, define

```
e0_i = (Y_i-p0_i)^2
e1_i = (Y_i-p1_i)^2
d_i  = e0_i-e1_i
```

where positive `d_i` favors M1. For `i in M`, the only mathematical assumption is `y_i in [L,U]`. Define the direct contrast function

```
d_i(y) = (y-p0_i)^2 - (y-p1_i)^2
       = 2*y*(p1_i-p0_i) + p0_i^2 - p1_i^2.
```

Because `d_i(y)` is affine in `y`, its exact extrema on `[L,U]` are obtained by evaluating both endpoints:

```
d_i,L = d_i(L)
d_i,U = d_i(U)
d_i,min = min(d_i,L,d_i,U)
d_i,max = max(d_i,L,d_i,U)
```

The exact all-eligible SSE improvement interval is

```
Delta_lower = sum_{i in O} d_i + sum_{i in M} d_i,min
Delta_upper = sum_{i in O} d_i + sum_{i in M} d_i,max
```

and the corresponding MSE interval is `[Delta_lower/N, Delta_upper/N]`. The interval is sharp for the stated rectangular, row-wise support set because each missing row can independently attain the relevant endpoint. It is not a confidence interval and has no probability interpretation.

For each model separately, define the row-wise squared-error extrema

```
qj_min(i) = (clip(pj_i,L,U)-pj_i)^2
qj_max(i) = max((L-pj_i)^2,(U-pj_i)^2),  j in {0,1}.
```

Then

```
SSEj_lower = sum_{i in O} (Y_i-pj_i)^2 + sum_{i in M} qj_min(i)
SSEj_upper = sum_{i in O} (Y_i-pj_i)^2 + sum_{i in M} qj_max(i)
MSEj_lower = SSEj_lower/N
MSEj_upper = SSEj_upper/N
```

These model-specific MSE bounds are row-wise sharp separately. They must not be presented as a jointly sharp interval for the RMSE difference. The identity `Delta = SSE0-SSE1` is the primary contrast bound; do not obtain it by subtracting independently optimized model-specific endpoints.

If a non-primary scale summary is requested, emit only the conservative enclosure

```
RMSEdiff_conservative_lower = sqrt(max(0,MSE0_lower)) - sqrt(max(0,MSE1_upper))
RMSEdiff_conservative_upper = sqrt(max(0,MSE0_upper)) - sqrt(max(0,MSE1_lower))
```

and label it `conservative_non_primary_rmse_difference`. Never divide it by an unidentified all-eligible `SD(Y)`. `G_obs` is emitted only on observed complete triplets with a defined test SD (`n_o >= 2` and positive finite `SD_obs(Y)`).

Emit three deterministic endpoint scenarios for auditing, without treating them as plausible imputations:

1. `all_missing_at_L`: every missing row gets `L`;
2. `all_missing_at_U`: every missing row gets `U`;
3. `rowwise_least_favorable_for_M1`: each missing row gets `L` if `d_i(L)<=d_i(U)`, else `U` (ties choose `L`).

For each scenario emit aggregate `N`, `n_observed`, `n_missing`, `missing_fraction`, `SSE0`, `SSE1`, `MSE0`, `MSE1`, `Delta=SSE0-SSE1`, and `Delta/N`; also emit the same fields by descriptive arm. Never emit row identifiers or row-level laboratory values.

## Exact deterministic common-displacement tipping point

This is a coordinate sensitivity analysis, not an imputation model. Set

```
m_ref = mean(observed future Y)       if n_o > 0
        mean(training T)               if n_o == 0 and n_train_y > 0
```

Use `reference_source=future_observed_mean` in the first case and `reference_source=training_observed_mean` in the second. If neither exists, set `tipping_status=no_reference` and emit no root. Define `a=L-m_ref`, `b=U-m_ref`; if `a>b`, set `tipping_status=invalid_support`.

For a common displacement `delta in [a,b]`, assign every missing row

```
y_i(delta) = clip(m_ref + delta, L, U).
```

Let `C_obs=sum_{i in O} d_i` and, for missing rows, `A=sum_{i in M} 2*(p1_i-p0_i)` and `B=sum_{i in M} (p0_i^2-p1_i^2)`. The exact all-eligible contrast is

```
Delta(delta) = C_obs + A*clip(m_ref+delta,L,U) + B.
```

Thus, after clipping, `Delta(delta)` is piecewise affine, not quadratic. Use this deterministic algorithm:

1. If `Delta(0)==0` (with exact decimal arithmetic where practical, otherwise absolute tolerance `1e-12 * max(1,|Delta(0)|,|Delta_lower|,|Delta_upper|)`), return `tipping_status=zero`, `delta_star=0`.
2. Construct sorted breakpoints `K=sorted(unique([a,b, L-m_ref, U-m_ref]))` restricted to `[a,b]`; retain only finite values. Since `[a,b]` already equals `[L-m_ref,U-m_ref]`, the effective endpoints are `a,b`.
3. On each closed segment `[k_r,k_{r+1}]`, determine the clipping state at its midpoint. If `m_ref+mid < L`, use constant `L`; if `>U`, use constant `U`; otherwise use `m_ref+delta`. Evaluate the affine segment at both endpoints. If either endpoint is zero, record that endpoint. For an unclipped segment, solve the single linear equation `C_obs + A*(m_ref+delta)+B=0`; accept the root if it lies in the segment, including boundaries. For a clipped segment, the function is constant; record the segment only if that constant is zero.
4. Deduplicate roots within the same tolerance. If one or more roots remain, choose the root minimizing `abs(delta)`; ties choose the numerically smallest `delta`. Return `tipping_status=root`, `delta_star`, `abs_delta_star`, and `delta_domain=[a,b]`.
5. If no root remains, return `tipping_status=sign_robust_common_displacement` and the endpoint signs `sign_at_domain_lower`, `sign_at_domain_upper`. This means only that the contrast does not cross zero under this common-displacement scenario; it is not robustness to arbitrary missing values.

Evaluate `Delta(0)`, every selected root, and both domain endpoints directly from the row formula as a verification check. If direct and segment evaluations disagree beyond the tolerance, set `tipping_status=arithmetic_failure` and block interpretation. If `Delta_lower <= 0 <= Delta_upper`, set `endpoint_interval_crosses_zero=true`; otherwise false. A root close to either support boundary is reported with `near_boundary=true` when `min(abs(delta_star-a),abs(delta_star-b)) <= 0.05*(b-a)` for a nondegenerate domain; this is a descriptive warning, not a new exclusion.

## Verifier test matrix and interpretation precedence

The verifier must recompute the formulas from retained aggregate-safe intermediate outputs or rerun the source scan, and inject at least these branches:

1. favorable observed `G_obs` with `[Delta_lower,Delta_upper]` crossing zero -> `selection_sensitive`, never supportive;
2. favorable observed point estimate with failed arm or complete-triplet gate -> `inconclusive`/descriptive-only, never supportive;
3. observed future `Y` outside `[L,U]` -> `unsupported_future_outside_range`, no temporal robustness claim;
4. no future observed `Y` -> `low_information_no_future_observed_y`, training-derived reference only, no supportive claim;
5. untimed document presence is not assigned a `Y`-window time;
6. examination/encounter presence is not labeled clinical follow-up;
7. endpoint bounds do not alter primary complete-triplet RMSE or its bootstrap interval;
8. model-specific MSE bounds are not mislabeled as sharp RMSE-difference bounds;
9. `Delta` uses `d=e0-e1`, so positive means lower M1 squared error; sign reversal is adverse/selection-sensitive as specified;
10. zero or near-boundary tipping roots remain sensitivity coordinates, not plausibility or clinical thresholds;
11. robust sign under the declared support set is not upgraded to transport, causality, utility, safety, or benefit;
12. adverse and inconclusive branches are retained rather than replaced by a favorable narrative;
13. any source/hash/header/denominator/clock failure yields `reconstruction_failure` and suppresses inferential interpretation;
14. identifiers, raw laboratory values, and clinical text are rejected from output.

Use this precedence for the per-record `interpretation_branch`:

1. `reconstruction_failure` if any immutable reconstruction or privacy assertion fails;
2. `inconclusive_unsupported_or_low_information` if support status is unsupported/low-information/degenerate, a primary estimand is undefined, an arithmetic check fails, or required support gates fail;
3. `adverse_bounded` if an adequately supported record has a defined primary result that is nonpositive under the prespecified adverse threshold or has `Delta_upper < 0`;
4. `selection_sensitive` if the observed result is favorable but `endpoint_interval_crosses_zero`, observation/transport warning flags are material, or the tipping root is boundary-near;
5. `supportive_prognostic_only` only when reconstruction passes, gates pass, primary `G_obs>0` with its prespecified interval excluding zero, `Delta_lower>0`, no material observation/transport warning is present, and no unsupported/undefined flag applies.

A record classified `supportive_prognostic_only` still supports only the selected short-horizon noncausal prognostic association in that calendar mixture. It never supports treatment benefit, clinical response, safety, mortality, hepatic failure, external validity, or a patient-level decision rule. If records disagree, the overall proposal status is the least favorable applicable branch, with `selection_sensitive` and `inconclusive` taking precedence over a favorable record; no later-era favorable point estimate can upgrade the inherited 2022-local conclusion to multi-era transport.

## Falsification and limits

The hypothesis is weakened or falsified, within this selected prognostic design, by a nonpositive primary contrast in an adequately supported block, repeated M1 degradation, or an all-eligible bounded interval with `Delta_upper<0`. It is not refuted by an unsupported block; that result is a data-support failure. A bounded interval crossing zero means the available data and declared support set do not identify the sign. A favorable observed-case result with a strong observation gradient remains selection-sensitive.

Computation can verify source hashes, full scans, headers, joins, duplicate handling, event clocks, outcome-blind risk sets, frozen predictions, endpoint arithmetic, tipping arithmetic, aggregate serialization, and interpretation branching. It cannot establish assay units/reference ranges, clinical severity, imaging response, treatment administration or intent, external-care capture, mortality, hepatic failure, completed follow-up, causal effects, utility, actionability, or patient benefit. Those require clinical adjudication and an independent temporal/external/prospective cohort with validated assay metadata and reliable outcome capture.
