## One bounded outcome-linked queue diagnostic

After P_C, J_C and P_A are fit on development and calibrated only on validation, use the sealed pooled-test predictions. Define `K=ceil(0.05*n)`; for pooled test, n=9,871 and K=494. All queue ties are broken by probability descending, then `subject_id,hadm_id,transfer_id` ascending.

1. The global Q0 queue is the top K across P_C for S=1 and P_A for S=0.
2. The global Q1 queue is the top K across J_C for S=1 and the same P_A for S=0.
3. For the slot-fixed Q1 queue, freeze the exact S=0 records selected by global Q0. If global Q0 contains m S=1 records, fill exactly m slots with the top J_C-ranked S=1 records.

Global Q1 tests the actual routed policy. Slot-fixed Q1 isolates value-driven ranking within S=1 while holding S=0 membership and branch capacity fixed; because the S=1 records in global Q0 are the top m by P_C, this is a comparable P1-versus-J1 queue at the capacity induced by the baseline policy.

Report for global and slot-fixed contrasts: additional R+D events per 1,000 reviewed, event counts, S=1/S=0 slots, entrants/exits and their outcomes, and raw/adjudicated/component sensitivities. Repeat the same decomposition for all 200 endpoint-fixed J1 nulls while leaving P_A and S=0 predictions invariant.

Run 2,000 two-sample paired subject-cluster replicates. In each replicate:

- resample validation subjects, refit the parent's frozen P_C, J_C and P_A calibration maps from sealed uncalibrated predictions, without changing models or choosing a calibrator;
- independently resample pooled-test subjects;
- apply all three refitted maps and recompute global and slot-fixed queues;
- use the same pooled-test subject draw for Q0, observed Q1 and all null Q1 comparisons.

This propagates uncertainty in cross-branch calibration alignment, which the parent's bootstrap over sealed test predictions alone omits. Save the fraction of replicates in which the S=1 global slot count changes by at least `ceil(0.05*K)=25` relative to the point estimate. This 5%-of-capacity quantity is descriptive, not another success threshold.

The smallest decision-changing check is thus global versus slot-fixed capture under calibration-refit uncertainty. No new subgroup, window, threshold, population or endpoint is introduced.
