# Does hypotension DURATION add AKI risk beyond DEPTH and severity, or is it an AKI-detection / hospital-practice artifact?

Lead working proposal - eICU 2.0 island, **episode 29**. Operation: **restart** onto unused
expert seed `[starting question]` ("Duration of hypotension"). Context provenance only
(not ancestry): the parked draw-intensity branch `candidate-02748be6...` (mu 32.14) and

## 1. Unresolved question and clinical importance
ICU teams titrate vasopressors/fluids to a mean arterial pressure (MAP) target. Prior work
established that a *time-weighted hypotension burden* (MAP<65 mmHg) predicts kidney
injury [K1] and that *cumulative duration* of MAP<65 predicts downstream deterioration, with
area-below-threshold and duration both carrying signal [K2]. What is unresolved is whether the
**duration** component adds clinically meaningful information **beyond the single deepest MAP
reached (depth)** and overall severity - the decision-relevant distinction for whether "time
below target" is an actionable monitoring target, or whether depth alone suffices. A serious
rival is that any duration-AKI association is an **ascertainment artifact**: patients monitored
more intensely (more MAPs and more creatinines) look both more hypotensive and more
AKI-positive, and this monitoring intensity differs by hospital [K3].

## 2. Hypothesis and strongest rival (falsifiable)
- H1 (duration adds): with depth and severity fixed, greater cumulative time/area below a MAP
  threshold in the early window predicts higher KDIGO AKI risk.
- R-DETECT (strongest rival): H1 attenuates to null once creatinine-sampling intensity
  (and MAP-monitoring intensity) is held equal/conditioned - the association is detection.
- R-SEV: sicker patients have both more hypotension (of every kind) and more AKI; residual
  severity confounding explains H1.
- R-PRACTICE: the pooled association is a between-hospital practice fingerprint and does not
  transport across hospitals.
Competing predictions: H1 predicts a positive duration coefficient **after** depth + severity
adjustment and **stable** under the detection control; R-DETECT predicts attenuation toward
null under the detection control; R-PRACTICE predicts between-hospital sign/size heterogeneity
and degraded leave-one-hospital-out (LOHO) performance.

## 3. Population, temporal boundaries, variables (eICU 2.0)
- Source: eICU 2.0 read-only CSVs (datasets/eicu/README.md). Join key `patientunitstayid`
  everywhere; **never** join other databases.
- Population: adult ICU stays (`patient.age >= 16`), ICU length `unitdischargeoffset >= 1440`
  min; baseline creatinine available; at least one follow-up creatinine.
- Timing: all offsets are MINUTES from ICU admission. Exposure window (0, 24] h. Outcome
  horizon (0, 72] h using creatinine trajectory; explicit landmark at 24 h so exposure
  precedes outcome ascertainment.
- Exposure (two, on the same rows):
  (a) DEPTH (baseline/simple) = minimum `systemicmean` in (0,24] h (`vitalPeriodic.observationoffset`);
  (b) DURATION/AREA (mechanistic alternative) = summed time (and trapezoidal area) with
      `systemicmean < 65` mmHg in (0,24] h, plus number of separate below-threshold episodes.
- Outcome: KDIGO serum-creatinine AKI (stage>=1) in (24,72] h = creat >=1.5x baseline or a
  >=0.3 mg/dL rise within 48 h. Exclude chronic dialysis/ESRD.
- Adjustment: `apachePatientResult.apachescore`/`predictedicumortality` (severity); vasopressor
  use (symbol map from `infusionDrug.drugname`/`medication.drugname` - string ambiguity noted);
  age; baseline creatinine/eGFR.
- Detection control: creatinine sampling intensity = number of `lab.labname=='creatinine'` rows
  in (0,24] h (channel-disjoint from the outcome values themselves). R-DETECT test: refit with
  sampling intensity as covariate and compare coefficient attenuation.

## 5. Baseline vs substantive alternative (method comparison)
- BASELINE: hospital-fixed-effects logistic model, AKI ~ depth (min MAP) + severity + covariates.
- ALTERNATIVE: same split/outcome/uncertainty, exposure replaced by cumulative duration/area
  below threshold + episode count. What the alternative reveals that the baseline loses:
  recurrence and sustained-vs-transient burden (two patients with the same minimum MAP can have
  very different cumulative exposure). Fitting target = AKI risk; split = hospital-held-out /
  LOHO; uncertainty = 95% CI (bootstrap over hospitals); budget = CPU, minutes-scale, inside the
  solver envelope (no GPU required). Deferral reason for a sequence/latent model: not needed to
  answer the depth-vs-duration contrast; revisit if duration's effect is time-ordering-specific.

## 6. Falsification criteria
- Supportive for H1: duration/area coefficient > 0 with 95% CI excluding 0 after depth+severity
  adjustment, and it remains positive (does not cross 0) under the detection control, with
  acceptable LOHO sign stability.
- Adverse for H1: coefficient ~null after depth adjustment, or attenuates to null under the
  detection control -> duration adds nothing beyond depth/detection.
- Inconclusive: wide CI straddling 0 (underpowered) or LOHO sign reverses in a majority of
  held-out hospitals (non-transportable) -> cannot separate H1 from R-PRACTICE with these data.
Each outcome is informative: a null duration result is a useful negative finding that supports
targeting depth, not "time below target".

## 8. Honest limits
Readiness only: no estimator, E-value or LOHO run at discovery. Creatinine-based AKI is
ascertainment-sensitive (partly addressed, not eliminated, by the detection control). eICU
lacks order-set/staffing data, so mechanism is not identified; association vs mechanism is
kept distinct. MAP is a 5-min median, not beat-to-beat. Vasopressor `drugname` strings are
not yet fully harmonized. Association does not establish a causal MAP target; that requires
prospective/trial evidence. Deferred alternatives documented in work/episode29-notes.md.
