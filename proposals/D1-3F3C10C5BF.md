# When instability is not being tested: monitoring-process dependence and transport of an observed renal signal in eICU

## Scientific deliverable and unresolved question

The new scientific deliverable is a fitted, uncertainty-quantified decomposition of an observed creatinine-rise signal into clinical instability, opportunity to obtain a qualifying creatinine measurement, and the probability that the obtained measurement is a rise. It must also quantify whether a physiology-first risk estimate transports across hospitals when testing practices differ. Completion requires a frozen audit and cohort flow, a 30-minute interval data set, fitted nested models and linked observation-process parameters, standardized competing-risk contrasts, hospital-held-out calibration, uncertainty intervals, and all prespecified falsification analyses. Discovery has not fitted these models and claims no clinical result.

The strongest claim supported by the inspected material and the parent audit is only that this eICU snapshot contains ICU-relative blood-pressure summaries, longitudinal laboratory results with unit/interface fields and revision times, ICU disposition, patient/stay identifiers, hospital context, and named infusion offsets that can be joined. The expert seeds are hypotheses, not evidence. The available data do not establish AKI, a causal effect of testing, or a clinical deterioration result.

The unresolved claim is whether an unstable ICU patient who experiences a marked reduction in creatinine testing has a systematically different *observed* creatinine-rise incidence than a similarly unstable patient who continues to be tested, and whether this process dependence causes clinically material cross-hospital transport error. The primary hypothesis is:

Among adult ICU stays reaching a six-hour landmark without an early observed creatinine-rise signal, an unstable interval with discordantly sparse creatinine testing has a lower observed-rise hazard than an unstable interval with concordant testing, because the qualifying observation opportunity has fallen; a model that represents this observation process will therefore have at least 20% less hospital-level calibration heterogeneity than a matched physiology-only model in whole-hospital held-out evaluation.

The expected direction is an ascertainment hypothesis, not a claim that renal injury is less common. A secondary, explicitly separable hypothesis is that the instability-by-testing-gap contrast changes the probability of a rise conditional on a creatinine being measured. If it does, the database signal contains a clinical-state association in addition to ascertainment; it remains observational.

This advances the parent’s trajectory-versus-ascertainment study by making monitoring-process dependence and transport the primary estimand. It asks whether the same clinical risk estimate means the same thing at hospitals with different measurement rhythms, and whether an observed renal endpoint can be interpreted without confusing no test with no rise. This is consequential for renal surveillance and for deciding whether an eICU-derived risk threshold is portable. It cannot by itself justify changing test frequency or treating a 65 mmHg MAP threshold.

## Explicit monitoring-process variables

Partition [0,360] into twelve 30-minute bins for the exposure history and use the same bins from 360 to 2,880 for risk. Define recent instability at interval start t only when a valid MAP is available in (t-60,t] or a named pressor offset is present by t. It is positive if a valid systemicmean is below 65 mmHg in (t-60,t] or a named pressor is present by t. Retain separate components for low MAP, low-MAP covered minutes, MAP coverage, and pressor presence; missing MAP is not stable physiology.

Define discordant-low-testing at t as recent instability plus no qualifying creatinine result in (t-180,t]. The principal gap feature is continuous time since the last qualifying creatinine; a parallel definition uses no finite all-lab result in (t-180,t]. The 180-minute rule is frozen before outcome fitting. The interval row also includes pre-landmark qualifying-creatinine count, all-lab count, median pre-landmark inter-test interval when defined, and the binary presence of any baseline test opportunity. A sensitivity defines discordance using the development-set 75th percentile of stable-state inter-test intervals, with that percentile frozen from development hospitals and never estimated in held-out data.

The analysis table must contain patientunitstayid, uniquepid, hospitalid, interval start/end, unit observation boundary, MAP values and coverage, instability components, qualifying and all-lab testing gaps/counts, baseline creatinine, first event time/type, unit disposition, and split assignment. It must preserve one row per stay-interval and record whether each value was available at interval start.

## Matched transparent baseline and substantive alternative

All models use the same eligible stays, interval rows, sources, label/unit maps, outcome states, time origin, preprocessing, split assignments and held-out hospitals.

The transparent baseline is a nested cause-specific pooled-logistic model with 30-minute risk intervals. B0 uses baseline creatinine, recent MAP and minimum MAP, MAP coverage, recent instability components, age, gender, ethnicity, admission source/type, unittype, Apache admission descriptors, early named-pressor presence and hospital context, but no post-landmark laboratory-process features. B1 adds time since the last qualifying creatinine, time since any numeric lab, recent testing indicators and the instability-by-testing-gap interaction. B0 and B1 are deliberately interpretable; use regularization selected by grouped inner hospital validation, with all imputation/scaling/feature decisions learned in development hospitals. The B1 process contrast and B0-versus-B1 calibration comparison are transparent reference results, not proof of causality.

The selected substantive alternative is a marked observation-process multi-state model using the same interval inputs. From the alive, observable, no-observed-rise state, fit linked cause-specific piecewise-exponential components for: (a) a qualifying creatinine observation, (b) a rise mark conditional on that observation, (c) unit death, and (d) alive unit observation loss. Recent instability, its MAP/pressor components, all-lab and creatinine gaps, prior testing density, baseline creatinine, coverage, admission covariates and hospital context enter the observation-intensity and conditional-rise components. The model reports the observed-rise CIF implied by the linked processes and separately reports the observation intensity and rise-given-observation probability.

This alternative can reveal whether the apparent low-testing contrast is almost entirely reduced opportunity, whether a rise is more likely among patients who are tested, or whether both processes vary. B1 can associate process features with an observed event but does not make the observation-versus-mark decomposition explicit. The alternative is selected for this scientific information, not for a small discrimination improvement or model complexity.

Standardize all CIFs to the same minimum MAP, recent instability, baseline creatinine, coverage, admission risk and covariate distribution. Fit no hospital-specific intercept for an unseen test hospital; use the training-population intercept and apply individual process features observed at prediction time. Report process-stratified estimates only when each stratum has prespecified minimum support.

Primary analyses are cause-specific competing-risk fits. Estimate 48-hour CIFs by standardization and report the absolute risk contrast, 95% confidence interval, and number needed to observe only as a descriptive transformation when appropriate. Use 500 hospital-cluster bootstrap replicates, with a uniquepid-clustered bootstrap sensitivity. For the observed endpoint, use IPCW or equivalent competing-risk calibration at 48 hours, with weights defined without future creatinine values. Report calibration intercept, slope, Brier score, AUROC and AUPRC; discrimination is secondary.

The primary process-dependence evidence has two components:

1. The standardized unstable/discordant-minus-unstable/concordant observed-rise CIF contrast must be at least 2 percentage points in the expected lower direction, with an interval that does not include zero. The linked model must show a lower qualifying-creatinine observation intensity in the discordant state. The conditional rise-given-observation result is reported separately.
2. In held-out hospitals, compare B0 and the selected linked model using hospital-weighted mean absolute 48-hour CIF calibration error and the interquartile range of hospital calibration intercepts. Support for transport improvement requires at least a 20% reduction in both metrics relative to B0, with a bootstrap interval for the reduction excluding zero, and no materially adverse subgroup calibration in hospitals with high versus low testing density.

A process model may improve calibration because it captures local documentation patterns rather than biology. Therefore a transport improvement without a stable observation-intensity decomposition is not sufficient for the primary claim. Conversely, a real process contrast with no transport improvement supports ascertainment dependence but not a portable clinical model.

## Falsification and interpretation

Predeclare the following falsification and robustness checks:

- repeat with no MAP interpolation, with only intervals meeting a prespecified coverage minimum, and with noninvasive MAP from vitalAperiodic;
- replace result time by last-revised time and restrict to the finite 0.1-to-30 mg/dL creatinine range;
- replace the creatinine-gap discordance indicator by the all-lab-gap indicator and by the development-only 75th-percentile gap;
- remove named-pressor context, then use pressor presence only as a descriptive stratification;
- restrict to unit stays whose unit disposition is explicit and whose unit boundary exceeds 2,880 minutes; separately report the primary competing-loss boundary;
- test the instability-by-gap interaction in intervals with stable MAP and no pressor as a negative process contrast, where a large effect would suggest residual confounding or label leakage;
- verify that no interval feature contains a lab result at or after that interval start, and audit exact duplicate labid handling, interval ordering and uniquepid split integrity.

Supportive findings are the expected lower observed-rise CIF with reduced observation intensity during unstable low-testing intervals, a separately reported conditional rise probability, and reproducible reduction in hospital calibration heterogeneity under the linked model across held-out folds and measurement sensitivities. This supports monitoring-process dependence of the *observed database endpoint* and suggests that transport reports should include testing opportunity.

Adverse findings are a null or reversed process contrast, no observation-intensity change, a transport result that is equal or worse for the linked model, disappearance after boundary/density/revision sensitivity, or a large effect in the stable negative-contrast check. These findings reject the proposed monitoring-dependence interpretation; they do not prove that sparse testing is safe, that testing caused any result, or that physiology-only models are clinically adequate.

Inconclusive findings include too few eligible stays, hospitals, events or process-strata; no variation in testing gaps; nonidentifiable competing states; missing or contradictory unit disposition; unstable label/unit maps; nonconvergence; extreme weights; or uncertainty intervals spanning the 2-point clinical-importance margin or the transport-reduction criterion. A computationally incomplete or unstable process analysis must be labelled inconclusive.

Computationally checkable claims include source paths and schema hashes, exact headers, label/unit maps, row and cohort flow, join multiplicity, interval availability, event times, competing states, split integrity, fitted parameters, CIF contrasts, calibration, bootstrap uncertainty, and sensitivity results. Clinical adjudication is required for true AKI/KDIGO status, baseline renal reserve, urine-output context, dialysis indication, causes of missing tests, interface interruption, treatment limitation or end-of-life decisions, rationale for discharge/transfer, and bedside severity. The configured release has no raw waveforms, images or complete narrative clinical context; vitalPeriodic is a summary stream. No causal effect of reducing or increasing testing, no causal effect of MAP or vasopressors, no hospital quality ranking and no bedside testing threshold can be claimed.

## Deferred alternatives and revisit rule

A pure GRU or temporal-convolution sequence model is retained as a deferred alternative. Its inputs would be the same twelve MAP bins, instability components, testing gaps, infusion presence and admission covariates; its target, splits, competing states, calibration and process decomposition would be identical. Revisit only if both primary model families leave reproducible held-out residual sequence structure across hospitals after process accounting. A small allocated GPU feasibility probe and a prespecified resource cap would then be appropriate; neural architecture or GPU use is not rejected categorically.

A new vasopressor-start or invasive-ventilation escalation endpoint is also deferred. infusionDrug provides infusionoffset and names but lacks a universal dose unit or treatment intent, and respiratory tables require a frozen label dictionary and expert clinical review. Promote only if an expert verifies onset semantics and the endpoint is supported independently of continuation, transfer and treatment limitation.

A causal under-monitoring study is deferred until adjudicated renal outcomes, reason-for-test and reason-for-discharge fields, treatment intent, complete urine output/dialysis context, and a design addressing time-varying confounding are available. These dependencies cannot be recovered by a more complex model.
