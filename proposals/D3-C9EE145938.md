# Provisional hypothesis: macrophage context changes FLS state through a cell-intrinsic response, not merely composition

Seed context: D3-M1 (composition versus within-cell regulation), narrowed to the verified assay scope.

## Proposed relationship
In the E-MTAB-8873 human synovial type B synovial cell (FLS) targeted assay, exposure to MerTK/CD206-positive versus MerTK/CD206-negative macrophages produces a reproducible, donor-aware change in FLS transcript state that is not adequately explained by differences in the number of contributing macrophage cells or by the measured FLS sample composition. This is a provisional hypothesis, not an executed result.

## Observed evidence and exact source locations
The assay registry in the disease_mechanisms catalog identifies E-MTAB-8873 as a targeted human STM/FLS coculture panel with 33 samples and 445 measured features, with donor/status/condition/treatment metadata in `[internal dataset path]`. The matrix is `.../prepared/E-MTAB-8873.counts.tsv.gz`, with row key `feature` and one column per `sample_id`. The design contains explicit `FLS_only`, `Mpos`, and `Mneg` conditions, plus LPS and MerTK-inhibitor perturbations; donor_id values include multiple comma-separated contributors and `donor_status` marks the need for a contributing-donor model. E-MTAB-8322 is a separate macrophage-only pseudobulk assay (27 samples, 33,694 features) and is not a whole-tissue composition measure. No expression contrast has been computed in this episode.

## Uncertainties and missing evidence
The hypothesis is unresolved because the targeted panel measures only 445 features and cannot establish effects for unmeasured genes; FLS pseudobulk samples summarize recorded cells, and reused/multiple donors require dependence-aware analysis. The available design does not provide an independent whole-tissue cell-abundance measurement for the same samples, so “composition” cannot be directly estimated here. Treatment, age, sex, batch, and macrophage phenotype may confound the response. Cross-sectional coculture does not establish a causal pathway or clinical treatment mechanism. Three inspected key works and frozen evidence receipts are not yet attached.

## Falsifiable test
Restrict to samples with verified FLS identity and matched `FLS_only`/Mpos/Mneg context where the design supports a paired or donor-aware comparison. Use the 445 measured features, preserving source transcript identifiers, and average repeated context measurements within each contributing-donor/condition unit before inference. Fit (A) a simple donor-aware regularized linear baseline using condition and measured covariates, and (B) a substantive joint hierarchical model with donor random effects and a latent within-FLS state component; compare held-out donor/condition generalization, uncertainty, and whether the Mpos–Mneg contrast remains after accounting for recorded cell counts and technical covariates. Support is a reproducible within-FLS contrast with stable donor-aware estimates; adverse evidence is no contrast or a contrast explained by recorded context/cell-count variables; inconclusive evidence is insufficient independent donor units, unstable estimates, or failed feature-map reconciliation. A future whole-tissue composition test requires matched cell-type abundance data not currently admitted.

## Method comparison and deliverable
The simple baseline is a regularized linear model of measured FLS features against context, donor, and recorded cell counts. The substantive alternative is a donor-aware hierarchical/joint state model that can separate within-cell response from sample-level context and quantify uncertainty; it reveals information the baseline loses about dependence and whether the signal is a reproducible FLS state rather than a sampling artifact. The solver must newly fit both models, report held-out/donor-aware uncertainty, and produce a contrast/decomposition. CPU is expected to suffice for this small targeted panel; GPU use is not scientifically required. The actual deliverable is a fitted comparison and uncertainty report, not a claimed mechanism.
