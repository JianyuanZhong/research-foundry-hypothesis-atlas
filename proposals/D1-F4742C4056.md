# Target-independent therapy-de-escalation endpoint tests whether Ventilation labels transport beyond structured physiologic and documentation baselines

## Question and advance

The parent lineage established two important but incomplete findings. First, exhaustive outcome-blind expansion of the exported eICU `carePlanGeneral` Ventilation vocabulary added only 0.10–0.13 percentage points of coverage in airway-bounded cohorts and did not improve hospital-held-out prediction of a later non-peak respiratory-setting-reduction proxy. Second, the broader/exact indicators did predict later respiratory-charting persistence beyond generic documentation controls, but that endpoint is principally an observation-process outcome. It remained unresolved whether the care-plan strings add transportable information for a more decision-relevant, target-independent physiologic/therapy endpoint rather than merely predicting that respiratory documentation will recur.

This child tests the falsifiable hypothesis that, after the inherited target-independent denominator and exact/broader semantics are frozen, the care-plan Ventilation indicators will improve prediction of a subsequent structured therapy-de-escalation event beyond (i) pre-landmark respiratory therapy/physiologic summaries and (ii) exposure-blind generic documentation-opportunity controls, with the gain persisting in hospital-held-out and stay-cluster uncertainty analyses. A negative result is clinically useful: it would argue against using the field to support transportable respiratory decision support, even if it predicts future chart persistence. A positive result would justify local interface review and blinded clinical adjudication; it would not establish liberation, extubation, readiness, benefit, or causal effect.

The strongest existing evidence supports only structured-documentation predictive fitness for the inherited chart proxies. The unresolved claim tested here is narrower and computable: do exact or outcome-blind broader labels improve cross-hospital prediction of a later structured respiratory-setting decrease after conditioning on pre-landmark therapy/physiology and generic documentation opportunity? No care-plan value is used to define the denominator, endpoint, or endpoint vocabulary.

## Endpoint and temporal separation

Only rows with `full_window == True` and `unitdischargeoffset > L+1080` are retained after the inherited denominator is frozen. The classification window is `[L,L+360]`. The endpoint window is strictly `(L+360,L+1080]`, so no endpoint observation at the boundary leaks into classification.

The endpoint is a target-independent structured therapy-de-escalation proxy. In the endpoint window, numeric values are parsed only for canonical `respiratoryCharting` labels: FiO2 (`FiO2`, `FIO2 (%)`, `Set Fraction of Inspired Oxygen (FIO2)`), PEEP (`PEEP`), pressure support (`Pressure Support`), and set ventilator rate (`Vent Rate`). FiO2 percentages are converted to fractions; invalid/nonfinite/out-of-range values are discarded. For each component with a valid inherited pre-landmark value and at least one valid post-window reading, the post value is the minimum observed value. The binary endpoint is one if any paired component decreases by at least 0.05 FiO2, 2 cm H2O PEEP, 2 cm H2O pressure support, or 2 breaths/min set rate. Paired-component count and component-specific deltas are retained for audit, not used to redefine the cohort. The endpoint is not conditioned on care-plan labels, exact receipt, broader receipt, or the inherited `robust_reduction` outcome.

This is more decision-relevant than raw chart persistence because it reflects an observed therapy-setting decrease and is anchored to numeric respiratory fields, but it remains a structured proxy. It does not prove that a patient was invasively ventilated, that a decrease was clinically appropriate, that extubation or liberation occurred, or that a bedside decision was made.

## Exposure-blind controls and models

The pre-landmark baseline contains `pre_fio2`, `pre_peep`, `pre_pressure_support`, `pre_vent_rate`, `pre_chart_n`, `pre_distinct_labels`, and `pre_robust_n`. These are computed before `L` from respiratory charting/setting summaries and do not use care-plan exposure or post-landmark endpoint readings. The generic process control adds `cp_any`, `cp_log_rows`, `cp_distinct_groups`, `vent_any`, `vent_log_rows`, and `vent_distinct_values` from care-plan rows in `[L,L+360]`; these variables represent documentation opportunity and intensity only, not care delivered. The exact model then adds inherited three-state `label3` for the two exact strings. The broader model instead adds four identity-preserving, outcome-blind `ventilated -` indicators: the two exact values plus `Ventilated - rapid wean/extubation` and `Ventilated - chronic dependency`.

Models are logistic regression (`C=1`, `max_iter=2000`, no class weighting), with one-hot landmark, median imputation plus missing indicators and standardization for numeric variables, and unknown-safe one-hot encoding. Models are fit independently in every leave-one-hospital-out (LOHO) fold; no held-out hospital contributes to preprocessing or fitting. Hospitals are eligible for each definition only with at least 20 rows and both endpoint classes. Primary estimands are row-weighted micro and equal-hospital macro log-loss deltas: broader minus process, broader minus exact, and process minus pre-landmark baseline. Brier score, AUROC, calibration, hospital-direction counts, paired-component distributions, and endpoint counts are secondary diagnostics.

Uncertainty uses 100 stay-cluster bootstrap replicates within each fixed held-out hospital, with all landmarks for a `sid` sampled together. Predictions are held fixed after LOHO fitting in this execution; therefore the interval quantifies stay composition uncertainty conditional on fitted models and observed hospitals, not training-fit or unseen-hospital uncertainty. A future confirmatory execution should add nested refitting, but the current bounded computation is sufficient to test feasibility and provide a prespecified transportability signal.

## Gates and interpretation

A supportive transportability result requires the broader model to beat both process and exact models in micro and macro log loss in the unbounded definition and at least two bounded airway definitions, with corresponding stay-cluster 97.5th-percentile deltas below zero, and at least 5 percentage points of broader-versus-exact receipt coverage gain with alternatives in at least five unbounded eligible hospitals and at least three hospitals in at least two bounded definitions. The coverage requirement prevents a tiny sparse label subgroup from being treated as a clinically meaningful rescue.

An adverse endpoint-transport result is defined as no broader-versus-process support in any bounded definition, broader worse than process in at least two bounded definitions by point estimates and with stay-cluster probability of worse macro loss at least 0.75, and no broader-versus-exact support. This supports abandoning the exported broader vocabulary as a transportable predictor for this therapy proxy, not a claim that no bedside information exists. Any other pattern is inconclusive. A discordance in which exact labels help but broader labels do not is evidence against semantic expansion, not proof that either label has bedside meaning.

## Limits and required next evidence

The inherited cohort is hash-frozen support rather than independently rebuilt here from every upstream eligibility table; this is disclosed rather than silently treated as raw reconstruction. Fixed-prediction bootstrap does not capture model-refit uncertainty, and the observed hospitals are not a random sample of future hospitals. Respiratory chart values may be copied, missing, delayed, or interface-specific; minimum post-window values can reflect documentation timing rather than continuous treatment. The endpoint cannot adjudicate invasive airway status, ventilator mode, SBT, extubation, readiness, appropriateness, benefit, harm, or quality. Direct time-resolved device and ventilator-mode data, SBT/extubation records, local interface/workflow metadata, blinded clinical adjudication, nested refitting, and external hospital validation are required for stronger clinical or transport claims. Automatic verification can check source hashes, required columns, temporal inequalities, no endpoint-informed denominator selection, row counts, LOHO separation, feature construction, model fits, and gate arithmetic, but cannot establish bedside semantics or clinical benefit.

The substantive change from the parents is therefore an exposure-blind, numeric therapy-setting endpoint and a stronger pre-landmark therapy/physiology comparator, while preserving the denominator, temporal boundaries, exact-vs-broader vocabulary, hospital-held-out estimand, stay clustering, and strict proxy limits. The evidence now argues that any apparent broader-label value is endpoint- and airway-definition-sensitive rather than a stable transportable decision-support signal.
