# Is the ICU MAP<65 -> AKI association a cumulative dose, or the temporal STRUCTURE of hypotension (time-to-correction and recurrence)?

## 1. Unresolved question and why it matters
ICU teams titrate fluids/vasopressors to a MAP target, so *how long* a patient spends below
65 mmHg is an actionable monitoring object. The parent chain (gen 7-8) decomposed the (0,24]h
MAP<65 burden into EARLY/LATE windows and added a concurrent-trajectory rival. **What the parent
still cannot separate:** LATE minutes conflate *one sustained episode* (long time-to-correction)
with *many short recurrent dips* that sum to the same minutes. Two mechanisms predict different
things:
- **H-dose (cumulative ischemic dose):** only total minutes-below-65 (and depth) matter; the
  pattern is irrelevant.
- **H-structure (time-to-correction / recurrence):** the *longest continuous run* (how long MAP
  stayed unrecovered) and the *number of discrete episodes* carry prognostic information beyond
  total minutes.

This distinction is decision-relevant and falsifiable. If structure adds risk beyond dose, the
clinical target is *prompt and durable MAP restoration* (avoid long uninterrupted runs) rather
than merely trimming total minutes; if structure adds nothing beyond dose, monitoring should
optimize the dose integral and a "time-to-correction" framing would be misguided. Defaulting to
a dose explanation (as most registries do) is itself a substantive claim that the data can test.
The closest inspected work [K1] uses the time-weighted MAP<65 burden as the reference exposure
and finds added shape features give no reproducible incremental discrimination; a perioperative
trajectory study [K2] suggests duration+recurrence classes do carry signal — the two are in
tension, which is exactly what this child resolves in an ICU AKI setting. The clinical decision
this informs (whether lower MAP is tolerable) remains an open randomized question [K3].

Precise scope: this is an **association/structure estimand**, not a causal MAP-target claim.
Distinguish what is supported vs untested:
- **Already supported (evidence):** a time-weighted MAP<65 burden is associated with organ injury;
  added observational *shape/morphology* features have not shown reproducible incremental
  discrimination [K1].
- **Untested (this experiment):** whether *contiguity (longest run)* and *recurrence (episode
  count)* add association **beyond mutually adjusted total minutes and depth** in an ICU
  creatinine-KDIGO AKI endpoint with per-hospital transport, and whether any surviving signal is
  robust to an E-value-style unmeasured time-varying confounding bound.

## 3. Baseline vs substantive alternative (same question)
- **Baseline (dose model, = parent):** hospital-FE logistic with depth + total minutes-below-65
  (+ depth interaction). This is the [K1]-style burden model.
- **Substantive alternative (structure model):** the same model **plus** longest-run and episode
  count (mutually adjusted with total minutes and depth), with the trajectory covariates.
- **What the alternative reveals that the baseline loses:** whether "this patient spent a long
  uninterrupted time under-target" or "this patient dipped repeatedly" adds information beyond
  "this patient accumulated X minutes under-target" — i.e. whether time-to-correction/recurrence
  is a distinct component or just another way to measure the same dose.
- **A second, genuinely different alternative — a learned temporal model (recorded, not the
  primary):** fit a small sequence model (1D CNN or GRU) on the (0,24]h MAP series (e.g. 5-min
  bins) to predict KDIGO-AKI, with held-out-hospital evaluation, and compare its calibration/
  discrimination to the dose baseline and to the structure model. This could reveal *nonlinear /
  order-sensitive* patterns (e.g. slope, recovery velocity) that the hand-crafted longest-run and
  episode-count summaries lose. Selection/deferral reason: it is a *diagnostic of what structure
  information exists*, not the confirmatory test; it is deferred to a bounded secondary aim
  because discovery budget is nearly exhausted and the pre-specified confirmatory estimand is the
  mutually adjusted logistic contrast. It is NOT excluded for being neural/complex; if the
  structure model and the sequence model disagree, the sequence model's permutation/attention
  importances become the follow-up question.
- **Estimand:** coefficients on (total minutes, longest run, episode count) with depth and depth
  interactions; nested likelihood-ratio tests comparing dose-only vs structure vs both; a
  bootstrap change-in-AUC with an explicit equivalence bound; a leave-one-hospital-out (LOHO)
  transport check inherited from the parent.
- **Compute (estimate, unverified):** CPU only for primary and LOHO tabular fits over ~1e5 stays;
  the optional sequence model fits on the same GPU/CPU allocation (<=16 CPU / 64 GB; << 8h).

## 4. Falsification criteria (pre-specified)
- **Supportive (structure matters):** longest-run logOR > 0 with 95% CI excluding 0 **and** its
  standardized contribution exceeds total-minutes', nested LR significant (p<0.05), it survives
  trajectory-covariate adjustment, LOHO keeps the sign in >= 60% of hospital-folds, and the
  E-value for the surviving structure coefficient is large enough to be judged implausible.
- **Adverse (dose only):** longest-run and episode-count CIs include 1 while total-minutes
  remains associated; the structure block adds no discrimination within a pre-registered
  equivalence bound (bootstrap change-in-AUC upper 95% bound < 0.01).
- **Inconclusive (pre-declared):** if `corr(total minutes, longest run) > 0.90` the contrast is
  not estimable; report a bounded-null with power, not a negative. An imprecise null does not
  refute H-structure.
- **Interpretation rules:** supportive => time-to-correction is a plausible monitoring target;
  adverse => dose integral suffices and a timing target is unjustified; inconclusive => the
  design is underpowered for the contrast and needs more hospitals/data. A null structure effect
  is a **useful negative**.
