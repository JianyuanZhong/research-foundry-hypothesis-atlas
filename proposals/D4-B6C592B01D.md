# Baseline creatinine–cystatin-C discordance and five-year consequential renal risk: a feasibility-gated UK Biobank experiment

## Lineage and unresolved question

This proposal is a substantive child of `[prior hypothesis]`. The parent is valid same-snapshot evidence, but it selected people who returned for a repeat assessment, used future-known elapsed time to that repeat, and predicted a repeat creatinine-eGFR threshold. It therefore did not test baseline deployment or a fixed-horizon clinical renal outcome.

The unresolved hypothesis is: among UK Biobank participants eligible at a baseline assessment, does one continuous baseline discordance feature, `Z = log(eGFRcys_0 / eGFRcr_0)`, add reproducible predictive information beyond a strong creatinine-only baseline model for a consequential renal event within five years, without degrading calibration or fixed-capacity event concentration?

The strongest claim supported by the parent is narrower: in the selected repeat-attender cohort, the continuous log-ratio gave reproducible held-out log-loss improvement over the inherited comparator, while its fixed-capacity benefit remained inconclusive. That result does not establish baseline deployment, five-year prognosis, measured GFR, CKD chronicity, clinical utility, causality, or transportability. This child tests those unresolved predictive claims only if endpoint ascertainment is certified.

## Stage 0: endpoint and horizon certificate (hard feasibility gate)

Before fitting any population model, produce a machine-readable certificate and stop with `FAIL_UNCERTIFIED` if any required item fails. Do not treat a blank outcome cell as a confirmed non-event unless the relevant registry completeness and censoring documentation explicitly justify that interpretation.

The certificate must establish all of the following.

1. `53-0.0` is the baseline assessment date, is parseable without participant-specific exceptions, and is the time origin. The five-year horizon is `[baseline_date, baseline_date + 5 calendar years]` with a prespecified leap-day rule (use the corresponding date in the fifth year, or the final day of February if unavailable).
2. `41270` is an ICD-10 diagnosis field, `41280` is the date of first inpatient diagnosis for the corresponding ICD-10 array, and `41270-0.j` pairs only with `41280-0.j` for every suffix `j`; no cross-suffix pairing is allowed. If the authoritative metadata instead identifies another exact code/date field pair, the study may use that pair only through a documented child amendment before execution.
3. The authoritative coding dictionary and version are available. The primary high-specificity renal event code set is frozen as the exact ICD-10 codes `N18.5`, `N18.6`, and `Z99.2` (advanced kidney failure/end-stage kidney disease or dialysis dependence), subject to confirmation that these codes are represented in the certified `41270` coding system. Prefix matching, undocumented synonyms, and post hoc code expansion are prohibited. A sensitivity definition may add `N18.4` only if declared before outcome computation; it cannot replace the primary definition.
4. For each participant, an event is present only when a certified code and its same-suffix certified date are both present, parseable, and within the horizon. A code without a paired date is not an event for the primary analysis and is reported as an ascertainment failure count. A date without a paired code is likewise not an event.
5. Death fields and their dates are semantically certified, and the release-matched death coverage end date is known. Death before a renal event is handled as a competing event, not silently as a renal non-event. The five-year renal cumulative-incidence target is estimable only when competing-event ascertainment is certified.
6. The release-matched coverage end date for inpatient diagnoses and death is known. Participants whose five-year horizon extends beyond certified observation are administratively censored at the certified end date; they are not assigned a negative outcome. If no valid censoring date or completeness rule is available, the certificate fails.
7. The baseline sample has sufficient certified ascertainment for a fixed-horizon analysis. Report counts, not rows, for valid baseline dates, biomarker completeness, certified pre-baseline renal events, competing deaths, horizon-complete participants, censored participants, and primary events. Do not impose an arbitrary event threshold before seeing the certificate; apply the prespecified support gate below.

The local snapshot currently supplies the columns but not all of these semantics, dictionaries, or coverage dates. Therefore the default status is feasibility pending, not a claim that the renal endpoint is already certified.

## Population and exclusions

The target population is all UKB participants in the one-to-one intersection of `population`, `assessment`, and `biological_samples` with:

- valid baseline date `53-0.0`;
- age at recruitment `21022-0.0` in the documented UKB recruitment range 40–69 years;
- sex `31-0.0` equal to the approved codes 0 or 1;
- finite, positive, unit-certified baseline creatinine `30700-0.0` and cystatin C `30720-0.0`;
- no certified primary renal event on or before the baseline date, using the same code/date definition;
- no use of future attendance, repeat measurements, repeat dates, future elapsed time, or future-derived eligibility.

If the registry cannot distinguish events before baseline from events after baseline, the certificate fails rather than allowing prevalent disease contamination. Baseline date, biomarker units, and assay semantics must be certified; plausible-looking numeric values do not establish units or validity.

## Predictor definitions and nested comparator

Compute race-free 2021 CKD-EPI creatinine eGFR from baseline creatinine and the certified unit conversion. Compute the prespecified 2012 cystatin-C-only eGFR from baseline cystatin C and its certified unit conversion. Define the sole extension feature exactly as:

`Z = log(eGFRcys_0 / eGFRcr_0)`.

Require both eGFR values to be finite and positive. Standardize `Z` using training-fold mean and standard deviation only. No other cystatin-C transformation, interaction, threshold, spline, repeat biomarker, or derived discordance feature is permitted.

The strong nested comparator `M0` uses only baseline variables available at deployment: an intercept, eGFRcr, age at recruitment, and sex. Model `Mc` is exactly `M0 + Z`. Use the same preprocessing, folds, regularization, and fitting procedure for both models. The comparison is incremental information from one continuous feature, not a comparison of different clinical populations.

## Outcome, estimands, and analysis

The primary outcome is five-year cumulative incidence of the certified primary renal event (first qualifying N18.5, N18.6, or Z99.2 diagnosis) with death before renal event treated as a competing event. The primary estimand is the paired participant-level difference in out-of-sample prediction quality for the five-year renal cumulative incidence under `Mc` versus `M0`.

Use repeated participant-level cross-fitting: 10 fixed, outcome/competing-event-stratified, five-fold repeats with public deterministic seeds recorded in the executable instructions. All feature preprocessing, knot choices if used, model fitting, and calibration operations must be training-fold only. There is no hyperparameter tuning. Do not use a future time variable.

Use a discrete-time competing-risk pooled-logistic implementation with person-period rows ending at five years or certified censoring. At each held-out participant, convert the fitted cause-specific event and death hazards to a five-year renal cumulative-incidence prediction by the product-integral recurrence. If a simpler implementation is used, it must reproduce this estimand and be verified against a reference implementation on aggregate test fixtures. IPCW or pseudo-observation alternatives require a substantive child proposal because they change the executable estimand.

Report, for every repeat and pooled across repeats:

- paired held-out renal cumulative-incidence Brier score difference and integrated Brier score;
- proper-score difference for the primary renal endpoint, with a two-sided 98% interval;
- discrimination, such as time-dependent AUC at five years, only as a secondary descriptive measure;
- calibration-in-the-large, calibration slope, and grouped calibration summaries for both models;
- calibration degradation of `Mc` relative to `M0`;
- fixed-capacity event concentration at a frozen 10% of eligible baseline positions, with stable tie handling and exact capacity accounting;
- prediction coverage, event support, competing-event support, censoring fraction, and fold-level counts.

Estimate uncertainty with participant-clustered bootstrap over the complete set of repeated held-out predictions and selections, while explicitly labeling conditional bootstrap uncertainty. If refit/split uncertainty is not implemented, it must be disclosed and cannot be described as full model uncertainty.

## Prespecified support and decision gates

A computational result is interpretable only if every fold has nonzero training support for the relevant event and competing event, every held-out prediction is finite, and every participant has exactly one prediction per repeat. The overall primary event count must be at least 100 and no repeat/fold may have fewer than 10 held-out primary events; otherwise classify the result as `INCONCLUSIVE_SUPPORT`, not adverse.

For a supportive incremental-information result, require all of:

1. the 98% interval for the primary proper-score difference favors `Mc` (negative difference under loss) and excludes zero;
2. at least 8 of 10 repeats favor `Mc`;
3. no calibration degradation exceeds prespecified operational margins of 0.10 for intercept/slope and 0.002 for observed-minus-predicted risk, with those margins labeled as computational tolerances rather than clinical safety thresholds;
4. fixed 10% capacity event concentration favors `Mc`, its two-sided 98% interval excludes zero, the point estimate exceeds a frozen +5 events per 10% capacity positions, and at least 8 of 10 repeats favor `Mc`;
5. coverage and censoring certificates pass and no endpoint-definition sensitivity reverses the direction.

Classify as `ADVERSE` only if a prespecified adverse condition is met: the primary proper-score interval is wholly unfavorable with at least 8 unfavorable repeats; or the extension reproducibly worsens calibration beyond the margins and fails to improve the primary score; or the fixed-capacity interval is wholly unfavorable with at least 8 unfavorable repeats. Sparse events, failed certificate items, unstable endpoint definitions, or insufficient fold support are `INCONCLUSIVE`, never adverse.

Otherwise classify as `INCONCLUSIVE`. In particular, a log-loss improvement without capacity improvement is not supportive of actionable triage, and a null result with broad uncertainty is not evidence of no biological or clinical value.

Falsification checks include a prespecified temporally impossible negative-control outcome formed only from certified records after the five-year horizon, endpoint-code/date suffix permutation tests that must not improve performance beyond the intact pairing, and a predeclared sensitivity restricting to primary inpatient diagnoses if that field is certified. These checks are falsification diagnostics, not opportunities to select a favorable endpoint. A failure of the negative control or instability under valid coding subsets falsifies the proposed mechanism of useful baseline prognostic signal or renders the result inconclusive, respectively.

## Interpretation boundaries and required next evidence

Supportive results would establish only that baseline `Z` adds internally cross-validated predictive information for the certified five-year renal endpoint in this UKB snapshot, under the stated missingness and censoring rules. They would not establish that cystatin-C testing improves outcomes, that the feature measures true GFR, that CKD is chronic, that a clinician should change management, or that the model transports to nonattenders or other health systems.

Adverse results would provide evidence against incremental predictive value or operational concentration under this prespecified protocol, while still not proving absence of biological association. Inconclusive results would identify a data or precision boundary and should not be converted into either clinical endorsement or rejection.

Clinical adjudication remains necessary for assay traceability, CKD chronicity, whether the selected codes represent clinically consequential kidney failure, consequences of false positives and negatives, and whether the 10% capacity and calibration margins correspond to a real decision. External validation, a decision-curve/cost study, and preferably measured GFR or longitudinal adjudicated CKD are required before any deployment or utility claim. The parent result remains internal same-snapshot evidence and is not prospective confirmation.
