## Precision of the overall RD (COMPUTED formula + assumptions)
Two-proportion risk difference, `SE(RD) = sqrt(p(1−p)(1/n1 + 1/n2))`; MDE at 80 % power = `2.80·SE`; 95 % CI half-width = `1.96·SE`.
- Optimistic (split the whole 65,366 cohort, p=0.1346): MDE ≈ **0.75 pp (80 %)**; 95 % CI ±0.52 pp. *Not realistic* — only the analyzable subgroup is exposed/eligible.
- Realistic **analyzable subgroup** (exposed 9,482 vs continuation 15,696 from the 37.66 % proxy):
  - p=0.1346 → SE 0.00444, **MDE 1.24 pp**, 95 % CI ±0.87 pp.
  - p=0.25 (Zhang-like 30-day mortality in this sicker subgroup) → SE 0.00563, **MDE 1.58 pp**, 95 % CI ±1.10 pp.
- Event count inside the analyzable subgroup (COMPUTED by range): ~**3,300** if 13 % mortality → ~**6,300** if 25 %.
- **Conclusion (COMPUTED):** at the observed N the design can separate an overall RD only if |RD| ≳ **1.3–1.6 pp**. This is the same order as the closest prior's precision (K1: antipseudomonal CI ±2.5 pp, anti-MRSA ±2.4 pp), so the effect is *estimable but not finely resolved*.

## Rewritten bands (overall 28-day mortality RD, de-escalation − continuation)
Reference **harm margin = +1.0 pp** (a clinically meaningful increase in 28-day mortality). Bands are stated so every branch is reachable at the observed N:
- **Supportive** (no clinically meaningful harm; possibly benefit): point RD < 0 **and** 95 % CI upper bound < +1.0 pp.
- **Adverse** (clinically meaningful harm): 95 % CI lower bound > +1.0 pp.
- **Inconclusive (falsifiable, prespecified):** the 95 % CI straddles +1.0 pp (upper bound ≥ +1.0 pp and lower bound ≤ +1.0 pp) — i.e. the data cannot rule out harm > 1 pp. At the observed precision this is the **expected** outcome for a true null (CI ≈ ±1.1–1.6 pp), so it is a genuine, attainable result rather than an unfalsifiable fallback.
- **Interaction `Delta = RD(non-improving) − RD(improving)`:** powered only for |Delta| ≳ **2–2.5 pp** (each stratum has ~1/2 the events of the analyzable subgroup ⇒ ~1.4–3,100 events); **Delta below this is prespecified inconclusive** and must not be reported as evidence of no interaction.

## What each outcome would / would not establish
- **Supportive:** the average safety claim survives at this precision; it would *not* establish benefit, mechanism, or safety in the non-improving stratum unless Delta is also resolved.
- **Adverse:** would challenge K1's fixed-day-4 safety signal at a culture-result landmark; requires adjudication that the crude proxy really captured de-escalation.
- **Inconclusive:** the honest ceiling of this single-centre retrospective design; motivates either a larger/adjudicated cohort or abandonment of the interaction claim.
