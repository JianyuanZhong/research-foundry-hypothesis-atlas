# Bounded, auditable state/opportunity residual test of the frozen eICU respiratory-label trajectory

## Scope and substantive repair

This is a compiler-ready successor of assessed-valid `[prior hypothesis]` and `[prior hypothesis]`. It preserves the Lead-frozen scientific schema exactly: 540 person-landmark rows, 443 distinct first qualifying ICU stays/persons, 74 hospitals; the first qualifying stay per `uniquepid`; landmarks `L ∈ {1440, 2880, 4320, 5760, 7200}` minutes after ICU admission; the first exact target label in `[L,L+360]`; `D = cplitemoffset`; inherited pre-landmark exclusions; exact literal labels; fixed B/E/T windows, parser, thresholds, K-state precedence, and repeated-landmark clustering by `patientunitstayid`. It remains descriptive and noncausal.

The strongest evidence available before execution supports only that the two literal care-plan values are sparse, hospital-heterogeneous structured documentation and that apparent associations can be produced by pre-existing state, documentation opportunity, source density, exits, persistence, or site practice. It does not establish SBT, extubation evaluation, clinician intent, readiness, delivered settings, treatment, benefit, harm, quality, or causality. The falsifiable unresolved claim is narrower: after using only information available before `D` and explicitly separating respiratory state from value-blind documentation opportunity, does the exact current label add reproducible information about a later independently constructed respiratory-chart trajectory in hospitals held out from fitting? A secondary, operational question is whether that increment changes a fixed queue for manual chart review; this is not patient utility.

The repair is execution-focused rather than a schema change. The primary computation is a deterministic, sparse-safe generalized-linear pipeline with a preflight that fails before outcome reads on any frozen-artifact, source, schema, time, or leakage mismatch. The Apache branch is deliberately excluded from the primary experiment and is not run as an unverified first-day covariate: the available `apacheApsVar` schema has no temporal field, and `sicuday=1` alone is not proof that values precede every landmark. Apache may be audited for exclusion only. This avoids spending bounded compute on a sensitivity whose timing cannot be established and avoids adding an unsupported clinical interpretation.

## Bounded primary analysis

Use leave-one-hospital-out folds. Hospitals, not rows, define folds; all landmarks for a `patientunitstayid` remain in one fold. No hospital indicator or held-out-site intercept is used. All imputation, scaling, regularization, calibration, state/opportunity cutpoints, and observation weighting (if used) are fit inside training hospitals only.

To make the experiment auditable under bounded compute, use a fixed sparse multinomial logistic regression with ridge penalty for each target, with no hyperparameter search. The prespecified penalty is `C=1` on standardized numeric features; categorical landmark and label indicators use one-hot encoding with a fixed reference level. Missing numeric values use training-fold medians and missingness indicators; no endpoint-derived feature is imputed. Fit with deterministic solver, fixed coefficient tolerance, fixed iteration cap, and deterministic row ordering. If convergence fails within the cap, mark that fold/metric unavailable rather than silently substituting another estimator. Use `M0` = pre-D state plus opportunity, no current label; `M1` = identical predictors plus exact current two-level label; and `Mopp` = opportunity only, no state values and no label. The fixed pipeline is run once per held-out hospital and target, not tuned on the held-out rows.

The primary target is the five-state K vector for all 540 rows. Report multiclass log loss and Brier score with all rows in the denominator, including competing exits, invalid exit timing, and non-exit unobservability. Report a separate classifiable-only descriptive target view only when its denominator and support are explicitly available; it never replaces all-row accounting. The label increment is `M1-M0`; `Mopp` is a comparator for opportunity-only information, not a substitute for M0. Report micro row-weighted metrics and equal-hospital macro metrics, with hospital-level contributions and fold support. Use no post-hoc threshold or feature selection.

For the state/opportunity diagnostic, within each training fold calculate a scalar state score from permitted state summaries/missingness and baseline airway/vital summaries and a scalar opportunity score from permitted value-blind counts, distinct timestamps, spacing, and entry-lag summaries. Use tertiles only if every bin is nonempty in training; otherwise use a deterministic median split; deterministically collapse sparse cells without using label, K, H, or effect direction.
