# Provisional HCC hypothesis: trajectory value versus care-process artifact

## Proposed relationship
Among adults admitted with an exact documented HCC diagnosis, an ordered 7-day laboratory trajectory (liver, coagulation, renal, and tumor-marker assays) will add held-out predictive information about a subsequent inpatient, non-routine procedure-based escalation proxy beyond an admission snapshot. The primary comparison is predictive, not causal.

## Clinical importance and rival explanation
This matters if temporal monitoring could identify patients for expert review before escalation. The strongest rival is that apparent trajectory value is a care-process artifact: treatment indication, routine HCC procedures, severity selection, or documentation intensity generate both measurements and procedures. A supportive result would therefore require incremental value for a prespecified non-routine endpoint, reduced value for routine treatment procedures, and no value in a timing-shifted negative control. An adverse result would favor the artifact explanation; an inconclusive result would leave the monitoring claim unresolved.

## Exact data and computable experiment
Use only the HCC dataset. The provisional binding is the HCC encounter/snapshot source, the HCC laboratory source, and the HCC procedure/treatment source identified in the HCC README and catalog; the solver must resolve the exact source paths, table names, columns, join keys, and time fields from those read-only files before fitting. The population is adults with an exact HCC diagnosis and a valid admission time. Define admission as the encounter time, restrict laboratory features to admission through day 7, and define the primary outcome as a prespecified non-routine procedure occurring after the 7-day window and before discharge. Routine HCC treatment procedures are a secondary endpoint, not the primary outcome.

The simple baseline is a regularized logistic model using admission snapshot demographics, admission department, treatment/procedure indicators, and documentation intensity. The substantive alternative is a time-aware model using ordered assay values, within-assay slopes or persistence, missingness timing, and cross-marker interactions over the same 7-day window. Fit and evaluate on a prespecified patient-level held-out split, with uncertainty intervals for incremental discrimination/calibration and a prespecified trivial margin. Include a timing-shifted negative control and compare routine versus non-routine endpoints. No fitted effect is claimed here.

## Evidence status and missing evidence
The prior episode audit reported HCC encounter, laboratory, and procedure support and exact source-bound counts, but this provisional draft has not re-inspected the current source files or frozen literature receipts. The three key inspected works, their claim mappings, and the final endpoint dictionary/clinical adjudication are not yet attached. Laboratory units, assay comparability, procedure semantics, discharge status, and external validation remain unresolved. These are feasibility and interpretation limits, not evidence against the hypothesis.

## Falsification and interpretation
Supportive: the temporal model exceeds the snapshot baseline by more than the trivial margin on held-out data for the non-routine endpoint, with uncertainty excluding the margin, and the timing-shifted control is null. Adverse: no incremental value, or value appears only for routine procedures/documentation controls. Inconclusive: wide intervals, insufficient endpoint support, or unresolved assay/unit validity. None establishes that a procedure is death, ICU admission, clinical deterioration, or harm; those claims require clinical adjudication or another study.

## Method choice and deliverable
The baseline is selected because it directly tests whether static severity and care-process variables suffice. The temporal alternative is selected because it can reveal persistence, cross-marker ordering, and time-varying missingness that a snapshot discards. A neural or mechanistic model is deferred unless the bounded temporal comparison is feasible and scientifically informative; complexity alone is not a reason to prefer it. The solver must newly fit both models, estimate held-out uncertainty and negative-control results, and report whether the endpoint and assay assumptions are adequate.
