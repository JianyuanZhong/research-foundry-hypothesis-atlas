# Broad-deployment adverse loss is not explained by a single model specification; calibration remains a limited alternative explanation

## Substantive child and unresolved question

This is a targeted substantive child of assessed-valid `[prior hypothesis]`. The parent found a small adverse broad-deployment loss for adding the exact three-state care-plan feature (`evaluation`, `no_trial`, `missing_exact_target`) to a frozen structured-chart baseline under leave-one-hospital-out evaluation. The parent appropriately established that this is a structured-documentation fitness result, not evidence about actual ventilation, SBT performance, extubation, care quality, benefit, harm, or causality.

The remaining inferential ambiguity is whether the adverse loss is primarily (i) a site/intercept calibration shift that could be mitigated by local recalibration, or (ii) a reproducible degradation that persists across regularization choices and is not attributable to one proxy component. The prespecified child hypothesis is that if the loss is only an intercept problem, a training-only, nested local-intercept recalibration should remove most of the label-minus-baseline loss; conversely, if label-model degradation is robust to L2 regularization and remains after calibration, the broad-deployment adverse interpretation is strengthened. A secondary component question asks whether one of the four composite outcome components accounts for the result. The frozen parent artifact does not contain component-specific post-window reduction flags, so a definitive component-attribution analysis is infeasible without reopening the raw extraction; the available paired-component strata are reported transparently rather than treated as attribution.

**Strongest claim supported before this child:** the parent’s exact model specification produced small positive broad-deployment loss deltas, especially for the bounded-airway variants, with site-balanced worsening and conditional stay-cluster uncertainty. This does not establish that the exact care-plan feature causes degradation.

**Untested claim addressed here:** the parent adverse result is not merely an artifact of C=1 logistic shrinkage, and it is not substantially rescued by an intercept-only recalibration that uses no held-out outcomes. The child also tests whether calibration shifts are comparably present in baseline and label models.

## Computable experiment

### Primary held-out estimand

For every airway definition, hospitals are eligible when they have at least 20 frozen outcome-observed rows and variation in `robust_reduction`, regardless of local exact-target receipt. Each outer fold holds out one eligible hospital. The baseline and label models are fit only on the other hospitals. The baseline has one-hot `landmark` plus the seven frozen numerical documentation/setting variables; the label model adds one-hot `label3`. Numerical variables use median imputation with missingness indicators and standardization; categorical unknown levels are ignored. The outcome is the frozen post-classification composite `robust_reduction` (any qualifying reduction in FiO2, PEEP, pressure support, or set ventilator rate), not a bedside event.

### Model/regularization sensitivity

The parent model is reproduced at L2 logistic-regression `C=1.0`, and prespecified sensitivity fits use `C=0.1` and `C=10.0`, all with the same features, preprocessing, solver family, and `max_iter=2000`. For every C, held-out predictions are retained for the same row-weighted micro and equal-hospital macro log-loss/Brier/AUROC comparisons. No C is selected using held-out outcomes.

### Calibration/intercept sensitivity

For each outer held-out hospital and each model, an intercept-only adjustment is estimated using only the outer training hospitals. Specifically, inner leave-one-training-hospital-out predictions are generated across the training hospitals, and a single scalar log-odds offset is chosen to minimize inner pooled log loss. That offset is then applied unchanged to the outer held-out hospital predictions. The held-out hospital’s outcomes are never used to estimate the offset. This is a transport-calibration sensitivity, not a claim that local recalibration is available prospectively; it avoids test-outcome leakage but still uses a potentially optimistic pooled training-site calibration target. Raw outer predictions remain the primary result.

The comparison reports raw and recalibrated label-minus-baseline deltas, hospital-specific deltas, mean prediction, observed-minus-predicted calibration, and the estimated offsets. The parent’s 300-resample stay-cluster bootstrap remains the uncertainty analysis for its primary raw results; this child does not relabel the conditional bootstrap as full model-training uncertainty. A nested refit bootstrap or independent temporal/multisite replication would be needed for that stronger uncertainty claim.

### Component-specific feasibility and available audit

The frozen artifact has four paired-component indicators but only one composite `robust_reduction` flag. Therefore it can report, for each airway definition and each component, paired-row/stay/hospital coverage and the composite event rate among rows where that component is paired. It cannot determine whether a particular component generated each positive composite outcome, nor fit component-specific labels without reopening the exact raw extraction. This limitation is an explicit falsification boundary: no component dominance claim is made from these strata.

## Interpretation gates

**Supportive for a pure calibration explanation:** if training-only recalibration removed the raw adverse deltas for most definitions, especially the bounded variants, while leaving component coverage and regularization otherwise stable. This was not observed.

**Adverse to the single-intercept/specification explanation:** if raw loss remains positive across C values and at least two bounded variants remain positive after leakage-free recalibration, with similar calibration offsets in baseline and label models. The executed result meets this descriptive robustness pattern for unbounded, 24-hour, and 6-hour variants; the 12-hour recalibrated result is a prespecified qualification, not hidden.

**Inconclusive:** if recalibration crosses zero for multiple variants, if effects are so small that nested training uncertainty could reverse them, or if component attribution is required. The 12-hour recalibration crossing zero and the absence of component-specific outcome flags keep the strongest conclusion appropriately qualified.

The resulting clinical-scientific conclusion is that the parent’s small adverse broad-deployment loss is unlikely to be explained solely by a universal intercept shift or by the selected C=1 specification. It is more consistent with modest, heterogeneous incremental misfit of the exact care-plan feature under the frozen structured-documentation proxy, particularly for 24-hour and 6-hour airway definitions. This is not evidence of clinical harm. It also does not establish that no individual hospital could benefit from separately validated local calibration or that any single outcome component is responsible.
