# Measurement-process-matched test of the latest intermediate assay value after repeat TACE

## Unresolved question, clinical relevance, and evidence boundary

Among adults already selected for a recorded first repeat TACE and an observed complete same-assay `B/P/Y` triplet, does the numeric result of the latest leakage-safe intermediate albumin or total-bilirubin measurement improve prediction of the next observed same-assay value `Y` after the model already knows:

1. the contemporaneous pre-repeat value `P`;
2. the remote pre-TACE2 anchor `B`;
3. a compact decision-time core; and
4. whether, how often, and how recently the assay was measured between TACE2 and repeat TACE?

This is a prognostic feature-value experiment, not a treatment-effect or monitoring-intervention experiment. Its clinical relevance is deliberately narrow but consequential for the next research step. If the archived intermediate numeric result adds reliable prediction after the current and remote values and the measurement process are known, future decision-support work should preserve and externally validate that longitudinal numeric feature rather than reducing the record to current state plus a baseline anchor. If a precise null is found, extracting the intermediate numeric result may be unnecessary for this locked prediction task, although the act of measuring and its clinical context can remain informative. An adverse result would justify omitting this numeric feature from the locked model, not reducing laboratory monitoring or changing TACE care.

The strongest evidence-supported claim is feasibility only. The inherited complete-source, outcome-direction-blind audit scanned all rows in the five required HCC sources and reproduced 319 systemic-record and 1,491 comparator pathway patients, 159 and 526 selected repeat events, 40/118 albumin triplets, and 41/119 total-bilirubin triplets. A qualifying intermediate value exists for 37/40 systemic and 108/118 comparator albumin triplets and 38/41 systemic and 108/119 comparator bilirubin triplets. Median intermediate timestamp count is one in each assay-arm cell; only 18 systemic and 42 comparator patients per assay have at least two intermediate timestamps. The audit inspected neither `Y` direction nor predictor-outcome association nor any fitted outcome model.

The unresolved falsifiable claim is that the patient-matched numeric `L` value adds reproducible out-of-fold prediction beyond `P`, `B`, compact covariates, and the identical measurement-process variables in both models. Support establishes only incremental prediction of the next *observed* same-assay value in this selected, observed cohort. It cannot establish toxicity, hepatic failure, treatment response or benefit, causal value of measuring, decision utility, or a reason to alter TACE or systemic therapy.

## Locked `B/P/Y` and leakage-safe intermediate history

For each selected repeat event and assay define exactly:

- `B`: latest valid uncensored result on TACE2 calendar days −30 through −1; day 0 is excluded.
- `P`: latest valid uncensored result in `event_encounter` during `[event_time−72 hours,event_time)`; exact `event_time` is excluded.
- `Y`: valid uncensored result in the same `event_encounter` during `(event_time,event_time+72 hours]` nearest nominal `event_time+24 hours`; choose the earlier timestamp on an exact-distance tie.

The assay-specific evaluation cohort requires `B`, `P`, and `Y`. Expected counts are albumin 40 systemic/118 comparator and total bilirubin 41/119. Albumin and bilirubin remain separate native-value outcomes and patient sets. No cross-assay pooling, rank score, change outcome, threshold classifier, or joint numeric score is allowed.

Define `H_rows` for the exact same assay label by all of the following:

1. `Test time >= tace2_time`;
2. `Test time < event_time−72 hours`;
3. `test time < P_time`;
4. normalized `visit number != event_encounter`;
5. valid uncensored parser and locked duplicate rule.

Preserve every qualifying distinct timestamp for counting. `L` is the numeric value at the latest qualifying timestamp, with final source order resolving an exact-time concordant tie. Define `H_any=1[N_H>0]`, `N_H` as distinct qualifying timestamps, `logN=log(1+N_H)`, and `R_hours=event_time−L_time` when observed. These are all pre-outcome.

The feasibility audit supports only this one-value representation: `H_any` occurs in 37/40 and 108/118 albumin triplets and 38/41 and 108/119 bilirubin triplets, while median `N_H` is one. Do not fit slopes, extrema, variability, splines, sequence models, trajectory clusters, or value-by-time interactions. Do not require `H_any=1`; the frozen complete-triplet population is retained.

When `H_any=0`, training-fold median-impute `L` and `R_hours`; retain `H_any=0`, while `logN=0`. Consequently the added numeric feature is deployable as “latest value if recorded” without equating absence with a measured median. All imputation and scaling use outer-training data only.

## Matched nested models and sole primary estimand

For each assay fit the same patients and folds:

`M_obs: Y ~ P + B + arm + age + sex + TACE2_to_repeat_days + P_lead_hours + H_any + logN + R_hours`

`M_value: Y ~ P + B + arm + age + sex + TACE2_to_repeat_days + P_lead_hours + H_any + logN + R_hours + L`

where `P_lead_hours=event_time−P_time >0`.

The models are deliberately identical except for numeric `L`. Thus the primary contrast cannot attribute information carried by assay availability, count, or recency to the numeric history value. `H_any`, `logN`, and `R_hours` are nuisance controls for the observation process, not trajectory or biological claims. The prior three-model `M_P/M_B/M_L` decomposition is reduced to this single decision-relevant comparison; the already established remote-anchor question is not retested as a second primary endpoint.

The sole primary assay-specific estimand is

`Delta_value,a = [RMSE_a(M_obs) − RMSE_a(M_value)] / SD_a(Y)`.

Both RMSEs use paired pooled out-of-fold predictions. `SD(Y)` is the sample standard deviation over the full assay-specific evaluation cohort, computed once. Higher values favor retaining the numeric intermediate result. Also report native RMSE and MAE for both models, `Delta_value,MAE`, pooled cross-fitted R-squared, prediction variance, fold errors, and arm-stratified descriptive errors. Calibration intercept/slope are descriptive; they do not become an undefined “material calibration” veto.

Use ridge linear regression with unpenalized intercept and penalties `{0.01,0.1,1,10,100}`. Select penalty separately for each model and outer training fold by inner leave-one-patient-out MSE; exact ties choose the smaller penalty. Median-impute numeric age using outer-training data and include age-missing only when it has training variance. Encode literal male as reference with fixed female and unknown/other/missing indicators. Remove any variance-zero indicator from both compared models in that fold under the same deterministic rule. Center/scale continuous predictors from outer-training data only. No replacement model may be selected after outcomes are inspected.

## Focused uncertainty and falsification

The following replaces the parent's stacked full-pipeline bootstrap, broad clock search, OLS diagnostics, and overlapping favorable-result vetoes with checks that target the actual claim.

1. **Conditional magnitude uncertainty.** Use 2,000 fixed-seed (`20260910`) stratified patient bootstrap replicates of frozen r00 paired OOF tuples `(arm,Y,pred_Mobs,pred_Mvalue)`, sampling within arm. Recompute RMSE, `SD(Y)`, and `Delta_value`. Require at least 95% estimable replicates and report the two-sided percentile interval. This interval is explicitly conditional on the fitted cross-validation pipeline; it does not include all training-set uncertainty. Partition repetition addresses split instability. It is not called an exact test.
2. **Patient-linkage destruction, primary falsification.** In each of 999 fixed-seed permutations, permute *numeric `L` only* among `H_any=1` patients within assay, arm, and r00 outer fold; keep `L_time`, `R_hours`, `H_any`, `logN`, `B`, `P`, `Y`, covariates, and folds fixed. Rerun all training-only preprocessing, tuning, and both model fits. This repairs the inherited internally inconsistent instruction to permute `(L,L_time)` while also preserving recency. Compute `p_link=(1+# permuted Delta_value >= observed Delta_value)/(1+999)` and Holm-adjust the two assay-specific `p_link` values. A favorable result requires observed delta above the 95th permutation percentile and Holm-adjusted `p_link<0.05`. This tests patient-specific numeric matching conditional on the recorded measurement pattern; it is not a causal randomization test.
3. **Observation-process audit, not a second outcome model.** Report `H_any`, `N_H`, and `R_hours` by assay, arm, and fold. Also report associations of `H_any` with arm, age, sex, event year, TACE2-to-repeat days, and `P_lead_hours` using counts/SMDs and a descriptive cross-fitted logistic model. Do not weight on `H_any`, exclude missing-`L` patients, or use this model as a favorable-result veto. Structured observation is expected and is handled by identical controls plus linkage destruction; it still limits transportability.
4. **Triplet-selection sensitivity.** Among all 159/526 selected repeat-event patients, model locked assay-specific triplet observation using only arm, age, sex, TACE2-to-repeat days, and event year in five-fold cross-fitting. Among observed triplets, calculate stabilized inverse-observation weights, truncated at fixed 1st/99th percentiles, and recompute paired OOF metrics without refitting the outcome models. Report probability range, balance, weight concentration, and arm-specific ESS. A favorable result is selection-sensitive if systemic ESS is below 30, comparator ESS below 80, one patient carries over 10% of total weight, weighted delta reverses sign, or `|weighted−unweighted Delta_value|>0.05`. Extreme probabilities are reported rather than serving alone as a veto after truncation. This MAR-style sensitivity cannot recover unobserved `Y` or remove collider bias.
5. **Prediction-aligned influence.** From r00 OOF tuples compute every patient's paired squared-error improvement and each leave-one-patient-out `Delta_value`. A favorable result is influence-sensitive if deleting any one patient reverses the sign or changes delta by more than 0.05, or if one patient contributes over 20% of the sum of absolute patient-level squared-error improvements. Do not use OLS Cook's distance or DFBETA as gates for a ridge cross-fitted estimand.
6. **Temporal and join assertions.** Assert every `B/H/P/Y` selector; no `H` row is in `event_encounter`, at/after `P`, in the 72-hour buffer, or post-event; no held-out values enter preprocessing; and no join multiplies a selected row. Any violation stops inference. The frozen `B/P/Y/H` clocks are not replaced by a broad outcome-dependent timing search.
7. **Repeat-event and pseudo-current selection.** Report the 319/1,491 to 159/526 cascade and event timing by arm. Do not weight back to patients without a repeat event because their repeat-event-centered outcome is undefined. Retain the inherited negative-feasibility fact that only 0 systemic/1 comparator patient per assay has the locked `B`, event-days −14 to −8 pseudo-current candidate, and primary `P`; do not widen it. This blocks event-specific or mechanistic interpretation, not the generic prognostic estimand.

No arm interaction, pathway-specific effect, assay threshold search, binary toxicity classifier, non-target assay control, joint score, decision-curve analysis, or clinical-utility claim is permitted.

## Deterministic interpretation branches

Apply precedence separately by assay. A two-assay statement additionally requires Holm-adjusted linkage evidence and concordant branches.

1. **Negative-feasibility/reconstruction-inconclusive.** Snapshot/source mismatch; unexplained failure to reproduce 319/1,491, 159/526, assay triplets, parser/duplicate facts, history/fold/rank support; or a clock/join/leakage violation. Do not widen the cohort or clocks, replace `L`, or choose another assay representation.
2. **Computationally inconclusive.** Post-drop rank/variance failure, pooled `SD(Y)=0`, non-executable locked ridge, or fewer than 95% estimable tuple bootstraps.
3. **Selection-, partition-, influence-, or linkage-sensitive/inconclusive.** Any corresponding focused gate fails. Report the favorable point estimate, but do not call it reliable numeric-history evidence.
4. **Adverse degradation.** Prior gates pass and the r00 95% interval for `Delta_value` lies wholly below zero. Conclude only that adding numeric `L` worsened prediction under the locked model. This argues against using `L` in this model, not against measuring the assay or against clinical monitoring.
5. **Supportive numeric-history evidence.** Prior gates pass; r00 `Delta_value>=0.05`; its unadjusted 95% interval excludes zero; `Delta_value,MAE>=0`; at least 16/20 partition deltas are positive with positive median; and observed delta exceeds the 95th linkage-permutation percentile with Holm-adjusted `p_link<0.05`. Conclude only that the latest prespecified leakage-safe numeric same-assay result adds reproducible prediction beyond current `P`, remote `B`, compact covariates, and the measurement pattern in selected observed repeat-TACE episodes. This supports retaining the numeric longitudinal feature for external validation; it does not show that ordering an extra assay improves care.
6. **Precise null for the prespecified increment.** Prior computational and focused sensitivity gates pass and the r00 interval upper bound is below `+0.05`. Conclude that this design rules out a gain of 0.05 standardized RMSE under the locked model and conditional uncertainty convention. For future model development this favors the simpler `P+B+measurement-process` representation, but it does not justify reducing clinical testing and does not establish equivalence, absence of biology, or absence of all possible history effects.
7. **No demonstrated patient-specific numeric increment.** Point estimate is below 0.05, MAE does not improve, or linkage destruction reproduces the gain, without an adverse or precise-null interval. State that current `P`, remote `B`, and/or measurement pattern may exhaust the available predictive signal; no claim about monitoring utility follows.
8. **Inconclusive.** The interval spans both meaningful degradation and `+0.05`, or any remaining prespecified ambiguity exists.

A panel-level supportive statement requires both assays to satisfy branch 5. A panel precise-null or adverse statement requires both assays to satisfy that same branch type. Otherwise report discordance assay by assay. The `0.05` margin is a design convention on standardized prediction error, not a validated clinically important difference.

## Missing evidence, noncausal limits, and verifier boundary

HCC lacks laboratory units/reference ranges, analyzer harmonization, adjudicated hepatic decompensation or complications, Child–Pugh/MELD context, tumor burden or radiographic response, technical TACE success/intent, transfusion/albumin infusion/fluid balance, infection/bleeding, verified medication administration/adherence/dose, outside care, and reliable mortality. Diagnoses are lexical encounter proxies without native time. Conditioning on a repeat event and complete `B/P/Y` observation can induce selection/collider bias. `Y` is an observation-process endpoint.

A verifier can check hashes and full scans; exact paths, columns, keys, joins, parsing and duplicates; cohort/event reconstruction; `B/H/P/Y` clocks; fold hashes and support; rank/variance removal; training-only ridge computation; paired OOF metrics; tuple bootstrap arithmetic; numeric-only linkage permutations and Holm correction; triplet weighting; influence metrics; and branch precedence. It cannot establish clinical importance, toxicity, hepatic failure, causation, treatment benefit, mechanism, administration, decision utility, monitoring policy, or transportability. Stronger conclusions require unit-validated assays, adjudicated actionable outcomes, verified treatment and procedure details, complete follow-up, external/prospective validation, and expert evaluation of whether using longitudinal results changes decisions and net benefit.
